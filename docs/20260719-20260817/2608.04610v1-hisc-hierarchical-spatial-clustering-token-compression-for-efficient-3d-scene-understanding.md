## 摘要
3D视觉-语言模型（3D VLMs）能够对多视角场景进行空间推理，但由于重复观测和大量无信息区域导致显著的令牌冗余，从而带来高昂的计算成本。尽管视觉令牌压缩在加速2D VLMs方面显示出潜力，但它无法捕捉3D场景的结构化特性，导致空间覆盖不完整和细粒度细节丢失。在本文中，我们提出了\textbf{HiSC}，一种用于3D VLMs中分层空间聚类令牌压缩的无需训练框架。HiSC通过利用几何和语义联合线索将令牌组织为空间锚定的聚类，将令牌压缩从令牌级选择提升到聚类级处理。具体来说，我们首先引入一种\textbf{基于空间图的合并（SGraM）策略}，该策略将跨视图冗余建模为空间连通性，并整合物理一致的区域，从而在LLM推理之前有效合并极其相似的冗余令牌。然后，我们在LLM推理中提出了一种\textbf{基于空间聚类的剪枝（SCluP）范式}，该范式在聚类间和聚类内执行分层压缩，在保留重要区域细粒度细节的同时保持对象实例完整性。在多种3D推理基准上的大量实验验证了HiSC的有效性，尤其是在高视觉令牌剪枝比率下。此外，HiSC在性能损失最小的情况下实现了超过90%的令牌缩减。代码可在 https://github.com/elecreak/HiSC 获取。

## Abstract
3D vision-language models (3D VLMs) enable spatial reasoning over multi-view scenes but suffer from substantial token redundancy due to duplicated observations and large uninformative regions, leading to high computational cost. Although visual token compression has shown promise in accelerating 2D VLMs, it fails to capture the structured nature of 3D scenes and leads to incomplete spatial coverage and loss of fine-grained details. In this paper, we propose \textbf{HiSC}, a training-free framework for hierarchical spatial clustering token compression in 3D VLMs. HiSC lifts token compression from token-level selection to cluster-level processing by organizing tokens into spatially grounded clusters using joint geometric and semantic cues. Specifically, we first introduce a \textbf{spatial graph-based merging (SGraM) strategy} that models cross-view redundancy as spatial connectivity and consolidates physically consistent regions, effectively merging extremely similar redundant tokens prior to LLM inference. We then propose a \textbf{spatial clustering-based pruning (SCluP) paradigm} within LLM inference, which performs hierarchical compression across clusters and within clusters, preserving object instance completeness while retaining fine-grained details for important regions. Extensive experiments on diverse 3D reasoning benchmarks show validate the effectiveness of HiSC, particularly under high visual token pruning ratios. Besides, HiSC achieves over 90\% token reduction with minimal performance degradation. Code is accessible at https://github.com/elecreak/HiSC.

## 2. 论文提出的方法论

### 2.1 总体框架：HiSC

HiSC是一个**无需训练（training-free）** 的加速框架，核心思想是：利用几何邻近性和语义相似性将token组织为空间锚定聚类（spatially grounded clusters），并在聚类级别上进行多层次的压缩处理。框架由两大互补模块组成：

### 2.2 模块一：空间图合并（SGraM，Spatial Graph-based Merging）

- **目标**：在进入LLM推理之前，消除多视角输入中的结构化冗余。
- **关键思想**：将跨视角冗余建模为**空间连通性**，而非单纯的全局特征相似性。
- **技术流程**（两阶段建模）：
  1. **几何-语义邻接矩阵构建**：分别计算几何邻接（3D欧氏距离 < τ_geo）和语义邻接（特征余弦相似度 > τ_sem），再将两者逐元素相乘得到统一邻接矩阵。只有**空间相邻且外观高度相似**的token之间才建立连接，避免错误聚合。
  2. **连通分量提取与合并**：将邻接矩阵视为无向图，提取连通分量，每个连通分量近似对应一个物理一致区域。对每个分量内的token进行特征和位置的均值聚合，生成超级token（super-token），在不破坏空间布局和语义一致性的前提下实现去冗余。
- **设计优势**：连通性的**传递性**可以捕捉物理连续表面上空间跨度大但局部结构一致的token组，同时避免将外观相似但空间不连通的对象错误合并。

### 2.3 模块二：空间聚类剪枝（SCluP，Spatial Clustering-based Pruning）

- **目标**：在LLM推理过程中，根据层次化策略进行token剪枝，同时保证对象级覆盖和重要区域细节保真。
- **步骤一：对象中心空间聚类**：
  - 先进行语义分组（K_sem = 16个语义聚类），再在每个语义组内通过空间邻接矩阵提取连通分量，实现物理实例的分离；
  - 这种"先语义、后空间"的设计可避免：纯语义分组混淆视觉相似但空间隔离的对象；纯空间划分无法捕捉语义身份。
- **步骤二：层次化聚类级剪枝**：
  - **聚类间预算分配**：根据各聚类重要性的平方按比例分配token预算，且每个聚类至少保留1个token——确保对象不消失、全局空间覆盖；
  - **聚类内token选择**：结合重要性选择与多样性采样，定义联合空间-语义距离（公式5）来促进结构多样性，使选中的token既具有区分度又覆盖簇内不同结构。

## 6. 论文的主要结论与发现

- **高效性与有效性的统一**：HiSC在Light和Medium压缩下几乎无损（相对分数98.87%和97.14%），在Extreme压缩（约90% token缩减）下仍能保持92.46%的相对性能，远超所有基线方法。
- **结构化冗余消除缓解注意力稀释**：在轻度和中等压缩时性能几乎与原始模型持平，说明有结构地去除冗余token不仅无害，反而能减少注意力分散。
- **连通性建模优于纯相似性建模**：解耦的几何-语义连接比纯语义、纯几何或3D特征纠缠的方式更准确可靠，验证了空间连通性对识别物理一致区域的关键作用。
- **层次化剪枝优于层级单一剪枝**：聚类级预算分配+聚类内多样性选择能同时保证对象完整性和细节保真，避免了token级剪枝的碎片化和cluster级剪枝的区域消失问题。
- **两模块互补**：SGraM在推理前安全去冗余，SCluP在推理中提供自适应结构化分配，二者缺一不可。

## 7. 优点

- **视角新颖**：将token压缩从token级提升到聚类级处理，与3D场景的物理组织结构对齐，是区别于现有2D压缩方法的本质创新。
- **免训练即插即用**：无需任何重训练或微调，直接应用于预训练模型，部署成本极低，工程实用性强。

- **层次化设计合理**：SGraM（LLM前合并）与SCluP（LLM内剪枝）形成互补流水线，前者消除大规模结构化冗余，后者处理推理中的动态冗余。
