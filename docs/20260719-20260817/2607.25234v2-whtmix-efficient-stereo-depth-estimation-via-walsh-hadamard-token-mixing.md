## 摘要
用于驾驶、机器人和增强现实的立体深度估计必须在严格的延迟预算下以高分辨率运行，然而在基于Transformer的匹配器中，聚合场景上下文的全局自注意力随像素数量呈二次增长，并最终主导运行时间。我们证明，立体Transformer中的联合自注意力阶段（其作用是在两个视图之间传播上下文）可以被一种数据无关的Walsh-Hadamard令牌混合器所替代，该混合器在对数线性成本下于变换域中全局混合令牌，同时保留执行左右对应关系的数据相关交叉注意力。在合成驾驶数据上，该混合器在端点误差上与注意力基线相当，同时将模型计算量减少了2.46倍，单图像推理延迟减少了2.65倍。复杂度分析表明，其收益由序列长度与通道宽度之比决定，这解释了为何高分辨率立体匹配是一个特别有利的场景，而分类Transformer则不然；我们在非立体的长序列基准上证实了这种令牌到通道的缩放特性。此外，我们引入了一种混合对数视差损失函数，旨在对对应远距离物体的小视差像素赋予更高权重。该方法在不增加任何额外计算开销的情况下，降低了远处物体的误差。

## Abstract
Stereo depth estimation for driving, robotics and augmented reality must run at high resolution under tight latency budgets, yet in transformer-based matchers the global self-attention that aggregates scene context grows quadratically with the number of pixels and comes to dominate runtime. We show that the joint self-attention stage of a stereo transformer, whose role is to spread context across both views, can be replaced by a data-independent Walsh-Hadamard token mixer that mixes tokens globally in the transform domain at log-linear cost, while the data-dependent cross-attention that performs left-right correspondence is retained. On synthetic driving data the mixer matches the attention baseline in end-point error while reducing model compute by a factor of 2.46 and single-image inference latency by a factor of 2.65. A complexity analysis shows the benefit is governed by the ratio of sequence length to channel width, which explains why high-resolution stereo matching is a particularly favorable setting and why classification transformers are not; we confirm this token-to-channel scaling on non-stereo long-sequence benchmarks. Furthermore, we introduce a hybrid log-disparity loss function designed to up-weight small-disparity pixels corresponding to long-range objects. This approach reduces the error on distant objects without incurring any additional computational overhead.

# WHTMix：基于Walsh-Hadamard令牌混合的高效立体深度估计

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心瓶颈**：立体深度估计在自动驾驶、机器人和增强现实等应用中必须在高分辨率下满足严格的延迟约束。然而，基于 Transformer 的立体匹配方法（如 STTR）依赖全局自注意力来聚合场景上下文，其计算复杂度随像素数量呈 **O(N²) 二次增长**，在高分辨率下成为运行时的主导瓶颈。
- **核心洞察**：作者指出，在立体 Transformer 层中，注意力承担两种截然不同的角色：
  1. **联合自注意力**：负责在左右视图内和视图间传播全局上下文——这一过程本质上是**数据无关的上下文聚合**；
  2. **交叉注意力**：负责执行真正的左右像素对应匹配——这一过程**必须依赖数据内容**。
- **关键洞见**：上下文聚合可以用固定的、数据无关的算子替代，而匹配必须保留数据依赖性。因此，作者提出用 **Walsh-Hadamard 变换（WHT）** 作为廉价的谱域令牌混合器替换联合自注意力，同时保留交叉注意力进行匹配，从而在保持精度的前提下打破二次复杂度瓶颈。

## 2. 论文提出的方法论

### 2.1 核心思想

> 将立体 Transformer 中的联合自注意力替换为 **数据无关的 Walsh-Hadamard 令牌混合器（WHTMix）**，在变换域中以 **O(N log N)** 的对数线性代价实现全局感受野，同时保留数据依赖的交叉注意力用于左右视图匹配。

### 2.2 WHTMix 模块结构

设输入联合令牌序列为 X ∈ R^{N×C}，WHTMix 的计算流程为：

1. **输入投影**：`Z = XW_in`，将通道投影到合适维度；
2. **通道域 WHT**：对通道轴施加 Walsh-Hadamard 变换，与可学习的逐频率增益 g_c 逐元素相乘，再逆变换回来；
3. **令牌域 WHT**：对令牌轴施加 WHT（必要时零填充到 2 的幂长度），与可学习的逐频率增益 g_t 逐元素相乘，再逆变换；
4. **输出投影**：`Y = ZW_out`。

**关键细节**：
- 增益 g_c、g_t 在**对数域**学习，初始化为零（即单位增益）；
- WHT 是正交变换，保持幅值，因此多层堆叠稳定；
- 与 FNet/GFNet 类似，该模块是**线性的**，非线性由层中的前馈网络（FFN）提供；
- WHTMix 与注意力的调用签名一致，可作为自注意力的**即插即用（drop-in）替代模块**。

### 2.3 混合对数视差损失（Hybrid Log-Disparity Loss）

- **动机**：标准 masked ℓ1 损失被大视差（近处）像素主导，导致小视差（远处）物体欠监督。
- **方法**：对每个有效像素 p 赋予权重：
  - `w_p = clip(τ / d_p, 1, w_max)`
  - 其中 d_p 为真值视差，τ = 16，w_max = 32；
- **效果**：视差低于 τ 像素的远距离像素被最高加权至 32 倍，且**不增加任何计算开销**。

### 2.4 复杂度分析

- **自注意力模块成本**：4NC²（投影）+ 2N²C（二次核心）；
- **WHTMix 成本**：约 2NC²（两次投影；蝶形运算仅加法，无乘法累加）；
- **模块级加速比**：`S_mod = 2 + N/C`，交叉点在 N = 2C；
- **端到端加速比上限**：`S_e2e → 3`（当 N→∞），因为交叉注意力和 FFN 是两个模型共享的；
- **核心结论**：收益由 **N/C（令牌数/通道宽度比）** 决定：
  - 高分辨率立体匹配（N/C = 256）→ 巨大收益；
  - 分类 ViT（N/C ≈ 0.26）→ 无收益甚至负收益。

## 6. 论文的主要结论与发现

1. **效率大幅提升且精度持平**：在 CARLA 数据集上，WHTMix 的 EPE（2.27）与注意力基线（2.29）在运行间波动范围内持平，计算量降低 **2.46 倍**，延迟降低 **2.65 倍**；
2. **复杂度理论得到验证**：`S = 2 + N/C` 的加速比预测与实测吻合（512×1024 处预测 2.90× vs 实测 2.65×；896×1792 处预测 2.97× vs 实测 2.85×）；
3. **N/C 比是决定收益的关键因素**：高分辨率、低通道宽度的稠密预测任务（N≫C）是 WHTMix 的理想场景，而分类 Transformer（N<C）不适用；
4. **混合对数视差损失有效**：远处物体（2-4px 和 4-8px 视差区间）的 EPE 大致减半（3.29→1.60 和 3.36→1.94），且零额外计算开销；
5. **非立体任务验证普适性**：在 LRA 长序列文本任务中，WHTMix 与注意力精度仅差 1.6 点而计算量减少 13.8 倍，说明该效应的驱动力是 N/C 比而非特定任务；
6. **诚实报告了合成到真实的精度差距**：在真实 KITTI 数据上 WHTMix 的 EPE（2.670）落后于注意力基线（2.204），表明固定混合器在真实数据稀缺时适应性不如注意力。

## 7. 优点

- **问题选择精准**：准确识别了立体 Transformer 中“上下文聚合可数据无关化、匹配必须数据相关”的结构特征，理论动机清晰；

- **复杂度分析具有预测力**：给出闭式加速比 `2 + N/C`，不仅能解释自身结果，还能准确预测哪些场景适用、哪些不适用；

- **消融设计干净**：通过三个仅差一个因素的变体，成功隔离了混合器和损失函数的各自贡献；
- **诚实透明**：如实报告 KITTI 上的精度退化，不回避方法的局限性。

## 8. 不足与局限

- **真实数据性能差距**：在 KITTI 上 WHTMix 比注意力基线差约 0.47 EPE（2.670 vs 2.204），固定混合器在小规模真实数据下适应性不足；作者建议大规模预训练，但未提供相关证据；
- **实验规模有限**：数据集较小，缺乏主流大基准验证；LRA 实验仅单次运行，统计显著性存疑；
- **基准对比不足**：未与当前最先进的立体匹配方法（RAFT-Stereo、IGEV-Stereo、FoundationStereo 等）对比，无法评估方法在实际应用中的竞争力；
- **小模型配置**：仅验证了 C=64、L=3 的小规模配置，该配置下注意力未必已充分展现其表达力；在更宽更深模型下混合器与注意力的差距可能不同；
- **FLOPs 与延迟的不完全对应**：在 LRA 小规模图像任务中，WHTMix 虽然 FLOPs 减少 4.3 倍，但实际延迟反而更慢（3.22ms vs 1.47ms），作者归因于启动开销，但这也说明纯理论加速比在低资源场景中的实践意义有限；
- **训练细节缺失**：未报告训练时长、收敛曲线、种子数等关键复现信息；
- **混合损失引入额外超参数**：τ 和 w_max 的选取缺乏敏感性分析。
