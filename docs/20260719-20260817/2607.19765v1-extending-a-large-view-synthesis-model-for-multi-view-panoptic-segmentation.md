## 摘要
大型视图合成模型通过跨视角注意力合成新视图，无需显式3D表示，近期的研究表明它们仅从RGB监督中就能学习到精确的空间对应关系。我们观察到这种对应关系超越了外观表现。当非真实感信号（如二值编码的全景标签）通过模型时，它们会被传播到具有一致空间结构的新视图中。这些结果表明，为RGB视图合成学习到的对应关系也能传播与视图无关的逐像素标签。基于这一观察，我们首次将大型视图合成模型从外观渲染扩展到3D场景理解。我们提出了一种全景分割流程，该流程复用冻结的视图合成模型，将全景标签从输入视图传播到新视图，无需3D重建，也无需对视图合成模型进行任何分割特定的训练。给定输入视图上的全景标签后，我们将其编码为二值通道表示，并通过同一模型渲染目标视图的分割结果。在ScanNet上，我们的方法在分割质量上达到了与需要显式3D重建的基于高斯的方法相当的水平，并在新视图合成上比它们高出超过7 dB。此外，该标签传播还能跨数据集迁移，在无需微调的情况下在Replica上超越了这些方法。

## Abstract
Large view synthesis models synthesize novel views through cross-view attention without explicit 3D representations, and recent studies have shown that they learn accurate spatial correspondence from RGB supervision alone. We observe that this correspondence generalizes beyond appearance. When non-photorealistic signals such as binary encoded panoptic labels are passed through the model, they are propagated to novel views with consistent spatial structure. These results indicate that the correspondence learned for RGB view synthesis can also propagate view-independent per-pixel labels. From this observation, we present the first work to extend large view synthesis models beyond appearance rendering to 3D scene understanding. We propose a panoptic segmentation pipeline that reuses a frozen view synthesis model to propagate panoptic labels from input views to novel views, without 3D reconstruction or any segmentation-specific training of the view synthesis model. Given panoptic labels on the input views, we encode them into binary channel representations and pass them through the same model to render target-view segmentation. On ScanNet, our method achieves segmentation quality on par with Gaussian based approaches requiring explicit 3D reconstruction, while outperforming them in novel view synthesis by more than 7 dB. The label propagation also transfers across datasets, surpassing these approaches on Replica without any fine-tuning.

## 2. 论文提出的方法论

- **核心思想**：复用冻结的（frozen）视图合成模型作为标签传播器，将输入视图的 panoptic 标签编码为二值通道表示，通过同一模型的跨视图注意力机制渲染目标视图分割结果。整个框架分为两条并行路径：
  - **渲染路径**：源视图图像 → 场景编码器 → 场景潜在表示 → 渲染解码器 → 目标视图 RGB 图像
  - **分割路径**：源视图 panoptic 标签 → 二值通道编码 → 同一场景编码器 → 同一渲染解码器 → 目标视图分割结果
- **关键技术细节**：

  - **视图合成模型**：采用 Less3Depend（基于 LVSM 的无位姿前馈视图合成模型），包含场景编码器 E、位姿估计器 P、渲染解码器 R。目标视图位姿以潜在 Plücker 嵌入形式估计，无需真实相机位姿。
  - **源视图分割**：使用一个共享查询解码器 D（基于 Mask2Former 架构，冻结 DINOv2 编码器），输入所有源视图特征和一组可学习的对象查询，一次性输出跨视图一致的 panoptic 标签，避免显式跨视图匹配。
  - **标签编码**：将每个像素的实例 ID 用 3 位二值编码（最多表示 8 个实例）映射到三通道图像，用查找表 L 记录实例到语义类别的映射。
  - **不确定性处理**：设置阈值 τ = 0.2，当渲染输出任一通道值接近 0.5（即处于模糊区域）时，标记该像素为不确定并留空。
  - **多实例扩展**：场景中实例超过 8 个时，将实例分组为多个 3 位编码批次，分别传播后再合并，线性增加推理时间但无需重训练。
  - **关键公式**：
    - 场景潜在表示：z = E(I_s1, …, I_sN, z0)
    - 目标位姿估计：ê_t = P(I_t, z)
    - 渲染路径：Î_t = R(z, ê_t)
    - 分割路径：z_seg = E(b_s1, …, b_sN, z0)，b̂_t = R(z_seg, ê_t)
    - 解码：Î_t(p) = B⁻¹(round(b̂_t(p)))，S_t(p) = L(Î_t(p))
  - **训练策略**：视图合成模型仅使用光度损失（L_MSE + 0.5·L_perceptual）进行 RGB 重建训练，不接收任何分割监督。共享查询解码器使用标准 Mask2Former 目标（交叉熵 + Dice + 分类损失）训练。分割传播只做前向推理，无梯度流入渲染权重。

## 6. 论文的主要结论与发现

- **结论一**：大型视图合成模型从 RGB 监督中学到的跨视图对应关系是**输入无关的（input-agnostic）**，能够同时传播外观和任意视图无关的逐像素标签。
- **结论二**：冻结的视图合成模型可以直接作为多视图全景分割的传播器，无需 3D 重建、无需分割特定训练、无需修改架构，即获得有竞争力的分割质量。
- **结论三**：本文方法在 ScanNet 上分割质量（0.5949 mIoU）与显式 3D 高斯方法 SIU3R（0.5894 mIoU）相当，而 RGB 重建质量（33.56 dB PSNR）显著更高（高出 7 dB 以上），体现了解耦设计的优势。
- **结论四**：标签传播在低重叠（[0.01, 0.3]）场景下比基于几何栅格化的方法退化更缓慢，PQ 差距从 0.0473 缩小到 0.0011，说明注意力式传播不适合时仍保持学习到的外推能力。
- **结论五**：模块化设计支持即插即用——替换源视角分割器（Mask2Former → SAM2 → PanSt3R）或替换 NVS骨干（Less3Depend → RayZer）均无需修改传播路径，且跨数据集零样本迁移上优于重建方法。

## 7. 优点

- **开创性**：首次将大型视图合成模型从 RGB 外观渲染扩展到 3D 场景理解，方法新颖、问题有意义。
- **简洁优雅**：仅通过信号级变换（二值编码标签）来引导同一个冻结模型做不同任务，无需额外训练或架构修改，技术方案极简且有效。
- **模块化解耦**：渲染与分割完全分离，两个组件可独立升级，避免了重建质量对分割质量的制约，这是对现有范式的重要改进。
- **坚实的经验分析**：通过梯度显著性（gradient saliency）分析方法从机理上验证了模型对应关系的输入无关性，实验证据较扎实。
- **分割一致性保障**：共享查询解码器同时处理所有输入视图，天然保证跨视图实例身份一致，避免了逐视角分割需要后处理匹配的问题。
- **跨数据集迁移能力强**：冻结传播路径在 Replica 上零样本超越需要显式重建的基线，说明对场景类型的依赖小，泛化潜力大。

## 8. 不足与局限

- **推理效率**：每个目标视图都需要完整前向传播一次视图合成模型，当只需要已知视点的分割结果时计算开销偏大；多实例场景需要多轮传播，推理时间线性增长。
- **实例容量限制**：单次传播仅支持 8 个实例，实际室内场景通常远超过该限制，虽然多轮分组可扩展，但增加了复杂度和错误累积风险。
- **PQ 指标不足**：在 ScanNet 上，PQ（0.6092 vs 0.6565）明显低于 SIU3R，说明实例级边界精度和识别能力仍有差距，原因在于 2D 标记空间传播缺乏显式 3D 几何约束，实例边界易受注意力空间模糊性影响。
- **信号适用范围有限**：该方法仅适用于视图无关的逐像素信号（如语义类别、实例 ID）。视图相关的信号（如深度、法线）无法直接传播，需要额外的相机感知变换，仍属开放问题。
- **跨数据集评估不足**：仅有 Replica 一个外数据集零样本评估，且 PanSt3R（源分割器）本身可能具有跨数据集设计的先验，难以完全隔离传播路径的泛化贡献。
- **户外和复杂场景验证薄弱**：室外场景仅有定性结果，缺乏对光照变化、分辨率、更多实例数场景的系统评估。
- **潜在偏差风险**：主要对比基于 ScanNet，且重建方法（SIU3R、LSM）与本文方法使用不同的视图采样协议、分割头架构和训练策略，存在一定的不可比因素；论文中 SIU3R 的 PQ 优于本文方法而被归因于“领域内特化”，但该解释缺乏深入实验验证。
