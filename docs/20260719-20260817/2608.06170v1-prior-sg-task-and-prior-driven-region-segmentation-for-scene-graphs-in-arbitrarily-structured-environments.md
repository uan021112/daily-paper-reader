## 摘要
分层3D场景图是自主移动平台高层空间推理的一种有前景的表示方法。然而，现有的提取框架通常依赖于纯局部视觉聚类或严格的几何启发式规则（如墙壁分隔的房间），这在开放式或任意结构环境中难以适用。我们提出了Prior-SG，一种任务与先验驱动的框架，从根本上将场景图生成视为概率对齐问题。随着机器人的探索，它利用多尺度、开放词汇的特征融合策略，将连续的RGB-D传感器流持续聚合为物理 grounded 的实例图。随后，系统通过最大后验（MAP）估计推断该地图的高层功能语义，并由先验图引导——先验图是由大型语言模型动态合成的对环境结构和任务相关词汇的逻辑预期。通过优化一个融合异构专家（视觉、几何和离散对象）与这些拓扑先验的马尔可夫随机场，系统解决了局部感知歧义。我们在多样的模拟住宅数据集和大型开放式真实世界环境中验证了该方法。与最近的基线相比，Prior-SG在语义区域分割准确性上达到了最先进水平，在缺乏物理墙壁的情况下稳健地描绘出遥远的功能边界，并独特地提供了零样本本体灵活性，使机器人能够根据给定的高层任务完全重构其空间划分。

## Abstract
Hierarchical 3D scene graphs are a promising representation for high-level spatial reasoning in autonomous mobile platforms. However, existing extraction frameworks typically rely on purely local visual clustering or strict geometric heuristics, such as wall-separated rooms, which fail in open-plan or arbitrarily-structured environments. We propose Prior-SG, a task- and prior-driven framework that casts scene graph generation fundamentally as a probabilistic alignment problem. As the robot explores, it continuously aggregates an incoming RGB-D sensor stream into a physically grounded Instance Graph utilizing a multi-scale, open-vocabulary feature fusion strategy. The system then infers the high-level functional semantics of this map through a Maximum A Posteriori (MAP) estimate, guided by a Prior Graph-a logical expectation of the environment's structure and task-relevant vocabulary synthesized dynamically by a Large Language Model. By optimizing a Markov Random Field that fuses heterogeneous experts (visual, geometric, and discrete objects) with these topological priors, the system resolves local perceptual ambiguities. We validate this approach across diverse simulated residential datasets and large, open-plan real-world environments. Prior-SG achieves state-of-the-art semantic region segmentation accuracy compared to recent baselines, robustly delineates distant functional boundaries in the absence of physical walls, and uniquely provides zero-shot ontological flexibility, enabling the robot to entirely restructure its spatial partitioning based on a given high-level task.

## 一、核心问题与研究动机

**背景痛点：** 现有分层3D场景图（Hierarchical 3D Scene Graphs）的提取方法主要存在两类范式及其固有缺陷：

- **严格几何启发式方法**（如 Hydra、HOV-SG）：依赖墙壁分隔、物理约束等硬编码假设来划分区域，在开放式平面（open-plan）或任意结构空间中会失效，无法处理无物理墙壁的功能区域划分。
- **纯自底向上视觉聚类方法**（如 Clio）：依赖全局CLIP特征投影，容易受到传感器噪声、视觉混叠（visual aliasing）和语义拖尾（semantic smearing）的影响，且高度依赖密集的近距离观测，无法对大尺度环境中远距离、部分观测的区域进行语义推断。

**核心洞见：** 人类对空间的理解并非仅依赖局部几何或孤立视觉信号，而是通过任务驱动的语义先验来解释环境结构。论文以此类比，提出将场景图生成从根本上重构为一个**概率对齐问题**——在具身传感器观测与高层语义期望之间建立概率对应关系。

**研究目标：** 使机器人能够在任意结构环境中，根据高层自然语言任务，以零样本方式动态重构空间划分，同时保持高精度的语义区域分割。

## 二、方法论

### 1. 总体框架（三阶段流水线）

系统架构包含三个核心阶段，形成完整的概率对齐流程：

```
传感器流(RGB-D) → 实例图GI（物理观测） + LLM先验图GP（语义期望）→ MAP推断 → 最优分区场L* → 完整场景图
```

### 2. 形式化定义

论文将场景图生成建模为最大后验（MAP）估计问题：

```
L* = arg max_L P(L | Z, E0, T)
```

通过引入先验图GP作为中介变量（由LLM从任务T和环境E0动态合成），将原始高维问题约化为可计算的图模型推断问题：

```
P(L | Z, E0, T) ≈ P(L | GI_obs, GP) ∝ P(GI_obs | L, GP) · P(L | GP)
```

### 3. 先验图生成（Prior Graph Extraction）

- **自顶向下状态空间截断**：LLM根据任务生成有限的目标区域集合RP，并为其填充相关对象集OP和原型场景节点PP，将开放语义空间聚焦到任务相关词汇上。
- **内在属性分配**：将区域/对象的文本标签通过CLIP文本编码器嵌入视觉-语言联合空间，为场景节点生成几何参数模板（如预期倾角与方差）。
- **概率结构边**：LLM生成两类概率矩阵——包含先验P(o|r, E0)（对象-区域条件似然）和拓扑先验P(ri↔rj|E0)（区域邻接转移似然），避免二进制硬关联，提供概率化表达。

### 4. 实例图构建与多尺度特征金字塔

- **物理主干**：使用Hydra的广义Voronoi图（GVD，结构化室内）或2D地点提取（大型/无边界环境）来实例化连续自由空间的拓扑地点图；用GroundingDINO+Faster SAM完成先验引导的开放集对象检测与3D提升。
- **多尺度特征金字塔**：静态金字塔由多个尺度的均匀滑窗裁剪构成，裁剪尺寸从底层到顶层递增。将每个3D地点建模为以先验半径rQ为协方差的高斯体积，投影到图像平面得到查询状态(sp = (up, σp))，通过空间亲和度和尺度信任因子加权聚合底层特征，得到单帧地点描述子ep和置信度T(p)。
- **时间聚合**：使用信赖加权平均（地点）和中心化平均（对象）融合历史观测，得到持久化描述子。

### 5. 全局推断：MRF与Graph Cuts

- **能量函数**：将MAP最大化转化为MRF能量最小化，包含一元势能（局部观测证据）和成对势能（拓扑正则化）。
- **置信加权对数线性池（Product of Experts）**：融合四类异构专家——
  - **视觉专家**：CLIP余弦相似度 + 温度Softmax + “Null”类噪声底（处理开放集杂波）
  - **几何专家**：von Mises分布评估局部倾角匹配，置信度基于邻域支撑度和形状各向异性
  - **对象专家**：对象-区域边际概率传播，通过空间距离加权的max-pooling将对象证据转移到地点节点
  - **环境先验专家**：注入全局区域存在先验P(r|E0)
- **α-β-swap优化**：因LLM拓扑先验违反三角不等式（非度量代价），采用α-β-swap算法而非α-expansion，严格处理非度量的高维拓扑规则。
- **区域实例化**：对相同标签的顶点诱导子图提取连通分量，生成独立的物理区域节点，建立层级边。

## 六、主要结论与发现

1. **语义分割SOTA**：Prior-SG在所有数据集上语义F1和mIoU均大幅优于基线——HM3D语义F1达68.0%（导航）/69.4%（扫描），CODa语义mIoU是Clio的3倍（43.8% vs 14.4%），Train Station语义mIoU达57.9% vs Clio的23.2%。
2. **运动鲁棒性**：基线方法在扫描→导航切换时性能显著下降（HOV-SG语义F1从46.8%跌至37.8%），而Prior-SG保持稳定（69.4%→68.0%），证明不需要穷举视角覆盖。
3. **开放平面预测能力**：系统能基于局部化多尺度特征在距离约18m外准确分割楼梯、提前预测尚未完全观测到的大厅区域，而全局特征方法则完全失败。
4. **零样本本体灵活性**：同一物理场景在“房地产列表”、“酒店服务”、“设施维护”三种任务下生成完全不同的空间分区，实现任务驱动的空间重构。
5. **专家协同效应**：拓扑先验（E）在所有数据集均可稳定提升性能；对象专家（O）在住宅场景帮助显著，但在大型开放环境无辨别力；几何专家（G）在开放平面的楼梯边界界定上提升mIoU。

## 七、方法亮点

1. **概念创新**：将场景图区域分割重新定义为概率对齐问题，而非纯重建或聚类问题，弥合了LLM抽象知识与物理观测之间的鸿沟。
2. **多尺度特征金字塔的工程巧妙性**：用静态金字塔 + 空间/尺度双维度加权聚合逼近理论上最优的连续动态裁剪，避免了昂贵的在线重投影计算，同时解决了全局特征投影的语义拖尾问题。
3. **非度量拓扑先验的严格处理**：识别出LLM生成的拓扑规则违反三角不等式，选择α-β-swap而非α-expansion，在数学上严谨。
4. **Product of Experts的健壮融合**：置信度动态归零机制实现了“平滑降级”——缺失数据的专家不污染联合分布。
5. **模块化可扩展性**：几何专家作为即插即用插件证明框架可方便扩展新模态。
6. **零样本任务适应能力**：仅通过修改LLM提示词即可完全重构空间本体，无需重新训练或人工调整。

## 八、不足与局限

1. **计算效率限制**：当前Graph Cuts在每一步对全局观测节点做整体优化，难以保证严格固定计算的实时部署；特征金字塔推理也较慢（论文图5/6显示单帧秒级延迟）。
2. **单层抽象局限性**：推断只涉及一个抽象层（区域层），城市级大规模任务需额外层级来管理组合复杂度。
3. **专家配置数据集依赖**：不同数据集需手工决定启用哪些专家（如对象专家在商店中可能有用却被禁用），削弱了系统完全自动声称的可信度。
4. **静态先验缺乏反馈**：先验图是固定的，无法利用观测结果动态更新LLM内部模型，错失结构外推（structure extrapolation）的机会。
5. **实验数据集与baseline覆盖不完整**：HOV-SG在TartanGround、CODa及Train Station上未评估（因算法本质无法处理无约束环境），缺少更广阔的真实世界数据集（如完整的3RScan）的系统对比；真实数据集中Train Station为自录数据，缺少公开可用性保证。
6. **几何专家适用性受限**：其角度模板依赖邻域协方差，在自然导航轨迹的探索边界处会引入噪声而劣化性能。
7. **对象检测的类别约束**：对象层被显式限制在先验对象集内，可能遗漏具有判别价值但LLM未预见的对象类别。
8. **指标局限性**：语义mIoU在部分数据集（如CODa）中数值仍偏低，提示mIoU评价体系下的部分匹配质量有提升空间；且未分析不同LLM（如GPT-4/GPT-3.5）对先验质量的影响。
