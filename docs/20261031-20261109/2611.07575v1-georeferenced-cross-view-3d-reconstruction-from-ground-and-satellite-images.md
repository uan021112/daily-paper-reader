## 摘要
从地面图像进行地理参考 3D 重建，不仅需要恢复局部场景几何，还需要在地理坐标系中定位每个相机中心和 3D 点。现有跨视角地理定位方法能够估计单个地面相机的 GPS 坐标，但无法重建稠密 3D 几何；而近期的前馈式多视图 3D 重建模型仅在局部坐标系中预测点图和相机姿态。我们提出 X-VGGT，这是一种前馈式跨视角几何 Transformer，通过联合处理一组地面图像和一幅带地理参考信息的卫星图像，统一完成上述任务，预测地面视角相机姿态、稠密 3D 点图，以及由重力、尺度、偏航角和平移参数化的场景级变换。该变换将局部重建投影到卫星平面，从而使所有地面图像与带地理参考信息的卫星图像实现地理配准。我们进一步为这一联合任务提出评估方案，并表明在多个跨视角数据集上，X-VGGT 能够生成准确的地理参考重建，且性能优于以往的跨视角地理定位和多视图 3D 重建模型。

## Abstract
Georeferenced 3D reconstruction from ground images requires recovering not only the local scene geometry, but also localizing every camera center and 3D point in a geographic coordinate frame. Existing cross-view geo-localization methods are able to estimate the GPS coordinate of a single ground camera, but do not reconstruct dense 3D geometry, while recent feed-forward multi-view 3D reconstruction models predict point maps and camera poses only in a local coordinate frame. We introduce X-VGGT, a feed-forward cross-view geometry transformer that unifies these tasks by jointly processing a set of ground-level images and a georeferenced satellite image to predict ground-view camera poses, dense 3D point maps, and a scene-level transform parameterized by gravity, scale, yaw and translation. This transform projects the local reconstruction into the satellite plane, resulting in the geo-registration of all ground images with the georeferenced satellite image. We further propose an evaluation protocol for this joint task and show that, across multiple cross-view datasets, X-VGGT produces accurate georeferenced reconstructions and outperforms prior cross-view geo-localization and multi-view 3D reconstruction models.

## 1. 核心问题与整体含义

- **研究问题**：如何从多张地面图像恢复场景三维结构，同时把每个相机和图像中的三维点放入真实地理坐标系？
- **研究动机**：现有跨视角地理定位通常只估计地面相机在卫星图上的位置，无法提供稠密的像素级三维定位；多视图重建模型虽能预测相机位姿和三维点图，却通常只输出带有尺度和坐标系歧义的局部重建。
- **论文的整体思路**：把地面多视图重建与卫星图配准作为一个联合任务，通过地面图像恢复局部三维几何，再利用带地理参考的卫星图将整个重建统一映射到地理平面。论文提出的模型称为 **X-VGGT**。

## 2. 方法论

### 核心思想

X-VGGT 联合输入一组地面图像和一幅正射、带地理参考的卫星图像，预测：

- 每张地面图像的相机位姿和内参；
- 每张地面图像对应的稠密三维点图；
- 将局部重建映射到卫星平面的场景级地理配准变换。

该变换由一个共享的场景级坐标映射实现，而不是逐张独立估计相机 GPS 位置，因而可以一致地定位所有相机和稠密三维点。

### 网络结构与数据流

- 以 **VGGT** 为基础，使用共享视觉编码器提取图像 patch 特征；模型以 DINOv2 初始化。
- 地面图像与卫星图像共同送入交替注意力 Transformer。模型交替进行：
  - **帧内注意力**：更新单张图像内部的特征；
  - **跨视图全局注意力**：让不同地面视图及卫星视图之间交换信息。
- 地面视图特征送入相机头和 DPT 稠密预测头，得到相机位姿与点图；卫星视图不被当作普通透视相机处理，而是通过专门的 **Satellite Alignment Head（SAH）** 预测地理配准变换。
- SAH 通过多轮迭代更新场景变换，最终从卫星视图 token 读出变换参数。

### 地理配准变换

变换参数为：

\[
\phi=(g,r_\psi,\alpha,t)
\]

其中：

- \(g\)：局部重建坐标系中的重力方向，决定卫星平面的法向；
- \(r_\psi=(\cos\psi,\sin\psi)\)：平面内的偏航方向；
- \(\alpha=\log s\)：对数尺度；
- \(t\)：卫星归一化坐标中的二维平移。

基于重力方向建立平面内的正交基，再由偏航角旋转该基。对局部三维点 \(X\)，地理映射为：

\[
G_\phi(X)=\exp(\alpha)
\begin{bmatrix}
x_\phi^\top X\\
y_\phi^\top X
\end{bmatrix}+t.
\]

因此，模型先恢复局部三维几何，再将点和相机中心投影到卫星平面。卫星图像的地理分辨率使尺度参数可以进一步用于生成米制深度。

### 训练目标

总损失由多项任务共同构成：

- 相机位姿损失；
- 点图回归及法线一致性损失；
- 地理变换参数损失；
- 投影后相机中心的卫星坐标损失；
- 投影后稠密三维点的卫星坐标损失。

地理变换参数、相机中心与稠密点的投影监督相互补充：参数损失直接监督变换，投影损失则约束该变换对实际几何的定位结果。相机损失权重为 5，其余地理配准和点图损失权重为 1。

### 训练数据构造

- 使用 KITTI 与扩展版 Aerial-MegaDepth（作者称 **Sat-MegaDepth**）。
- 为 Sat-MegaDepth 增加正射卫星影像，并根据相机 GPS/ENU 坐标、深度点图和卫星地理范围生成相机中心及稠密点的卫星坐标监督。
- 对卫星图进行翻转和 90° 旋转等增强，并同步变换相机、点图和地理坐标，保持监督一致。

## 3. 实验设计、数据集与对比方法

### 数据集与场景

论文评估覆盖四个跨视角数据集：

- **KITTI**：车载序列，使用带 LiDAR 深度和卫星图的增强版本；在地理上与训练区域分离的 Test-2 划分上测试。
- **Mapillary Metropolis**：芝加哥多方向车载图像，包含相机位姿、卫星图和 MVS 深度，用于零样本评估。
- **WRIVA**：多个美国场景的非序列、无序图像集合，具有相机标定和 GPS 标注；没有深度标注。
- **ACC-NVS1**：来自多个真实场景的多视图数据，使用地面图像序列及补充的卫星图；没有用于稠密评估的深度标注。

主实验通常每个场景输入 **16 张地面图像和 1 张卫星图**，卫星图覆盖约 \(150\,\text{m}\times150\,\text{m}\)。评估最多从每个数据集抽取 1024 个场景；不同数据集按序列、多方向视图或无序图像集的特点构造场景。

### Benchmark 与评价指标

论文将任务拆分为三个方面：

1. **相机地理定位**：相机中心位置误差（米）和朝向误差（度）。
2. **像素级地理配准**：地面图像有效像素投影到卫星平面后的定位误差（米）。
3. **局部三维重建**：通过相机相对旋转、相对平移的准确度及联合 AUC 评估。

像素级深度指标仅在 KITTI 和 Metropolis 上报告；WRIVA 与 ACC-NVS1 缺少对应深度标注。

### 对比方法

- 跨视角定位：**FG²、Loc²**；
- 多视图三维重建：**MASt3R、VGGT、Aerial-MegaDepth（A-MD）**；
- 组合式基线：**VGGT + Loc²**，先由 VGGT 重建，再用 Loc² 的相机位置拟合共享相似变换，将局部重建对齐到卫星坐标系。

主结果中，各方法使用相同数量的地面图像和卫星图输入；但各基线原生输出能力不同，部分基线需要通过额外投影或几何对齐才能计算地理指标。

## 4. 资源与算力

- 模型从预训练 VGGT 检查点初始化，使用 **4 张 NVIDIA H100 GPU** 训练 **80,000 次迭代**。
- 地理配准损失消融实验使用 **2 张 H100 GPU** 训练 **10,000 次迭代**。
- 论文未给出训练的具体墙钟时长，因此无法据此估算完整训练耗时。
- 推理效率在 **NVIDIA A100 80GB** 上测量。输入 16 张地面图像加 1 张卫星图时，报告延迟约 **1.020 秒**、显存约 **13.63 GiB**。输入增至 64 张时，延迟约 **7.539 秒**、显存约 **26.65 GiB**。这些时间不包含模型加载、数据预处理和数据传输。

## 5. 实验数量、充分性与公平性

### 实验覆盖

论文实验大致包括：

- **主结果**：4 个数据集上的相机地理定位；其中 2 个数据集上的像素级地理配准；4 个数据集上的局部三维重建。
- **消融与分析**：
  - 地理配准损失组成消融；
  - 地面图像数量从 8 到 96 张的影响；
  - 地面—卫星联合交互与 late-fusion 对比；
  - 卫星图裁剪范围、分辨率、地理错位的鲁棒性；
  - oracle alignment 分析；
  - 推理延迟与显存分析；
  - 另有度量深度的定性展示。

因此，实验并非只验证单一指标，而是覆盖定位、稠密配准、局部重建、鲁棒性和计算成本等多个方面。

### 充分性与公平性

- **较充分之处**：包含跨区域 KITTI 测试和多个零样本数据集；既比较单项任务基线，也比较“重建 + 定位”组合基线；通过消融和鲁棒性分析检验模型设计与输入条件的影响。
- **需要谨慎解读之处**：
  - 不同基线原生支持的任务不同，必须通过额外投影、卫星虚拟相机或后处理才能统一评估；这有助于比较，但并非完全同构的原生输出对比。
  - Loc² 等跨视角方法主要面向独立相机定位，而 X-VGGT 使用多张地面图像共同估计场景变换，信息条件并不完全相同。
  - KITTI 用于训练，虽然主评估采用地理上分离的 Test-2 区域，但仍不等同于完全不同来源的训练数据；Metropolis、WRIVA 和 ACC-NVS1 的零样本结果对此有所补充。
  - 鲁棒性实验只选取满足特定卫星裁剪条件的 512 个场景，且与主结果的场景集合不同。论文明确提示，不能直接把该实验的绝对误差与主表比较。
  - 主要数值结果是均值，提供的文本未显示置信区间或显著性检验，因此对方差和统计显著性的判断有限。

## 6. 主要结论与发现

- X-VGGT 在报告的四个数据集上取得平均相机定位误差 **22.38 米**、平均朝向误差 **30.93°**，优于文中所比较的定位和重建基线。
- 在 KITTI 和 Metropolis 上，像素级地理配准误差分别为 **25.52 米**和 **17.84 米**，优于表中对比方法。
- 同时，模型保持了较强的局部三维重建能力；其局部重建 AUC 在若干数据集上与 VGGT 相当或更高。
- 消融显示，直接监督稠密点投影和相机中心有助于提升定位与像素配准；地面图像与卫星图像进行联合交互也优于 late fusion。
- 更多地面视图通常能降低位置与朝向误差，但会增加推理时间和显存开销。
- Oracle alignment 结果显示，地理配准仍有提升空间；而在 Metropolis 上，即使相机中心通过 oracle 对齐，稠密配准误差改善有限，说明**相机定位准确并不必然意味着稠密几何也准确地落在地理坐标系中**。

## 7. 优点

- **任务统一明确**：将局部三维重建、相机地理定位和像素级地理配准纳入同一前馈框架。
- **共享几何约束**：采用场景级变换统一对齐相机中心和三维点，避免逐帧独立定位造成的坐标不一致。
- **利用卫星分辨率恢复尺度**：除地理定位外，还能将局部重建转为米制尺度，并生成米制深度图。
- **实验维度较广**：覆盖多种场景组织方式、多个数据集、零样本评估、消融、卫星输入扰动及效率测量。
- **对比不只限于单模型**：纳入了 VGGT 与 Loc² 的组合基线，检验“独立定位后再对齐重建”是否能替代联合建模。
- **结果揭示了指标之间的差异**：尤其说明相机中心误差和像素级几何误差并不等价，避免将单一相机定位指标误当作完整重建质量。

## 8. 不足与局限

### 方法和应用条件

- 依赖**正射且带地理参考、具有已知空间分辨率的卫星图像**；卫星影像过时、低分辨率、遮挡，或与地面影像存在明显差异时，性能可能下降。
- 训练中使用的卫星裁剪尺度约为 **150–250 米**。显著改变卫星区域大小可能改变模型看到的尺度和上下文，论文指出可能需要微调或调整裁剪方案。
- 地面图像与卫星图之间视角和外观差异极大，方法仍依靠训练数据学到有效跨视角关联；对未覆盖地区、特殊地貌或传感器组合的泛化尚不能仅由现有实验完全确定。

### 实验范围和解释边界

- 稠密配准评估只覆盖 KITTI 和 Metropolis；另外两个数据集主要用于相机定位评估，因此像素级重建的跨数据集验证仍有限。
- 深度和点图监督来自 LiDAR 或 MVS 等数据源，不同来源的密度和误差特性可能影响训练与评估；论文采用的数据构造也依赖外部卫星影像。
- 鲁棒性实验显示降低卫星分辨率、扩大裁剪范围和人为错位都会增加误差，表明模型对卫星图的细节和地理准确性存在实际依赖。
- Oracle alignment 对比提示，地理变换预测并非已解决到接近真值的程度；并且在部分场景中，仅改善相机对齐不能充分改善稠密点图的位置。
- 论文的结论适用于其设定的单幅正射卫星图与地面多视图场景，不能直接推及一般卫星影像、任意尺度地图或没有可靠地理参考的场景。
- 对安全关键应用仍需额外验证：作者也提醒，定位误差可能发生，应用于决策或安全场景前应进行校验。
