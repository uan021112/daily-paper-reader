## 摘要
视觉-语言-动作模型（VLA）利用视觉-语言模型（VLM）处理视觉观测和语言指令，使机器人能够执行操作任务。然而，动作预测目标本身缺乏细粒度、针对特定任务的感知监督，因此容易依赖与任务无关的视觉捷径，导致注意力偏离目标物体和关键交互区域，从而限制其操作性能与泛化能力。为此，我们提出面向机器人操作的自动感知引导注意力对齐框架（$A^3$-VLA），从操作过程本身中提取针对特定任务的视觉引导信息。具体而言，$A^3$-VLA首先根据交互引起的视觉变化，启发式地生成目标物体和机器人的候选区域，并在离线阶段利用视觉分割模型对这些区域进行细化。随后，通过两个互补的目标函数将这些区域作为显式感知引导：注意力分配损失鼓励语言或机器人状态 token 查询视觉输入时，充分关注对任务至关重要的区域；对比学习损失则使候选目标区域的表征与语言指令对齐，同时将其与任务无关区域区分开来。在模拟和真实世界操作任务上的大量实验表明，$A^3$-VLA能够持续提升多种VLA骨干模型的性能，在各基准测试中的平均成功率提升了6.5%–25.2%。

## Abstract
Vision-Language-Action Models (VLAs) enable robots to perform manipulation tasks by leveraging Vision-Language Models (VLMs) to process visual observations and language instructions. However, the action prediction objective itself lacks fine-grained task-specific perceptual supervision, making it prone to relying on task-irrelevant visual shortcuts, leading attention away from target objects and key interaction areas, thereby limiting its operational performance and generalization ability. To address this, we propose Automatic Perception-Guided Attention Alignment for Robot Manipulation ($A^3$-VLA), a framework that derives task-specific visual guidance from the manipulation process itself. Specifically, $A^3$-VLA first generates heuristic candidate regions for target objects and the robot from interaction-induced visual changes, and refines them with a visual segmentation model offline. These regions serve as explicit perceptual guidance through two complementary objectives: an attention allocation loss that encourages sufficient focus on task-critical regions when language or robot state tokens query the visual input, and a contrastive learning loss that aligns the representations of candidate target regions with language instructions while separating them from task-irrelevant regions. Extensive experiments on simulated and real-world manipulation tasks demonstrate that $A^3$-VLA consistently improves multiple VLA backbones, with an average success rate gain of 6.5% - 25.2% across benchmarks.

## 1. 核心问题与整体含义

- **研究问题：**视觉-语言-动作模型（VLA）通常以动作预测为主要训练目标，但动作损失并不直接监督模型应该关注图像中的哪些区域。微调过程中，模型可能转而依赖任务无关的视觉线索，忽视语言指令指定的目标物体或机器人关键交互区域。
- **研究动机：**已有 VLA 即使能生成动作，也可能没有把语言与正确的视觉目标对应起来。作者认为，操作轨迹中的接触时刻、物体变化和机器人运动本身包含了“任务中哪些区域重要”的信息，可以据此提供任务相关的感知监督。
- **整体思路：**提出 A³-VLA，从操作过程中自动提取并细化目标物体和机器人区域，再将这些区域用于辅助 VLA 训练，使模型更关注任务关键视觉区域、并加强目标视觉表征与语言指令之间的联系。
- **推理阶段：**只使用训练好的 VLA，不需要额外运行分割模型，因而作者称该方法不增加推理时计算开销。

## 2. 方法论

### 核心流程

1. **从操作变化提出候选区域。**
   - 根据轨迹中的机器人状态或其他任务线索确定粗略交互时刻 \(t_k\)，例如夹爪状态或接触信号。
   - 对目标物体，寻找交互前变化较小、交互后变化较大的图像区域：交互前稳定、交互后变化的图像块被视为目标候选。
   - 对机器人区域，寻找相邻观测之间变化较大的图像块。
   - 多次交互任务分别处理各交互区段，再合并候选区域。阈值 \(\tau\) 在实验中设为 10。

2. **用 SAM2 离线细化区域。**
   - 将交互时刻得到的候选图像块转成二值掩码，分别作为目标物体和机器人区域的提示，交由 SAM2 沿轨迹传播。
   - 再把像素级掩码映射到 VLA 的图像 patch 网格；当 patch 与掩码的重叠比例超过阈值 \(\rho\) 时，将其纳入伪区域，文中设 \(\rho=0.25\)。
   - 这些区域是用于软监督的伪标签，并非精确的人工标注。

### 两类感知辅助目标

- **注意力分配损失：**
  - 在 VLM 最后一层取注意力并对注意力头求平均。
  - 对语言 token 查询图像 patch 的注意力，要求分配给目标候选区域的总注意力不低于阈值 \(\eta_1\)。
  - 对机器人状态 token 查询图像 patch 的注意力，要求分配给机器人候选区域的总注意力不低于阈值 \(\eta_2\)。
  - 损失采用平方惩罚：若伪区域获得的注意力已达到阈值则不再惩罚；低于阈值时惩罚差额。实验中 \(\eta_1=\eta_2=0.25\)。

- **对比学习损失：**
  - 将语言指令的 token 表征平均池化为语义锚点；将目标候选区域的图像 patch 表征池化为正样本，将目标区域外的 patch 表征池化为负样本。
  - 使用余弦相似度和对比损失，使语言表征更接近目标区域表征、远离非目标区域表征。
  - 该损失只在交互前应用，以降低机器人遮挡对目标区域表征的干扰。

### 联合训练

- 总损失由主动作流匹配损失、两项注意力分配损失和对比学习损失组成：
  \[
  L=L_{FM}+\lambda_1(L_{l2i}+L_{s2i})+\lambda_2L_{cl}.
  \]
- 文中默认 \(\lambda_1=0.1\)、\(\lambda_2=0.01\)。模型在训练时联合优化动作生成和感知对齐目标。

## 6. 主要结论与发现

- A³-VLA 在所测仿真和真实任务中提升了多种 VLA 骨干的表现。论文报告在不同基准上的平均成功率增益约为 **6.5%–25.2%**，具体幅度随骨干和基准而异。
- 在 VLABench 上，A³-VLA（π0）、A³-VLA（OpenVLA-OFT）和 A³-VLA（π0.5）的平均成功率分别为 0.64、0.40 和 0.67；对应骨干为 0.47、0.16 和 0.41。
- 在 RoboTwin 2.0 上，三个对应骨干的平均成功率分别从 0.42、0.20、0.58 提升至 0.52、0.27、0.65。
- 真实世界实验中，A³-VLA（π0）的平均成功率为 0.76、任务进度均值为 0.87，高于表中 π0 与 π0.5 的结果；Select Bottles 任务提升尤为明显。
- 消融结果显示，语言到图像注意力对齐贡献最大：移除后 VLABench 平均成功率由 0.64 降至 0.52；移除状态到图像对齐或对比损失也会降低表现。
- 结果支持作者的解释：显式感知监督可能帮助模型在微调中保持对任务目标的关注，并使动作学习更快或更稳定。不过，注意力可视化和实验结果本身并不能单独证明这种机制是性能提升的唯一原因。

## 7. 优点

- **利用操作过程生成监督：**区域引导来自交互前后的视觉变化，不依赖逐帧人工框选或掩码标注，降低了构造任务相关感知监督的人工成本。
- **监督目标互补：**注意力分配约束关注位置，对比学习约束视觉区域与语言的语义关系，分别作用于注意力空间和表征空间。
- **软约束设计较合理：**只要求伪区域获得最低注意力质量，不强制模型完全忽略其他图像内容，降低了噪声伪标签带来过度约束的风险。
- **有一定模型通用性：**方法应用于多种 VLA 骨干，且在仿真、真实场景及扰动条件下都进行了评估。
- **不增加推理阶段的模块负担：**SAM2 仅用于离线预处理，部署时只运行微调后的 VLA。

## 8. 不足与局限

- **依赖可识别的交互时刻：**方法假设能通过夹爪状态、接触信号或任务状态区间获得粗略交互时刻；没有清晰交互事件的任务或不同机器人形态可能需要额外的事件检测机制。
- **候选区域可能不可靠：**目标完全遮挡、目标很小、与背景难以区分，或目标与干扰物一起运动时，视觉变化启发式可能给出较弱或错误区域；SAM2 的传播也受分割质量影响。
- **存在错误监督风险：**伪区域即使经过细化仍不是人工标注真值，错误区域可能误导注意力或对比学习。论文提出未来可考虑不确定性感知加权，但当前方法尚未解决这一问题。
- **实验的统计证据有限：**没有误差条、置信区间或显著性检验；评估 episode 数有限，尤其真实世界每任务仅 20 次，结果的不确定性无法从报告中充分判断。
- **测试覆盖仍有限：**真实世界仅覆盖一个机械臂平台及五类厨房任务，尚不足以证明对不同机器人、传感器、操作技能和开放环境的普遍适用性。
- **效率报告不完整：**虽给出 GPU 型号、数量和训练步数，但没有明确训练耗时、SAM2 预处理时间或完整算力成本。
- **性能提升机制仍有待进一步验证：**论文报告注意力图更集中、训练曲线更好，但对伪区域质量、注意力变化与成功率提升之间的因果关系，尚缺少更直接的机制性验证。
