## 摘要
自然的人机交互要求机器人能够在三维环境中理解语言和手势，以支持抓取与放置、物体检索等任务。三维具身指称理解（3D-ERU）通过从包含人类指向手势及相应语言描述的场景（点云）中识别目标物体的三维位置来支持此类任务。然而，当前的 3D-ERU 模型缺乏跨模态表征对齐，且处理开销较高，并会随点云规模增大而增加。为解决这一问题，我们提出 GVT3D，该方法采用具身融合模块，在共享嵌入空间中联合建模语言、手势和视觉输入，从而促进跨模态对齐。此外，我们引入一种注视聚焦方法，仅对指向方向估计值周围的粗略区域内的点云进行选择性处理，以减少计算量。与先前的 3D-ERU 模型相比，GVT3D 的准确率提高约 8%；在保持准确率相近的同时，注视聚焦使执行速度提升 2.95 倍。

## Abstract
Natural human-robot interaction requires robots to interpret language and gestures within a 3D environment to support tasks such as pick-and-place and object retrieval. 3D Embodied Reference Understanding (3D-ERU) supports this by identifying the 3D location of a target object from a scene (point-cloud) containing a human pointing gesture and an accompanying language description. However, current 3D-ERU models lack alignment of cross-modal representations and incur high processing costs that increase with the point-cloud's size. To address this, we propose GVT3D, which employs an Embodied Fusion module that jointly models language, gesture, and vision inputs within a shared embedding space, promoting cross-modal alignment. We additionally introduce a foveation approach that selectively processes the point cloud within a coarse region around the estimated pointing direction to reduce computations. GVT3D achieves ~8% higher accuracy and foveation enables 2.95x faster execution while maintaining comparable accuracy, relative to prior 3D-ERU models.

## 1. 核心问题与整体含义

- **研究任务：** 三维具身指称理解（3D-ERU）要求机器人结合三维场景、人的指向手势和语言指令，定位指令所指的目标物体。例如，机器人需要理解“把那边的箱子拿来”中的“那边”及“箱子”，并在场景点云中找到对应物体。
- **研究动机：** 既有 3D-ERU 方法存在两类不足：
  - **模态融合不充分：** 语言和手势往往各自独立处理，手势通常只在最后阶段作为几何指向线索使用，未能充分利用二者共同消歧的能力。
  - **计算开销较大：** 处理完整点云及大量候选物体会增加推理成本，影响模型在机器人边缘设备上的实时应用。
- **整体思路：** GVT3D（Gesture-Vision-Text Token Enrichment）以共享的跨模态表示联合建模语言、手势与视觉，并通过手势引导的候选筛选减少视觉编码工作量，目标是在提升定位准确率的同时降低推理延迟和能耗。

## 2. 方法论

### 2.1 整体流程

GVT3D 分为两个阶段：

1. **各模态编码：** 分别提取场景视觉、语言和手势特征。
2. **融合与定位：** 将三种模态投影到共同表示空间，进行联合注意力交互，再对候选物体进行多模态匹配和打分。

### 2.2 视觉编码与手势引导的候选筛选

- **三维特征：** 使用 PointGroup 处理带 XYZ 和 RGB 信息的场景点云，获得逐点语义特征、物体候选及候选特征。
- **多视角二维特征：** 对候选物体点云进行归一化，并从三个视角投影为深度图；再用冻结的 CLIP ViT-B/32 提取视觉特征。不同视角的特征经过瓶颈 MLP 适配、聚合和投影后，与 PointGroup 的三维特征拼接，形成候选物体的视觉表示。
- **手势引导的 foveation（聚焦处理）：** 模型先估计指向方向，再按候选物体与指向方向的对齐程度排序，只对排名靠前的候选执行较昂贵的深度投影和 CLIP 编码，其余候选仍保留三维特征参与后续推理。候选 \(i\) 的指向偏置可概括为：
  \[
  b_i=\frac{(c_i-a)^\top \hat d_{\text{pred}}}
  {\max(\|c_i-a\|_2,\epsilon)}
  \]
  其中 \(c_i\) 是候选中心，\(a\) 是指向手臂的肩部位置，\(\hat d_{\text{pred}}\) 是预测的单位指向方向。需要注意，论文中的 foveation 主要是**筛选候选物体、减少其二维视觉编码**，并非直接裁剪整个点云的某个空间区域。

### 2.3 语言与手势编码

- **语言：** 使用冻结的 CLIP 文本编码器，提取词级和句级特征；词级特征经 MLP 投影到 128 维。
- **手势：** 从 PointGroup 识别的人体点云中提取人体特征，预测人体关节位置，并利用关节特征编码器及自注意力层产生手势 token。
- **指向方向回归：** 不直接把肩部到指尖的连线当作指向射线，而是将左右手臂的肩、肘、腕、食指指尖等关节相对位置输入 MLP，输出归一化的指向方向。这样旨在适应手臂不完全伸直等自然动作。

### 2.4 具身融合与候选打分

- **具身融合模块：** 将文本、手势和视觉特征分别投影到 256 维空间，拼接成一个序列，由 Transformer 编码器对全部 token 做联合自注意力，使不同模态能在 token 层面相互影响。之后将融合结果拆分，并映射回各自模态的维度，与原特征残差相加、层归一化。
- **跨模态匹配：** 融合后的语言与手势 token 作为指称信息，与候选物体视觉特征通过 Transformer 式交叉注意力结构匹配，得到内容分数 \(S_{\text{conf}}\)。
- **自适应分数融合：** 将内容分数与几何指向偏置 \(S_b\) 加权组合：
  \[
  S_{\text{final}}=w_0S_{\text{conf}}+w_1S_b,\qquad
  [w_0,w_1]=\operatorname{Softmax}(\operatorname{MLP}(F_{\text{agg}})).
  \]
  权重依据人体整体姿态特征自适应产生。最终选取得分最高的物体作为预测目标。
- **训练：** 使用 PointGroup 的语义、偏移和物体性损失，以及指称交叉熵、对比损失和关节定位损失；另在前 10 个 warm-up epoch 使用逐渐衰减的指向 bootstrap 损失。模型端到端训练 40 个 epoch。

## 3. 实验设计

### 3.1 数据集与任务

- 主要基准为 **ImputeRefer**：基于 ScanNet 场景和 ScanRefer 指称表达扩展，包含约 **707 个场景、35,000 个样本**，每条样本指向一个目标物体。
- 数据集区分：
  - **Unique：** 场景中目标类别只有一个物体。
  - **Multiple：** 场景中存在多个同类别候选物体，是更具挑战性的消歧情形。
- 主要指标为 **IoU@0.25 和 IoU@0.5**；此外还评估推理延迟、能耗、跨模态表示对齐以及真实机器人任务表现。

### 3.2 对比方法

- **具身指称理解方法：** ScanERU、Ges3ViG。其中 Ges3ViG 是主要对比对象。
- **不使用手势的三维视觉定位方法：** 3DVG-Transformer、HAM、3DJCG、RefMask3D、M3DRef-CLIP。
- **消融/变体：** 去除具身融合、去除手势、固定简单语言输入、不同 foveation 候选预算，以及只使用内容分数、只使用手势分数、等权融合等设置。

### 3.3 主要结果

- 不使用 foveation 时，GVT3D 的整体 IoU@0.5 为 **66.7%**，Ges3ViG 为 **58.7%**，相差 **8.0 个百分点**。
- 在 Multiple 场景中，IoU@0.5 从 Ges3ViG 的 **55.8%** 提升到 **65.2%**，提高 **9.4 个百分点**。
- 在 Jetson Orin Nano 上，论文报告不使用 foveation 时 GVT3D 相比 Ges3ViG 快约 **1.75 倍**；当 foveation 的候选预算 \(k=10\) 时，速度约快 **2.95 倍**，并报告能耗约为 Ges3ViG 的 **29.24%**。
- 跨模态分析显示，融合后模态间线性 CKA 和 Recall@1 均有提升；例如视觉—文本、视觉—手势和文本—手势的 Recall@1 分别达到 **43.6%、19.9% 和 15.4%**。
- 真实机器人实验中，GVT3D 的目标定位被评为正确的比例为 **70%**，Ges3ViG 为 **56%**。对于定位正确的子集，机器人导航到目标附近的平均距离为 **0.79 米**；部分试验因里程计漂移而中止。

## 6. 主要结论与发现

- 在 3D-ERU 中，语言、手势和视觉特征的联合交互能够提升目标定位，尤其有助于存在多个同类别候选物体时的消歧。
- 学习式的指向方向估计可替代简单的肩—指尖几何假设，但手势仍不应独立决定目标：论文中只使用手势分数的设置明显较弱，而内容分数单独使用已接近完整模型。
- Foveation 通过减少候选物体的二维视觉编码量，改善边缘设备上的速度和能耗表现；但预算过小时可能提前排除正确目标，使模型无法恢复。
- 在远距离（public zone，至少 3.70 米）场景中表现下降，表明指向线索的区分能力会受人—目标距离影响。

## 7. 优点

- **问题定义贴近实际人机交互：** 同时利用语言、手势和三维几何信息，针对单靠语言描述可能不充分的场景。
- **融合机制具有针对性：** 具身融合模块通过联合 token 自注意力在匹配前进行跨模态交互，不只是将各模态分数简单相加。
- **兼顾精度与部署效率：** 同时报告准确率、推理延迟和能耗，并在 Jetson Orin Nano 上验证。
- **设计具有可解释性：** 通过 CKA、Recall@1、噪声干预和距离分析，尝试说明模态对齐及不同线索的作用。
- **包含真实系统验证：** 将定位模块接入移动机器人与 Nav2，而非止于离线 benchmark。

## 8. 不足与局限

- **数据和任务覆盖有限：** 核心离线评估集中于 ImputeRefer，且每条样本仅指向一个物体；多目标、区域级指称和更复杂的交互式任务没有覆盖。
- **真实验证规模较小：** 30 个场景及有限参与者不足以充分验证跨用户、跨环境的稳健性；此外，模型经过真实数据微调，泛化结论应谨慎解读。
- **远距离及密集场景仍具挑战：** 远距离指向准确性下降；在密集场景中，若 foveation 候选预算过小，正确目标可能被排除。
- **效率依赖预算选择：** foveation 加速与召回风险存在权衡；论文的高加速结果不能脱离候选预算和场景分布单独理解。
- **部分性能提升的因果归因仍有限：** 消融结果支持融合模块的重要性，但完整系统同时包含学习式手势回归、CLIP 多视角视觉特征和融合结构，难以完全分离各组件对总体提升的贡献。
- **资源披露不完整：** 未报告训练 GPU、训练耗时等关键训练成本信息，不便于复现及全面比较资源开销。
