Abstract
Learning semantic representations for 3D Gaussian Splatting has recently emerged
as a promising direction for 3D scene understanding. However, existing 2D-to-
3D semantic lifting approaches rely primarily on 2D segmentation supervision
and lack object-level priors, causing the learned representation to be driven by
local mask evidence rather than holistic object structure. In this paper, we present
VLSplat, a vision-language guided approach for object-centric semantic lifting
in 3D Gaussian Splatting. Our method augments mask-based lifting with object-
level semantic priors derived from vision-language models and refines Gaussian
representations using an object-group scene graph. The refinement is performed
through two language-guided modules: intra-group refinement suppresses semantic
noise within object groups, while inter-group acquisition expands object support
regions by incorporating structurally relevant candidates from neighboring groups.
Extensive experiments on indoor scene datasets demonstrate that VLSplat improves
the semantic consistency and structural completeness of object-level categories.
Our code and models are available at https://vlsplat.github.io/.

Introduction
Understanding 3D scene semantics from multiple 2D views is a fundamental problem in computer
vision, enabling object-level understanding and downstream applications such as robotics [1, 2],
AR/VR, scene editing [3, 4], and semantic mesh extraction [5, 6]. Recently, 3D Gaussian Splatting
(3DGS) [7] has emerged as a powerful representation for real-time novel-view synthesis, motivating
growing interest in learning semantic-aware Gaussian representations for joint rendering and scene
understanding. In this setting, the goal is to lift 2D semantic observations, typically segmentation
masks, into object-aware 3D Gaussian representations such that 3DGS captures semantic properties
of the underlying scene.
Existing semantic 3DGS methods can be broadly divided into language-feature lifting and mask-
based grouping. Language embedding approaches learn language latent fields or attach vision-
language features to Gaussian primitives for open-vocabulary 3D understanding. Language latent-field
methods [8, 9, 10, 11, 12, 13] distill CLIP [14] features into a continuous 3D feature space for natural-
language querying, whereas Gaussian-level embedding methods [15, 16] associate such features with
individual primitives for more discrete point-level semantics. However, these methods mainly lift or

associate vision-language semantics with reconstructed Gaussians for retrieval and querying, rather
than directly optimizing Gaussian features with vision-language guidance for category-aware object

In contrast, mask-based grouping methods use 2D segmentation masks to learn Gaussian groups at
instance-level, often producing more explicit object separation than language-field representations [17,
18, 19, 20]. Recently, codebook-based lifting has been introduced for 3DGS semantic lifting, where
Unified-Lift [21] associates Gaussian features with a trainable object-level codebook to organize
primitives into mask-consistent object regions. However, such methods are induced by local 2D
segment masks such as SAM [22], whose view-dependent and multi-level predictions can split the
same object into multiple parts or merge semantically different regions into one mask, especially in
indoor scenes. As a result, the learned Gaussian groups may appear locally consistent in rendered
views, but they are not explicitly grounded in category-level object semantics, limiting complete
object-centric representation learning.
In this work, we propose VLSplat, a vision-language guided framework for category-aware object-
centric semantic lifting in 3DGS. Our goal is to extend codebook-based Gaussian lifting from
category-agnostic instance grouping to category-aware object representation learning under 3DGS
optimization. We first construct hybrid 2D supervision by combining text-prompted object masks
for major indoor categories with category-agnostic masks for the remaining regions. This provides
semantic object cues while retaining dense mask coverage for the scene.
To overcome noise and inconsistency from 2D masks, we reinterpret learned Gaussian-codebook
groups as nodes in a scene graph. Each node represents a semantic object candidate or an uncertain
fragment, and graph relations provide spatial context for reasoning about whether a group is a
meaningful object, noisy component, or candidate region to be reassigned. Based on this graph,
VLSplat performs two complementary refinements: intra-group semantic refinement suppresses noisy
primitives within object nodes, while inter-group acquisition expands incomplete object support
by retrieving structurally plausible candidates from surrounding background regions using vision-
language priors.
We conduct extensive experiments on 3D semantic and instance segmentation and point-level semantic
segmentation. Following the thing–stuff taxonomy [23], VLSplat targets thing categories, i.e., objects
with a well-defined shape such as chairs, desks, and beds. Rather than merely lifting vision-language
semantics onto reconstructed Gaussians for retrieval or querying, our method directly optimizes
Gaussian features with vision-language guidance through scene-graph structured refinement. Our
contributions are summarized as follows:
• We propose VLSplat, a vision-language guided semantic lifting framework that extends
codebook-based Gaussian grouping from category-agnostic instance clustering to object-
centric representation learning.
• We design an object scene graph that interprets codebook groups as nodes enriched with
VLM-derived language priors and spatial adjacency, and use it as an object-level prior for
Gaussian refinement.
• We introduce language-guided Gaussian gating on synthetic object views, enabling intra-
node refinement and inter-node acquisition that improve both the semantic consistency and
structural completeness of object groups.

Related Work
2D-to-3D Semantic and Instance Lifting.
2D-to-3D lifting transfers 2D masks, segments, or
semantic features into 3D fields while enforcing multi-view consistency. Neural-field-based methods
lift object selections, panoptic masks, or contrastive segments into volumetric representations [20, 24],
while related approaches incorporate open-vocabulary semantics, promptable segmentation, or
hierarchical grouping into radiance fields [25, 26, 27]. With the rise of 3DGS, later methods lift 2D
mask supervision onto explicit Gaussian primitives for object-level instance segmentation [17, 18, 19,
28, 29, 30]. Unified-Lift [21] further introduces codebook-based Gaussian semantic lifting, where
Gaussian features are associated with a trainable object-level codebook to form mask-consistent
object regions. Recent works also revisit the lifting solver itself through structured self-training,
global label assignment, or modular segmentation on pre-trained 3DGS scenes [31, 32, 33]. However,
2


existing lifting methods remain strongly tied to 2D mask quality and cross-view consistency, whereas
our proposed VLSplat injects object-level language priors and graph-guided reassignment to refine
ambiguous or incomplete Gaussian groups.
Vision-Language Gaussian Embedding.
Recent works extend 3DGS to language-aware scene un-
derstanding by embedding semantic, CLIP [14]-aligned, or foundation-model features into Gaussian
representations [9, 11, 12, 13, 34]. These methods distill vision-language features into continuous 3D
language fields or Gaussian primitives for open-vocabulary retrieval, natural-language querying, and
rendered-view semantic prediction [9, 10, 11, 12, 13, 35, 36]. Recent SAM [22]+CLIP [14] based
approaches improve object-level localization by combining object masks with language features:
OpenGaussian [16] and LangSplatV2 [15] link SAM-derived instance features with CLIP embed-
dings for point-level open-vocabulary understanding, and PanoGS [8] uses language-guided graph
cuts with SAM-guided affinities for panoptic scene understanding. Beyond per-scene optimization,
SceneSplat [37] and Chorus [38] pretrain generalizable 3DGS scene encoders with vision-language or
multi-teacher supervision, following self-supervised point representation learning such as Sonata [39].
While effective for queryable semantic fields and transferable scene encoders, these methods mostly
treat language features as annotations to be lifted or distilled, whereas VLSplat uses object-level
language priors to structurally refine Gaussian object groups.
Structured Scene Graph Reasoning.
3D scene graphs provide structured abstractions for objects,
regions, agents, and their relations in 3D environments. Early works construct hierarchical scene
graphs for indoor scenes and reconstructed environments, linking object-level semantics with indoor-,
or scene-level structure [40, 41, 42]. Later mapping systems extend scene graphs to online spatial
perception, dynamic agents, and robot planning through metric-semantic maps and layered graph
structures [43, 44, 45]. Recent language-aware scene graphs further support open-vocabulary scene
abstraction, open-set relation prediction, language-guided navigation, and context-aware entity
grounding [46, 47, 48, 49, 50, 51]. While prior works mostly use scene graphs as output abstractions,
structured memories, or downstream reasoning substrates [52, 53, 54, 55], VLSplat uses graph
structure as an optimization scaffold for refining object-centric Gaussian groups during semantic
lifting.
3
Proposed Approach
VLSplat addresses object-level 3D instance and semantic segmentation in 3D Gaussian Splatting
scenes, illustrated in Fig. 1. The method first lifts object-aware 2D semantic masks into 3D with
Gaussian-level features and an object-level codebook (Sec. 3.1). It then constructs a 3D scene graph
that associates codebook groups with language semantics and spatial context (Sec. 3.2). Finally,
VLSplat uses the scene graph as an object-level prior to refine Gaussian features beyond mask-level
supervision, producing more object-consistent semantic representations (Sec. 3.3).

After obtaining the spatial support of each codebook group,

Thing–stuff taxonomy.
Following the thing–stuff taxonomy in panoptic scene understanding [23],
we report the metrics separately for our defined thing and stuff splits. Thing categories are bed,
cabinet, chair, desk, monitor, and sofa, which serve as target nodes in our scene graph. Stuff categories
are wall, floor, ceiling, curtain, door, picture, and window, which are evaluated during rendering but
not used as primary targets for object-centric refinement.

4.2
3D Point Cloud Semantic Segmentation
Datasets & Evaluation metrics.
Following prior point-level 3D Gaussian segmentation works [16],
we evaluate 3D semantic and instance segmentation on ScanNetV2 [60] and Replica [59]. Both
datasets provide annotated 3D geometry with point-level semantic and instance labels, allowing
predictions to be directly evaluated on fixed 3D support. For semantic segmentation, we report
mIoU and mAcc. For instance-aware evaluation, we report panoptic reconstruction quality [61], i.e.,
PQ [62] with an IoU matching threshold of 0.25, for thing and stuff categories, denoted as PRQ(T)
and PRQ(S), respectively.

5
Conclusion
We presented VLSplat, a vision-language guided framework for object-centric semantic lifting in 3D
Gaussian Splatting. VLSplat addresses the limitations of mask-based lifting by using object-level
language priors and scene-graph structure to refine Gaussian features beyond local 2D mask evidence.
Through intra-node refinement and inter-node acquisition, our method suppresses semantic noise
within object groups and recovers missing object support from neighboring regions. Experiments
on render-level and point-level segmentation show that VLSplat improves semantic consistency and
structural completeness, particularly for target object categories.
Limitations.
Although VLSplat can recover missing object support caused by view-level mask
inconsistency, it still requires a reasonable coarse object group to be formed during the initial lifting
stage. If an object is rarely observed or rarely detected across the input views, the codebook may
fail to construct a reliable object node, and synthetic object-view rendering may provide insufficient
visual evidence for CLIP-based gating. Stronger 3D or generative priors, such as SAM3D [5] or
video diffusion models, could help complete such weakly observed regions, but they also introduce
challenges in multi-view consistency and alignment with the reconstructed 3D coordinate system.
In addition, VLSplat relies on foundation models such as SAM3 [57], a VLM, and CLIP [14], and its
sensitivity to these choices has not been systematically studied. Our evaluation also focuses on thing
categories in indoor scenes. Finally, the refinement introduces additional offline optimization cost
that grows with the number of target nodes.
Broader Impact.
VLSplat improves object-centric 3D scene understanding by organizing Gaus-
sian primitives into semantically meaningful object representations. This can benefit downstream
applications such as robotics, AR/VR, and semantic mapping. Such representations could support
tasks requiring object-level assessment of 3D scenes, such as progress monitoring in built envi-
ronments [63]. However, inaccurate semantic lifting may lead to incorrect object localization or
unreliable scene interpretation, especially in safety-critical applications.

SAM2–SAM3 Mask Combination
Mask sources.
We use both SAM3 [57] and SAM2 [56] to construct the 2D mask supervision used
for Gaussian-level semantic lifting. SAM3 is applied with category-level text prompts and provides
semantically labeled masks for major indoor classes. In our implementation, the prompt set includes
wall, floor, ceiling, bed, cabinet, chair, curtain, desk, door, monitor, picture, sofa, and window. These
masks are useful for maintaining object-level semantic consistency, but they do not cover objects
outside the prompt vocabulary and may miss small or weakly visible regions.
SAM2 is used through its automatic mask generator. Unlike SAM3, SAM2 does not require text
prompts and usually provides dense instance coverage over the image. However, the resulting masks
do not have category labels, and a single semantic object can be split into several small instances.
This behavior is problematic for our lifting stage because different parts of the same object may be
assigned to different group IDs.
Compared variants.
We consider three mask construction variants before applying the merged
masks to Gaussian-level lifting. The first variant is SAM2-only, where all masks are obtained from
the SAM2 automatic mask generator. This gives dense coverage, but often produces fragmented
instances around object boundaries, furniture, and small cluttered regions. The second variant is
SAM3-only, where only text-prompted SAM3 masks are used. This gives more stable semantic
regions for prompted categories, but leaves uncovered pixels when objects are small or outside the
predefined class set. The third variant is our SAM3-priority merged mask, where SAM3 is treated
as the main semantic source and SAM2 is used only to fill regions not sufficiently covered by SAM3.

SAM3 post-processing.
Before merging, SAM3 masks are filtered to reduce duplicate or noisy
semantic regions. Small SAM3 masks with area below 500 pixels are removed. We also suppress
duplicate masks across related classes using mask overlap. This is especially needed for categories
such as desk and table, where the same physical object can be detected by both prompts. After this
step, SAM3 masks serve as the semantic backbone for the merged supervision.
Repainting.
After filtering, the retained SAM2 masks are combined with the post-processed SAM3
masks and converted into a single 16-bit instance map. When multiple masks overlap, masks are
painted in ascending order of confidence score, so that higher-confidence masks overwrite lower-
confidence ones. This produces a single valid instance ID for each pixel and avoids ambiguous pixel
assignments during lifting.

desk, but several small objects and local regions on the desk remain uncovered. The merged result
keeps the main semantic regions from SAM3 while adding SAM2 masks in the regions missed by
SAM3. This provides denser supervision without fully replacing the object-level consistency of
SAM3.
B
Limitations of prompt-based 2D mask generation.
Even with our SAM3 [57]+SAM2 [56] mask generation strategy, prompt-based 2D segmentation
can remain unstable across views. This issue is particularly common in indoor scenes, where objects
of the same category are spatially adjacent or partially occluded. As shown in Fig. 6, neighboring
desks may be merged into a single region in one view while being separated into distinct instances
in another. Such view-inconsistent masks provide ambiguous supervision for semantic lifting and
can lead to fragmented or incorrectly merged Gaussian groups. These failure cases motivate the
need for our ROI-based scene graph, which improves grouping consistency by reasoning over object
relationships directly in 3D space.

Effect of VLM Prompts on Object-level Representation Learning
Fig. 7 visualizes the proposed intra-node and inter-node refinement process for object-centric Gaussian
representation learning. Following Sec. 3.2, we first construct an object scene graph and identify the
reliable object Gaussians Gin and the candidate Gaussians Gadd. We then learn the opacity gates of
the candidate Gaussians using CLIP [14]-based language guidance. Through this process, intra-node
refinement suppresses noisy Gaussians inside the object region while encouraging object-consistent
Gaussians to be treated as positive evidence, leading to more discriminative object features. In
contrast, inter-node refinement acquires candidate Gaussians from background or unlabeled groups
when they are semantically and structurally consistent with the target object.
The results show that the proposed gating mechanism helps recover missing object parts while
preventing irrelevant Gaussians from being incorporated. In the first and third rows, inter-node
refinement successfully includes thin structural parts such as chair or desk legs, which are often
weakly observed in 2D masks or initially assigned to background Gaussian groups. In the second
row, although valid table-leg candidates are not sufficiently included in Gadd, the learned gate still
prevents noisy candidates from being incorrectly merged into the target object. This indicates that the
refinement process is useful not only for acquiring missing object parts but also for filtering unreliable
candidates.
We further compare different text prompts used for CLIP-based Gaussian gating. The prompts are
constructed from object labels obtained from the scene graph and SAM3 masks, and are compared
with more general prompt templates such as “a photo of a {class}”. Overall, more descriptive prompts
that include color or structural attributes provide stronger language guidance for selecting appropriate
Gaussians. For example, in the first row, the prompt containing the phrase “four legs” assigns higher
positive scores to Gaussians corresponding to the chair legs. Similarly, in the table and desk examples,

Qualitative results on point-level 3DGS semantic segmentation
Fig. 10 provides close-up views
of selected object regions in 3D scenes. These visualizations demonstrate the effectiveness of our
refinement strategy for 3D point cloud segmentation. In the upper scene, our method produces a
cleaner segmentation of the red chair. By performing intra-node refinement, it filters noisy points
and incorrectly assigned regions within the object group, reducing mixed-class predictions inside
the object and improving object-level separation. Furthermore, inter-node refinement helps recover
object parts that are weakly observed by 2D masks. For example, the chair legs are partially assigned
to background Gaussian groups in the initial representation, but our method successfully incorporates
them by leveraging language-prior information during Gaussian semantic representation learning. As
a result, the final segmentation better preserves the structural completeness of the object.
A similar trend is observed in the lower scene. Our method more clearly separates neighboring
objects within the same space while preserving fine-grained structures such as thin chair legs. These
results indicate that the proposed refinement process improves both local semantic consistency and
object-level structural completeness.
