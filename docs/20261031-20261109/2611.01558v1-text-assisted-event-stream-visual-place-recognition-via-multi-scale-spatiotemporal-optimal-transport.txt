## ABSTRACT 

Benefiting from the high dynamic range, high temporal resolution, and low en-ergy consumption of event cameras, low-altitude economic research leveraging event cameras has become a popular topic. Several existing attempts introduce natural-language descriptions into visual place recognition (VPR) to mitigate the sparsity of structural spatial information inherent to event cameras. Nevertheless, these methods still fail to fully address two core challenges: effectively encoding event streams and semantically aligning event streams with text. In this paper, we propose a multi-scale spatial-temporal optimal transport approach, MSTOT-EPR, to address these challenges. Specifically, given event streams and scene text in-formation, we first adopt a visual encoder and a text encoder to extract respective feature representations. We then apply optimal-transport constraints to achieve cross-modal alignment. We then design a cross-modal bottleneck fusion mod-ule to further fuse bimodal features. Furthermore, we develop multi-scale spa-tial optimal transport and inter-frame temporal optimal transport modules to mine high-quality spatial-temporal event features for scene recognition. Extensive ex-periments on the NYC-Event-VPR and EPRBench datasets fully validate the ef-fectiveness of our proposed framework for event-based VPR. The source code of this paper will be released upon acceptance. 

## 1 INTRODUCTION 

Visual Place Recognition (VPR) Chen et al. (2026b) aims to match a query image to its corre-sponding location in a large-scale geotagged database. It holds great research value for many real-world applications, including autonomous driving navigation, large-scale map reconstruction, and low-altitude economy. State-of-the-art VPR solutions are mostly implemented with visible-light cameras; thus, they inherit various inherent challenges from conventional visual perception, such as extreme viewpoint variation, illumination fluctuation, adverse weather conditions, long-term tempo-ral shift, and frequent dynamic occlusions. Developing high-performance VPR approaches remains a challenging problem worthy of further investigation. Benefiting from the unique advantages of event cameras, including low energy consumption, high dynamic range, and high temporal resolution, event-based vision has attracted increasing attention from researchers Gallego et al. (2020a); Chen et al. (2026a); Wang et al. (2026a). Each pixel of an event camera works independently and records the intensity changes of scenes continuously. Specifically, an individual event is formulated as (x, y, t, p ), where x, y denote the spatial pixel co-ordinates, t represents the timestamp, and p refers to the event polarity. The polarity value of +1 indicates an increase in brightness, while -1 corresponds to a decrease in brightness. In recent years, several studies have begun to explore event-based VPR Wang et al. (2026b); Kong et al. (2022), such as Sparse-Event-VPR Fischer & Milford (2022), which performs training-free place match-ing using sparse event-count representations, and EventGeM Hines et al. (2026), which combines 1arXiv:2611.01558v1 [cs.CV] 1 Nov 2026 Under review as a conference paper at ICLR 2027

Despite this progress, these works are still limited by the following issues: 1). Existing event stream-based visual place recognition algorithms mostly adopt event representations from a single time window and rarely consider the asynchronous nature of event cameras. Consequently, they are vulnerable to motion-induced positional shifts and instabilities stemming from event sparsity. 2). Few existing works take into account the lack of semantic information caused by the spatial sparsity of event streams, while the visual place recognition task heavily relies on both spatial-detail features and semantic features. 3). Existing text-enhanced methods for event streams adopt coarse-grained modeling strategies, which fail to establish fine alignment between the temporal features of events and the deep semantic information of texts. These methods cannot effectively adapt to the semantic modeling of complex event streams, thereby severely limiting the performance upper bound of event stream understanding and reasoning tasks. To handle these aforementioned issues, in this paper, we propose a novel multi-scale spatial-temporal optimal transport (OT) based framework for event stream-based VPR, termed MSTOT-EPR. Opti-mal transport (OT) was originally proposed to find the minimum-cost mapping between two prob-ability distributions, resolving the problem of measuring discrepancy for heterogeneous mass dis-tributions. For spatial-temporal modeling, OT excels at capturing structural correspondences across sequential states rather than simple pointwise differences, making it robust against misalignment and spatial-temporal shift. Specifically, given the event streams and scene text information, we first adopt a vision encoder and a text encoder to extract their feature representations. Then, we apply optimal transport constraints to achieve cross-modal alignment. More importantly, we design the cross-modal bottleneck fusion module to achieve bimodal feature fusion and develop multi-scale spatial optimal transport and inter-frame temporal optimal transport modules to mine high-quality spatial-temporal event features for scene recognition. We propose a novel multi-scale spatial-temporal optimal transport-based framework for event stream-based visual place recognition, termed MSTOT-EPR. Extensive experiments on multiple event-based VPR benchmark datasets fully validated the ef-fectiveness of our proposed framework for the representation learning of text-assisted event streams. 

## 2 RELATED WORK 

Visual Place Recognition. Visual Place Recognition (VPR) is a fundamental capability for au-tonomous navigation and spatial AI, aiming to identify the geographical location of a query ob-servation by retrieving matching candidates from a reference database. Early learning-based ap-proaches mainly focused on learning compact and discriminative global descriptors from RGB im-ages. NetVLAD Arandjelovic et al. (2016) introduced a differentiable VLAD layer for weakly supervised place recognition, while subsequent methods such as ConvAP Ali-bey et al. (2022) and MixVPR Ali-Bey et al. (2023) further improved feature aggregation and descriptor robust-ness. With the development of transformer architectures, ViT-based models such as TransVPR Wang et al. (2022) have enhanced long-range dependency modeling and feature alignment for challenging scenes. Recently, foundation models and query-based aggregation strategies have further advanced VPR. AnyLoc Keetha et al. (2023) demonstrates that off-the-shelf self-supervised visual features can provide strong zero-shot place recognition performance. BoQ Ali-bey et al. (2024) introduces a bag-of-queries mechanism to aggregate patch-level features into compact global descriptors softly. SALAD Mahjoub & Kasaei (2023) explores optimal-transport-inspired aggregation for dynamic feature clustering, improving robustness under challenging appearance variations. Despite these advances, most existing VPR methods are designed for synchronous RGB frames and rely heavily on dense appearance cues. Their performance can degrade under low illumination, high dynamic range, high-speed motion, and severe motion blur. Moreover, existing aggregation strate-gies mainly operate on spatial image patches, leaving the sparse and asynchronous temporal struc-ture of event streams insufficiently explored. In contrast, our work focuses on event-stream-based VPR and introduces a spatial-temporal alignment framework tailored to the unique characteristics of event data. 

Event-based and Multimodal Perception. Event cameras are bio-inspired asynchronous sensors that respond to per-pixel log-intensity changes, providing microsecond-level temporal resolution, high dynamic range, low latency, and resilience to motion blur Gallego et al. (2020b). These prop-erties make event streams attractive for robust visual perception in extreme scenarios where con-ventional RGB cameras may fail. Early event-based methods usually converted raw events into frame-like representations, such as event histograms, time surfaces, or voxel grids, enabling the use of conventional convolutional architectures Rebecq et al. (2019). Later studies explored graph-based, point-based, and spiking neural models to better preserve the sparse and asynchronous nature of event data Bi et al. (2019). In the context of place recognition, EventVLAD Fischer & Milford (2020) and recent event-based VPR benchmarks Lee et al. (2023) have shown the potential of event cameras for robust localization under challenging visual conditions. However, event streams mainly encode brightness changes rather than absolute appearance, making them semantically sparse and difficult to interpret compared with RGB images. To compensate for limited semantic information, multimodal learning has become an effective strategy. Vision-language pre-training models such as CLIP Radford et al. (2021) map visual and textual information into a shared representation space, enabling strong cross-modal generalization. Text-guided and language-assisted recognition meth-ods further demonstrate that natural language descriptions can provide high-level semantic priors for visual understanding Zhou et al. (2022); Liang et al. (2022). In VPR, language descriptions can help disambiguate visually similar places by introducing scene-level contextual cues. Nevertheless, directly applying vision-language fusion to event-based VPR remains challenging. Event features are sparse, asynchronous, and temporally ordered, whereas textual features are dis-crete and semantic. Simple concatenation, projection, or contrastive matching may ignore the fine-grained spatial correspondence and temporal evolution of event streams. Therefore, an effective 3Under review as a conference paper at ICLR 2027 text-assisted event VPR framework should explicitly align multimodal representations across both spatial and temporal dimensions. This motivates our multi-scale spatial-temporal optimal transport design. 

Optimal Transport in Computer Vision. Optimal transport (OT) establishes soft correspondences between probability distributions by minimizing the cost of transporting mass under marginal con-straints Villani (2009); Peyr´ e & Cuturi (2019). Unlike pointwise similarity or global pooling, OT captures distribution-level structure and supports many-to-many matching, making it suitable for aligning heterogeneous visual representations. Entropic regularization further enables efficient and differentiable optimization Cuturi (2013), facilitating applications in domain adaptation and struc-tured feature matching Courty (2017); Sarlin (2020). Existing OT-based VPR methods, such as SALAD Mahjoub & Kasaei (2023), primarily focus on spatial aggregation from static RGB images. In contrast, our approach extends OT to event-text alignment, multi-scale spatial correspondence, and inter-frame temporal modeling. Further background and a detailed discussion of OT-related vision methods are provided in Appendix A. 

## 3 METHODOLOGY 

3.1 OVERVIEW 

Event streams are robust to illumination changes and rapid motion, but their spatial sparsity limits the extraction of discriminative place representations. Textual descriptions provide complementary scene semantics, yet the modality gap between event and text features, together with the temporal variations across event frames, remains challenging to model. To address these issues, we propose Multi-Scale spatial-temporal Optimal Transport for Event-stream Place Recognition (MSTOT-EPR), which establishes structured correspondences across modalities, spatial scales, and time using opti-mal transport. As illustrated in Fig. 2, we first extract event and text features and align them through cross-modal OT and bottleneck fusion. Multi-scale spatial OT then captures spatial structures at different resolutions, while inter-frame temporal OT aligns consecutive frames to a shared anchor support. Finally, the enhanced spatial-temporal features are aggregated into a compact global de-scriptor for place retrieval. 3.2 INPUT REPRESENTATIONS

Evaluation metrics. Following the official evaluation protocols of both datasets, we adopt Recall@ K (R@ K) as the evaluation metric, with K ∈ { 1, 5, 10 }. For each query, database samples are ranked according to the similarity between their predicted descriptors. A query is considered correctly localized if at least one ground-truth reference appears among the top-K retrieved candi-dates. R@ K is the percentage of correctly localized queries over the entire query set; higher values indicate better retrieval performance. 4.2 IMPLEMENTATION DETAILS 

We use pretrained DINOv2 ViT-B/14 as the visual backbone and frozen CLIP ViT-L/14 for seman-tic supervision. Each input consists of five consecutive event frames resized to 224 × 224 , with the middle frame ( a = 2 ) selected as the temporal anchor. Unless otherwise specified, the bottleneck dimension is 256, and all OT modules perform 20 Sinkhorn iterations with an entropic regulariza-tion coefficient of 0.08. SALAD uses 64 clusters to produce an 8448-dimensional descriptor. The model is trained for 20 epochs using AdamW with an initial learning rate of 6 × 10 −5. ## A BACKGROUND AND APPLICATIONS OF OPTIMAL TRANSPORT 

Optimal Transport (OT) provides a principled framework for comparing probability distributions by finding a transport plan that minimizes the cost of moving probability mass between them Villani (2009); Peyr´ e & Cuturi (2019). Unlike pointwise metrics or global pooling, OT captures soft many-to-many correspondences under marginal constraints. Entropic regularization enables efficient and differentiable optimization through Sinkhorn iterations Cuturi (2013), making OT practical for mod-ern representation learning. OT has been applied to domain adaptation Courty (2017), distribution-aware learning objec-tives Frogner (2015), style transfer Kolkin (2019), and feature matching Sarlin (2020). In visual place recognition, SALAD Mahjoub & Kasaei (2023) employs OT-inspired assignments to aggre-gate local image features into compact global descriptors. However, existing OT-based VPR meth-ods mainly focus on static RGB images and use OT for spatial matching or feature aggregation. Event-based VPR additionally requires heterogeneous event-text alignment and the modeling of spatial and temporal event structures. Unlike prior methods that apply OT within a single modal-ity or representation level, our approach introduces OT along three dimensions: event-text token alignment, multi-scale spatial alignment, and inter-frame temporal alignment. It therefore extends OT from static feature aggregation to joint cross-modal, cross-scale, and temporal modeling for text-assisted event-stream VPR.

## D IMPLEMENTATION DETAILS 

We implement MSTOT-EPR using PyTorch Lightning and train it on a single NVIDIA RTX 3090 GPU. Each input sample consists of five consecutive event frames resized to 224 × 224 . The frames are normalized using ImageNet statistics and augmented with RandAugment during training. Each mini-batch contains 20 places, with four event sequences sampled for each place. We use pretrained DINOv2 ViT-B/14 as the visual backbone and fine-tune only its last four Transformer blocks, while keeping the CLIP ViT-L/14 text encoder frozen. The spatial OT module constructs multi-scale representations using scale factors of 0.5, 1.0, and 2.0. The temporal OT module aligns all five frames to the middle frame ( a = 2 ). All OT modules perform 20 log-domain Sinkhorn iterations with an entropic regularization coefficient of 0.08. The bottleneck dimension is set to 256, and the alignment-loss weights are set to (λ, μ ) = (0 .05 , 0.05) . SALAD uses 64 clusters and produces an 8448-dimensional ℓ2-normalized place descriptor. The model is trained using the Multi-Similarity loss and Multi-Similarity Miner. We use AdamW with an initial learning rate of 6 × 10 −5, a weight decay of 9.5 × 10 −9, and a linear learning-rate scheduler. Training lasts for 20 epochs using mixed-precision computation.
