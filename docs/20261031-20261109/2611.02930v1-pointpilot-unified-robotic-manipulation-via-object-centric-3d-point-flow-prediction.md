## 摘要
泛化仍是机器人领域面临的核心挑战，这要求策略能够应对来自多个维度的域变化，例如不同的机器人构型、相机位姿和/或场景布局。为解决这一问题，我们提出 PointPilot——一种以任务为中心、与 3D 空间对齐的操作框架，其基础是 3D 空间点流预测。PointPilot 不对全局场景进行建模，而仅表示与任务相关的物体（将机器人夹爪视为物体），从而避免预测与操作任务无关且可能冗余的场景部分。此外，PointPilot 在统一坐标系中对齐 3D 空间表示，并能够依据物体点流，在不同操作模式下实现闭环、全自动的动作执行，无需单独训练动作专家；相比之下，现有方法通常需要额外的动作预测头，或仅支持（半）自动执行及特定的单臂模式。给定传感器观测和语言指令，我们的模型以端到端方式联合学习子任务规划、任务相关物体定位和 3D 点流预测。通过在共享的 3D 点流空间中处理异构数据，PointPilot 能够吸收来自不同机器人构型的示范。大量仿真和真实世界实验验证了我们的方法。值得注意的是，我们展示了 PointPilot 的零样本机器人构型泛化能力：单个训练好的策略即可部署于此前未见过的机器人构型，并成功完成操作任务，无需任何额外微调。

## Abstract
Generalization remains a central challenge in robotics, calling for policies that address domain variations from multiple dimensions such as diverse embodiments, camera poses, and/or scene layouts. In order to approach this problem, we introduce PointPilot, a task-focused and 3D aligned manipulation framework built on a 3D space point-flow prediction. Rather than modeling the global scene, PointPilot only represents task-focused objects (robot grippers treated as objects), avoiding the prediction of potentially redundant scene parts unrelated to the manipulation tasks. Moreover, PointPilot aligns 3D spatial representation in one unified coordinate and supports closed-loop and fully automatic action execution across different manipulation modes from object point flow without a separately trained action expert, while existing works typically need an extra action head or are (semi-)automatic and single-arm mode specific. Given sensor observations and language instructions, our model jointly learns subtask planning, task-relevant object grounding, and 3D point flow prediction in an end-to-end way. By processing heterogeneous data in a shared 3D point flow space, PointPilot is able to absorb demonstrations from different embodiments. Extensive simulative and real world experiments validate our method. Notably, we demonstrate zero-shot embodiment generalization with PointPilot. A single trained policy can be deployed on previously unseen embodiments and successfully complete manipulation tasks without any additional fine-tuning.

- **研究问题**：机器人操控策略需要适应不同机器人构型（embodiment）、相机视角、场景布局和操作模式，但不同机器人原生动作空间的维度、坐标系和控制语义各不相同，导致异构示范难以直接共享。现有方法还常依赖额外的动作解码器、抓取模块或人工介入，或者只支持单臂操控。
- **研究动机**：物体在任务中的运动比机器人关节动作更接近任务本身，也更容易跨机器人共享。因此，论文尝试以任务相关物体的三维运动作为统一监督和控制接口。
- **整体含义**：PointPilot 不预测整幅场景的运动，而是预测当前操作阶段中少量“任务聚焦对象”的三维点流。机器人夹爪也被视为一种对象；在接近阶段预测夹爪运动，在抓取后预测与夹爪刚性耦合的物体运动。预测结果再通过几何适配器转换为机器人末端执行器（EEF）目标，从而连接异构示范与实际控制。

# 2. 方法论

## 2.1 核心思想

PointPilot 把子任务规划、任务对象定位、未来三维点流预测和夹爪开合预测集成到一个模型中。各类机器人共享同一种“任务对象点流”表示；机器人特有的运动学和控制差异，则由部署时的机器人接口处理，而非另行训练动作预测头。

方法主要包括以下环节：

1. **子任务规划**
   - 使用以 Qwen2.5-VL 为骨干的视觉语言模型，根据主视角图像、全局语言指令及此前的子任务文本记忆，生成当前子任务和下一阶段子任务。
   - 当前子任务的隐藏特征传递给后续对象定位模块；下一子任务用于规划监督和更新后续记忆。
   - 记忆机制旨在减少长序列任务中反复执行已完成子任务的问题。

2. **语言引导的三维对象定位**
   - 对主视角图像特征加入基于相机内参构造的三维视锥位置编码。该编码通过沿像素对应的相机射线采样多个深度假设得到，**不要求推理时输入真实深度**。
   - 将图像特征与当前子任务特征送入 Transformer 解码器，预测任务对象的三维边界框（中心、尺寸、旋转）及执行角色。
   - 执行角色包括左手、右手、双手共享和无效，用于说明预测对象运动应分配给哪个夹爪。训练时通过匈牙利匹配对齐预测对象与标注对象。

3. **多视角几何对齐**
   - 主视角作为统一参考坐标系。辅助视角（例如腕部相机）的相机射线坐标通过标定外参变换到主视角坐标系，再加入三维位置编码。
   - 这样，多视角视觉信息和后续预测的点流在相同空间中表达；辅助视角特征进入点流预测模块，但不进入对象定位模块的视觉记忆。

4. **三维点流与夹爪状态预测**
   - 对每个预测的对象边界框进行 Halton 采样，得到其内部的初始点；论文设定每个对象采样 30 个点，最多预测 2 个对象。
   - Point DiT 对未来 30 步的点位移进行条件流匹配预测，并同时预测两侧夹爪的开合状态。点 token 与夹爪 token 在时间步维度联合建模。
   - 点流网络以对象几何与图像特征、规划和 grounding 信息、对齐后的辅助视角特征为条件。推理时从高斯噪声出发，使用 16 次前向 Euler 步骤生成点位移。

5. **由点流转为机器人动作**
   - 将当前点与预测点转换到世界坐标系，使用 Kabsch 刚体配准拟合旋转和平移变换。
   - 将该变换应用到被分配的末端执行器当前位姿：接近抓取时，依据夹爪自身点流执行；抓取后，依据物体点流驱动与物体耦合的夹爪。
   - 双手共享同一对象时，两个夹爪使用同一个刚体变换但保留各自的相对位置。随后通过机器人逆运动学和控制器执行，并基于新观测重新规划，形成闭环。
   - 该执行适配器是**无学习的几何模块**，依赖局部刚性耦合假设，并非完全不需要机器人专属信息：仍需各机器人的标定、运动学和控制接口。

6. **训练目标**
   - 联合优化子任务规划、三维 grounding、点流流匹配和夹爪二分类损失。
   - 训练使用分阶段演示、任务对象几何与轨迹监督；场景超过子任务终点的点流目标会保持在阶段终点，夹爪标签也按规则延续。
   - 文中说明模型共享视觉编码器会被微调；但预测框坐标在采样锚点及 ROI 投影前会被 detach，因此动作损失不会通过这些几何输出反向更新边界框头。

# 6. 主要结论与发现

- PointPilot 在统一三维点流空间中共同处理异构机器人示范，并在仿真中同时支持单臂与双臂操控。
- 论文报告了从 ALOHA 到 ARX 和 Piper 的零样本迁移结果；在其配对评估设置下，PointPilot 的跨本体性能下降小于 X-VLA，尤其是 Piper 上差距较明显。
- 真实世界任务展示了无需额外学习动作专家、基于点流生成目标并闭环重规划的可行性，但三项任务成功率不一。
- 规划记忆使 LIBERO 平均成功率提高 10.6 个百分点，Long 套件提高 22.2 个百分点；加入主视角几何编码、辅助视角及多视角空间对齐后，点流损失逐步降低，支持几何对齐与多视角信息具有互补作用。

# 7. 优点

- **动作表示统一**：以对象运动而非机器人原生动作作为共同监督，有助于跨平台汇聚数据。
- **覆盖多种操作模式**：通过执行角色与可变数量的任务对象，统一处理单臂、双臂及双手协同。
- **强调可执行性**：点流通过刚体几何拟合转为 EEF 目标，不需要另行训练连续动作解码器；同时结合夹爪状态预测实现闭环执行。
- **空间处理明确**：将主视角、辅助视角和点流对齐到同一三维坐标系，避免仅依赖多视角外观融合。
- **实验范围较广**：包含仿真、真实机器人和目标机器人无微调的跨本体部署，且报告了失败率较高的任务，而非只展示成功案例。
- **提供较多实现细节**：附录描述了数据构造、模型张量规模、训练目标、推理积分和评测预算，有利于复现与审查。

- **刚性耦合假设限制适用范围**：物体抓取后，系统假定对象与夹爪局部刚性连接；发生滑移、软体形变或接触关系变化时，刚体适配器可能不可靠。论文也指出当前方法主要面向局部刚性对象和夹爪式执行。

- **仍依赖机器人专属基础设施**：尽管不训练机器人专属动作头，部署仍需要相机内外参、机器人运动学、逆运动学与控制器；腕部相机几何对齐也需要正确标定。
