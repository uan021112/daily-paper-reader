## 摘要
大多数视觉-语言-动作（VLA）策略通过在视觉-语言模型（VLM）上附加外部动作机制，将操作与认知割裂开来：要么将动作量化为离散 token，而其误差与物理位移之间不存在稳定对应关系；要么将连续轨迹生成交由独立的动作专家负责，导致其梯度与 VLM 主干网络的更新相互竞争，或无法用于更新主干网络。我们认为，操作与认知应由同一模型共同承载，即从解耦的 VLA 转向具身视觉-语言模型（eVLM）。我们提出 Concertina，这是一种 eVLM，将连续轨迹表示、分块生成和物理坐标监督直接置于共享扩散式 VLM 主干网络的计算路径与参数路径中。每个控制时间步都在主干网络的隐空间中编码为一个连续潜在动作 token；共享 Transformer 则通过与多模态预训练相同的“扰乱—重建”算子，重建按时间顺序排列的动作块。在 44.6 亿参数的模型中，主动动作投影仅占参数量的 0.21%，且不含独立的动作生成器层；相比之下，代表性连续 VLA 中专用动作专家的参数容量占 16.5%–35.1%。借助我们提出的 Action Interface Audit（动作接口审计），我们确认，跨时间的轨迹耦合产生于共享主干网络的中层和后层，而非动作接口处。在标准基准测试中，Concertina 在常规 LIBERO 上取得 98.15% 的平均成功率，在包含 10,030 个任务的 LIBERO-Plus 基准上取得 85.9% 的成功率，并在 CALVIN ABC-D 上达到 4.142 的平均完成链长度。代码：https://github.com/lose4578/Concertina；Hugging Face：https://huggingface.co/collections/Traly/concertina

## Abstract
Most vision-language-action (VLA) policies decouple manipulation from cognition by bolting an external action mechanism onto a vision-language model (VLM)--either quantizing actions into discrete tokens whose errors bear no stable correspondence to physical displacements, or delegating continuous trajectory generation to a separate action expert whose gradients compete with or are blocked from updating the VLM backbone. We argue that manipulation and cognition should instead be embodied in the same model, shifting from a decoupled VLA to an Embodied Vision-Language Model (eVLM). We introduce Concertina, an eVLM that places continuous trajectory representation, blockwise generation, and physical-coordinate supervision directly on the computation and parameter path of a shared diffusion VLM backbone. Each control timestep is encoded as one continuous latent action token in the backbone hidden space, and the shared Transformer reconstructs temporally ordered action blocks via the same corrupt-and-reconstruct operator used for multimodal pretraining. Active action projections account for only 0.21% of parameters in the 4.46B model with zero separate action-generator layers, compared with 16.5%-35.1% dedicated action-expert capacity in representative continuous VLAs. Using our proposed Action Interface Audit, we confirm that cross-time trajectory coupling emerges in the middle and late layers of the shared backbone rather than at the action interfaces. On standard benchmarks, Concertina achieves 98.15% average success on regular LIBERO, 85.9% on the 10,030-task LIBERO-Plus benchmark, and 4.142 average completed chain length on CALVIN ABC-D. # 论文总结：Concertina：在单一扩散式视觉-语言模型中融合操作与认知

## 1. 核心问题与整体含义

- **研究问题：**如何让预训练视觉-语言模型（VLM）直接生成精确的连续机器人动作，同时保留其原有架构、训练方式和视觉语言能力？
- 作者认为，现有视觉-语言-动作模型（VLA）常以两种方式把“认知”与“操作”分开：
  - **离散动作表示：**把动作量化为离散 token。token 预测错误与实际物理位移之间未必有稳定对应关系，近邻错误和远距离错误可能受到相同的分类惩罚。
  - **外部连续动作专家：**将轨迹生成交给独立模块。这样会造成动作计算与 VLM 主干分离，动作梯度可能与主干更新冲突，或被阻断而无法更新主干。
- 论文提出 **具身视觉-语言模型（eVLM）** 的思路：让感知、语言理解和动作轨迹生成由同一模型、同一主干网络及相互贯通的参数路径共同承载。
- **Concertina** 是该思路的具体实现：把连续动作置于共享扩散式 VLM 的隐空间中，以物理坐标直接监督，并复用多模态预训练已有的扰动—重建过程。

## 2. 方法论

### 2.1 连续潜在动作 token

- 对长度为 \(H\) 的轨迹，每个时间步的完整 \(D\) 维动作向量 \(a_i\) 经位置独立的动作编码器映射为一个连续潜在 token \(z_i\)：
  - 每个时间步对应**一个 token**，而不是把各动作维度拆成多个 token。
  - 位置独立的动作编码器和解码器只负责坐标映射，不负责跨时间建模；时间依赖由共享 Transformer 处理。
- 共享主干根据视觉、语言、本体状态及动作 token 的上下文计算动作隐状态，再由动作解码器还原到物理动作坐标。
- 动作重建损失直接作用于归一化后的物理坐标。论文还按坐标类型设置权重，重点补偿平移、旋转和夹爪坐标的尺度差异；夹爪闭合概率使用概率值二元交叉熵监督。

### 2.2 分块生成与 packed teacher forcing

- 将长度为 \(H\) 的轨迹切成大小为 \(K\) 的连续动作块：
  - **块间因果：**当前块依赖此前已完成的块。
  - **块内双向：**同一块中的动作一起建模、并行预测和协调。
- 训练时，将多模态条件、受扰动的动作序列和干净的教师强制动作序列打包进一次主干前向计算：
  - 受扰动分支负责预测当前块。
  - 干净分支为后续块提供教师强制上下文。
  - 通过注意力可见性规则避免当前块的目标泄漏。
- 论文采用按块分层抽取的扰动率，并对被选中重建的位置按扰动概率进行逆概率加权，使不同扰动程度下的监督得到平衡。

### 2.3 推理流程

1. 对指令、图像和状态进行编码，并缓存多模态前缀。
2. 按时间顺序逐块生成动作；当前动作块初始化为零向量哨兵。
3. 共享主干对块内动作进行并行预测，可按风险分数逐步提交候选动作。
4. 可选地对低置信度位置重新遮蔽并细化；完成的动作块重新编码后加入缓存，供后续块使用。

整个过程中不使用单独的动作 Transformer、扩散网络或动作 codec。论文报告，4.46B 参数模型中主动动作接口约占 **0.21%**，不含独立动作生成器层。

### 2.4 动作接口审计

论文提出三类诊断指标，用来检验动作表示、计算过程和参数容量是否与主干耦合：

- **EGC（Error-Geometry Consistency）：**测量训练接口中的单位错误对应的物理动作误差是否稳定。
- **TCA / NLR（轨迹耦合归因 / 非局部响应比）：**通过有限差分观察改变某个时间步的输入后，远处时间步的动作响应，并定位这种跨时间依赖出现在哪些层。
- **ASCR（动作专属容量比）：**测量专门用于动作生成的参数占模型容量的比例。

## 6. 主要结论与发现

- Concertina 在所测试 benchmark 上取得较强结果：LIBERO 平均 **98.15%**、LIBERO-Plus **85.9%**、CALVIN 平均链长 **4.142**。
- 块内双向建模和块间因果建模适合将短时动作片段作为整体生成；论文发现 \(K=10\) 的动作块优于更短分块，并将其与示范数据中的时间相关性联系起来。
- 物理坐标加权、状态遮蔽和多块继续预训练均对下游结果有明显影响。
- 动作接口本身不承担跨时间建模；论文通过有限差分审计发现，跨时间轨迹耦合主要形成于共享主干的中后层。
- 将互不兼容的动作坐标目标同时施加在共享隐空间上可能产生强烈梯度冲突。论文的反事实实验中，辅助绝对动作目标与主目标梯度的余弦相似度为负，并伴随 CALVIN 表现大幅下降。
- 作者据此主张：在共享模型中，动作表示、坐标监督和主干训练方式需要共同设计，而不能简单把多个动作目标或专家模块接入同一模型。

## 7. 优点

- **架构简洁、耦合路径清楚：**动作轨迹由共享主干生成，避免单独的大型动作专家。
- **保留物理误差含义：**连续动作直接在坐标空间监督，避免离散 token 分类损失难以反映物理误差距离的问题。
- **生成效率具有潜力：**一个动作时间步对应一个完整连续 token，且块内可以并行预测；论文报告的单次前向延迟较低。
- **机制分析比较深入：**不仅报告最终成功率，还设计了 EGC、NLR 和 ASCR 来分析误差几何、跨时间计算位置和专属参数容量。
- **消融维度较全面：**对块宽、坐标权重、状态遮蔽、损失目标、动作接口训练状态和执行视野等因素进行了对照。
- **覆盖多种评估目标：**除常规任务成功率外，还评估扰动鲁棒性、长链任务、离线重建和闭环重规划设置。
