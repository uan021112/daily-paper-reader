tldr: 三维场景分解需从整体输入中恢复对象网格，同时保持各物体空间布局与场景几何一致。传统方案逐对象在规范空间生成，再估计位姿和尺度拼接，容易造成布局不稳。CoLa3D从单张图像或现有场景网格提取共享场景潜变量，以查询式变换器直接分解出可重新组装的对象网格。实验显示，该方法在合成和真实数据上提升场景一致性与对象质量，速度约快两倍，训练数据不足SAM 3D的百分之一，并保留准确可见几何。

## 摘要
我们提出 CoLa3D，这是一种简单而有效的可组合 3D 场景分解模型。给定来自单张图像或现有场景网格的单个整体场景潜变量作为输入，该模型可直接输出一组空间布局一致的物体网格，并能将其重新组装为连贯的场景。CoLa3D 在共享的整体场景潜变量中实现 3D 场景分解，开创了一种新范式；不同于其他方法在规范空间中逐个生成物体，再通过脆弱的位姿与尺度估计将物体拼接起来，CoLa3D 可在紧凑的潜空间中学习将场景分解为多个物体。其网络是一种轻量、灵活且可扩展的基于查询的 Transformer，可接受多种类型的查询，包括 2D 掩码、3D 点和可学习查询。在合成数据集和真实世界数据集上，CoLa3D 在可组合 3D 场景分解方面均达到最先进水平，显著提升了全局场景级一致性和物体级质量，同时运行速度快 2 倍，训练数据量不足 SAM 3D 的 1%。其可见深度表现与 MoGe2 相当，进一步表明潜变量分解在生成物理完整、可分解的物体网格的同时，能够保留准确的可见场景几何结构。

## Abstract
We introduce CoLa3D, a simple and effective model for composable 3D scene decomposition that, given a single whole-scene latent from either a single image or an existing scene mesh as input, directly outputs a set of object meshes with consistent spatial layout that can be assembled back into a coherent scene. CoLa3D introduces a novel paradigm for 3D scene decomposition within a shared whole-scene latent, unlike alternatives that perform per-object generation in canonical spaces and then glue the objects back together with fragile pose and scale estimation. The network is a lightweight, flexible, and scalable query-based transformer that accepts various types of queries, including 2D masks, 3D points, and learnable queries, and learns to decompose the scene into objects in a compact latent space. On both synthetic and real-world datasets, CoLa3D achieves state-of-the-art performance on composable 3D scene decomposition, substantially improving global scene-level consistency and object-level quality while running 2 times faster and using less than 1% of SAM 3D's training data. Visible depth on par with MoGe2 further confirms that latent decomposition preserves accurate visible scene geometry while producing physically complete, decomposable object meshes.

# CoLa3D：可组合潜变量 3D 分解

## 1. 核心问题与整体含义

- **研究目标**：从单张图像或已有的整体场景网格中，恢复一组独立的物体网格，并使这些网格重新组合后仍能保持原场景的几何与空间布局。
- **研究动机**：许多现有方法先在各物体的规范坐标系中逐个生成，再估计物体的位姿和尺度、拼回整体场景。这个过程容易产生位置偏差、比例失准、物体互相穿插等问题。传统点云实例分割虽能区分对象，却常受噪声和几何不完整影响，而且通常只输出分割结果，不直接提供完整物体网格。
- **核心主张**：应当先获得整体场景的紧凑 3D 潜变量，再直接从这一共享潜变量中提取对象。由于各物体始终位于同一场景坐标系中，分解结果更容易保留整体空间关系，也更适合编辑、重排与物理仿真。

## 2. 方法论

### 核心流程

1. **获取整体场景潜变量**：
   - 输入可以是单张图像，也可以是已有的场景网格。
   - 使用 TRELLIS.2 的结构化 3D 潜空间表示场景；网格输入通过编码器得到潜变量，图像输入则先由图像条件生成模型产生场景潜变量。
   - 为增强语义辨别能力，将 Utonia 提取的 3D 语义特征映射至与几何潜变量相同的维度，并与几何特征相加。

2. **以查询式 Transformer 分解场景**：
   - 查询可以是**2D 物体掩码**、**3D 点**或**可学习查询**。
   - 掩码查询编码掩码外观及其中心位置；点查询结合点的空间位置与对应潜变量特征；可学习查询则提供一组固定容量的对象槽位。
   - Transformer 通过查询间自注意力、与冻结 DINOv3 图像特征的交叉注意力，以及查询与场景潜变量之间交替进行的双向交叉注意力，逐步形成对象级表示。3D RoPE 用于提供空间位置信息。

3. **预测对象归属并解码网格**：
   - 对每个潜变量单元与每个查询计算归属概率，具体是将两者投影到共同特征空间后，计算温度缩放的余弦相似度，再经过 Sigmoid 得到软归属分数。
   - 由于潜变量网格较粗、接触区域可能由多个物体共享，模型采用**多热分配**，允许一个潜变量单元同时关联多个对象；推理时再阈值化，必要时用 argmax 补上未归属单元。
   - 按对象归属从原场景潜变量中提取各对象潜变量，并通过共享的 TRELLIS.2 解码器并行生成物体网格。由于对象潜变量保留原场景坐标，通常无需再单独回归物体位姿或进行后处理配准。

### 训练与推理细节

- 训练目标由潜变量空间的掩码损失和查询多样性正则项构成：掩码损失结合 BCE 与 Dice；多样性项惩罚查询之间过高的余弦相似度，以减少多个查询重复解释同一对象、遗漏其他对象的情况。
- 可学习查询模式下，论文采用匈牙利匹配完成预测与真实对象的对应；掩码和点提示模式则直接利用提示与对象的对应关系。
- 对可学习查询的推理结果，还会进行冗余查询合并和连通域清理，以抑制重复对象及零散噪声。

- CoLa3D 的核心结果是：**在共享整体场景潜变量中直接分解对象**，能够改善物体网格与场景布局的一致性，避免逐对象生成后再拼接所带来的部分空间错位。
- 在 3D-FRONT、MetaScenes、Replica、ScanNet++ 和 MetaScenes-hard 的实验中，CoLa3D 多个设置在场景级指标上表现突出；部分对象级指标则由不同查询设置分别取得最佳表现，说明查询方式会影响场景质量与单体质量之间的取舍。
- 作者报告其推理速度约为部分强基线的两倍，并声称在显著少于 SAM 3D 的训练数据规模下取得较好结果。
- 在深度与互穿评估中，CoLa3D 展现出较强的可见几何保持能力和较低的物体互穿倾向，但不同数据集、指标和查询模式下排名并非处处领先。

## 7. 优点

- **建模思路直接**：从整体场景潜变量抽取对象，而不是分别生成再拼接，针对性地处理布局不一致问题。
- **共享坐标系带来结构优势**：对象几何与相对位置在同一场景表示中建立联系，适合输出可重新组合的场景资产。
- **查询形式灵活**：同时支持掩码、点和无显式提示的可学习查询，覆盖交互式与自动分解场景。
- **推理流程简洁**：Transformer 在单次前向过程中完成潜变量分解，各对象再由共享解码器并行解码；相较依赖多对象扩散或逐场景优化的方案，具有速度优势。
- **评估角度较全面**：除了网格几何，还评估场景一致性、物体互穿、可见深度、扩展到密集场景的能力，并提供消融实验。
- **下游潜力明确**：对象级网格可用于场景编辑、重排和物理仿真，论文还展示了对已有场景网格的分解路径。

## 8. 不足与局限

- **潜变量分辨率限制**：论文明确指出，粗粒度潜变量网格可能把细薄物体或紧密接触的多个对象混在同一单元中；多热标签能缓解但不能根本消除这一问题。
- **物体数量与场景复杂度受限**：默认可学习查询上限为 8；扩展实验将其提高到 20，但训练和测试仍集中于室内场景，不能据此推断对任意复杂场景均可扩展。
- **对基础模型与语义特征有依赖**：方法依赖 TRELLIS.2、Utonia 和 DINOv3 等组件；图像输入时还需生成场景潜变量，并为提取 3D 语义特征解码代理网格，实际系统的完整计算成本不只由分解 Transformer 决定。
- **单张图像的固有不确定性仍在**：输入无法直接观测被遮挡部分，生成结果依赖模型先验；文中的“物理完整”并不等于所有不可见几何都能被可靠恢复。
- **数据覆盖与外推有限**：训练主要基于 3D-FRONT，重点是室内家具场景；作者也指出场景数据在规模、质量和对象密度方面仍是瓶颈。对室外场景、长尾类别、不同文化和建筑风格的泛化尚需进一步验证。
- **评测结果需谨慎解读**：真实场景集较小且经过质量筛选；部分指标在对齐后计算，提示式变体使用了较强先验；又缺少跨种子统计和显著性报告。因此，“领先”更适合限定为论文所采用的数据集、筛选规则和评测协议。
- **资源披露不完整**：虽报告了 CoLa3D 主训练的 GPU 数量和时长，但 TRELLIS.2 场景级微调的资源、完整模型端到端成本及不同组件的耗时分解未充分说明。
