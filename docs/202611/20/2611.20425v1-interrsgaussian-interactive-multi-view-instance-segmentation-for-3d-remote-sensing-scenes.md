## 摘要
遥感图像分割在众多应用中发挥着关键作用。交互式实例分割是图像分割中的一项专门任务，旨在根据用户输入的提示，为目标对象生成精确的分割结果。然而，既有交互式实例分割研究主要聚焦于单视角图像，限制了其对复杂三维遥感场景的全面理解。本研究将交互式实例分割从单视角扩展至多视角框架，并可轻松转换为三维分割格式，从而实现跨多个视角对三维遥感场景更准确、全面的感知。首先，我们构建了一个遥感多视角交互式实例分割数据集，包含五个不同场景，每个场景均由约一百个不同视角拍摄。其次，我们提出了一种基于三维高斯的新型实例分割方法 InterRSGaussian。用户可以在任意视角下对目标对象进行点选，InterRSGaussian 无需人工标注，即可在所有输入视角中生成视角一致的实例分割结果。随后，还可将多视角分割结果投影至三维点云，以实现三维分割。为提升训练效率和分割性能，我们引入了一种用于初始化的先验蒸馏网络。总体而言，本研究将传统的二维遥感场景感知扩展至三维多视角框架，使用户能够通过交互，在复杂环境中更全面地理解目标对象。

## Abstract
Remote sensing image segmentation plays a critical role in various applications. Interactive instance segmentation, a specialized task within image segmentation, aims to generate precise segmentation results for target objects based on user input prompts. However, previous studies on interactive instance segmentation primarily focus on single-view images, limiting their ability to comprehensively understand complex 3D remote sensing scenes. In this study, we extend interactive instance segmentation from a single-view to a multi-view framework, which can also be easily converted to a 3D segmentation format, thus achieving more accurate and comprehensive 3D remote sensing scene perception across multiple views. First, we construct a multi-view interactive instance segmentation dataset for remote sensing, comprising five distinct scenes, each captured from about one hundred different views. Second, we propose InterRSGaussian, a novel instance segmentation method based on 3D Gaussians. InterRSGaussian enables users to provide point clicks on target objects from any arbitrary view and generates view-consistent instance segmentation results across all input views without requiring manual annotations. The resulting multi-view segmentation can further be projected onto 3D point clouds for 3D segmentation. To improve training efficiency and segmentation performance, we introduce a prior distillation network for initialization. Overall, this study extends traditional 2D remote sensing scene perception into a 3D multi-view framework, enabling a more comprehensive understanding of target objects in complex environments with user interactivity.
