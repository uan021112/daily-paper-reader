A B S T R A C T
Remote sensing image segmentation plays a critical role in various applications. Interactive instance
segmentation, a specialized task within image segmentation, aims to generate precise segmentation
results for target objects based on user input prompts. However, previous studies on interactive
instance segmentation primarily focus on single-view images, limiting their ability to comprehen-
sively understand complex 3D remote sensing scenes. In this study, we extend interactive instance
segmentation from a single-view to a multi-view framework, which can also be easily converted to a
3D segmentation format, thus achieving more accurate and comprehensive 3D remote sensing scene
perception across multiple views. First, we construct a multi-view interactive instance segmentation
dataset for remote sensing, comprising five distinct scenes, each captured from about one hundred
different views. Second, we propose InterRSGaussian, a novel instance segmentation method based
on 3D Gaussians. InterRSGaussian enables users to provide point clicks on target objects from
any arbitrary view and generates view-consistent instance segmentation results across all input
views without requiring manual annotations. The resulting multi-view segmentation can further be
projected onto 3D point clouds for 3D segmentation. To improve training efficiency and segmentation
performance, we introduce a prior distillation network for initialization. Overall, this study extends
traditional 2D remote sensing scene perception into a 3D multi-view framework, enabling a more
comprehensive understanding of target objects in complex environments with user interactivity.
1. Introduction
Remote sensing image segmentation [16, 43, 18, 36] is
a fundamental perception task in remote sensing image pro-
cessing. It assigns a category label to each pixel in the input
image, enabling the extraction of critical information such as
object location, boundaries, and spatial distribution. Image
segmentation tasks can be broadly classified into semantic
segmentation [7, 19, 1] and instance segmentation [33, 13,
39]. Semantic segmentation assigns a semantic label to each
pixel, grouping regions with the same category. Further-
more, instance segmentation not only differentiates between
semantic categories but also identifies and distinguishes
individual objects within the same category, assigning each
instance a unique identify ID. This distinction makes in-
stance segmentation particularly valuable for applications
such as object detection [2, 26], object counting [5], and
scene understanding [9], where precise object delineation is
crucial for accurate analysis and decision-making.
Interactive instance segmentation builds upon traditional
instance segmentation by incorporating user prompts—such
as point clicks, bounding boxes, or text descriptions—to
guide the segmentation process. This user-driven paradigm
enables more precise and flexible object extraction while
enhancing user control through selective perception and
analysis of objects of interest. Furthermore, segmentation
results can be dynamically refined in real time based on

With the rapid advancement of 3D scene reconstruction

scene perception into a 3D multi-view framework that can
be easily converted to other 3D formats, such as point cloud

understanding of objects and complex environments.

Beyond perception outcomes, view consistency is also criti-

To ensure view consistency in segmentation results,
this study extracts 3D spatial representations from input
multi-view remote sensing images. Various 3D spatial rep-
resentations have been employed for modeling 3D remote
sensing scenes, including point clouds [47, 12, 23], TSDFs
(Truncated Signed Distance Fields)[31, 10], latent neural
representations[25, 32], and 3D Gaussians [14, 3, 11], all of
which have become prominent research directions. Among
these, 3D Gaussians offer an effective balance between
accuracy and efficiency. Accordingly, this study adopts 3D
Gaussians as the core 3D spatial representation for 3D re-
mote sensing scenes and proposes a novel method for multi-
view instance segmentation based on this representation.
In particular, the method aims to eliminate the need for
manual annotations during training or optimization, thereby
significantly reducing labor costs and improving practical
scalability.
To achieve segmentation without manual labeling, this
study leverages the prior knowledge embedded in foundation
models [15, 46]. Foundation models have garnered signif-
icant attention in artificial intelligence, particularly within
deep learning, due to their ability to generalize across tasks.
Typically, a foundation model is pre-trained on large-scale
datasets [6, 22], and through extensive exposure to diverse
data, it develops robust, general-purpose feature extraction
capabilities. This adaptability enables these models to be
effectively applied to a wide range of downstream tasks
without requiring task-specific training from scratch. For
instance, models from the SAM series [15, 45, 48, 44]
can automatically or interactively segment a wide variety
of scenes, producing 2D segmentation results that demon-
strate strong generalization ability. Similarly, models from
the DINO series [46, 17] exhibit universal visual feature
extraction capabilities, efficiently learning useful visual rep-
resentations through unsupervised learning, which makes
them highly versatile for various downstream applications.
The large model priors not only provide high-quality initial
segmentation but also offer robust visual features for initial-
ization.
Overall, this study focuses on the task of interactive im-
age segmentation, which holds significant value, and extends
traditional 2D perception to multi-view stereo perception. A
novel method for multi-view interactive instance segmenta-
tion in remote sensing is proposed, incorporating 3D spa-
tial information representations of the scene and leveraging
foundational model priors to enable segmentation without
the need for manual labels. Furthermore, this study explores
the use of foundation model priors as initialization to ac-
celerate training/optimization convergence and improve seg-
mentation performance. Additionally, an interactive multi-
view instance segmentation dataset specifically designed for
3D remote sensing scenes is constructed.
2. Material

generated from varying heights and viewpoints. The real-
world data collection is conducted using the Google Maps
platform and is intended solely for academic research. First,
we select the target scene and adjust the pixel resolution to
ensure clear image details. Then, we utilize the 3D view
mode of Google Maps, enabling free rotation to observe the
target area from multiple perspectives. Using the perspective
rotation and screen recording functions provided by Google

3. Method
This study proposes an multi-view instance segmenta-
tion method based on 3D Gaussians, termed InterRSGaus-
sian. InterRSGaussian leverages pre-reconstructed 3D Gaus-
sians or reconstructs the 3D spatial representation of the
input multi-view images, providing a structured foundation
for instance segmentation across different views. InterRS-
Gaussian enables users to prompt target objects using point
clicks in arbitrary view image and subsequently generates
multi-view instance segmentation results for each view. The
proposed method integrates 3D Gaussians for 3D spatial rep-
resentation extraction, identity feature learning and pseudo-
label generation for transferring 2D prompts into multi-
view segmentation, DINO distillation for initialization to
accelerate training convergence. The overview of the method
is shown in Figure 3.

4. Results
Our experiments were performed on a platform featuring
an RTX 3090 GPU and an Intel Core i9 CPU, utilizing
the constructed dataset. We also analyze the runtime per-
formance on this platform. The average total runtime for
segmenting objects across 100 views is 760 s. In addition to
the GPU usage of the SAM and DINO networks, the spatial
representation extraction and identity feature optimization
for 3D Gaussian require an average additional 10–12 GB of
GPU memory. In the training process, for 3D spatial repre-
sentation extraction, positions follow an exponential decay
learning rate, while colors, scaling, rotation, and opacity use
constant rates. The default learning rate is set to 1e-5. For
identity feature learning, semantic features are initialized
from 2D DINO features and optimized at a learning rate of
1e-5 with exponential decay, while all other parameters are
frozen. The distillation network is initialized using Kaiming
initialization and optimized with a learning rate of 1e-5. The

Although SAM cannot handle every view perfectly and
struggles with occlusions and sudden appearances of objects
in some views, it still provides high-quality pseudo labels in
most views. Based on these pseudo-labels, Gaussian Group-
ing and our method produce higher-quality results. By using
the 3D spatial representation of 3D Gaussians, the optimiza-
tion of the identity feature of each point is informed by valid
pseudo label information from all views. Therefore, even if
the pseudo label quality of SAM is low in some views, it can
be compensated by other high-quality views.

method, we show the results of two optimization scenarios.
One involves optimizing 1k times, and the other involves

The results show that with the same number of opti-
mizations, the method proposed in this study outperforms
Gaussian Grouping in all scenes. Especially in sys #3, under
the optimization setting of 1k, our method outperforms
Gaussian Grouping by more than 5 percentage points. The
main reason is that sys #3 contains large-scale objects and
occlusions between objects, leading to low-quality pseudo-

DINO distillation prior, and the initialized identity features
themselves have the ability to distinguish between objects,
allowing it to better handle low-quality pseudo-labels.
By comparing the results of different optimization itera-
tions, we found that the benefit of increasing the number of
optimizations is not obvious (This will be further discussed
in Sec. 5). This is reflected in both Gaussian Grouping
and the proposed method. For example, in sys #1, more
optimizations only provide a 0.17 improvement for Gaus-
sian Grouping, which has decreased in most scenarios for
the proposed method. However, increasing the number of
optimizations will greatly increase the training/optimization
time. Therefore, under the setting of 1k training/optimization
times, the proposed method achieves the best results with
less training time.
4.2. Qualitative results
We show the qualitative results of the proposed method
in Figure 4 with randomly selected 10 views for each scene.
First, we can observe that the segmentation of prompt
objects for all scenes is strongly consistent across views.
This is due to the unified identity representation in 3D spatial
form within 3D Gaussians.
Second, we can observe that the segmentation results
of sys #1 and #2 are the most complete and accurate. This
is mainly because the prompt objects in these two scenes
are not blocked and do not disappear or appear from certain
views, so the pseudo-label quality of SAM is relatively high.
In contrast, the green prompt building in real #2 disappears
from certain views, resulting in a decrease in the pseudo-
label quality of SAM. Therefore, using this as supervision
leads to a decrease in segmentation quality.
Finally, the segmentation of objects of different sizes is
compared, and it is found that the proposed method has better
performance for small and medium-sized objects. This is
because large objects require more and denser prompts, and
the 5 prompt points set in this study cannot guarantee that the
edges of large objects can be correctly segmented by SAM in
every view. For example, the segmentation accuracy of the
edges of the buildings in sys #3 and the bridges in real #1 is
relatively poor.
Additionally, we discuss other output formats of our
method. In addition to the multi-view segmentation format,
we can directly input the identity features of each point in the
3D Gaussians into the decoder to obtain the segmentation.
This process outputs the segmentation results in point cloud
format, as shown in the right part of Figure 4. Since ground
truth for point cloud segmentation is unavailable, we cannot
perform a quantitative analysis of these results. However, the
qualitative results are highly promising. The segmentation
results in point cloud format enable us to further analyze the
3D spatial distribution of each prompt object. The results
with this format can be particularly valuable in several appli-
cations, such as environmental monitoring, urban planning
and development, geospatial data analysis, and more.

5.1. Comparison with Related Methods
Most 3D Gaussian Splatting studies summarized in [37]
focus on reconstruction, editing, and related downstream
applications. InterRSGaussian extends this representation
to interactive instance segmentation by associating identity
features with 3D Gaussians in remote sensing. The unified
3D representation enables consistent in segmentation results
across views.
The method in [40] suggests informative views and
requires users to draw strokes in multiple views. In contrast,
InterRSGaussian requires only point prompts in a single
view and automatically propagates the results to other views,
providing a more convenient interaction process. However,
it does not explicitly select the optimal view and may be
sensitive to occlusion or depth errors in the selected view.
The methods in [34, 35] perform supervised instance
segmentation directly on 3D point clouds by exploiting
semantic and geometric cues. Although they provide ex-
plicit 3D reasoning, they require semantic and instance
annotations for training. InterRSGaussian instead uses SAM
pseudo-labels and DINO features, reducing annotation costs
while supporting category-independent selection of user-
specified objects. However, it does not explicitly model part
hierarchies or jointly reason about geometry and semantics,
and remains sensitive to pseudo-label noise.
6. Limitation
We acknowledge several limitations. First, directly ap-
plying general-purpose foundation models to remote sens-
ing images may be suboptimal because of domain gaps.
Parameter-efficient fine-tuning (PEFT) methods, such as
adapters, prompt tuning, and low-rank adaptation, could
improve the SAM pseudo-labels and DINO initialization
features with limited trainable parameters [42]. We will
leave PEFT-based adaptation for future work. Second, rely-
ing on SAM-generated pseudo-labels introduces noise, and
handling extremely thin or ambiguous boundaries remains
challenging. To address this issue, we plan to develop an
end-to-end framework that jointly optimizes 3D structure,
color, and identity features. Third, the number of scenes in
our dataset is limited, although we have ensured coverage
of major urban object types with diverse sizes and textures.
We will continue expanding the dataset to strengthen our
findings.
7. Conclusion
This study extends interactive instance segmentation
from the conventional single-view setting to a multi-view
setting. The proposed InterRSGaussian utilizes 3D Gaussian
to generate view-consistent segmentation results from user-
provided point prompts. We also construct a multi-view
interactive instance segmentation dataset containing five 3D
scenes, each captured from approximately 100 views. To
accelerate convergence and improve segmentation perfor-
mance, we introduce a prior distillation network to initialize
the identity features. Experimental results demonstrate the
