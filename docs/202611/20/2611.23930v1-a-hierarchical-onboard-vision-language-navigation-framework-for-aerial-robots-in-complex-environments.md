## 摘要
无人机（UAV）需要在严格的机载资源限制下实现语义推理、智能决策和长时程导航。近年来，基于基础模型的方法在实现这一目标方面取得了令人瞩目的进展，但在复杂环境中，现有方法仍受到三维数据可用性、轨迹可行性、长时程推理和计算效率等方面的限制。为弥补这些不足，我们提出面向空中机器人的分层视觉-语言-导航（VLN）框架 VLN-AR。VLN-AR 将多模态推理与底层控制解耦，从而能够结构化地预测三维位姿指令和导航意图，并将其转化为动态可行的动作。为缓解数据匮乏和领域差异问题，我们提出了一套基于三维高斯泼溅（3DGS）的全自动流程，用于生成可扩展的、具有照片级真实感的无人机导航数据。此外，渐进式三阶段训练策略进一步提升了模型的落地能力、场景推理能力和复杂导航能力。我们还设计了一种轻量级认知智能体，通过具备记忆意识的任务分解增强长时程推理能力。最后，我们提出了多种机载优化技术，包括 token 稀疏化和模型轻量化，在保持资源受限无人机平台上高导航性能的同时，实现了 7.1–9.4 倍的加速。实验结果表明，与现有方法相比，该方法在仿真和真实世界无人机导航任务中均取得了显著提升。项目网站：https://wyz000.github.io/VLN-AR/

## Abstract
Unmanned Aerial Vehicles (UAVs) are expected to achieve semantic reasoning, intelligent decision-making, and long-horizon navigation under strict onboard constraints. While recent foundation-model-driven approaches have shown promising progress toward this goal, existing methods remain limited by challenges in 3D data availability, trajectory feasibility, long-horizon reasoning, and computational efficiency in complex environments. To bridge these gaps, we propose VLN-AR, a hierarchical vision-language-navigation (VLN) framework for aerial robots. VLN-AR decouples multimodal reasoning and low-level control, enabling structured prediction of 3D pose commands and navigation intentions that are translated into dynamically feasible actions. To mitigate data scarcity and domain gaps, we introduce a fully automated 3D Gaussian Splatting (3DGS)-based pipeline to generate scalable photorealistic UAV navigation data. A progressive three-stage training strategy further enhances grounding, scene reasoning, and complex navigation. In addition, a lightweight cognitive agent improves long-horizon reasoning via memory-aware task decomposition. Finally, we design onboard optimization techniques, including token sparsification and model lightweighting, achieving 7.1x-9.4x speedup while maintaining high navigation performance on resource-limited UAV platforms. Experiments show great improvements over existing methods in both simulation and real-world UAV navigation. Project website: https://wyz000.github.io/VLN-AR/

## 1. 核心问题与整体含义

- **研究问题**：无人机如何在机载算力受限、环境复杂且部分可观测的情况下，理解自然语言指令、进行空间推理，并安全完成多步骤导航。
- **研究背景**：传统无人机导航通常依赖预设模块和规则，难以理解开放词汇指令；端到端视觉语言模型则可能难以生成满足无人机动力学约束的动作，且普遍面临三维训练数据不足、长程任务推理弱、机载推理成本高等问题。
- **整体思路**：论文提出 **VLN-AR**，把高层多模态理解与低层飞行控制分开：视觉语言模型负责判断“要去哪里、为什么、是否完成或需要重规划”，动作专家负责生成安全、动态可行的飞行轨迹。论文同时构建自动化仿真数据管线、渐进训练方法和机载加速方案，形成从数据、训练到部署的完整导航框架。

## 2. 方法论

### 2.1 分层导航架构

- 输入为自然语言指令和当前及历史视觉观测。
- 高层视觉语言模型基于多帧观测输出五类信息：
  - **三维位姿指令**：目标位置及偏航角；
  - **二维边界框**：在图像中定位目标；
  - **推理文本**：说明导航意图或搜索依据；
  - **任务完成标记**：判断当前子任务是否结束；
  - **重规划标记**：判断当前视野是否足以支持下一步导航。
- 低层采用基于 Ego-Planner 改进的、无需学习的动作专家，将高层输出转化为避障且符合动力学约束的轨迹。论文称其控制频率超过 **200 Hz**。
- 目标表征按任务类型灵活选用：可见物体可使用边界框结合深度估计位置；空间关系任务（如“从树的左侧绕过”）则直接预测三维位姿；目标不可见时利用历史观测和推理结果进行探索。

### 2.2 3DGS 自动化数据生成

- 使用 **3D 高斯泼溅（3DGS）**重建室内外场景，并导入 Unity 仿真环境；结合场景理解工具获取物体标签、三维框、场景结构等信息。
- 在可通行区域随机采样起点和目标点，通过考虑避障、飞行高度、动力学可行性和平滑度的轨迹规划器生成飞行轨迹。
- 仿真无人机沿轨迹飞行，同步采集 RGB、深度、点云、位姿等数据；再利用模板或视觉语言模型扩展指令表达，并筛选轨迹和标注。
- 作者报告训练数据约 **400 万条**，涵盖导航、VQA、空间问答、目标定位和推理等类型。数据管线还混入少量真实无人机数据以改善现实适应性。

### 2.3 三阶段训练

1. **落地与推理增强 SFT**：使用问答、目标定位、空间推理等混合数据，训练视觉理解、跨模态定位和推理能力。
2. **导航专项 SFT**：使用无人机导航轨迹及空间推理数据，训练位姿预测、任务完成判断和重规划行为。
3. **面向推理导航的强化微调**：将视觉语言模型与动作专家放入闭环仿真，以 **GRPO** 优化导航表现。奖励主要依据任务是否成功，并针对多阶段任务累积阶段奖励；对组内奖励无差异的样本组予以丢弃，以避免相对优势失效。

### 2.4 认知智能体与记忆机制

- 将复杂指令拆分为连续子任务，逐项判断完成状态并推进任务队列。
- 维护动态多模态记忆，包括历史指令、轨迹、关键画面和任务状态，以缓解遮挡或相似场景导致的状态混淆。
- 当常规搜索无效时，执行主动感知（例如旋转观察）；仍未发现目标时，再利用历史记忆和推理生成探索方向，或判断当前子任务不可达。

### 2.5 机载视觉 token 稀疏化与系统优化

- 历史帧以 0.5 秒间隔采样，共 8 帧、覆盖约 4 秒；历史帧降采样，当前帧保留较高分辨率。
- 根据指令文本与视觉 token 的跨模态相似度筛选视觉 token，在 ViT 的多个中间层逐步压缩；最终保留约 **25%** token。
- 配合注意力和算子优化、Flash-Attention、FFN 与归一化融合、KV-cache 预加载、CUDA Graph 及低精度量化等方法降低推理耗时和内存开销。

## 3. 实验设计

### 3.1 数据集与场景

- **公开仿真基准**：AerialVLN、OpenFly。作者称这两个数据集未用于训练。
- **自建室内 3DGS 仿真集**：约 **1 万条导航样本**，覆盖办公室、家庭、商场、影院等场景；测试场景称为训练未见。
- **真实无人机测试**：在多种室内外环境进行 101 个案例的测试，包括家庭、办公、物流设施、户外公园和商业区域等。
- **鲁棒性测试**：悬浮物体与不连续结构、超过 5 米的高度变化、暗光、动态障碍干扰、未见场景零样本部署等。

### 3.2 Benchmark 与指标

- 主要指标包括：
  - **成功率（SR）**：无碰撞且到达目标阈值内的任务比例；多子任务任务要求全部子任务成功。
  - **导航误差（NE）**：最终位置与目标位置的平均欧氏距离。
  - **轨迹时间（TT）**：完成导航任务所需时间。
- 文中还评估不同任务类型的成功率，如物体导航、空间推理、精确导航、长程导航和场景理解。

### 3.3 对比方法

论文比较了多类方法，包括：

- **端到端 VLN**：OpenUAV、AerialVLN、OpenFly、UAV-Flow；
- **MLLM 导航智能体**：CityNavAgent、SPF、Fly0；
- **端到端 VLA**：OpenVLA、π0、GR00T N1.5；
- **零样本多模态模型**：Qwen3-VL-4B、ChatGPT 5.2、Gemini 3 Pro；
- **先前分层方法**：VLA-AN。

在 AerialVLN、OpenFly 和自建仿真集上，VLN-AR 的成功率分别为 **78.15%、76.88%、92.66%**；真实测试报告 **91/101（90.1%）** 成功率。

## 4. 资源与算力

- **机载平台**：NVIDIA Jetson Orin NX；文中称计算模块约重 **80 g**，算力约 **100 TOPS**。另在 Jetson AGX Thor 上测试了优化迁移。
- **机载推理结果**：4B-AWQ 模型约 946.7 GFLOPs，解码速度为 0.062 秒/token；2B 和 7B 模型分别为 0.032 和 0.110 秒/token。相对基线加速约 **7.1–9.4 倍**。
- 论文另报告整体推理时间由约 4100 ms 降至 494 ms，约 **8.3 倍**加速。
- **未明确报告**：训练所用 GPU 型号和数量、训练总时长、各阶段训练耗时与能耗等，因此无法从文中评估训练成本与复现所需算力。

## 5. 实验数量与充分性、公平性

### 5.1 实验覆盖概况

按论文报告，可归纳为多组互补实验：

- **3 个仿真基准**上的主结果及多类方法比较；
- **101 个真实世界任务**；
- **5 类鲁棒性测试**，每类 20 次，共 100 次测试；
- 多组消融实验，包括不同数据来源、三阶段训练、token 保留率、认知智能体和机载推理优化；
- 对 **976 个仿真长程导航回合**进行人工检查，分析任务完成标记错误。

总体上，实验不仅评估导航成功率，也覆盖推理、长程任务、实际部署和推理效率，覆盖面较广。

### 5.2 充分性与公平性判断

- **有利之处**：包含公开数据集、自建未见场景、真实飞行和组件消融；多个对比方法采用相同动作专家或统一输入输出格式，有助于减少控制器差异对比较的影响。
- **需要谨慎之处**：
  - 自建数据集和部分真实测试由作者构建，任务定义、成功阈值和标注质量可能影响结果；文中虽说明测试集与训练场景分离，但未提供足够细节供独立核验。
  - 不同基线的训练数据、模型规模、调参预算和运行条件未必完全等同，尤其是零样本 API 模型与经过专门训练的方法，横向比较存在天然限制。
  - 多项主要结果以成功率为主，缺少置信区间、显著性检验和更细致的失败类别统计；真实测试 101 例、每类鲁棒性测试 20 例的规模仍有限。
  - 数据自动生成及指令改写可能引入标注偏差；轨迹筛选规则（例如终点误差阈值）也可能改变训练样本分布。
- 因此，实验能够支持“该系统在所测设置下表现较强”的结论，但对更广泛环境、长期运行和不同硬件平台的普适性仍需更多独立验证。

## 6. 主要结论与发现

- 分层设计有助于兼顾语言语义理解、三维目标表达和安全轨迹执行；相比直接从图像生成低层动作，结构化位姿预测更便于利用成熟的飞行规划器。
- 3DGS 自动数据生成结合多样化问答、定位和推理数据，有助于缓解数据不足，并提升空间理解与长程导航表现。
- 三阶段训练各有侧重：第一阶段提升场景理解和空间推理，第二阶段改善精确及长程导航，第三阶段进一步增强闭环推理与导航协调。
- 认知智能体对长程任务帮助尤其明显：论文中长程导航成功率从去除智能体时的 **57.4%** 提高到 **88.0%**。
- 指令引导的视觉 token 压缩在约 25% token 保留率时，论文报告目标 token 召回率约 **92.5%**、导航成功率约 **91.7%**，说明在其测试条件下能减少计算而较好保留任务相关视觉信息。
- 在 Orin NX 上通过 token 稀疏化和系统优化实现显著推理加速；仿真、真实飞行及鲁棒性测试均显示较强表现，但并不意味着已解决小目标、模糊视觉和歧义指令等问题。

## 7. 优点

- **系统性强**：从自动数据构建、模型训练、任务记忆到机载部署形成较完整的技术链路。
- **接口设计合理**：高层语义推理输出结构化位姿或图像目标，低层规划器负责动力学可行性和避障，减少端到端模型直接控制带来的不稳定风险。
- **长程任务机制明确**：通过任务拆分、记忆融合、完成检测和主动探索处理部分可观测环境。
- **数据管线具有扩展性**：3DGS 场景重建与仿真轨迹采集减少纯真实数据采集成本，并提供丰富视觉细节。
- **部署考虑较充分**：不仅报告模型结果，也评估 ViT、解码和系统执行优化，并在实际无人机上进行机载测试。
- **消融相对全面**：尝试分别验证数据类型、训练阶段、智能体和 token 稀疏化的作用。

## 8. 不足与局限

- **算力与复现信息不完整**：没有披露训练硬件、训练时长、能耗等关键成本；部分系统优化和数据处理细节也可能影响复现。
- **空间定位仍是主要瓶颈**：作者指出小目标、远距离结构以及二维图像到三维坐标的映射误差会导致目标点偏移；真实测试中也有难以识别小物体和精确理解序数描述的失败案例。
- **对图像质量和指令清晰度敏感**：运动模糊、低照度、相似物体和歧义描述均可能造成错误定位或导航偏差。
- **长程任务完成判断仍有误差**：作者检查的 976 个仿真长程回合中，约 1.3% 存在完成标记错误，主要是提前终止或未能及时切换子任务。
- **安全性证据仍有限**：论文强调动作专家提供避障保护，但测试次数和场景范围不足以证明在所有动态环境中的安全性；“无碰撞”结果也不能替代系统性的安全边界或风险分析。
- **实验独立性有限**：自建场景、自动生成指令和评测协议均由论文团队设计；缺少独立团队复现、统计显著性分析及更大规模长期运行测试。
- **未来扩展仍有空间**：当前视觉语言模型决策频率约 2 Hz，虽然低层动作专家频率超过 200 Hz，但高层频率仍可能限制快速动态场景中的响应；论文也将多模态感知、因果时间推理和更高端到端频率列为未来方向。
