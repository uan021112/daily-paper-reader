# Abstract 

To advance the development of embodied general naviga-tion, zero-shot open-vocabulary multi-object navigation has attracted increasing attention, aiming to enable robots to efficiently search multiple objects in unseen environments without training. For this task, the key lies in improving navigation policies from earlier searches to locate subsequent goals more efficiently. Recent methods automate this process through trajectory reflection and rule revision, enabling policy self-improvement. However, the mechanisms for diagnosing problems and generating revisions are typically designed by humans and remain fixed across iterations. Consequently, the system’s capacity for continued self-improvement re-mains constrained, even as its navigation policy evolves. To this end, we propose RPSI-Nav , a Recursive Policy 

Self-Improvement framework for zero-shot multi-object nav-igation that revises both the navigation program and its revision mechanism. RPSI-Nav diagnoses search behavior, requests diagnostic views when existing observations cannot distinguish competing causes, and generates targeted navi-gation revisions. Feedback from subsequent goal searches is linked to the rules that produced these revisions, guiding changes to diagnosis, observation acquisition, and revision planning. The updated improver governs subsequent nav-igation improvements, forming a recursive loop in which RPSI-Nav revises its own improvement process. Across goals, the robot conditionally inherits accepted program updates and spatial memory, enabling search experience to improve both future navigation and adaptation. Benchmark experiments and qualitative real-robot evaluations validate RPSI-Nav’s effectiveness.

# 1 Introduction 

Zero-Shot Object Navigation (ZSON) is a challenging task in Embodied AI, requiring an agent to navigate to target objects in unfamiliar environments without training. Unlike conventional object navigation methods that focus on a single target, we consider zero-shot open-vocabulary multi-object navigation, where a robot must search for and locate multiple language-specified targets in succession within the same environment [1, 19]. In this setting, agents can use experience from earlier searches to refine their navigation strategies and locate subsequent goals more efficiently. When agents autonomously reflect on past searches and revise their decision rules, this process constitutes policy self-improvement. Related work [2, 15, 28] explores such self-improvement across navigation settings. However, their updates primarily concern navigation rules or decision guidance, while the procedures that generate these updates remain predefined. In multi-object navigation, subsequent searches can reveal whether earlier revisions resolved their intended problems. However, the observations needed to explain an ineffective revision may not yet be available, and acquiring them consumes the same movement budget as navigation. Later searches can therefore expose omissions in the diagnostic checks or observation requests that guided earlier repairs. If this feedback only triggers further policy updates, the rules producing these omissions may remain unchanged, even as the navigation policy evolves. Its improvement program diag-noses search problems, gathers observations that distinguish competing explanations, and generates targeted revisions to the navigation program. # 2 Related Work 

Open-vocabulary and multi-object navigation. Zero-shot object navigation uses pretrained models for seman-tic grounding, commonsense reasoning, and relational search [4, 38, 40, 46]. OpenFMNav interprets free-form requests [11], while VoroNav combines topology and seman-tics for exploration [35]. MultiON studies semantic memory over object sequences [34]; OneMap and WTRP-Searcher support zero-shot multi-object search through persistent map-ping and global planning [1, 19]. GOAT-Bench evaluates multimodal lifelong navigation, and 3D-Mem builds reusable scene memory for exploration and reasoning [10, 37]. Recent work further advances multimodal goal understanding and scene representations for navigation [7, 9, 22, 23, 39]. These studies primarily improve environmental representations and search planning, while we use feedback from successive goal searches to revise both the navigation program and its improvement mechanism. 

Experience-driven navigation improvement. Navigation agents increasingly turn execution experience into reusable rules, memories, and reflective guidance. Recent methods improve navigation through rule evolution, memory updates, 2and reflective guidance [2, 5, 14, 15, 28, 45]. Other ap-proaches improve navigation models through self-reflective learning and recursive training loops [13, 18]. RPSI-Nav instead studies program-level improvement with frozen foun-dation models: subsequent goals provide feedback on earlier revisions, which updates both the navigation program and the diagnosis, observation-acquisition, and revision rules that produce future changes. 

Agents and recursive self-improvement. Language feedback and failure analysis support behavioral revi-sion [20, 21, 25]. Programmatic approaches enable reusable skills and automated optimization of agent workflows and memory mechanisms [8, 17, 29, 36, 42]. Recursive self-improvement evolves agent code and its revision mecha-nisms [41, 43]. Hyperagents and MetaSkill-Evolve explicitly make the improvement process itself editable [33, 44]. In robotics, related work improves policy code, execution har-nesses, and diagnostic resources through feedback, targeted experiments, or selective model updates [3, 26, 27, 31, 32]. RPSI-Nav studies recursive improvement in continuous vi-sual search, where evidence for assessing a repair may arrive during later goals or require additional movement to obtain. Cross-goal feedback revises how the improver diagnoses fail-ures, requests observations, and selects navigation changes. Accepted rules govern subsequent revisions under their ap-plicable conditions. 

# 3 Method 

RPSI-Nav leverages sequential goal searches to improve navigation and its revision mechanism. Early searches supply policy-improvement experience, while later searches test whether prior revisions fix their target issues. We link these two feedback streams via recursive self-revision: the improver updates itself, and the updated improver shapes future navigation revisions. Accepted changes transfer across goals under applicable conditions.

RPSI-Nav links these observations to earlier patches and the improve-ment rules that generated them. When the records leave competing explanations unresolved, it requests diagnostic observations within the navigation budget before revising the improver. # 4 Experiments 

We evaluate RPSI-Nav on HM3D multi-object navigation [1, 19], HM3D-MFMON [16], GOAT-Bench [10]. We build RPSI-Nav upon the publicly released OneMap framework [1], which serves as our base navigation system and primary implementation baseline. For standard HM3D evaluation, we follow the original multi-object navigation protocol to examine the benefits of introducing recursive program self-improvement. The agent receives RGB-D observations, poses, and issued goals, with all foundation models frozen. In standard evaluations, spatial memory and accepted program updates persist across goals and reset between episodes. We report SR and SPL, plus PR and PPL for three-goal tasks. Scores are percentages, and absolute gains are percentage points. 

## 4.1 Comparative Evaluation 

Multi-Object Navigation on HM3D We evaluate RPSI-Nav on the HM3D benchmark following the OneMap proto-col [1]. In the sequential protocol, the next goal is revealed after the current goal is found, and failure terminates the episode. We also evaluate the simultaneous protocol of WTRP-Searcher [19], where all goals are available from the outset. As shown in Table 1, RPSI-Nav achieves the best performance across all metrics under both protocols. Since RPSI-Nav is built upon OneMap, we first examine the improvements over this base navigation framework. Under the sequential protocol, RPSI-Nav improves SR from 54.20% to 63.14% and SPL from 27.80% to 35.81%, yielding gains of 8.94 and 8.01 percentage points, respectively. These correspond to relative improvements of 16.5% in SR and 28.8% in SPL. Moreover, RPSI-Nav surpasses the stronger WTRP-Searcher baseline by 5.94 SR and 2.41 SPL points. Under the simultaneous protocol, RPSI-Nav further im-proves upon OneMap by 3.39 SR and 2.78 SPL points, while exceeding WTRP-Searcher by 2.53 SR and 3.41 SPL points. These results demonstrate consistent improvements over the underlying navigation framework and competitive perfor-mance against stronger baselines. Effect of cross-goal improver inheritance. To examine whether evolved improvement rules benefit subsequent goals, we compare RPSI-Nav with a variant that resets 𝑅 to 𝑅 0

at each goal transition. The accepted navigation program, spatial memory, and revision history are retained across goals, and both 𝑃 and 𝑅 remain editable within each goal search. # 5 Conclusion 

We presented RPSI-Nav, a recursive self-improvement frame-work for zero-shot open-vocabulary multi-object navigation. Using feedback from sequential searches, RPSI-Nav revises both navigation programs and its own diagnostic, observation-acquisition, and revision rules, transferring verified updates across goals under applicability guards. Benchmark evalua-tions and real-robot deployments demonstrate its effective-ness and practical feasibility.
