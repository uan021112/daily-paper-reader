## Abstract 

Accurately matching human intentions in 3D space is an important goal of artificial intelligence. Recently, 3D Intention Grounding (3D-IG) has emerged, aiming to localize target 3D objects given a natural-language intent. Unlike conventional visual grounding with descriptive referring expressions, 3D-IG intents are abstract and non-descriptive, making object localization substantially more challenging. This requires inferring latent functional requirements from non-descriptive intents and aligning them with object-level 3D representations. However, existing methods largely rely on implicit intent–object matching, leading to logical gaps and limited interpretability, robustness, and generalization. To address these challenges, we propose Chain-of-Causal Reasoning (CoCR), a causality-inspired functional depen-dency reasoning framework that explicitly bridges abstract intentions and candidate objects through intermediate functional requirements. Specifically, CoCR progres-sively decomposes complex intents into ordered functional requirements, thereby forming an explicit intent–function–object reasoning chain that links abstract inten-tions to object suitability. Building on this chain, we construct a causality-inspired functional dependency graph to model requirement–attribute relationships and intro-duce a causal-visual alignment module that aligns function-aware representations with the geometric-semantic features of 3D point clouds, enabling bidirectional verification between structured functional reasoning and visual evidence. Extensive experiments on 3D Intention Grounding and 3D Visual Grounding demonstrate that our method enhances intent-aware object localization. Our code is available at 

https://2490o.github.io/CoCR .

## 1 Introduction 

In real-world human-computer interaction scenarios, particularly in applications involving embodied intelligence [1, 2], humans typically express their needs through natural language (e.g., ‘I need back support’), rather than providing explicit object references [3, 4] (e.g., ‘the pillow on the sofa’). Therefore, compared to the traditional 3D Visual Grounding task [4], the recently proposed 3D Intent Grounding (3D-IG) task [5] is more suitable for real-world applications. The core objective of this task is to enable models to interpret a natural-language intent, infer the functional requirements, and then accurately match and localize the corresponding target objects in 3D scenes. The core challenge of the 3D-IG task lies in the abstract nature of human intent. Unlike the traditional Visual Grounding task, which relies on explicit object categories or visual descriptions, the intent texts processed by 3D-IG do not point to specific object characteristics. Instead, they focus on functional attributes and usage contexts. This requires the model first to infer implicit functional requirements from vague expressions and then match them with 3D object features, significantly

Existing methods [5] match target objects by establishing semantic correspondences between ‘verbs and objects,’ relying on direct alignment between verbs and objects, as shown on the left side of Figure 1. However, this direct semantic association introduces a clear logical gap, as the model does not understand why a particular object should match a given intent. Specifically, the model can only match at the semantic level but fails to infer whether an object truly satisfies the implicit functional requirements of the intent. For example, when faced with the intent ‘I need something to support my back,’ the model may match ‘support’ and ‘back’ with multiple objects, such as a sofa, pillow, or chair, but it cannot determine which object actually provides ‘back support,’ leading to potential mismatches and incorrect localization in open-world scenarios. Therefore, existing methods often lack an explicit modeling of the functional dependencies between intents and object suitability, limiting their robustness and generalization. To address these issues, we propose a new method, i.e., Chain-of-Causal Reasoning, which parses and grounds intents through a functional causal chain that explicitly bridges abstract intents, functional requirements, and object suitability. Specifically, our method first employs Intent Causal Parsing to decompose natural language intentions into functional requirements along a structured reasoning chain, as illustrated in the upper-right part of Fig. 1. By explicitly identifying and organizing latent needs, the module enables the model to more accurately capture the user’s intent. For example, given the intent of natural language, ‘I want something to support my back to relieve pressure’, the model first identifies the core requirements: ‘support my back’ and ‘relieve pressure’. It then further infers the corresponding physical properties: the former requires the object to provide adequate support, while the latter implies that the object should be soft. Through this stepwise reasoning mechanism, the model transforms complex intentions into explicit functional requirements, forming a functional causal chain from abstract intent to functional requirements and then to object suitability. This progressive functional causal reasoning allows the model to consistently understand complex intentions, reducing misunderstandings caused by semantic ambiguity. Next, based on this reasoning chain, the parsed functional requirements are represented as intermediate nodes in a functional causal dependency graph, establishing explicit links from natural-language intent to object suitability and localization. For example, the intent ‘support my back to relieve pressure’ is decomposed into functional nodes such as ‘supportiveness’ and ‘softness’, and functional dependency mappings are established between these functional nodes and candidate objects, as shown in the lower right part of Fig. 1. This design not only mitigates the logical gaps present in traditional semantic-matching methods but also provides an interpretable functional causal reasoning process for 3D intent grounding, enhancing the model’s robustness and explainability in open-world scenarios. Finally, we introduce Causal–Visual Feature Alignment, which encodes functional requirements as function-aware representations and aligns them with 3D point cloud features to enable bidirectional verification between functional reasoning and visual evidence. 2Extensive experiments on 3D Intention Grounding and 3D Visual Grounding demonstrate that our method effectively enhances intent understanding and improves object localization. To summarize, our contributions are as follows: • We propose a new method, Chain-of-Causal Reasoning, which decomposes complex intents along a functional causal chain and builds an explicit intent–function–object dependency graph for interpretable and robust 3D object localization. • We design a causal–visual feature alignment module that encodes functional requirements as functional causal representations and aligns them with 3D point cloud features, enabling bidirectional verification between functional causal reasoning and visual evidence. • We validate the effectiveness of our method on 3D Intention Grounding and 3D Visual Grounding, demonstrating strong and competitive performance across multiple benchmarks. 

## 2 Related Works 

2.1 Causal Graph Modeling 

Causal modeling has been widely explored to improve model interpretability, robustness, and gener-alization. In visual tasks, existing studies introduce causal mechanisms for image classification [6], object detection [7], point cloud classification [8], and 3D novel class discovery [9]. In 3D visual grounding, MA 2TransVG [10] models causal effects among explicit textual attributes for fine-grained localization. However, these methods mainly focus on observable attributes, object categories, or point-level representations, while 3D intention grounding requires reasoning over latent functional needs behind abstract intents. Therefore, we focus on task-level functional causal reasoning by con-structing an explicit intent–function–object causal chain. More discussions on functional requirements and object attributes are provided in Appendix A.1.1 and Appendix A.1.3. 

2.2 3D Intention Grounding 

3D Intention Grounding aims to localize target objects in 3D scenes according to natural-language human intentions. Different from conventional 3D visual grounding [11, 12, 3, 13], where queries usually contain explicit object categories, attributes, or spatial relations, intention grounding requires inferring implicit functional requirements from abstract and non-descriptive intents. Intent3D [5] introduces this task and proposes IntentNet based on verb–object alignment. However, direct verb– object matching may introduce semantic logical gaps, since it does not explicitly explain why a candidate object satisfies the underlying functional needs of an intent. To address this limitation, we propose Chain-of-Causal Reasoning (CoCR), which decomposes complex intentions into functional requirements and builds a functional causal dependency graph for interpretable intent–function–object reasoning. Related 3D visual grounding and 3D-MLLM methods are discussed in Appendix A.1.2. 

## 3 Method 

The overall framework of our Chain-of-Causal Reasoning (CoCR) method is illustrated in Fig. 2. CoCR follows a functional causal reasoning process that explicitly bridges abstract intents, functional requirements, and candidate objects. The framework consists of three key modules: (i) Intent Causal Parsing, which decomposes complex intentions into step-wise functional requirements; (ii) Intent Causal Grounding, which establishes explicit functional dependency links between functional requirements and candidate objects; and (iii) Causal–Visual Feature Alignment, which iteratively updates the functional dependency graph and enables robust cross-modal reasoning. In CoCR, causal refers to task-level functional causal dependencies rather than formal causal identification under structural causal models; detailed discussion is provided in Appendix A.2.1.

Explicitly mod-eling the functional dependencies among intents, functional requirement nodes, and candidate objects enables the model to map functional requirements to object suitability, mitigating the gaps caused by direct semantic matching. Specifically, we map the functional requirement set F = {f1, f 2, . . . , f K }

to intermediate nodes in the graph and the candidate object set O = {o1, o 2, . . . , o M } to candidate terminal nodes, where M denotes the total number of candidate objects. The graph G = ( V, E)

consists of a node set V = {Q, F, O} and an edge set E, where edges represent task-level functional dependency relationships. 3.3 Causal-Visual Feature Alignment 

After obtaining the functional dependency graph G, we further integrate function-aware represen-tations with the geometric–semantic features of the 3D scene point cloud to achieve collaborative reasoning between functional inference and visual perception. Specifically, given the input 3D scene point cloud X , we first employ a 3D point cloud encoder (e.g., PointNet++) to extract the scene representation V ∈ RM ×d, where M denotes the number of candidate objects in the point cloud and d

is the feature dimension. Meanwhile, based on the functional requirements extracted in Intent Causal Parsing, represented by the probability distribution P (fj | Q), we obtain a set of function-aware representations C ∈ RK×d, where K corresponds to the number of functional requirements. These representations are computed as: 

Cj = P (fj | Q) · Embed (fj ), j = 1 , 2, . . . , K, (9) where Embed (fj ) denotes the embedding of the j-th functional requirement fj in a d-dimensional vector space, and P (fj | Q) indicates its relevance to the input intent. The resulting set of function-aware representations C is then used for fusion with 3D point cloud features. ## 4 Experiments 

In the experiments, for the 3D Intention Grounding (3D-IG) task, we follow the settings of Intent3D [5] to evaluate the model’s cross-modal reasoning ability between natural language intention under-standing and 3D object grounding. We conducted comparative experiments on both the validation and test sets and performed fair comparisons with multiple baseline models. Additionally, we conducted further evaluations on 3D Visual Grounding task to comprehensively assess the proposed method’s effectiveness in terms of accuracy and robustness. 

4.1 Experimental setup Dataset. In our experiments, for the 3D Intention Grounding (3D-IG) task, we adopt the official evaluation setting of the Intent3D dataset [5]. Intent3D is primarily derived from the ScanNet [16] dataset and contains 44,990 intention texts across 1,042 ScanNet scenes. The dataset covers large-scale indoor 3D environments paired with natural language intention descriptions, providing an effective benchmark for assessing a model’s cross-modal reasoning ability between intention understanding and 3D object grounding. Additionally, we validate the effectiveness of our method on the Nr3D, Sr3D, and ScanRefer datasets for the 3D Visual Grounding task, with more detailed descriptions of these datasets provided in Appendix A.3.1. 

Evaluation Metric. Consistent with baseline methods, we evaluate our model using Top-1 Accuracy and Average Precision (AP). Top-1 Accuracy measures the correctness of the model’s highest-confidence prediction, while AP assesses detection performance across varying confidence thresholds. In experiments, we compute IoU between predicted and ground-truth boxes, and count a prediction as correct if IoU exceeds 0.25 or 0.5. 

4.2 Implementation Details 

To ensure a fair comparison, we adopt the same point cloud feature extractor, PointNet++ [17], and the text feature extractor, RoBERTa [18], as IntentNet. The model is trained for a total of 120 epochs on four NVIDIA 3090 GPUs with 24 GB of memory, using a batch size of 16, and the overall training time is approximately 40 hours. In terms of input settings, the number of point cloud tokens is fixed at 1024, and the maximum length of text tokens is set to 256. During training, our method parses intention causal chains via Intent Causal Parsing and builds a causal graph through Intent Causal Grounding to align functional requirements with object features, enabling causal reasoning. ## 5 Conclusion 

For the 3D Intention Grounding (3D-IG) task, we propose Chain-of-Causal Reasoning (CoCR), a causality-inspired functional dependency reasoning framework for intent-aware 3D object localization. Specifically, the method incrementally decomposes complex intentions into functional requirements along the causal chain, clarifying priorities and latent needs, thus forming a causal chain from abstract intentions to object attributes and improving the accuracy of intent understanding. Based on this, we build a causal graph linking functional requirements to object attributes and employ a causal-visual fusion mechanism for deep cross-modal alignment and bidirectional verification. Extensive experiments on 3D Intention Grounding and 3D Visual Grounding tasks demonstrate that our method effectively enhances intent understanding and improves object localization accuracy.

A.1 Related Works A.1.1 Functional Affordance and Causality-inspired Reasoning 

The 3D Intention Grounding task is closely related to functional affordance understanding, since the target object is determined by whether it can satisfy the user’s intended function. The concept of affordance emphasizes the actionable properties or functional possibilities provided by an object to an agent [33]. In visual understanding, affordance and function recognition have been widely studied to infer what actions or utilities an object can support beyond its visual appearance [34]. Recent studies further explore affordance grounding with vision-language models [35] and 3D object affordance grounding from language instructions, visual observations, and interactions [36], showing the importance of connecting language, perception, and object functionality. However, 3D Intention Grounding differs from conventional affordance understanding in its problem formulation. Most affordance-related methods start from observed objects, visual regions, or language instructions, and then predict possible actions, interaction regions, or object functions. In contrast, 3D Intention Grounding starts from an abstract human intent and requires the model to infer the latent functional requirements before selecting the target object. For example, the intent ‘I want something to support my back and relieve pressure’ does not directly specify an object category or an interaction region. Instead, the model must infer functional requirements such as supportiveness, softness, and comfort, and then determine which candidate object in the current 3D scene can satisfy these requirements. Our CoCR framework can be viewed as a causality-inspired extension of functional affordance reasoning for 3D intention grounding. Specifically, functional requirements are introduced as intermediate causal variables between abstract intentions and candidate objects. The intent induces latent functional requirements, and these requirements further determine the suitability of candidate objects. This forms an explicit intent–function–object causal chain, which differs from direct intent– object similarity matching. By introducing functional requirements as mediators, CoCR provides an interpretable reasoning mechanism that explains why a candidate object is suitable for a given intention. This formulation also clarifies the relation between our method and strict causal inference. We do not claim to estimate causal effects under structural causal models. Instead, we focus on task-level functional causal dependencies, where the causal meaning is reflected by functional necessity and directional reasoning. In this sense, CoCR bridges affordance-based object understanding and causality-inspired structured reasoning, making it more suitable for abstract 3D intention grounding where explicit visual descriptions are absent. 

A.1.2 3D Visual Grounding 

3D Visual Grounding aims to localize target objects in a 3D scene according to natural-language descriptions. Existing methods mainly focus on aligning linguistic expressions with object-level or point-level 3D representations. Early benchmarks such as ScanRefer [11] and ReferIt3D [12] establish the basic setting of language-guided 3D object localization, where the input query usually contains explicit object categories, attributes, or spatial relations. Based on this setting, a series of methods have been proposed to improve cross-modal alignment. TGNN [26] introduces text-guided graph neural networks to model object relations, while 3D-SPS [27] performs single-stage grounding through referred point progressive selection. EDA [21] further decouples textual expressions and conducts dense alignment between language and 3D proposals. Recent works also enhance ground-ing performance through multi-view modeling, semantic-geometric alignment, and scene-aware representations, such as MVT [28], G 3-LQ [29], MiKASA [30], GPS [31], and PQ3D [32]. In addition, TSP3D [4] improves grounding efficiency by using text-guided sparse voxel pruning and completion. Beyond single-object grounding, some studies extend 3D visual grounding to more complex scenarios. Multi3DRefer [37] focuses on grounding text descriptions to multiple 3D objects, while ConcreteNet [38] improves verbo-visual fusion for dense 3D visual grounding. D-LISA [39] introduces dynamic modules and language-informed spatial attention for multi-object grounding. These methods show that modeling object relations, spatial context, and language-guided interaction is important for complex 3D grounding. However, they still largely assume that the language query provides descriptive cues that can be directly aligned with visual objects. Recently, 3D multimodal large language models have been introduced to grounded 3D scene understanding. Representative methods such as Chat-Scene [40], Chat-3D [24], and Robin3D [41] leverage the reasoning ability of 14 large language models to connect 3D scene representations with natural-language instructions. These methods show strong potential for general 3D vision-language understanding, but they often require explicit object identifiers, object categories, or descriptive instructions to support reliable localization. In contrast, 3D Intention Grounding focuses on abstract and non-descriptive human intentions, where the target object is implied by latent functional requirements rather than directly mentioned in the query. Therefore, this task requires not only visual-language alignment but also functional reasoning from human intent to object suitability. 

A.1.3 Functional Requirements vs. Object Attributes 

To clarify the specific challenge of 3D Intention Grounding, it is important to distinguish functional requirements from object attributes. Object attributes refer to explicit and observable properties of an object, such as color, shape, size, material, category, or spatial relation. These attributes are widely used in conventional 3D visual grounding, since the language query often directly describes the target object. For example, a query such as ‘the red chair near the table’ provides clear visual and spatial cues, allowing the model to localize the target through direct text–object alignment. In contrast, functional requirements describe the expected capability or utility of an object, such as supportiveness, softness, washability, sittability, storability, or comfort. These requirements are usually not directly observable from the surface form of the text, but must be inferred from abstract human intentions. For example, the intent ‘I want something to support my back and relieve pressure’ does not explicitly mention a target category or visual attribute. Instead, it implies latent functional requirements such as supportiveness, softness, and comfort. Therefore, 3D Intention Grounding requires the model to infer what functions are needed and then determine which candidate objects can satisfy these functions in the current 3D scene. This distinction differentiates our method from attribute-centric grounding methods. For instance, MA 2TransVG [10] models multi-attribute interactions and employs an Attribute Causal Analysis Module to quantify the causal effects of explicit visual attributes extracted from the text. This mechanism is effective for descriptive queries that contain rich attribute cues, such as color, shape, size, or spatial relation. However, abstract intention queries often lack such explicit descriptions, making attribute-level causal modeling insufficient for intention grounding. Similarly, methods such as VPPNet [3], MBVG [13], and PQ3D [32] improve visual-language grounding through stronger feature interaction or promptable queries, but their grounding process still mainly relies on explicit linguistic-visual correspondences. Unlike these methods, our Chain-of-Causal Reasoning framework introduces functional requirements as intermediate causal variables between abstract intentions and candidate objects. Instead of directly matching an intent with object categories or visual attributes, CoCR first decomposes the intent into latent functional requirements and then constructs an intent–function–object reasoning chain. In this way, the model can explicitly explain why a candidate object is suitable for a given intention. For example, a pillow may be selected not because the query mentions ‘pillow’, but because it satisfies the inferred requirements of softness and pressure relief. This functional causal reasoning provides a more suitable mechanism for 3D Intention Grounding, especially when the input intent lacks explicit visual descriptions. 

A.2 More Method Details A.2.1 Causal Interpretation of CoCR 

We clarify that the term ‘causal’ in CoCR refers to task-level functional causal dependencies in 3D intention grounding, rather than formal causal identification under structural causal models (SCMs), do-calculus, or intervention-based causal inference. In this work, causality is defined from the perspective of functional necessity: an abstract human intent gives rise to a set of latent functional requirements, and these functional requirements further determine whether a candidate object is suitable for satisfying the intent. Therefore, the causal relation modeled by CoCR is not a statistical treatment effect, but a directional functional dependency chain from intent to function and then to object suitability. We do not formulate CoCR as a strict SCM for the following reasons. First, the goal of 3D intention grounding is not to estimate the causal effect of an intervention, but to infer which object best satisfies an abstract human intention in a 3D scene. A formal SCM usually requires explicitly defined endogenous variables, exogenous noise variables, structural equations, and intervention operators. However, in 3D-IG, the key variables, such as user intention, functional requirements, 15 object affordance, scene context, and object suitability, are often latent, semantic, and task-dependent, making it difficult to specify universally valid structural equations. Second, existing 3D-IG datasets provide paired intention texts, 3D scenes, and target object annotations, but they do not contain interventional data, counterfactual annotations, or controlled manipulations of functional requirements. As a result, formal causal identification or do-calculus-based estimation is not supported by the available supervision. Third, the functional relation between an intent and an object is highly context-dependent. For example, an object that satisfies ‘support my back’ in one scene may be unsuitable in another scene due to its pose, accessibility, size, or surrounding context. This makes it more appropriate to model task-level functional dependencies than to assume a fixed global causal structure. Specifically, given an intention query Q, CoCR first decomposes it into a set of intermediate functional requirements F = {f1, . . . , f K }. These functional requirements serve as causal mediators between the abstract intent and candidate objects. For example, the intent ‘I want something to support my back and relieve pressure’ does not directly indicate a specific object category. Instead, it implies functional causes such as supportiveness, softness, and comfort. These functional causes then determine why objects such as a chair, sofa, or pillow may be considered suitable, while other visually or semantically related objects may be rejected. In this sense, CoCR explicitly models the reasoning path Q → F → O, where F explains the functional causes behind object selection. The proposed functional causal dependency graph further operationalizes this idea by assigning directional dependency weights between the intent, functional requirements, and candidate objects. The edge from Q to fj reflects how strongly the intent requires a certain function, while the edge from 

fj to om reflects how well the candidate object satisfies that functional requirement. The final object score is therefore not obtained through direct intent–object matching, but through the aggregation of function-mediated causal dependencies. This design reduces the logical leap of direct semantic matching and provides an explicit intermediate reasoning structure. Although CoCR does not claim to estimate causal effects in the strict SCM sense, its causal nature is reflected in three aspects. First, it introduces functional requirements as explicit mediating variables, which explain why an intent should lead to a particular object. Second, the dependency graph is directional: the intent induces functional requirements, and functional requirements determine object suitability, rather than treating all text and object features as undirected correlations. Third, the graph supports intervention-style analysis at the functional-node level. For instance, suppressing a key functional node such as ‘softness’ would reduce the suitability score of objects whose relevance mainly comes from pressure relief, while increasing the weight of ‘supportiveness’ would strengthen the scores of objects that provide stable body support. Such node-level perturbations reveal how functional causes affect the final grounding decision. Therefore, the ‘causal’ in Chain-of-Causal Reasoning should be understood as task-level functional causal reasoning: CoCR makes the latent functional causes behind object suitability explicit, organizes them into a directional intent–function–object chain, and verifies them with 3D visual evidence through causal–visual feature alignment. This formulation is weaker than formal causal inference, but stronger than direct similarity-based matching, because it exposes the functional mechanisms that connect abstract intentions to concrete 3D objects. 

A.2.2 More Details about Intent Causal Parsing 

In Intent Causal Parsing (ICP), we decompose natural language intentions into functional require-ments using a prompt template. The template is as follows: ‘Given a natural language intention, generate a step-by-step reasoning sequence to identify the functional requirements of the object. The reasoning process should first identify the core demands, then infer the required functional proper-ties, and finally synthesize a complete set of functional requirements.’ For example, as shown in Figure 5, given the intention Q = ‘I want something that can support my back to relieve pressure’, the model first identifies the core demands, producing s1 = {support back , relieve pressure }.It then infers the functional properties required by each core demand, resulting in s2 =

{requires supportiveness for back support } and s3 = {requires softness for pressure relief }. By integrating these intermediate steps, the model generates the final reasoning sequence s4 =

{required functions include supportiveness and softness }. Finally, the reasoning path from the ini-tial intention s0 = Q to s4 is mapped to the global functional requirement nodes. Each node 

fk ∈ { f1, . . . , f K } represents a distinct functional property. In this example, the reasoning sequence 16 is mapped to functional nodes such as softness, elasticity, and supportiveness, forming the basis for causal graph construction.

Construction of the Global Functional Requirement Set. To map parsed reasoning steps into a unified functional space, we construct a global functional requirement set F = {f1, . . . , f K } from the training split. Different from object categories, functional requirements describe the intended usage or affordance implied by natural language intentions. For example, tables, desks, and counters may share the function of placement surface, while chairs, sofas, and beds may share the functions of seating, body support, and rest. Therefore, a compact functional vocabulary is necessary for bridging abstract intentions and concrete 3D object candidates. Specifically, we construct the vocabulary from all intent annotations in the training split, which contains 35,850 intention-object pairs. Only the training split is used, and no validation or test descriptions are involved, thus avoiding information leakage. The construction process contains three steps. First, we collect all training intention descriptions and extract high-frequency action phrases and functional cues, including verbs, verb-object phrases, and usage-related expressions. Typical examples include ‘place my laptop’, ‘store my books’, ‘sit comfortably’, ‘throw away waste’, ‘write down notes’, and ‘display presentations’. Second, we merge synonymous or semantically overlapping functional cues into unified functional nodes. For instance, ‘put’, ‘place’, ‘lay out’, and ‘set down’ are merged into placement surface; ‘store’, ‘keep’, and ‘organize’ are merged into storage and organization; while ‘discard’, ‘dispose of’, and ‘throw away’ are merged into waste disposal. Third, we manually verify the resulting functional nodes to remove noisy, overly specific, or redundant entries, ensuring that each node represents a general and reusable functional requirement rather than an object-specific phrase. After this process, the final vocabulary contains K = 40 functional nodes, covering common indoor functional needs such as placement surface, work/study support, dining support, storage, organization, display, carrying, waste disposal, seating, rest, body support, writing, presentation, visual display, illumination, cleaning, bathing, cooking, liquid containment, wearing, decoration, hanging, spatial reference, and concealment. 17 Implementation Details. A.3 More details of the experimental settings A.3.1 Dataset 

Our main experiments are divided into two parts: the 3D Intention Grounding task and the 3D Visual Grounding task, providing a comprehensive evaluation of the effectiveness of our method. 

3D Intention Grounding (3D-IG) Task: For this task, we adopt the official evaluation setting of the Intent3D dataset [5]. Intent3D is primarily derived from the ScanNet [16] dataset and contains 44,990 intention texts across 1,042 ScanNet scenes. On average, each scene contains 61 instances and 43 texts, with each scene-object pair receiving 6 intention texts. The dataset includes 568 distinct verbs and 2,894 distinct nouns. Covering large-scale indoor 3D environments with paired natural language intention descriptions, Intent3D provides an effective benchmark for evaluating a model’s cross-modal reasoning ability between intention understanding and 3D object grounding. To ensure fair comparison with existing methods, we strictly follow the official data split, dividing the dataset into a training set (35,850 samples), a validation set (2,285 samples), and a test set (6,855 samples), with no overlapping scenes across splits. 

3D Visual Grounding Task: We validate our method on the Nr3D and Sr3D datasets, both built upon ScanNet and widely used for 3D visual grounding. Nr3D [12] contains 41,503 human-annotated referring expressions across 707 indoor scenes, where each description uniquely identifies a target object among distractors. Sr3D [12] contains 83,572 machine-generated expressions based on predefined templates that focus on spatial relationships between objects. Both datasets provide ground-truth object masks. Performance is evaluated using accuracy, measuring the proportion of correctly localized target objects. 

A.3.2 Implementation Details 

To ensure a fair comparison with existing methods, we adopt a common architecture for the founda-tional feature extractors, using PointNet++ [17] for 3D point cloud feature extraction and RoBERTa-base [18] for natural language intent encoding, consistent with baselines such as IntentNet. Our model is implemented in PyTorch and trained on a distributed system of four NVIDIA 3090 GPUs, each equipped with 24GB of memory, with a total batch size of 16. Figure 8 presents several failure cases of our method, highlighting its current limitations. The first type of failure occurs when multiple target objects are present and their sizes are very small. The second type of failure involves detection box misalignment. In the illustrated scenario, the model parses the intent “I intend to display slides for a business presentation” and identifies the target object as a projector. This case emphasizes that our method partially relies on the accuracy of candidate boxes: even if the intent parsing is correct, misaligned boxes can result in incorrect object localization. Improving candidate box precision is an important direction for future work. This demonstrates that in highly cluttered or occluded environments, our method may not achieve complete object localization.
