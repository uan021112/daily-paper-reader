## 摘要
潜在空间规划器通过比较预测未来图像与目标图像的嵌入来选择动作。这一做法假设嵌入空间中的距离能够反映场景距离目标的远近。我们使用模拟器执行得到的未来状态来检验这一假设，从而排除预测误差的影响。对于六种冻结的 DINO 和 V-JEPA 编码器，特征距离几乎无法反映物体与目标之间的距离：其秩相关系数最高仅为 0.11，而物体掩码质心的相关系数为 0.87。特征距离主要受背景和机器人图像块影响，且基于冻结特征的读出对机械臂的表征远优于对物体的表征。受视觉腹侧通路（是什么）和背侧通路（在哪里／如何）的启发，我们提出 DOCK，通过学习与测得的物理运动相一致的物体表征，使其变化能够反映实际运动。被抓取的物体会随夹爪移动，因此可以利用关节角度的正向运动学，作为物体位移的无标注代理信号。我们从 21 个模拟厨房场景中的 9,951 条持物移动轨迹中挖掘出 40.4 万个位移样本对，并训练三个组件：从图像块特征汇聚得到的物体 token（是什么）、使读出坐标之差等于测得位移的空间标尺（在哪里），以及基于物体 token 的动力学预测器（如何）。将学习到的表征用作规划代价时，DOCK 能在 21 项任务中的 15 项将物体放置到位，与读取真实物体位置的 oracle 相当；相比之下，掩码几何方法完成 10 项，冻结特征距离方法完成 9 项。即使未见过的机械臂出现在画面中，DOCK 仍能解决最多的任务；其排序能力也能迁移到留出的场景布局，并适用于未见过的物体实例和类别，无需任何适配。

## Abstract
Latent-space planners select actions by comparing the embedding of a predicted future image with that of a goal image. This assumes that distance in the embedding reflects how far the scene is from the goal. We profile this assumption with simulator-executed futures, which removes prediction error. For six frozen DINO and V-JEPA encoders, feature distance barely tracks the object's distance to its goal: the rank correlation is at most 0.11, against 0.87 for object-mask centroids. It is dominated by background and robot patches, and frozen-feature readouts capture the arm far better than the object. Inspired by the ventral (what) and dorsal (where/how) visual streams, we propose DOCK, which learns an object representation whose changes agree with measured physical motion. A grasped object moves with the gripper, so forward kinematics on the joint angles gives a proxy for the object's displacement without annotation. From 9,951 held-object transport trajectories in 21 simulated kitchen scenes, we mine 404K displacement pairs and train three components: an object token pooled from patch features (what), a spatial ruler that makes differences of readout coordinates equal to measured displacements (where), and a dynamics predictor over object tokens (how). Used as a planning cost, the learned representation places the object in 15 of 21 tasks, as many as an oracle that reads the true object position, while mask geometry reaches 10 and frozen feature distance 9. It still solves the most tasks when the unseen robot arm is visible, and its ranking transfers to held-out layouts with unseen object instances and categories without any adaptation.
