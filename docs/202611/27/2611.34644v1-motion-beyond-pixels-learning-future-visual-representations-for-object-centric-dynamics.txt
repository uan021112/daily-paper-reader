Abstract 

Many embodied world models predict future states in latent spaces optimized for RGB reconstruction, which do not explicitly prioritize object-level semantics and geometry relevant to motion generation. We present MotionRep, a visual representation world model that jointly generates future DINO representations and 3D object flow, coupling semantic and geometric information with object-centric dynamics. To make high-dimensional DINO features amenable to generative modeling, we introduce DINO-VAE, which combines temporal and channel compression with latent regularization to produce compact latents while preserving semantic and geometric information. Conditioned on an initial observation, object query points, and a language instruction, a unified diffusion transformer predicts future visual representations and 3D object flow through joint attention. MotionRep employs asymmetric modality-specific noise schedules to keep the visual stream ahead of 3D object flow during joint denoising, allowing progressively refined future visual representations to guide flow generation. Experiments on simulated and real-world manipulation benchmarks demonstrate that MotionRep outperforms pixel-based baselines in 3D object flow accuracy and generalization to unseen scenes, while requiring only three denoising steps for inference. These results support predictive visual representations as an effective future-state space for object-centric dynamics modeling.

1 Introduction 

Effective robotic manipulation requires reasoning beyond the current observation to anticipate future object dynamics. 3D object flow explicitly represents the trajectories of object points in 3D space, providing a natural description of future physical dynamics (Yuan et al., 2024). Recent 3D object flow world models incorporate future visual state modeling to support motion generation, making the choice of visual representation a critical design decision (Li et al., 2025; Lu et al., 2026b). Existing 3D object flow world models commonly predict future states in pixel-reconstruction-oriented latent spaces (Li et al., 2025; Lu et al., 2026b), which preserve substantial low-level texture and appearance details but do not explicitly prioritize object semantics and spatial geometry relevant to motion prediction (Yu et al., 2025; Yao et al., 2025). Modeling such complex appearance details can increase inference cost and limit generalization to unseen scenes. In contrast, visual representation world models predict future states rich in semantic and geometric information (Zhou et al., 2025; Assran et al., 2025; Guo et al., 2026). However, these approaches primarily focus on visual representation prediction, while jointly modeling visual representations and 3D object flow remains underexplored. To address this challenge, we introduce MotionRep, a visual representation world model for object-centric dynamics that jointly generates future DINO representations and 3D object flow, modeling future visual states in the DINO representation space rather than pixel-reconstruction-oriented latent spaces (Fig. 1). • We demonstrate the value of explicitly predicting future visual representations for 3D object flow generation, and introduce MotionRep to jointly model future DINO representations and object motion. 

• We introduce DINO-VAE, which makes dense DINO features amenable to generative modeling through temporal and channel compression and latent regularization, while preserving semantic and geometric information. 

• We develop an asymmetric denoising strategy with decoupled timesteps and modality-specific noise schedules, enabling representation-guided flow generation and bidirectional conditional dynamics modeling.

2 Related Work 

3D Object Flow World Models. Vision-language-action (VLA) models directly predict robot actions from multimodal observations (Kim et al., 2024; Black et al., 2024; Brohan et al., 2023), while world action models (WAMs) incorporate future state prediction to explicitly model environment dynamics (Du et al., 2023; Li et al., 2026b; Tian et al., 2025; Ye et al., 2026; Hu et al., 2024). However, video generation world models primarily focus on visual scene evolution and often lack explicit representations of 3D object motion. In contrast, 3D object flow captures object dynamics through 3D point trajectories, providing explicit geometric and motion information for robotic manipulation (Yuan et al., 2024; Zhi et al., 2025; Lin et al., 2026). Existing 3D object flow generation methods follow two paradigms. Two-stage approaches generate future videos and recover 3D trajectories using point trackers (Li et al., 2025; Karaev et al., 2024; Lu et al., 2026a; Karhade et al., 2025), suffering from accumulated generation and tracking errors. Single-stage approaches directly generate 3D object flow (Lee et al., 2026; 2025; Zhang et al., 2026; Li et al., 2026a), with some methods further jointly generating future videos (Lu et al., 2026b). However, direct flow generation often lacks explicit future state guidance, while joint video-flow models typically rely on pixel-oriented VAE latents, which may not fully capture semantic and geometric information. In contrast, MotionRep jointly generates future visual representations and 3D object flow in the semantically and geometrically rich DINO representation space, providing more informative future state guidance for 3D motion generation. 

Visual Representation World Models. Most video world models operate in pixel VAE latent spaces optimized for visual reconstruction (Rombach et al., 2022; Yang et al., 2025; Wan Team et al., 2025; Blattmann et al., 2023a;b), devoting substantial capacity to low-level appearance details that may be less relevant to dynamics modeling. In contrast, self-supervised visual models such as DINO and V-JEPA learn representations rich in semantic and spatial information (Caron et al., 2021; Oquab et al., 2024; Amir et al., 2021; Bardes et al., 2024; Sim´ eoni et al., 2025; Assran et al., 2025). Recent studies have explored these representations for generative modeling, either to improve optimization (Yu et al., 2025; Yao et al., 2025) or as direct generation spaces (Zheng et al., 2026; Singh et al., 2026; Guo et al., 2026; Xie et al., 2026), demonstrating faster convergence and improved generation quality. However, much of the progress in representation-based generation has been demonstrated on images (Yu et al., 2025; Yao et al., 2025; Zheng et al., 2026), while high-dimensional features (Zheng et al., 2026)

3.3 Unified Representation and Flow Modeling 

Building on the compact visual latents produced by DINO-VAE, MotionRep jointly models future visual representations and object-centric dynamics in a unified generative framework, as shown in Fig. 2. MotionRep employs DINO features to represent the evolution of future states, while explicitly modeling the 3D motion and geometric changes of target objects through 3D object flow. 

3D Object Flow Encoding. We use the definition of 3D object flow from Sec. 3.1. Since flow is represented directly in metric 3D space, its numerical scale can differ substantially from the Gaussian noise used in diffusion-based generative modeling. We therefore normalize flow with a global scale factor

To associate each flow token with its corresponding geometric location, we further use the initial 3D coordinate P0,p as a geometric anchor. Specifically, we separately encode the global 3D position of each point and its local geometry relative to the object centroid, and fuse the two as the 3D geometric positional encoding for each flow token. 

Cross-Modal Dynamics Modeling. We then concatenate the representation latent sequence produced by DINO-VAE with the flow token sequence, and feed them into a unified diffusion transformer together with the clean initial object points P0 for joint modeling. Joint attention allows visual and flow tokens to interact bidirectionally: predicted future visual states can guide flow generation, while flow provides explicit object-motion information for predicting future scene states. To further capture cross-modal spatiotemporal correspondences, we introduce spatiotemporal RoPE. We assign spatial coordinates to

4 Experiments 

4.1 Experimental Setup 

We systematically evaluate MotionRep across multiple aspects, including 3D object flow generation, DINO-VAE representation analysis, ablation studies of key design choices, and multi-task dynamics inference. Our experiments span simulated and real-world manipulation scenarios, with comparisons against advanced 3D object flow world models. Further details on datasets, benchmark protocols, baseline implementations, and evaluation metrics are provided in the Appendix. 

4.2 Evaluation of Flow Generation 

Quantitative Analysis. We first evaluate MotionRep on 3D object flow generation using WorldFlowBench (Lu et al., 2026b). Given the initial frame, the initial 3D point set of the target object, and a task description, the model generates the full future object flow sequence. Table 1 compares MotionRep with video generation pipelines followed by 3D tracking, direct flow generation methods, as well as joint visual and flow generation methods. MotionRep achieves strong trajectory prediction performance across all three benchmarks, demonstrating its ability to accurately model future object motion. On Sim7, MotionRep achieves an ADE of 0.0447 m, an FDE of 0.0768 m, and a PWT of 0.5965. It also maintains stable and competitive performance on the real-world Real3 and SpatialCog benchmarks, indicating robustness to more complex appearance variations, interaction patterns, and motion distributions. Compared with methods that jointly generate future states and flow in pixel-reconstruction-oriented VAE latent spaces, MotionRep models future dynamics in the DINO representation space, providing richer semantic and geometric state constraints for flow generation. Overall, these results show that joint modeling in a visual representation space improves the trajectory accuracy and stability of 3D object flow generation.

Out-of-Distribution Generalization. Inference Efficiency. To evaluate the inference efficiency of MotionRep, we compare the inference steps and latency of different 3D object flow generation methods under identical hardware conditions. As shown in Table 3, MotionRep predicts 48 future frames of 3D object flow in only 2.21 seconds, achieving 6× and 83 × speedups over WorldFlow and MolmoMotion, respectively, demonstrating efficient joint generation. This efficiency advantage benefits from the properties of the DINO representation space. Unlike pixel-reconstruction-oriented VAE latents, DINO representations emphasize object-level semantics and spatial geometry rather than low-level textures and appearance details. Modeling future states in this representation space therefore reduces the need to explicitly model complex high-frequency texture variations, enabling MotionRep to achieve high-quality joint generation of future visual representations and 3D object flow with only 3 sampling steps. 

Qualitative Results. We further qualitatively evaluate the generation results of MotionRep. These results demonstrate that MotionRep effectively models future visual states and object-centric 3D motion jointly within a unified framework.

4.4 Ablation Studies 

We further conduct ablation studies on RoboTwin to assess the contribution of key components to 3D object flow generation (Chen et al., 2025b), including DINO-VAE, future DINO generation, modality-specific noise scheduling, and visual representation world model pretraining, as summarized in Table 6. This shows that explicitly predicting DINO representations provides temporally evolving visual states that more effectively constrain flow generation. Removing DINO-VAE and directly modeling the original DINO features also leads to performance degradation, demonstrating that the compact DINO-VAE latent space is better suited for generative modeling than high-dimensional DINO features. Replacing modality-specific noise scheduling with a shared noise schedule degrades performance, indicating that asymmetric denoising enables visual representations to provide more effective guidance for flow generation. In addition, joint training from random initialization underperforms pretrained initialization, suggesting that pretraining future DINO generation provides a useful dynamics prior for flow modeling. Overall, all ablations lead to performance degradation, demonstrating the complementary contributions of these components in MotionRep.

5 Conclusion 

We presented MotionRep, a visual representation world model that jointly generates future DINO representations and 3D object flow for object-centric dynamics modeling. DINO-VAE compresses high-dimensional DINO features into compact generative latents while preserving semantic and geometric information. Asymmetric denoising enables progressively refined future visual representations to guide 3D object flow generation. Experiments on simulated and real-world benchmarks demonstrate that MotionRep improves 3D object flow accuracy over the baselines, generalizes to unseen scenes, and enables efficient generation with only three denoising steps. MotionRep further supports visual-conditioned inverse dynamics and flow-conditioned forward dynamics within the same model. Together, these results demonstrate the value of explicitly predicting future visual representations for 3D object flow generation. 

Limitations and Future Work. A key limitation of MotionRep is the difficulty of obtaining accurate 3D object flow annotations in real-world scenes, where supervision often relies on existing 3D trackers and may contain tracking noise. Future work will explore more reliable flow acquisition and extend MotionRep to longer-horizon tasks with more complex temporal dynamics.

B Implementation Details 

We provide further implementation details of MotionRep, including the architectural configurations and parameter counts of both DINO-VAE and the joint DINO-Flow DiT, as well as detailed training and inference settings. 

B.1 DINO-VAE Implementation 

The frozen DINOv3-L encoder is excluded from parameter counting. DINO-VAE comprises six trainable modules with a total of 117.08M parameters (Table II). Temporal attention pooling compresses the 1 + T

input frames into 1 + T / 4 latent frames, followed by a three-layer block-causal ViT encoder operating at hidden dimension D = 1024. A latent head then predicts the mean μ and log-variance log σ2 in a 

d = 128-dimensional latent space. The decoder first projects the latents back to dimension D, processes them through a three-layer ViT decoder, and restores the original temporal resolution through temporal unpatchification to reconstruct the input DINO features. DINO-VAE achieves approximately 32 × compression through 4 × temporal and 8 × channel compression, without spatial downsampling. Attention is causal across latent frames while remaining bidirectional within each frame, ensuring that the first latent depends exclusively on the initial observation and provides a leakage-free conditioning signal. We train DINO-VAE for five epochs using AdamW with a warmup-stable-decay learning rate schedule, a peak learning rate of 10 −4.

B.3 Training Setup 

We adopt a two-stage training strategy consisting of DINO-only pretraining and joint DINO-flow training. In the first stage, we train the DINO DiT to model future visual representations without the object-flow branch. In the second stage, we initialize from the pretrained DINO DiT and introduce the object-flow branch to jointly model future visual representations and 3D object flow. We use 967,377 video clips collected from 11 data sources, grouped into three categories: Sim7, Real3, and SpatialCog, as detailed in Sec. C.1. To effectively leverage large-scale internet-sourced training data of varying origins and quality, we adopt a four-stage curriculum during joint DINO-flow training, progressively adjusting the sampling ratios across the three data categories. As summarized in Table IV, Stage A primarily uses simulated data to establish basic motion modeling capabilities. Stage B increases the proportion of SpatialCog, a curated in-house dataset, to facilitate adaptation to real-world environments. Stage C emphasizes Real3, a large-scale internet-sourced dataset, to improve real-world motion modeling. Finally, Stage D increases the sampling ratio of SpatialCog for final refinement. The curriculum spans 36,000 training iterations, with stage-specific sampling ratios and learning rates.

We train the joint model on 64 NVIDIA H100 GPUs, with approximately 40,000 iterations of DINO-only pretraining followed by 36,000 iterations of joint DINO-flow training. We use the AdamW optimizer with a global batch size of 64 packed sequences, each containing at most 55,296 tokens. An exponential moving average (EMA) of the model parameters is maintained throughout training, and the EMA weights are used for evaluation. 

B.4 Inference Setup 

During inference, we use the EMA weights of the jointly trained model to generate future visual representations and 3D object flow, conditioned on the initial observation, 3D object query points, and language instruction. We employ the UniPC solver with 3 sampling steps and a classifier-free guidance (CFG) scale of 1.2. To facilitate few-step inference, we adopt smaller noise shifts to provide more balanced coverage of the denoising trajectory. We further set the visual representation shift lower than the flow shift, enabling progressively refined future visual states to guide 3D object flow generation. Finally, the generated visual latents are decoded into DINO features using the frozen DINO-VAE decoder, while the predicted 3D object flow is rescaled and added to the initial 3D point coordinates to recover future object trajectories. 

C Experimental Details 

C.1 Datasets and Benchmarks Datasets. We collect a total of 967,377 video clips from 11 data sources, spanning simulated environments, real-world internet videos, and in-house recordings. We organize the data into three groups: Sim7 ,comprising seven simulation datasets (RoboTwin, Meta-World, ManiSkill, RoboCasa, MIKASA, RLBench, and MetaFold); Real3 , comprising three real-world datasets (AgiBot World, Something-Something v2, and EPIC-KITCHENS); and SpatialCog , an in-house real-world dataset with calibrated camera parameters. The detailed data composition is summarized in Table V. To prevent data leakage, we exclude evaluation clips from the training set. For 3D object flow supervision, Sim7 directly uses ground-truth 3D motion provided by simulators, while 3D object trajectories in Real3 and SpatialCog are estimated from RGB videos using SAM 2 and Track4World. Specifically, we first segment the target object using SAM 2 and sample query points on its visible surface in the initial frame. We then track these points using Track4World and transform the reconstructed 3D points and their trajectories into the initial camera coordinate system using depth, camera intrinsics, and camera poses. All samples are associated with undistorted pinhole camera intrinsics. Sim7 provides ground-truth 3D geometry from simulators, SpatialCog provides calibrated camera parameters, and Real3 primarily relies on monocular estimation for 3D geometry. Beyond 3D object flow generation, we evaluate the representation capabilities of DINO-VAE on additional datasets. For depth estimation and semantic segmentation, we use held-out robotic manipulation videos. For video representation evaluation, we use UCF101 following the evaluation protocol of DINOv3.

C.2 Evaluation Metrics 3D Object Flow. We evaluate 3D object flow generation using Average Displacement Error (ADE), Final Displacement Error (FDE), and Percentage Within Threshold (PWT). ADE measures the mean 3D Euclidean position error across all query points and timesteps, while FDE measures the mean position error at the final timestep. PWT measures the fraction of point-frame predictions within distance thresholds of 1, 2, and 5 cm, averaged across the three thresholds. ADE and FDE are reported in meters. All metrics are computed over the prediction horizon and then averaged across clips within each evaluation group. 

Depth and Semantic Segmentation. For depth estimation, we report Absolute Relative Error (AbsRel), Root Mean Squared Error (RMSE), and δ1. AbsRel measures the mean absolute relative depth error, RMSE measures the root mean squared depth error, and δ1 denotes the fraction of pixels with a predicted-to-ground-truth depth ratio within a factor of 1.25. For semantic segmentation, we report mean Intersection over Union (mIoU), averaged across five semantic classes. 

Visual Representation Evaluation. Following the DINOv3 evaluation protocol, we assess the semantic structure of visual representations using top-1 classification accuracy on UCF101. We report results under two inference settings: Single and test-time augmentation (TTA). Single uses a deterministic temporal sampling strategy covering the first and last frames, with uniformly spaced intermediate frames, and a central square crop. TTA averages the predicted class probabilities across six views, constructed from three spatial crops and two temporally interleaved frame sequences.  

> 22 C.3 Baselines

C.3 Baselines 

We compare MotionRep against three categories of baselines: video-generation-and-tracking pipelines that estimate 3D motion from generated videos, direct-flow methods that predict future 3D trajectories without explicit RGB video generation, and joint visual-flow generation methods that model future visual states and 3D motion together. All methods are evaluated under the same conditioning setting, using a single initial observation, a natural-language task description, and initial 3D query points. 

Video Generation and 3D Tracking. NovaFlow (Li et al., 2025) generates future videos conditioned on the initial observation and task description, and subsequently extracts actionable 3D object flow using off-the-shelf perception modules. Cosmos3-Nano + Track4World combines Cosmos3-Nano (NVIDIA, 2026) for future RGB video generation with Track4World (Lu et al., 2026a), a feed-forward world-centric 3D tracker, to recover 3D point trajectories. Cosmos3-Nano + 4RC replaces Track4World with 4RC (Luo et al., 2026), which reconstructs 3D geometry and motion from generated monocular videos. LingBot-Video-MoE + Track4World uses LingBot-Video-MoE (Ma et al., 2026) for autoregressive video generation, followed by Track4World for 3D trajectory estimation. LingBot-Video-MoE + 4RC similarly combines LingBot-Video-MoE with 4RC for 3D motion reconstruction. These methods estimate 3D motion through an intermediate video-generation stage, making their performance dependent on both video generation and subsequent 3D tracking or reconstruction. 

Direct Flow Generation. MolmoMotion-AR (H1) (Zhang et al., 2026) autoregressively predicts language-conditioned 3D point trajectories by representing coordinates as discrete tokens. μ0 (Lee et al., 2026) directly models future trajectories of semantic interaction points in a normalized, anchor-relative 3D trace space. EgoWAM (Li et al., 2026a) models future dynamics beyond pixels, including a 3D-flow variant that predicts camera-stabilized 3D motion. Unlike video-generation-and-tracking pipelines, these methods directly predict geometric motion without generating RGB videos. 

Joint Visual and Flow Generation. WorldFlow (Lu et al., 2026b) jointly models future RGB video and 3D object flow within a unified generative framework, serving as the most directly comparable baseline to MotionRep. 

C.4 DINO-VAE Evaluation Protocols Latent Semantic Probing. To assess the semantic information retained in compressed DINO-VAE latents, we follow the DINOv3 evaluation protocol and perform linear probing on UCF101. Specifically, we apply spatial and temporal pooling to the video representations extracted by each model to obtain video-level feature vectors, which are then passed through LayerNorm and a single linear classifier for video classification. The classifier is trained for 20 epochs using cross-entropy loss. Under the same evaluation protocol, we compare the original DINOv3-L features, DINO-VAE latents, and video VAE latents from CogVideoX and Wan2.2 to evaluate their ability to preserve high-level semantic information. 

Depth Decoder. We evaluate the quality of reconstructed DINO features and compressed DINO-VAE latents using MSE, cosine similarity, and frozen downstream decoder to assess the preservation of geometric and semantic information. The depth decoder is a lightweight convolutional network with 0.63M parameters, taking only the last-layer DINO feature as input. It constructs four feature scales from a single feature and progressively fuses them through top-down upsampling, producing a single-channel positive depth map at the input image resolution. The training objective combines a disparity-space data term, a scale-invariant logarithmic loss, a gradient loss, and an edge loss, with larger weights assigned to the latter two to improve depth boundary preservation.  

> 23 C.5 Out-of-Distribution Evaluation Protocol

Segmentation Decoder. The segmentation decoder employs a lightweight decoder with 0.76M parameters. It constructs multi-scale features from the same DINO feature through four parallel projection branches and fuses them to produce per-pixel semantic predictions. The segmentation task comprises five classes: background, table, robot, clutter, and the currently manipulated object. The training objective combines equally weighted cross-entropy and Dice losses, with inverse-frequency class weights computed from the training split to mitigate class imbalance. 

RGB Decoder. We adopt a lightweight ViT RGB decoder (Zheng et al., 2026), initialized from a pretrained RAE pixel decoder and subsequently fine-tuned on our data, to map the last-layer DINO features back to pixel space. When reconstructing future RGB frames, we further introduce a lightweight first-frame reference module that leverages high-frequency information from the initial RGB frame to recover texture details not fully preserved in DINO features, thereby improving the visual quality of reconstructed videos. 

PCA Visualization. We apply principal component analysis (PCA) to visualize the spatial structure of DINO-VAE latents. Specifically, we project the latent features onto the first three principal components and map them to the RGB channels to obtain spatial feature visualizations. Regions with similar colors correspond to more similar representations in the projected feature space, providing a qualitative view of the spatial structure preserved after temporal and channel compression. 

C.5 Out-of-Distribution Evaluation Protocol 

To further assess the out-of-distribution (OOD) generalization of MotionRep, we evaluate it on RoboMIND 2.0, a dataset entirely excluded from training. This dataset encompasses diverse manipulation scenes and tasks unseen during training, enabling us to assess the model’s ability to predict 3D object motion under distribution shifts. We select 200 video clips from RoboMIND 2.0 and follow the same evaluation protocol, metrics, and settings as WorldFlowBench. The results are reported in main paper. 

C.6 Inference Efficiency Details 

To ensure a fair and reproducible evaluation of inference efficiency, we conduct all measurements on an NVIDIA H800 GPU with a batch size of 1. We select 50 samples from each of the three WorldFlowBench evaluation groups, Sim7, Real3, and SpatialCog, and use the same samples to evaluate all methods. We compare inference efficiency against several baseline methods that achieve strong performance in 3D object flow generation.

We provide additional qualitative results of jointly generated future DINO representations and 3D object flow across diverse manipulation scenarios. D.3 Bidirectional Dynamics Inference 

Beyond joint generation, we further provide qualitative results for visual-conditioned inverse dynamics and flow-conditioned forward dynamics to examine the bidirectional conditional dependencies between future visual states and object motion. 

Flow-Conditioned Forward Dynamics. For forward dynamics inference, we provide ground-truth 3D object flow as a condition and generate the corresponding future DINO representations. As the object moves, the generated DINO features capture its spatial changes in a manner consistent with the ground-truth DINO features, while preserving the relatively stable background structure. 

Visual-Conditioned Inverse Dynamics. For inverse dynamics inference, we provide ground-truth future DINO representations as conditions and generate the corresponding 3D object flow. As shown in Fig. VIII, the predicted trajectories exhibit strong agreement with the ground truth in motion direction, temporal evolution, and overall displacement across real-world and simulated manipulation scenarios. In scenes involving object movement and robotic interactions, MotionRep effectively infers 3D motion from the spatial changes encoded in future visual representations. These results indicate that future DINO representations not only describe scene states but also provide informative conditions for object-centric motion inference.
