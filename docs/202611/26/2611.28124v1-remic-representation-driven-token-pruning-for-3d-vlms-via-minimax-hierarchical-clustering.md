## Abstract
3D vision-language models (3D VLMs) have demonstrated strong capabilities in 3D scene understanding and spatial reasoning. However, their reliance on multi-view inputs produces long visual token sequences, imposing substantial computational overhead during inference. Existing pruning methods often rely on token salience or feature diversity as proxies for representativeness, without explicitly modeling the representation gap between the original token set and the retained subset, thereby leading to suboptimal representation of the original scene. In this paper, we propose ReMiC, a training-free, representation-driven token pruning framework based on minimax hierarchical clustering. ReMiC treats retained tokens as prototypes for the original observations, formulating pruning as minimizing the maximum representation error under a fixed token budget. Local prototype initialization allocates tokens according to regional representation needs, while global prototype refinement updates the selected prototypes using cross-region information to further reduce the maximum representation error. Extensive experiments conducted on three representative 3D VLMs across five 3D scene understanding benchmarks demonstrate the effectiveness and generalization of our method. Notably, by retaining only 10% of visual tokens, ReMiC preserves 93.2% of the performance of Video-3D LLM and achieves a $2.04\times$ faster inference speed.
