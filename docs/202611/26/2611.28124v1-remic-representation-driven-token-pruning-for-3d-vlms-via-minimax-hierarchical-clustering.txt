Abstract
3D vision-language models (3D VLMs) have demonstrated
strong capabilities in 3D scene understanding and spatial
reasoning.
However, their reliance on multi-view inputs
produces long visual token sequences, imposing substantial
computational overhead during inference. Existing prun-
ing methods often rely on token salience or feature diversity
as proxies for representativeness, without explicitly model-
ing the representation gap between the original token set
and the retained subset, thereby leading to suboptimal rep-
resentation of the original scene. In this paper, we propose
ReMiC, a training-free, representation-driven token prun-
ing framework based on minimax hierarchical clustering.
ReMiC treats retained tokens as prototypes for the orig-
inal observations, formulating pruning as minimizing the
maximum representation error under a fixed token budget.
Local prototype initialization allocates tokens according to
regional representation needs, while global prototype re-
finement updates the selected prototypes using cross-region
information to further reduce the maximum representation
error. Extensive experiments conducted on three represen-
tative 3D VLMs across five 3D scene understanding bench-
marks demonstrate the effectiveness and generalization of
our method. Notably, by retaining only 10% of visual to-
kens, ReMiC preserves 93.2% of the performance of Video-
3D LLM and achieves a 2.04× faster inference speed.
1. Introduction
Recent 3D vision-language models (3D VLMs) have
demonstrated strong performance in 3D scene understand-
ing, showing promise for applications in autonomous driv-
ing and embodied intelligence [13, 16, 18, 30, 41]. Given
the scarcity of annotated 3D data, 3D VLMs [12, 19, 22, 34,
40] usually build upon pretrained video-language models to
leverage visual priors learned from large-scale 2D data, us-
ing multi-view images as visual inputs. However, process-
ing these inputs introduces a major computational bottle-
neck: the number of visual tokens grows linearly with the
number of input views. For example, Video-3D LLM [41]
encodes 32 input views into 6,272 visual tokens, substan-

Visual token pruning aims to retain a compact subset that
faithfully represents the original visual input. Attention-
based methods [7, 25, 33, 35, 38] estimate token salience
from attention scores and prioritize highly attended tokens,
while diversity-based methods [1, 3, 15, 31, 36] select to-

dancy. Both approaches rely on proxies for representative-
ness, without directly evaluating how well the retained sub-
set represents the original observations. In multi-view 3D
scenes, attention ranking can overlook cross-view redun-
dancy and concentrate the token budget on repeated obser-

vations of a few salient regions, leaving other regions un-
derrepresented [17]. Maximizing feature separation can fa-
vor outliers in feature space while discarding representative
tokens that capture dominant visual patterns [21]. Such se-
lection biases leave parts of the scene poorly represented,
limiting the visual evidence available for object localization
and spatial reasoning.
To address this issue, we explicitly model the represen-
tation gap between the original token set and the retained
subset. We treat the retained tokens as prototypes, with ev-
ery original token assigned to one of them. As illustrated in
Fig. 1, observations of the same local scene region across
views are represented by a shared retained prototype. Each
token’s representation error is defined as the joint feature-
spatial distance to its prototype, capturing differences in
both visual content and 3D position. To keep all original
tokens close to their prototypes, we aim to minimize the
maximum representation error under a fixed token budget.
Building on this formulation, we propose ReMiC, a
training-free, two-stage framework for visual token prun-
ing via minimax hierarchical clustering [4]. Local prototype
initialization builds a minimax tree independently in each
spatial region to provide candidate representations at differ-
ent granularities. These trees are jointly cut under a shared
token budget to minimize the maximum representation er-
ror, retaining finer representations where coarser grouping
incurs larger errors. Global prototype refinement then up-
dates the selected prototypes using cross-region information
to further reduce the maximum representation error.
Extensive experiments have been conducted on five 3D
scene understanding benchmarks [2, 6, 10, 23, 37] and
three representative 3D VLMs [9, 29, 41]. ReMiC consis-
tently achieves the best average performance among exist-
ing token pruning methods across all evaluated token bud-
gets. Notably, with only 10% of the visual tokens retained,
ReMiC preserves 93.2% of the original performance on
Video-3D LLM, while achieving a 6.72× prefill speedup
and a 2.04× end-to-end inference speedup.
Our contributions are summarized as threefold:
• We explicitly model the representation gap between the
original and retained token sets, and formulate visual to-
ken pruning as minimizing the maximum representation
error under a fixed token budget.
• We propose ReMiC, a training-free, two-stage framework
for visual token pruning via minimax hierarchical clus-
tering. Local prototype initialization adaptively allocates
prototypes across scene regions, while global prototype
refinement improves prototype selection by incorporating
cross-region information.
• Extensive experiments across three 3D VLM backbones
and five scene understanding benchmarks show that
ReMiC maintains strong task performance under aggres-
sive pruning while substantially accelerating inference.
2. Related Work
2.1. 3D Vision-Language Models
Recent advances in vision-language models have spurred
growing interest in extending their capabilities to 3D scene
understanding [11, 13, 16, 42]. Early approaches equip lan-
guage models with 3D understanding through point-cloud
encoding or object-centric scene representations [8, 14, 27,
32].
Given the scarcity of 3D–language paired data, a
growing line of work [12, 19, 22, 34] has explored adapt-
ing pretrained video-language models for 3D scene under-
standing, thereby leveraging rich visual priors learned from
large-scale 2D data. For example, Video-3D LLM [41] and
LLaVA-3D [43] incorporate 3D positional embeddings into
multi-view visual features, grounding observations across
views in a shared 3D coordinate system. To further enhance
spatial understanding, VG-LLM [40] and GS-Reasoner [9]
incorporate geometric features from pretrained 3D encoders
into visual representations. Meanwhile, Ross3D [29] in-
troduces cross-view and global-view reconstruction objec-
tives to provide 3D-aware visual supervision during train-
ing. Despite the rapid progress of 3D VLMs, they still face
substantial inference overhead due to the long visual token
sequences generated by multi-view inputs.
2.2. Visual Token Pruning
Visual token pruning offers an effective way to reduce VLM
inference costs by compressing visual sequences while pre-
serving essential information [44–46].
Existing methods
can be broadly categorized into two groups.
The first
is attention-based pruning, which prioritizes visual tokens
with high attention scores. For example, FastV [7] uses at-
tention scores from an early LLM decoder layer to remove
low-scoring visual tokens from subsequent layers, while Vi-
sionZip [33] uses vision encoder attention to select dom-
inant tokens and merges the remaining tokens into con-
textual tokens based on feature similarity. The second is
diversity-based pruning, which seeks to reduce redundancy
in the retained set by selecting visual tokens that are dis-
similar in feature space. In this category, DivPrune [1] aims
to maximize the minimum pairwise feature distance among
retained tokens, while DART [31] selects a small set of vi-
sual and text tokens as pivots and retains visual tokens with
low cosine similarity to these pivots.
Recent work extends visual token pruning to multi-view
3D scenes by incorporating geometric information to guide
token selection across views. DTC [15] removes redun-
dant tokens through feature matching within progressively
enlarged voxels. Geo3DPruner [17] uses geometry-aware
global attention to guide intra- and inter-voxel selection,
while Merge3D [25] selects dominant tokens using 2D at-
tention and merges the remaining tokens based on semantic
and geometric similarity.

3. Method
We first describe visual token construction in 3D VLMs
(Sec. 3.1) and formulate visual token pruning via minimax
hierarchical clustering (Sec. 3.2). Building on this formula-
tion, we present ReMiC, a training-free, two-stage frame-
work for visual token pruning that aims to minimize the
maximum representation error across the scene (Fig. 2). Lo-
cal prototype initialization (Sec. 3.3) adaptively allocates
tokens across scene regions according to their representa-
tion needs. Global prototype refinement (Sec. 3.4) then up-
dates the selected prototypes using cross-region information
to further reduce the maximum representation error.
3.1. Preliminaries
We consider multi-view 3D VLMs that take RGB images,
depth maps, and camera parameters as inputs to construct
spatially grounded visual tokens for LLM inference. The
3D VLM extracts patch-level features from RGB images
using a vision encoder, projects them into the LLM embed-
ding space, and applies spatial pooling to obtain N visual
features fi ∈Rd. Using depth maps and camera parame-
ters, the model maps visual observations into a shared world
coordinate system, assigning each token a 3D coordinate
xi ∈R3. The backbone then applies a spatial encoding
function ϕ(·) to obtain the spatial feature si = ϕ(xi) ∈Rd,
which is combined with the visual feature to yield the fused
token representation zi = fi + si ∈Rd.
We represent each 3D visual token as vi = (zi, xi),
forming the scene token set V = {vi}N

3.2. Minimax Formulation for Token Pruning
We formulate visual token pruning as minimax hierarchical
clustering [4], with each retained token serving as a proto-
type for a cluster of original tokens. We aim to minimize
the maximum representation error across these clusters.
Joint Feature–Spatial Distance.
To preserve both visual
content and spatial structure during pruning, we define a
joint distance for minimax hierarchical clustering. Specifi-
cally, we measure feature dissimilarity with cosine distance
and spatial separation with Euclidean distance:
df(vi, vj)=1 −cos(zi, zj), dx(vi, vj)=∥xi −xj∥2. (2)

Token Pruning Objective.
Given a token budget B, we
cut the minimax tree to obtain B disjoint clusters that col-
lectively cover all original tokens. Let C denote these clus-
ters, each represented by its prototype pC.
The largest

R(C) = max
C∈C r(C).

Intuitively, R(C) asks whether the prototypes adequately
represent even the worst-represented parts of the scene, pro-
viding a uniform upper bound on the representation error of
every original token. Keeping this bound small therefore
guarantees that all scene regions are well represented. To
achieve low error, a few prototypes may suffice for regions
with limited variation, but regions with greater spatial or
feature variation may require more. Reducing R(C) thus fa-
vors allocating more prototypes to regions that require finer
representation, while allowing simpler regions to be repre-
sented with fewer. This promotes spatial coverage while
adapting representation granularity to local scene complex-
ity. Given these properties, we aim to minimize R(C) under
a fixed token budget.
3.3. Local Prototype Initialization
Stage 1 constructs local minimax trees to organize candi-
date clusters at different granularities, then jointly cuts these
trees to obtain B initial prototypes.
Local Tree Construction.
We sort the tokens by their
Morton codes [24] and evenly partition the resulting se-
quence into L groups, where L ≤B. Tokens adjacent in
this order tend to be proximal in 3D space, allowing con-
tiguous segments of the sequence to serve as local scene
regions. A minimax tree is then built independently within
each region as described in Sec. 3.2. This design improves
computational efficiency through parallel tree construction
and balanced workloads, while preserving downstream task
performance by maintaining spatial locality.
Adaptive Tree Cutting.
A natural approach to initializ-
ing B prototypes is to allocate equal budgets to regions and
cut their trees independently. However, regions with differ-
ent levels of complexity may require different numbers of
prototypes, so we jointly cut these trees to allocate the bud-
get adaptively. Let F denote the valid cuts of the local trees
into B disjoint clusters covering all original tokens. The
optimal cut satisfies

3.4. Global Prototype Refinement
The regional partitioning in Stage 1 confines each prototype
to representing tokens within its own region. However, to-
kens in one region may be better represented by a prototype
in another. Stage 2 therefore reorganizes clusters globally
and reselects their prototypes to further reduce the maxi-
mum representation error across the scene.

4. Experiments
4.1. Experimental Settings
Benchmarks.
We evaluate ReMiC on five 3D scene un-
derstanding benchmarks: ScanRefer [6] for single-object
visual grounding, Multi3DRefer [37] for multi-target vi-
sual grounding, Scan2Cap [10] for 3D dense captioning,
ScanQA [2] for 3D spatial understanding, and SQA3D [23]
for situated reasoning conditioned on a specified position
and orientation. Together, these benchmarks cover three key
3D scene understanding tasks: object localization, scene
description, and spatial reasoning. We follow the standard
evaluation settings and metrics for each benchmark.
Baselines.
We compare ReMiC with five state-of-the-art
visual token pruning methods: 1) VisionZip [33], which se-
lects dominant tokens using attention scores and merges the
remaining tokens into contextual tokens; 2) DivPrune [1],
which formulates token selection as a max-min diversity
problem (MMDP) [26]; 3) V-CAST [20], which allocates
frame budgets using temporal curvature and selects to-
kens with dual spatial anchors; 4) 3DZip [3], which com-
bines voxel aggregation, diversity-based anchor selection,
and spatially constrained token merging; and 5) CoVeR [5],
which selects tokens based solely on 3D coordinates to
maximize spatial coverage.

4.2. Main Comparison
Comparison on Video-3D LLM.
As shown in Table 1,
ReMiC achieves the best aggregate performance at every
token budget. This consistency aligns with our minimax
tree design, which adapts representation granularity to the
available token budget. In contrast, 3DZip is less compet-

aggregation may prematurely discard fine-grained details
that could otherwise be preserved. At 10% token retention,
ReMiC retains 93.19% of the original performance on aver-
age, compared with 90.19% for VisionZip and 91.38% for

represent the original token set preserves scene information
more effectively under aggressive pruning than prioritizing
token importance or feature diversity. ReMiC also consis-
tently outperforms CoVeR on average, supporting the value
of minimizing representation error in both feature and spa-
tial domains rather than optimizing spatial coverage alone.

demonstrating that ReMiC can adapt to diverse 3D fea-
ture representations. In contrast, V-CAST exhibits substan-

4.4. Qualitative Results
As shown in Fig. 3(a), ReMiC maintains consistently
low maximum representation errors with small fluctuations
across frames, whereas DivPrune and VisionZip exhibit
higher errors and pronounced variations. The higher errors
indicate that parts of the scene are poorly represented, while
the large fluctuations reveal uneven representation quality
across views, suggesting that the token budget favors certain
regions while leaving others underrepresented. Fig. 3(b)
further visualizes the spatial distribution of retained tokens.
VisionZip tends to concentrate the token budget on back-
ground and floor regions, missing critical local objects. Di-
vPrune retains scattered tokens across the scene but fails to
preserve fine-grained details of small or structurally com-
plex objects. By comparison, ReMiC maintains broad spa-
tial coverage while preserving more complete object struc-
tures and local details. Together, these observations high-
light the importance of selecting tokens based on how well
they represent the original scene, rather than relying solely
on salience or feature diversity.

4.5. Efficiency Analysis
Table 6 compares the efficiency and accuracy of ReMiC,
3DZip, and DivPrune on ScanQA using a single NVIDIA
RTX 3090 GPU under identical settings. Pruning, Prefill,
E2E, and Memory denote token pruning overhead, prefill
latency, end-to-end latency, and peak reserved GPU mem-
ory, respectively. At 10% token retention, ReMiC achieves
6.72× and 2.04× speedups in prefill and E2E inference,
respectively, while reducing peak reserved GPU memory
by 7.8% compared with the base model. Benefiting from
parallel local tree construction, ReMiC requires 20.5% less
pruning time than 3DZip while improving EM by 0.49
points. Notably, while the pruning overhead of both base-
lines varies with the retention budget, ReMiC maintains
nearly constant overhead, enabling a flexible trade-off be-
tween efficiency and accuracy.
5. Conclusion
We introduce ReMiC, a training-free, representation-driven
token pruning framework for 3D VLMs based on mini-
max hierarchical clustering. ReMiC combines local proto-
type initialization for adaptive token allocation across spa-
tial regions with global prototype refinement to incorporate
cross-region information. By explicitly modeling the repre-
sentation gap between the original and retained token sets,
ReMiC preserves scene-level coverage and fine-grained de-
tails. Experiments across three 3D VLMs and five 3D scene
understanding benchmarks demonstrate that ReMiC consis-
tently outperforms existing pruning methods while substan-
tially accelerating inference.
