# Mesh-Free Keypoint Learning for Category-Level 6D Object Pose Estimation 

Junghoon Seo *, Hakjin Lee, and Jaehoon Sim 

PIT IN Corp., South Korea 

Abstract — Category-level 6D pose estimation relates partial RGB-D observations of unseen instances to a canonical frame shared across a category. Object-aware reconstruction helps adaptive keypoints retain the geometry of the visible surface. Common reconstruction targets select observed points by their distance to a registered instance surface. We present MORSE-Pose, which derives this support directly from standard pose and metric-size annotations. We map observed 3D points to normalized object coordinates and retain those inside a tolerance-dilated pose-and-size envelope. This construction is consistent across camera frames and metric scales. When the annotated extent bounds the object surface, the envelope conservatively contains the support of a conventional surface-distance selector. We integrate this target with multi-level RGB-D features, adaptive keypoints, and learnable category context. Experiments on REAL275 and HouseCat6D show that the envelope closely matches surface-based supervision at both point and task levels, remains stable under boundary perturbations and viewpoint changes, and supports competitive category-level pose accuracy across benchmarks. 

I. I NTRODUCTION 

Robotic manipulation requires a stable object-centered reference frame for reasoning about grasps, placements, contacts, and tool motion. Instance-level pose estimation obtains this frame by aligning an observation to a known object model [1], [2]. Category-level 6D pose estimation addresses a broader setting by predicting rotation, translation, and metric size for an unseen instance of a known category in a shared canonical frame [3]–[5]. A successful estimator must establish the same semantic axes across substantial variation in shape, appearance, viewpoint, and visibility. This capability allows a robot to transfer an interaction strategy to a novel mug, bottle, or tool without first acquiring its exact geometry. Category-level pose estimation is both a geometric es-timation problem and a representation learning problem. An RGB-D crop records the object surface visible from one viewpoint and can include points from supporting surfaces or the background. Organizing the visible geometry in a category-consistent frame helps relate corresponding parts across instances. Adaptive 3D keypoints provide an effective interface for this purpose [6]–[9], aggregating dense observations into a compact, instance-conditioned structure that supports correspondence-based reasoning across intra-category shape variation. Object-aware reconstruction provides complementary su-pervision by encouraging this intermediate representation to retain the measured structure from which pose is inferred,

Standard annotations also describe where to select points for reconstruction. Pose defines the canonical frame, and metric size gives the extent along each axis. We use these annotations to construct a pose-and-size envelope. Each observed 3D point is mapped to normalized object coordinates using the annotated pose and size, and it contributes to reconstruction when it lies inside the annotated extent after each face is dilated by an object-normalized tolerance. The support follows the orientation and anisotropic extent of the instance, and canonicalization gives the tolerance a consistent meaning across camera frames, categories, and metric scales. When the annotated extent bounds the object surface, the dilated envelope contains every point a surface-distance criterion selects, extending support to nearby measurements around concavities and interiors. MORSE-Pose, short for Mesh-free Object-aware Recon-struction via pose-and-Size Envelopes, integrates this su-pervision with an adaptive RGB-D keypoint estimator in which multi-level visual features, geometric evidence, and learnable category prototypes shape keypoints that support correspondence prediction, pose and size estimation, and observed-surface reconstruction, while inference uses only the RGB-D crop and category label. Our evaluation connects the supervision geometry to the final task through point-level audits, matched target substitutions, robustness and cross-view studies, ablations, and efficiency comparisons. A. Category-Level 6D Pose Estimation 

Pose estimators use different geometric references at inference. Instance-level methods align observations to a known object model [1], [2]. Generalizable methods use reference views or a mesh of a novel object [10], [11]. NOCS [3] established the category-level setting by mapping observations of unseen instances into a shared canonical space to estimate pose and metric size jointly. Methods differ in how they connect an observation to this canonical space. Shape-prior approaches deform a learned category template toward the observed instance [4], [8], [12], [13], providing complete category-level shape con-text. Observation-driven approaches infer canonical structure directly from RGB-D through decoupled rotation estima-tion [5], [15], geometry-guided voting [16], hybrid-scope point features [17], implicit canonical transformations [18], sparse pose queries [19], transformer aggregation [20], SE(3)-consistent RGB-D fusion [21], and spherical or correspondence-centric representations [22], [23]. MORSE-Pose follows the observation-driven setting and focuses on how object-aware reconstruction can be supervised from category-level pose annotations. 

B. Adaptive Keypoints and Shape-Aware Learning 

Sparse keypoints provide a compact bridge between ob-served and canonical geometry. AG-Pose [6] learns instance-adaptive keypoints from point clouds and enriches them with local and global geometric relations. Subsequent work incorporates causal feature adjustment and multimodal distilla-tion [7], additional sensing modalities [24], stronger category context [8], category-specific optimization [25], progressive shape completion [9], and memory over previously observed instances [14]. Reconstruction and completion objectives provide comple-mentary geometric supervision. Dense canonical rendering and complete-shape prediction use geometric assets to define targets on an object surface. For object-aware reconstruction, the target consists of measured points in the RGB-D crop. MORSE-Pose uses pose and metric size to select the points that guide the keypoint representation. III. At inference, MORSE-Pose receives an RGB-D crop and category label and directly predicts pose and size. IV. E XPERIMENTS 

A. Experimental Setup 

Datasets and metrics. We evaluate on NOCS REAL275 [3], which contains six categories and uses the synthetic CAMERA25 split for joint training, and on HouseCat6D [31], which spans ten household categories with diverse scenes, viewpoints, materials, and occlusion. Instance masks follow the protocol shared by recent methods: REAL275 inference uses the segmentation results released by prior work [12], whereas HouseCat6D is trained and evaluated with the ground-truth masks the benchmark provides. We report average precision for 3D intersection over union and the joint thresholds 5◦2 cm , 5◦5 cm , 10 ◦2 cm ,and 10 ◦5 cm , with symmetric categories handled according to each benchmark. REAL275 IoU 75 follows the corrected CATRE protocol [32], consistent with recent comparisons. 

Training protocol. MORSE-Pose is trained from RGB-D observations, instance masks, category labels, pose, and metric size. Unless noted, models use N =1 ,024 sampled points, K=96 keypoints, and τ =0 .1. The benchmark models use 336 ×336 RGB crops and are trained for 55 epochs on REAL275 and 140 epochs on HouseCat6D. Controlled target studies share a fixed reference estimator, identical schedules, and three random seeds. The reference configuration reaches
