## 摘要
事件相机能够在传统相机出现模糊或饱和时持续捕捉场景结构，因此适用于快速运动或光照不佳场景中的三维感知。然而，具有稠密三维真值标注的事件数据集，其规模和多样性都远不及支撑前馈式三维重建模型的图像数据集。我们提出 Déjà-Events，这是一种仅使用事件数据的模型，可在一次前向传播中根据多个视角预测深度、相机位姿和点图。它不依赖稀缺的三维标签，而是从 Déjà View 蒸馏而来；Déjà View 是一个前馈式 RGB 模型，通过反复应用同一个共享 Transformer 模块来逐步细化其 token。在配对的 RGB 与事件记录上，事件学生模型学习复现冻结教师模型的最终 token，无需深度或位姿真值标注，且训练参数仅约占其总参数的 1%。由于事件在边缘和运动纹理处密集，而在无纹理区域几乎缺失，我们进一步提出稀疏性感知自适应门控机制：该机制使共享模块的门控适应事件信号，并根据事件密度按图像块进行调整，从而确保随着细化步数增加，模型仍能保持准确性。仅在模拟数据上训练的 Déjà-Events，在 EventScape 以及真实数据集 MVSEC 和 DSEC 的零样本测试中，均取得了我们评估的事件视觉方法中最低的点图误差。在 DSEC 上，其误差仅为最强基线的一半（AbsRel 为 0.15，对比 0.30），参数量约为基线的十分之一。此外，它在 EventScape 和 DSEC 上的深度误差最低，在 EventScape 上的轨迹误差也最低。

## Abstract
Event cameras keep capturing structure where conventional cameras blur or saturate, which makes them attractive for 3D perception in fast or poorly lit scenes. Event datasets with dense 3D ground truth, however, are far smaller and less diverse than the image collections behind feed-forward 3D reconstruction models. We present Déjà-Events, an event-only model that predicts depth, camera pose and pointmaps from multiple views in a single forward pass. Rather than relying on scarce 3D labels, we distil it from Déjà View, a feed-forward RGB model that refines its tokens by repeatedly applying one shared transformer block. On paired RGB and event recordings, the event student learns to reproduce the frozen teacher's final tokens, which requires no depth or pose ground truth and trains only about 1% of its parameters. Because events are dense at edges and moving texture but nearly absent in textureless regions, we further introduce sparsity-aware adaptive gating, which adapts the shared block's gates to events and adjusts them per patch by event density, so that accuracy holds as refinement steps are added. Trained only on simulated data, Déjà-Events achieves the lowest pointmap error among the event-based methods we evaluate, on EventScape and zero-shot on the real MVSEC and DSEC datasets. On DSEC it halves the error of the strongest baseline (0.15 vs. 0.30 AbsRel) with about a tenth of its parameters. It also has the lowest depth error on EventScape and DSEC and the lowest trajectory error on EventScape.

## 1. 核心问题与整体含义

- **研究问题**：如何在缺少大规模、带稠密三维真值的事件相机数据时，仅凭事件流实现多视角三维几何预测，包括深度、相机位姿和点图（pointmap）。
- **研究动机**：事件相机具有高时间分辨率和高动态范围，在快速运动、弱光或图像饱和时仍可能保留场景边缘与运动结构。但事件信号空间分布不均，且事件三维数据集规模较小，难以像 RGB 模型那样依靠大量三维标注训练。
- **整体思路**：把已有 RGB 多视角几何模型 Déjà View（DVLT）作为冻结教师，以配对的 RGB 帧和事件流作为蒸馏数据，让事件模型学习教师的中间几何表征；同时针对事件数据的稀疏性设计自适应门控，使模型的迭代细化能因图像块而异。

## 2. 方法论

### 2.1 整体架构与蒸馏

- 教师 DVLT 用 DINOv2 将多视角图像编码为 token，再反复调用同一个共享 Transformer 模块细化这些 token。模块包含视图内的帧注意力和跨视图的全局注意力，最终解码出相机、射线图和深度，并据此得到点图。
- 事件学生沿用教师的主要结构和冻结解码器，但以事件输入替代 RGB。训练目标不是深度或位姿真值，而是让学生在相同迭代步数 \(K\) 后，尽可能复现教师的最终 token：
  - 每次训练随机抽取 \(K\)，主要覆盖 8–16 步；
  - 损失结合 token 方向的余弦距离和幅值加权的 \(L_1\) 距离；
  - 因为教师解码器固定，学生学会匹配教师 token 后，便可通过同一套解码器产生几何预测。
- 学生只训练约 **160 万参数**，约占模型总参数的 1%；主要通过 LoRA 适配器调整 DINOv2 和共享模块，并训练事件输入 stem，解码器保持冻结。

### 2.2 事件表示

- 将每个时间窗口内的事件累积为 **5 个时间分箱**的体素网格；事件极性分别以正、负值累计，并按图像范围归一化。
- 输入 stem 将其转换为 DINOv2 可接受的三通道表示：正极性累积、绝对极性累积、负极性累积。通道归一化参数从 ImageNet 归一化设置初始化后可学习。
- 该输入最终将时间分箱信息汇总，因此方法虽输入源自时序事件流，当前设计并未完整利用事件在窗口内的精细时间顺序。

### 2.3 稀疏性感知自适应门控（SAAG）

- 原始 DVLT 的门控只随递归步骤变化，对所有图像块使用相同的更新尺度。作者认为，这不适合事件图像：有些块事件密集，有些块近乎空白，不同区域可能需要不同程度的特征更新。
- SAAG 包含两部分：
  1. **微调步骤门控**：解冻共享模块中原有的门控网络，使其适应事件输入和递归细化过程。
  2. **增加图像块级修正**：计算每个 patch 的事件密度，并将该密度与当前步骤的时间间隔编码输入小型 MLP，预测注意力和 MLP 更新门控的修正量。
- 修正项按 patch 调整原门控，使事件密集或稀疏区域能够采用不同的更新强度；这些门控仍通过 token 蒸馏损失训练，不另加稀疏性损失。每个修正 MLP 有 2,114 个参数。
- 由于共享模块可重复运行，模型能在推理时改变细化步数，从而在计算量和预测质量间作权衡。论文还考察了超出训练步数范围时的表现。

## 3. 实验设计

### 3.1 数据集与场景

- **EventScape**：CARLA 仿真数据，输入分辨率为 \(512 \times 256\)，提供深度和位姿真值。模型在 Town01–Town03 上蒸馏，在 Town05 的 116 个测试序列上评估；深度截断到 200 米。
- **MVSEC**：真实事件相机数据，使用 4 个室外驾驶序列，包含白天和夜间场景；深度来自激光雷达，截断到 80 米。论文将其作为零样本真实数据测试。
- **DSEC**：真实驾驶数据。论文选用 10 个验证序列，深度由激光雷达提供，位姿伪真值由激光雷达里程计生成；深度截断到 50 米。模型同样未在 DSEC 上训练。

### 3.2 评测任务与指标

- **深度**：AbsRel（绝对相对误差）和 \(\Delta_1\)。
- **相机位姿**：ATE（绝对轨迹误差）和 \(AUC_{20}\)。
- **点图**：点图 AbsRel 和 Inl@25（相对误差不超过 25% 的点比例）。
- 每个序列被切分为不重叠的 18 帧窗口。对仅预测相对尺度和偏移的深度方法，评测时进行基于中位数的尺度与偏移对齐；位姿和点图使用 Sim(3) 对齐。部分模块化方法使用真实相机内参，而 Déjà-Events、教师和 EventVGGT 使用各自预测的内参。

### 3.3 对比方法

- 深度网络：E2Depth、EReFormer、Depth AnyEvent（DAE）及其循环版本 DAE-R。
- 多任务或事件几何方法：EventVGGT 的两种配置。
- 视觉里程计与组合方案：DEVO，以及将 DEVO 位姿与各深度网络组合的模块化管线。
- RGB 教师 DVLT 作为参考上限/参照，而不是事件方法的直接竞争者。

## 4. 资源与算力

- **训练设置**：EventScape 上训练 20,000 步，使用 2–18 视图的片段，LoRA rank 为 16；仅明确训练约 1.6M 参数。
- **推理计算量**：模型约 118.4M 总参数，每帧约 604.6 GFLOPs；相较教师 DVLT，计算量约高 1%，显存约高 2%。
- **硬件信息**：论文说明推理峰值显存是在 **NVIDIA A40** 上测量的，Déjà-Events 约需 1.65 GiB。文中没有明确给出 GPU 数量、训练所用硬件或训练总时长，因此无法据此完整复现训练资源消耗。
- EventVGGT 参数量约 1.16B，显存约为 Déjà-Events 的 2.5 倍；不同配置的计算量约为其 2–4 倍。部分模块化管线推理计算量接近或略低，但训练参数更多。

## 5. 实验数量与充分性

- 论文涵盖 **3 个数据集、3 类主要输出任务**（深度、位姿、点图），并进行跨仿真到真实场景的零样本评估。
- 主要结果表包括深度、位姿、点图及算力比较；另有：
  - SAAG 与门控设置的消融；
  - 递归步数 \(K\) 的变化实验，评估超出训练区间后的表现；
  - MVSEC 夜间场景实验，以及增加白天数据蒸馏后的分析。
- 总体上，跨数据集和任务的评测较有覆盖面，且不仅报告单一指标；不过，消融结果显示 SAAG 在默认 \(K=16\) 时的深度提升较小，主要价值更多体现在递归步数扩展时的稳定性。
- **公平性与可比性注意事项**：
  - RGB 教师使用图像输入，应视为参照而非事件输入基线。
  - 方法之间的输入、输出和后处理并不完全相同；尤其是部分模块化管线使用真实内参，而 Déjà-Events 使用预测内参。
  - DSEC 位姿伪真值由激光雷达里程计生成，不等同于统一来源的精确真值。
  - EReFormer 在 DSEC 上因输入位置编码限制而使用中心裁剪，其结果不可与其他方法严格直接比较，论文也未对其排名。
  - 深度尺度/偏移对齐及 Sim(3) 对齐会减弱部分绝对尺度或全局位姿差异，解释结果时需考虑评测协议。

## 6. 主要结论与发现

- 仅通过配对 RGB–事件记录进行 token 蒸馏，Déjà-Events 无需深度或位姿标注，即可从事件输入预测多视角深度、相机位姿和点图。
- 仅用模拟数据训练后，模型在真实 MVSEC 和 DSEC 上仍能零样本工作。
- 在论文评估的事件方法中，Déjà-Events 在 EventScape、MVSEC 和 DSEC 上均取得最低点图误差；在 EventScape 和 DSEC 上取得最低深度误差，在 EventScape 上取得最低轨迹误差。
- DSEC 上深度 AbsRel 为 **0.145**，约为最强事件基线 EventVGGT 的一半（0.282）；点图 AbsRel 为 **0.148**，也明显低于 EventVGGT Option A 的 0.301。
- 作者认为模型仍受 RGB 教师质量与相机内参预测误差影响；事件模型并不会在所有场景中自动超过教师。MVSEC 夜间场景中，RGB 质量下降时，学生在某些几何指标上可优于教师。
- SAAG 对默认步数下的指标提升有限，但有助于模型在增加递归步数时维持稳定表现，使步数成为更可用的计算调节选项。

## 7. 优点

- **缓解三维标注稀缺**：用冻结 RGB 教师的表征蒸馏训练事件模型，不依赖深度或位姿真值。
- **多任务统一预测**：在一次前向处理中输出深度、位姿与点图，而不是分别拼接多个专用模型。
- **与事件数据特性相适配**：SAAG 显式利用 patch 级事件密度调节特征更新，针对事件空间稀疏性设计，而非仅在损失层面考虑稀疏。
- **训练参数效率较高**：模型规模约 118M，但只训练约 1.6M 参数；相对于 EventVGGT，参数量约低一个数量级。
- **评测覆盖较广**：同时报告仿真和真实数据、不同几何任务以及资源指标，并分析夜间场景、相机内参与递归步数的影响。
- **结果分析较审慎**：论文区分教师参考与事件基线，也讨论了模型受教师输入质量和预测内参误差制约的现象。

## 8. 不足与局限

- **对教师的依赖**：学生目标是复现教师 token，教师在清晰、曝光良好的图像上所具有的几何优势也限定了学生可学习的上限；教师输入质量差时，蒸馏目标可能不可靠。
- **时间信息利用不足**：事件的 5 个时间分箱最终被汇总成三通道输入，窗口内“事件发生在何时”的信息没有充分保留，因此难以直接支持连续时间或帧间几何预测。
- **真实场景覆盖有限**：真实测试集中驾驶场景占主导，尚未充分验证无人机、快速转动、严重运动模糊等更能体现事件优势的场景。
- **相机内参存在明显误差**：论文指出某些数据集上的焦距预测偏差会显著影响点图质量；模型输出并非在所有场景都能稳定恢复准确内参。
- **绝对位姿表现并非全面领先**：在 MVSEC 和 DSEC 上，DEVO 的平移误差更低；事件 VGGT 的位姿预测也表现不佳，说明不同方法的位姿能力差异较大，整体几何表现不能只由点图指标概括。
- **部分实验可比性受限**：DSEC 位姿采用伪真值，个别基线使用裁剪输入，且不同方案在是否使用真实内参、尺度对齐方式上存在差别。
- **资源报告不完整**：虽报告 A40 上的推理显存和模型计算量，但没有明确说明训练 GPU 数量、训练耗时等，训练成本难以完全评估。
- **对 SAAG 的证据仍可加强**：默认步数下消融带来的误差改善较小；要更有力证明其普遍有效性，还需要更多数据集、不同事件密度条件及不同递归步数下的系统验证。
