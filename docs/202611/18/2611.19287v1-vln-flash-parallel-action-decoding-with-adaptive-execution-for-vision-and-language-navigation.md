## 摘要
当视觉与语言导航策略以自回归方式生成动作序列时，机器人必须等待一连串相互依赖的预测。离散动作词汇表较小，因此可以并行评估所有短时域规划。我们提出 VLN-Flash，这是一种无需训练的解码器，可在一次前向传播中评估完整的动作前缀树。通过分支特定的注意力机制和匹配的 token 位置，VLN-Flash 能在精确算术下保留原始策略针对每个前缀的条件动作分布。我们利用每个深度处逐步贪心前缀与其最强替代项之间的分数差，决定执行多少个动作。随后，机器人执行所选深度下联合得分最高的规划，然后再次进行观测。在匹配输入下，与 Uni-NaVid 和 StreamVLN 上的原生自回归解码相比，VLN-Flash 的动作解码速度提升近 3 倍。与原生自回归解码器相比，它在 R2R-CE 和 RxR-CE 上提升了成功率和路径长度加权成功率（SPL），成功率最高提升 2.7 个百分点。在 Unitree GO2 上，VLN-Flash 提高了导航成功率，并将动作间的平均等待时间缩短约 160 毫秒（扣除网络传输时间后）。

## Abstract
When a vision-and-language navigation policy generates an action sequence autoregressively, the robot waits for a chain of dependent predictions. A small discrete action vocabulary makes it possible to score all short-horizon plans in parallel. We introduce VLN-Flash, a training-free decoder that evaluates the complete action-prefix tree in a single forward pass. Branch-specific attention and matched token positions preserve the original policy's conditional action distribution for each prefix in exact arithmetic. We use the score margin between the stepwise-greedy prefix and its strongest alternative at each depth to decide how many actions to execute. The robot then executes the plan with the highest joint score at the chosen depth before observing again. On matched inputs, VLN-Flash achieves a nearly $3\times$ speedup in action decoding over native autoregression on Uni-NaVid and StreamVLN. Compared with the native autoregressive decoders, it improves success rate and success weighted by path length (SPL) on R2R-CE and RxR-CE, with success gains up to 2.7 percentage points. On a Unitree GO2, VLN-Flash improves navigation success and cuts the mean wait between actions by about 160 ms after subtracting network transmission time.
