## 摘要
轻量化三维建筑模型有助于城市空间分析，但其制作通常需要进行稠密场景重建、建筑提取和网格简化。尽管三维高斯泼溅（3D Gaussian Splatting，3DGS）比传统多视图立体方法效率更高，现有大规模方法仍缺乏语义选择能力和并行实例级训练机制。本文提出 SemLite-GS，这是一种以建筑为中心的框架，可从大规模无人机倾斜影像中重建轻量化建筑网格。首先，利用正射参考图建立全局一致的建筑标识，并将其传播至倾斜影像，从而构建相机—实例对和感兴趣区域。其次，语义选择式并行 PGSR 训练在相关图像区域内联合处理多个相机—实例对，同时仅更新目标高斯；上下文高斯保持固定，以维持可见性。最后，从渲染得到的深度图、不透明度图和法线图中提取建筑平面，并以此指导有符号距离场优化，生成具有自适应多边形分配和清晰结构边界的网格。在多个大规模无人机数据集上的实验表明，与代表性的全场景 3DGS 方法相比，SemLite-GS 显著缩短了建筑重建时间。在多边形预算相当的情况下，与传统的稠密重建后再进行网格简化的方法相比，SemLite-GS 能更好地保留主要平面结构和清晰的建筑转折。源代码见 https://github.com/IRIS-LAB-whu/SemLite-GS。

## Abstract
Lightweight 3D building models support urban spatial analysis, but their production often requires dense scene reconstruction, building extraction, and mesh simplification. Although 3D Gaussian Splatting (3DGS) is more efficient than conventional multi-view stereo, existing large-scale methods lack semantic selection and parallel instance-level training. We present SemLite-GS, a building-centric framework that reconstructs lightweight building meshes from large-scale UAV oblique imagery. First, an orthographic reference map establishes globally consistent building identities, which are propagated to oblique views to form camera-instance pairs and regions of interest. Second, semantic-selective parallel PGSR training jointly processes multiple pairs within relevant image regions while updating only target Gaussians; contextual Gaussians remain fixed to preserve visibility. Third, architectural planes extracted from rendered depth, opacity, and normal maps guide signed distance field optimization, producing meshes with adaptive polygon allocation and well-defined structural boundaries. Experiments on multiple large-scale UAV datasets demonstrate that our SemLite-GS substantially reduces building reconstruction time compared with representative full-scene 3DGS methods. With comparable polygon budgets, SemLite-GS achieves superior preservation of dominant planar structures and sharp architectural transitions compared with conventional dense reconstruction followed by mesh decimation. The source code is available at https://github.com/IRIS-LAB-whu/SemLite-GS.

## 1. 核心问题与整体含义

- **研究目标**：从大规模无人机倾斜影像中，直接识别目标建筑并生成轻量化三维网格。
- **研究动机**：传统流程通常先对整个场景进行稠密重建，再提取建筑、简化网格。这会为非目标区域付出额外计算成本；而单纯的网格简化虽然能减少面数，却可能破坏屋脊、建筑角点、屋面与立面交界等结构。
- **现有 3DGS 方法的不足**：大规模 3DGS 通常按场景或空间块处理，缺少面向建筑身份的选择性优化；高斯表面重建方法也多以几何精度为目标，较少直接解决有限多边形预算下的结构保持。
- **论文主旨**：把建筑语义选择提前融入高斯优化，并在网格生成阶段引入建筑平面约束，避免“全场景稠密重建后再通用简化”的常见路径。

## 2. 方法论

SemLite-GS 包含三个主要阶段。

### 2.1 正射锚定的建筑实例识别与跨视角传播

- 先用 FastGS 根据已配准的无人机影像和相机参数，快速初始化一个共享的场景级高斯表示。
- 将场景渲染为正射影像（DOM），在重叠正射影像块上运行 SAM3，合并分割结果，建立具有全局一致性的建筑实例地图。
- 将正射影像上的建筑标签投影到高斯上：依据高斯中心在正射图中的位置及其局部标签支持度赋予实例身份；再用高度范围和空间连通性过滤不合理的高斯。
- 将带标签的高斯渲染回原始倾斜视角，生成逐视角建筑掩码和 ROI。传播时，所有场景高斯都参与前向遮挡与透射率计算，但只有目标建筑高斯提供该建筑的语义支持；由此处理树木、邻楼等对目标建筑的遮挡。
- 最终形成稀疏的“相机—建筑实例”观察图，每条边记录相机、实例、验证后的掩码和 ROI。

### 2.2 语义选择式并行 PGSR 优化

- 每轮从多个建筑中各选取一个有效的相机—实例观察对，并在共享 GPU 工作负载中并行处理。
- 每个观察对的活动高斯集合由两部分组成：
  - **目标高斯**：属于当前建筑，参与渲染并接受参数更新；
  - **上下文高斯**：可能影响 ROI 内可见性，例如前景植被或邻近结构，参与渲染但保持固定。
- Rasterizer 在图像 ROI（必要时扩展为包含边界保护区的 guarded ROI）内投影和构建 Gaussian–tile 条目，仅对实际覆盖相关区域的高斯进行分块、排序和光栅化。
- 优化目标沿用 PGSR 的光度与几何监督，并在目标掩码内计算相关损失；多视图项利用目标区域的有效跨视角对应关系。
- 另外引入**冻结上下文保护损失**：将边界附近可靠上下文像素的当前渲染与固定参考渲染进行比较，抑制边界误分割导致目标高斯“吸收”植被或邻近建筑的情况。
- 多个观察对分别计算梯度后，按共享场景高斯索引聚合；只对目标高斯进行参数更新、增密和剪枝。上下文高斯只用于维持可见性。

### 2.3 平面约束的轻量网格重建

- 将优化后的目标高斯渲染到有效视角，获得深度、不透明度和法线等几何观测；筛选可靠像素并反投影至世界坐标。
- 融合多视角观测，按空间连通性和法线相似性聚类并拟合建筑平面，同时为每个平面确定有限的空间支撑范围（如屋面或立面区域）。
- 从高斯几何初始化实例级有符号距离场（SDF），再在平面支撑范围内施加点到平面、法线方向等约束；平面影响在边界附近逐渐减弱，未获得可靠平面支持的区域仍主要由高斯几何决定。
- 对优化后的 SDF 提取零等值面，并结合有限平面区域进行面片合并、边界简化和三角化。平面内部适当减少多边形，非平面区域与屋脊、角点、立面交界等结构则保留更多几何表达。
- 该过程直接生成轻量网格，不必先构造高密度中间网格再进行通用简化。

### 3.3 对比方法

**大规模重建流程比较**包括：

- CityGS-X + QEM

- PG-SAG + QEM

## 6. 主要结论与发现

- 正射域中的全局实例锚定可以改善大规模倾斜影像中的跨视角建筑身份一致性，并减少逐视角分割漏检、碎片化等问题。
- 以建筑实例为单位进行 ROI 约束的并行训练，能够避免为非目标场景区域持续付出完整的优化成本；上下文高斯冻结而继续参与渲染，有助于在节省更新成本的同时维持遮挡关系。
- 平面约束 SDF 网格生成，相较于对稠密重建结果直接做 QEM，能更好地在有限面数下表达大平面并保留建筑结构转折。
- 在论文给出的数据和配置下，SemLite-GS 相比几种全场景 3DGS 流程明显缩短运行时间；其总耗时与 Metashape+QEM 接近，并在轻量网格 CD 上取得较好结果。
- 上下文保护项降低了边界污染风险；并行处理更多相机—实例对能加快训练，但会提高显存占用，速度收益也不是线性的。

## 7. 优点

- **面向目标建筑端到端设计**：把实例发现、跨视角关联、优化和网格生成串为一条流程，而不只是处理预先隔离好的单栋建筑。
- **语义与可见性兼顾**：目标高斯接受更新，上下文高斯继续参与前向合成，有助于避免孤立优化造成的遮挡和边界错误。
- **计算域约束明确**：同时在高斯域和图像域进行筛选，ROI 在 tile 构建前施加，减少不必要的投影、排序和光栅化工作。
- **网格生成直接体现建筑先验**：有限平面支撑、SDF 和共享边界设计，服务于平面简化与结构边缘保留，而非单纯追求均匀减面。
- **实验分析较全面**：报告了多场景精度、面数、运行时间、重建成功率，并通过模块消融分析掩码、上下文保护和并行度的影响。
- **具备可复现潜力**：论文提供了代码仓库地址，并报告了主要 GPU 配置和关键运行时间数据。

## 8. 不足与局限

- **依赖初始高斯场景质量**：正射语义图由 FastGS 初始化结果渲染得到。若初始化漏掉建筑或产生明显几何、渲染误差，错误可能沿语义标签和观察图传播；后续选择性训练通常无法找回从未被识别的建筑。
- **受正射分割质量影响**：SAM3 提示分割、重叠块合并和标签传播仍可能在复杂遮挡、相邻建筑紧密接触或外形不规则时出错。对边界有帮助的上下文保护项不能完全替代准确的实例掩码。
- **结构保真评价仍不充分**：主要定量指标是 CD、顶点数和面数。论文也承认，CD 不能直接衡量平面性、屋脊定位、边缘直线性、拓扑正确性或墙体交线完整性；目前结构优势主要由定性图示支持。
- **定量覆盖范围有限**：只有五个场景提供 LiDAR 参考，Tianjin_Xiqing 仅做定性评价；数据集和场景虽涵盖多个来源，但不足以证明对各种建筑类型、城市密度和成像条件都具有稳定泛化能力。
- **参考数据与比较存在潜在偏差**：建筑 LiDAR 点云需人工提取，可能引入主观性；部分方法的成功率不同，成功案例 CD 不能完整反映失败代价；QEM 参数、后处理和软件流水线也可能影响对比。
- **效率结论依赖特定实现和硬件**：核心效率实验基于单张 RTX 4090。不同方法的运行阶段、输入处理及实现优化不完全一致，因而耗时结果不宜直接视为对算法本身的纯粹比较。
- **资源扩展存在权衡**：并行度提高会显著增加显存；多进程也可能受 GPU 容量和输入驻留位置限制。论文虽展示了更快配置，但未证明在更大城市级数据和更多目标实例下仍能保持相同扩展性。
- **相关方法比较不完全**：论文未能对 GS2Poly 做可复现的定量对比，理由是研究时缺少公开实现；轻量网格基线虽有比较，但输入与处理机制并非完全同质。
