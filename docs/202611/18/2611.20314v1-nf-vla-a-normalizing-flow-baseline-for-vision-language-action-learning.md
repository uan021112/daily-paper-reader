## 摘要
自回归归一化流（NF）能够提供可处理的概率密度，用于学习和采样连续机器人动作。我们表明，仅凭单一的最大似然目标，就可以训练出在操作基准测试中表现可与领先方法媲美的视觉-语言-动作（VLA）策略。我们提出 NF-VLA，将条件自回归归一化流与基于分数的动作细化相结合。其深浅架构将视觉、语言和本体感觉前缀条件集中于高容量的深层模块，而无条件的浅层模块则提供共享的可逆动作变换。视觉-语言骨干网络与流模型通过对经高斯平滑的动作片段进行精确最大似然训练，实现联合优化。推理时，同一学习得到的概率密度提供一次基于分数的校正，以细化生成的动作，使其适应训练时的平滑处理，无需单独训练去噪器。NF-VLA 使用预训练的视觉-语言骨干网络在 LIBERO 上训练，且未进行机器人预训练；在四个标准测试套件上的成功率达到 98.35%，使用同一检查点且不进行进一步微调时，在 LIBERO-Plus 上的成功率达到 72.6%。消融实验表明，仅在深层模块进行前缀条件化以及基于分数的细化均能提升闭环成功率。总之，这些结果证明，经过精心设计的自回归流是具有竞争力的 VLA 控制方法；单一学习得到的概率密度即可支持策略训练、动作生成与细化。

## Abstract
Autoregressive normalizing flows (NFs) provide a tractable density for learning and sampling continuous robot actions. We show that a single maximum-likelihood objective can train vision--language--action (VLA) policies competitive with leading methods on manipulation benchmarks. We present NF-VLA, which combines conditional autoregressive normalizing flows with score-based action refinement. Its deep--shallow architecture concentrates visual, language, and proprioceptive prefix conditioning in a high-capacity deep block, while unconditioned shallow blocks provide a shared invertible action transformation. The vision--language backbone and flow are jointly trained by exact maximum likelihood on Gaussian-smoothed action chunks. The same learned density supplies a single score-based correction at inference, refining generated actions to account for training-time smoothing without a separately trained denoiser. Trained on LIBERO from a pretrained vision--language backbone without robot pretraining, NF-VLA achieves 98.35\% success across the four standard suites and 72.6\% on LIBERO-Plus using the same checkpoint without further fine-tuning. Ablations show that deep-only prefix conditioning and score-based refinement both improve closed-loop success. Together, these results establish carefully structured autoregressive flows as a competitive approach to VLA control, with one learned density supporting policy training, action generation, and refinement.

## 2. 方法论

### 核心思想

- 将预训练视觉—语言骨干与条件自回归归一化流结合，预测长度为 \(H\) 的连续动作块。
- 采用**深浅结构**：视觉、语言和本体感知条件作为前缀输入高容量深层流模块；浅层流模块不直接接收条件，仅对动作表示进行共享的可逆变换。
- 对归一化动作加入高斯噪声进行平滑训练，并用精确最大似然目标联合优化视觉—语言骨干和流模型。

### 关键技术与流程

1. **多模态条件构造：**视觉观察和指令由预训练视觉—语言模型编码；本体感知状态与视觉—语言特征经线性投影后拼接为条件前缀。
2. **自回归可逆变换：**每个流块对动作 token 预测逐维仿射变换的平移与尺度参数。因果注意力保证参数只依赖此前动作 token；不同流块交替反转动作顺序。雅可比矩阵具有三角结构，因此对数行列式可高效计算。
3. **平滑动作的最大似然训练：**对归一化动作块 \(X\) 加入高斯噪声，得到 \(\tilde X=X+\sigma\epsilon\)。将其映射到标准高斯潜变量 \(Z\)，训练目标由潜变量的高斯负对数概率和各流块的对数尺度项组成。模型只使用这一最大似然目标，不添加辅助预测或表示对齐损失。
4. **采样与分数修正：**推理时从标准高斯采样潜变量，逆向通过深层和浅层流块逐 token 恢复动作块；随后计算学得密度关于动作的梯度，并执行一次 Tweedie 修正：
   \[
   \hat X=\tilde X+\sigma^2\nabla_{\tilde X}\log q_\theta(\tilde X\mid C).
   \]
   该修正近似从平滑动作恢复干净动作的后验均值，并非干净动作分布的精确采样；它使用模型自身的分数，无需独立训练去噪网络。

## 6. 主要结论与发现

- NF-VLA 在 LIBERO 上完成 **1,967/2,000** 个 episode，整体成功率为 **98.35%**；在四个套件中，Object、Goal、Long 表现突出，Long 达 **97.8%**。
- 同一检查点在 LIBERO-Plus 上达到 **72.6%**，但不同扰动类别表现差异明显：光照为 96.9%、物体布局为 83.7%，机器人初始状态为 53.8%。
- 消融结果显示：
  - 移除一次分数修正后，LIBERO 平均成功率下降 **1.90 个百分点**；
  - 将条件扩展到所有流块，平均成功率比只在深层条件化低 **1.20 个百分点**；
  - 在所有流块使用 AdaLN 的配置，平均成功率为 **92.85%**，低于全块前缀条件化配置。
- 论文据此认为，结构设计合理的自回归流可以成为有竞争力的 VLA 控制方案；一个学习得到的密度可兼顾似然训练、动作生成与动作修正。
