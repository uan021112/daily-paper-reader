## 摘要
皮层内脑机接口能够驱动机械臂，但用户仍被置于快速的感觉运动闭环之中：每次接近、修正和抓取都必须由神经信号指定。皮层内神经元群体活动能否不依赖符号命令或人工设计的技能库，而作为学习型具身策略的任务级条件，仍是未知的。NI-ACT 通过一种分层脑—具身框架探讨这一问题：仅读取一次短暂的运动皮层信号，将其作为持续有效的意图；随后，视觉运动策略依据视觉和本体感觉闭合感知—动作环路。在一项场景本身无法确定目标物体的反事实抓取任务中，神经意图单独决定了机器人抓取哪个物体；替换意图后，行为也随之改变。将完整的群体潜在表示作为专用意图标记传入，而非使用单热解码方向，使132个留出场景中的抓取完成率从69%提高至81%；相比之下，仅使用连续方向并未优于单热标签。信号的读取位置同样重要：在一次双阵列记录中，当读取窗口保持一致时，运动前区（PMd）意图的抓取完成率高于初级运动皮层（M1）意图（77% 对 53%），而传统的提示后 M1 读取率为42%。准备活动本身已足够：在一项中心向外任务中，仅从提示信号出现前（即任何动作发生前）的 PMd 读取意图，就能驱动完整抓取；在一次记录中，其完成的抓取次数甚至超过同一只动物提示后读取的表现。这些结果表明，神经信号的表征方式，以及读取信号的位置和时间，共同决定了它向具身智能体传达运动目标的效果。

## Abstract
Intracortical brain-computer interfaces can drive robotic arms, but they keep the user inside the fast sensorimotor loop: every approach, correction, and grasp must be neurally specified. Whether intracortical population activity can instead serve as a task-level condition for a learned embodied policy, without symbolic commands or hand-designed skill libraries, remains unknown. NI-ACT addresses this question with a hierarchical brain-embodied framework: a brief motor-cortical signal is read once as a persistent intent, and a visuomotor policy then closes the perception-action loop from vision and proprioception. In a counterfactual grasping task where the scene cannot specify the target, the neural intent alone determined which object the robot grasped; replacing the intent changed the behavior accordingly. Passing the full population latent as a dedicated intent token, rather than a one-hot decoded direction, raised grasp completion from 69% to 81% over 132 held-out scenes, whereas a continuous direction alone did not improve on a one-hot label. Where the signal was read also mattered: in one dual-array session, with the readout window matched, premotor (PMd) intent completed more grasps than primary motor (M1) intent (77% vs. 53%), and the conventional post-cue M1 readout reached 42%. Preparatory activity was itself sufficient: in a center-out task, intent read only from PMd before the go cue (that is, before any movement) drove complete grasps, and in one recording it completed more grasps than the same animal's post-cue readout. These results show that how a neural signal is represented, and where and when it is read, jointly determine how effectively it conveys movement goals to an embodied agent.

# 1. 核心问题与整体含义

- **研究问题：**传统侵入式脑机接口（BCI）通常逐时刻解码神经活动，要求用户持续控制机械臂的接近、对准、抓取和修正。论文探讨一种不同的分工：能否只从运动皮层活动中读取一次“要做什么”，再由具身策略根据视觉和关节状态决定“怎么做”？
- **研究动机：**运动皮层群体活动可能在动作开始前就包含目标信息；与此同时，学习型视觉运动策略能够根据观测完成反馈控制。若二者结合，神经通道就可以传递任务级目标，而不必持续承担快速运动控制。
- **论文核心主张：**NI-ACT 将短暂的神经活动转化为在整个任务期间保持不变的意图，由机器人策略闭环执行。作者进一步研究了意图的**表示方式、读取脑区和读取时机**如何影响最终抓取表现。
- **证据边界：**论文展示的是跨独立神经记录与机器人演示数据的计算验证，并非用户实际控制机器人。结果支持“神经意图足以条件化策略并影响行为”，但尚不能证明其优于连续神经控制，也不能直接证明其降低了用户负担。

# 2. 方法论

## 2.1 分层控制框架

NI-ACT 将控制分为神经意图读取和具身执行两个层级：

1. 输入一段运动皮层的脉冲计数序列 \(S\)，经过神经编码器得到三个输出：128 维群体潜变量 \(z\)、二维目标方向 \(\hat v\) 和七类方向 logits \(\ell\)。
2. 意图接口从中选取一种表示 \(u\)，并在任务开始时传给机器人；任务过程中保持不变。
3. ACT 具身策略每次接收前视相机和腕部相机图像、机械臂关节状态，以及意图 \(u\)，预测未来 32 步关节目标；约每 32 个控制步重新规划一次（约 0.53 秒）。

因此，神经信号以任务决策的频率读取，策略则以较高频率利用视觉和本体感觉闭环控制。

## 2.2 神经编码器与三种意图接口

- **神经编码器：**使用时间卷积网络（TCN），包含三个一维卷积块，通道数为 256、卷积核大小为 5、膨胀率为 1、2、4；经时间均值池化和最大池化后，投影至 128 维潜空间，并接方向回归头和七类分类头。
- **训练目标：**联合优化七类方向交叉熵与二维方向回归误差，回归项权重为 0.2；训练时使用 10% 脉冲 dropout，并依据验证集早停。神经编码器训练完成后冻结。
- **三种接口：**
  - **Hard-7：**对七类方向 logits 取 argmax，再传入七维 one-hot 向量，代表符号化目标标签。
  - **Soft-2D：**传入二维连续方向，保留目标方向信息，但不保留更丰富的群体表示。
  - **Full-Latent：**传入完整的 128 维神经潜变量，并将其作为专用 token 输入 ACT，而不是拼接到关节状态中。
- **策略训练：**每种接口各训练一个 ACT 策略。策略使用共享的 ImageNet 预训练 ResNet-18 处理两路图像，以四层、宽度 512、八头的 Transformer 编码观测，再预测 32 步、每步 9 维的关节目标。每个策略通过行为克隆训练 20,000 步，批量大小为 64。
- **可归因性设计：**关闭 ACT 的条件变分自编码器（VAE），避免策略从其他潜在变量中自行选择目标模式。策略不接收物体坐标或目标标签，目标身份由意图提供；视觉与关节状态负责执行。

## 2.3 方法流程概括

可以将方法概括为：

> 神经活动窗口 \(S\) → 冻结的神经编码器 \(E_\theta(S)\) → 选定意图接口 \(u\) → 视觉—本体感觉策略 \(\pi_\phi(I_t,q_t,u)\) → 预测动作块并反馈重规划。

意图只在任务开始时读出一次，动作则由策略持续根据机器人观测调整。

## 5.2 充分性与公平性评价

- **设计较有说服力之处：**反事实场景使视觉不能单独指出目标；替换神经意图又提供了直接检验信号是否影响目标选择的对照。所有接口共享相同演示、数据划分和策略架构，Full-Latent 的编码器与其他接口使用同一冻结编码器，因此接口差异不易归因于编码器训练不同。
- **结果指标较完整：**不仅报告抓取完成率，还区分目标选择、错误抓取和执行未完成，并对同一场景进行配对比较。
- **仍有实验充分性限制：**
  - 主要 PMd–M1 闭环比较来自**一只动物的一次双阵列 session**，独立生物学重复有限。
  - 每个策略通常只训练一次；文中也明确指出各闭环策略并未进行多随机种子重复。
  - 两种打包控制只在测试集 2 上评估，覆盖范围小于主要接口比较。
  - 任务只有三个物体、七个候选方向、固定起始姿态和单一机械臂，且没有遮挡；布局的实际几何多样性有限。

- **公平性与解释边界：**各接口均为自身输入格式训练策略，这有利于比较“各自优化后的接口”，但也意味着结果并非单纯的同一策略下替换输入表示。Full-Latent 与其他接口在维度、内容和注入方式上原本不同，论文通过额外打包控制部分分离这些因素，但仍未覆盖所有可能的编码方式。
- **统计审慎性：**文中对方向级分析标明为探索性并做 Holm 校正；主要配对比较使用 McNemar 检验。但较小样本、单次策略训练和单 session 结果仍限制统计稳定性与外部效度。

# 6. 主要结论与发现

- **神经意图确实影响机器人抓取目标。**在主要反事实实验中，Full-Latent 在 30 个场景中完成 27 次目标抓取；将神经试次替换为不同方向后，原目标抓取降为 0/30。在替换方向上确有其他物体的 16 个信息性场景中，机器人有 13 次转向替换方向对应的物体。
- **意图表示方式影响执行完成率。**在 132 个场景中，Full-Latent 完成 107 次（81.1%），Hard-7 完成 91 次（68.9%），配对差异显著（McNemar \(p=0.005\)）。两者都没有抓起错误物体，差别主要体现在选对目标后能否完成抓取。
- **二维连续方向没有显示优势。**Soft-2D 完成 86/132（65.2%），未优于 Hard-7。因而论文支持的是“该实验实现中的二维方向表示不够”，而非一般性地断言连续表示无效。
- **Full-Latent 的优势不明显依赖单试次特异几何信息或 token 路径。**Class prototype 与 Full-Latent 表现相近，并优于普通 Hard-7；Hard-7 one-hot 走专用 token 路径后表现反而较差。作者据此认为编码维度与表示格式是重要因素，但究竟是维度本身还是类别之间保留的关系结构起作用，仍未完全区分。
- **PMd 比 M1 更适合传递目标信息。**在猴 J 的迷宫任务中，PMd 在多种读取窗口下的目标解码准确率高于 M1。闭环测试中，运动窗口匹配时 PMd 完成 102/132（77.3%），M1 完成 70/132（53.0%）；传统提示后 M1 读取完成 56/132（42.4%）。
- **离线解码准确率并不能充分预测闭环成功率。**不同脑区和时间窗的离线准确率差异，与最终抓取完成率并非简单对应；即使正确解码了目标，策略也可能无法完成接近或抓取。
- **运动前准备活动已足以驱动抓取。**猴 M 的 PMd-only 和 go cue 前 PMd 读取分别完成 17/30 和 20/30 次抓取，并能引导目标选择；猴 T 的五个 session 也显示准备期目标信息随时间累积。该结果支持“执行动作之前即可读出具有操作价值的意图”，但并不证明准备期读取普遍优于动作后的读取。

# 7. 优点

- **问题设定有针对性：**把神经解码从“如何移动”转向“要完成什么目标”，契合脑—具身系统中高层意图与低层执行的分工。
- **反事实设计增强因果解释：**同一场景可对应不同目标，能较有力地排除策略单靠视觉捷径猜目标的解释；替换意图进一步检验行为是否随神经信号改变。
- **接口比较不止于解码准确率：**直接以闭环抓取表现检验神经表示对策略是否有用，揭示离线解码表现不等同于实际执行能力。
- **研究问题覆盖较完整：**同时考察意图表示、脑区来源、读取时间和跨动物/记录的一定程度泛化。
- **控制变量较细：**冻结编码器、先划分神经训练/留出试次、使用相同机器人演示，并加入 prototype 与路径控制，提升了结果归因的可信度。
- **局限披露相对明确：**作者承认缺少连续解码基线、用户闭环测试、真实机器人验证，以及脑区比较独立重复不足等关键限制。

# 8. 不足与局限

- **尚非真实用户交互：**神经记录来自非人灵长类，机器人演示来自独立来源；两者通过目标方向配对，没有真实用户根据机器人反馈调整意图，也没有用户负担或可用性评价。
- **缺少关键基线：**没有与连续神经运动解码进行同机器人、同任务对照，不能证明一次性任务级意图在完成率、时间、带宽或主观负担方面更优。
- **动物和脑区证据有限：**PMd 对 M1 的闭环优势主要依赖一只动物的一次双阵列记录；其外部有效性需要更多动物、session 和个体验证。
- **任务范围较窄：**意图只传递空间方向，不包含物体身份、抓取类型或操作步骤；场景物体少、布局受限、没有遮挡，且只涉及单臂和固定起始姿态。
- **仿真到真实的落差未验证：**闭环结果来自 Isaac Sim，文中没有实体机器人实验；真实环境中的视觉噪声、接触动力学、物体差异和安全问题仍未解决。
- **神经潜表示的迁移性未知：**不同动物和 session 的潜空间未对齐，尚未证明在一个记录上训练的策略可直接接受另一记录的潜变量。
- **长期稳定性与校准仍有挑战：**作者报告跨天测试的解码准确率会下降；即使归一化或加入新一天的少量标注数据有所改善，临床部署仍可能需要周期性校准。
- **表示机制仍未完全厘清：**现有控制显示 128 维 class prototype 可接近 Full-Latent，但尚未测试随机类别代码等对照，因此不能精确断言优势究竟来自维度、类别间几何结构还是其他因素。
- **训练和算力复现信息不足：**虽报告训练步数和部分超参数，但缺少硬件与耗时，增加了计算资源复现的不确定性。
