Abstract
Feature pyramids provide dense predictors with features
at several spatial resolutions. However, it remains largely
unexplored which pyramid levels each output location should
aggregate information from. We investigate this question by
allowing each output location to attend to features from every
pyramid level and measuring how attention is distributed
across scales. Surprisingly, locations on the finest output
grid allocate approximately 75% of their attention to features
two levels coarser, rather than to the current or adjacent
levels. Even on the same output grid, the balance shifts
toward coarser features as object size increases.
These observations motivate Asymmetric Global Pyramid
Fusion (AGPF), a neck that preserves the original output
grids while allowing each location to dynamically select its
contextual sources across scales. Each location interacts
with a multiscale memory whose features are aligned in
image coordinates, enabling flexible cross-scale aggregation
without altering prediction resolutions. Compared with FPN,
AGPF improves all 19 object detection and all seven instance
segmentation configurations evaluated on COCO. A single
fusion block improves Cascade Mask R-CNN by 1.7 box
AP and 2.3 mask AP, and the gains consistently transfer to
semantic and panoptic segmentation.
1. Introduction
Feature pyramids provide representations of an image at
multiple spatial resolutions. Dense predictors rely on these
representations for complementary localization detail and se-
mantic context, while a neck determines how information is
exchanged among them. This organization naturally invites
a structural view of fusion: connect pyramid levels so that
their features can support one another. Yet the level at which
a feature is needed for prediction does not determine where
its supporting context should come from. A fundamental
question is therefore which pyramid features each output
location should combine.

which levels each output location actually depends on. Con-
sider two locations on the finest output grid, one on a small
object and the other on a large one. In FPN, both receive
coarse context through the adjacent level, where features
from farther up the pyramid have already been combined.
Adding a cross-level shortcut gives both locations direct ac-
cess to a more distant source. If each location could draw
directly from every level, would nearby levels contribute
most, and would the two locations favor the same sources?
We let each output location attend to a shared memory
of pooled features from all pyramid levels and measure the
share of attention it assigns to each level (Fig. 2(b)). Over
object-centered queries on COCO, attention concentrates on
P4 and P5. Queries on the finest level, P2, allocate approx-
imately 75% of their attention to P4, two levels away; this
preference persists after accounting for the number of mem-
ory tokens at each level. The concentration does not imply
a fixed assignment: even with the query level held constant,
attention shifts from P4 toward P5 as object size increases.
Thus, the finest output grid can draw most of its retrieved
context from a nonadjacent source, while the balance among
sources changes with the represented object.
These findings suggest organizing pyramid fusion around
the sources selected by each location (Fig. 1, top). The out-
put hierarchy specifies the resolutions at which features are
produced; the observed retrieval patterns describe a differ-
ent organization of how context is used. We develop this
view into Asymmetric Global Pyramid Fusion (AGPF), a
neck that gives each output location direct access to a shared
multilevel spatial memory and learns the contributions of its
sources. This formulation preserves the native output grids
while allowing each query to compare context across both
levels and spatial regions. Complementary gradient-based
analysis shows that AGPF retains strong local sensitivity
while exhibiting a broader spatial dependence on the input
pyramid than FPN (Fig. 2(a)).
Joint retrieval across resolutions also requires a consis-
tent spatial reference. A displacement of one cell represents
different image-space distances at different pyramid lev-
els, and memory pooling changes those distances further.
We introduce Feature-Aligned Rotary Position Embedding
(FA-RoPE), which places each query and memory token at
the image-space center of its sampling cell before applying
rotary encoding. Cross-level interactions therefore use a
common spatial reference, accounting for both backbone
stride and memory pooling.
Making source selection practical also requires control-
ling the size of the context. The two finest levels account
for over 90% of the tokens in an uncompressed pyramid, but
preserving their dense output grids need not require equally
dense representations on the memory side. We therefore
retain every output query and spatially pool the fine-level
memory, keeping sources from all levels directly accessible.
A controlled comparison shows that this compact memory
matches full-pyramid attention in box and mask AP with
far fewer query–key interactions, so compression need not
restrict retrieval to a subset of pyramid levels.
AGPF integrates source selection, spatial alignment, and
memory pooling into a compact asymmetric attention block
whose output retains the multiresolution interface expected
by existing prediction heads. Stacking this block without
changing that interface yields AGPF-S, AGPF-B, and AGPF-
L.
Replacing FPN with AGPF improves all 19 evaluated
object-detection and all seven instance-segmentation con-
figurations on COCO, spanning one-stage, two-stage, and
cascade detectors with convolutional and Transformer back-
bones (Fig. 1, bottom), and the gains extend to semantic
segmentation on Cityscapes and ADE20K and to panoptic
segmentation. Together, the routing analysis and the task
results support a view of pyramid fusion centered on per-
location source selection: dense multiresolution outputs can
be served by selective retrieval from a compact, spatially
aligned context.

bottom-up path augmentation [32], search over cross-scale
connections [13], and repeated bidirectional weighted fu-
sion [43]. Related designs further address how context is
assembled: Dynamic Head combines scale-, spatial-, and
task-aware attention [9], while Gold-YOLO gathers multi-
level features and distributes the fused information back to
individual levels [45].
Cross-level attention. Attention-based pyramid modules
provide direct precedents for content-dependent cross-scale
interaction. FPT uses separate self-level, top-down, and
bottom-up transformations [51]. CA-FPN augments pyra-
mid features by attending to a shared global content map
derived from the deepest backbone stage [15]. CFPT com-
bines grouped cross-layer channel and spatial attention with
consistent positional encoding [10]. In AGPF, pooled spa-
tial tokens from all levels form a globally shared memory,
allowing each native-resolution query to allocate attention
jointly across levels and positions. We use this formulation
to examine how source allocation relates to output level and
object scale.
Efficient multiscale attention. Multiscale models reduce
attention cost through sparse sampling, selective feature
updates, and pooled representations. Deformable DETR
retrieves from a small set of query-dependent locations at
each level [59]. Lite DETR interleaves updates across levels
to reduce high-resolution processing [25], while RT-DETR
combines self-attention at the coarsest feature level with con-
volutional cross-scale fusion [57]. MViT and MViTv2 use
pooling attention to construct efficient hierarchical backbone
representations [11, 28]. AGPF applies memory compres-
sion to an existing pyramid while preserving the dense query
grids used by prediction heads, allowing a compact multi-
level context to serve output locations across resolutions.
3. Approach
AGPF treats the feature at each output location as a query
that retrieves context from a shared multilevel memory. Each
block preserves dense queries, pools the keys and values, and
aligns their spatial coordinates before attention (Fig. 3(a)).
The resulting features retain the original pyramid resolutions
for the prediction heads.
Pyramid tokenization. Given an image, we form the input
pyramid {Cl}l∈L from backbone features, using the levels re-
quired by the prediction architecture. Level l has spatial size
Hl ×Wl and image stride sl. We project each level to a com-
mon width d and flatten it into Xl ∈RNl×d, where Nl =
HlWl. The full token sequence is X = Concatl∈L Xl, with
each token associated with its source level and spatial loca-
tion.
Memory pooling. Within each block, we add a learned level
embedding to Xl and use linear projections shared across
levels to obtain queries Ql, keys Kl, and values Vl. Queries
retain every spatial location. Keys and values are pooled
separately on their spatial grids and then concatenated across
levels:
Q = Concatl Ql,
[K, V ] = Concatl Pl([Kl, Vl]).
(1)
Here, Pl applies spatial pooling at stride rl independently to
the key and value branches. We use depthwise convolution
for pooling, with separate parameters for the two branches.
Levels with rl = 1 skip pooling. Our default configuration
compresses the finer levels, which contain most of the pyra-
mid tokens, while retaining the coarser levels at their native
resolutions. Tokens from different levels remain separate in
the memory, even when pooling gives them the same spatial
resolution.
Aligned spatial reference. Queries and memory tokens can
have different strides, so the same grid index can refer to dif-
ferent image locations. Feature-Aligned Rotary Position Em-
bedding (FA-RoPE) expresses their positions in a common
image coordinate system (Fig. 3(c)). Common-coordinate
rotary embeddings have been used for multi-resolution crops
in MuViT [37] and different patch sizes in HyperDiT [19].

and independently pooled memory, accounting for both the

Joint pyramid retrieval.
We implement joint retrieval
as asymmetric multi-head attention between dense queries
and pooled keys and values. Each query attends to every
memory token, with the softmax normalized jointly over all
source levels and spatial positions within each head. Even
queries on the same output grid can therefore assign dif-
ferent weights to source levels and spatial regions. Before
output projection, we add the unrotated projected query to
the retrieved context. A standard FFN follows the atten-
tion update; both sublayers use residual connections and
post-normalization.

Simple implementation and stacking. A single standard at-

fusion modules for individual level pairs. After each block,
we split the output sequence by query level and reshape it
into feature maps Yl on the original Hl × Wl grids, preserv-

stacked without modifying the prediction heads, each con-
structing its memory from the updated features; varying their
number yields AGPF-S, AGPF-B, and AGPF-L.

4. Experiments
We evaluate AGPF on object detection, instance segmenta-
tion, and panoptic segmentation on COCO, and on semantic
segmentation on Cityscapes and ADE20K. Our COCO exper-
iments first examine how individual output locations select
and use pyramid context, then compare AGPF with alterna-
tive necks across detectors and backbones, and finally ablate
its main design choices.
4.1. Experimental Setup
Datasets and metrics. We evaluate object detection and
instance segmentation on COCO val2017 [29] using box
and mask AP. Semantic segmentation is evaluated on
Cityscapes [8] and ADE20K [58] using mIoU and mAcc.
For panoptic segmentation on COCO, we report PQ, PQTh,
PQSt, SQ, and RQ [24].

4.4. Ablation Studies
Memory resolution. The default pooled memory preserves
the accuracy of the full-memory reference: 42.9/38.3 ver-
sus 42.7/38.2 box/mask AP (Table 5(c)). Further compres-
sion, however, affects accuracy (Table 6). Changing the KV
strides from [4, 2, 1, 1, 1] to [4, 2, 2, 1, 1], which addition-
ally downsamples P4, reduces performance to 41.7/37.5.
The more aggressive [8, 4, 2, 1, 1] configuration obtains
41.5/37.3. The sensitivity to P4 compression is consistent
with its prominent role in retrieval and supports retaining its
native memory resolution while compressing the finer levels.
Fusion depth and query density. Table 5(a) compares the
AGPF variants. Increasing fusion depth from one block
to three improves box/mask AP by 1.4/1.1. Increasing it
further to six blocks adds only 0.3/0.1 AP, while training
iteration time rises from 0.62 to 0.94 seconds. AGPF-B
therefore captures most of the depth-related gain at a lower
training cost than AGPF-L.
AGPF-T instead reduces query density by pooling P2
queries. Relative to AGPF-S, it saves 13.6% of training mem-
ory and reduces iteration time from 0.51 to 0.41 seconds,
but loses 0.8/0.7 box/mask AP. We retain dense queries
in the standard S/B/L variants, with AGPF-T providing an
additional option when memory is constrained.

5. Discussion
Retrieval preference and spatial detail. Low average at-
tention to fine-resolution memory does not imply that fine-
resolution features are dispensable: a source used sparingly
in aggregate may still matter to particular predictions, and
fine-resolution features define dense output queries as well
as supplying context. AGPF compresses the memory while
preserving these queries, and the accuracy loss from addi-
tionally pooling queries (Sec. 4.4) separates the two roles.
Reducing context density and reducing the spatial resolution
of prediction features are therefore distinct tradeoffs.
Scope and future work.
AGPF addresses pyramid fu-
sion within the interface used by existing dense prediction
heads. In DETR-style systems, encoder representations are
designed together with object-query decoding and the set-
prediction objective [3, 59], so their effectiveness within that
joint design does not establish their effectiveness as stan-
dalone pyramid necks serving other prediction heads; we
therefore do not treat them as interchangeable neck base-
lines, and Tables 3 and 4 compare complete-system accuracy
and cost rather than encoder quality in isolation. Extending
compact pyramid retrieval to such joint encoder–decoder
designs remains future work.
8


6. Conclusion
This work shows that an output location’s level in a fea-
ture pyramid does not fully describe its use of context: when
pyramid sources are jointly accessible, queries can favor non-
adjacent levels, and their allocation across sources changes
with object scale even at a fixed query level. AGPF turns this
observation into a practical fusion design in which dense out-
put queries retrieve from a compact multilevel memory with
a shared spatial reference, and controlled neck replacements
improve detection and segmentation across the evaluated ar-
chitectures while retaining their prediction interfaces. Dense
prediction outputs can therefore be supported by selective
retrieval from compact context, which suggests treating the
output hierarchy and the organization of context as separate
design choices, and using the source preferences of indi-
vidual locations to guide how pyramid information is made
available and combined.

A. Measurement Protocols
We use the measurements defined in Sec. 3. All analyses are
conducted on COCO val2017. Unless otherwise stated,
routing and translation analyses use AGPF-S with its default
pooled memory.
A.1. Object-centered query sampling
We evaluate routing on all 5,000 COCO images and 36,334
valid ground-truth instances. For each instance, we sam-
ple a query at its bounding-box center at every output level,
allowing object scales to be compared while holding the
query level fixed. Attention mass is aggregated over in-
stances and attention heads following Eq. 4. Enrichment
uses the memory-token counts of each image before ag-
gregation. Small, medium, and large instances follow the
COCO object-size groups.
A.2. Matched gradient measurements
We sample 600 objects, with 200 from each COCO size
group and at most one object per image. Each query is placed
at the ground-truth box center and assigned to a pyramid
level according to object scale after test-time resizing. FPN
and AGPF-S are evaluated at the same query location and
level for each object. We exclude objects whose centers lie
within 5% of an image boundary to reduce truncation of the
dependency maps. All radius statistics use the normalized
gradient distribution defined in Sec. 3.
A.3. Matched input translations
We evaluate 200 COCO images under translations of 64,
128, and 192 pixels. These displacements are integer-aligned
with all effective query and memory strides. Features are
recomputed after each input translation, and attention is
compared at corresponding interior query locations. For
each input, level-local coordinates and FA-RoPE use the
same checkpoint and extracted query/key features; only their
positional coordinates differ. Drift is measured using the
source-normalized attention distributions and normalized
Jensen–Shannon divergence defined in Sec. 3.

99.0%. FA-RoPE substantially reduces these large discrep-
ancies, although attention need not be exactly preserved
when the translated image also produces different feature
content.

Figure 15 presents additional qualitative comparisons of
gradient-based spatial dependency between FPN and AGPF-

query, we visualize the sensitivity of its output feature to the
input feature pyramid, following the procedure described

quantitative analysis, further illustrating how AGPF enables
