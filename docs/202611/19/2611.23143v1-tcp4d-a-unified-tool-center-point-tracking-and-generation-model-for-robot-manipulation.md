## 摘要
机器人操作视频提供了丰富的视觉信息，但从 RGB 观测中恢复机器人动作和夹爪状态标注仍然颇具挑战。我们采用与机器人本体无关的工具中心点（TCP）位姿作为动作空间，并提出 TCP4D：一种统一模型，通过共享的四维场景表示同时跟踪观测到的 TCP 运动并生成未来 TCP 轨迹。给定单目视频和初始二维 TCP 查询，跟踪器可直接恢复以米制表示的 SE(3) 中的 TCP 位姿与夹爪状态，同时估计场景几何和相机参数。生成器沿恢复出的 TCP 轨迹从同一四维表示中采样局部特征，再将其与机器人观测和语言指令结合，以预测未来 TCP 状态。我们提出一种新的跨机器人本体数据增强流程：通过重定向恢复出的运动并合成相应观测，将现有 RGB 视频转换为适用于其他机器人本体的示范数据，且无需源机器人记录的状态。实验表明，跟踪器在 DROID 和 RoboLab 上的绝对轨迹误差分别为 7.60 mm 和 16.07 mm，并且仅用十个示范样本即可适配新的机器人本体。生成器在 RoboTwin 上取得 69.19% 的平均成功率，并在两个真实世界任务中优于成熟的策略模型；此外，与仅使用增强示范数据训练相比，联合使用源示范数据和增强示范数据进行训练可使目标机器人成功率提高 41.5%。

## Abstract
Robot manipulation videos provide a rich visual experience, yet recovering robot action and gripper-state annotations from RGB observations still remains challenging. Using the embodiment-agnostic tool-center-point (TCP) pose as the action space, we present TCP4D, a unified model in which a shared 4D scene representation both tracks observed TCP motion and generates future TCP trajectories. Given a monocular video and initial 2D TCP queries, the tracker directly recovers metric TCP poses in SE(3) and gripper states alongside scene geometry and camera parameters. The generator samples local features from the same 4D representation along the recovered TCP tracks, then combines them with robot observations and language instructions to predict future TCP states. Our new cross-embodiment augmentation pipeline converts existing RGB videos into demonstrations for alternative embodiments by retargeting the recovered motion and synthesizing the corresponding observations, without recorded source-robot states. Experiments show that the tracker achieves absolute trajectory errors of 7.60 and 16.07 mm on DROID and RoboLab and adapts to a new embodiment with only ten demonstrations. The generator achieves 69.19% mean success on RoboTwin and outperforms well-established policy models on two real-world tasks, while joint training on source and augmented demonstrations improves target-robot success by 41.5% over augmented-only training.

- **研究动机**：如果能从普通视频中恢复机器人末端的运动，就能把缺少动作标签的视频转化为操作示范；若使用与机器人本体无关的动作表示，还能将同一任务运动迁移到不同机器人上。
- **整体思路**：论文提出 TCP4D，以 TCP 的三维位姿 \(SE(3)\) 和夹爪状态作为统一动作表示，使用共享的四维场景表示完成两项任务：
  1. 从已有视频中跟踪 TCP 位姿和夹爪状态；
  2. 根据观测和语言指令生成未来 TCP 轨迹。
  
  同一套恢复出的任务空间运动还可通过逆运动学重定向到其他机器人本体，用于生成跨本体示范。

## 2. 方法论

### 2.1 TCP 跟踪器

- **输入**：单目 RGB 视频，以及每只机械臂在参考帧中的初始二维 TCP 查询点。
- **共享场景编码**：模型借鉴 4RC 的设计，使用基于 DINOv2 的 Transformer 编码视频。图像被划分为 patch，并加入相机 token 和时间 token；通过帧内与跨帧注意力提取空间结构和时间对应关系。
- **几何估计**：几何解码头预测每帧的米制深度图、相机射线图及相应置信度；相机头还可估计相机相对于机器人基座的位姿和视场参数。
- **TCP 查询与跟踪**：模型在初始帧的 TCP 查询点附近采样 \(3\times3\) patch 特征，经过查询解码器与各目标帧的场景特征交互，直接回归：
  - TCP 三维平移；
  - TCP 朝向，采用连续 6D 旋转表示，再投影到 \(SO(3)\)；
  - 夹爪状态；
  - 位姿置信度。
- **核心区别**：模型直接跟踪虚拟 TCP 的完整 \(SE(3)\) 状态，而不是先跟踪夹爪表面点，再通过刚体拟合和机器人先验间接推算 TCP。

### 2.2 TCP 生成器

- **条件输入**：最近 \(L=4\) 帧 RGB 图像、当前机器人关节与夹爪状态、腕部相机图像、语言指令，以及由跟踪器恢复的历史 TCP 轨迹。
- **轨迹条件特征**：将历史 TCP 的三维位置投影回对应图像，在共享场景表示中提取局部 TCP 特征，并加入空间和时间编码。
- **生成模型**：使用 Diffusion Transformer（DiT）预测未来 \(h=32\) 步的双臂 TCP 状态。每只手臂的动作由位置、6D 旋转表示和夹爪状态组成，共 10 维；双臂轨迹因此为每步 20 维。
- **训练目标**：采用 flow matching。令目标动作序列为 \(A\)、高斯噪声为 \(\epsilon\)，则中间状态写作
  \[
  A_\tau=(1-\tau)\epsilon+\tau A,
  \]
  训练网络预测速度场 \(v^\star=A-\epsilon\)。推理时使用 4 次 Euler 更新从噪声生成未来轨迹。
- **条件编码器**：腕部图像由冻结的 DINOv2-Large 编码，语言由冻结的 T5-base 编码；DiT 将机器人状态、历史 TCP 局部特征和含噪未来动作共同建模。

### 2.3 两阶段训练

1. **阶段一：几何和 TCP 重建**
   - 联合训练视频骨干网络、几何头和 TCP 跟踪器。
   - 损失包含深度、相机射线、TCP 位姿、时间速度一致性和夹爪状态监督。
   - 位姿监督将每个 TCP 扩展成 7 个虚拟刚性点（中心及沿三个局部坐标轴正负方向的点），以便同时约束位置和朝向。
2. **阶段二：条件轨迹生成**
   - 从阶段一权重初始化，继续训练场景与 TCP 模块，并训练条件模块和 DiT。
   - 损失包含场景几何、当前 TCP 状态监督和未来动作 flow-matching 损失。

### 2.4 跨本体数据增强

- 从源机器人 RGB 视频和初始 TCP 查询出发，恢复 TCP 轨迹、夹爪状态及相机几何。
- 将轨迹变换到公共世界坐标系，使用目标机器人的 URDF 和逆运动学求解目标关节状态；若初始基座位置不可达，可搜索附近的基座平移位置。
- 使用 SAM3 分割源机器人，或在可用时根据源 URDF 与机器人状态渲染掩码；随后通过视频修复模型补全背景，并将目标机器人渲染后合成到视频中。
- 该流程不要求源机器人提供记录的 TCP 轨迹或关节状态，但仍需要目标机器人模型；深度信息可选，用于改善遮挡判断或掩码质量。

## 6. 主要结论与发现

- 论文证明了从单目 RGB 视频直接预测 TCP 的完整位姿和夹爪状态是可行的，并且相较于“先跟踪表面点、再拟合刚体”的路线，在文中测试的 DROID 和 RoboLab 上取得更低的轨迹误差与更高的跟踪成功率。
- TCP 的 \(SE(3)\) 表示可作为跨机器人本体的任务空间接口：在 UR5 上仅用少量示范微调，跟踪性能已有明显提升。
- 使用恢复的任务空间运动生成目标机器人示范，在实验中不需要源机器人的记录状态；增强数据能够支持目标机器人策略学习，而与源数据联合训练通常效果更好。
- 生成器在干净模拟环境和两个真实任务上表现较强，但从 clean2clean 到 clean2random 的成功率显著下降，表明环境变化下的泛化仍是关键挑战。

## 7. 优点

- **任务链路统一**：将场景重建、TCP 跟踪、未来动作生成和数据增强连在同一套表示与接口上，减少彼此割裂的处理环节。
- **动作表示具有本体通用性**：以 TCP 位姿代替机器人关节动作，便于通过逆运动学将任务运动映射到不同机械臂。
- **直接预测虚拟 TCP**：针对 TCP 位于自由空间、点跟踪无法直接确定朝向的问题，模型直接估计完整 \(SE(3)\) 状态。
- **几何监督较完整**：联合训练深度、相机射线、位姿、运动一致性和夹爪状态；虚拟刚性点为旋转监督提供了明确几何约束。
- **增强流程降低数据门槛**：可从 RGB 视频提取运动，再进行目标机器人 IK、背景修复和目标机器人合成，为缺少目标本体示范的场景提供数据来源。
- **评测维度多样**：覆盖合成环境、未见任务、少样本迁移、下游数据效用和真实机器人运行，而不只报告单一离线误差。
