Abstract

requires joint reasoning about geometric structure and se-
mantic context. Pretrained 3D experts provide spatially
grounded region proposals, while 2D experts provide se-

to integrate these complementary capabilities into a frame-
work that can both produce meaningful part segmentations
and progressively refine them. We present PartAgent, a
training-free agentic framework for 3D part segmentation
built upon two complementary modules: (i) Structural–

1. Introduction
3D part segmentation aims to partition a 3D object into mean-
ingful parts [9, 10, 22–24, 46, 50], which is a fundamental
task in 3D understanding [4, 5, 25, 28, 29, 41]. Doing so
requires both geometric cues about the object’s structure
and semantic context to determine which regions belong
together. 3D experts [22, 23] propose spatially grounded
regions, while image-based approaches [21, 36, 46] provide
visual grouping and semantic context across views.
Turning these complementary cues into meaningful parts
remains challenging: (i) A 3D proposal may cover only
a fragment of a component or span several components,
while semantic predictions from different views may dis-
agree about part boundaries or identities. Constructing a
coherent partition therefore requires jointly considering ge-
ometric and semantic evidence to determine how regions
should be grouped into parts. (ii) Even after integration, the
initial partition may still be imperfect and require further
inspection and revision. To address both challenges, we
present PartAgent (Fig. 2), a training-free agentic frame-
work that combines geometric and semantic evidence from
pretrained 3D and 2D experts to construct meaningful part
partitions, and then iteratively refines the segmentation by
selecting targeted actions based on current observations.
To construct meaningful initial partitions, our key intu-
ition is to treat spatially grounded regions as building blocks
and use semantic evidence to guide how they are refined
and grouped into parts. We propose Structural–Semantic Ex-
pert Integration, which maps multiview semantic predictions
onto the original mesh through image-to-surface correspon-
dences and uses the mapped evidence to refine 3D expert
regions. It then composes these regions into candidate parti-
tions at multiple granularities, selects an initial partition, and
retains alternative candidates for later revision.
Further refinement requires deciding where to inspect,
what to revise, and whether a proposed change improves
the result. We propose Observation-Driven Closed-Loop
Partition Refinement, which uses a vision–language model
(VLM) to examine projected partitions, geometry renders,
and semantic predictions and select a targeted action. The
agent can inspect a region, repair 2D segmentation masks,
revise part groupings, or select an alternative candidate. The
agent verifies each proposed update before adoption. Both
acceptance and rejection guide later actions.

Our contributions are threefold:
• A Training-Free Agentic Framework for 3D Part Seg-
mentation. We integrate frozen 2D and 3D experts to
construct meaningful part partitions and iteratively refine
them through VLM-guided decisions.
• Structural–Semantic Expert Integration. We use mul-
tiview semantic evidence to refine 3D expert regions and
compose candidate partitions at multiple granularities.
• Observation-Driven Closed-Loop Partition Refinement.
We introduce an observation-driven loop that adaptively
refines both part groupings and their supporting semantic
evidence. Verification determines which updates to adopt
and provides feedback for subsequent action selection.

3.1. Overview
Given a triangular mesh M = (V, F), we seek a partition
P = {P1, . . . , PK} whose regions are disjoint and cover the
input surface. Here, V and F are the vertex and triangular-
face sets. Each Pi ⊆F contains the faces of one of the K

2D experts, and uses a vision–language model (VLM) for
reasoning and verification. We refer to the regions predicted
by the 3D expert as 3D expert regions. Fig. 3 summarizes the
two key modules. Structural–Semantic Expert Integration
(SSEI) uses multiview semantic evidence to refine the 3D ex-
pert regions. The resulting regions, called integrated leaves,
are grouped into complete candidate partitions from which
SSEI selects an initial partition P0 (Sec. 3.2). Observation-

3.2. Structural–Semantic Expert Integration
A 3D expert region may capture only a fragment of a compo-
nent or span several components. Image predictions provide
semantic context, but do not directly define a consistent sur-
face partition. We use image evidence to refine 3D expert
regions, then construct candidate segmentations at different
granularities, as shown in Fig. 3A.
Shared multiview evidence. We render the input mesh
from multiple viewpoints to obtain images Iv and retain the
camera parameters and rasterized pixel–face maps,

The VLM examines the rendered views together to propose
and review a part list describing each possible part’s category
and which visible regions it should include or exclude. Each
entry in the part list receives a distinct color shared across
views. We keep this part list and color scheme fixed. The 2D
expert then produces a color-coded part mask for each target
render using the other views as context. We instruct the
2D expert to preserve the target render’s silhouette, visible
surfaces, and pose. These predictions form E0 in Fig. 3A.
We decode the mask colors and combine evidence across
views by semantic category.

3.3. Observation-Driven Closed-Loop Refinement
Refinement can require different actions. An ambiguous re-
gion may need closer inspection, inaccurate image evidence
may need repair, and an incorrect grouping may be corrected
by regrouping leaves or selecting an existing candidate. The
VLM in Fig. 3B uses observations to choose the action, its
spatial target, and when to finish. Each action outcome
guides the next decision. In Fig. 4, the agent inspects the
tractor and proposes separating its fender from the tire and
merging the two regions belonging to the same wheel by
regrouping existing leaves. After the proposal is accepted,
the agent inspects the exhaust.

For example, unclear part structure or uncertainty about an
alternative candidate can prompt Inspect before a change is
proposed. When a fragmented or incorrectly merged part
can be corrected by regrouping existing leaves, the agent
can choose Compose. If an inspected candidate appears to
offer a more plausible segmentation, it can choose Reselect.
Repair 2D is reserved for visible errors in the 2D masks that
regrouping or reselection alone cannot address. Previous
outcomes help the agent reconsider unsuccessful proposals.
From 2D repairs to local 3D updates. The VLM first
checks the repaired 2D mask against the original render,
previous mask, and other views. If the VLM accepts the re-

to produce a proposed segmentation ePt. Changes are re-

segmentation stays unchanged. The proposal then undergoes
partition verification against the original renders before it
can replace the current segmentation.

all methods on the same fixed subsets using their officially

each object, we average scores within each annotation level,
then across the available levels. Dataset scores average these
object scores. Avg. in Tab. 2 is the mean of the four dataset-
level scores. For ablations, we also report Partition Match
mIoU. For each object, we compute mIoU separately for
each complete candidate partition using only its masks and

5. Conclusion
We presented PartAgent, a training-free agentic framework
for 3D part segmentation using frozen 2D and 3D experts. It
8


uses multiview semantic predictions to refine 3D expert re-
gions and group them into an initial segmentation. The agent
then examines the result, decides what to revise, and checks
proposed changes. Feedback from these checks guides its
next action. PartAgent achieves 68.41 Mask Match mIoU on
PartObjaverse-Tiny-WT, exceeding the strongest competing
method by 8.53 points. Across 3DCoMPaT200, PartNeXt,
PartNetE, and PartObjaverse-Tiny, it achieves the highest
mIoU on each dataset, with a four-dataset mean of 69.36,
7.28 points above the best competing method’s mean score.

C.2. CLR Action Ablations
We further ablate ‘Compose’, ‘Repair 2D’, and ‘Reselect’ to examine how these actions contribute to closed-loop refinement.
As shown in Tab. S2, removing ‘Compose’ lowers Partition and Mask by 0.86 and 1.16 points, respectively. Removing
‘Reselect’ lowers them by 0.25 and 0.29 points. And removing ‘Repair 2D’ lowers them by 0.02 and 0.09 points. Repair 2D
yields small average gains but helps prevent an occasional failure that matters in practice. When the 2D expert hallucinates a
part, the incorrect mask can introduce a false part into the 3D segmentation. Fig. S5 provides qualitative examples of how
repairing the 2D masks removes false regions and corrects misplaced boundaries in the 3D segmentation. This matters in
practice when a part hallucinated by the 2D expert would otherwise appear as a separate part in the final result.
