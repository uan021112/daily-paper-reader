## Abstract
Semantic occupancy perception has emerged as a promising paradigm for jointly modeling 3D scene geometry and semantic information. However, this unified representation cannot compensate for missing information caused by occlusion and sensor coverage. Multi-agent cooperation alleviates this limitation, but information from different agents is not equally useful across spatial regions. Meanwhile, feature representations from each agent form the basis of reliable multi-agent fusion. Cross?modal fusion constructs such representations by integrating complementary semantic and geometric information. Despite this complementarity, jointly establishing reliable 3D correspondence across agents and preserving modality-specific structures remains challenging. To address these limitations, we propose CoopOcc, which performs cooperative 3D semantic occupancy perception through multi-agent and cross-modal fusion. CoopOcc uses ego?query cross-agent attention (EQCA) to selectively aggregate aligned features across agents, and anchor-based bidirectional feature interaction (ABFI) for cross-modal exchange at matched coordinates. We further construct SemanticVVSim, a simulation dataset, and establish a unified benchmark. For simulation-to-real transfer, we propose confidence-aware hierarchical occupancy and relational distillation (CHORD). CoopOcc performs best overall among ten evaluated methods on SemanticVVSim. On Occ3D-nuScenes, CHORD improves performance using knowledge from SemanticVVSim. The code is available at https://github.com/LOTEAT/CoopOcc.
