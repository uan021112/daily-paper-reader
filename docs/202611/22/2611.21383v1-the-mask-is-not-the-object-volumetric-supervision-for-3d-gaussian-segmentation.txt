## Abstract 

3D Gaussian Splatting enables object-level operations on Gaussian primitives, yet existing segmentation methods are largely trained and evaluated through rendered views. This mismatch can produce accurate rendered masks from incomplete 3D selections since alpha-blended feature supervision concentrates learning on dom-inant contributors while leaving occluded or low-contribution Gaussians weakly supervised. We propose VODA, a plug-and-play supervision objective that exploits local depth structure to group per-pixel contributors and directly supervises all Gaussians in selected depth clusters, bypassing contribution-weighted gradient delivery. To evaluate volumetric completeness, we introduce Removal-3D, a syn-thetic object-removal benchmark, and the Removal Depth Error (RDE), a metric comparing predicted and ground-truth depth changes. Across four rendering-based baselines, VODA consistently improves volumetric segmentation on Removal-3D while maintaining or improving performance on LERF and ScanNet. Further analysis shows that VODA recovers lower-contribution Gaussians, while simple gradient reweighting and spatial propagation fail to reproduce comparable gains. 

## 1 Introduction 

Object-level editing of reconstructed scenes requires selecting objects as complete 3D entities. Removing, relocating, or extracting an object depends on capturing its full spatial extent, including its interior. For scenes represented by 3D Gaussian Splatting (3DGS) [12], this means selecting all Gaussians associated with the object. Yet existing segmentation methods [22, 24, 29, 10, 28, 6] are commonly evaluated by the accuracy of their rendered 2D masks, which does not establish whether the underlying 3D selection is complete. Figure 1 illustrates this gap: a selection can produce an accurate mask yet miss some of the object’s Gaussians, leaving visible remnants after removal. This gap stems from rendering-based feature supervision. Existing methods [29, 10, 28, 6] learn per-Gaussian instance features through rendered 2D feature maps, using external feature or mask targets, or mask-based contrastive objectives. Despite their differences, these objectives deliver gradients according to each Gaussian’s rendering contribution (§3.1). Dominant contributors can thus suffice to render an accurate mask, while low-contribution Gaussians belonging to the same object receive weak or no supervision and may remain unselected. We therefore study volumetric 3D Gaussian segmentation , aiming to select object-associated Gaus-sians beyond those needed to render a correct mask. We propose VODA , a plug-and-play objective that extends object-level supervision beyond the dominant contributors. VODA modifies only feature supervision, leaving the baseline’s reconstructed scene, feature representation, and inference-time selection procedure unchanged. Our key observation is that, after RGB optimization, Gaussians associated with the same object tend to cluster at similar depths, while larger depth gaps often reflect separation between distinct

Targets constructed from rendered features are then applied directly to every Gaussian in the selected cluster, supervising both dominant and low-contribution members while bypassing the contribution-weighted gradient path (§3.3). Evaluating volumetric segmentation requires measuring whether an object selection is complete beyond its visible projection. Existing benchmarks score rendered masks or visible surface labels and therefore do not directly measure this property. We use object removal as a diagnostic: removing a complete selection should produce the same depth change as removing the target object itself. We therefore introduce Removal-3D, a synthetic indoor-scene benchmark with paired ground-truth depth maps before and after target removal. To quantify how closely a predicted selection reproduces this change, we propose Removal Depth Error (RDE), which compares the ground-truth depth change with the change induced by removing the predicted Gaussians. Experiments across four rendering-based baselines [28, 6, 29, 10] show that VODA consistently improves volumetric segmentation on Removal-3D while maintaining or improving performance on standard benchmarks [13, 9]. Ablations identify direct Gaussian-level supervision as the primary source of these gains, while additional diagnostics support the need to change which Gaussians receive supervision rather than merely modifying the existing rendering-based signal. In summary, our contributions are threefold. (1) We formulate volumetric 3D Gaussian segmentation, distinguishing selection completeness from rendered-mask accuracy and identifying the bias in rendering-based supervision. (2) We propose VODA, a plug-and-play objective that directly super-vises all Gaussians in selected depth clusters. (3) We introduce Removal-3D and RDE, a benchmark and metric that assess selection completeness through removal-induced depth changes. 

## 2 Related Work 

The explicit primitives of 3D Gaussian Splatting (3DGS) [12] support object-level selection and edit-ing. Recent methods attach semantic features or object identities to Gaussians for object-level scene understanding [29, 33]. We focus on how 2D supervision is transferred to Gaussians, distinguishing rendering-based feature learning from direct 2D-to-Gaussian association. 

Rendering-based Feature Learning. Earlier NeRF methods lift 2D semantics through feature distillation, mask supervision, or contrastive learning [31, 16, 26, 25, 1, 19, 4, 14, 30, 2], including distillation of pretrained visual features such as DINO [3]. Rendering-based 3DGS methods similarly alpha-blend per-Gaussian features into 2D maps, with two main supervision paradigms. Supervised feature learning matches these maps to external targets: CLIP features [22, 24, 32, 34, 23, 18], SAM mask identities as in Gaussian Grouping [29], or both jointly [10]. Self-supervised feature learning instead uses SAM masks as grouping cues, pulling features within a mask together and pushing features across masks apart without explicit feature targets [28, 6, 5, 8, 17]. As illustrated in Figure 2a, low-contribution Gaussians can therefore receive weak supervision even when the rendered features match the 2D targets or grouping constraints. VODA complements either paradigm with direct Gaussian-level supervision while leaving the reconstructed scene, feature representation, and inference-time selection unchanged. 

Direct 2D-to-Gaussian Association. Another line of work associates 2D observations directly with Gaussians rather than learning features through rendered-map losses. Lifting By Gaussians [7] assigns 2D mask labels to the per-pixel maximum-contributing Gaussian and merges the resulting fragments across views. Dr. Splat [15] registers CLIP embeddings to dominant or Top-k Gaussians for optimization-free 3D search. Quantile Rendering [11] uses quantile-based sampling to associate high-dimensional features with a sparse set of influential Gaussians. Despite their different association rules, these methods associate each pixel with only a sparse subset of Gaussian contributors, as illustrated in Figure 2b. Multi-view observations can expand this set, but object-associated Gaussians that remain weak contributors across views may still receive no assignment. Thus, bypassing rendered-feature optimization alone does not necessarily resolve the incompleteness induced by sparse, contribution-based association. VODA instead uses per-pixel depth structure to identify the target-associated cluster and directly supervises all Gaussians within it. 

## 3 Method 

We propose VODA, a plug-and-play supervision objective for volumetric 3D Gaussian segmentation. We first analyze why standard rendering-based supervision is insufficient in §3.1. The depth-aware rasterizer in §3.2 then groups per-pixel contributors and selects a target depth cluster. Direct Gaussian-level supervision in §3.3 applies a feature loss to every Gaussian in the selected cluster, together with a complementary pixel-level push loss that encourages separation between object instances.

3.2 Depth-Aware Rasterizer 

To address this imbalance, we need to identify object-associated Gaussians beyond those retained by maximum or Top-k selection (Figure 2). Instead of relying solely on individual rendering contributions, we exploit the local depth structure of the reconstructed scene. During reconstruction, cloning and splitting introduce new Gaussians around existing primitives [12]. This local refinement motivates using depth proximity as a cue for object association: contributors representing the same local object region can form a depth cluster containing both dominant and low-contribution Gaussians. Larger gaps can indicate separation from other objects or the background.

It disables transmittance-based early termination to retain contributors behind dominant Gaussians. Since there are no ground-truth instance features for individual Gaussians, we construct Gaussian-level pseudo-targets from the full rendered feature F(p) defined in Eq. 1, rather than rendering the selected cluster alone. This feature is dominated by high-contribution Gaussians that receive strong baseline supervision, providing a learned feature signal for other Gaussians in the same cluster. ## 4 Experiments 

We evaluate VODA on two standard 3DGS segmentation benchmarks, LERF and ScanNet, in §4.1, and on our Removal-3D benchmark for volumetric evaluation in §4.2. We further ablate its design choices in §4.3 and analyze recovered Gaussians and contribution-based alternatives in §4.4. We evaluate four baselines spanning both feature-learning paradigms in §2: OpenGaussian [28] and LaGa [6] are self-supervised, while Gaussian Grouping [29] and ILGS [10] are supervised. 

Implementation details. We implement VODA on the official codebase of each baseline and apply it only to the feature-learning stage, leaving RGB reconstruction and inference unchanged. The depth-clustering and loss hyperparameters are shared across all four baselines. VODA is applied within the existing feature stage for OpenGaussian and LaGa, and as a short feature-only fine-tuning stage for Gaussian Grouping and ILGS. Full implementation details are provided in the supplementary.

Supervision delivery. We compare VODA’s direct loss with a rendering variant that uses the same selected depth clusters and target features, but delivers supervision through feature rendering. Thus, the two variants differ only in how supervision reaches the selected Gaussians. Direct supervision consistently performs better across both baselines on LERF and Removal-3D, with the largest difference on Gaussian Grouping, where LERF mIoU rises from 12.40 to 43.73. Pixel-level push. We next isolate the pixel-level push loss while retaining direct supervision. The push loss has little effect on standard LERF performance, but consistently improves volumetric selec-tion on Removal-3D. This supports its complementary role to direct supervision. Direct supervision improves Gaussian coverage, while the push loss reduces feature mixing between nearby instances and improves volumetric selection. Boundary visualizations in the supplementary illustrate this effect. 

Target aggregation. Finally, we compare uniform averaging with the α-weighted aggregation in Eq. 5. Alpha weighting yields modest but consistent improvements across both baselines, supporting the choice to place greater trust in pixels where the selected Gaussian has a higher per-pixel alpha. Overall, the ablation shows that direct supervision provides the primary benefit, while the pixel-level push improves instance separation and α weighting improves target reliability.

Normalize and Clamp rescale the rendering gradient, while KNN propagates features from nearby high-contribution Gaussians. None of these alternatives matches VODA. All three substantially degrade volumetric performance for OpenGaussian, while for Gaussian Grouping, Normalize improves LERF performance but severely degrades Removal-3D. These failures reflect a limitation of contribution-based heuristics. Rendering contribution alone does not indicate whether a Gaussian is associated with the target object. Reweight-ing therefore cannot identify the relevant low-contribution Gaussians or recover those that receive no rendered gradient. Indeed, across the six analyzed scenes, 8.5–18.7% of recovered Gaussians receive zero contribution in every training view. KNN avoids this zero-gradient issue, but spatial proximity likewise does not establish object association and may propagate features across object boundaries. 

## 5 Conclusion 

VODA closes the gap between rendered-mask accuracy and volumetric completeness by group-ing contributors by depth and directly supervising every Gaussian in selected clusters. We intro-duce Removal-3D and RDE to measure selection completeness from depth changes after object removal. Across four baselines, VODA improves applicable standard benchmarks and both mRDE and rendered-mask mIoU on Removal-3D. Reweighting and spatial propagation fail to match VODA, suggesting that reaching low-contribution Gaussians matters more than scaling rendered gradients. 

Limitations. Depth clustering may merge contacting objects or fragment objects with sparse interiors, and the pixel-level push only partly addresses these cases. Because occluded Gaussians lack feature-level ground truth, we assess their supervision indirectly through downstream selection and removal. Exact volumetric evaluation requires paired full-scene and object-removed depth maps, available only for the three synthetic Removal-3D scenes. 10 Acknowledgments

A.3 Additional Baseline Comparison and Positioning Reconstruction-time correspondence: Segment then Splat. Segment then Splat (STS) [20] and VODA both seek object-consistent Gaussian representations, but introduce object identity at different stages. STS partitions Gaussians into object-specific sets using pre-obtained masks and optimizes the scene under this fixed correspondence. VODA instead operates on an already-reconstructed scene: it adds direct object-level supervision to the baseline’s features while leaving geometry, opacity, and appearance unchanged. STS therefore establishes object-specific Gaussian sets during reconstruction, whereas VODA improves feature-based object assignment after reconstruction. 

Volumetric segmentation and reconstruction quality. We evaluate the public STS implementation under the same Removal-3D protocol (Table 7). STS achieves higher selection mIoU than Gaussian Grouping (38.37 vs. 26.23), but has a higher mRDE than either unmodified baseline (62.10 vs. 39.31 and 50.05). In contrast, VODA improves both metrics for each baseline without retraining its geometry. Table 8 also reports full-scene reconstruction quality averaged over the three scenes. VODA leaves these metrics unchanged because it modifies only object features. In this setting, STS has lower PSNR and SSIM and higher LPIPS than the two baselines. These results show that reconstruction-time correspondence alone does not ensure volumetrically complete object selection. However, STS and the feature-learning baselines use different reconstructed scenes, so this comparison does not isolate object assignment from reconstruction quality. The baseline–VODA comparisons keep the reconstructed scene fixed and isolate the effect of feature supervision. 

Complementary scope and trade-offs. Fixed mask-based correspondence can propagate errors from partial views or ambiguous boundaries into both object assignment and geometry optimization. This dependence makes reliable masks and cross-view tracking important for reconstruction-time methods. VODA decouples feature supervision from reconstruction and can be applied to pre-trained scenes, but cannot repair errors in the geometry it inherits. STS is attractive when a reliable initial object decomposition is available, while VODA addresses incomplete selection in existing rendering-based feature-learning pipelines. We therefore view the approaches as complementary rather than claiming that either paradigm universally dominates the other. 14 Table 7: Object selection on Removal-3D.

We evaluate object removal on SPIn-NeRF [21] (10 scenes) and 360-USID [27] (7 scenes), which provide captures of scenes both with and without a target object. For a real-world proxy of RDE, we reconstruct the with-object and without-object captures independently using vanilla 3DGS and use their rendered depth difference as the reference removal signature. Unlike Removal-3D, this reference is estimated from reconstructions rather than ground-truth geometry. We also compare removal renderings with the without-object reference images using PSNR, SSIM, and LPIPS. VODA improves object-mask IoU in all four dataset–baseline settings. However, the proxy RDE changes are small, with a slight regression for OpenGaussian on 360-USID, and the image-space changes are mixed. These datasets mainly contain single-object, low-occlusion captures, in which baseline selections already recover most of the depth change. Moreover, image-space metrics conflate removal completeness with the quality of newly exposed regions, which were not observed during reconstruction. Thus, these evaluations support transfer to real reconstructions but do not directly establish volumetric completeness under heavy occlusion.
