## 摘要
从单张输入图像生成一致的多视角 RGB 图像和法线图，可为 3D 重建提供互补的外观与几何线索。然而，保持跨视角一致性需要在不同视点之间交换信息；随着视角数量和空间分辨率的增加，密集跨视角注意力的计算成本会变得很高。本文提出全局-局部代理注意力（Global-Local Proxy Attention，GLPA），在保留视角内细粒度处理能力的同时降低跨视角通信成本。具体而言，GLPA 在每个视角内保留全分辨率交互，并使用紧凑的全局代理进行跨视角通信。为进一步利用交换的信息，GLPA 引入迭代式代理细化机制：根据更新后的特征重新构建代理，并在单个去噪步骤内的后续交互中重复使用相同的注意力参数。我们在两种结构差异显著的扩散骨干网络 FLUX 和 Stable Diffusion 上评估 GLPA。在 FLUX 上的实验表明，与密集注意力相比，GLPA 将每个去噪步骤中的注意力计算速度提升了 2.65 倍，同时将重建 IoU 从 0.6849 提高到 0.7019，并将 NVS LPIPS 从 0.086 降至 0.076。Stable Diffusion 上的结果进一步证明了 GLPA 的有效性：注意力计算速度提升 1.80 倍，且五项质量指标均有所改善。

## Abstract
Generating consistent multi-view RGB images and normal maps from a single input image provides complementary appearance and geometric cues for 3D reconstruction. However, maintaining cross-view consistency requires information exchange across viewpoints, and dense cross-view attention becomes computationally expensive as the number of views and spatial resolution increase. In this paper, we propose Global-Local Proxy Attention (GLPA) to reduce cross-view communication costs while preserving fine-grained within-view processing. Specifically, GLPA retains full-resolution interactions within each view and uses compact global proxies for cross-view communication. To further leverage the exchanged information, GLPA incorporates iterative proxy refinement, which rebuilds the proxies from updated features and reuses the same attention parameters for subsequent interactions within a single denoising step. We evaluate GLPA on two structurally different diffusion backbones, FLUX and Stable Diffusion. Experiments on FLUX show that GLPA achieves a $2.65\times$ speedup in attention computation per denoising step over dense attention, while improving reconstruction IoU from 0.6849 to 0.7019 and reducing NVS LPIPS from 0.086 to 0.076. Results on Stable Diffusion further demonstrate the effectiveness of GLPA, with a $1.80\times$ attention speedup and improvements across all five quality metrics.

# 1. 核心问题与整体含义

- **研究背景：** 从单张图像生成物体的多视角 RGB 图像和法线图，是单图像 3D 重建的一种常见中间路线。RGB 图像提供外观线索，法线图提供几何线索；这些视图若彼此不一致，就可能导致重建出的 3D 模型残缺或失真。
- **核心问题：** 扩散模型通常通过跨视角注意力交换信息，以提高不同视角的一致性。但若所有视角的所有图像 token 都进行密集交互，计算开销会随 token 总数近似平方增长，分辨率或视角数增加时尤其昂贵。
- **论文主张：** 视角内的信息处理和视角间的信息交换承担不同作用：前者需要保留空间细节，后者更需要传递有助于一致性的概括信息。因此，论文提出 **全局-局部代理注意力（GLPA）**：视角内保留全分辨率注意力，视角间则通过紧凑代理传递信息；再以迭代代理细化改善跨视角交互效果。

# 2. 方法论

## 2.1 全局-局部代理交互

- 在每一层注意力中，将 token 按视角和数据域（RGB、法线）组织起来。
- **局部路径：** 每个查询 token 仍与同一视角内的全分辨率 RGB 和法线 token 交互，从而保留纹理、轮廓、法线变化等细节。
- **全局路径：** 对各视角、各数据域的特征网格分别做空间平均池化。若池化步幅为 \(s\)，每个 \(s\times s\) 区域生成一个代理 token。代理经过自注意力后，可在不同视角和数据域之间交换信息。
- 每个全分辨率查询的注意力键和值由两部分组成：同视角的全分辨率局部 token，以及全局代理。由此，跨视角交互由原始 token 之间的密集连接，改为查询与少量代理之间的连接。
- 设全分辨率 token 数为 \(S\)，代理数为 \(M\)，则跨视角读出的主要交互从约 \(O(S^2)\) 降为 \(O(SM)\)，另有代理之间约 \(O(M^2)\) 的交互开销。局部注意力仍然存在，因此整体节省取决于具体视角数、分辨率和实现方式。

## 2.2 迭代代理细化

- 仅从初始特征生成代理，可能无法反映第一次跨视角交互后已经更新的信息。为此，GLPA 在同一去噪步骤内执行两轮交互：
  1. 从当前特征 \(U\) 池化得到代理，执行代理自注意力和局部—全局交互，得到第一轮输出 \(\Delta^{(1)}\)。
  2. 将第一轮结果以有界残差反馈到原始特征，形成第二轮工作状态：
     \[
     X^{(2)} = U + \gamma\tanh(\alpha)\Delta^{(1)}.
     \]
     其中 \(\alpha\) 是每个注意力层学习的标量，\(\gamma\) 是固定超参数，因此反馈系数绝对值不超过 \(\gamma\)。
  3. 从更新后的 \(X^{(2)}\) 重新池化代理，再执行代理自注意力和局部—全局交互，输出第二轮结果。
- 两轮复用同一组注意力参数，不增加额外扩散采样步骤或新的注意力层；但第二轮需要额外计算。论文默认采用池化步幅 \(s=2\)、交互轮数 \(R=2\)。

## 2.3 骨干网络适配

- 方法分别适配了 Transformer 架构的 **FLUX.1-dev** 和 UNet 架构的 **Stable Diffusion 2.1-UnCLIP**。
- SD 版本沿用代理构造与迭代细化思路，并按 UNet 的视角和数据域结构组织局部注意力。

# 3. 实验设计

## 3.1 数据集与评测场景

- **训练数据：** Objaverse 的 LVIS 子集，约 32,000 个 3D 物体。论文将物体归一化并从预设视角渲染 RGB 图像和法线图，分辨率为 \(512\times512\)。
  - FLUX 配置生成 8 个视角；
  - SD 配置生成 12 个视角。
- **主要 benchmark：** Google Scanned Objects（GSO）数据集，用于多视角生成与 3D 重建评测。
- **真实场景补充：** 使用互联网收集的图像做定性测试，考察真实图像上的泛化表现，但未报告相应的系统量化指标。
- **评测指标：**
  - 新视角合成（NVS）：LPIPS、SSIM、PSNR；
  - 3D 重建：Chamfer Distance（CD）和 IoU。

## 3.2 对比方法

- **注意力基线与变体：** Dense attention、GLPA（无细化）、第二轮复用旧代理的 GLPA，以及完整 GLPA。
- **相关高效注意力方法：** PT-DiT、Agent Attention；在 SD 效率对比中还包括 Era3D、CTR3D。
- **完整系统比较：** 与 RealFusion、Zero-1-to-3、One-2-3-45、Shap-E、Magic123、SyncDreamer、Wonder3D、LGM、Era3D 和 CTR3D 等方法比较生成或重建结果。
- 需注意：这些系统方法所用骨干、训练数据和流程可能不同，不能简单视为完全同条件的注意力模块对比。

# 4. 资源与算力

- **训练硬件：** 两种骨干均使用 **8 张 NVIDIA A100 GPU**。
  - SD2.1-UnCLIP：训练 40,000 步，总 batch size 128；
  - FLUX.1-dev：训练 10,000 步，总 batch size 32。
- **推理设置：**
  - SD：DDIM 40 步，guidance scale 3.0；
  - FLUX：Euler flow-matching 采样 28 步，guidance scale 3.5。
- **训练时长未报告：** 论文没有提供总 GPU 小时、实际训练墙钟时间、A100 显存规格或训练能耗，因而无法据此估算完整训练成本。
- **效率结果主要是注意力开销，而非端到端耗时：**
  - FLUX：每个去噪步骤的注意力运行时间由 1.637 秒降至 0.617 秒，约 **2.65 倍加速**；
  - SD：由 0.730 秒降至 0.405 秒，约 **1.80 倍加速**；
  - 另一个注意力模块测试中，FLUX 的 GLPA 延迟为 22.07 ms、峰值显存 0.601 GB；SD 对比中 GLPA 延迟为 5.02 ms、峰值显存 0.156 GB。
- 这些数值是注意力模块或注意力计算层面的统计，不能直接等同于完整扩散生成的整体加速比例。

# 5. 实验数量与充分性

- 论文报告了多类实验：GSO 上的整体 NVS 与重建评测、不同注意力设计比较、代理细化消融、池化步幅与交互轮数消融，以及互联网图像上的定性展示。
- **主要消融包含：**
  - 关闭迭代细化；
  - 第二轮沿用第一轮代理，而非重新构造；
  - 池化步幅 \(s=2,4,8\)；
  - 交互轮数 \(R=1,2,3\)。
- 池化与轮数实验显示：从 \(R=1\) 增至 \(R=2\) 时质量改善，但增至 \(R=3\) 后性能下降、计算增加；增大步幅虽降低计算开销，却会损害生成与重建质量。
- 方法验证覆盖两个结构不同的扩散骨干，这是较有价值的泛化检验。不过，替代注意力设计的 FLUX 比较只使用 **6,000 个训练样本、训练 2,000 步、20 个测试样本**，评测规模有限。
- **总体评价：** 对方法内部设计的消融较完整，且同时评测生成与重建；但外部比较和统计报告仍不足以全面证明跨数据集、跨场景的稳健性。文中未报告多随机种子、置信区间或显著性检验，结果的统计稳定性难以判断。
- **公平性方面：** 同一骨干内 Dense 与 GLPA 的效率比较相对直接；跨方法比较可能受模型架构、训练预算、采样流程和实现优化差异影响。论文提供了统一协议的注意力替代设计对比，但样本和训练步数有限。

# 6. 主要结论与发现

- GLPA 在压缩跨视角通信的同时保留视角内全分辨率处理，在两种扩散骨干上均能显著降低注意力开销。
- **FLUX 上：** 完整 GLPA 将注意力运行时间从 1.637 秒降至 0.617 秒；CD 从 0.0193 降至 0.0185，IoU 从 0.6849 升至 0.7019，LPIPS 从 0.086 降至 0.076，SSIM 从 0.922 升至 0.927。PSNR 则从 28.03 降至 27.80，说明并非所有指标都提升。
- **SD 上：** 完整 GLPA 相对密集注意力将注意力运行时间从 0.730 秒降至 0.405 秒，并改善 CD、IoU、LPIPS、SSIM 和 PSNR 五项质量指标。
- 消融结果支持迭代代理细化的作用：重新从更新后的特征构造代理，通常优于第二轮复用旧代理；但更多交互轮数并不必然更好。
- 论文还报告，GLPA 在所测配置下比 Dense attention 具有更低的峰值显存；与 PT-DiT、Agent Attention 的比较中，也呈现较好的质量—显存折中。

# 7. 优点

- **设计动机明确：** 将视角内细节处理与跨视角信息交换分开，针对性地压缩较昂贵的跨视角路径。
- **避免过度压缩本地特征：** 与先缩减全部 token 再交互的方案不同，GLPA 保留完整分辨率的视角内路径，有利于细节保真。
- **迭代机制简洁：** 代理依据更新后的特征重建，且复用注意力参数；通过有界残差反馈控制更新幅度。
- **验证维度较丰富：** 同时报告 NVS、几何重建、注意力运行时间和峰值显存，并对关键组件进行了消融。
- **跨架构适配：** 在 Transformer 型 FLUX 和 UNet 型 Stable Diffusion 上均有实验，说明方法并非只针对单一网络结构。
- **质量与效率兼顾：** 在多数报告指标上，完整 GLPA 不仅加速注意力计算，也改善了重建质量和部分 NVS 指标。

# 8. 不足与局限

- **评测覆盖有限：** 主要量化 benchmark 是 GSO；真实互联网图像仅展示定性结果，缺少规模化的真实场景量化验证。多视角数和分辨率的系统扩展实验也较少。
- **统计可靠性不足：** 未报告多次运行、置信区间或显著性检验；注意力替代设计的比较仅在 20 个测试样本上进行，结论可能受样本选择影响。
- **效率口径需谨慎：** 主要报告注意力模块或每步注意力计算时间，没有充分呈现端到端生成延迟、完整推理显存、吞吐量或训练成本；实际应用中的总收益可能与注意力加速比例不同。
- **额外迭代有成本：** 代理细化改善质量，但第二轮及更多轮会增加计算；消融显示第三轮反而降低质量，表明迭代收益依赖具体配置。
- **代理表达能力受池化限制：** 平均池化无可学习的 token 选择机制，可能在细小部件、非均匀重要区域或复杂几何对应关系上丢失信息。增大池化步幅导致质量下降，也说明代理空间分辨率是关键权衡。
- **跨方法公平性有限：** 不同系统方法的骨干、训练数据、训练预算和重建流程可能不同；相关排行榜结果可供参考，但不应全部解释为 GLPA 单一模块带来的因果优势。
- **复现信息仍不充分：** 论文没有给出训练墙钟时间、GPU 小时等关键资源指标；若要评估实际部署成本，还需要更完整的实现与硬件信息。
