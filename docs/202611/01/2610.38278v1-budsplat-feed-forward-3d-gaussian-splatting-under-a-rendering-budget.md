## 摘要
前馈式 3D Gaussian Splatting 近年来已成为逐场景优化的一种有前景的替代方案。它能够直接根据输入图像预测高斯基元，从而快速合成新视角。然而，当输入从稀疏多视图扩展到密集多视图时，其渲染效率很快便会遇到瓶颈：尽管更多视图提供了更丰富的几何约束，却也会导致候选高斯基元的数量迅速增加。现有方法无法可靠地区分冗余基元，因而会在被反复观测的区域产生大量冗余基元，增加渲染成本，却难以显著提升视觉质量。我们提出 BudSplat，这是一种紧凑的前馈式 3DGS 框架，能够学习在基元数量受限的条件下保留最有价值的高斯基元。BudSplat 包含两项创新设计。第一项是细节感知重要性分数，该分数从多层级视觉 token 中提取，为剪枝可能损害感知质量的区域提供显式提示。该分数可注入体素融合过程，从而在多视图聚合时保留高价值的局部贡献。第二项是质量感知高斯剪枝，通过综合考虑渲染贡献和细节重要性来选取紧凑的基元集合。质量感知剪枝支持局部配额再分配，有助于避免将过多基元分配给大面积冗余区域。在 RE10K、DL3DV 和 ACID 上的实验表明，BudSplat 在渲染质量与效率之间实现了良好的权衡。

## Abstract
Feed-forward 3D Gaussian Splatting has recently emerged as a promising alternative to per-scene optimization, enabling fast novel view synthesis by predicting Gaussian primitives directly from input images. However, it quickly faces a bottleneck of rendering efficiency while scaling from sparse to dense multi-view inputs, which offer more geometric constraints but produce a rapidly growing set of candidate Gaussians. Existing solutions cannot reliably distinguish redundant primitives, leading to many redundant primitives from repeatedly observed regions and increased rendering cost without much gain in visual quality. We propose BudSplat, a compact feed-forward 3DGS framework that learns to keep the most valuable Gaussians under a limited primitive count. BudSplat has two novel designs. The first is a detail-aware importance score that is extracted from multi-level visual tokens, providing an explicit cue for regions where pruning is likely to harm perceptual quality. The score can be injected into voxel fusion to preserve high-value local contributors during multi-view aggregation. The second is quality-aware Gaussian pruning that selects a compact set of primitives by jointly considering rendering contribution and detail importance. The quality-aware pruning enables local quota redistribution that helps avoid over-allocating primitives to large redundant regions. Experiments on RE10K, DL3DV, and ACID show that BudSplat achieves a favorable trade-off among rendering quality and efficiency.

# 论文总结：BudSplat——在渲染预算约束下的前馈式 3D Gaussian Splatting

## 1. 核心问题与整体含义

- **研究背景：** 3D Gaussian Splatting（3DGS）能以显式高斯基元高效渲染新视角，但传统方案通常需要针对每个场景单独优化。前馈式 3DGS 直接根据多视图图像预测高斯，可省去逐场景优化；但当输入视图增多时，候选高斯也会快速增长，抬高渲染成本。
- **核心矛盾：** 更多视图通常能提供更充分的几何约束，却会在重复观测区域产生大量相似基元。简单依靠置信度、透明度或全局 top-k 剪枝，可能保留大片平滑区域的冗余高斯，同时删掉薄结构、边界和高频纹理等对感知质量更敏感的细节。
- **论文主张：** 剪枝不应只是预测完成后的压缩步骤，而应被视作一种**有限渲染预算下的基元分配问题**：识别哪些高斯更值得保留，并让细节重要的区域获得足够预算。
- **整体方案：** BudSplat 在已有前馈式重建流程上，加入细节重要性估计、重要性保持的体素融合，以及质量感知剪枝与局部配额再分配，目标是在减少渲染高斯数量的同时尽量保持 novel-view 重建质量。

## 2. 方法论

### 2.1 整体流程

- 以 AnySplat 风格的前馈重建流程为基础，使用 VGGT 从多视图图像预测相机、深度、点图、置信度和多层视觉 token。
- 根据密集几何和图像特征生成候选高斯。
- 从多层 token 中估计 patch 级细节重要性，并把该分数传递到后续体素融合。
- 对融合后的高斯进行质量感知排序，在给定保留比例下剪枝；随后通过 patch 级配额分配缓解全局 top-k 对大面积区域的偏向。

### 2.2 从 token 提取细节重要性

- 对 VGGT 的若干层 token 使用轻量的降维—升维模块，重建 token 中较常见的低秩成分：
  \[
  \hat{x}=W_u\phi(W_d\,\mathrm{LN}(x)).
  \]
- 将原 token 与重建结果的残差 \(r=x-\hat{x}\) 输入线性评分头，得到每层的细节 logit。再对多个层的 logit 进行学习加权，并经 sigmoid 得到 patch 级细节分数。
- 直觉上，低秩重建尝试解释较常见的 token 成分，剩余残差则可能包含边界、细薄结构和局部高频变化等信息。论文同时强调：残差本身不等同于“重要性”，因此还对细节分支进行监督。
- 监督目标结合两类线索：一是当前重建的渲染残差，二是 RGB、深度和法线的局部变化。两类信号经归一化并合成为目标，停止梯度后用于 BCE 训练。

### 2.3 重要性保持的体素融合

- 将空间上落入同一体素的候选贡献者合并。对贡献者 \(j\)，融合 logit 为：
  \[
  \ell_j=\lambda_c c_j+\lambda_d d_j+\lambda_t t_j,
  \]
  其中 \(c_j\) 是置信度，\(d_j\) 是细节分数，\(t_j\) 是局部支持先验。
- 在体素内部通过温度 softmax 得到融合权重，再据此加权融合位置、特征和细节分数。这样，细节分数较高的少数贡献者可以在融合时避免被大量平滑区域观测稀释。
- 融合后记录体素支持数 \(s_m\)，并结合最大权重贡献者的 token 来源，为每个融合高斯保存后续剪枝和配额分配所需的信息。

### 2.4 质量感知剪枝与配额再分配

- 训练时，轻量 gate 预测软保留概率 \(q_m\)，用其调节高斯透明度；训练过程逐步降低 gate 下限、收紧保留比例，并通过直通估计让硬选择参与前向渲染的同时保留 gate 的梯度路径。
- 推理时，根据下式为融合高斯排序：
  \[
  r_m=\log(\alpha_m+\epsilon)+\beta D_m-\gamma\log(1+s_m),
  \]
  其中：
  - \(\alpha_m\)：透明度，近似反映渲染贡献；
  - \(D_m\)：细节重要性；
  - \(s_m\)：体素支持数，用于温和抑制可能的重复冗余。
- 在总预算 \(K=\lceil\rho M\rceil\) 下，先按分数筛选。为避免全局 top-k 被大量候选的平滑区域主导，方法再按 patch 分配局部配额：先根据候选数设置基础配额，再依据 patch 细节强度和剩余容量分配余量。各 patch 内仍按同一排序分数选取高斯。
- 训练目标包含重建损失、细节分支损失、预算匹配损失、gate 正则，以及由渲染重要性和同一步未门控教师提供的辅助监督。

## 3. 实验设计

### 3.1 数据集与评测场景

- **训练数据：** RealEstate10K（RE10K）与 DL3DV 混合训练，采样权重分别为 0.7 和 0.3。
- **评测数据：**
  - RE10K：含室内外前向场景及较平滑的相机轨迹；
  - DL3DV：场景和视角变化更丰富；
  - ACID：作为域外数据集，测试跨数据集泛化。
- **评测协议：** 基于 NoPoSplat 的测试视图候选构造低重叠、大基线压力测试。RE10K 和 ACID 筛选视角重叠率低于 30% 的视图对，并在相机轨迹间采样目标视图；DL3DV 则对候选轨迹段的端点视角筛选低于 30% 重叠的片段。作者指出，这一协议与标准 benchmark 不同，因此绝对分数不宜直接与标准设置下的公开结果比较。
- **指标：** PSNR、SSIM、LPIPS，以及实际用于渲染的高斯数量（#GS）。测试输入视图数为 16、20、24、32、48、72，渲染分辨率为 \(448\times224\)。

### 3.2 对比方法

- **GGN：** 建模高斯组关系并进行 Gaussian pooling。
- **AnySplat：** 使用可微体素化融合密集高斯。
- **WorldMirror：** 通用前馈式世界重建方法，输出包括 3D 高斯。
- **VolSplat：** 体素对齐预测方法，但要求已知相机位姿；作者将其视作 pose-aware 参考，并承认与无位姿方法并非严格公平比较。

### 3.3 实验结果概览

- 主结果表覆盖 3 个数据集、3 个代表性视图数（16、32、72）和两种 BudSplat 保留比例（5%、40%）；补充表给出 20、24、48 视图结果。
- 以 RE10K、72 视图为例，BudSplat 40% 设置报告 23.78 PSNR、0.842 SSIM、0.173 LPIPS、1384K 个高斯；对应的 AnySplat 与 WorldMirror 分别使用 3461K 和 3034K 个高斯。
- 5% 设置可将高斯数量压到数万至数十万量级，但质量并非在所有数据集和指标上都优于其他方法。例如 RE10K 72 视图的 5% 设置有 173K 个高斯，PSNR 为 23.52；而 ACID 上 5% 设置的 LPIPS 整体也不如 40% 设置。
- 论文还报告了定性比较，以及剪枝前后投影高斯密度和 RGB 差异可视化，用于观察高斯预算的空间分配。

## 4. 资源与算力

- 实验使用 **8 张 NVIDIA H100 GPU**，采用混合精度训练，批量大小为每张 GPU 1。
- 使用 AdamW，学习率 \(2.0\times10^{-4}\)，warm-up 180 步，训练 **8K 步**。
- 输入分辨率为 \(448\times224\)。文中未报告完整训练耗时、每场景推理耗时或能耗，因此无法据此估计实际训练成本。
- 作者测得 24 视图时，完整训练步骤的每卡峰值显存约 **42 GB**；仅 VGGT 前向—反向的峰值约 **33 GB**。这两项是分别测得的峰值，不能简单将差值解释为 BudSplat 新模块的显存开销。
- 论文指出，BudSplat 的主要限制之一是剪枝发生在 VGGT 几何骨干之后，因此它降低的是最终表示和渲染阶段的高斯数量，不能消除骨干处理密集输入时的计算与显存负担。

## 6. 主要结论与发现

- 在多视图输入增加时，BudSplat 能显著减少实际渲染的高斯数量，同时在 RE10K、DL3DV 和 ACID 上保持有竞争力的图像质量。
- 更高保留预算的 BudSplat（40%）通常更容易达到较高质量；更激进的 5% 设置进一步降低高斯数量，但会付出一定质量代价，且代价因数据集和指标而异。
- 消融结果表明，细节 token 重要性、重要性保持的体素融合、质量感知排序和 patch 配额都对最终效果有贡献；去除细节 token 分支造成的性能下降最明显。
- 定性密度分析与论文设计相符：剪枝主要减少平滑或重复观测区域的冗余支持，同时相对保留边缘、边界和纹理丰富区域。不过，这类分析是定性且依赖目标视角的，并非对所有场景都成立的定量保证。

## 7. 优点

- **问题定位明确：** 将高视图数下的高斯膨胀视为渲染预算分配问题，而非单纯的后处理压缩。
- **重要性贯穿流程：** 细节线索在融合前就参与体素聚合，避免只在融合后排序、无法恢复已被稀释的局部贡献。
- **融合与剪枝相互配合：** 先在体素内调整贡献权重，再在高斯层面排序，最后按 patch 重新分配预算，形成较完整的紧凑化流程。
- **有预算—质量对照：** 5% 和 40% 两种保留比例展示了压缩强度与重建质量之间的取舍。
- **评估覆盖较广：** 测试了多个数据集和输入视图数，并包含跨数据集评测、消融和密度可视化。
- **局限说明相对充分：** 论文明确指出 VGGT 骨干仍是显存瓶颈、几何质量会影响融合效果，且极小预算仍可能损失复杂细节。

## 8. 不足与局限

- **骨干计算未被压缩：** BudSplat 在 VGGT 预测密集几何之后才控制高斯数量，因此不能直接解决密集多视图输入下的 VGGT 计算和显存瓶颈。
- **依赖重要性估计及几何质量：** 如果细节分数错误，或不同表面被分到同一体素，基于加权平均的融合可能损失结构；作者也指出方法依赖几何和置信度预测的可靠性。
- **极低预算下仍有损失：** 复杂区域可能无法用很少的高斯充分表达；5% 设置的结果显示强压缩与质量之间仍存在明显权衡，且各数据集表现不一。
- **评测覆盖仍有限：** 论文未测试专门的稀疏 360° benchmark；低重叠协议对特定视角关系进行筛选，不能代表所有真实应用场景。
- **统计报告不足：** 未见多次运行方差或置信区间，消融的跨数据集、跨预算覆盖也有限。
- **效率指标不完整：** 报告了高斯数量和显存，但没有提供明确的推理延迟、每场景处理时长或完整训练耗时；高斯数量下降并不自动等同于相同比例的端到端加速。
- **基线比较存在条件差异：** VolSplat 使用已知位姿；不同基线的资源需求和 OOM 情况也不一致，因此某些设置下的性能对比不能视为完全同条件的比较。
