## Abstract 

We study 3D visual grounding in 3D Gaussian Splatting (3DGS), where a referring expression should identify a target object as both a rendered 2D mask and a set of explicit 3D Gaussians. Prior methods typically extract 3D targets by applying heuristic thresholding or top-ratio filtering to dense primitive-level relevance scores. However, these scores often vary substantially across scenes and prompts, making such heuristics sensitive and leading to unstable targeting. ClusterSplat addresses this by reframing 3D target selection as cluster-level selection over scene-adaptive candidates. The method first learns instance-aware Gaussian features, forms feature-aware seed voxels, and merges neighboring seed voxels when a description-length criterion decreases, producing a scene-specific set of cluster candidates. Given a referring expression, a query-conditioned cluster scorer ranks the cluster candidates with a lightweight MLP, and the selected cluster directly defines the explicit 3D tar-get while its cluster score is rendered for the 2D mask. On ScanRefer, ClusterSplat achieves the best rendered 2D segmentation and explicit 3D target metrics among the compared 3DGS baselines. It also obtains the best average Ref-LERF scores, supporting the same trend under fine-grained referring descriptions. On ScanNet v2 class name queries, ClusterSplat achieves the strongest rendered 2D results and the highest 3D matching accuracy, while maintaining competitive 3D IoU. Our project page is available at https://jaesung8.github.io/clustersplat/ .

3D Gaussian Splatting (3DGS) has recently emerged as a compelling explicit alternative to neural radiance fields [1]. It offers photorealistic novel-view synthesis with real-time rendering capabili-ties [2]. Beyond visual rendering, 3DGS is rapidly evolving into a general-purpose 3D representation capable of structural modeling [3, 4] and semantic understanding [5–8]. A pivotal direction in this evolution is language grounding. This capability enables natural-language querying of 3D scenes through referring expressions. While recent approaches have successfully lifted vision-language embeddings into 3D space for open-vocabulary querying [5, 9], explicitly extracting the precise 3D extent of a target object remains a significant challenge. The core difficulty lies in the continuous nature of the relevance fields used in prior works. Existing methods typically compute dense, primitive-level relevance scores and isolate the target by applying heuristic discretization, such as global thresholding or top-k filtering [6, 10, 11]. However, these heuristics are highly sensitive in open-vocabulary settings. Relevance score distributions often vary substantially with the scene context and the complexity of the prompt (e.g., compositional attributes or spatial relations). Consequently, relying on scale-sensitive hyperparameters often leads to unstable targeting. Figure 1 illustrates this failure mode: top-ratio filtering can scatter selected primitives across the referred object and nearby distractors rather than producing one coherent 3D target. As shown by the top-ratio analysis in Appendix B.1, dense relevance fields often lack clear decision boundaries, causing the target to be missed or merged with background under a fixed selection ratio. Moreover, indoor scenes vary substantially in object count, object scale, clutter, and same-class distractors, so cluster candidates should adapt their granularity to the scene structure. Section 4.3 analyzes the candidate-quality trade-off behind this design choice. To overcome this instability, we design ClusterSplat as a cluster-level targeting framework (Figure 2) that shifts the selection granularity from individual primitives to scene-adaptive cluster candidates. We view the cluster index as the coarse decision variable for a single referred target and construct these candidates with a scene-adaptive merge procedure guided by description length. These observations, together with the scattered primitive selections in Figure 1, motivate formulating 3D target selection as a discrete selection problem over coherent object-level candidates rather than as a filtering task over millions of unstructured primitives. The framework can be viewed as two stages that align with the offline scene preparation and query-conditioned grounding blocks in Figure 2. First, we optimize instance-aware Gaussian features and construct feature-aware seed voxels. We then build a candidate graph over seed-voxel descriptors and merge adjacent components only when the description length decreases, producing a scene-specific number of clusters. Second, during target selection, a query-conditioned cluster scorer ranks the candidates with a lightweight MLP to select the target cluster. The selected cluster directly defines the explicit 3D target, and its cluster-level scores are rendered to produce the 2D mask. Furthermore, we observe that the advancement of 3DGS grounding is hindered by the lack of evaluation protocols that jointly assess rendered 2D masks and explicit 3D target sets. Current benchmarks like Ref-LERF [12] are limited in scene diversity, while standard semantic segmentation metrics fail to capture the nuances of compositional language grounding. Class name prompts provide category-level grounding, but they cannot uniquely specify one target when multiple objects from the same category appear in a scene. Referring expressions address this ambiguity through attributes and spatial relations, making ScanRefer a more demanding test of object-level targeting. To bridge this gap, we define a reproducible evaluation protocol that combines official ScanNet v2 annotations with ScanRefer expressions [13, 14]. Our main comparison uses the subset of 10 scenes adopted by recent 3DGS open-vocabulary baselines for reproducibility. This enables class name grounding and referring expression segmentation to be reported on the same ScanNet v2 scenes. In summary, our contributions are as follows: • We introduce a scale- and granularity-aware formulation for 3D visual grounding in 3DGS. By transforming primitive-level score filtering into cluster-level selection over scene-adaptive candidates, we avoid per-query score thresholds while allowing the cluster granularity to follow the scene structure. • We propose ClusterSplat , a two-stage framework that first learns instance-aware Gaussian features and constructs scene-adaptive clusters with a description-length criterion, followed by query-conditioned cluster scoring for explicit target selection and 2D mask rendering. 2• We evaluate ClusterSplat with a reproducible protocol combining ScanNet v2 annotations and ScanRefer expressions that reports class name grounding and referring expression segmentation on the same ScanNet v2 scenes. • On the ScanRefer benchmark, experiments show state-of-the-art referring segmentation among the compared 3DGS baselines. Ref-LERF further confirms consistent gains in fine-grained scenes, while ScanNet v2 class name evaluation shows improved rendered 2D masks and competitive 3D object matching. 

## 2 Related Work 

2.1 3D Gaussian Splatting and Language Grounding 

Neural rendering first achieved high-quality novel-view synthesis with implicit radiance fields [1], while recent explicit representations such as 3DGS provide real-time rasterization-based rendering [2]. Explicit primitives also support faster optimization and direct geometric manipulation compared with fully implicit scene encodings. Subsequent work improves 3DGS through structural regularity, filtering, surface-aligned primitives, and alternative optimization strategies [3, 15–17]. Beyond rendering, explicit Gaussian primitives have become a substrate for semantic and language-aware feature fields learned through language embeddings, 2D foundation-model distillation, or cross-modal rasterization [5, 7, 8, 18–20]. However, view-consistent semantic rendering does not by itself define a reliable single-object 3D target. Dr. Splat directly registers language embeddings to Gaussians [10], interaction-oriented methods lift 2D prompts into Gaussian space [21, 22], and instance-level Gaussian representations recover object-level subsets [23, 24]. Yet many pipelines still extract targets from continuous relevance scores using thresholding, top-k selection, or related discretization rules [6, 10, 11]. These rules remain sensitive to scene- and prompt-dependent score scales, which makes explicit 3D targeting unstable. This sensitivity has also motivated alternatives to fixed similarity cutoffs, such as hyperplane-based selection of Gaussians of Interest [11]. Referring tasks in 3D Gaussian scenes make this limitation more apparent. ReferSplat introduces the Ref-LERF benchmark and obtains supervision from reliable Grounded-SAM candidates [12, 25], but view-wise mask cues can still under-specify whether a prediction forms one coherent 3D instance when the Gaussian representation admits ambiguous groupings [6]. Related 3DGS methods use grouped or instance-aware structure for point-level open-vocabulary understanding, view-dependent semantic aggregation, or dense open-vocabulary 3D segmentation [6, 26, 27]. These objectives are complementary to our setting, where a referring expression should select one referred target. This motivates grouping primitives into stable candidates and performing discrete selection in the grouped space. In ClusterSplat, clusters serve as the decision domain for single-target referring expressions, and the selected cluster directly determines the explicit 3D target. 

2.2 3D Visual Grounding 

3D visual grounding aims to localize a language-specified target within a 3D scene. It is commonly separated into comprehension tasks, which predict a coarse target location such as a box, and segmentation tasks, which predict a precise point- or mask-level region [14, 28]. ScanNet v2 scenes and ScanRefer expressions have been instrumental in this area by providing RGB-D reconstructions with rich, compositional language descriptions [13, 14]. Related 3D referring-expression datasets further study language grounding beyond a single benchmark family [29]. Building on these datasets, point-cloud methods have improved language-geometry alignment and relational reasoning [28, 30, 31]. Open-vocabulary 3D scene understanding has also been explored with CLIP-aligned point features and class-agnostic 3D mask proposals before the recent shift toward 3DGS representations [32, 33]. Foundation-model supervision further improves scalability, with AugRefer generating diverse synthetic supervision [34] and SeeGround enabling zero-shot grounding by bridging 3D scenes with 2D vision-language models [35]. Adapting this progress to 3DGS requires care because 3DGS optimizes unstructured primitives pri-marily for rendering. Unlike explicit point clouds, Gaussian primitives are not directly organized as semantic units, so pixel-level parsing can hide failures in the underlying 3D target set. ## 3 Method 

3.1 Problem Definition and Target Selection Problem Definition. We study 3D visual grounding in a 3DGS scene representation. A scene is modeled as a set of Gaussian primitives G = {gi}Ni=1 . Each primitive gi has geometric and appearance parameters (mean μi ∈ R3, covariance Σi, opacity αi, and spherical harmonics SH i). We augment each primitive with a learnable instance-aware feature fi ∈ RDf . Given a query q with referring expression text Tq , the model predicts two outputs. The first is a 2D segmentation mask for an arbitrary camera pose π, denoted by M2D (π). The second is a 3D target represented as a subset of Gaussians, Starget ⊂ G . We focus on the single-target referring setting and introduce a query-specific target cluster index k⋆q ∈ { 1, . . . , K s}. Here, Ks is the scene-specific number of cluster candidates produced for scene s.

3D Targeting via Scene-Adaptive Clusters. Prior 3DGS language grounding pipelines typically compute continuous relevance scores over primitives and extract the target using heuristic filtering rules. However, such primitive-level filtering is inherently unstable as score distributions vary substantially across scenes. Cluster-level selection provides a more structured decision space, but the cluster candidates must remain faithful to scene-dependent object scale and clutter. We therefore formulate 3D visual grounding as selection among scene-adaptive cluster candidates. By aggregating Gaussians into clusters, we reformulate the challenging dense prediction task into a tractable discrete selection problem. Crucially, this simplification relies on clusters representing coherent object-level candidates rather than arbitrary geometric fragments. Our cluster candidates are generated by a scene-adaptive merge procedure guided by description length over feature-aware seed voxels defined in Section 3.2. This allows the number of cluster candidates to vary across scenes. For scene s, we partition the Gaussians into Ks ≪ N clusters {G k}Ks

3.2 Instance-Aware Gaussian Feature Learning and Scene-Adaptive Clustering Instance-aware Gaussian feature learning. Stage 1 adapts an instance-aware Gaussian feature objective related to OpenGaussian [6], using training-view instance masks to learn geometry-aligned Gaussian features. Each Gaussian has a learnable feature fi ∈ RDf . These features are rendered to feature maps with the same opacity-aware compositing used by 3DGS. Within each training mask, rendered features are pulled toward a mask prototype. Prototypes from different masks in the same view are separated to discourage feature collapse. The resulting geometry-aligned feature field is used for scene-adaptive cluster construction. Appendix A.2 provides the detailed loss definitions. 

Scene-adaptive clustering. After feature learning, we construct cluster candidates from feature-aware seed voxels. Each Gaussian is assigned using its scene-normalized spatial voxel index and the dominant signed dimension of its ℓ2-normalized instance feature. This initialization over-segments the scene so Gaussians with different feature directions can remain separate even within the same spatial voxel. For each seed voxel, we compute a normalized feature prototype ϕa and a 3D centroid. A minimum spanning tree (MST) in the whitened feature-position descriptor space restricts the candidate merges. During greedy merging, a component S is a connected set of seed-voxel prototypes. We evaluate each component with an MDL-inspired description-length cost and a BIC-style component penalty [36, 37]:

## 4 Experiments 

4.1 Experimental Setup Datasets. To evaluate 3D visual grounding in 3DGS, we use two complementary benchmarks. We first pair ScanNet v2 [13] RGB-D scenes and official annotations with ScanRefer [14] referring expressions, using the scene subset and preprocessing convention adopted by recent 3DGS open-vocabulary evaluations. ScanRefer provides referring expressions and target object IDs for objects in the ScanNet v2 scenes, enabling evaluation of both class name grounding and referring expression segmentation within the same reconstructed scenes. We also use Ref-LERF from ReferSplat [12] to assess fine-grained spatial reasoning in small-scale scenes; Appendix A.4 gives the ReferSplat confidence-weighted IoU pseudo-mask rule used for Ref-LERF supervision. 

Evaluation Protocol. For ScanNet v2 and ScanRefer, we evaluate on the common 10-scene subset adopted by OpenGaussian [6]. Table 1 reports two complementary settings on the same reconstructed scenes: ScanRefer referring segmentation and ScanNet v2 class name grounding. Both settings evaluate rendered 2D masks and explicit 3D Gaussian target sets. Appendix A.4 and Appendix A.5 provide the held-out view split, annotation sources, and object ID propagation details. 

Baselines. We compare ClusterSplat against language-embedded 3DGS pipelines, including LangSplat [5], OpenGaussian [6], Dr.Splat [10], and ReferSplat [12]. Prior works typically output continuous primitive relevance scores, so they require thresholding or top-ratio discretization to define a 3D target set. We therefore sweep the top-ratio in {0.01 , 0.02 , . . . , 0.10 } for each score-based baseline and report the best per-method oracle result; ClusterSplat instead uses Top-1 cluster selection and does not tune a per-query or per-scene score threshold. 

4.2 Benchmark results ScanRefer referring segmentation. ScanRefer directly evaluates the referred-object setting be-cause each referring expression is tied to a specific object ID in a ScanNet v2 scene. Table 1 therefore reports ScanRefer first. Compared with ScanNet v2 class name evaluation, ScanRefer is more demanding because the model must identify one referred object among category distractors using attributes, spatial relations, and instance-specific language. Under this setting, ClusterSplat improves both rendered 2D segmentation and explicit 3D target selection over the compared 3DGS baselines. The comparison with ReferSplat trained under the same supervision indicates that the gain is not solely attributable to pseudo-caption or mask supervision, but also to the cluster-level selection architecture. The larger improvement in 3D target metrics further suggests that this architecture is especially useful when the query contains attributes or spatial relations that make primitive-level score filtering unstable. 

ScanNet v2 class name evaluation. The ScanNet v2 class name results in Table 1 provide a complementary diagnostic on the same evaluation scenes. ClusterSplat substantially improves rendered 2D segmentation, indicating that the selected clusters provide stable image-space evidence across held-out views. ## 5 Discussion and Limitations 

ClusterSplat reduces dependence on primitive-level score filtering by selecting a scene-adaptive cluster as the explicit target. Its main limitation is therefore the candidate pool. Over-merging nearby similar objects or splitting one object across several clusters can limit the conservative Top-1 selection. This explains why ScanNet v2 class name matching accuracy is strong while exact 3D IoU remains stricter: the selected cluster can overlap the correct object enough for matching, yet still miss parts of the object extent or include nearby fragments. Future work can handle fragmented candidates with uncertainty-aware multi-cluster selection. Our formulation handles expressions that refer to a single object. Separate queries can select several objects, but grounding a plural expression that refers to a variable number of instances remains future work. The experiments cover ten indoor ScanNet v2 scenes and four Ref-LERF scenes, with each scene prepared separately. Broader scene coverage and transfer to unseen scenes remain to be evaluated. Training relies on annotated instance masks and generated descriptions, and each new scene requires offline preparation before queries can be processed. 

## 6 Conclusion 

We presented ClusterSplat, which converts 3DGS visual grounding from primitive-level score filtering into discrete selection over scene-adaptive Gaussian clusters. The method learns instance-aware Gaussian features, builds scene-adaptive clusters with a description-length criterion, ranks them with query-conditioned scoring, and renders cluster-level scores for 2D mask prediction. Results show state-of-the-art referring segmentation on ScanRefer among the compared 3DGS baselines, with Ref-LERF providing complementary fine-grained validation. The method also produces strong rendered masks and competitive 3D object matching on ScanNet v2. These results support scene-adaptive cluster selection for referring expression grounding in 3DGS. ## A Implementation Details 

A.1 System Setup and Hyperparameters 

Unless otherwise specified, experiments are conducted on a single NVIDIA RTX 5090 GPU. The online efficiency measurements in Appendix B.6 are measured on an NVIDIA RTX A6000 server. We implement our framework using PyTorch 2.8.0+cu128 and CUDA 12.8. To ensure training stability and precision, mixed-precision training is not employed. For the model architecture, we use a frozen CLIP text encoder [38] and project token embeddings to the ClusterSplat cluster/text hidden dimension dp = 64 . Cluster assignments are loaded from the offline scene-adaptive feature-clustering step and used as fixed assignments during Stage 2. The resulting scene-specific cluster counts on the 10-scene ScanNet v2 subset are 53-143, with an average of 87.3 clusters per scene. The token-conditioned cluster scorer is a two-layer MLP with one hidden layer of dimension 128, separate from the prototype dimension dp. The same cluster scores are used for Top-1 3D target selection and rendered 2D mask prediction. The model is optimized using the Adam optimizer with a fixed learning rate of 1 × 10 −4 for all experiments. The total number of training iterations is set to 10,000. We use the focal and Dice segmentation objective with equal weights and do not use cluster-entropy regularization in the current full setting.

Interleaved Train/Evaluation Split. To rigorously evaluate 3D generalization on unseen viewpoints, we adopt an interleaved evaluation split. We define the evaluation set Veval as every 20th frame with an offset of 10. The remaining frames constitute the training set Vtrain . All pseudo-caption generation and feature supervision construction are performed after this split and only on Vtrain , so the held-out evaluation frames are never used to construct training supervision. 

Evaluation Protocol Details. The main quantitative table for ScanNet v2 and ScanRefer reports two related but distinct evaluations on the same reconstructed scenes. The ScanRefer columns use referring expressions tied to target object instances, while the ScanNet v2 columns use class name queries derived from official scene annotations. For 2D evaluation, predicted masks are rendered on held-out frames and compared with official ScanNet v2 instance annotations projected to those frames [13]. For 3D evaluation, object instance IDs are propagated to Gaussians using the Mahalanobis-distance assignment described below, and IoU is computed over the resulting object ID Gaussian set [10]. ScanRefer target object IDs define the foreground instance for referring segmentation queries, preventing same-category distractors from being counted as target foreground.

A.5 Automated Pseudo Label Pipeline 

We generate language supervision for the training views ( Vtrain ) using training frame ScanNet v2 instance masks and Vision-Language Models (VLMs). The masks are official training frame annotations, while the associated captions are pseudo-captions generated for language supervision. This setting is therefore annotation-assisted rather than annotation-free. Evaluation frame masks, official ScanRefer referring expressions, and evaluation target object IDs are not provided to the pseudo-caption generator or the optimization objective. 

Step 1: Training-frame Instance Mask Extraction. For each training frame, we extract the official ScanNet v2 2D instance masks and compute the tight 2D bounding box for each visible instance. These training frame masks, rather than SAM proposals, serve as the visual anchors for the subsequent caption generation process. 

Step 2: Extensive Pseudo-Caption Generation. Previous works have explored the use of VLMs to generate comprehensive 3D object and scene descriptions at scale [34]. Similarly, we employ GPT-4.1 [47] to generate five diverse pseudo-captions for each training frame instance mask. The GPT-4.1 input consists of the training RGB image, the instance mask, and its bounding box; it does not include official ScanRefer expressions, evaluation target object IDs, evaluation-frame masks, or 3D object annotations. Unlike 3D visual grounding methods that rely on a single description per object, these multiple pseudo-captions provide richer linguistic variation while remaining independent of the evaluation queries. We prompt GPT-4.1 to describe visual attributes, spatial context, and object distinctiveness visible within the masked region, following the types of attributes emphasized in 3D visual grounding [35]. As shown by the generated captions in Figure 4, this produces pseudo-captions that describe the training frame instance without exposing the held-out target answer.

Template-based Augmentation for ScanNet v2. While GPT-generated captions provide linguistic diversity, short category names in ScanNet v2 (e.g., "chair", "table") can be too terse as language prompts. To provide the CLIP text encoder with natural sentence context, we wrap the class nouns into simple prompt templates: • "There is a {} in the scene." • "The scene contains a {}." • "This visual element is part of a {}." • "This local feature corresponds to a {}." This augmentation preserves class name supervision in a sentence-like form and improves the stability of text-cluster alignment without introducing evaluation queries into training. 19 A.6 Baseline Implementation Details 

We evaluate our framework against four strong language-embedded 3DGS pipelines: LangSplat [5], OpenGaussian [6], Dr.Splat [10], and ReferSplat [12]. To ensure a fair comparison, all baselines are reproduced using their official implementations with the following specific configurations: • LangSplat: We employ the CLIP-based auto-encoder with a latent dimension of 3. • OpenGaussian: We use the official implementation with the SAM-based feature setting and evaluate its continuous relevance scores under the same held-out view split and top-ratio sweep described below. • Dr.Splat: We use the official implementation with the released configuration on the same reconstructed scenes. Its continuous relevance scores are converted to 3D target sets using the same top-ratio sweep, while the Mahalanobis label propagation protocol is used only to construct object ID pseudo-GT for evaluation. • ReferSplat: We train this model using the same training-frame mask and pseudo-caption supervision as our method. This ensures that any performance gains are attributed to our architectural contributions rather than differences in training data quality. 

3D Target Extraction Strategy. A critical challenge in benchmarking is that prior works typically out-put continuous relevance scores, requiring a discretization step to define the 3D target set Starget . As shown in Fig. 5, a fixed global threshold is often suboptimal due to scale variations across scenes. To prevent underestimating the baselines, we adopt an oracle evaluation protocol. Specifically, for each baseline method, we perform a grid search for the top-ratio parameter ρ ∈ { 0.01 , 0.02 , . . . , 0.10 }.We report the best per-method oracle performance achieved across this range. This strategy provides a per-method oracle within the swept range, so the comparison is less affected by under-tuned discretization choices for competing score-based methods.

B.1 Sensitivity Analysis of Selection Heuristics 

We investigated the stability of primitive-level score discretization in existing baselines. To this end, we conducted a grid search on the top-ratio hyperparameter for OpenGaussian [6] and Dr.Splat [10]. We evaluated the 3D targeting performance across 10 ScanNet v2 scenes by sweeping the top-ratio from 0.01 to 0.10 .Figure 5 visualizes the results. We observe that the optimal selection ratio depends heavily on the scene. For example, Dr.Splat peaks at a ratio of 0.04 in scene0070 . However, scene0645 

shows a decreasing trend. This variation indicates that using a fixed global ratio is ineffective for open-vocabulary scenarios. Additionally, the performance curves show sharp peaks. Small deviations from the optimal ratio cause significant drops in 3D IoU. These findings confirm that primitive-level relevance fields lack clear decision boundaries in 3D space. Our method uses a Top-1 cluster extraction rule that removes per-query and per-scene score-threshold calibration during 3D target extraction.
