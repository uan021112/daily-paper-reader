REFERENCE-VIEW ATTENTION REUSE FOR MULTI-VIEW 3D
TRANSFORMERS

ABSTRACT
Feed-forward multi-view 3D reconstruction relies on global attention for cross-view aggregation,
but the attention cost grows quadratically with the number of views, making inference increasingly
expensive for larger inputs. Existing acceleration methods compress tokens or sparsify attention,
potentially losing geometric detail or restricting cross-view aggregation while leaving redundancy
among attention outputs underexploited. We observe similar cross-view attention distributions in
certain layers, revealing an opportunity to reduce repeated global aggregation through output reuse.
However, the layers suitable for reuse vary with the input, and reusing one layer alters the features
received by later layers. Similarity at individual layers therefore cannot characterize the combined
effect of multiple reuse decisions on output drift. To address these challenges, we propose CAR3T, a
training-free framework combining reference-view attention output reuse with offline risk calibration
and online dynamic layer selection. Calibration models cumulative reuse risk, while online selection
adapts reuse to each input under a calibrated budget. CAR3T retains all input tokens and attends
to the keys and values of all views, reducing the core attention computation in selected layers from
quadratic to linear. Experiments on VGGT, DA3, and π3 show forward speedups up to 1.41× with
at most 100 views and 1.75× on longer sequences, with accuracy trade-offs across backbones and
datasets.

Introduction
Multi-view 3D reconstruction recovers scene geometry and camera parameters from images, supporting robotic
perception [1, 2] and autonomous driving [3, 4]. Current feed-forward models such as VGGT [5], Depth Anything 3
(DA3) [6], and π3 [7] learn cross-view feature interactions and predict geometry and camera parameters in a single
forward pass. They aggregate information across views through global attention, whose efficiency is central to scaling
reconstruction to larger inputs.
However, global attention remains a bottleneck when scaling these models to many views. Each view contributes
queries that attend to the keys and values of all views, so the core attention computation grows quadratically with the
number of input views. Efficient kernels such as FlashAttention reduce memory access costs [8], but retain the quadratic
computation of exact dense attention. With dozens or hundreds of input views, repeating global aggregation for every
query becomes expensive.
Existing acceleration methods reduce this cost through token compression [9, 10, 11], sparse attention [12, 13], or
compact global representations [14]. Such compression or sparsification can lose geometric detail or limit information
exchange, yet redundancy among attention outputs remains underexploited. To examine this possibility, we analyze
cross-view attention in VGGT, DA3, and π3 and observe similar attention distributions in certain layers. Since queries
across views share the same global keys and values, similar distributions can produce similar aggregation responses.
This observation motivates reusing a reference view’s attention response across views to reduce repeated computation
while preserving all input tokens and access to all keys and values.

However, applying this reuse poses challenges in both layer selection and the control of output drift. Cross-view
attention similarity varies across layers and inputs, so the suitability of reuse changes with the current features. Moreover,
reusing one layer alters the features passed to later layers, making the final output drift depend on the combination of
reused layers. Similarity at one layer therefore provides an incomplete basis for multiple reuse decisions. Effective
reuse requires adapting layer selection to the input while accounting for cumulative output drift and interactions among
the selected layers.
To address these challenges, we propose CAR3T, a training-free framework that combines reference-view attention
output reuse with offline risk calibration and online dynamic layer selection. In each selected layer, CAR3T computes
the reference view’s attention response over the keys and values of all views and reuses it across views. With one
reference view, this reduces the core attention computation from quadratic to linear in the number of views. The query,
key, value, and subsequent output projections remain unchanged. Other layers retain the original global attention to
preserve view-specific aggregation. Offline calibration relates Query Drift to Output Drift and models single-layer
sensitivity, pairwise interactions, and higher-order combination risks. A Pareto analysis of latency and output drift
on validation inputs determines the reuse budget. During inference, the online module combines query features,
cumulative risk, and a lookahead estimate of future reuse value to guide layer selection under calibrated risk constraints.
CAR3T operates with unchanged pre-trained weights and requires no fine-tuning. Experiments on VGGT, DA3, and
π3 across eight benchmark settings show overall forward speedups of 1.13× to 1.31× with up to 100 input views.
Longer sequences yield speedups up to 1.75×. Pose and reconstruction evaluations characterize the resulting accuracy
trade-offs across backbones and input scales. Our main contributions are:
• We introduce reference-view attention output reuse that reduces the core attention computation while retaining all
input tokens and attending to all keys and values.
• We combine offline risk calibration with online dynamic layer selection to adapt reuse to each input under a
calibrated budget, accounting for cumulative risk and interactions among reused layers.
• We evaluate CAR3T on three feedforward reconstruction models, showing inference speedups across input scales
and quantifying the geometric accuracy trade-offs.

Related Work
Feedforward Visual Geometry Models. In recent years, feedforward visual geometry models have gradually emerged
as a new paradigm distinct from traditional multi-stage optimization pipelines. DUSt3R [15] regresses pixel-aligned 3D
point maps from uncalibrated image pairs, while MASt3R [16] extends it with local features for robust dense matching.
MV-DUSt3R+ [17], Fast3R [18], MUSt3R [19], MVSplat [20], and DepthSplat [21] have advanced multi-view 3D
reconstruction using point maps and 3D Gaussians. With further advancements, VGGT [5] unifies multi-view visual
geometry modeling using a feedforward Transformer architecture, simultaneously predicting camera parameters, depth
maps, point maps, and 3D point trajectories through alternating frame-wise and global attention mechanisms. π3 [7]
and DA3 [6] further reduce reliance on fixed reference frames and specialized architectures, collectively advancing
feedforward 3D reconstruction toward unified and generalizable multi-view geometry models. However, these models
fundamentally depend on dense cross-view global feature interactions, leading to a rapid increase in computational cost
with growing number of views, which becomes a significant efficiency bottleneck when scaling to long sequences and
large-scale scenes.
Efficient Inference for Feedforward 3D Reconstruction Models. Efficient feedforward reconstruction methods
reduce computation through 1) token compression, 2) compact scene representations, or 3) attention sparsification.
FastVGGT [9] prunes tokens based on aggregation patterns, while LiteVGGT [10], HTTM [22], and Co-Me [11]
use geometry-aware caching-based, head-wise temporal, and confidence-guided merging, respectively. Spark3R [23]
combines asymmetric query merging, key-value pruning, and layer-adaptive scheduling. Such compression reduces
attention cost, but merged or removed tokens no longer contribute independently, and aggressive compression may lose
view-specific correspondences and geometric detail. For compact scene representations, FlashVGGT [14] aggregates
information through cross-attention between frame descriptors and image tokens, while VGG-T3 [24] uses test-
time training to distill variable-length scenes into a fixed-size state. These approaches trade representation capacity
against geometric fidelity. For attention sparsification, Block-Sparse Global Attention [25] replaces dense cross-view
interactions with block-sparse connections, AVGGT [12] uses frame-wise attention and sampled key-value tokens, and
SAF3R [13] adaptively selects head-specific computation modes. Reducing these connections can limit cross-view
aggregation and does not explicitly model redundancy among attention outputs across views.

Methodology
This section introduces CAR3T, a framework for accelerating inference in multi-view 3D Transformers. We first outline
the overall workflow of CAR3T in Sec. 3.1. We then motivate global attention reuse through an analysis of cross-view
attention similarity and define the reference query reuse operator in Sec. 3.2. Sec. 3.3 describes the offline calibration of
reuse risk and budgets. Finally, Sec. 3.4 presents calibration-guided online layer selection.
3.1
Overview of CAR3T
As shown in Fig. 1, CAR3T adopts a framework combining offline risk calibration with online dynamic layer selection
to selectively reuse multi-view global attention, thereby reducing computational overhead and controlling model output
drift caused by reuse.
Let L denote the set of indices for candidate global attention layers. In the offline stage, we evaluate reuse configurations
S ⊆L in terms of output drift D(S) and inference latency T(S), and calibrate an empirical risk model bR. In the online
stage, given multi-view input I = {Ii}M
i=1 with M views and the calibrated risk budget Beff, we use the risk model bR
to dynamically select the reuse layers S∗(I) ⊆L.
For each layer ℓ∈S∗(I), CAR3T reuses attention outputs from a certrain reference view r ∈{1, . . . , M} across
views; for all other layers, original global attention computations are preserved. Without fine-tuning the pre-trained
model or training additional selection networks, CAR3T dynamically adjusts its reuse strategy according to input,
achieving a controllable trade-off between inference efficiency and model output consistency.

attention heads, and the shaded regions show the interquartile range. The JSD varies across layers in all three models,

analysis, and use it to determine the risk budget required for online inference.

Risk Budget Determination. After selecting the elbow-point configuration, we re-evaluate the set of reusable layers

the same risk metric. The individual single-layer limit Bsingle prevents any single layer from consuming too much
budget. We calibrate separately for different ranges of the number of views and select the corresponding calibration
result based on the number of input views.
3.4
Calibration-Guided Online Layer Selection
Online Dynamic Layer Selection. During inference, CAR3T decides, in network layer order, whether to reuse each
global attention layer. At layer ℓ, let Sℓ−1 denote the set of layers selected so far, and let S′ = Sℓ−1 ∪{ℓ}. CAR3T
first checks whether the number of input views and the query drift are within the calibrated range. It then performs the
standard checks for the single-layer risk constraint and the cumulative risk constraint:
ρℓ≤Bsingle,
R(S′) ≤Beff.
(15)
To reserve budget for subsequent layers, CAR3T compares two options: reusing the current layer and consuming part
of the remaining budget, or skipping the current layer and retaining the budget. For each option, approximate dynamic
programming uses offline risk estimates to predict how many subsequent layers can be reused within the remaining
budget. CAR3T prefers the option that is expected to yield a larger total number of reusable layers, counting the current
layer toward the total if it is reused. When it reaches a subsequent layer, CAR3T re-evaluates and makes a decision
using the layer’s actual query features.

4.1
Experimental Setup
Implementation Details. We use the images from ScanNet++ to perform offline calibration for each backbone network
separately. We adopt four calibration tiers, each containing 50 scenes, with 38 scenes used for risk model fitting and 12
for budget calibration. Each scene contains up to 50, 150, 250, and 500 views, respectively. The number of views and
tier configuration are set according to the requirements of the test inputs, and during online inference, the calibration
tier is selected based on the number of input views.
Models and Datasets. We evaluate CAR3T on three models: DA3 [6], π3 [7], and VGGT [5]. Each pair of baselines
shares the same pretrained weights, with only the feature reuse setting toggled. Reference view selection for each
model is described in Appx. B.2. The main experiments cover 86 scene settings across ETH3D [27], 7Scenes [28],
ScanNet++ [29], DTU [30], DTU-64 [30], Waymo [31], and vKITTI [32]. Inference efficiency is reported for all the
above settings; camera pose results exclude vKITTI [32]; 3D reconstruction evaluation uses ETH3D [27], 7Scenes [28],
ScanNet++ [29], and Waymo [31]. Long-sequence experiments are conducted on 7Scenes [28], NRGBD [33], and
ScanNet++ [29], while ablation experiments use a fixed VGGT [5] backbone.
Inputs and Evaluation Metrics. In the main experiments and ablation studies, at most 100 frames are input for each
scene: when fewer than 100 frames are available, all frames are retained, ensuring that the baselines and CAR3T use the
same inputs. For long-sequence experiments, the input is fixed at 50, 150, 250, and 500 frames, with ScanNet++ results

4.2
Main Results
We apply CAR3T to VGGT, DA3, and π3 and evaluate them pairwise against their respective original models.
Inference Efficiency. Table 1 reports both the actual average number of input frames and the forward inference time.
Across all scenes, CAR3T achieves speedups on all three models, demonstrating its ability to reduce inference overhead
across architectures. The speedup gains are more pronounced on datasets with up to 100 input frames, such as 7Scenes,
ScanNet++, and Waymo. These gains stem from computing global attention only for the reference view in the selected
layers and reusing the resulting output across views. This reduces the core attention computation cost in these layers
while preserving the full key-value context.
Camera Pose Accuracy. Table 2 reports pose accuracy under the strict AUC@5◦metric. With π3, CAR3T remains
within 0.020 AUC of the baseline on five datasets and improves performance on ScanNet++. CAR3T also improves DA3
on 7Scenes, while results for DA3 and VGGT vary across datasets. These results illustrate the efficiency–accuracy trade-
off of applying CAR3T to different backbones. Results under AUC@30◦are provided in Table 9 in the supplementary
material.

Efficiency and Accuracy on Long Sequences. As shown in Table 4, CAR3T achieves inference acceleration across all
tested configurations, and the acceleration gain generally increases as the input sequence length grows, indicating that
feature reuse can further reduce inference overhead in long-sequence scenarios. This trend stems from differences in
computational complexity: the overhead of global attention grows quadratically with the number of views, whereas
reusing attention outputs from reference-view attention can reduce the attention computation in selected layers to linear
complexity. As a result, longer sequences can achieve greater computational savings from cross-view reuse of attention
outputs.
For pose estimation, π3 and VGGT generally maintain accuracy across sequence lengths, while DA3 remains close to
the baseline in most settings. Reconstruction results are also largely stable, with improvements in several cases, although
DA3 at 250 frames exhibits larger accuracy changes. Overall, CAR3T demonstrates stable inference acceleration across
different backbones and sequence lengths, while accuracy changes are jointly influenced by the backbone architecture
and input sequence length.
4.3
Compatibility with Existing Acceleration Methods
Table 5 evaluates CAR3T applied to VGGT and the acceleration methods FastVGGT [9] and CoMe [11]. CAR3T
provides additional acceleration for both methods across all three datasets, demonstrating its compatibility with existing
acceleration approaches. This is because token merging shortens the sequence length but does not explicitly eliminate
the similarity between attention distributions across different views. CAR3T leverages this residual redundancy by
reusing the attention outputs of the reference view in the selected layer, thereby further reducing computational cost
on top of token merging. Fig. 4 visualizes reconstructions from 50–200 input frames. CAR3T preserves the major
geometric structures and scene layout of the original models while reducing inference overhead.

Ablation Studies
To analyze the roles of the reuse strategy and budget selection in CAR3T, we conduct ablation studies with the VGGT
backbone on several datasets.
Reuse Strategy. Table 6 compares full-layer reuse, fixed 12-layer and 14-layer configurations constructed from the
low-JSD layers in Fig. 3, and CAR3T. Although full-layer reuse achieves the highest speedup, it causes a substantial
drop in pose and reconstruction accuracy. The two fixed low-JSD configurations also achieve speedup, but their
accuracy is significantly lower than that of CAR3T. In particular, compared with the fixed 12-layer configuration,
CAR3T achieves nearly the same average number of reused layers while attaining higher AUC@30◦and F-score and
lower Overall distance. This indicates that low JSD can be used to filter candidate layers, but relying solely on a
pre-determined fixed set of layers is still insufficient to guarantee prediction quality across different inputs; CAR3T’s
input-adaptive decision improves accuracy preservation under a similar reuse scale.

5
Conclusion
We propose CAR3T, a training-free framework that accelerates multi-view 3D reconstruction by reusing reference-view
attention outputs. It combines offline risk calibration with online query drift estimation and layer selection to adapt to
layer- and input-dependent attention redundancy while controlling reuse error. Despite the additional overhead of these
online decisions, experiments show that CAR3T reduces inference time while largely preserving reconstruction quality.
