Abstract
Autonomous driving systems must not only interpret the cur-
rent scene but also anticipate perceptual challenges such as
occlusions, sparse observations, and recurring failure pat-
terns. However, most existing LiDAR semantic segmenta-
tion methods operate in a frame-centric manner, process-
ing each scan independently and discarding past contextual
experience, which limits robustness under dynamic scene
changes. We propose DREAM, a Dual-memory REAsoning
framework for continual LiDAR seMantic segmentation that
reframes perception as an experience-driven and anticipa-
tory process. DREAM maintains two complementary mem-
ory banks in a strictly online setting: a latent memory
that stores compact semantic abstractions of previously ob-
served scenes, and an error memory that records repre-
sentations associated with uncertain predictions. At each
timestep, relevant memory entries are retrieved via cosine
similarity and integrated into the feature space through a
lightweight modulation mechanism, enabling the model to
reinforce consistent semantic patterns while suppressing re-
curring failure modes. The backbone remains frozen and no
past scans are replayed, ensuring computational efficiency
and bounded memory growth. Extensive experiments on
multiple large-scale LiDAR benchmarks demonstrate that
DREAM achieves state-of-the-art performance, with con-
sistent improvements on dynamic and small-scale objects,
highlighting the effectiveness of persistent and error-aware
memory for robust long-horizon perception.
1. Introduction
Semantic scene understanding is a core capability for au-
tonomous systems operating in complex environments such
as autonomous driving. Among perception tasks, seman-
tic segmentation provides dense structured representations
of the surrounding scene that are critical for downstream
*Corresponding author.
planning and decision-making. However, reliable auton-
omy requires perception systems that remain robust under
challenging sensing conditions such as occlusions, sparse
measurements, and dynamic scene changes. Despite strong
progress in deep learning–based perception, most LiDAR
semantic segmentation methods remain fundamentally re-
active, processing each scan independently or within short
temporal windows [7]. This frame-centric formulation pre-
vents perception systems from leveraging past experience
to anticipate recurring perceptual challenges.
In real-world deployment, LiDAR observations arrive as
a continuous stream where each scan provides only a par-
tial and noisy view of the environment. Measurements are
often affected by occlusions, sensor noise, and long-range
sparsity. Under such conditions, treating frames indepen-
dently [4, 13, 21, 27, 29, 32] leads to brittle predictions and
temporal inconsistencies, particularly for distant or rarely
observed structures. In contrast, human perception relies
on accumulated experience: past observations inform fu-
ture interpretation and help anticipate recurring patterns of
uncertainty [14]. Enabling perception models to accumu-
late and exploit such experience remains a key challenge
for robust long-horizon scene understanding.
Three-dimensional representations provide a natural
foundation for storing perceptual experience. Unlike im-
age projections, 3D space preserves metric structure, allow-
ing memory to maintain consistent object scales and spatial
relationships across viewpoints. This enables stable seman-
tic priors, more uniform representation across near and far
regions, and improved reasoning about occlusions and mo-
tion. Regions that become temporarily unobserved due to
occlusions can therefore be retained in memory without in-
terference from newly observed surfaces. However, main-
taining spatial memory alone does not fully address a key
limitation of deployed perception systems: the tendency to
make similar errors under recurring sensing conditions re-
peatedly.
Recent work has begun exploring memory-augmented
perception for LiDAR segmentation. Earlier approaches,

such as Cylinder3D [32] and Meta-RangeSeg [25], primar-
ily focus on improving feature representations and spatial-
temporal aggregation for semantic segmentation, but they
do not explicitly maintain persistent memory across obser-
vations. MemorySeg [12], for example, maintains a per-
sistent voxel memory that aggregates information across
streaming LiDAR scans and improves understanding of
long-range and occluded regions.
While effective, such
approaches primarily accumulate spatial context and treat
memory as a passive repository of past observations. In
practice, perception systems frequently encounter recurring
failure patterns, such as systematic uncertainty under se-
vere sparsity or occlusion. Conventional architectures lack
mechanisms to explicitly represent these failure modes and
use them to guide future predictions.
To address this limitation, we propose DREAM, a dual-
memory framework for continual LiDAR semantic segmen-
tation that augments perception with both perceptual and
error-aware memory. DREAM maintains two compact la-
tent memory banks operating in a strictly online setting.
A latent perceptual memory stores compressed semantic
descriptors of previously observed scenes, while an error
memory stores latent representations associated with uncer-
tain predictions. At each timestep, a global latent descrip-
tor extracted from the current scan retrieves relevant en-
tries from both memory banks using cosine-similarity ad-
dressing. The retrieved latent and error memories are pro-
jected into the dense feature space and integrated through
a lightweight modulation mechanism prior to classification.
This allows the network to reinforce reliable semantic pat-
terns while suppressing conditions that previously produced
low-confidence predictions.
The proposed framework DREAM, processes one scan
at a time, maintains bounded memory capacity, and avoids
computationally expensive attention mechanisms or long-
horizon backpropagation. The backbone encoder remains
frozen, while lightweight memory modulation layers condi-
tion perception on retrieved experience. This design enables
temporally aware semantic segmentation while maintaining
efficiency suitable for real-time autonomous driving scenar-
ios. The effectiveness of the proposed DREAM architecture
is substantiated through comprehensive evaluations on three
benchmark datasets: SemanticKITTI[2], nuScenes[3], and
PandaSet[26].
In summary, the key contributions of this work are as
follows:
• Proposal of DREAM, a Dual-Memory Reasoning for An-
ticipatory 3D Perception for Autonomous Driving.
• We introduce an error-aware memory mechanism that ex-
plicitly models recurring uncertainty patterns and helps
mitigate future perceptual failures
• Proposal of a Dual Memory Modulation scheme for con-
tinual LiDAR semantic segmentation that integrates per-
ceptual and error-aware memories to enable experience-
conditioned perception, one of its first kinds.
2. Related Works
In this section, we review existing LiDAR semantic seg-
mentation methods and discuss approaches that incorporate
temporal reasoning for streaming LiDAR perception.
2.1. LiDAR Semantic Segmentation
LiDAR semantic segmentation methods can be broadly cat-
egorized based on the underlying data representation: point-
based [11, 15, 16, 24], projection-based [6, 27, 31], voxel-
based [4, 10, 32], and hybrid approaches that combine mul-
tiple representations [21, 28].
Point-based methods [11, 15, 16, 24] operate directly
on raw point clouds and learn point-wise features using
permutation-invariant networks. While effective, many of
these approaches rely on aggressive downsampling to main-
tain computational efficiency. For example, KPConv [24]
introduces deformable point convolutions that significantly
improve segmentation performance, but at the cost of in-
creased computational complexity.
Projection-based methods [6, 27, 31] project 3D point
clouds into structured 2D representations such as range-
view or bird’s-eye-view images. These approaches benefit
from efficient 2D convolutional networks and often achieve
real-time inference. However, the projection process intro-
duces geometric distortions and information loss, which can
limit segmentation accuracy.
Voxel-based approaches [4, 10, 32] convert point clouds
into structured 3D grids and process them using sparse con-
volutional networks [5, 22]. These methods have demon-
strated strong performance by preserving spatial structure
while enabling efficient computation.
Nevertheless, dis-
cretization into voxels may lead to loss of fine geometric
details when voxel resolution is reduced.
To leverage the strengths of different representations,
recent works combine multiple modalities [21, 28–30].
For instance, SPVNAS [21] integrates point-based and
voxel-based features within a unified architecture, while
RPVNet [28] employs a tri-branch network that jointly pro-
cesses range-view, point-wise, and voxel features. These
hybrid approaches improve segmentation accuracy by ex-
ploiting complementary geometric representations.
2.2. Temporal LiDAR Reasoning
To incorporate temporal context, several works attempt to
aggregate information from multiple LiDAR frames. Early
approaches [18, 20, 25] integrate a small number of past
frames to enhance segmentation accuracy.
For example,
SpSequenceNet [20] introduces cross-frame attention and
interpolation mechanisms to combine features from consec-
utive scans, while MetaRangeSeg [25] incorporates resid-


ual depth information from previous frames.
Although
these methods improve short-term consistency, they oper-
ate within limited temporal windows and discard historical
context beyond a few frames.
Other works explore recurrent formulations for tempo-
ral state maintenance.
Duerr et al. [8] propose a recur-
rent model that aligns range-view features across streaming
scans, while MemorySeg [12] introduces a persistent latent
voxel memory for improved segmentation in long-range and
occluded regions. StrObe [9] similarly maintains a multi-
scale BEV memory for incremental object detection. How-
ever, range-view and BEV representations are prone to pro-
jection artifacts and occlusion conflicts, and none of these
approaches explicitly model recurring perceptual failures.
In contrast, DREAM augments LiDAR segmentation
with persistent latent memory designed for long-horizon
perception. Rather than storing raw observations or geomet-
ric maps, our framework maintains compact representations
capturing both semantic experience and historical uncer-
tainty. Retrieving relevant past contexts while suppressing
recurring failure patterns enables robust, anticipatory per-
ception, making DREAM one of the first approaches to han-
dle LiDAR segmentation entirely within the latent space.
3. Methodology
Most LiDAR segmentation networks process each scan in-
dependently, ignoring temporal context critical for han-
dling occlusions, sparsity, and recurring scene configura-
tions.
To address this, we introduce DREAM (Fig. 1),
a dual-memory reasoning framework for continual LiDAR
semantic segmentation. DREAM treats segmentation as an
experience-driven process where structured latent memo-
ries evolve, enabling anticipatory reasoning over streaming
data in a strictly online regime.

3.8. Memory-Conditioned Perception
DREAM formulates LiDAR semantic segmentation as a
perception problem conditioned on accumulated context


from streaming observations. Rather than processing each
scan independently, the model maintains two latent mem-
ory banks, ML
t and ME
t , which store compact representa-
tions of previously observed semantic structures and his-
torical low-confidence predictions.
At each timestep, a
global latent descriptor retrieves relevant entries through
content-based addressing, and the retrieved memories mod-
ulate the dense feature representation prior to classification.
This mechanism allows the model to incorporate contex-
tual information from past observations while maintaining
a feed-forward inference pipeline. As a result, DREAM
integrates long-horizon contextual cues into LiDAR per-
ception in a computationally efficient manner, enabling
temporally aware semantic segmentation in streaming au-
tonomous driving scenarios.
4. Experimental Setup
We evaluate the proposed framework on three large-
scale autonomous driving datasets: SemanticKITTI [2],
nuScenes [3], and PandaSet [26]. These datasets are col-
lected using different LiDAR sensors and capture diverse
urban environments, making them suitable for evaluating
perception systems operating in streaming conditions. Our
experiments focus on assessing the effectiveness of persis-
tent memory for long-horizon perception and its ability to
improve robustness under sparse observations, occlusions,
and dynamic scene changes. In addition to comparisons
with existing methods, we perform ablation studies to an-
alyze the contribution of each component of the proposed
dual-memory design.
4.1. Datasets
We evaluate on three large-scale autonomous driving
datasets. SemanticKITTI [2] comprises 22 sequences cap-
tured with a Velodyne HDL-64E in Germany, with se-
quences 0–10 for training and 11–21 for testing.
La-
bels are mapped to 19 classes (single-scan) and 25 classes
(multi-scan), where we primarily report multi-scan results
as our method models temporal context.
nuScenes [3]
contains 1000 driving scenes from Boston and Singapore
(700/150/150 train/val/test split), captured with a Velodyne
HDL-32E at 2 Hz, with 31 classes mapped to 16 categories.
PandaSet [26] provides temporally continuous sequences
recorded in Silicon Valley using a Hesai Pandar64, with
103 sequences and fine-grained classes grouped into 14 cat-
egories following [8].
4.2. Evaluation Protocol
During evaluation, each sequence is processed in temporal
order from the first frame to the last. The memory state
is updated online during inference, allowing the model to
accumulate experience across the sequence. Performance
is evaluated using Intersection-over-Union (IoU) [17], with
mean IoU (mIoU) across all semantic classes reported as
the primary metric. In addition, we report seen-class mIoU,
which averages IoU only over classes present in the evalu-
ated sequence, as well as class-wise IoU scores for detailed
analysis.
4.3. Implementation Details
Training proceeds in two stages: the segmentation head is
first trained for 50 epochs in a single-scan setting, after
which the dual-memory mechanism and modulation lay-
ers are fine-tuned for 20 additional epochs in an online
recurrent manner. The backbone remains frozen through-
out.
Each LiDAR scan is projected into a 64 × 1024
range-view with five channels (range, x, y, z, intensity).
A pre-trained ResNet-18 extracts dense features from the
third residual stage and a 512-dimensional global descrip-
tor from the final stage for memory retrieval. The latent
and error memory banks store KL=64 and KE=32 vec-
tors (D=512) respectively, using cosine similarity for top-1
retrieval and FIFO replacement. The error memory is up-
dated via low-confidence regions. Optimization uses Adam
(lr = 5 × 10−4) with class-weighted cross-entropy and
mixed precision training.
Augmentations include global
scaling, random translation, and vertical-axis rotation. The
model is trained on 8 NVIDIA A100 GPUs (80GB) using
distributed data parallelism.
4.4. Quantitative Analysis
We evaluate DREAM on SemanticKITTI, nuScenes, and
PandaSet, with results summarized in Tables 1, 2, and 3.
On SemanticKITTI (Tab. 1), DREAM achieves 61.7%
mIoU, outperforming MemorySeg (58.3%) and Meta-
RangeSeg (49.7%).
Gains are most pronounced in dy-
namic categories (moving cars, bicyclists, pedestrians, mo-
torcyclists) and structural classes (building, trunk, terrain),
reflecting the benefit of temporal reasoning via the dual-
memory design.
On nuScenes (Tab. 2), DREAM achieves 81.8% mIoU,
with notable improvements in barrier, pedestrian, and traffic
cone categories, suggesting the memory mechanism effec-
tively addresses sparsity and scale challenges.
On PandaSet (Tab. 3), DREAM achieves 71.0% mIoU,
performing consistently across foreground classes (truck,
person, traffic sign) and background classes (sidewalk, ter-
rain), confirming generalization across sensor configura-
tions and urban environments.
Across all benchmarks, persistent latent memory enables
robust segmentation under sparse observations, occlusions,
and dynamic scene changes.

4.7. Ablation Studies
4.7.1. Importance of the Memory
To evaluate the impact of persistent memory, we com-
pare DREAM against a single-frame baseline (SFB) that
removes both latent perceptual memory and error mem-
ory components. The comparison is performed using the
distance-based evaluation shown in Fig. 2. Results indicate
that incorporating memory significantly improves segmen-
tation performance, particularly at larger distances where
LiDAR measurements are sparse and noisy. This demon-
strates that maintaining a persistent latent representation of
past observations helps the model recover semantic context
that may be missing in individual frames.
4.7.2. Distance-based Analysis
Fig. 2 highlights the benefit of persistent dual memory at
longer ranges, where LiDAR point clouds become increas-
ingly sparse. We compare DREAM against a single-frame
baseline (SFB) that removes both memory modules.
DREAM consistently outperforms the SFB across all
distance bins, with the most pronounced gains at 80m:
26.47% mIoU on nuScenes and 52.33% mIoU on PandaSet,
where point density is lowest. The progressive improve-
ment with distance confirms that persistent memory be-
comes more beneficial as perceptual difficulty increases, en-
hancing semantic consistency through compact scene repre-
sentations and explicit uncertainty modeling.

5. Conclusion
We presented DREAM, a dual-memory reasoning frame-
work for continual LiDAR semantic segmentation that
reformulates perception as a temporally grounded process.
DREAM maintains two complementary memory banks:
a perceptual memory that accumulates stable semantic
abstractions and an error memory that records recurring
failure patterns.
Retrieved memories modulate dense
features before classification, reinforcing consistent se-
mantics while suppressing previously observed errors. The
framework operates strictly online, avoids scan replay, and
keeps the backbone frozen, yielding a bounded-memory
design suitable for real-world deployment.
Experiments
on SemanticKITTI, nuScenes, and PandaSet demonstrate
state-of-the-art performance, with the most significant
gains in dynamic and small-object categories.
DREAM
advances LiDAR segmentation from stateless prediction
to memory-augmented reasoning,
offering a scalable
foundation
for
long-horizon
autonomous
perception.
