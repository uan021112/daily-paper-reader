STAC++: Plug-and-Play Adaptive Spatio-Temporal Aware Cache Compression
for Streaming 3D Reconstruction

Abstract
Streaming 3D reconstruction must preserve geometry under
limited memory, yet STAC’s fixed-resolution spatial key–
value (KV) cache grows as scenes expand.
We propose
STAC++, a plug-and-play, training-free framework that
compresses and reuses spatial memory for long-term recon-
struction in unbounded scenes. Adaptive Spatial KV Cache
(ASKC) organizes KV states into an octree with adaptive
resolutions across regions and layers.
Response-Aware
Cache Compression (RACC) guides KV merging by mea-
suring attention-output changes, balancing storage savings
with geometric preservation.
Temporal Context Refine-
ment (TCR) reuses cached intermediate features and re-
computes only a short backbone suffix to refine historical
predictions with later observations.
Integrated into four
pretrained streaming backbones, STAC++ reduces spatial
memory consumption while maintaining competitive recon-
struction quality on long sequences and large scenes, with
further quality gains from refinement at limited computa-
tional overhead. The code will be made publicly available
upon acceptance.
1. Introduction
3D reconstruction is a fundamental problem in computer
vision and computer graphics, with a wide range of ap-
plications including robotic mapping [44], augmented re-
ality [28], and novel-view synthesis [16, 26]. Traditional
image-based 3D reconstruction combines Structure-from-
Motion (SfM) [30] for camera estimation and sparse struc-
ture recovery with Multi-View Stereo (MVS) [31] for dense
geometry. These pipelines rely on explicit correspondence
matching and iterative geometric optimization.
Recent
feed-forward geometric models instead infer scene geom-
etry directly from images using pretrained networks, reduc-
ing reliance on scene-specific iterative optimization and im-
proving reconstruction efficiency.
Feed-forward reconstruction methods can be broadly
categorized into offline methods that process a fixed image

which predicts pairwise pointmaps followed by global
alignment, and VGGT [38], which jointly predicts cameras
and dense geometry from multiple views. However, their
computational and memory costs limit scalability to long
sequences. Online methods [5, 17, 49, 54] instead reuse his-
torical representations to reconstruct incoming frames in-
crementally. StreamVGGT [54] adapts VGGT to stream-

InfiniteVGGT [49] controls this growth
with a bounded rolling cache and diversity-aware token
pruning, enabling long-sequence inference within a fixed
memory budget. However, these methods do not explicitly
exploit 3D spatial information in KV-cache management.
STAC [41] introduces a spatial KV cache that merges his-
torical tokens into voxel-aligned representatives, reducing
spatial redundancy while preserving geometric evidence.
However, its fixed-resolution grid allows the number of oc-
cupied voxels to grow with scene extent, so long streams
exploring unbounded environments can still exhaust GPU
memory. Uniform voxel coarsening saves memory but risks
losing fine geometric detail in complex regions.

frames, yet earlier predictions remain fixed even when later
views reveal the same surfaces more clearly. These limita-
tions motivate our central question: How can we adaptively
compress and actively reuse spatial KV memory to support
long-term reconstruction of unbounded scenes, while pre-
serving geometric detail and refining earlier predictions un-
der limited memory and computational budgets? Answer-
ing this question poses two challenges. (1) Handling un-
bounded scenes requires spatial representations that accom-
modate continually expanding scene coverage while con-
trolling cache growth and preserving geometric detail. (2)
Operating within a bounded memory budget requires retain-
ing informative historical evidence and efficiently reusing it
to refine earlier predictions with later observations, without
replaying the entire backbone.
To address these challenges, we propose STAC++, a
plug-and-play, training-free framework that controls spa-
tial memory growth and efficiently reuses historical evi-
dence for long-term streaming reconstruction in unbounded
scenes (see Fig. 1). Firstly, Adaptive Spatial KV Cache
(ASKC) organizes spatial KV states into an octree hier-
archy with different resolutions across scene regions and
transformer layers. This hierarchy supports merging fine-
grained cells into coarser representations as the scene ex-
pands. Secondly, Response-Aware Cache Compression
(RACC) guides KV merging by evaluating how candi-
date merges change the backbone’s attention outputs (here-
after referred to as responses). It identifies spatial repre-
sentations that can be consolidated with limited response
changes, balancing memory savings against geometric in-
formation preservation.
Finally, Temporal Context Re-
finement (TCR) revisits historical frames after a fixed de-
lay, using later observations and accumulated spatial mem-
ory to refine earlier predictions. By reusing cached interme-
diate features and recomputing only a short backbone suf-
fix, TCR creates additional opportunities to exploit spatial
memory while limiting the computation required for refine-
ment. We implement STAC++ as an inference-time plugin
for STream3R [17], StreamVGGT [54], InfiniteVGGT [49],
and LingBot-Map [5], preserving their pretrained weights
without additional training. Experiments across these four
backbones demonstrate that STAC++ reduces spatial mem-
ory consumption while maintaining competitive reconstruc-
tion quality, scales to long sequences and large scenes, and
further improves reconstruction quality through delayed
suffix refinement with limited computational overhead.
Our main contributions are summarized as follows:
• We propose STAC++, a plug-and-play, training-free
framework that unifies adaptive spatial memory compres-
sion and historical evidence reuse for long-term stream-
ing reconstruction in unbounded scenes without modify-
ing pretrained backbone weights.
• We develop ASKC, RACC, and TCR for hierarchical
spatial KV caching, response-guided merging, and suffix
refinement of historical predictions, controlling memory
and computation while preserving geometry.
2. Related Work
2.1. Offline Feed-Forward 3D Reconstruction
DUSt3R [42] predicts pairwise pointmaps with global
alignment; MASt3R [18] adds learned matching features.
VGGT, Fast3R, and MUSt3R [3, 38, 48] extend predic-
tion to multiple views, while FLARE [51] jointly recov-
ers geometry, appearance, and cameras. π3 [43] removes
reference-view dependence through permutation equivari-
ance, and VGGT-Ω[39] scales geometric learning with ef-
ficient register attention. Dense cross-view interaction nev-
ertheless remains costly as the image collection grows.
For scalability, MERG3R [8] partitions and aligns im-
age subsets, while LiteVGGT [34] merges geometrically
redundant tokens and reuses merge decisions across lay-
ers. VGG-T3, ZipMap, and Scal3R [11, 14, 47] compress
context into test-time-trained states, using fast weights or
synchronized adaptive memory to retain information across
image chunks; Test3R [50] adapts reconstruction models at
test time. These approaches address offline scalability or
adaptation rather than adaptive causal KV storage. Octree-
GS [29] provides hierarchical spatial detail for Gaussian
rendering; our hierarchy instead compresses transformer
KV memory for subsequent streaming inference.

retraining.
SLAM3R [22] learns local reconstruction
and registration; MASt3R-SLAM and multi-agent MAG-

LASER [10] enables training-free streaming through layer-
wise depth-scale alignment across windows.

4. Method
We propose STAC++, a plug-and-play, training-free
framework for controlling spatial KV memory growth and
reusing historical evidence in streaming 3D reconstruction.
STAC++ combines three modules (Fig. 2). Adaptive Spa-
tial KV Cache (ASKC) organizes historical states at multi-
ple spatial resolutions. Response-Aware Cache Compres-
sion (RACC) determines which states can be merged by
measuring their effect on attention outputs. Temporal Con-
text Refinement (TCR) revisits historical frames after a de-
lay, reusing cached intermediate features and recomputing
a short backbone suffix to incorporate later observations.
All three modules operate during inference and preserve the
pretrained backbone weights.
4.1. Adaptive Spatial KV Cache (ASKC)
In unbounded scenes, fixed-resolution spatial caches grow
with scene coverage and retain redundancy across neighbor-
ing voxels. Uniform coarsening saves storage but may dis-
card locally distinct geometric evidence. ASKC instead or-
ganizes spatial KV states in an expanding octree, selectively
merging neighboring fine-grained cells into coarser parents
independently across layers while retaining finer represen-
tations where detailed evidence remains necessary.

4.2. Response-Aware Cache Compression (RACC)
Merging spatially adjacent states saves memory but can al-
ter the geometric evidence available to the backbone. A
straightforward approach is to explicitly compute the atten-
tion responses before and after a candidate merge p and take
their difference:
∆op,ℓ,h = Att(bqℓ,h, Cp,ℓ,h) −Att(bqℓ,h, Cℓ,h),
(4)
where Att(·) denotes attention, bqℓ,h is the shared query, and
Cℓ,h and Cp,ℓ,h are the contexts before and after the merge.
The corresponding responses are denoted by oℓ,h and op,ℓ,h,
respectively. However, directly evaluating this change for
every candidate merge requires repeating query–key scor-

full context, making evaluation costly. We therefore sam-
ple a small set of queries and compute response changes

affected by each merge. RACC balances response preser-
vation against storage savings.

4.3. Temporal Context Refinement (TCR)
During causal streaming inference, each frame is recon-
structed using only the observations available when it ar-
rives. Later frames may provide complementary viewpoints
and additional geometric evidence for previously observed
regions, enriching the spatial cache. However, this updated
memory benefits subsequent inference without automati-
cally revising earlier predictions, which remain tied to their
original, more limited context. The most direct approach is
to reprocess historical frames through the entire backbone
using the updated context. However, this repeats substantial
feature computation. We therefore introduce TCR to refine
historical predictions after a fixed delay using the updated
temporal and spatial context. TCR retains intermediate fea-
tures during initial inference and recomputes only a short
backbone suffix, allowing earlier frames to reuse later ob-
servations while limiting the additional computation.
Refinement scheduling. During initial inference, we re-
tain each frame’s decoder features from layers 5 and 12, the
intermediate input needed for suffix recomputation, and its
spatial lookup region. After a delay of D frames, we revisit
the historical frame once using the updated context. The
refinement delay is independent of the merge interval, and
merge keyframes share their retained inputs with RACC.
Refinement process. At time t, we refine frame t −D
by resuming from its retained intermediate features.

5. Experiments
5.1. Implementation Details
STAC++ is a plug-and-play, training-free framework. We
integrate it into four online reconstruction backbones:
STream3R [17], StreamVGGT [54], InfiniteVGGT [49],
and LingBot-Map [5], keeping their pretrained weights
frozen.
For comparison, we also extend STAC’s spa-
tial caching [41] to InfiniteVGGT and LingBot-Map while
preserving their native temporal memory policies.
In-
finiteVGGT evicts by token budget rather than a fixed tem-
poral window; we archive evicted patch KV in spatial mem-
ory once their 3D positions are predicted.
Datasets and Metrics. We evaluate 3D reconstruction
on 7-Scenes [33], Neural RGB-D [1], and ETH3D [32],
as well as on Long3D [49] and Oxford Spires [36](christ-
church-05 excluded) for large scenes and long streams. For
camera pose estimation, we evaluate on ETH3D, Sintel [2],
and TUM RGB-D [35].
We report accuracy (Acc) and
completeness (Comp) as mean prediction-to-reference and
reference-to-prediction nearest-neighbor distances (m), re-
spectively. F1 (%) uses thresholds of 0.10 m for 7-Scenes
and Neural RGB-D and 0.25 m for ETH3D, Long3D, and
Oxford Spires. For cameras, we report absolute trajectory
error (ATE, m) after Sim(3) alignment and angular AUC
(%) at 3◦and 30◦, using the larger relative rotation or
translation-direction error per valid frame pair.
Baselines. We integrate STAC++ into STream3R [17],
StreamVGGT [54], InfiniteVGGT [49], and LingBot-
Map [5]. For each backbone, we compare STAC++ with
native inference and STAC [41], and additionally include
windowed STream3R and StreamVGGT baselines.
Implementation details. Following STAC [41], each
cell stores up to P = 4 representatives and B = 8 buffered
tokens per head. We use a finest cell size of δ = 0.05,
merge parameters τm = λ = 5 × 10−4, suffix depth
k = 8, and default refinement delay and merge interval
D = M = 8 frames (For large scenes D = M = 16).
STream3R-W and StreamVGGT-W use 36- and 48-frame
windows, respectively, while their STAC and STAC++ vari-
ants use eight-frame windows. InfiniteVGGT’s native token
budget of 1,200,000 is reduced to 650,000 for STAC and
STAC++. All LingBot-Map variants use a temporal window
of 16 keyframes and retain eight scale anchors. In this way,
STAC and STAC++ share temporal memory settings within
each backbone. All experiments run on a single NVIDIA

5.2. 3D Reconstruction.
Table 1 compares reconstruction on 7-Scenes, Neural RGB-
D, and ETH3D. Relative to windowed STream3R and
StreamVGGT and native InfiniteVGGT and LingBot-Map,
STAC++ improves F1 in 9 of 12 settings. All four back-
bones improve on Neural RGB-D, with gains of 1.99–10.31
percentage points.
At the same temporal window or to-
ken budget as STAC, STAC++ reduces mean peak GPU
memory by 14.0%–26.8% across backbones.
This sug-
gests that adaptive compression can reduce spatial redun-
dancy while retaining evidence useful for reconstruction.
When integrated into LingBot-Map, STAC++ outperforms
CUT3R [40], TTT3R [6], and ZipMap [14] in accuracy,
completeness, and F1 across these datasets.
For large scenes and long streams, Table 2 reports re-
sults on Long3D [49] and Oxford Spires [36]. VGGT [38],
VGG-T3 [11], CUT3R [40], and ZipMap [14] encounter
out-of-memory (OOM) failures on these large-scene bench-
marks.
With InfiniteVGGT and LingBot-Map, STAC++
completes every evaluated sequence, whereas the STAC
variants encounter out-of-memory failures on multiple se-
quences. This difference highlights the importance of con-
trolling spatial memory growth as trajectories lengthen and
scene coverage expands.
STAC++ also improves recon-
struction quality on Oxford Spires, reducing both Acc and
Comp for InfiniteVGGT and LingBot-Map. In terms of in-
ference time, STAC++ is faster than windowed STream3R
and StreamVGGT baselines on Long3D, while its runtime
relative to native InfiniteVGGT and LingBot-Map varies
across datasets. These results show that adaptive spatial
caching supports more reliable long-stream inference while
retaining geometric evidence, with the quality–memory
trade-off varying across scenes evaluated in these bench-
marks and across different pretrained backbones.

5.3. Camera Pose Estimation.
Following prior work [5, 41], we evaluate camera pose esti-
mation on Sintel [2], TUM RGB-D [35], and ETH3D [32].
As shown in Table 3, STAC++ lowers ATE in all 12 com-
parisons with the corresponding native baselines, using the
windowed variants for STream3R and StreamVGGT. Com-
pared with STAC under the same temporal window or to-
ken budget, it lowers ATE in 11 of 12 settings and reduces
mean peak GPU memory by 21.2%–27.0% across back-
bones. This suggests that a more compact spatial cache can
preserve evidence useful for camera localization while im-
proving memory efficiency. Angular AUC gains vary across
datasets and backbones, with both metrics improving for
LingBot-Map on TUM RGB-D.
5.4. Ablation Study
We conduct ablation studies on Oxford Spires to evaluate
ASKC, RACC, and TCR. The ASKC and RACC ablations
examine spatial cache compression. The TCR ablation ex-
amines temporal context refinement.
Effect of ASKC. The w/o ASKC variant corresponds
to STAC, which aggregates tokens only within fixed-
resolution spatial cells (Table 4). Hierarchical merging sub-
stantially reduces memory relative to this baseline.
Effect of RACC. The w/o RACC variant accepts every
eligible merge, while random merging uses the response-
guided policy’s per-sequence acceptance rate, with re-
sults averaged over three seeds. Response-guided merging
achieves better Acc and F1 than random merging and w/o
RACC at similar memory usage (Table 4).
Effect of TCR. In Table 4, refining eight layers achieves
the best Acc among the TCR variants. Shallower refinement
offers little benefit, while deeper suffixes add computation
without improving quality, supporting k = 8 as the default.
6. Conclusion
We presented STAC++, a plug-and-play, training-free
framework for long-term streaming 3D reconstruction in
unbounded scenes. Adaptive Spatial KV Cache (ASKC)
organizes spatial KV states in an octree with adaptive reso-
lutions across regions and transformer layers. Response-
Aware Cache Compression (RACC) guides KV merging
through attention-output changes to balance memory sav-
ings with geometric preservation. Temporal Context Re-
finement (TCR) reuses cached intermediate features and re-
computes a short backbone suffix to refine historical predic-
8


tions with later observations. Experiments across four pre-
trained backbones demonstrate reduced memory consump-
tion and competitive reconstruction and camera pose esti-
mation quality, with improved scalability to long sequences
and large scenes. Delayed refinement further improves re-
construction quality with limited computational overhead.
