## 摘要
形状各异的工具可能具有相似的功能，但要将操作技能迁移到不同工具上，就需要理解工具几何形状与特定任务之间的关系，并据此调整操作策略。关键挑战在于发现不同工具在完成任务时共有的可供性，并验证这些可供性是否能支持新工具完成类似工作。我们提出 A$^2$-VLA，这是一种将具身智能体与视觉-语言-动作（VLA）策略相结合的工具适配框架。该框架将工具可供性视为智能体能够构建、测试和修正的假设。给定使用少量源工具进行遥操作的演示，智能体会在仿真中重建场景，并自主确定与任务相关的可供性特征：功能区域及其关键几何属性。智能体通过自主开展重建场景中的实验，开发可供性提取技能，并不断改进这些特征与技能。经过验证的提取技能会累积到一个可复用于未见工具的技能库中。最后，A$^2$-VLA 在训练和推理期间，将编码后的功能区域特征作为条件输入，馈入 $π_{0.5}$ 骨干模型。评估考察了重建场景中的可供性可靠性，以及真实机器人在未见工具上的任务成功率。我们的方法在基于可供性的仿真跨工具轨迹重定向任务中取得了 86.1% 的成功率。在三项真实机器人工具使用任务中，与 $π_{0.5}$ 相比，A$^2$-VLA 将任务成功率提高了 30.7 个百分点。

## Abstract
Tools with different shapes can have similar functions, but transferring manipulation skills across tools requires understanding how tool geometry relates to the specific task and adjusting the manipulation strategy accordingly. The key challenge is to discover the common affordances that contribute to task completion across different tools and verify whether they support new tools in performing similar work. We present A$^2$-VLA, a tool-adaptation framework that combines an embodied agent with a VLA policy. It treats tool affordances as hypotheses the agent can construct, test, and revise. Given teleoperated demonstrations with a few source tools, the agent reconstructs the scenes in simulation and autonomously determines task-relevant affordance features: functional regions and their key geometric properties. It develops affordance-extraction skills and refines both the features and skills through autonomous experiments in the reconstructed scenes. Validated extraction skills accumulate in a reusable skill library for unseen tools. Finally, A$^2$-VLA uses encoded functional-region features as conditioning inputs to a $π_{0.5}$ backbone during training and inference. Evaluation examines affordance reliability in reconstructed scenes and real-robot task success on unseen tools. Our method achieves 86.1% success in simulated cross-tool trajectory retargeting based on affordances. On three real-robot tool-use tasks, A$^2$-VLA improves task success by 30.7 percentage points over $π_{0.5}$.

- **整体思路：** 论文提出 A²-VLA，将具身智能体的分析与仿真实验能力，与 VLA 策略的动作执行能力结合起来。智能体把可供性视为可检验的假设：从少量源工具示范中提出功能区域和几何特征，在重建场景的仿真中测试、诊断和修正，形成可复用的提取技能；随后将提取出的特征编码为策略输入，指导其操作未见工具。
- **核心主张：** 跨工具迁移的关键不应是工具身份或固定动作轨迹，而应是工具上支持任务交互的功能结构，以及相应的操作策略。

## 2. 方法论

### 2.1 整体流程

A²-VLA 的方法可概括为“**重建—发现—测试—修正—编码—执行**”：

1. **重建源工具示范场景：** 利用遥操作示范中的图像、机器人轨迹、相机标定参数和机器人模型，在仿真中重建工具、目标物体和场景布局。
2. **发现任务相关可供性：** 智能体比较源工具示范，判断哪些功能区域及其几何属性支持任务，例如区域位置、局部方向、切割方向或支撑面法向。
3. **在仿真中验证和修正：** 将源工具轨迹依据候选可供性重定向到其他工具，执行模拟并检查任务结果、接触情况和诊断视图。若失败，智能体据此调整功能区域、几何特征或提取技能。
4. **构建可复用技能库：** 将通过仿真验证的可供性提取技能及其适用条件存入技能库，用于标注源工具示范，也用于分析未见工具。
5. **训练并部署可供性引导的 VLA：** 将统一编码后的功能特征作为条件输入给基于 π₀.₅ 的策略。部署时，智能体先在仿真中分析、验证未见工具的特征，再将其提供给 VLA 执行真实机器人任务。

### 2.2 仿真轨迹重定向

- 设源工具完成任务的轨迹为 \(Q\)，其逐时刻可供性特征为 \(f_t^{src}\)。对目标工具，寻找满足可达性与碰撞约束的轨迹 \(Q'\)，使其特征 \(f_t^{tgt}(q'_t)\) 与源特征对齐，同时保持轨迹平滑。
- 其目标函数由两部分构成：
  - **可供性对齐损失：** 匹配源、目标工具功能区域的位置和任务相关方向；
  - **轨迹平滑项：** 避免产生不连续或不自然的机器人运动。
- 仿真结果提供任务成功与否、接触信息等反馈，用于迭代修正特征和提取技能，而不只是一次性预测功能区域。

### 2.3 特征编码与 VLA 训练

- 每个任务使用统一的 **12 维可供性向量**。特征以机器人基座坐标系表达，具体维度随任务而异，通常包括功能区域位置、方向轴的编码及任务相关方向。例如：
  - **勾取圆环：** 钩取区域核心位置、末端切线方向及可选的凹面开口方向；
  - **切割沙料：** 工作边缘位置、边缘切线方向及可选的切割面方向；
  - **支撑并搬运盘子：** 支撑区域位置、支撑平面法向及抬升方向。
- 可供性向量经学习得到的编码器映射为单个条件 token，与图像、语言指令和机器人状态共同输入 π₀.₅。
- 策略同时预测动作片段和未来可供性轨迹；训练损失由动作的 flow-matching 目标与未来可供性轨迹的辅助监督组成。这样的辅助预测旨在鼓励策略在不同工具间保持任务相关的功能轨迹。
- 训练数据还包括 **10% 的反事实轨迹重定向数据**：随机扰动当前可供性位姿，再规划动作，使可供性轨迹平滑回到原任务轨迹，以增强策略遵循可供性条件的能力。
- 部署时，策略根据当前观察、机器人状态和可供性条件生成一段动作，机器人执行部分动作后重新观察并规划。

- **仍有限的部分：**
  - 真实任务只有三类，均属于较易用功能区域和轨迹重定向描述的工具操作，任务覆盖面有限。
  - 未报告多次独立训练的均值、标准差或置信区间；episode 数虽有报告，但仅凭成功率难以判断统计显著性。
  - 多个任务上的结果仍不高，尤其是未见工具 Cut Sand 仅 26%，说明总体平均值不能代表各任务的稳定性。
  - 仿真比较使用重建场景；其可靠性依赖场景、工具模型和接触效果重建质量。论文报告通过轨迹回放检查，但未提供足以全面评估 sim-to-real 一致性的量化指标。
  - 由于输入条件并不完全相同（部分基线获得 CAD），且各方法使用原生表征和迁移流程，比较结果有参考价值，但并非所有方法在完全相同信息条件下的严格对照。

## 6. 主要结论与发现

- 在仿真跨工具轨迹重定向中，A²-VLA 达到 **86.1% 平均成功率**，明显高于直接 VLM 预测可供性的 Raw VLM（37.8%）。这支持了“先测试和修正可供性，再用于迁移”的设计。
- 在真实机器人未见工具上，A²-VLA 平均成功率为 **35.3%**，高于 π₀.₅ 的 4.7% 和 Agent-Only 的 25.0%。相较 π₀.₅，提升为 **30.6 个百分点**，论文概述为约 30.7 个百分点。
- 仿真修正有助于提升仿真重定向成功率；从 0 次到 6 次修正，Cut Sand、Reset Plate、Pnp Ring 分别提升 23.8、18.3、30.0 个百分点。Full A²-VLA 在真实机器人未见工具上的平均表现也高于不进行仿真迭代的变体（35.3% 对 22.0%）。
- 增加源工具多样性通常有利于发现更具普适性的功能结构：Pnp Ring 使用 1 种到 5 种源工具时，未见工具平均仿真成功率从 56.2% 上升至 81.3%，不同工具间的成功率波动也明显缩小。
- Human Oracle 在未见工具上的平均成功率为 47.3%，高于 Full A²-VLA 的 35.3%。这表明自动发现的可供性仍有改进空间，同时也说明即使可供性质量较好，VLA 执行能力仍可能限制任务成功。

## 7. 优点

- **把可供性发现做成闭环过程：** 不只让 VLM 一次性猜测功能区域，而是通过仿真执行结果检查假设并迭代修正。
- **分工清晰：** 智能体负责功能分析、仿真试验和未见工具特征提取；VLA 根据图像、语言、机器人状态和可供性特征生成动作。
- **中间表示具有迁移导向：** 采用统一特征语义和坐标协议，使不同外形工具可用同一类条件输入表达其任务相关功能。
- **具备一定可复用性：** 将验证过的提取程序及适用条件保存为技能库，而非针对每个新工具从头分析。
- **评价维度相对丰富：** 同时包含仿真可供性可靠性、真实机器人成功率、源工具与未见工具测试、仿真修正消融、源工具数量分析和 Human Oracle 参照。
- **对失败的边界有所揭示：** Human Oracle 与 Full A²-VLA 的差距、以及不同任务上的成功率差异，说明“可供性发现正确”与“策略能否成功执行”并非同一问题。

## 8. 不足与局限

- **适用范围受限：** 论文指出，方法目前主要适用于能够通过轨迹重定向解决的工具迁移；需要学习全新接触策略、复杂操作机制或非重定向型技能时，未必适用。
- **可供性正确不保证动作成功：** VLA 可能无法严格遵循给定的功能特征，导致执行失败；Human Oracle 的结果也显示策略执行仍是瓶颈之一。
- **仿真依赖较强：** 方法需要重建场景与工具，并依赖模拟接触和任务结果提供有效反馈。重建误差或仿真与真实环境的差异可能使修正方向不可靠。
- **任务和工具覆盖有限：** 仅评估勾取、切割、支撑搬运三项任务，不能据此断言对其他工具类别、柔性物体、复杂双手协同或长时序任务同样有效。
- **未见工具表现仍有限且不均衡：** 总体 35.3% 的成功率显示迁移有显著改善，但距离可靠部署仍有差距；Cut Sand 的成功率尤其低。
- **资源报告不完整：** 未提供 GPU 型号、数量、训练时长和智能体调用成本，限制了计算效率评估与复现。
- **统计报告有限：** 文中没有报告重复训练方差、置信区间或显著性检验，部分成功率差异的稳健程度难以判断。
- **潜在模型依赖与复现风险：** 智能体部分由 GPT-6 Astra 驱动，而文中未充分报告其提示、调用细节和成本；此外，整体框架依赖仿真工具链与模型质量，实际复现可能面临额外门槛。
