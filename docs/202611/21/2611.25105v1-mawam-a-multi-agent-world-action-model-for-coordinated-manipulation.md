## 摘要
机器人团队中的每一个动作都会改变队友随后必须行动的世界。因此，协同操作需要同时预测团队的动作以及这些动作共同塑造的物理未来。我们提出 MAWAM，这是一种多智能体世界-动作模型，可在单次采样中联合生成每台机器人的未来视角和可执行动作片段。MAWAM 基于预训练的单机器人世界-动作骨干模型构建，通过跨智能体注意力对所有机器人的动作与未来视角 token 进行联合去噪，同时为每台机器人保留独立的控制接口。在三项真实机器人任务（收集洗衣袋、折叠浴巾和递交雨伞）中，MAWAM 均取得最高成功率，平均成功率为 67.8%，比使用相同示范数据和摄像头训练的 MA-VLA 高 18.9 个百分点。在仿真中，MAWAM 在由最多四条机械臂组成的团队所执行的八项任务上，平均成功率达到 90.3%。消融实验表明，跨智能体注意力和团队阶段的未来视频监督均有助于提升协同控制能力：去除注意力后，四臂接力任务的成功率从 95.0% 降至 39.0%；去除该监督后，Place Food 任务的成功率从 78.0% 降至 47.0%。

## Abstract
Every move in a robot team changes the world in which its teammates must act. Coordinated manipulation therefore calls for predicting the team's actions together with the physical future they jointly create. We introduce MAWAM, a multi-agent world-action model that jointly generates each robot's future views and executable action chunks in a single sample. Built from a pretrained single-robot world-action backbone, MAWAM jointly denoises all robots' action and future-view tokens through cross-agent attention, while preserving a separate control interface for each robot. MAWAM achieves the highest success on all three real-robot tasks (laundry-bag collection, bath-towel folding, and umbrella handover), with 67.8% mean success, 18.9 percentage points above MA-VLA trained on the same demonstrations and cameras. In simulation, MAWAM reaches 90.3% mean success on eight tasks with teams of up to four arms. Ablations show that cross-agent attention and team-stage future-video supervision both improve coordinated control: without attention, a four-arm relay falls from 95.0% to 39.0%, and without this supervision, Place Food falls from 78.0% to 47.0%.

# MAWAM 论文总结

## 1. 核心问题与整体含义

- **研究问题**：多机器人协同操作中，每台机器人的动作都会改变共享环境，进而影响队友下一步能观察到什么、能够做什么。若各机器人只独立生成动作，容易出现不同步、等待或无法配合等问题；若只预测多视角未来，又不能直接生成可执行的联合控制。
- **研究动机**：现有方法往往只强调分散式策略、联合动作生成或任务级规划，较少将团队动作与其共同造成的视觉后果放在同一生成过程中建模。
- **论文主张**：把协同操作看成“团队共同塑造物理未来”的问题。MAWAM 在同一次生成中同时预测所有机器人的动作片段和未来相机视图，让动作生成与环境演化预测相互关联。
- **整体意义**：该工作尝试把单机器人世界—动作模型扩展到多机器人团队，使团队既能生成可执行控制，也能联合建模行动后各自将看到的场景。

## 2. 方法论

### 2.1 核心思想

- MAWAM 从预训练的单机器人世界—动作模型 **GR00T 2** 出发，扩展为多机器人联合模型。
- 对每个机器人，模型保留其独立的：
  - 私有相机视图；
  - 状态输入；
  - 动作输出和控制接口；
  - 任务角色信息。
- 模型将所有机器人的动作 token 与未来视图 token 放入共享 Transformer，通过**跨机器人注意力**联合去噪。一次采样因此同时包含团队动作以及这些动作所对应的未来视图。

### 2.2 联合预测目标

设团队包含 \(N\) 个机器人。模型依据当前指令、各机器人的观测和状态、任务角色，以及可选的共享全局相机输入，预测：

1. 各私有摄像头在未来时刻的视图；
2. 每个机器人的动作片段。

论文中动作预测跨度为 **24 个控制步**；未来视图覆盖同一时间跨度，每隔 3 步预测一帧，共 8 帧。模型以流匹配方式训练，损失由两部分构成：

- **未来视频损失**：监督各机器人的未来私有视图；
- **动作损失**：监督各机器人可用控制维度。

两类目标都通过有效性掩码排除填充项、无效相机视图或不可用控制维度。共享全局相机（若存在）可作为只读上下文，不作为未来视频预测目标。

### 2.3 跨机器人交互与身份—角色表示

- **跨机器人注意力**：所有机器人的状态、视图和动作 token 在同一 Transformer 中进行密集双向交互。每个机器人生成动作时可以利用队友的动作及未来视图信息。
- **视图归属**：通过显式的“视图—机器人映射”标记每个私有相机属于哪台机器人，避免相机流与动作控制对应关系混淆。
- **机器人身份**：模型使用正则单纯形顶点作为 RoPE 的“机器人轴”身份编码。同一机器人的所有私有视图使用相同身份码；训练时随机分配身份码并打乱完整机器人数据组，降低身份或序列位置与特定机器人绑定的风险。
- **任务角色**：另用角色嵌入表示“持袋”“递交者”“接收者”等职责。身份和角色被明确区分：多台机器人可以承担同一角色，但各自仍保留独立观察、状态和动作输出。
- **动作—视频关联**：把某机器人动作 token 的摘要加入其所属视图的未来 token，促使模型关联该机器人的控制与其相机视角下的未来变化。

### 2.4 两阶段训练与闭环控制

1. **单机器人预热（Warm-up）**：从预训练模型出发，每次使用一台机器人的视图、状态和动作进行适配；此阶段关闭角色、身份编码和跨机器人注意力，使模型适应目标相机及控制器。
2. **团队训练**：使用同步的多机器人演示，启用角色、随机身份分配、机器人组打乱和跨机器人注意力，并联合监督所有机器人的动作与未来视图。
3. **部署执行**：一次联合采样生成各机器人的 24 步动作片段和未来视图。机器人同步执行前 8 步，之后根据新的观测重新采样和规划。

## 6. 主要结论与发现

- 真实机器人三项任务中，MAWAM 均取得最高成功率，平均为 **67.8%**；相比同数据与相机设置下的 MA-VLA（48.9%），高 **18.9 个百分点**。
- 仿真八项任务平均成功率达到 **90.3%**，团队规模最多为四条机械臂。
- 跨机器人注意力对强耦合任务尤其重要：去除后，Long Pipeline Delivery 成功率从 **95% 降至 39%**；真实机器人平均成功率从 **67.8% 降至 52.2%**。
- 团队阶段未来视频监督也能提升协调控制：Place Food 成功率从 **78% 降至 47%**（去除该监督后）。
- 未来视图 token 的作用不等于必须在推理时生成完整视频。冻结未来 token 时多数任务表现相近；但直接从模型输入中移除未来 token，在 Pass Shoe、Long Pipeline Delivery 等任务中造成严重性能下降。
- 角色信息对职责不同的团队至关重要；但同一职责可以由多台机器人共享，而不必合并它们的身份、观测和控制接口。
- 在人为延迟队友的接力实验中，MAWAM 会延迟接收机器人的动作启动，表现出比独立智能体更明显的时序适应能力。

## 7. 优点

- **问题建模有针对性**：把联合动作与团队共同造成的视觉未来纳入同一模型，直接针对协作中动作—环境—队友之间的耦合。
- **兼顾联合协作与个体控制**：通过共享注意力建模团队互动，同时保留每台机器人的独立观察、状态和动作接口。
- **充分利用预训练模型**：单机器人预热使团队模型能继承已有世界—动作表征，而不是从头学习联合控制接口。
- **身份与职责解耦**：机器人身份编码和任务角色分开，支持多个机器人共享职责，同时维持各自的数据归属。
- **评测类型较多**：包括真实机器人、不同规模仿真团队、消融、延迟队友测试和未来视图预测，能从多个角度检验方法。
- **给出可执行的闭环方案**：预测长动作片段，但只执行其中一部分并重新规划，降低开放环动作预测可能造成的误差累积。

## 8. 不足与局限

- **团队规模和组成有限**：实验最多涉及四个仿真机械臂，真实机器人实验为固定的两机器人团队；论文也指出尚未支持动态团队成员变化。
- **跨平台与异构协作尚未验证**：尚未系统展示不同机器人本体、传感器配置或控制接口混合时的效果。
- **真实场景任务数量有限**：真实任务只有三项，且每项 30 次试验；对于家庭、工业等更广泛场景的泛化能力仍需验证。
