Abstract
Human–object motion synthesis requires coordinated hu-
man participation as objects move toward specified goals.
However, reaching object targets does not ensure that con-
tact is established and maintained, while adjustments that
improve contact may interfere with task completion. We
introduce CoRelate, a diffusion framework that coordi-
nates full-body human–object motion through explicit in-
teraction relations and task feedback for rigid and articu-
lated objects. We represent intended participation through
hand–part relations that specify the participating hand, its
part-relative reference position, and participation interval.
These relations serve both as generation conditions and as
references for measuring interaction realization. At each
denoising step, a temporal refiner trained jointly with the
generator combines relation deviations, task residuals, and
motion features from the current prediction to jointly up-
date human and object motion across the sequence. Af-
ter generation, temporal motion correction addresses re-

1. Introduction
Generating full-body human–object interaction is central
to character animation, interactive simulation, and behav-
ior modeling for embodied agents and robotic systems
[18, 19, 46].
Purposeful interaction requires the human
and object to move coherently over time while accomplish-
ing a requested task goal. Sparse object waypoints offer
a practical way to specify such tasks without prescribing
a complete motion sequence, by constraining selected ob-
ject states while leaving substantial freedom in how the per-
son participates and how the object moves between way-
points [19, 39]. Successful human–object motion synthesis
must therefore realize both what the object accomplishes
and how the human participates in the same generated mo-
tion (Fig. 1).
Prior work on joint human–object generation infers both
motions from language or motion conditions [5, 27], with
additional control through initial states and sparse object
waypoints [19, 39].
Contact and relation modeling can
improve human–object coordination [17, 47]. Geometry-
aware guidance and learned refinement further improve ge-
ometric alignment and motion coherence [17, 29, 39]. How-
ever, in operations requiring hand contact, an object may be-
gin moving before contact is established or continue mov-
ing while the hand remains separated from its surface or
loses contact. Such failures can persist even when the sup-
plied object targets are satisfied. Reducing relation error
alone does not determine an appropriate correction under
sparse task constraints, since the discrepancy can be re-
duced by adjusting human motion, intermediate object mo-
tion, or both. Task residuals provide an explicit signal for
coordinating these adjustments with the supplied object tar-
gets, as moving an object toward the hand may undo an
already reached target or help correct an overshoot. More-
over, an update that improves contact in one interval may
disrupt participation or motion continuity elsewhere. We
use representations of intended participation as a reference
for measuring its realization and guiding motion updates to-
gether with task feedback. This leads to our research ques-
tion: How can we represent and use interaction relations to
coordinate human–object motion that establishes and sus-
tains contact while satisfying object goals and preserving
motion quality?
We present CoRelate, a diffusion framework that coor-
dinates human–object motion under sparse object goals us-
ing explicit interaction relations and task feedback. From
an initial motion proposal and task geometry, we construct
hand–part relations specifying which hand participates, its
reference position relative to the object part, and its par-
ticipation interval. These relations serve both as genera-
tion conditions and as references for measuring interaction
realization. During denoising, relation deviations measure
departures from the selected hand–part arrangement, while
task residuals measure errors at the supplied object targets.
A temporal refiner trained jointly with the generator, com-
bines these signals with motion features to predict coordi-
nated human and object updates across the sequence. Re-
lations and sparse waypoints remain fixed, while feedback
is recomputed from the evolving human and object trajec-
tories at each denoising step. A common part-relative inter-
face supports rigid and articulated interactions, with object
updates applied to rigid poses and articulated joint states, re-
spectively. After joint generation and refinement, segment-
level temporal motion correction addresses remaining con-
tact failures.
At this stage, we fix the generated object
trajectory and a continuous solver adjusts local hand mo-
tion and preserves protected human motion. By distributing
corrections across neighboring frames, the solver improves
contact while limiting abrupt wrist changes. Our contribu-
tions are:
• A relation representation that specifies where and when
each hand participates to condition generation and evalu-
ate interaction realization for rigid and articulated objects.
• A feedback-driven refiner that integrates relation devia-
tions, task residuals, and motion features from current
predictions to jointly update human and object motion.
• A temporal motion correction method that reduces resid-
ual contact failures while preserving object trajectories
and human motion.
2. Related Work
Full-body human–object motion generation.
Human–
object generation builds on text-conditioned motion syn-
thesis [3, 7, 11, 24, 38, 51] and controllable generation
[12, 44, 52]. For moving objects, human motion can be gen-
erated from complete object trajectories [18], while task-
conditioned methods synthesize interactions from higher-
level specifications [6, 22].
Text-driven joint generators
infer both human and object motion through coupled mo-
tion streams, contact guidance, and relation intervention
[5, 27, 34, 41].
For spatial control, CHOIS [19] jointly
generates human and object motion from language, initial
states, and object waypoints.
Related approaches intro-
duce geometry-aware spatial control [39] and flexible con-
ditions over SE(3) trajectories [16]. For articulated manipu-
lation, CoDA [29] coordinates separate body and hand mo-
tion priors. This coordination allows whole-body posture to
2


adapt to hand-level interaction constraints on movable ob-
ject parts. Other articulated generators combine locomotion
and manipulation [53] or use surface keypoint trajectories
to represent multiple objects and articulation [28].
Interaction relations and dynamics. Geometric represen-
tations based on sampled points, interaction fields, and sur-
face anchors provide spatial context for human–object inter-
action [15, 23, 30]. Relative geometry and contact represen-
tations can support joint motion reconstruction [10, 26, 43],
whole-body grasping and dexterous manipulation [36, 42,
49, 50], and text-driven hand motion [2, 4, 9, 21]. Con-
tact prediction [5, 25, 27], affordance models [20, 35], and
temporal contact models [1, 33] provide useful cues about
where and when interaction should occur. Joint-level re-
lation models [48] and part-relative motion representations
with learned voting [17] can encode human–object cou-
pling within generation. For example, ROG [47] learns a
spatiotemporal prior over interactive distance fields, where
it refines the field computed from the current motion pre-
diction and uses the refined relations to guide motion up-
dates during denoising. SK-HOI [28] predicts a spatiotem-
poral contact distance field from generated object trajecto-
ries and uses it to guide human-motion synthesis through
noise optimization. HOI-Dyn [40] learns object responses
to human motion and uses response consistency to super-
vise joint generation. Our method uses the selected local
hand–part relations both to condition generation and to pro-
vide a reference for measuring participation. The realiza-
tion is evaluated against the evolving motion prediction and
the resulting deviations are combined with task residuals to
enhance learned human–object updates within denoising.
Geometric guidance and motion refinement. Geomet-
ric constraints are incorporated through contact supervision
[5, 19, 27], sampling guidance [12, 33, 47], and diffusion-
noise optimization [13, 28, 29, 32] to improve contact align-
ment and spatial accuracy.
Learned hand-motion mod-
els typically use local object surfaces and temporal hand–
object correspondences to synthesize or refine poses that
reduce penetration and contact inconsistencies [37, 54, 55].
For full-body interaction, contact-relative motion predic-
tion can correct denoised human–object sequences within
diffusion [45].
For instance, MaMi-HOI [39] combines
geometry-aware feature adaptation with a spatially con-
ditioned whole-body adapter to reduce the motion stiff-
ness that local contact refinement can introduce.
PAMI
[17] recursively updates human and object motion after ini-
tial coarse generation using surface geometry and tempo-
ral attention, coupled with body support, trajectory smooth-
ness, and preservation losses to discourage unwanted mo-
tion changes. CoRelate uses hand–part references and re-
computes their realization errors together with sparse-target
residuals at each denoising step. A learned refiner uses both
signals to jointly update human motion and object states.
For remaining local failures after generation, we solve con-
tinuous arm segments while retaining object motion and re-
stricting edits to the selected human joints and time inter-
vals.
3. Method
Given conditions c = (ℓ, Xinit, g, M) with a language in-
struction, an initial human–object state, sparse object tar-
gets, and an object model, CoRelate generates a coordinated
motion sequence X = (H, O). The object goals specify
object states at selected times; the intervening human and
object trajectories are jointly generated and refined. To de-
scribe how the human participates in the process, we con-
struct interaction relations R that specify which hand inter-
acts with which object part, the wrist reference in the part
frame, and the participation interval. During denoising, we
measure deviations of the current motion prediction from
the prescribed relations and object targets, and a learned re-
finer combines this feedback with motion context to predict
joint human and object updates (Fig. 2). After generation,
local motion correction addresses remaining contact viola-
tions while keeping the resulting object trajectory and mo-
tion outside the editable region fixed. We describe relation-
conditioned generation in Sec. 3.2, feedback-driven joint re-
finement in Sec. 3.3, and constrained segment-level correc-
tion in Sec. 3.4.

3.2. Relation-Conditioned Motion Generation
To construct R, we first sample a motion proposal X using
a motion generator conditioned only on c without relation
inputs. The proposal and task conditions are then used to
construct the interaction relations. The relation-conditioned
generator subsequently starts a separate sampling process
from fresh noise under c and R.
Interaction relations. We represent each relation as r =
(h, j, xrel, I, φ) ∈R, which specifies the participating
hand, target part, part-local wrist reference, participation
interval, and phase assignment. Proposal-derived relations
describe the selected participation arrangement rather than
contacts uniquely required by the task. The reference xrel
r
∈
R3 specifies the wrist position relative to part j during the
hold phase. Hold denotes sustained hand–part participa-
tion, including pushing or pulling, without requiring a fin-
ger grasp. Expressing it in the part frame allows the ref-
erence to move with the interacting component, such as a
translating drawer or a rotating door. This separates global
part motion from deviations in relative hand following. It
need not lie on the surface as the wrist is offset from the
palm or finger contact.
The time-dependent assignment
φr : Ir →{establish, hold, release} distinguishes ap-
proaching, maintaining, and leaving the relation, so that ap-
proaching and departing do not require the same fixed rel-
ative position as the hold phase. We denote each phase by

coordinate-wise median of the proposal wrist positions, ex-

beddings bias attention and contribute relative information
to the residual feature update.
3.3. Joint Human–Object Refinement
We refine human–object motion by jointly considering the
selected interaction relations and object task targets.
At
each denoising step, we compute relation feedback and task
residuals from the current clean-motion prediction bX0. The
refiner combines these signals with the generator’s motion
features to predict coordinated human and object updates
across the motion sequence.

Fψ together on recorded motion sequences, with supervi-
sion applied through the corrected motion:

These terms supervise motion reconstruction, FK-decoded

Supervision on the corrected motion trains the refiner to
map relation deviations, task residuals, and motion con-
text to coordinated human and object increments. Gradi-
ents jointly train Dθ and Fψ, including through the geomet-
ric feedback. Relation construction lies outside this gradi-
ent path, and the timing predictor Pη is trained separately.
The separate proposal generator remains frozen. After mo-
tion generation, a finger-only optimization uses a training-
derived PCA hand-pose prior and contact, penetration, re-
lease, and temporal-smoothness terms. It preserves body
motion, wrist positions, palm orientations, and object tra-
jectories.
3.4. Temporal Motion Correction
Joint refinement can leave local contact violations in the
generated motion.
Correcting these violations indepen-
dently at each frame can introduce abrupt motion or discon-
tinuities at edit boundaries. We therefore jointly optimize
human joint rotations over short temporal segments around
contact violations while keeping the generated object tra-
jectory fixed, preserving its existing object-target errors.
Editable regions. Given a post-refinement prediction Xref,
the selected relations identify the participating hands and
intervals, while the current geometry locates contact viola-
tions during object motion. An editable mask Medit speci-
fies which body joints and frames can change within these
temporal segments. We extend each interval to include ap-
proach and boundary-transition frames. The observed pre-
fix and motion outside the editable region remain protected.
Temporal optimization.
At inference time, the solver
jointly optimizes shoulder, elbow, and wrist rotations over
each selected segment, keeping network parameters, root
translation, and object motion fixed. FK updates hand posi-
tions while preserving bone lengths. Its objective combines
geometric, temporal, and edit-magnitude terms:
Lseg = wcLc + wsLs + wpLp
+ waLa + wjLj + wdLd.
(7)
The contact and slip terms Lc and Ls encourage surface
proximity and relative following. The temporal terms La
and Lj penalize changes in acceleration and excessive
wrist steps, including transitions to unchanged motion. A
surface-proximity proxy Lp and an edit-magnitude penalty
Ld regularize the correction. Joint optimization distributes
adjustments across neighboring frames. The correction pre-
serves object trajectories and protected human motion, leav-
ing object-target errors unchanged.
4. Experiments
4.1. Experimental Setup
Datasets. We evaluate on FullBodyManipulation [18] and
ParaHome [14]. FullBodyManipulation contains approxi-
mately 10 hours of paired human and object motion involv-
ing 15 objects. We follow the CHOIS subject split [19].
ParaHome captures household interactions involving rigid
objects and articulated parts.
We use recording-disjoint
splits for evaluation. Models are trained independently on
each dataset.
Metrics. We measure object-target accuracy using endpoint
position error Te and horizontal waypoint error Txy, follow-
ing prior protocols [19, 39]. Interaction is evaluated us-
ing hand-contact precision, recall, and F1 (Cprec, Crec, CF1)
against reference contact labels, averaged over windows.
We propose Motion-weighted Contact Coverage (MCC),
which measures the fraction of object motion accompanied
by hand contact. We assess geometry and motion quality
using hand-mesh penetration (Phand), foot sliding (FS), FID,
top-3 text–motion retrieval (Rprec), and embedding-space
diversity (Div.).
Reference fidelity is measured by root-
relative MPJPE, object translation error Tobj, and rotation-
matrix error Oobj. Position and penetration errors are in cm,
and Oobj is dimensionless. We also define Complete Interac-
tion Success (CIS), which measures the percentage of out-
puts that jointly satisfy object goals and waypoints, applica-
ble contact requirements, and motion-validity criteria. For

4.3. Qualitative Results
We visualize the generated human–object interactions in
Fig. 3. In the rigid-object example, CHOIS and HOI-Dyn
exhibit intervals of object motion without hand contact and
leave the object away from its goal. MaMi-HOI maintains
hand contact but still leaves a visible offset between the fi-
nal object position and the goals. Similar coordination is-
sues appear in the articulated interactions. CoDA makes
contact with the manipulated doors, but contact can be in-
terrupted and the doors do not reach their target configu-
rations. SK-HOI shows more pronounced hand–part sep-
aration, with the door moving despite absent or lost hand
contact. In comparison, CoRelate maintains hand contact
as the object or articulated part moves toward its target and
produces interactions where human participation accompa-
nies task completion.
4.4. Ablation Study
We assess the cumulative contributions of generation and
refinement components on FullBodyManipulation (Tab. 3).
Relation conditioning improves contact metrics and com-
plete interaction success, which supports the use of explicit
participation information to guide generation. Adding the
refiner without feedback provides only a modest additional
success gain, whereas task feedback provides the largest
improvement in complete interaction success and substan-
tially reduces object-goal errors. This contrast highlights
the value of explicit task residuals beyond adding the re-
finement architecture alone. Relation feedback further im-
proves both contact metrics and object-goal accuracy, which
suggests that measuring interaction realization helps refine
contact together with the intended object motion. The full
model achieves the highest complete interaction success. R-
precision remains relatively stable, and relation feedback
improves FID over task feedback alone, although motion-
quality metrics do not improve uniformly across component
additions. These results support relation conditioning and
complementary task and relation feedback.

5. Conclusion and Limitations
We presented CoRelate for coordinated human–object mo-
tion synthesis under sparse object goals. Explicit interaction
relations serve as both generation conditions and references
for measuring interaction realization.
Relation feedback
and task residuals jointly guide human–object updates dur-
ing denoising, while temporal motion correction addresses
remaining contact failures without changing object trajecto-
ries or protected human motion.
Our method has several limitations. Relations remain
fixed during generation, which may limit recovery from un-
suitable participation arrangements, and the current repre-
sentation does not support repeated regrasping within a mo-
tion window. Local motion correction cannot resolve fail-
8


ures that require changes to object motion or broader body
adjustments. The method also does not explicitly model ar-
ticulated finger grasps or contact forces, so geometric con-
sistency alone does not guarantee physical validity. Future
work could adapt participation timing and hand–part assign-
ments during generation to support repeated regrasping.
