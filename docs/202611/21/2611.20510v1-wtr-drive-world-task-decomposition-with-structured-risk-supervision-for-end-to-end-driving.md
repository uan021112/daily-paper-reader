## 摘要
由候选轨迹条件化的场景预测，可能缺少跨候选轨迹一致的对象级参照。聚合规划评分也未明确指出与违规相关的对象和时间。我们提出 WTR-Drive（World-Task-Risk Driving，世界—任务—风险驾驶），这是一种基于 Drive-JEPA 的规划器，将共享场景估计与候选条件化推理分离。与候选轨迹无关的 World Memory（世界记忆）在每轮细化时重新读取原始视觉特征，以估计对象状态、地图结构和未来运动。候选反馈会更新残差 Task 分支，但不会写回 World Memory。该分支通过针对候选的检索和门控视觉反馈引导细化。最终的 Task 读出为评分提供候选条件化特征。我们利用现有候选评分过程中的 rollout 推导结构化风险目标，无需额外调用模拟器。对于责任方碰撞和碰撞时间违规，这些目标编码了事件是否发生、与共享对象槽位的关联，以及首次违规所在的时间分箱。在 NAVSIM 的 navtest 划分上，WTR-Drive 在 v1 上取得 94.66 PDMS，在 v2 上取得 88.24 EPDMS（专家帧序列评估）。这两个分数分别比已发表的 Drive-JEPA 结果高 0.96 和 0.44 分。候选级分析表明，最佳候选的得分更高，所选轨迹的得分却可能更低，这揭示了候选质量与选择效果之间的差距。

## Abstract
Proposal-conditioned scene predictions can lack a common object-level reference across candidate trajectories. Aggregate planning scores also leave the objects and times associated with violations implicit. We present WTR-Drive (World-Task-Risk Driving), a Drive-JEPA-based planner that separates shared scene estimation from proposal-conditioned reasoning. A proposal-independent World Memory estimates object states, map structure, and future motion by re-reading the original visual features at each refinement round. Proposal feedback updates a residual Task branch without writing back to World Memory. This branch guides refinement through candidate-specific retrieval and gated visual feedback. A final Task readout supplies candidate-conditioned features for scoring. We derive structured risk targets from existing candidate-scoring rollouts without additional simulator calls. For at-fault collision and time-to-collision violations, the targets encode event existence, association with shared object slots, and the first violation time bin. On the NAVSIM navtest split, WTR-Drive achieves 94.66 PDMS on v1 and 88.24 EPDMS on v2 (expert-frame sequential evaluation). These scores are 0.96 and 0.44 points above the published Drive-JEPA values, respectively. Candidate-level analysis shows that higher best-candidate scores can coexist with lower selected-trajectory scores, revealing a gap between candidate quality and selection effectiveness.
