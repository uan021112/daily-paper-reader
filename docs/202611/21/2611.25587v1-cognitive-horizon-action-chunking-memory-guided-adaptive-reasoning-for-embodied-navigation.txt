Abstract
Multimodal foundation models are advancing embodied nav-
igation, but frequent inference incurs substantial computa-
tional cost. We present Cognitive-Horizon Action Chunking
(CHAC), a training-free framework for memory-guided adap-
tive reasoning with a frozen navigation policy. Retained visual
context, completion cues, and controller feedback determine
the cognitive horizon, or how many cached waypoints the
robot executes before refreshing its prediction. At the policy’s
stop request, local visitation history guides a bounded correc-
tion with at most one extra movement and no additional model
calls. CHAC reduces vision-language model calls by 33.4%
on HM3D-OVON and 64.7% on R2R-CE, with success-rate
decreases of 0.63 and 10.82 percentage points, respectively.
Success rate and success weighted by path length improve
per model call on both benchmarks. Across four physical
navigation tasks with 40 runs per method, CHAC achieves 18
successes versus 14 for native execution, reducing model calls
by 54.9% and GPU inference time by 49.7%.

Introduction
Recent advances in multimodal foundation models are ex-
panding embodied intelligence. Robot-control evaluations
of general-purpose multimodal models [4] and advances in
manipulation with Gemini Robotics 2.5 [21] illustrate the
promise of connecting visual understanding and language
instructions with embodied action. For navigation, vision-
language models (VLMs) interpret scenes, ground goals and
instructions, and generate movement through unfamiliar en-
vironments [12, 28, 32, 35]. Sustained navigation requires
coordinating this inference with physical execution.
Repeatedly invoking large vision-language policies incurs
computational cost over many physical actions. Action chunk-
ing amortizes this cost by predicting several future actions per
invocation [8, 33]. Its benefit depends on execution: frequent
refreshes limit reuse, while extended execution can carry a
prediction beyond its supporting observations and motion con-
ditions. Efficient navigation requires deciding how long to
act on a prediction and when new evidence warrants another
policy invocation.
Existing approaches adjust inference timing or execution
horizons using consistency or uncertainty signals [1, 10, 13,
19, 23]. Navigation must also account for movement-induced
changes: a turn reveals a new action direction, a completion
cue warrants fresh inference, or the controller cannot realize
the requested motion. Refreshing changes subsequent actions,
observations, and execution before termination. Its computa-
tional effect therefore extends beyond the immediate cost of a
new call, motivating decisions based on current evidence and
retained context.
Our key insight is that retained visual context and visitation
history can guide both inference timing and terminal execu-
tion. Visual references and observation coverage preserve
the context available when each prediction was generated.
Completion cues and motion feedback complement this con-
text when deciding whether to reuse or refresh a prediction.
Executed actions also leave a position history that remains
available after prediction replacement. Our offline trajectory
analysis reveals episodes in which the robot enters a suitable
stopping region but later stops outside it (Section 5.5). Nearby
visited positions can therefore provide a geometric reference
for a bounded terminal correction.
We introduce Cognitive-Horizon Action Chunking
(CHAC), a training-free framework for memory-guided adap-
tive reasoning with a frozen navigation policy (Fig. 1). CHAC
determines when to reuse a cached prediction and when to
invoke the policy again. Its cognitive horizon counts the or-
dered waypoints executed before refresh. A visual boundary

Our contributions are threefold:
• We introduce CHAC, a training-free framework for
memory-guided adaptive reasoning combining an on-
line cognitive horizon for policy invocation with history-
guided terminal correction.
• We identify how refresh decisions interact with subse-

• We evaluate navigation quality and inference cost across
two benchmarks and physical tasks, with matched termi-

Related Work
2.1
Vision-Language-Action Models for Navi-
gation
Vision-and-language navigation (VLN) grounds language in
sequential visual decisions [3], while vision-language-action
(VLA) policies map multimodal observations and instructions
to executable actions [16, 36]. NaVid uses observation history
to predict actions [32]. OmniNav, SimpleVLN, and NaVIDA
predict waypoints or action chunks [12, 28, 35]. ETPNav
organizes waypoints in an evolving topological map [2]. These
models supply multi-step predictions whose execution and
refresh affect deployment cost.
2.2
Action Chunking and Adaptive Reasoning
ACT combines multi-step prediction with temporal ensem-
bling [33], and Diffusion Policy generates actions through
conditional denoising [8]. BID selects chunks using bidirec-
tional consistency [20]. SGAC combines self-guidance with
agreement between predictions [23]. Adaptive horizons use
action entropy, attention, cross-horizon agreement [15, 19, 25],
denoising variance in DVAC [11], trajectory geometry in
GeoAAC [7], or action-expert stability in ChunkTrust [13]. A3
2


verifies candidate prefixes [6], while DEHP learns a horizon
with a frozen policy [34]. AdaNav learns uncertainty-based
reasoning triggers [10]. ASPEN learns command persistence
to schedule reuse or fresh inference in a frozen navigation
VLA [1]. CHAC instead regulates ordered waypoint reuse
with retained visual context and execution checks, without
training a scheduler.
2.3
Memory and Feedback-Guided Execution
MEM combines short-term video and long-term language
memory for robot control [24]. In navigation, EvoNav summa-
rizes past trajectories [9], and MSGNav selects a final view-
point using visibility [14]. Feedback also guides inference
and correction: RTC and LiveVLN overlap inference with mo-
tion [5, 26], Slow4fast-VLN coordinates slow reasoning with
control [18], and A2C2 corrects cached actions [22]. Scene-
change triggers adapt inference timing [27]. For behavioral
correction, CorrectNav learns from error trajectories [31], and
SC2-WM uses world-model feedback [29]. CHAC uses exist-
ing visual context to schedule policy calls and local visitation
geometry for terminal correction, with frozen model weights.

4
Cognitive-Horizon Action Chunking
CHAC implements memory-guided adaptive reasoning
through the online scheduling of frozen-policy invocations.
Retained visual references and observation coverage inform
prediction reuse. Accumulated position records provide a ge-
ometric reference for terminal correction. New visual and
motion evidence determines whether the remaining waypoints
are executed or refreshed. Refreshing replaces the prediction
while retaining navigation history. At the native STOP request,
nearby visited positions supply the geometric reference for a
bounded correction.
4.1
Memory-Guided Action Reuse
CHAC retains a prediction while its execution checks permit
continued motion. The cognitive horizon hk describes this
lifetime as observations and motion feedback evolve. After
waypoint j, a refresh event Bk,j ends reuse before the next
cached movement. The available information Fk,j includes
the prediction, observations, execution state, motor feedback,
and native read-only controller previews. The first such event
determines the executed prefix:
hk = min{H, inf{j ≥1 : Bk,j}} .
(2)
Boundary checks are restricted to j < H, with inf ∅= +∞:
absent a refresh event, the full chunk is reused. Each event
uses information available at the check, making hk a bounded
stopping time with {hk ≤j} ∈Fk,j (Appendix B). The
episode budget imposes an additional execution limit.

Coordinated execution.
The two boundaries check the
same prediction before further reuse. Before each cached
MOVE, CHAC checks directional visual contrast, predicted
arrival, and controller-supported progress in sequence, refresh-

For fixed execution evidence, an additional boundary can
only preserve or shorten the current horizon. Over a closed-
loop episode, however, refresh changes subsequent actions, ob-
servations, and stopping decisions. Total calls depend on both
calls per action and the number of actions executed. A shorter
horizon therefore need not increase total calls. Section 5.4 ex-
amines this distinction through paired runs, including savings
associated with earlier failed stops.

Unified execution.
Algorithm 1 integrates reuse, refresh,
and terminal correction in one execution loop. A refresh re-
places unexecuted waypoints and renews the visual reference
while retaining navigation history. Accepted movements up-
date that history and receive motor feedback. A native STOP
request invokes the bounded correction, subject to the condi-
tions above, before stopping. Native decoding uses command
odometry. Available motion-state estimates provide feedback
and populate the spatial history.

Experiments
We evaluate how prior inference remains useful during cached
execution and as visitation history. Benchmark comparisons
establish the trade-off between navigation quality and infer-
ence cost. Ablations and paired analyses examine boundary
coordination and terminal correction, followed by physical
trials of prospective reuse.

5.3
Ablation Study
Table 2 reveals complementary contributions during execution
and at stopping. Moving from native execution to Fixed-5
reduces calls from 45,286 to 33,814, while SR falls from
30.60% to 21.40%. Adding terminal correction restores SR to
29.40% and raises SPL from 11.60% to 14.77% without ad-
ditional model calls. The executed history therefore supports
successful stopping beyond the use of predictions as cached
actions.
With terminal correction retained, Full CHAC achieves a
similar SR of 29.60% while reducing calls by 11.8% and
environment actions by 18.5% relative to Fixed-5 + Terminal.
SPL rises from 14.77% to 15.93%. The boundaries thus reduce
inference and execution demand at a comparable observed
success rate, while terminal correction accounts for most of the
success recovery in this comparison. Individually removing
Commitment or Visual from Full adds 5,300 or 1,052 calls.
The following analyses examine this dependence on execution
and test what information the history provides at stopping.
5.4
Closed-Loop Boundary Coordination
Commitment-dependent cost reversal.
The same visual
refresh rule has opposite observed effects on total calls with

Limitations
CHAC reduces neural inference demand with task-dependent
losses in success and SPL and increased environment actions.
Physical latency depends on camera acquisition and executed
motion. Terminal correction depends on the policy’s STOP
request and local visitation geometry. The physical trials use
calibrated motion estimates and exercise prospective reuse.
Paired simulation interventions provide the evidence for ter-
minal recovery. Broader deployment with measured odometry
would clarify motion robustness and end-to-end efficiency.
7
Conclusion
CHAC implements memory-guided adaptive reasoning with
a frozen navigation policy. Retained visual context regulates
prediction refresh, while visitation history enables bounded
terminal correction without additional inference. Our analy-
ses connect these decisions to navigation quality, inference
demand, and physical execution costs.

one additional movement slot relative to direct STOP; the

C
Implementation Details
Cache and boundary checks.
CHAC stores the five-
waypoint prediction, its inference-frame reference, and a cur-
sor into the ordered chunk. Continuation decodes the next
cached waypoint in the current execution frame. Visual, task,
and execution checks run in this order and stop at the first trig-
ger. A refresh discards the remaining cached waypoints and
establishes a new visual reference. Motor feedback can invali-
date the cache after execution. The model weights, waypoint
order, and native decoding rules remain fixed.
Visual evidence.
The simulation implementation caches
three grayscale references at 32 × 32 resolution. Compar-
isons use 32×30 images split into three vertical regions. Each
of the three current regions is compared with nine reference
regions, yielding a fixed-size pixel calculation per check. An-
gular coverage includes the inference views and native visual
history. Command odometry updates the current action di-
rection. The image reference stays unchanged until the next
policy invocation.
Motion interfaces.
Simulation previews use the native con-
troller’s filtered and snapped displacement while preserving
the simulator state. Physical deployment acquires the three
views sequentially and executes calibrated chassis commands.
Its feedback and projection interface use motion estimates
from the calibration. Both adapters supply motion feedback to
the execution checks.
Terminal records.
The simulation terminal stage reads po-
sition records aligned with native visual history and the three
current views. It retains multiplicity, applies the Hb local-
ity radius, and clips the mean offset to ρ = min(b, smotor).
For the reported simulation setting, H = 5, b ≈0.424 m,
and smotor = 0.25 m. The local history radius is approxi-
mately 2.12 m. A single pass over retained records computes
the mean, followed by a constant-size projection and native
admissibility check.
HM3D-OVON baseline scoring.
For AAC in Table 1, we
rescore the recorded trajectories using the common success
criterion of an actual STOP at a goal distance below 0.25 m.
