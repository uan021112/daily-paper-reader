Abstract
Tools with different shapes can have similar functions, but transferring manipulation skills across tools
requires understanding how tool geometry relates to the specific task and adjusting the manipulation strategy
accordingly. The key challenge is to discover the common affordances that contribute to task completion
across different tools and verify whether they support new tools in performing similar work. We present
A2-VLA, a tool-adaptation framework that combines an embodied agent with a VLA policy. It treats tool
affordances as hypotheses the agent can construct, test, and revise. Given teleoperated demonstrations with a
few source tools, the agent reconstructs the scenes in simulation and autonomously determines task-relevant
affordance features: functional regions and their key geometric properties. It develops affordance-extraction
skills and refines both the features and skills through autonomous experiments in the reconstructed scenes.
Validated extraction skills accumulate in a reusable skill library for unseen tools. Finally, A2-VLA uses
encoded functional-region features as conditioning inputs to a π0.5 backbone during training and inference.
Evaluation examines affordance reliability in reconstructed scenes and real-robot task success on unseen tools.
Our method achieves 86.1% success in simulated cross-tool trajectory retargeting based on affordances. On
three real-robot tool-use tasks, A2-VLA improves task success by 30.7 percentage points over π0.5.

1 Introduction
People can often reuse a familiar manipulation skill with an unfamiliar tool after inspecting it and attempting
to interact with the environment using it. A differently shaped implement may still provide functional regions
similar to those of a familiar tool, such as an edge for cutting or a tip for hooking, even though its appearance
and required wrist motion differ substantially from those of the original tool. What transfers is therefore
neither the tool’s identity nor a fixed end-effector trajectory, but an understanding of the properties that make
the intended interaction possible. Enabling robots to acquire and reuse this understanding from limited tool
experience would reduce the need to collect demonstrations for every new tool–grasp combination.
Toward this goal, we study how to enable a robot system to adapt to new tools that can perform the same
task, starting from teleoperated demonstrations using a small set of source tools. Vision-language-action
(VLA) policies already possess some tool-manipulation capabilities [3, 6, 14], but adapting them to entirely
new tools still requires repeated rollout collection and fine-tuning to maintain performance. Predefined
functional representations of tools have shown useful structure for transfer: MimicFunc establishes functional
correspondences through keypoints and function frames [18], and FuncBridge learns functional trajectories
separately from their grounding into actions [23]. Meanwhile, improvements in the embodied manipulation
capabilities of general-purpose large vision-language models (VLMs) make autonomous analysis of tool
function possible. Our focus is how an agent system can autonomously identify task-relevant functional
regions and determine their key geometric features, capturing functional commonality across tools to guide a
VLA policy in adapting to new tools.
We treat task-relevant affordance features as experimentally testable hypotheses. Although hierarchical robot
systems already connect reasoning by general-purpose VLMs to low-level policy execution through language
or spatial guidance [4, 7, 16], language or keypoints alone cannot fully represent the geometric details of
tools. Cross-tool adaptation additionally requires deciding which tool properties should be represented
for a specific task and testing whether these properties can guide the policy to complete it correctly. We
introduce A2-VLA, in which the agent starts from a few real-robot teleoperated demonstrations, reconstructs
the demonstrated scenes and tools in simulation, and conducts experiments within them. The agent analyzes
how different source tools accomplish the task, determines task-relevant affordance features, develops
affordance-extraction skills, and applies them to other tools to attempt task execution. Based on experimental
feedback, it analyzes unsuccessful interactions and refines the selected functional regions, geometric features,
or extraction skills. Successful skills and their applicability conditions accumulate during this process in a
reusable skill library. When faced with an unseen tool, the agent can therefore reuse previously validated
skills to identify corresponding functional regions and extract the same features.
We condition the low-level VLA execution policy on agent-encoded functional-region features through a
low-dimensional affordance interface. While analyzing the source tools, the agent determines task-relevant
affordance features, which are encoded under a unified protocol as conditioning inputs for VLA training.
Unseen tools’ affordances are described through the same protocol: their specific affordance parameters
are extracted while the coordinate representation and feature semantics remain unchanged. This gives the
agent freedom to select functional regions and geometric features while maintaining a consistent policy
input format. Encoded features serve as conditioning inputs when training a π0.5 policy with an auxiliary
affordance prediction head. During deployment, the agent reconstructs the unseen tool in simulation, extracts
and tests candidate affordances, and refines their parameters from simulation feedback before encoding them
under the same protocol for the VLA policy. At execution time, the VLA conditions each action chunk on the
updated affordance features and current observations.
Our evaluation examines the reliability and reusability of autonomously discovered affordances and their
effectiveness in cross-tool transfer. Simulation tests compare our affordance discovery and validation process
with other tool-adaptation methods, including task success when using affordances to retarget trajectories in

Our main contributions are:
• An agentic tool-adaptation framework that starts from teleoperated demonstrations using a small set of
source tools and autonomously determines task-relevant affordance features. The agent reconstructs the
demonstrated scenes in simulation, tests and refines these features through autonomous experiments, and
retains refined affordance-extraction procedures as reusable skills across tools.
• An affordance-guided VLA model that integrates the resulting low-dimensional feature vectors into action
generation. Affordance conditioning and auxiliary affordance-trajectory supervision train the policy to
faithfully follow the supplied affordance information while using current observations and robot state to
complete tool-use tasks.
2 Related Work
Tool adaptation. Tool adaptation requires understanding how a tool itself functions in a specific task.
KETO [15] and GIFT [19] learn sparse grasp and functional keypoints, while FuncBridge [23] predicts 2D
functional keypoint trajectories to guide action generation. However, functional points alone may not capture
more complex manipulation characteristics. Other work, such as MimicFunc [18], automatically extracts
keypoints and constructs function frames for cross-tool transfer. Its affordance schema and frame-construction
rules are predefined, however, so adaptation remains organized around interactions expressible within that
abstraction rather than autonomously determining which functional features a task requires. MAGIC [9]
matches DINOv2 visual features and local curvature to transfer a demonstrated contact strategy, with physical
simulation checking candidate motions. Its candidate generation relies on visual–geometric analogies and
struggles with substantially different tools. Other work uses simulation environments to discover and validate
reliable tool geometries, including GeT-USE [20] and ToolAnalogy [1], thereby improving the ability to
select suitable tools.
Vision-language-action models. VLAs learn observation-conditioned manipulation from multimodal
pretraining and robot demonstrations. Representative models include OpenVLA [6], the flow-matching
policy π0 [3], and π0.5 [14]. However, their manipulation knowledge remains dependent on the behaviors
and interactions covered by training data. Unfamiliar tool geometries and contact patterns can expose gaps in
this coverage, limiting cross-tool generalization. Hierarchical architectures decouple high-level task-related
information from low-level policies, allowing task reasoning and action control to be modeled separately. Hi
Robot uses language subgoals and HAMSTER uses 2D paths; these intermediate interfaces guide low-level
execution with task goals or spatial plans [4, 7, 16]. Existing work also adds functional guidance to VLAs and
related visuomotor policies, grounding task intent in spatial interaction structure. RT-Affordance [12] uses
key-stage end-effector poses, FuncBridge [23] predicts functional keypoint trajectories, and AFI [21] uses
3D affordance fields to guide waypoints and select trajectories. These representations provide explicit cues
about where and how to interact, connecting semantic goals to geometrically grounded action generation.
Embodied agents. Embodied agents use general knowledge to analyze tool functions and formulate
execution strategies. ReKep [5] generates relational keypoint constraints, and ToolAnalogy [1] proposes
functional features. Meanwhile, agentic real-to-sim systems, such as WorldMirror and SceneRig, reconstruct
interactive environments for trajectory replay and policy testing [8, 11, 22], allowing agents to test their
understanding of manipulation through interaction. For reusable skill development, ASPIRE [10] uses
execution feedback to repair control programs and distill reusable skills. A2-VLA applies real-to-sim

3 Problem Formulation
Given a task instruction ℓ, we are provided a small set of source tools, each with real-robot teleoperated
demonstrations. At time t, the observation ot = (It, qt) contains camera images It and the robot configuration
qt. The first command predicted from ot is at. An action chunk At = (at, . . . , at+H−1) contains H
consecutive robot commands. The demonstrations provide the observations and trajectories needed to
reconstruct tool interactions in simulation.
We seek transfer to unseen tools, disjoint from source tools, without additional task demonstrations. The
agent autonomously determines task-relevant affordance features by analyzing source-tool demonstrations,
identifying functional regions and key geometric properties shared across tools. It develops skills to extract
corresponding features from unseen tools. We denote the encoded functional-region feature vector at time
t by ft. Feature values follow a unified task-level encoding protocol. For an unseen tool, the skills use
inspection observations and its attachment to the robot. Different tools supply different values under the
same feature definitions and encoding. The policy πθ uses ft together with ot and ℓto complete the task. We
evaluate affordance reliability through simulated cross-tool retargeting and transfer performance through
real-robot task success.
4 A2-VLA
A2-VLA connects an agent that analyzes tool function with a VLA that executes the task (Fig. 2). The
agent reconstructs demonstrated interactions, develops affordance-extraction skills, and tests them through
simulation. Validated affordances condition VLA training and deployment.
4.1 Reconstructing Demonstrated Interactions
The agent performs real-to-sim reconstruction using observations and recorded robot trajectories from source-
tool demonstrations, together with calibrated camera parameters and a robot model, to reconstruct the tools,
target objects, and their spatial arrangement in simulation. Recorded motions anchor the reconstruction to the
demonstrated interaction. The resulting environment enables the agent to replace a tool, change its functional
parameters, adjust object positions, and execute candidate action sequences while observing contact and
task outcomes. The reconstructed environment enables the agent to rapidly test candidate functional regions
through simulated tool interactions.
4.2 Autonomous Affordance Discovery
From examples to extraction skills. As shown in Fig. 2(a), the agent compares source-tool demonstrations
to identify the functional region and properties that enable the task, such as position, local orientation, and
task-specific direction. It develops executable affordance-extraction skills for these task-relevant features.
Each skill extracts and encodes features as ft at each demonstrated time step, with spatial features expressed
in the robot-base frame through tool attachment and kinematics. Ordering these features in time yields the
demonstrated affordance trajectory.

and task instruction ℓ. An action prediction head and an auxiliary affordance prediction head output the
action chunk and future affordance trajectory:

The training target is Ft = (ft+1, . . . , ft+H), extracted from demonstrated action-target configurations by
the agent’s validated affordance-extraction skill. Each ft+h+1 describes the functional region at the target
of at+h, for h = 0, . . . , H −1. Thus ft is the current affordance feature vector, while Ft contains the H

The two heads are trained jointly with L = Lact + Laff. The action term is the backbone’s flow-matching
objective. The auxiliary term supervises the predicted affordance trajectory, encouraging similar affordance
trajectories across tools performing the same task. See Fig. 2(b) and Appendix C for details.
To strengthen the VLA’s ability to follow affordance guidance, we additionally include 10% counterfactual
trajectory-retargeting data. We randomly select chunks from source-tool demonstrations, modify the pose of
the functional-region affordance, and replan the subsequent action sequence so that the modified affordance
pose smoothly returns to the affordance-pose trajectory of the original task demonstration. This process aims
to train the VLA to execute the task by strictly following the current affordance pose and observations of the

When using an unseen tool, the policy can thus use the tool affordances analyzed by the agent to execute the

4.4 Unseen-Tool Adaptation
At deployment, the agent first reconstructs the unseen tool in simulation, then extracts candidate affordance
parameters with its affordance-extraction skills. Using these parameters, it retargets demonstrations for
simulation tests and iteratively refines the parameters from the feedback. The refined parameters are
then encoded as ft using the unified task-level encoding protocol and supplied to the VLA. Following
the backbone’s inference procedure, the VLA conditions on ft and current observation ot, predicts an
action chunk, executes part of it, and receives a new observation before predicting the next chunk. Spatial
components of ft track the robot configuration and tool attachment pose. The agent handles tool analysis and
simulation tests before real-robot execution; the VLA controls the subsequent real-robot actions.
5 Experiments
We assess the reliability and reusability of affordances discovered through autonomous simulation exper-
iments, as well as their effectiveness in supporting real-robot task transfer to unseen tools. We evaluate
our method on three common tool-use tasks. In Pnp Ring, a tool moves a keyring from the left peg to the
rightmost peg; Cut Sand requires slicing through the sand with the tool’s functional edge and placing the cut
portion in the adjacent bowl; and Reset Plate requires retrieving a plate and placing it on the top level.
5.1 Evaluation Setup
For each task, we provide real-robot teleoperated demonstrations using a set of source tools. A disjoint set
of unseen tools is supplied through RGB-D inspection observations, with no manipulation demonstrations.
CAD-assisted simulation baselines additionally receive the geometric inputs specified below. Our agent
starts from the skill library built using source tools. Real-robot evaluation tests both source tools used for
demonstrations (Table 2) and unseen tools (Table 3). For each task and tool set, VLA-based methods use 50
evaluation episodes and Agent-Only direct control uses 20. Each episode samples a tool uniformly from the
corresponding set. Task-specific counts and success criteria are listed in Appendix A (Tables A1 and A2).

simulation-guided testing and refinement of affordance-extraction skills. Compared with other tool-adaptation
methods, our agent more effectively identifies functionally similar regions for precise trajectory retargeting

6 Limitations
Our method is currently limited to tool-transfer problems that can be addressed effectively through retargeting.
Although task-relevant affordance features can be determined autonomously, some forms of tool-skill transfer
in real deployment cannot be solved simply through retargeting. In addition, the VLA may fail to follow
correct affordance guidance, leading to task failure.
7 Conclusion
A2-VLA uses agent reasoning and planning to guide VLA task execution by autonomously determining
task-relevant affordance features. Starting from demonstrations with a small set of source tools, the agent
reconstructs scenes, identifies functional regions and their key geometric features, and continually improves
affordance-extraction skills through simulated retargeting tests. At deployment, the agent uses the validated
skills to extract the affordances of an unseen tool and supplies them as inputs that guide the VLA policy
in completing the task. This enables reliable skill transfer and ultimately improves task success on the real
robot.

C Model Architecture and Training Details
C.1 Single-Token Affordance Conditioning
We retain the π0.5 policy architecture [14], with its Gemma-based transformer backbone, visual encoder,
language encoder, and robot-state projection. The agent supplies the current tool’s encoded functional-region
feature vector ft ∈R12, constructed as described in Appendix B. A learned affordance encoder Eaff projects
this vector into a single affordance feature token zt = Eaff(ft) at the backbone’s context-embedding width.
The complete conditioning prefix is
Xt = [Ximg, Xlang, Xstate, zt],
(C.1)
where the first three groups encode It, ℓ, and qt, respectively. Thus each observation contributes one
affordance feature token alongside the standard multimodal context. Its value is determined by the tool’s
current functional-region features. All twelve feature coordinates are provided to the encoder; an absent
task-specific direction is represented by the zero vector specified in Appendix B.
C.2 Action Expert and Prediction Heads
The action horizon is represented by H noisy action tokens in the action-expert suffix. During each flow-
matching step, the action expert processes these tokens while attending to the conditioning prefix Xt. Let
hτ,h denote its hidden state for action step t + h, where h ∈{0, . . . , H −1}, at flow time τ. Two heads read
these states:
bvh = Dact(hτ,h),
bFt[h] = Daff([Qaff(hτ,h), zt]) .
(C.2)
The action prediction head Dact directly maps each action-step state to a 14-dimensional flow velocity. In
the auxiliary affordance prediction head, a query MLP Qaff maps the same state to an action-step query. An
output MLP Daff fuses this query with the single affordance feature token zt by concatenation and predicts
a 12-dimensional affordance feature vector. The query varies across action steps, while zt supplies the
current tool’s functional-region context throughout the chunk. Stacking these vectors over the horizon gives
bFt ∈RH×12. Both outputs are obtained from the same action-expert forward pass.
C.3 Sequence Supervision and Training
For each source tool, the agent identifies the functional region and develops the task-relevant extraction
skill. We compose the tool’s pose relative to the wrist with the wrist pose from robot forward kinematics,
expressing the functional region in the robot-base frame. The current input ft uses the observed configuration
qt; each subsequent target ft+h+1 uses the configuration commanded by at+h. Stacking these targets gives
Ft ∈RH×12, paired step by step with At ∈RH×14.

The auxiliary objective supervises all twelve coordinates, including zero-valued direction entries. The

C.4 Policy Inference
At each policy update, the current observation, instruction, and affordance feature token form the conditioning
prefix. Starting from Gaussian action noise, the action expert iteratively predicts flow velocities and denoises
the action chunk from τ = 1 to τ = 0. The robot executes part of this chunk before receiving a new
observation and replanning. The auxiliary head produces the corresponding affordance trajectory. Spatial
components of ft are updated from robot kinematics and the tool’s attachment pose, and the encoder produces
the updated feature token for the next control cycle.
