## 摘要
前馈模型通过采用临时设计的注意力机制，对所有视图中的图像块进行密集关联，在三维重建领域取得了巨大成功。然而，这种密集全局注意力的计算成本会随视图数量呈二次增长，因而无法应用于更大规模的重建场景。本文从经典运动恢复结构（structure-from-motion）的视角指出，大多数密集注意力计算并非必要：三维结构源自二维图像中几何匹配的区域。我们通过稀疏几何注意力重建方法（Sparse Geometric Attention Reconstruction，SGAR），将这一原则引入基于学习的前馈重建。在 SGAR 中，每个图像块 token 仅关注来自其他视图的一小组图像块 token；这些 token 由一个轻量级的学习式键选择模块选出，该模块经过训练，可预测 token 在跨视图中的三维邻近关系。因此，SGAR 以效率更高、由几何相似性引导的稀疏注意力取代了密集全局注意力。SGAR 是一种通用方法，可通过微调应用于不同的前馈模型。实验结果表明，在最先进的密集和稀疏方法中，SGAR 速度最快，也是精度最高的稀疏方法。在 1,000 个视图下，其运行速度最高可达密集注意力的 12 倍，同时保持稳定的位姿精度；而现有稀疏方法在此设置下会失效。在相同时间预算下，SGAR 在重建更完整几何结构方面也表现最佳。

## Abstract
Feed-forward models have been very successful in 3D reconstruction with ad hoc attention designs that relate all view patches densely. However, the cost of this dense global attention grows quadratically with the number of views, preventing the model from applying to larger-scale reconstruction settings. In this paper, we argue that most dense attention computations are unnecessary from a classical structure-from-motion perspective: 3D structures stem from geometrically matching regions in 2D. We bring this principle to learning-based feed-forward reconstruction with our Sparse Geometric Attention Reconstruction (SGAR) method. In SGAR, each patch token attends to only a small set of patch tokens from other views, chosen by a lightweight learned key selection module trained to predict cross-view 3D proximity of tokens. Thus, dense global attention is replaced by much more efficient geometric-similarity-guided sparse attention. SGAR is a general method that can be applied to different feed-forward models by fine-tuning. In our experiments, we show that SGAR is the fastest among both state-of-the-art dense and sparse methods and the most accurate sparse one. It runs up to 12-times faster than dense attention at 1,000 views with stable pose accuracy where existing sparse methods fail, and shows the best performance in reconstructing more complete geometries on the same time budget.

# 1. 核心问题与整体含义

- **研究问题**：前馈式多视图三维重建模型（如 VGGT、DejaView）通常让不同视图中的图像块 token 进行稠密全局注意力。这样有助于融合多视图信息，但计算成本随 token 总数近似二次增长，视图数增加时会变得缓慢、占用大量显存，甚至无法运行。
- **研究动机**：经典运动恢复结构（SfM）依靠跨视图几何对应来恢复三维结构。论文据此提出：重建任务中的注意力不必让所有图像块彼此交互，真正有用的往往是观察到相同或邻近三维表面的图像块。
- **整体含义**：SGAR（Sparse Geometric Attention Reconstruction）通过学习跨视图图像块的几何相似性，预测哪些 token 值得彼此关注，再以稀疏注意力替代稠密全局注意力。它不是从头设计一个重建模型，而是通过微调，将这一稀疏机制适配到已有的前馈重建模型中。

# 2. 方法论

## 核心思想

- 将每个图像块 token 映射到一个**几何嵌入空间**：在三维中观察同一表面区域的图像块，其嵌入应彼此接近。
- 根据嵌入对所有图像块聚类，并让每个图像块只与所在簇及少量邻近簇中的图像块进行稠密交互。
- 同时保留少量跨场景信息通道，避免局部稀疏注意力导致全局信息丢失。

## 关键技术流程

1. **生成几何嵌入**  
   对每个图像块 token 使用可学习线性投影 \(W_{\text{adj}}\)，再对嵌入进行去中心化和归一化。两块嵌入的余弦相似度由此用于衡量其几何关联程度。

2. **用几何监督训练嵌入**  
   训练阶段依据真实深度和相机几何确定跨视图对应块：若一个图像块中的像素经三维反投影、再投影到另一视图后，与另一块中的像素位置和深度相符，则认为两块对应。  
   对应块作为正样本，其余候选块作为负样本，使用多正样本 InfoNCE 对比损失，使对应块嵌入靠近、非对应块嵌入远离。该对比损失主要训练 \(W_{\text{adj}}\) 和温度参数；重建损失则训练主干网络。

3. **聚类并选择注意力键**  
   将全部图像块嵌入用球面 k-means 聚为约 \(\sqrt{N}\) 个簇，其中 \(N\) 是图像块 token 数。每个簇选择与自身最相似的 4 个簇（包括自身），一个查询块便可关注这些簇中的图像块。聚类会在每层重新执行，以跟随网络特征变化。

4. **构造稀疏全局注意力**  
   每个图像块的注意力键由四部分构成：
   - 所有视图的特殊 token（相机 token、register token）；
   - 参考视图中的图像块；
   - 自身簇及邻近簇中的图像块；
   - 其他簇的摘要 token。  
   
   特殊 token 仍能密集访问全部 token，以提供全局信息。参考视图块和簇摘要则为局部簇之外的信息提供补充通道。

5. **高效实现**  
   按簇对 token 排序，并将 token 整理为适配 128-token tile 的块稀疏布局，以利用 GPU 注意力内核。论文给出的稀疏全局注意力复杂度约为  
   \(O(N(V+P+\sqrt{N})D)\)，而稠密注意力约为 \(O((VT)^2D)\)。这里 \(V\) 为视图数、\(P\) 为单视图图像块数、\(T\) 为单视图总 token 数、\(D\) 为注意力维度。

6. **适配方式**  
   SGAR 从预训练的稠密注意力模型出发，替换其全局注意力并微调；论文将其应用于 DejaView 和 VGGT-Ω。推理时不需要真实三维几何监督。

# 6. 主要结论与发现

- 稠密注意力中存在显著冗余：论文展示的 oracle 结果表明，只保留少部分几何相关键也能保留大部分位姿精度。
- SGAR 在不同序列长度下均表现出较强的效率优势；在 1,000 视图时，SGAR (DejaView) 达到 AUC@30 **84.6**，而 DejaView 为 **86.5**，但运行时间由 **319.6 秒降至 26.1 秒**。
- 在长序列场景中，其他高效方法有的显著损失精度，有的出现显存不足或运行失败；SGAR 在保持较稳定位姿精度的同时扩展到 1,000 个视图。
- 在相同时间预算下，SGAR 的重建覆盖率最高。例如，1 秒预算下 SGAR (VGGT-Ω) 的 Coverage@5 cm 为 **80.7%**，20 秒时为 **95.9%**。
- 消融结果显示，使用学习到的几何嵌入聚类优于直接对原始 token 聚类；仅选少量高分键也不如对相关簇内图像块进行注意力。参考视图块和簇摘要都能补充跨局部簇的上下文信息。

# 7. 优点

- **切入点明确**：将多视图重建依赖的几何对应关系转化为注意力键选择问题，而不是仅近似原注意力图。
- **方法可迁移**：能通过微调适配不同已有的前馈重建模型，新增参数主要是几何嵌入投影和温度参数。
- **速度与精度兼顾**：在大规模视图设置下显著减少推理时间，同时保持接近稠密模型的位姿表现。
- **稀疏结构适配硬件**：通过聚类共享键集合和块稀疏布局，将稀疏选择组织成适合 GPU 内核处理的计算形式。
- **评估维度较全面**：除固定视图数下的准确度和运行时间外，还评估同等时间预算下能否恢复更完整的几何结构。

# 8. 不足与局限

- **仍有精度损失**：论文承认稀疏化相对稠密模型仍会造成一定准确度下降，相关差距尚未消除。
- **长序列评测较集中**：扩展到 1,000 视图的核心测试主要依赖一个 ScanNet 长场景，尚不足以充分证明对不同场景类型、运动轨迹和视图重叠模式都同样稳健。

- **适用范围仍需验证**：结果聚焦于所测试的前馈式重建模型和数据集；在更极端的视图规模、低重叠输入、动态场景或不同输入分辨率下的表现，仍有待进一步实验。
