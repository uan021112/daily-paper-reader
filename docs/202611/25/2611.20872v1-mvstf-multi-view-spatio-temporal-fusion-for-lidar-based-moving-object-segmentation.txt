MVSTF: Multi-View Spatio-Temporal Fusion for LiDAR-Based
Moving Object Segmentation
Jiaoju Zhou, Chao Ye*, Xuebo Yang, and Weiyang Lin
Abstract—Autonomous mobile robots confront significant chal-
lenges in recognizing the motion properties of objects in dy-
namic environments. However, existing methods are hindered
by limitations such as boundary ambiguity, occlusion, viewpoint
constraints, and training complexity. In this paper, we propose
an innovative end-to-end Multi-View Spatio-Temporal Fusion
network, named MVSTF, which utilizes sequential point clouds to
generate multi-view images and feature differences, and designs
a multi-branch network to extract spatio-temporal and dimen-
sional features in parallel, and realizes high-precision moving
object segmentation. First, sequential point clouds are utilized
to generate multi-view images and feature differences. Then, an
end-to-end multi-branch network including Dual Down-sampling
Blocks (DDB), Spatial Attention Blocks (SAB), Multi-Kernel
Convolutional Neural Network blocks (MKCNN), Dual Feature
Fusion Blocks (DFFB), and the Point Fusion (PF) module, is
designed to extract motion features from feature differences and
geometric and semantic features from multi-view images. Finally,
an auxiliary semantic head is introduced to further improve
the algorithm’s robustness and the model’s interpretability. This
work is validated on the SemanticKITTI and KITTI-Road bench-
marks, achieving state-of-the-art results on the SemanticKITTI-
MOS validation set and the KITTI-Road validation set, and
competitive results on the hidden SemanticKITTI-MOS test set.
The code is available at https://github.com/ZhouJJ111/MVSTF.

Voxel-based methods (e.g., 4DMOS [5], InMOS [6]) discretize
the point cloud into sparse 4D voxels and employ sparse
4D convolutional networks to extract spatiotemporal features
efficiently. These methods offer strong capabilities in modeling
object trajectories and capturing local geometric structures.
However, the voxelization process introduces quantization ar-
tifacts that degrade fine-grained detail representation, and their
computational and memory demands limit scalability in large-
scale dynamic scenes. In contrast, projection-based methods
transform the 3D point cloud into 2D images to leverage
mature image segmentation architectures. Range View (RV)-
based approaches (e.g., LMNet [1], MotionSeg3D [2], RV-
MOS [7]) project the point cloud into depth maps and compute
residuals between consecutive frames to infer motion cues.
Bird’s-Eye View (BEV)-based methods (e.g., MotionBEV [8])
encode planar object motion from a top-down perspective.
Despite their computational efficiency, these methods suffer
from occlusion, geometric distortion, and boundary ambiguity
due to reliance on a single viewpoint. Moreover, they often
require heuristic post-processing steps (e.g., K-Nearest Neigh-
bors (KNN) or Conditional Random Fields (CRF)) to project
2D predictions back to the 3D domain, introducing additional
complexity and uncertainty into the pipeline. Hybrid methods
combine multiple representations, such as point, voxel, or
projection features, to exploit their complementary strengths at
the cost of higher architectural complexity. A detailed survey
of all four categories is provided in Section II.
To address the aforementioned limitations, we propose
MVSTF, a unified framework that integrates multi-view rep-
resentations and temporal modeling to enhance the robustness
and accuracy of MOS. The design of MVSTF is guided
by five core principles: (1) Multi-view complementarity: By
combining spherical and bird’s-eye projections, MVSTF mit-
igates information loss and occlusion caused by single-view
limitations, enabling comprehensive geometric perception; (2)
Multi-representation fusion: A multi-path architecture, com-
posed of a point-based MLP branch and a multi-view CNN
branch, is designed to balance fine-grained geometry with
global semantic context; (3) Explicit motion modeling: Inter-
frame feature differences are computed on BEV representa-
tions to capture structured and robust motion cues along dom-
inant object trajectories; (4) End-to-end optimization: A Point
Fusion (PF) module eliminates reliance on post-processing
steps, enabling a fully differentiable training pipeline with joint
optimization across stages; (5) Auxiliary semantic supervision:
An auxiliary semantic head is incorporated during training
to inject static structural priors into the motion prediction
process, significantly improving generalization in dynamic
and cluttered scenes. Together, these components form a
cohesive and high-performance framework tailored to real-
world complexity. As illustrated in Fig. 1, MVSTF integrates
four complementary representations—raw point cloud, RV,
BEV, and inter-frame feature differences—into a unified per-
ception pipeline. Comparative and ablation studies on the
SemanticKITTI and KITTI-Road benchmarks demonstrate the
effectiveness of this approach. The multi-view representations
and segmentation results of point clouds are shown in Fig. 2.

II. RELATED WORK
Moving Object Segmentation (MOS) has become a key
task in autonomous driving and robotics, aiming to capture
both spatial geometry and temporal motion of dynamic agents.
Unlike semantic segmentation, which focuses on static class


3
labels, MOS emphasizes the temporal evolution of point
states. To address the increasing demand for spatiotemporal
modeling, LiDAR-based MOS methods have evolved from
semantic segmentation architectures by adopting diverse input
representations. Based on the type of input representation,
existing approaches can be broadly categorized into four
groups: point-based, voxel-based, projection-based, and hybrid
methods. Each category reflects a distinct trade-off between
spatial representation fidelity and temporal modeling capacity.
A. Point-based methods
Point-based methods operate directly on raw 3D point
clouds, preserving fine-grained geometric structures without
the quantization loss introduced by voxelization or projection.
Foundational approaches such as PointNet [9] and Point-
Net++ [10] leverage shared multilayer perceptrons (MLPs)
and hierarchical feature aggregation to enable effective point-
level processing. Subsequent methods like KPConv [11] and
PointConv [12] introduce irregular convolutional kernels tai-
lored to the unordered nature of point clouds, while graph-
based models such as GACNet [13] enhance local contex-
tual reasoning through attention mechanisms. For improved
efficiency, lightweight models like RandLA-Net [14] utilize
random sampling and sparse neighborhood construction to
reduce computational cost.
Despite their success in static point cloud segmentation,
point-based methods face two key limitations in dynamic
environments. First, their high computational and memory
costs, combined with inconsistent neighborhood definitions,
hinder their scalability in large-scale or real-time applications.
Second—and more critically—most of these methods are not
equipped with explicit temporal modeling mechanisms, mak-
ing them inadequate for capturing inter-frame motion cues,
which are essential for accurate and robust MOS.
B. Voxel-based methods
Voxel-based methods discretize irregular point clouds into
structured 3D voxel grids, enabling convolutional neural net-
works to efficiently capture spatial structures and semantic
context. In static semantic segmentation, MinkowskiNet [15]
introduces a sparse tensor framework and 4D sparse con-
volutions to model large-scale scenes with high computa-
tional efficiency. SPVCNN [16] further refines voxel-based
operations to reduce overhead while maintaining accuracy,
and Cylinder3D [17] employs cylindrical voxelization with
asymmetric convolutions to adapt to the non-uniform density
patterns of LiDAR data. In the context of MOS, voxel-based
architectures have been extended to capture spatiotemporal dy-
namics. For instance, SpSequenceNet [18] voxelizes sequen-
tial scans and introduces cross-frame global attention (CGA)
and cross-frame local interpolation (CLI) to extract temporal
dependencies. 4DMOS [5] constructs sparse 4D tensors and
applies Bayesian filtering for robust temporal fusion. InMOS
[6] enhances instance-level segmentation by integrating an
instance-awareness module into the voxel backbone.
Despite their structural advantages, voxel-based methods
face two key limitations. First, voxelization inevitably intro-
duces quantization errors, degrading the representation of fine-
grained geometries—especially in sparse or cluttered regions.
Second, voxel granularity poses a critical trade-off: finer reso-
lutions improve spatial fidelity but increase computational cost,
while coarser resolutions enhance efficiency at the expense of
detail. Balancing accuracy, efficiency, and scalability remains
an open challenge for deploying voxel-based MOS in real-
world dynamic environments.
C. Projection-based methods
Projection-based methods transform irregular 3D point
clouds into structured 2D representations—such as RV, BEV,
or cylindrical projections—enabling efficient feature extraction
via convolutional neural networks. These methods are widely
adopted in LiDAR semantic segmentation due to their regular
data structures and computational efficiency. For instance,
LeNet [19] introduces boundary-aware filtering, sparse con-
volutions, and interpolation strategies to enhance segmenta-
tion accuracy and runtime. In the MOS domain, projection-
based methods are extended to capture temporal dynamics.
LMNet [1] encodes inter-frame residuals between current
and historical RV images to infer motion. MotionSeg3D [2]
adopts a dual-branch spatiotemporal architecture with motion-
guided attention and point-wise refinement to reduce ghosting.
RVMOS [7] integrates temporal interval modulation and aug-
mentation strategies to improve robustness. MotionBEV [8]
leverages a polar BEV projection and height-difference-based
motion encoding, augmented with cross-attentional fusion be-
tween appearance and motion features for enhanced dynamic
segmentation.
Despite their efficiency, projection-based methods suffer
from inherent limitations due to their reliance on single view-
points. RV projections are prone to spherical distortion, which
affects near-field object geometry, while BEV projections
struggle with uneven vertical point density and occlusions,
leading to missing spatial context. These issues are especially
critical for MOS, where precise boundary localization and
temporal consistency are essential. To address these lim-
itations, we propose MVSTF, a multi-view spatiotemporal
fusion framework that integrates complementary spherical and
BEV projections. By combining geometric cues from different
perspectives and explicitly modeling inter-frame feature differ-
ences, MVSTF constructs a unified, modular, and temporally-
aware framework for robust motion segmentation in complex
real-world environments.

multi-branch architecture that integrates raw point clouds with
multi-view projection features, and introduces a Sequential In-

branches, fusing point and BEV features to support multi-task

via inter-frame residual features, significantly improving the
temporal consistency and recognition of dynamic objects.
Recent studies have advanced LiDAR scene understanding
through temporal modeling [25], weak supervision [26], and
semi-supervised [27] learning. Point cloud perception has
also been extended to object-level SLAM [28] and category-
level robotic grasping [29]. While these approaches improve
generalization and reduce annotation costs, they often rely on
heuristic designs or limited supervision. In contrast, MVSTF
adopts a fully supervised, end-to-end framework that achieves
a balanced trade-off among accuracy, computational efficiency,
and deployability, making it well-suited for motion segmenta-
tion in complex dynamic environments.
Despite their effectiveness, hybrid methods often suffer
from architectural complexity, high computational cost, and
opaque fusion strategies, which hinder real-world deployment.
To address these issues, MVSTF introduces a multi-branch
framework that fuses point-based and projection-based fea-
tures, with the following three key innovations: (1) Architec-
tural refinement: Inspired by SegNet4D [23], MVSTF adopts
a dual-branch structure that jointly learns semantic categories
and motion states, improving discriminability and general-
ization across diverse environments. (2) Explicit temporal
modeling: Building on insights from Mars3D [24], MVSTF
introduces inter-frame feature differencing in the BEV branch
to capture motion cues along the ground-dominant plane,
improving temporal consistency and motion discrimination.
(3) Dual temporal strategies: MVSTF supports two temporal
modeling modes to accommodate different application needs:
(i) a feature difference-based strategy for high-precision offline
tasks such as HD map generation and trajectory prediction,
and (ii) a height residual-based mode that enables real-time
inference at sensor frame rates, suitable for vehicle-mounted
or edge-computing platforms.
III. OUR APPROACH
As shown in Fig. 3, MVSTF is organized as three parallel
feature branches that encode different representations of the
same point cloud sequence: a point-based branch processes
the raw points with a shared MLP, a BEV branch takes as
input the current BEV image concatenated with the inter-
frame feature differences, and an RV branch takes as input the
current range image. In each projection branch, the encoder
is composed of three building blocks with distinct roles: the
Dual Down-sampling Blocks (DDB) progressively reduce the
spatial resolution while retaining fine-grained details, the Spa-
tial Attention Blocks (SAB) emphasize informative locations
at each scale, and the Multi-Kernel Convolutional Neural
Network blocks (MKCNN) capture multi-scale motion and
appearance patterns. In the decoder, the Dual Feature Fusion
Blocks (DFFB) adaptively fuse features from different layers.
Finally, the Point Fusion (PF) module maps the BEV and RV
features back to the original points and merges them with the
point-based features to produce the final point-wise prediction.
During training, an auxiliary semantic head provides additional
supervision and is removed at inference. Fig. 1(c) presents the
concept-level pipeline of MVSTF, while Fig. 3 provides the
module-level architecture; the multi-view images, the feature
differences, and the auxiliary semantic head in Fig. 1(c)
correspond, respectively, to the projection branches, the BEV
feature difference module, and the auxiliary semantic head in
Fig. 3.
The BEV and RV representations of point clouds could
provide complementary information, effectively addressing the
spatial ambiguities inherent in single-view approaches. Thus,
we employ a multi-view strategy to separately extract motion
and spatial features. To mitigate information loss during the
projection process and address boundary-blurring from back-
projection, we introduce a feature extraction branch for raw
point clouds. This enhancement significantly improves seg-
mentation accuracy, particularly for small objects.
A. Multi-View Feature Encoding
The data preprocessing module processes raw point clouds
using the PointNet [9] network to extract point-level features.
It then combines the BEV feature differences from previous
scans with the current scan’s BEV image, feeding them into
the BEV branch. Simultaneously, the RV image from the
current scan is input to the RV branch. The three-branch
network operates independently. To mitigate the challenges
posed by limited sample size and occlusion of moving objects,
we adopt the SICP strategy for data augmentation.

B. Network Structure
1) Multi-Branch Networks: We adopt a hybrid strategy to
exploit the complementary strengths of diverse point cloud
representations, as shown in Fig. 3. The network consists of
three branches: the point-based branch, the BEV branch, and
the RV branch. For the point-based branch, a three-layer MLP
is utilized to extract features from the raw point clouds. For the
BEV and RV branches, we employ a 2D fully convolutional
neural network to extract motion and appearance features,
respectively. To mitigate boundary artifacts caused by the
back-projection process while preserving the detailed infor-
mation from the raw point clouds, we apply adaptive feature
aggregation from all three branches using the PF module. For
the BEV branch, we construct a (N + 1)C × Hbev × Wbev
tensor by concatenating the BEV image of the current frame
with the feature differences from previous scans, where N
represents the number of previous scans and C denotes the
number of feature channels. In the RV branch, the output of the
point-based branch is transformed into an RV image, forming
a C × Hrv × Wrv tensor.
2) Fully Convolutional Network: The fully convolutional
network is built upon the encoder-decoder framework of
ResNet [30]. For the encoder, we employ the Dual Down-
sampling Block (DDB) to retain fine-grained information

and sizes of objects, along with the challenge posed by the
uneven distribution of point cloud density—complicating the
recognition of distant and small targets—we design a Multi-
Kernel Convolutional Neural Network block (MKCNN). Op-
erating with a stride of 2 and utilizing kernels of varying sizes,
the MKCNN effectively captures a range of motion patterns
and improves segmentation accuracy, especially for distant
and small objects. The MKCNN block is shown in Fig. 4. It
receives the feature maps produced by the preceding encoder

quent fusion stage. While the MKCNN block draws inspiration
from the multi-branch design of the Inception architecture, it
fundamentally differs in both implementation and task align-
ment. First, MKCNN is specifically tailored for dynamic point
cloud segmentation, where data sparsity and long-range target
recognition are critical. To this end, it employs directionally
decomposed convolutions (e.g., 1 × 7 followed by 7 × 1),
which significantly expand the receptive field while reducing
computational overhead. Second, MKCNN integrates a diverse
set of kernel sizes (1×1, 3×3, 5×5, 7×7), enabling multi-scale

context in distant and sparse regions, while smaller kernels
focus on fine-grained details in near-range and dense areas.
Therefore, unlike Inception—which primarily serves image
classification in dense domains—MKCNN is purpose-built for
3D temporal perception, offering both task-specific efficiency
and adaptability to complex dynamic environments.
For the decoder, we employ Dual Feature Fusion Blocks
(DFFB) shown in Fig. 5(b), which concatenate the feature
maps of different layers and adopt an attention mechanism
to adaptively extract motion and appearance features.
3) Point Fusion module: To achieve fine-grained point-level
perception and integrate multi-view features, we design a Point

IV. EXPERIMENTS
A. Experiment Setups
1) Datasets: The SemanticKITTI dataset [1], [31] is col-
lected from a city in Germany using high-resolution and high-
density Velodyne HDL-64E S3 LiDAR sensors. It includes
26 semantic categories, consisting of 6 moving classes, 19
static classes, and 1 outlier class. The dataset comprises 22
sequences, with sequences 00-07 and 09-10 serving as the
training set, sequence 08 as the validation set, and sequences
11-21 used for testing. For the MOS task, all point cloud
categories are remapped into two classes: moving and non-
moving/static. To mitigate the issue of imbalanced data dis-
tribution, we incorporate an additional KITTI-Road dataset
[32], where sequences 30-34 and 40 are used for training,
and sequences 35-39 and 41 are reserved for validation. This
additional training data improves the model’s generalization
across different environments.
To enhance the identification of rare categories, PointPillars
[33] employs an instance copy-paste strategy. Since motion
features are derived from LiDAR sequences, the instance
copy-paste method needs to be adapted from single-frame
to multi-frame contexts. The Sequential Instance Copy-Paste
(SICP) strategy [22] addresses this by considering insertion
positions and ray occlusion, ensuring more accurate feature
augmentation across frames.

The LiDAR data in SemanticKITTI is collected by a Velo-
dyne HDL-64E S2 sensor operating at 10Hz, implying a
100ms interval between consecutive scans. In this context,
we propose two temporal modeling strategies to meet varying
application requirements:
• Feature Difference Strategy (with N = 8) achieves
the highest IoUMOS of 85.60%, but incurs an average
inference time of 238.92ms, exceeding the scan interval.
This makes it suitable for high-precision offline tasks
such as ghost artifact removal in HD map construction.
• Height Residual Strategy reduces the computational
load significantly, achieving 79.09% IoUMOS with an
inference time of only 94.99ms—well within the sen-
sor’s scan cycle—thus enabling real-time deployment on
resource-constrained platforms like in-vehicle or edge
systems.
Based on these observations, we introduce a dual-mode tempo-
ral modeling framework: The feature difference module targets
accuracy-critical offline scenarios. The height residual module
prioritizes real-time efficiency for online perception. This
dual-path design offers a flexible trade-off between accuracy
and efficiency, enabling adaptive deployment across diverse
environments.

F. Applications
To assess the practical benefits of MVSTF for localization
and mapping, we integrate its motion masks into SuMa++
[40] and evaluate the resulting pipeline on KITTI odometry
training sequences 00–10. An offline two-pass pipeline is
adopted, with all methods sharing the baseline-estimated poses
for ego-motion compensation, the backend configuration, and
the semantic predictions.
(1) Odometry/SLAM: As reported in Table VIII, integrating
MVSTF reduces the translational error without loop closure
from 1.3709% to 0.8848%, a relative reduction of 35.46%,
while reducing the rotational error from 0.3411°/100 m to
0.3272°/100 m. With loop closure, the translational error
decreases from 1.3475% to 0.9841%, corresponding to a
relative reduction of 26.97%. These results demonstrate that
MVSTF-based motion filtering further improves translational
accuracy beyond the existing semantic constraints.
(2) 3D Mapping: All methods accumulate observations
within a range of 2–75 m into 0.2 m voxel maps using
the same baseline-estimated poses. As shown in Table IX,
MVSTF achieves a dynamic-point removal rate of 95.17%
and a static-point retention rate of 99.9941%, both the highest
among the evaluated learning-based methods. Its dynamic-
voxel residual rate is only 4.02%, representing relative re-
ductions of 57.72% and 68.14% compared with LMNet and
MotionBEV, respectively, while retaining 99.9743% of the
static-only reference voxels. Fig. 11 further illustrates these
benefits. MVSTF achieves dynamic-voxel residual rates of
5.31% and 9.11% in the two local regions, respectively, outper-
forming both comparison methods. The enlarged views show
reduced motion-trail artifacts in road regions while preserving
the surrounding static structures. Together, the quantitative
and visual results demonstrate a favorable balance between
dynamic-observation removal and static-structure preservation.
V. CONCLUSION
To address the challenges of boundary-blurring, artifacts,
single-view limitations, and training complexity commonly
encountered in existing LiDAR-based MOS methods, we pro-
pose a novel and effective end-to-end high-precision segmen-
tation framework, MVSTF. First, the sequential point cloud
data is preprocessed to generate RV images, BEV images,
and BEV feature differences. A three-branch framework is
then employed to effectively integrate spatio-temporal features
and channel information from multiple views. The projection
branch utilizes an encoder-decoder architecture, incorporating
Dual Down-sampling Blocks (DDB), Spatial Attention Blocks
(SAB), Multi-Kernel Convolutional Neural Network blocks
(MKCNN), and Dual Feature Fusion Blocks (DFFB). An end-
to-end framework is established using the point-based branch
and the point fusion (PF) module. The auxiliary semantic
head is introduced to improve the model’s interpretability
and robustness. Comparative experiments and ablation studies
on the SemanticKITTI and KITTI-Road datasets validate the
effectiveness of the proposed method, which achieves state-of-
the-art results on the SemanticKITTI-MOS validation set and
the KITTI-Road validation set while remaining competitive on
the hidden SemanticKITTI-MOS test set.
Future work will focus on two main directions. First, we
aim to extend MVSTF’s multi-sensor fusion capability by
incorporating semantic and texture information from cameras,
enhancing its perception of fine-grained semantics and motion
boundaries. Second, we seek to improve system robustness
and adaptability in real-world scenarios, including sensor
degradation, adverse weather, and dynamic environments. Ad-
ditionally, we will explore model compression and lightweight
design to enable efficient deployment on edge platforms.
