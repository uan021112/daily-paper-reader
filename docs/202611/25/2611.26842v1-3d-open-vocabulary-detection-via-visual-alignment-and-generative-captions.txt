3D Open-Vocabulary Detection via
Visual Alignment and Generative Captions
Thomas E. Huang, Alex Zihao Zhu, Hao Xiang, Tianyi Cai, Jingwei Ji,
Yuliang Zou, Jiafan Yu, Xin Huang, and Mingxing Tan
Waymo
Abstract— Open-vocabulary 3D object detection remains a
significant challenge for outdoor scenes, with existing methods
often struggling to effectively transfer the rich semantic
knowledge from powerful 2D Vision-Language Models (VLMs)
into a 3D context. We propose a novel, two-part framework for
this task. First, we introduce a direct, object-level distillation
method. We generate class-agnostic 3D proposals to source
regions from the entire scene, without relying on any manual
labels. We leverage a spatially-aware VLM to extract a semantic
embedding from each proposal’s projected 2D bounding box
and supervise our 3D model to predict this embedding on a per-
instance basis. Second, to enhance zero-shot capability and inject
domain-specific information, we employ a powerful Multimodal
Large Language Model (MLLM) as an image captioner to
generate rich textual captions for each of these proposals. These
captions are integrated into the training objective to directly
align the 3D features with these rich semantics, creating a
composite loss that combines direct feature distillation with
caption-based semantic enrichment. Our experiments validate
the effectiveness of our approach, establishing a new state of
the art in 3D open-vocabulary detection on the Waymo Open
Dataset and nuScenes.
I. INTRODUCTION
Accurate 3D object detection is foundational for safety-
critical applications like autonomous driving. Current state-of-
the-art 3D detectors, which rely on LiDAR point clouds [1],
[2] and multi-view images [3], [4], have achieved remarkable
performance on challenging benchmarks [5], [6]. However,
these methods are fundamentally limited: they can only
identify and localize objects that belong to a pre-defined set
of categories seen during training. In real-world environments,
systems constantly encounter novel objects and long-tail
concepts, rendering closed-set detectors unreliable. When
a closed-set detector fails to identify a novel obstacle such as
debris or an unconventional vehicle, it poses a direct threat to
downstream motion planning and collision avoidance systems.
The emerging field of open-vocabulary 3D object detection
addresses this limitation by aiming to detect arbitrary objects
described by natural language. To achieve this open-set
capability, prevailing approaches typically rely on knowledge
distillation from large-scale pre-trained 2D Vision-Language
Models (VLMs) [7]. These methods transfer the VLM’s rich
semantic features to the 3D detector, either by projecting 2D
features to 3D points/voxels for alignment [8], or by using
2D open-vocabulary detections [9], [10] as pseudo-labels for
3D localization [11], [12]. This enables the 3D model to
predict an embedding vector that can be compared against

The primary challenge in this domain is bridging the
knowledge gap between the feature-rich 2D domain, where
vast Vision-Language Models (VLMs) like CLIP [7] have
acquired broad open-world knowledge, and the sparse, 3D
domain. Directly aligning sparse, unorganized, 3D features
with dense, pre-trained 2D image features is notoriously noisy.
Additionally, the 2D VLMs are pre-trained on web-scale
data, which are general, but may create significant domain
gaps when applied to specific domains. 3D autonomous
driving environments are often cluttered, occluded, and have
highly varied-perspective views. Relying solely on this visual-
only alignment is insufficient; the 2D visual features are
often semantically ambiguous and lack the granularity to
distinguish between fine-grained categories (e.g., ‘trailer’ vs.
‘truck’). This forces the 3D model to learn a similarly coarse
representation, limiting its generalization.
In this work, we introduce a novel, end-to-end framework
that effectively transfers and grounds open-world semantic
knowledge to a 3D detector. First, our Visual Alignment
stage (Section III-B) creates a robust visual foundation. To
overcome the noise and sparsity of 3D-to-2D projection, we
distill knowledge in an object-centric manner. We first gener-

ate class-agnostic 3D box proposals using DBSCAN [13] on
the raw point cloud, allowing us to source distillation targets
from all regions of the scene, including background and
potential novel objects, without relying on any ground-truth
labels or prior knowledge. We aggregate 2D VLM features at
the object level and use this stable visual signal to supervise
the underlying 3D voxel features. This efficiently distills the
VLM’s rich visual knowledge into the 3D backbone, creating
a feature space that is visually discriminative.
While this VLM distillation provides general open-world
knowledge, the original image embeddings are pre-trained to
cover a broad range of captions, and may miss domain specific
context. To this end, we propose a second Language Align-
ment stage (Section III-C) which complements this visual-
alignment and instills fine-grained semantic understanding.
We leverage a powerful Multimodal Large Language Model
(MLLM) as an image captioner and domain adapter. Using
the same DBSCAN-generated 3D regions, we generate high-
fidelity, descriptive captions directly from the 3D dataset’s
image patches. These captions are then embedded into the
VLM embedding space with the VLM text encoder. By
aligning the visually-grounded 3D features (from Stage 1)
to these domain-specific text embeddings, we overcome the
semantic ambiguity of 2D visual features and explicitly force
it to learn the nuanced semantics of the 3D environment (e.g.,
“a white sedan stopped in traffic”). In short, our loss combines
the breadth of pre-trained image embedding distillation with
the depth of per-object caption embedding distillation.
Our contributions are summarized as follows:
1) We introduce a Visual Alignment strategy that uses
class-agnostic proposals to distill object-level 2D VLM
features into their corresponding 3D voxels, enabling
robust feature learning from the entire scene without
manual labels.
2) We propose a Language Alignment strategy that uses
an MLLM to generate high-fidelity, contextual text
captions for these same scene regions, grounding the
3D features in rich, descriptive language.
3) We achieve state-of-the-art results for open-vocabulary
3D object detection on the challenging Waymo Open
Dataset and nuScenes benchmarks.
II. RELATED WORK
A. 3D Closed-Vocabulary Object Detection
Mainstream 3D object detectors can be broadly categorized
by their data representation. Early works [14], [15] operated
directly on raw point clouds, but were often computationally
expensive. The dominant paradigm shifted to voxel-based
methods [16], [17], which discretize the scene into a regular
grid, enabling efficient 3D sparse convolutions. This was
further refined by hybrid point-voxel architectures [18] and
efficient anchor-free heads like CenterPoint [19]. More
recently, Transformer-based detectors [20], [21], [2], [1], [4],
[3] have achieved state-of-the-art performance. Despite their
high accuracy, these methods are fundamentally ”closed-set”:
they are trained with a fixed vocabulary (e.g., car, pedestrian)
and cannot detect any object outside this pre-defined list.
B. Vision-Language Modeling
The dominant paradigm in training Vision-Language Mod-
els (VLMs) has been contrastive learning on web-scale image-
text pairs, pioneered by CLIP [7] and ALIGN [22]. These
models learn a joint embedding space, enabling powerful
zero-shot image-level classification. However, this image-
level supervision limits their spatial granularity, making
them suboptimal for dense prediction tasks like detection.
Subsequent works have focused on adapting these models
for region-level understanding, either by fine-tuning on
detection data [23], [24], creating dense feature maps [25], or
incorporating self-supervised objectives for spatial awareness,
such as TIPS [26]. A separate and parallel class of models,
Multimodal Large Language Models (MLLMs), has emerged
by connecting vision encoders to Large Language Models
(LLMs) [27], [28], [29]. These models excel at complex
reasoning and generative tasks like captioning.
C. Open-Vocabulary Object Detection
Open-vocabulary detection was first popularized in 2D.
Early methods [30] focused on distilling knowledge from
a VLM like CLIP [7] into a region-based detector [31] by
aligning region-of-interest (RoI) features with the VLM’s text
embeddings. More recent approaches have developed end-to-
end transformer frameworks [32] or improved performance
by pre-training on large-scale grounded image-text data [23],
[10]. Extending this to 3D introduces the significant challenge
of bridging the 2D-3D modality gap. One line of work
applies 2D open-vocabulary models to multi-view images
and “lifts” the resulting 2D boxes into 3D space [11], [12],
[33], [34]. However, the open vocabulary needs to be known
before training, and extension to new categories require data
regeneration and retraining. A more direct approach aligns
3D features directly with the VLM’s embedding space. This
is often done by projecting entire 3D point clouds into 2D
views [35], [36], [37] or by distilling 2D VLM features into
3D point or voxel features [8], [38]. Our work follows this
latter distillation-based approach.

In 3D open-vocabulary object detection, the detector is
tasked with predicting objects from an “open” vocabulary,
including categories unseen during training. Standard classi-
fication does not work in this setting. Typically, language is
used as an intermediary [32], [10], and the detector predicts
an open-vocabulary embedding for each object, rather than the
standard classification objective. This enables classification
through comparison against arbitrary text queries during
inference, thereby generalizing to unseen categories.
B. Visual Alignment
The first component of our method focuses on establishing
a visual-semantic link between the 3D features and the rich,
pre-trained knowledge embedded in a VLM. We aim to
directly distill such knowledge into the 3D features to enable
open-vocabulary classification directly in 3D.
3D Feature Extraction. Our alignment framework is de-
signed to be agnostic to the 3D backbone. For our experiments,
we build upon a Transformer-based point cloud detector,
SWFormer [21]. Given an input point cloud, SWFormer first
applies voxelization and then uses a series of sparse window
Transformer blocks for feature processing and multi-scale
feature fusion to produce voxel features F3D ∈RNv×D.
Generic Objects Extraction. A primary challenge in aligning
3D features with 2D VLM features is establishing a robust
correspondence. The most direct approach is to perform point-
to-pixel alignment [8]. This is achieved by projecting each
3D point pi onto the 2D image plane using the given extrinsic
Rl and intrinsic Kl camera parameters:

However, this point-to-pixel strategy is quite brittle, especially
for outdoor scenes. A 3D point can be easily assigned an
incorrect 2D semantic feature due to minor calibration errors
or small occlusions (e.g., a pole in front of a vehicle), which
in turn introduces noise into the training signal.
To mitigate the noise inherent in point-to-pixel alignment,
we adopt an object-centric distillation strategy without relying
on manual labels. We deviate, however, from the standard
practice of lifting 2D detection boxes [11], [12], which neces-
sitate a fixed list of categories during training for prompting
the 2D detectors and limits true open-vocabulary generaliza-
tion. Instead, we treat object discovery as a geometric problem
rather than a semantic one. We employ RANSAC [39] to
separate the ground plane and DBSCAN [13] to cluster the
remaining points into distinct entities. This strategy generates
a comprehensive set of class-agnostic 3D proposals covering
the entire scene. For each 3D proposal b′

Projecting all 3D geometric proposals to 2D indiscrimi-
nately can still generate low-quality pairs. This introduces
noise, for example, by forcing the model to align a 3D object
with a 2D crop of its occluder. To ensure high-fidelity 2D-3D
correspondence, we apply a rigorous filtering process. First,
we perform view frustum and depth filtering. We discard
any 2D projected boxes that are fully outside the image
bounds, are too small or large, or whose corresponding 3D
box is closer than 5m or further than 50m. Second, we
perform occlusion filtering to resolve ambiguity in the camera
perspective. We calculate the Intersection over Area (IoA)
for overlapping boxes and remove any box that has a high
IoA with another box and is further away from the camera,
as it is presumed to be occluded.

requires a VLM that can produce spatially-aware, high-
resolution feature maps. Standard VLMs like CLIP [7] are
not ideal for this, as they are trained for image-level tasks
with a global image-text alignment objective. Consequently,
prior works [40] using CLIP must rely on an inefficient
process: running separate forward passes on individual image
crops to extract visual features for each object. This approach,
however, is context-poor, as it discards all surrounding scene

C. Language Alignment
While visual alignment transfers visual knowledge from
pre-trained VLMs, the VLM image encoder is trained on
a large corpus of image-text pairs, and so the image-text
similarity may not be sufficiently discriminative for any given
text prompt. Additionally, the image embeddings suffer from
visual ambiguity (e.g., distinguishing a truck from a semi-
truck solely by its 2D patch) and the limited textual diversity
of standard class labels. To overcome this and instill a
richer semantic understanding, our second component focuses
on bridging this vision-language gap through leveraging
contextually-rich language generated by a Multimodal Large
Language Model (MLLM) image captioner. We posit that
aligning to MLLM-generated captions, which are rich in
contextual and descriptive attributes (e.g., ‘a white sedan
stopped in traffic’), forces the 3D model to learn a more
nuanced semantic space than aligning to the fixed, iconic
visual concepts learned by the VLM (e.g., a general ‘car’).

D. Model Details
We provide additional details regarding our model.
Localization. Following [21], we utilize a CenterNet detection
head for regressing 3D bounding boxes from voxel features.
Since we do not have access to a pre-defined vocabulary
during training, we use a single detection head for all objects,
and we modify the classification branch to output a binary
foreground/background prediction rather than classify into
object classes. As 3D localization training requires precise
bounding boxes, this component is trained with a separate
set of standard, amodal 3D boxes for supervision, rather than
the DBSCAN boxes used for alignment.
Training. We train our detector in an end-to-end manner by
jointly optimizing all objectives:
Ltotal = Ldet +λvisLvis +λlangLlang,
(5)
where Ldet is the standard loss for the CenterNet detection
head, including heatmap, size, and offset regression losses,
and λvis and λlang are used to weight the alignment losses.
Our method does not require images during inference
time, and the proposed alignment components are only used
during training. Thus, the only additional computation are
the lightweight open-vocabulary embedding heads, which are
a tiny fraction of the overall detector.
Inference. To classify objects into open-vocabulary categories,
we rely on the open-vocabulary embeddings from the model.
During inference, we take textual descriptions of categories
of interest Tc and encode them using the VLM text encoder
ET(Tc) = ec. These descriptions can be any free-form text
(Fig. 6). Then, we simply compute the cosine similarity
between the predicted and the provided text embeddings and
assign the label with the highest score.
IV. EXPERIMENTS
A. Experimental Setup
Dataset. We conduct experiments on the Waymo Open
Dataset (WOD) [5] and nuScenes [6]. WOD includes 1000
sequences, split into 798 for training and 202 for validation.
The dataset uses five cameras, covering a 270-degree view
around the vehicle. WOD contains annotations for three object
categories: vehicle, pedestrian, and cyclist. The nuScenes
dataset contains 1000 driving sequences, split into 700 for
training, 150 for validation, and 150 for testing. Each sequence
is 20 seconds in length and annotated at 2Hz. It also has
images taken from six cameras, covering 360-degrees around
the vehicle. nuScenes provides annotations for ten object
categories for the detection task.
Evaluation Settings. The core contribution of our work is the
open-vocabulary alignment pipeline, which is agnostic to the
underlying 3D localization method. To isolate the performance
of our alignment strategy, we conduct experiments using
boxes that are available to us, including unsupervised, amodal
pseudo-labels from [33] on WOD and ground-truth (GT)
boxes (no class labels) on nuScenes. These boxes are used
to supervise our class-agnostic detection branch.
For WOD, we follow existing open-vocabulary proto-
cols [42], [33] and evaluate zero-shot 3D detection per-
formance without utilizing any GT labels. We report 3D
and BEV Average Precision (AP) at an IoU threshold of
0.4 and difficulty level 2 (all objects). We use two range
settings: the standard range (100m × 40m around the ego-
vehicle) and the extended range (160m x 160m). As [33] and
[42] use slightly different evaluation protocols, we compare
with each separately. We compare with methods that support
open-vocabulary inference (ViLGOD [42], UP-VL [33]) and
unsupervised detection methods with GT label assignment
(OYSTER [44], LISO [45]).

results were skewed by the performance of the box generation

B. Main Results
In this section, we present the main results of our method.
For the class-agnostic baseline, we use the same class-agnostic
detector as our method to generate boxes, but assign class
labels of all classes to each box.
Waymo Open Dataset. The results on the WOD dataset are
shown in Table I and Table II. Compared with ViLGOD [42],
our method obtains competitive performance on vehicles
and pedestrians but significantly better results on cyclists,
resulting in an overall 3D mAP improvement of 9.4 points.
Previous methods perform worse for cyclists due to rarity and
similarity to pedestrians, while our detector can successfully
detect them with high accuracy. In addition, we demonstrate
our method’s generalization to long ranges by evaluating on
the extended range setting from ViLGOD [42]. Our method
achieves an mAP of 31.1, significantly outperforming the
ViLGOD by 11.8 points. Notably, we see massive gains in
detecting vulnerable road users (VRUs), with Cyclist AP
improving from 4.6 to 27.7 (+23.1).
Compared to UP-VL [33], our method achieves large
performance gains across both vehicles and VRUs, improving
overall mAP by 8.7 points. As we use the same auto labels,
this demonstrate that our distillation strategy is more effective
in transferring world knowledge to the 3D detector compared
to the point-to-pixel strategy employed in UP-VL.
nuScenes. The results on the nuScenes dataset are presented
in Table III. OpenSight [11] relies on Grounding DINO [10]
for open-vocabulary classification by providing the 2D
detector with prompts of class names both during training
for feature alignment and inference for feature integration.
This results in limited generalization to truly novel classes
where the names are not known beforehand. Our method
does not have such a limitation. Despite this, our method
achieves 36.9 mAP, a 2.7 points improvement over OpenSight,
demonstrating the effectiveness of our alignment protocol.

Component Analysis. We first analyze the impact of our two
proposed alignment stages in Table IV. Without any alignment,
the detector is unable to classify objects, achieving a low
mAP of 6.0. Using only Visual Alignment yields a strong

V. CONCLUSION
In this work, we presented a novel 3D open-vocabulary
framework that learns robust, open-world representations
by aligning 3D features to both spatially-aware VLMs and


generative MLLM captions. We use class-agnostic geometric
clustering to source proposals directly from the point cloud
and a dual-stream multi-modal distillation framework to align
these proposals with the VLM features. Our experiments
demonstrate state-of-the-art open-vocabulary detection perfor-
mance on the Waymo Open Dataset and nuScenes, validating
that our approach can better align 3D geometry with 2D
large-scale pre-trained models.
