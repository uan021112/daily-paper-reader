## 摘要
同时重建和理解3D环境对于具身智能体至关重要。为实现这一目标，前馈语义3D高斯泼溅（3DGS）从稀疏多视角观测中高效构建语义场景表示。然而，现有方法缺乏显式的实例判别，主要支持基于类别或短语的语义查询。为此，我们提出GroupForward，一种实例分组的前馈高斯泼溅模型，能够从稀疏、无位姿且未标定的多视角图像中重建几何、外观、实例结构和语义。与现有方法将高维语义特征附加到每个高斯上不同，GroupForward学习紧凑的实例嵌入，将高斯分组为跨视角一致的3D实例，将前馈语义3DGS从逐高斯语义特征渲染转化为实例级语义聚合与传播。基于这些实例组，我们进一步提出指涉场景推理框架（RSRF），用于复杂的3D指涉分割。RSRF构建实例分组的3D场景图，并为给定的指涉表达式检索候选实例。随后，视觉语言模型对结构化的实例证据和多视角观测进行推理，以在候选中识别被指涉的实例。因此，RSRF将语言交互从简单的语义查询扩展到复杂的指涉场景推理。在语义重建和指涉推理上的实验证明了我们实例分组重建与推理框架的有效性。

## Abstract
Simultaneously reconstructing and understanding 3D environments is essential for embodied agents. Toward this goal, feed-forward semantic 3D Gaussian Splatting (3DGS) efficiently constructs semantic scene representations from sparse multi-view observations. However, existing methods lack explicit instance discrimination and mainly support category- or phrase-based semantic queries. To this end, we propose GroupForward, an instance-grouped feed-forward Gaussian splatting model that reconstructs geometry, appearance, instance structure, and semantics from sparse, unposed, and uncalibrated multi-view images. Unlike existing methods that attach high-dimensional semantic features to each Gaussian, GroupForward learns compact instance embeddings that group Gaussians into cross-view consistent 3D instances, reformulating feed-forward semantic 3DGS from per-Gaussian semantic feature rendering to instance-level semantic aggregation and propagation. Building on these instance groups, we further propose a Referential Scene Reasoning Framework (RSRF) for complex 3D referring segmentation. RSRF constructs an instance-grouped 3D scene graph and retrieves candidate instances for a given referring expression. A vision-language model then reasons over structured instance evidence and multi-view observations to identify the referred instance among the candidates. RSRF thereby extends language interaction from simple semantic querying to complex referential scene reasoning. Experiments on semantic reconstruction and referential reasoning demonstrate the effectiveness of our instance-grouped reconstruction and reasoning framework.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：具身智能体在真实3D环境中需要同时完成场景重建与场景理解，以便进行感知、规划与交互。3D高斯泼溅（3DGS）因其高效渲染、显式表示和易于附加语义属性的特点，已被广泛用于语义3D场景重建。
- **痛点一：缺乏显式实例区分**。现有前馈语义3DGS方法（如LSM、Uni3R）将高维语言对齐特征附加到每个高斯上，能够支持语义查询，但无法将高斯显式分组为物体实例，难以区分同一类别下的多个实例，且无法保持跨视角的身份一致性。
- **痛点二：语言交互能力有限**。现有方法仅支持类别级或短语级查询（如"椅子""门"），但真实语言指令常常是复杂的指涉表达式（如"靠近柜子的垃圾桶""我想坐在门附近"），需要对象身份、空间关系、功能属性、上下文信息的联合推理。
- **核心含义**：论文提出以"实例"作为桥梁实体，将前馈语义3DGS从逐高斯的语义特征渲染范式转变为实例级语义聚合与传播范式，并将语言交互从简单语义查询扩展到复杂指涉场景推理，从而构建"可指涉的3D场景"（referable 3D scenes）。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体架构
方法由两部分组成：**GroupForward**（实例分组的前馈3D重建）和**RSRF**（指涉场景推理框架）。核心思想是将**持久的3D实例组**作为中间实体，连接低层高斯重建与高层语言推理。

### 2.2 GroupForward：实例分组的前馈高斯泼溅

- **输入输出**：输入稀疏、无位姿、未标定的多视角图像，输出带紧凑实例嵌入的高斯图元，并通过聚类得到跨视角一致的3D实例组。
- **高斯图元表示**：每个像素被提升为一个高斯图元 `G_{i,p} = {μ, α, s, q, c, e}`，其中 `e` 为新增的紧凑实例嵌入，维度 `d_e = 8`，远低于典型语义特征维度（如LSeg的512维）。
- **网络结构**：共享多视图编码器 + 两个解码器：
  - 几何解码器：相机位姿头 + 深度头；
  - 高斯解码器：属性头（标准高斯属性）+ 实例头（紧凑实例嵌入）。
- **尺度对齐自渲染（Gauge-Aligned Self-Rendering）**：为避免仅依赖真值相机位姿监督而忽视预测位姿与重建场景的一致性，方法额外执行一次基于预测位姿的"停止梯度"位姿推理，并通过共享上下文视图计算尺度对齐因子γ，将联合预测位姿对齐到上下文位姿尺度后，用上下文构建的高斯场景在预测位姿下渲染新视图进行光度监督。

- **渲染一致的实例学习（Rendering-Consistent Instance Learning）**：
  - 直接损失：在上下文视图嵌入空间中，计算每个实例的ℓ2归一化质心，通过pull（拉近嵌入到质心）和push（推开不同质心间距至边缘m）损失进行监督；
  - 渲染损失：将每个高斯对实例k的分配概率（softmax over负距离）临时作为可渲染属性，光栅化到上下文/目标视图，用dice损失+focal损失与真值实例掩码对齐；同时对渲染后的嵌入施加pull/push损失，确保3D空间的实例一致性。
- **语义聚合与传播**：推理时用HDBSCAN聚类所有上下文视图的实例嵌入得到3D实例组，从冻结的2D开放词汇模型（默认LSeg）提取语义特征，在每个实例组内通过掩码加权池化得到语义原型。目标视图语义通过渲染实例分区权重与原型组合传播得到——高维语义特征每个实例只存一份，而非每个高斯存一份。

- **三阶段课程训练**：
  1. Stage 1：冻结实例头，训练编码器、几何解码器、高斯解码器，优化重建损失（ℓ1+SSIM+LPIPS+位姿/深度/点图/法线监督）；
  2. Stage 2：冻结其他部分，仅训练实例头，优化实例损失；
  3. Stage 3：全模型联合微调。
  - 无真值实例标签时：先用SAM2逐视图提取掩码，再利用Stage 1学到的几何与相机将掩码跨视图投影、丢弃几何不一致对应、按投影重叠度关联身份，生成伪标签。

### 2.3 RSRF：指涉场景推理框架

- **3D场景图构建**：每个实例组为一个节点，节点属性包含语义原型、3D中心/空间范围/体积、2D投影几何与可见性；有序边编码空间关系（3D距离、相对高度、大小比例、2D投影关系）。
- **候选实例检索**：将指涉表达式解析为目标概念、目标基数、锚定实例、空间关系、视觉属性；综合语义相关性、几何相关性、跨视角可见性打分，保留Top-K节点（K=8）供VLM推理，缩小推理空间。
- **VLM推理**：为每个候选节点构建证据包（语义/几何属性、邻接关系、跨视角观察、全局概览、高亮掩码、物体裁剪、局部上下文），Qwen3-VL-8B-Instruct在闭集选择中选择目标实例；由于节点保留了与各视角掩码的显式对应，所选实例可直接映射为跨视角一致的3D分割结果，无需额外掩码预测。

## 6. 主要结论与发现

- **实例分组优于逐高斯语义特征渲染**：在ScanNet两视图基准上，GroupForward以mIoU 0.5905（源视图）和0.5989（新视图）全面超越LSM、Uni3R等现有方法，同时PSNR 26.23、SSIM 0.8948、LPIPS 0.1230在几何与外观上也最优；消融显示移除实例嵌入改用逐高斯高维语义特征渲染后mIoU大幅下降（0.5989→0.5479），验证了实例级表示的有效性。
- **渲染一致的实例学习至关重要**：去掉渲染级实例损失（L_render）后mIoU下降约2.2个百分点，说明仅依赖上下文空间对比不足以保证3D一致性。
- **尺度对齐自渲染改善位姿-场景一致性**：移除自渲染后外观指标全面下降，而语义指标仅微降，表明该模块主要贡献于重建质量。
- **三阶段课程训练是稳定训练的关键**：跳过课程训练直接联合优化会导致灾难性退化（mIoU 0.4669、PSNR 18.92），表明实例学习对几何和相机质量高度依赖。
- **伪标签泛化可行**：使用VGGT预测几何或SAM2伪掩码替代真值监督时，性能仅适度下降且仍优于基线方法，降低了对标注的依赖。
- **RSRF实现复杂指涉推理**：在指涉分割中达到mIoU 0.6496，远超Uni3R（0.2538）和Sa2VA（0.5012），支持复杂表达式、跨视角一致性和原生3D输出。

## 7. 优点

- **范式创新**：将前馈语义3DGS从"逐高斯高维特征"重定义为"实例级语义聚合与传播"，用低维嵌入（8维）代替高维语义特征（512维），在计算效率和语义质量上双赢。
- **显式实例结构**：紧凑实例嵌入 + 渲染一致性学习 + 推理时密度聚类，直接获得跨视角一致的3D实例组，可区分同类别多实例。
- **语言交互能力跃升**：RSRF构造实例分组3D场景图，将VLM推理引入前馈重建管线，把指涉分割转化为闭集选择问题，从类别/短语查询扩展到复杂指涉推理，且天然支持3D输出。
- **实用性与通用性**：支持无位姿、无标定、稀疏多视图输入；支持任意数量输入视图；不依赖GT标签也可训练（SAM2伪标签+VGGT几何）；与不同2D语义模型兼容。
- **工程稳健**：三阶段课程训练策略合理，既稳定了重建，又防止实例学习阶段的优化崩溃。

## 8. 不足与局限

- **依赖2D语义模型质量**：语义原型从冻结LSeg特征池化得到，语义表现直接受限于2D语义模型；论文实验也表明换用OpenSeg或CLIP后性能显著下降（mIoU分别降至0.4536和0.1630）。
- **实例监督依赖问题**：虽然有SAM2伪标签方案，但消融显示伪标签仍带来性能损失（mIoU -2.5~-3.4），且SAM2本身对复杂场景可能产生不稳定掩码。
- **实验覆盖范围有限**：
  - 仅在ScanNet上训练、Replica上泛化，均为室内场景，未验证户外、动态或大尺度场景；
  - 指涉推理评测规模较小，表达式类型和难度覆盖有限；
  - 缺少嵌入维度、温度、K值等超参数的敏感性研究。
- **训练成本较高**：8×A100（80GB）上约30小时/两视图模型，加上多视图阶段共约60小时，实验成本不低，实际部署前馈推理虽快，但训练门槛较高。
- **VLM推理的潜在瓶颈**：Top-K=8候选的限制可能漏掉正确的目标实例；上下文窗口与证据包的组织方式尚未做系统性分析；VLM可能在新场景或长尾语义上有幻觉风险，论文未做错误分析。
