## 摘要
高保真三维生成建模日益依赖于潜在扩散范式，其中底层三维VAE的重建质量成为主要瓶颈。现有方法主要遵循两种范式：基于稀疏体素的表示能够实现强大的重建质量，但会带来显著的内存和计算开销；而基于集合的表示则紧凑且连续，但由于潜在稀疏性和过度的全局平滑性，其在保真度上通常有所欠缺。我们提出了MSVS-VAE，一种分层基于集合的VAE，在不牺牲紧凑性的前提下弥合了这一保真度差距。我们的关键思想是通过分层点洗牌上采样逐步致密化锚定VecSet潜变量，从而增加细粒度几何建模的空间容量。为了高效地从致密化的层次结构中解码，我们用AVS-Conv（一种在局部邻域内而非整个潜在集合中进行操作的几何感知局部聚合算子）替代全局交叉注意力。我们进一步引入多尺度查询解码来融合从粗到细的潜在特征，其中粗尺度提供稳定的全局上下文，而细尺度细化局部几何，减少过局部感受野带来的伪影。在Objaverse、ABO和野外基准上的大量实验表明，MSVS-VAE始终优于先前的基于集合和基于体素的VAE，其解码速度比先前基于集合的方法快约10倍，比基于体素的基线紧凑性高约10倍。

## Abstract
High-fidelity 3D generative modeling increasingly relies on the latent diffusion paradigm, where the reconstruction quality of the underlying 3D VAE becomes a primary bottleneck. Existing approaches largely follow two paradigms: sparse voxel-based representations achieve strong reconstruction quality but incur significant memory and computational overhead, while set-based representations are compact and continuous yet typically lag in fidelity due to latent sparsity and excessive global smoothness. We propose MSVS-VAE, a hierarchical set-based VAE that closes this fidelity gap without sacrificing compactness. Our key idea is to progressively densify anchored VecSet latents via hierarchical point-shuffle upsampling, increasing spatial capacity for fine-grained geometry modeling. To efficiently decode from the densified hierarchy, we replace global cross-attention with AVS-Conv, a geometry-aware local aggregation operator operating within local neighborhoods rather than the exhaustive latent set. We further introduce multi-scale query decoding to fuse coarse-to-fine latent features, where coarse scales provide stable global context, and fine scales refine localized geometry, reducing artifacts from overly local receptive fields. Extensive experiments on Objaverse, ABO, and in-the-wild benchmarks demonstrate that MSVS-VAE consistently outperforms prior set-based and voxel-based VAEs, delivering approximately 10x faster decoding than prior set-based methods and approximately 10x higher compactness than voxel-based baselines.

- **现有范式的不足**：
  - **稀疏体素（voxel-based）方法**（如 Direct3D-S2、SparC3D、SparseFlex）：重建质量高，但需要大量活动体素，导致内存和计算开销高昂；同时几何与离散网格绑定，结构预测的小误差可能导致脆弱的拓扑和非水密网格。
  - **集合（set-based）方法**（如 Dora、HY3D2.1、Lattice）：将形状编码为紧凑的潜在集合，通过连续查询算子解码，表示紧凑且支持任意分辨率查询；但重建保真度明显落后于体素方法。
- **核心问题定位**：作者认为集合式 VecSet 表示的保真度差距源于两个根本局限：① 全局交叉注意力隐式引入过度全局平滑，削弱了局部细节建模能力；② VecSet 表示过于稀疏（通常比稀疏体素网格少数十倍 token），严重限制了解码时的空间分辨率。
- **整体含义**：本文旨在提出一种分层集合式 VAE（MSVS-VAE），在不牺牲紧凑性的前提下显著缩小集合式表示与体素式表示之间的重建质量差距，从而为高保真 3D 生成提供更高效的基础表示。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构流程

> 输入点云 + 体素查询 → 编码器提取紧凑锚定 VecSet 潜在集合 → 分层点洗牌上采样渐进加密 → 多尺度查询解码预测 SDF → 等值面提取得到网格。

### 2.2 核心设计一：AVS-Conv（几何感知局部聚合算子）

- **动机**：替代现有 VecSet 方法中查询点与全部潜在 token 之间全局交叉注意力（复杂度 O(MN)），消除全局平滑并降低计算成本。
- **技术细节**：
  - 对每个查询点 qi，在支持集中检索 K 个最近邻 N(i)（欧氏度量下的 KNN）。
  - 基于相对偏移 Δpij = pj − qi 的位置编码，通过 MLP 预测动态权重 wij = MLP(γ(Δpij))。
  - 聚合公式：VC(qi, N(i)) = Σ wij ⊙ fj（通道级乘法），并加入邻域均值池化作为残差捷径。
  - 最终输出经 LayerNorm + FFN 残差块细化：zi = φ(qi; S) + FFN(LN(φ(qi; S)))。
- **应用场景**：编码器中用于从输入表面点聚合特征到潜在锚点；解码器中用于上采样后的自聚合和查询解码。

### 2.3 核心设计二：Hierarchical Point-Shuffle Upsampling（分层点洗牌上采样，PSU）

- **动机**：VecSet 表示的稀疏性限制了空间分辨率，直接增加 token 数量会带来过高训练/查询开销；需要在不显著扩大整体特征预算的前提下渐进加密。
- **技术细节**：
  - 对每层潜在集合 Z(l)（含 Ml 个 token），通过 feature shuffle MLP 将每个特征 z_m(l) 拆分为 r 个子特征（通道数减半），通过 point split MLP 预测 r 个几何偏移 Δc，形成 r 个子潜在 token（新中心 c + Δc）。
  - 经过多级上采样，潜在集合的空间密度呈指数增长（Ml+1 = r × Ml），同时单 token 通道容量递减，整体特征预算受控。
  - 上采样后用 AVS-Conv 做自聚合细化。

### 2.4 核心设计三：Multi-Scale Query Decoding（多尺度查询解码，MSQ）

- **动机**：只依赖最细尺度潜在层容易因感受野过局部而在平滑区域产生高频伪影；需要融合粗尺度的全局上下文和细尺度的局部细节。
- **技术细节**：
  - 对任意空间查询 qi，分别从所有 L 个渐进潜在尺度中通过独立的 AVS-Conv 算子查询特征：h_i(l) = AVS(l)(qi; Z(l))。
  - 将各尺度特征拼接后经轻量融合头得到 hi = Fuse([h_i(1)∥⋯∥h_i(L)])，再由 MLP 输出最终 SDF 值。

### 2.5 训练目标

- 使用截断符号距离函数（TSDF，截断距离 τ=1/128）对近表面几何优先监督。
- 总损失：Ltotal = λ_recon(‖ŝ − s̄‖₁ + ‖ŝ − s̄‖₂²) + λ_KL L_KL，其中 KL 项将潜在 token 正则化到标准正态分布。

### 2.6 训练策略

- **两阶段渐进式训练**：先在完整 3D 资产上用固定 4096 token 预算预训练（捕捉全局拓扑和低频几何）；再用局部随机 3D 裁剪微调（同样 4K token 只分配到裁剪区域），有效提升局部空间分辨率以细化高频细节。局部阶段仅监督近表面查询点的 SDF，因为远场 SDF 依赖超出局部块范围的全局拓扑。

## 6. 主要结论与发现

- **集合式 VAE 可以达到体素级重建质量**：MSVS-VAE 在三个基准上全面超越 Lattice，且仅用 20K tokens 就超过了 SparseFlex-1024（210K tokens）在 Objaverse 和 in-the-wild 上的表现；用 40K tokens 在多数指标上接近或超过所有体素基线。
- **紧凑性优势显著**：以约体素方法 10% 的 token 数实现相当或更优的重建质量，为下游生成建模提供了更高效的基础。
- **解码效率大幅提升**：AVS-Conv 将查询延迟随 token 规模的增长速度大幅减缓，相对 Lattice 实现约 5.5×/9.4×/14.4× 的加速（10k/20k/40k tokens）。
- **模块贡献明确**：PSU 是最关键组件（移除后 MD 从 1.395 恶化到 3.693）；MSQ 对表面平滑度和细节保持均有正面作用。
- **测试时缩放行为良好**：增加 token 预算可以一致地提升重建质量。

## 7. 优点（方法/实验亮点）

- **问题定位精准**：明确指出集合式 VecSet 保真度不足的两个深层原因（全局平滑 + 潜在稀疏性），并逐一给出对应解决方案，逻辑链条清晰。
- **层次化潜在加密思路新颖**：将点云上采样领域的 point-shuffle 思想迁移到 3D VAE 潜在空间，在保持整体紧凑的前提下增加空间分辨率，是平衡紧凑性与表达力的优雅设计。
- **高效的局部聚合算子（AVS-Conv）**：用 KNN + 动态权重卷积替代全局注意力，兼具计算效率和空间归纳偏置，且在不同阶段（编码、上采样细化、查询解码）统一复用，体现设计的一致性。
- **多尺度融合设计合理**：粗尺度提供全局稳定上下文，细尺度雕刻局部细节，有效抑制了过度局部感受野带来的伪影。
- **两阶段训练策略**：全局预训练 + 局部裁剪微调有效缓解了高保真连续表面学习的内存瓶颈。
- **实验覆盖面广**：多数据集、多指标、多基线的交叉验证，以及效率与缩放行为的分析，使结论更加扎实。

## 8. 不足与局限

- **作者自述的局限**：
  1. 在集合式连续隐式框架下提取尖锐特征（sharp features）仍有挑战；
  2. 解码效率仍落后于体素类方法；
  3. 尚未扩展到纹理建模，这是未来工作的重要方向。
- **从方法角度看**：
  - 编码器依赖外部模型（如 HY3D2.1）提供的活动体素中心作为锚点，这一依赖使得管道并非完全端到端自包含，在无现成生成模型的场景下可能受限。
  - AVS-Conv 依赖 KNN 检索，在点云分布极不均匀或存在大空洞的区域，固定 K 近邻的鲁棒性和稳定性有待进一步验证。
  - 层次化上采样中每级 token 数指数增长，虽然通道数同步减少，但极高分辨率下内存占用和计算规模的总体趋势仍需关注。
- **从实验角度看**：
  - 评估聚焦于几何重建，未涉及纹理/外观重建质量，与论文自述局限一致。
  - 消融实验粒度较粗，缺乏对关键超参数的敏感性分析（如 KNN 的 K 值、上采样倍数 r、层级数 L）。
  - 相比体素方法在极端高分辨率（如 1024³ 以上）的扩展能力，本文没有展示 MSVS-VAE 在极高分辨率下的行为。
  - 训练数据仅来自 Objaverse，对跨域泛化（如真实扫描数据、CAD 模型等）的评估有限。
