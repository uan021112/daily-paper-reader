## 摘要
触觉感知是机器人操作的核心，其中滑移检测是一项典型且关键的任务。然而，现有的滑移数据集主要局限于二分类，缺乏细粒度的方向感知。为解决这一局限，我们提出了一种配备定制均匀RGB照明的视触觉传感器，以及一个统一的感知框架。在硬件层面，该传感器实现了高精度、亚毫米级的深度重建。基于这一能力，我们收集了一个包含15个物体的多任务视触觉数据集，并为每个数据样本同步生成深度信息。在算法层面，我们设计了一种双头TimeSformer网络来处理动态时空滑移。在未见过的物体上，该网络在3类接触状态预测和细粒度8类滑移方向分类方面分别实现了95.5%和91.5%的鲁棒准确率。此外，利用ResNet-50主干网络进行基于静态触觉的物体类别识别，在15个类别中取得了98.8%的出色准确率。所提出的软硬件框架为复杂机器人操作提供了高保真反馈和强大的多模态感知基线。

## Abstract
Tactile sensing is central to robotic manipulation, among which slip detection stands out as a quintessential and critical task. However, existing slip datasets are predominantly limited to binary classification, lacking fine-grained directional perception. To address this limitation, we propose a visuo-tactile sensor featuring customized uniform RGB illumination, alongside a unified perception framework. At the hardware level, the sensor achieves high-precision, sub-millimeter depth reconstruction. Based on this capability, we collect a multi-task visuo-tactile dataset encompassing 15 objects, synchronously generating depth information for each data sample. Algorithmically, we design a dual-head TimeSformer network to process dynamic spatiotemporal slip. On unseen objects, this network achieves robust accuracies of 95.5% and 91.5% for 3-class contact state prediction and fine-grained 8-class slip direction classification, respectively. Furthermore, static tactile-based object class recognition utilizing a ResNet-50 backbone yields an outstanding accuracy of 98.8% across 15 categories. The proposed hardware-software framework provides high-fidelity feedback and a powerful multi-modal perception baseline for complex robotic manipulation.

## 二、方法论

### 1. 硬件设计：均匀照明无标记视触觉传感器
- 传感器尺寸为 **37 mm × 34 mm × 34 mm**，模块化设计：
  - 弹性接触模块（光学透明硅胶 + 白色漫反射涂层，可拆卸更换）；
  - 照明模块（PCB 上集成 RGB LED + 半透明磨砂扩散片）；
  - 信号接收模块（微型相机）。
- **光学设计创新**：
  - 对光源空间布局进行精心的工程化设计，将光源隔离到 PCB 上的不同照明区域，并在上方放置光扩散滤光片，实现接触层上的高度均匀光照；
  - 通过优化接触模块与相机的相对位置，使**鬼影（ghost images）完全处于相机焦深之外**，从而消除丙烯酸支撑板反射造成的成像伪影；
  - 均匀照明有效抑制镜面高光，为光度立体（photometric stereo）深度重建提供物理前提。

### 2. 深度重建：基于参考球标定的经验光度立体法
- 使用已知物理半径（r = 3 mm）的标准球体压入弹性体进行标定，利用球面压痕的解析几何模型计算真实表面梯度：
  - 压痕深度剖面：\( z(x,y) = \sqrt{R^2 - r^2} \)，其中 \( r = \sqrt{(x-x_c)^2 + (y-y_c)^2} \)；
  - 水平梯度：\( p_{ref} = \frac{\partial z}{\partial x} = -\frac{x-x_c}{\sqrt{R^2-r^2}} \)；
  - 垂直梯度：\( q_{ref} = \frac{\partial z}{\partial y} = -\frac{y-y_c}{\sqrt{R^2-r^2}} \)。
- 训练一个连续映射函数 \( f: [p, q] = f(I_R, I_G, I_B, x, y) \)，将 **RGB 强度 + 像素空间坐标**映射到表面梯度，以补偿光照分布的空间非均匀性；
- 实际感知时，将采集的 RGB 图像通过标定模型转换为稠密梯度场，再用 **Poisson 求解器**积分重建连续深度图：\( \nabla^2 z = \frac{\partial p}{\partial x} + \frac{\partial q}{\partial y} \)。

### 3. 动态滑移检测：双头 TimeSformer 网络
- 输入为 **8 帧连续触觉图像序列**（T=8, H=480, W=640, C=3），resize 至 224×224，分块（patch）后线性投影，并添加**空间与时间位置编码**；
- 核心为堆叠的 **Divided Space-Time Attention** 模块：交替计算跨帧的时间自注意力与帧内的空间自注意力；
- 提取全局 token 后，送入**双头全连接架构**：
  - **状态头（State Head）**：预测 3 类接触状态（Static、Press、Slip）；
  - **方向头（Direction Head）**：预测 8 类滑移方向（45° 间隔）。
- **掩蔽联合损失函数**：
  \[
  L_{total} = L_{state} + \lambda \cdot \mathbb{I}(state=slip) \, L_{dir}
  \]
  通过指示函数确保**仅在真实标签为"滑移"时反向传播方向损失**，避免静态/按压状态的噪声干扰。

### 4. 静态材质分类：ResNet-50
- 采用 ImageNet 预训练的 **ResNet-50** 作为主干，输入单帧触觉图像，修改全连接层输出 15 类；
- 训练时使用颜色抖动和几何增强增强鲁棒性；
- 集成 **Grad-CAM** 可视化，验证网络关注的微观高频特征（锐利边界、有机孔隙等）是否与物理感知一致。

## 八、不足与局限性

1. **无标记方案尚未实现真正零标定**：传感器依赖标准球体压痕进行经验光度立体法标定，标定过程需要精确控制压入深度与球体定位；若实际部署中弹性体老化或更换，需要重新标定，影响维护效率。
2. **动态深度重建的时序一致性不足**：实验表明深度模态在动态滑移检测中明显弱于 RGB 模态，说明当前基于单帧静态重建的深度生成方式并不天然适合动态时序任务，缺少跨帧时间约束或光流对齐机制。
3. **未见物体泛化测试覆盖不完整**：仅用 RGB 模态在未见物体上评估滑移检测，深度模态、材质分类在完全未见物体上的泛化能力均未涉及；**材质分类器的跨域泛化未知**（例如未见物体类别、多光照条件的鲁棒性）。
4. **"方向级滑移检测"存在标注边界模糊性**：8 类方向以 45° 为间隔，但真实滑移可能发生在边界角度附近；论文未说明标注者间一致性（inter-annotator agreement）或标签噪声的量化分析。
5. **数据集规模与多样性存在天花板**：
   - 15 个物体类别全部为刚性物体，未覆盖柔性物体、织物、液体或可变形物体；
   - 所有数据来自同一传感器原型，未验证跨传感器（不同弹性体硬度、不同批次）的可迁移性；
   - 滑移序列的机械臂运动策略单一（主要为横向牵引），缺少旋转滑移、斜向滑移、动态抓取力变化等复杂场景。
6. **硬件性能细节缺失**：未提供相机帧率、图像采集延迟、传感器耐久性（涂层磨损周期）、弹性体回复时间等工程指标，限制了实际机器人实时闭环应用的评估。
7. **缺乏与已有数据集的直接对照实验**：虽然表 I 从类别粒度上对比了数据集特性，但未在本文数据集上复现已有方法（如 STNet、Meier 等人的算法），也没有在已有数据集上测试本文方法，跨数据集泛化验证空缺。

   - 优化弹性体材料与涂层耐磨性，延长寿命；
   - 提高相机帧率与分辨率，减小动态模糊对时序特征提取的影响。
4. **工程应用层面**：
   - 将滑移检测器接入机械臂闭环控制，实现**实时滑移抑制**（如检测到滑移后自动增加夹持力）；
   - 将材质分类与抓取力规划结合，构建"感知-决策-执行"完整触觉操作闭环。

## 十、个人思考与启发

1. **"无标记 + 均匀照明"是一对巧妙的设计组合**：传统无标记方案的最大瓶颈是从无纹理区域恢复几何的困难；本文通过均匀 RGB 照明与经验光度立体相结合，提供了一种在有限硬件成本下获得稠密深度的高效路径，值得在更多触觉传感器设计中借鉴。
2. **时间序列 Transformer 应用于触觉的姿势新颖**：将视频理解中的 Divided Space-Time Attention 迁移到触觉滑移方向识别，说明**触觉时序信号与视觉时序信号在结构上具有可迁移性**，为触觉-视觉跨模态表征学习提供了启发。
3. **方向级滑移分类的意义不仅是精度提升**：8 方向标签使机器人能判断物体将朝哪个方向滑落，从而做出**方向性纠正操作**（如朝反方向微调夹爪姿态），这是二分类无法提供的控制信息；这代表了触觉感知从"事件检测"向"状态估计"演进的重要方向。
4. **对数据集构建的启示**：本文数据集虽然覆盖面有限，但提供了"多任务标签 + 多模态（RGB+Depth）"的标准范式，未来可将该范式扩展至更大规模、更多任务（如滑动摩擦系数估计、表面粗糙度回归）的触觉基础数据集。
5. **审稿视角的反思**：本文在硬件创新上扎实，但算法对比与消融不足是常见审稿痛点；未来相关论文应更加重视"在统一数据集上做好基线矩阵 + 消融矩阵"以提升说服力。

## 十一、总结

本文提出了一种基于均匀 RGB 照明与无标记光学设计的视触觉传感器，并构建了集**滑移方向级检测**与**静态材质分类**于一体的统一感知框架。硬件层面，均匀光照与无标记设计有效解决了镜面高光与微纹理遮挡两大传统痛点，实现了约 **0.072 mm** 的深度重建精度；算法层面，基于双头 TimeSformer 的滑移检测器在已知物体上达到状态分类 99.68%、方向分类 96.95% 的高精度，在未见物体上仍保持 95.5%/91.5% 的较好泛化；基于 ResNet-50 的静态材质分类在 RGB 模态达 98.8% 准确率。尽管在消融分析、算法对比、数据多样性等方面仍有提升空间，本文在**硬件-数据-算法一体化设计**上提供了完整且可复现的范例，对触觉感知领域的滑移检测与物体识别研究具有实质性的参考价值。
