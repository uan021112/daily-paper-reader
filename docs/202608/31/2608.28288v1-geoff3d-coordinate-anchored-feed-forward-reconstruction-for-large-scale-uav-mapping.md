## 摘要
现有的前馈三维重建方法通常处理有限数量的图像，并在局部或内部归一化坐标系中恢复相机位姿和几何结构。将其扩展到大规模无人机测绘需要可扩展的多块处理与可靠的聚合，而完整的Sim(3)对齐在近似共线的轨迹上可能变得不稳定。我们提出GeoFF3D，它结合了坐标锚定模型与空间大规模重建框架（SLRF）。该模型使用地理参考相机平移和可选的几何先验，直接在重力对齐的Z轴向上度量坐标系中预测相机位姿和稠密点图。SLRF将图像划分为空间重叠的块，传播共享视图先验，并分层聚合局部重建结果，同时适用于不同的有界视图模型。在九个航空测绘区块中，GeoFF3D实现了最佳的平均重建质量，将F@5从Pi3X + SLRF的0.829提升至0.877。在较长的UAVScenes序列上，其达到0.848，而Pi3X + SLRF为0.687，最强评估的SLAM/流式基线为0.451。GeoFF3D约在五分钟内重建2000幅图像，展示了可扩展且稳健的大规模无人机重建能力。代码可在https://github.com/yanxian-ll/GeoFF3D获取。

## Abstract
Existing feed-forward 3D reconstruction methods typically process a bounded number of images and recover cameras and geometry in local or internally normalized frames. Extending them to large-scale UAV mapping requires scalable multi-chunk processing and reliable aggregation, while full Sim(3) alignment can become unstable for near collinear trajectories. We present GeoFF3D, which combines a coordinate-anchored model with a spatial large-scale reconstruction framework (SLRF). The model uses georeferenced camera translations and optional geometric priors to predict camera poses and dense point maps directly in a gravity-aligned Z-up metric frame. SLRF partitions images into spatially overlapping chunks, propagates shared-view priors, and aggregates local reconstructions hierarchically, while remaining applicable to different bounded-view models. Across nine aerial mapping blocks, GeoFF3D achieves the best average reconstruction quality, improving F@5 from 0.829 for Pi3X + SLRF to 0.877. On long UAVScenes sequences, it reaches 0.848, compared with 0.687 for Pi3X + SLRF and 0.451 for the strongest evaluated SLAM/streaming baseline. GeoFF3D reconstructs 2,000 images in approximately five minutes, demonstrating scalable and robust large-scale UAV reconstruction.The code is available at https://github.com/yanxian-ll/GeoFF3D.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：无人机倾斜摄影测量被广泛用于城市建模、地形测绘、灾害评估和基础设施巡检。传统摄影测量系统依赖多阶段几何估计和迭代优化（如 SfM/MVS），计算开销巨大；而现有前馈重建模型（如 DUSt3R、MASt3R、VGGT、Pi3 等）可直接从多视图图像预测相机参数和稠密点图，效率更高。
- **核心问题**：现有前馈方法通常只能处理**有界数量**的输入图像（如 16~30 张），并在**局部相机系或内部归一化坐标系**中重建。实际无人机航测往往包含**数百至数千张图像**，并且需要输出统一的**地理参考、重力对齐的度量坐标系**（Z-up 公制世界系）中的结果。
- **两大挑战**：
  1. **地理配准不稳定**：将局部重建结果转至世界系通常需要估计完整 Sim(3) 变换（尺度、旋转、平移），但对于**近共线无人机轨迹**，其 roll 和 pitch 方向约束弱，容易导致重建整体倾斜，即便相机中心对齐看似准确。
  2. **大规模分块一致性**：大图像集合需分割为多个重叠块独立重建，块间在坐标系和共享视图深度上可能有差异，导致表面重复、垂直偏移、接缝明显，在多条航带场景中尤其突出（时间邻近不等于空间重叠）。
- **整体意义**：论文提出 **GeoFF3D**，将地理参考先验融入预测坐标系本身，而不是事后注册，从而避免不稳定的完整 Sim(3) 对齐；同时构建空间大规模重建框架（SLRF）实现跨块一致和可扩展聚合，使前馈重建能够应用于真实的、包含数百至数千张图像的大规模无人机测绘任务。

## 2. 方法论

### 2.1 总体思路

GeoFF3D 由两部分组成：

1. **坐标锚定前馈模型**：利用近似地理参考相机平移（GNSS）和可选几何先验（旋转、深度、内参），直接在重力对齐的 Z-up 公制坐标系中预测相机位姿和稠密点图。
2. **空间大规模重建框架（SLRF）**：对图像进行空间重叠分块、从中心向外推理并传播共享视图先验、使用重力保持变换进行分层聚合。

### 2.2 坐标锚定前馈模型

- **坐标系设计**：预测在局部地理参考笛卡尔系中进行，Z 轴与重力相反，X-Y 平面为当地水平面。使用锚点平移中心 \(c_T\) 和场景尺度 \(s_T\) 归一化相机平移和深度先验；推理后恢复到世界度量系。因此不同块在聚合前已经处于同一 Z-up 系。
- **先验编码**：
  - 图像编码器输出视觉 patch 特征 \(F_i^I\)；
  - 射线方向和深度观测编码为 patch 级特征 \(F_i^R\), \(F_i^D\)；
  - 地理参考平移和旋转编码为 view 级嵌入 \(e_i^t\), \(e_i^r\)，广播到该视图所有 patch token；
  - 融合特征：\(F_i = F_i^I + m_i^R F_i^R + m_i^D F_i^D + m_i^t e_i^t + m_i^r e_i^r\)，其中掩码表示先验可用性；训练时随机 dropout 先验，支持完整/部分/稀疏观测。
- **预测头**：
  - 相机头输出 SE(3) 的相机到世界变换 \(W_{c\to w}^i\)；
  - 稠密头预测每像素图像平面射线 \(r_i(u)\) 和正 Z 深度 \(d_i(u)\)，组合生成相机系点，再经变换和反归一化得到世界点：  
    \(\hat{X}_w^i(u) = s_T \pi_3(W_{c\to w}^i [d_i(u) r_i(u); 1]) + c_T\)；
  - 另设置信度头用于融合时抑制不可靠几何。
- **训练**：
  - 初始化自 Pi3X 预训练模型，在 UAVFF3D 和 BlendedMVS 上微调，统一转换为重力对齐 Z-up 坐标系。
  - 损失：\(L = \lambda_{local}L_{local} + \lambda_{world}L_{world} + \lambda_{pose}L_{pose} + \lambda_{grav}L_{grav}\)，系数分别 0.5, 1.0, 0.2, 1.0。
  - `L_local` 监督相机系点图、Z 深度、射线、相对位姿；`L_world` 监督归一化地理参考系中的稠密几何和绝对位姿；`L_grav` 最小化预测与真实相机向上方向的余弦误差，主要约束 roll/pitch。
  - 两阶段训练：先 224 像素 80 轮建立坐标锚定 Z-up 预测；再 518 像素微调 10 轮，同时随机丢弃/扰动几何先验，增强鲁棒性。

### 2.3 空间大规模重建框架（SLRF）

- **足迹引导的空间分块**：
  - 利用 GNSS 位置和 IMU 方向估计每幅图像地面覆盖范围；
  - 沿轨迹轴递归分割，建立自适应二叉树；每叶子块核心视图数 ≤ 0.7M，加上相邻区域 seam 视图后总视图 ≤ M；
  - 每张图属于一个核心集，但可作为相邻块的 seam 视图，提供重叠用于深度传播和对齐。
- **中心向外推理与先验传播**：
  - 构建块邻接图，选择离场景中心最近的块为根，广度优先处理；
  - 维护按图像 ID 索引的深度缓存；处理每个块前，读取其共享视图的缓存深度作为输入先验；推理后用置信度分位数阈值（0.25）过滤低置信度区域并更新缓存；对重复估计优先采用核心视图预测；
  - 若相机内参未知且同相机，则用第一块预测的平均内参作为后续块输入。
- **重力对齐分层聚合**：
  - 每个叶子块先用**重力对齐相似变换**（GA-Sim）锚定到地理参考平移先验：\(T(x)=s R_z(\theta)x + t\)（估计尺度、偏航、平移，保持 roll/pitch）；
  - 兄弟节点之间用**重力对齐刚体变换**（GA-Rigid）：\(T(x)=R_z(\Delta\theta)x + \Delta t\)（仅估计残余偏航和平移）；
  - 自底向上沿足迹树聚合至单一根重建，累计变换应用到所有叶子块，最终融合置信度过滤的核心视图几何。
  - 这种变换避免了完整 Sim(3) 对近共线轨迹的 roll/pitch 弱约束问题。

## 6. 主要结论与发现

- 在 9 个航空测绘块上，GeoFF3D 在 Accuracy、Completeness、F@1、F@5 上均取得最佳平均（2.72 m、2.59 m、0.267、0.877），相比 Pi3X+SLRF 分别降低 18.7% 和 15.8% 的错误，F@1 提高 0.036，F@5 提高 0.048。
- 在 UAVScenes 长序列上优势更大：相比 Pi3X+SLRF，Accuracy 从 6.05 m 降至 4.14 m（-31.5%），Completeness 从 4.40 m 降至 2.28 m（-48.2%），F@1 从 0.181 提升至 0.319，F@5 从 0.687 提升至 0.848，大幅超越最强 SLAM/流式基线 LingBot-Map（F@5=0.451）。
- 消融表明：
  - 世界坐标系损失（L_world, L_pose）是建立坐标锚定系统的关键；
  - 重力监督显著降低 GDE；
  - SLRF 的足迹分层流水线比时间顺序流水线效果好得多；
  - GA-Sim/GA-Rigid 在保持几何的同时降低接缝误差；
  - 先验传播提升跨块一致性；
  - GeoFF3D 对 2 倍位姿噪声具有较强鲁棒性，但仅使用平移先验时性能下降明显；
  - 块大小 30 是质量/效率最佳平衡。
- 坐标锚定对一般多航带聚合有益，而度量尺度和重力约束对细长轨迹尤其重要。

  - 消融实验覆盖模型组件、流水线、噪声鲁棒性、块大小、可扩展性；
  - 提供逐序列结果和定性可视化（顶视图、侧剖面、轨迹），便于分析失效模式。
- **资源效率**：2000 图约 5 分钟，16 GiB 显存，具有实际部署潜力，代码已开源。

## 8. 不足与局限

- **依赖地理参考先验质量**：方法强依赖 GNSS/IMU 平移先验，当先验稀疏或噪声过大时性能显著下降（“仅平移”对比实验显示 CD 和 ATE 大幅恶化）。
- **未提供严格 SfM 基线**：实验中未与经典 COLMAP SfM/MVS 做定量对比，因此无法明确相对传统高精度方法（通常更慢但可能更精确）的取舍。
- **长序列评估存在偏差风险**：UAVScenes 的帧采样采用固定步长 3，可能不利于依赖连续视频帧的 SLAM 或流式方法（如 VGGT-SLAM、LingBot-Map），导致其表现被低估。
- **UAVScenes/部分场景仅有单次或有限序列**，未报告多种子/多次运行统计差异，统计显著性未说明。
- **NPU-DroneMap 无真值**，只能定性展示泛化，无法量化。
- **训练依赖 Pi3X 预训练**，未从零训练对比，模型收益可能与初始化有关。
- **缺少在线/增量重建**：目前是离线分块流程，文中也承认未来需探索在线重建和全局优化。
- **显存与时间分析仅基于单场景（Town01）**，扩展性结论的通用性有限。
