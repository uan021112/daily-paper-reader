## 摘要
标准Transformer已在点云物体分类中证明有效，但在复杂场景中的密集预测任务中，其性能常因先验假设薄弱而受限。为解决这一挑战，我们提出PCT-Prompt，一种新颖框架，通过引入提示引导特征分支来增强标准Transformer，以提升密集预测任务的性能。标准Transformer分支利用预训练模型从点云数据中提取全局特征，作为处理高层特征的主干网络。同时，提示引导特征分支包含两个关键组件：一是细粒度特征提取块，使用几何敏感抽象层捕获多尺度几何特征，并结合PnP-3D层将局部上下文与全局正则化集成；二是提示精炼特征学习块，生成提示令牌，并通过交叉注意力机制进行精炼。此外，我们引入提示丢弃机制，在Transformer层间逐步移除提示信息，以平衡局部细节与全局一致性。在ShapeNetPart、S3DIS和DALES数据集上的实验结果表明，PCT-Prompt显著提升了标准Transformer对密集预测任务的适应性，在真实场景中取得了优异性能。

## Abstract
Standard Transformers have proven effective in point cloud object classification, but their performance in dense prediction tasks within complex scenes is often hindered by weak prior assumptions. To address this challenge, we propose PCT-Prompt, a novel framework that enhances standard Transformers by introducing a prompt-guided feature branch to improve performance in dense prediction tasks. The standard Transformer branch leverages pre-trained models for global feature extraction from point cloud data, serving as the backbone for processing high-level features. Meanwhile, the prompt-guided feature branch consists of two key components: a fine-grained feature extraction block that captures multi-scale geometric features using geometry-sensitive abstraction layer, along with the PnP-3D layer to integrate local context with global regularization. The second component, the prompt-refined feature learning block generates prompt tokens, which are subsequently refined through cross-attention mechanisms. Additionally, we introduce a prompt drop mechanism that progressively removes prompt information across Transformer layers, balancing local details and global consistency. Experimental results on the ShapeNetPart, S3DIS, and DALES datasets demonstrate that PCT-Prompt significantly improves the adaptability of standard Transformers to dense prediction tasks, achieving strong performance in real-world scenarios.

  - **标准 Transformer**（如 Point-BERT、Point-MAE、ACT、ReCon）结构灵活、易于部署、可加载丰富预训练权重，但存在明显不足：

- **核心问题**：如何在不改变标准 Transformer 核心结构的前提下，增强其对点云密集预测任务（部件分割、室内/室外场景语义分割）的适应能力？
- **整体含义**：论文提出 **PCT-Prompt** 框架，通过引入“提示引导特征分支”，在标准 Transformer 旁并行提取多尺度几何细节，并通过提示令牌（prompt tokens）与主干交互，从而弥补标准 Transformer 在局部细节和几何先验上的不足，同时保留其通用性和预训练优势。

## 2. 研究方法论：核心思想、关键技术细节

### 2.1 总体架构

- 框架由两个分支组成：
  - **标准 Transformer 分支**：负责全局特征提取，可加载不同预训练权重（如 Point-BERT、Point-MAE 等）。
  - **提示引导特征分支**：包含细粒度特征提取（FFE）块和提示精炼特征学习（PFL）块，生成并精炼提示令牌，与 Transformer 主干双向交互。

### 2.2 标准 Transformer 分支

- **Patch Embedding**：
  - 输入点云 \(P \in \mathbb{R}^{n \times 3}\)，使用最远点采样（FPS）选取 \(S\) 个中心点，再用 KNN 聚合 \(K\) 个邻近点形成局部子云。
  - 子云减去中心点以去除全局坐标影响，通过轻量 PointNet 提取嵌入：  
    \(F_{\text{emb}} = \text{MaxPool}(\text{MLP}(\text{KNN}(\text{FPS}(P)) - \hat{P}))\)
  - 叠加由中心点坐标经 MLP 生成的位置编码 \(F_{\text{pos}}\)，得到 Transformer 输入 \(F^0_{\text{st}} = F_{\text{pos}} \oplus F_{\text{emb}}\)。
- **Transformer Backbone**：
  - 包含 \(L=12\) 层，划分为 \(N=6\) 个块（经验最优）。
  - 每个块可接收来自提示分支的提示令牌 \(F^i_{\text{prompt}}\)，与特征令牌 \(F^{i-1}_{\text{st}}\) 拼接后输入 Transformer 块：  
    \(\langle \hat{F}^i_{\text{st}}; \hat{F}^i_{\text{prompt}}\rangle = \text{Block}(F^{i-1}_{\text{st}}; F^i_{\text{prompt}})\)

### 2.3 提示引导特征分支

#### （1）细粒度特征提取块（FFE）

- 输入点云经 MLP 编码为特征后，构建四级层次结构，每级包含：
  - **几何敏感抽象层（GSA）**：使用 FPS 和 KNN 选取中心点与邻域，引入相对位置编码和可学习的几何仿射机制，增强对稀疏不规则结构的鲁棒性。
  - **PnP-3D 层**：轻量即插即用模块，局部分支通过邻域图聚合捕获细粒度结构，全局分支通过通道与点维度的双线性交互增强特征一致性。
  - 每级输出特征：\(F_j = \text{MLP}(F^{\text{GSA}}_j \oplus \text{PnP3D}(P_j; F^{\text{GSA}}_j))\)
  - 多尺度采样率：\(C = \{n/4, n/16, n/64, n/256\}\)，最终形成统一的多尺度特征金字塔 \(F^0_{\text{pyramid}}\)。

#### （2）提示精炼特征学习块（PFL）

- **Prompt Generator（提示生成器）**：
  - 对多尺度特征金字塔进行自适应最大池化，得到每尺度的全局描述，并添加可学习位置编码，得到全局特征：  
    \(F^i_{\text{global}} = \text{AdaptiveMaxPool1D}(\text{MLP}(F^{i-1}_{\text{pyramid}})) + F^i_{\text{pos}}\)
  - 经 Conv1D、LeakyReLU、LayerNorm 处理后生成提示令牌：  
    \(F^i_{\text{prompt}} = \text{LayerNorm}(\text{LeakyReLU}(\text{Conv1D}(F^i_{\text{global}})))\)
  - 提示令牌与 Transformer 特征令牌拼接，共同送入对应 Transformer 块。
- **Prompt Refiner（提示精炼器）**：
  - 利用 Transformer 块输出 \(\langle \hat{F}^i_{\text{st}}; \hat{F}^i_{\text{prompt}}\rangle\) 作为 Key/Value，以多尺度特征金字塔作为 Query，通过交叉注意力将全局语义融入各尺度：  
    \(\hat{F}^i_{\text{pyramid}} = \text{Softmax}(\frac{\text{LN}(F^{i-1}_{\text{pyramid}}) \cdot \text{LN}(\langle \hat{F}^i_{\text{st}}; \hat{F}^i_{\text{prompt}}\rangle)^T}{\sqrt{d}}) \cdot \text{LN}(\langle \hat{F}^i_{\text{st}}; \hat{F}^i_{\text{prompt}}\rangle)\)
  - 随后通过共享权重 MLP 跨尺度传播信息：\(F^i_{\text{pyramid}} = \text{MLP}_{\text{shared}}(\hat{F}^i_{\text{pyramid}})\)。
- **Prompt Drop（提示丢弃机制）**：
  - 随着 Transformer 层数加深，提示令牌的作用减弱，因此每次交互后移除提示令牌，仅保留特征令牌作为下一层输入：  
    \(F^i_{\text{st}} = \langle \hat{F}^i_{\text{st}}; \hat{F}^i_{\text{prompt}}\rangle \setminus \hat{F}^i_{\text{prompt}}\)
  - 好处：使提示信息在深层持续发挥作用，平衡局部细节与全局一致性。

### 2.4 特征融合与密集预测

- 将 Transformer 分支输出上采样至与特征金字塔相同的四种分辨率，与提示分支特征逐元素相加，送入类似 PointNet++ 分割头的解码器（包含特征传播层），逐步恢复逐点语义预测。

### 2.5 损失函数

- ShapeNetPart：标准交叉熵损失。
- S3DIS 和 DALES：加权交叉熵损失，权重 \(w_i = N/f_i\)，以缓解类别不平衡。

## 6. 主要结论与发现

- **PCT-Prompt 显著提升标准 Transformer 的密集预测性能**：
  - ShapeNetPart：相比 Point-BERT，实例 mIoU 提升 0.6%（85.6→86.2），类别 mIoU 提升 0.9%（84.1→85.0），接近变体 Transformer（如 PCT、PointCAT）水平。
  - S3DIS（Area 5）：相比 Point-BERT，mAcc 提升 3.1%（75.7→78.8），mIoU 提升 7.4%（63.5→70.9），并超过多个变体 Transformer（PT、PatchFormer、SPT 等）。
  - DALES：相比 Point-BERT，mIoU 提升 6.5%（72.0→78.5），mAcc 提升 5.3%（79.6→84.9）。
- **组件消融**：FFE 和 PFL 均有效，生成器与精炼器互补，Prompt Drop 带来最好性能；交互频率 N=6 为最优。
- **预训练兼容性**：PCT-Prompt 可与多种预训练模型配合，且均优于单独使用标准 Transformer；其中 Point-BERT 权重在本框架下效果最佳。
- **总体结论**：提示引导机制有效弥合了标准 Transformer 与变体 Transformer 在密集预测任务上的差距，拓展了标准 Transformer 的下游任务适用性。

## 7. 优点

- **创新性**：在标准 Transformer 旁引入独立的提示引导分支，不动主干结构即可注入多尺度几何先验，思路新颖。
- **通用性**：可灵活加载多种预训练权重（Point-BERT/Point-MAE/ACT/MaskPoint/ReCon），具有即插即用性。
