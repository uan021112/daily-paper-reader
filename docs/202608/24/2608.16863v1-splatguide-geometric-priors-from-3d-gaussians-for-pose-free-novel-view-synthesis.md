## 摘要
从无位姿图像生成逼真的新视图需要3D几何理解和合成未见内容的能力。一种自然的策略是将前馈3DGS重建与多视图扩散相结合。然而，先前的流水线最多从重建中提取一种信号，要么是像素渲染，要么是学习特征，而没有一种利用逐高斯可见性进行遮挡感知的参考选择。这种“信息脱节”导致可渲染几何、可见性线索和学习特征未被使用。SplatGuide通过以三种互补角色重用单个3DGS场景来弥合这一脱节。渲染图像提供像素对齐的几何条件。逐高斯源视图索引被渲染为目标视图投票图，用于遮挡感知的参考选择。重建token通过交叉注意力提供特征级指导。所有三种信号均来自同一次重建前向传播。在RealEstate10K、DL3DV、Tanks-and-Temples和Mip-NeRF 360上，SplatGuide实现了最先进的无位姿新视图合成。在RealEstate10K上，在输入视图数量适中的情况下，它超越了基于真实位姿的基线。

## Abstract
Generating photorealistic novel views from unposed images requires both 3D geometric understanding and the ability to synthesize unseen content. A natural strategy combines feed-forward 3DGS reconstruction with multi-view diffusion. Yet prior pipelines extract at most one signal from the reconstruction, either pixel rendering or learned features, while none exploits per-Gaussian visibility for occlusion-aware reference selection. This *information disconnect* leaves renderable geometry, visibility cues, and learned features unused. SplatGuide closes this disconnect by reusing a single 3DGS scene across three complementary roles. Rendered images provide pixel-aligned geometric conditioning. Per-Gaussian source-view indices are rendered into a target-view voting map for occlusion-aware reference selection. Reconstruction tokens supply feature-level guidance via cross-attention. All three signals derive from the same reconstruction forward pass. Across RealEstate10K, DL3DV, Tanks-and-Temples, and Mip-NeRF 360, SplatGuide achieves state-of-the-art pose-free novel view synthesis. On RealEstate10K, with a moderate number of input views, it surpasses the ground-truth-pose baseline.

### 研究背景与动机
- **问题定义**：从无位姿（pose-free）的输入图像集合生成照片级真实感的新视图，是3D视觉领域的核心挑战之一。该任务在无相机标定、无受控采集、无位姿标注的真实场景中尤为重要。

- **现有方法的两难困境**：
  - **前馈3D重建模型**（如DUSt3R、NoPo-Splat、WorldMirror等）虽能在单次前向传播中恢复相机位姿和场景几何，但只能插值观测视角之间的内容，无法"想象"未观测区域。
  - **多视图扩散模型**（如SEVA、CAT3D等）能从新视角生成照片级真实感图像，却依赖预计算的精确位姿，在缺乏标注的现实场景中难以应用。
  
- **自然策略**：将重建与扩散结合——重建提供几何锚定，扩散合成重建无法覆盖的内容。**然而**，现有组合管线存在核心瓶颈：

- **核心问题——信息脱节（Information Disconnect）**：
  > 前馈重建已生成完整的3DGS场景，其中编码了可渲染几何、逐高斯源视图归属（source-view ownership）和学习到的特征表示，但现有管线最多只提取其中一种信号，其余信息被完全丢弃。

  - **位姿-only方法**（SEVA、CAT3D等）：仅使用估计的相机参数，丢弃整个重建场景，导致质量远低于真值位姿上限。
  - **像素级方法**（ViewCrafter等）：渲染几何为图像以条件化视频扩散，但限制为轨迹插值，且绑定特定架构。
  - **特征级方法**（Gen3C、Geometry Forcing）：注入稠密潜在特征，但需要VGGT等模型产生计算成本极高的密集特征。
  - **参考视图选择**：所有方法均使用位姿距离或时间连续性等启发式策略，忽略遮挡信息，在紧凑上下文预算下失效。

### 论文含义
SplatGuide通过复用单个3DGS场景的**三种互补信号**来弥合重建与生成之间的信息脱节，使无位姿新视图合成质量首次在RealEstate10K上超越基于真值位姿的基线。

## 2. 论文提出的方法论

### 整体架构：三阶段管线
SplatGuide采用"**重建 → 选择 → 生成**"的三阶段流程，从单个前馈重建前向传播中提取三种互补信号：

### 2.1 阶段一：重建（Reconstruction）

**公式**：
```
(P_ref, G) = f_recon(I_ref)
```
- 采用像素对齐高斯预测的前馈骨干网络（默认WorldMirror），每个像素回归一个3D高斯。
- 每个高斯 gᵢ 天然携带**源视图索引** v(i) ∈ {1,...,V}---该索引由构造决定，无需额外监督，也无需合并启发式。
- 通过标准3DGS光栅化渲染目标位姿和参考位姿下的粗糙图像：

  ```
  Î_P = Σ_{k∈N(P)} c_k α'_k Π_{l=1}^{k-1} (1 - α'_l)
  ```

### 2.2 阶段二：可见性感知视图选择（Visibility-Aware View Selection）

**核心组件**：

1. **视图索引图渲染**：将逐高斯源视图索引渲染为目标视角下的索引图（Index Map）。采用**首次命中深度测试**（first-hit depth test），每个像素仅保留最近高斯并写入其源视图的调色板颜色。
   
2. **可见性评分**：
   ```
   S(k) = Σ_p I[ v̂(p) = k ]
   ```
   每个目标像素投票给最能解释其可见表面的源视图。

3. **两个补充组件**（解决纯几何覆盖的不足）：
   - **DeDup（去重）**：丢弃与已选视图可见高斯高度重合的候选，避免预算浪费在近似重复视角上。采用2×2网格分块的边际增益计算。
   - **PoseAug（位姿增强）**：最大-最小邻近规则，保证每个目标至少有一个邻近上下文视图：
     ```
     j* = argmax_j min_k ||t_k - t_tgt_j||₂
     k* = argmin_k ||t_k - t_tgt_j*||₂
     ```

### 2.3 阶段三：扩散生成（Diffusion Generation）

**像素级几何条件**——渲染图像：
- 将渲染图像 Î_ref 和 Î_tgt 编码到潜在空间，与噪声潜变量、Plücker射线嵌入、二进制掩码拼接：
  ```
  z_cond = [ z_t, z_render, e_plk, m ] ∈ R^{H×W×(2C+C_plk+1)}
  ```
- 扩展U-Net首层卷积输入通道（从C+C_plk+1到2C+C_plk+1），新权重零初始化以保持预训练行为。

**特征级条件**——重建token：
- 从重建骨干末层提取每视图1个相机token + 4个寄存器token（d_r=1024）。
- 通过学习的线性投影映射到扩散U-Net的交叉注意力维度，经专用交叉注意力层注入。

**训练目标**：仅训练扩散模型，重建骨干和VAE保持冻结。使用标准潜扩散噪声预测目标：
```
L = E_{z₀,ε,t} [ || ε - ε_θ(z_t, t, C) ||²₂ ]
```

## 6. 论文的主要结论与发现

### 核心结论
1. **信息脱节是根本瓶颈**：无位姿NVS的瓶颈不在于重建无法提供什么，而在于现有管线没有使用什么。完整复用3DGS的三种信号能弥补预测位姿的精度损失。

2. **实现了无位姿NVS的最佳性能**：
   - RealEstate10K：3视图下比最强位姿only基线SEVA（无位姿）高+3.05 dB；9视图时**超越真值位姿SEVA基线**
   - DL3DV：在所有视图数下取得最佳LPIPS
   - Mip-NeRF 360 和 Tanks-and-Temples：域外场景保持最佳

3. **视图选择是一阶设计决策**：仅选择策略差异即可造成7 dB的PSNR差距（B=6时）。可见性感知选择在上下文预算紧张时增益最大。

4. **生成互补重建**：SplatGuide超越纯重建基线（如RE10K 3视图下比WorldMirror高+5.39 dB），证实扩散先验对未观测区域生成的关键价值。

5. **模块化设计有效**：重建骨干可零样本替换（WorldMirror → AnySplat），无需重新训练扩散模型，且更强骨干直接转化为更好的生成质量。

6. **重建token与渲染图像互补**：渲染锚定空间布局，token提供全局场景上下文解决纹理/风格歧义，组合带来16%的相对LPIPS降低。

## 7. 优点

### 方法设计亮点
1. **信息复用最大化**：三个信号（渲染、可见性、token）来自同一前向传播，零额外3D基元，无额外监督。

## 8. 不足与局限

### 方法本身的局限
1. **失败模式呈相关性**：渲染、token和源视图索引均来自同一重建G。当重建骨干退化时（无纹理表面、宽基线、重复结构、动态内容），所有信号同时退化，扩散模型失去独立几何线索。
2. **动态场景完全失效**：运动既破坏重建，又破坏视图索引图中首次命中对应的基本假设，是最尖锐的限制场景。
3. **扩散骨干单一**：仅验证SEVA作为扩散骨干，其他多视图扩散架构（如DiT类）的适配性未验证。

### 实验覆盖的缺口
1. **消融训练子集有限**：Tab. 4消融仅在DL3DV代表性子集上训练，指标可能不完全代表完整数据集上的表现。
2. **无位姿误差增长的压力测试**：未系统分析重建位姿误差如何随输入视图数量、场景类型变化而对生成质量产生何种非线性影响。
3. **缺乏LLM标注的开放域评估**：自采数据规模较小，覆盖的场景类型有限。
4. **与地面真值位姿方法的不完全对齐**：Gen3C和Geometry Forcing需真值位姿，无法直接对比，但从可比较设置的消融性分析缺失。

### 应用限制
1. **推理成本**：端到端75.5s/视图（RTX 4090），虽选择器近零成本，但重建3.73s+扩散采样71.8s仍是实时应用的障碍。
2. **分辨率受限**：576×576的生成分辨率低于部分生产级需求。
3. **计算资源门槛**：8×H200的训练配置对一般研究团队具有较高门槛。
4. **依赖像素对齐高斯**：骨干必须输出每个像素一个高斯的模型才能天然支持源视图索引，限制了候选骨干范围。
