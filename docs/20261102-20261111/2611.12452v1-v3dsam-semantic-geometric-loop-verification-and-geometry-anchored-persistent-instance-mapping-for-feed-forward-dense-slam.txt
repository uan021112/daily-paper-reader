# V3DSAM: Semantic-Geometric Loop Verification and Geometry-Anchored Persistent Instance Mapping for Feed-Forward Dense SLAM 

Ye Maolin, Zhao Dongqing ∗, Li Linyang, Xue Shuai, Liu Yuan, Wang Yiyuan, and Li Wen 

Information Engineering University 

> *Corresponding author: Zhao Dongqing.

Abstract — To address unreliable cross-view association in long-sequence feed-forward dense SLAM, this letter presents V3DSAM, an open-vocabulary semantic dense SLAM system that establishes physical correspondences at both the scene and object levels. The system combines feed-forward geometric estimates from VGGT-SLAM 2.0 with open-vocabulary seman-tic observations from SAM3. We introduce semantic-geometric dual-scale loop verification, which identifies false loop closures using pixel-level bidirectional reprojection and object-level 3D spatial correspondences, without accessing backbone-internal features. We further propose geometry-anchored persistent instance mapping, which defines physical instances through class-constrained 3D connectivity in an optimized global co-ordinate system and assigns global IDs without inter-frame identity propagation. The proposed verifier rejects all four false loop candidates in our TUM RGB-D evaluation, while long-sequence ScanNet experiments show improved instance identity consistency. Thus, V3DSAM reduces dependence on internal backbone features and temporal ID propagation for robust long-term cross-view association. 

Index Terms— SLAM, Semantic Scene Understanding, Loop Closure Detection, Persistent Instance Mapping. I. I NTRODUCTION 

Visual simultaneous localization and mapping (SLAM) is fundamental to autonomous navigation, augmented reality, and 3D scene understanding. Recently, visual geometry foun-dation models such as VGGT have enabled feed-forward es-timation of camera poses and dense scene geometry through large-scale multiview pretraining, providing a new geomet-ric basis for dense visual SLAM [1]. Meanwhile, open-vocabulary vision models, including the SAM family and CLIP, enable flexible category- and object-level semantics in 3D scene representations, facilitating semantic SLAM systems that combine geometric reconstruction with open-vocabulary scene understanding [2], [3], [4], [5]. A central challenge in extending local feed-forward ge-ometry to long-sequence SLAM is establishing reliable and persistent physical correspondences across observations sep-arated in time and viewpoint. The challenge manifests as scene-level false loop closures and object-level instance drift. A. Feed-Forward Visual Geometry and Dense SLAM 

Traditional iterative visual SLAM systems, such as ORB-SLAM3 and DROID-SLAM, estimate camera poses and 3D structure by iterative bundle adjustment with hand-crafted features or dense photometric constraints [6], [7], [8]. Recently, visual geometry foundation models, including DUSt3R, MASt3R, and VGGT, have learned global geo-metric priors from large-scale multiview pretraining. Given one or more images, they directly predict camera poses, dense depth, and 3D point clouds without frame-by-frame iterative optimization [1], [9], [10]. Building on these mod-els, MASt3R-SLAM, VGGT-SLAM, and VGGT-SLAM 2.0 combine keyframe management, local maps, loop closure, and global optimization to extend feed-forward geometry to long-sequence dense SLAM [11], [12], [13]. This work further investigates the consistency of cross-view association in long sequences. 

B. Loop Candidate Retrieval and Verification 

Loop-closure processing comprises candidate retrieval (loop detection) and loop verification. The former retrieves potential revisit pairs from historical keyframes, whereas the latter rejects false candidates to prevent erroneous constraints from affecting global optimization. Candidate retrieval commonly uses global image descrip-tors such as NetVLAD and SALAD [14], [15]; Hydra instead employs hierarchical 3D scene structures for loop association [16]. Conventional verification often relies on geometric registration such as ICP, which performs reliably in scale-consistent iterative SLAM but may be challenged by noise in feed-forward geometry and semantic ambiguity [17]. In feed-forward SLAM, MASt3R-SLAM reprocesses can-didate frames through its backbone for two-view inference and verifies them using matching quality, coupling verifi-cation to the encoder and introducing additional inference cost [13]. EC3R-SLAM uses a homography-RANSAC inlier ratio for loop verification, relying on geometric cues without object-level semantics [18]. VGGT-SLAM 2.0 extracts the signal αmatch from VGGT attention layers to verify retrieved candidates without additional training; however, this signal is tied to a specific network architecture and is less readily reusable. Establishing interpretable cross-view physical cor-respondence from explicit feed-forward 3D geometry and independent semantic observations, without using backbone-specific features, therefore remains of interest. 

C. Cross-View Instance Association and Open-Vocabulary Instance Mapping 

Early instance SLAM methods often depend on predefined semantic categories or local instance association. MaskFu-sion establishes instance correspondences using 2D masks and temporal tracking [19], PanopticFusion fuses panoptic observations into a 3D voxel map to maintain identities [20], and SGS-SLAM jointly optimizes geometry and semantics with 3D Gaussian representations [21]. Nevertheless, stable identities remain challenging across long temporal gaps and large viewpoint changes. With advances in vision-language pretraining, CLIP-Fields aggregates CLIP features into 3D point clouds for point-level open-vocabulary queries, primarily targeting offline multiview fusion [22]. OVO combines semantic categories, vision-language embeddings, temporal tracking, and spatial constraints to build instance-level maps, but long-term iden-tity persistence remains limited [23]. These approaches place greater emphasis on semantic representation richness than on long-term identity consistency. For semantic mapping built on feed-forward geometry, SceneVGGT back-projects SAM masks to construct se-mantic point clouds, but instance partitioning still depends heavily on inter-frame 2D semantic-label matching [24]. IRIS-SLAM fine-tunes the feed-forward backbone to learn dedicated instance embeddings, coupling its approach to internal model representations [25]. In multiview 3D instance construction, Open3DIS and MaskClustering use 2D masks to guide 3D instance aggregation, but do not specifically address noise in predicted feed-forward geometry [26], [27]. Maintaining long-term global instance identities under such geometric noise, without temporal ID propagation, remains an open challenge. III. M ETHOD 

A. Overview of V3DSAM 

As shown in Fig. 2, V3DSAM takes a continuous monoc-ular RGB sequence as input. VGGT-SLAM 2.0 and SAM3 provide camera intrinsics and extrinsics, dense depth, and semantic masks. An appearance-retrieval module generates loop candidates, which are processed by semantic-geometric dual-scale verification. Only candidates satisfying both con-sistency constraints enter global geometric optimization. In the resulting optimized world coordinate system, multiview semantic observations are fused by geometry-anchored in-stance assignment to construct a persistent dense 3D instance map.

This connectivity relation is an equivalence relation and partitions the voxel set into disjoint connected compo-nents, each representing a physical 3D instance. A KD-tree performs neighborhood searches among voxels of the same class, and a union-find algorithm efficiently computes the connected components. After discarding noisy components with fewer voxels than a minimum threshold, each remaining component receives a unique global instance ID that serves as the persistent identity of the physical entity. To associate 3D instances with 2D observations, instance voxels are projected into keyframe images, producing an instance mask M3D . A. Experimental Setup 1) Datasets: Experiments use ScanNet [28] and TUM RGB-D [29] indoor datasets. The TUM RGB-D experi-ments cover eight Freiburg1 sequences. With a unified front-end configuration, these sequences yield 15 SALAD loop candidates: 11 true and four false loops. Together with four ScanNet scenes, the evaluation contains 46 candidate frame pairs. All hyperparameters of the loop-verification module are selected using TUM RGB-D only and transferred directly to ScanNet without retuning, to test cross-dataset generalization under fixed parameters. 

2) Parameters and Hardware: VGGT-SLAM 2.0 pro-vides the feed-forward geometry, and SAM3 generates open-vocabulary semantic observations for keyframes. On TUM RGB-D, each submap contains 32 frames and the SALAD candidate threshold is 0.95. For loop verification, the pixel- and object-level consis-tency thresholds are τpix = 0 .10 and τobj = 0 .25 , respec-tively. Within a frame, same-class 3D clustering uses a 0.3 m neighborhood threshold and removes sparse clusters contain-ing fewer than 80 points. Persistent instance mapping uses a 0.02 m voxel resolution and a 0.05 m 3D neighborhood connection distance, and filters out connected components containing fewer than 100 voxels. Experiments are conducted on an NVIDIA RTX 4090 GPU and an Intel i7-14700 CPU. 

3) Evaluation Metrics: Trajectory accuracy is measured using absolute trajectory error (ATE-RMSE). Loop verifica-tion is evaluated using a confusion matrix, precision, recall, and F1-score. Following the overlap-based loop-labeling principle in [30], we define loop ground truth from the extent of shared 3D visibility computed using ground-truth poses and depth. V. C ONCLUSION 

This paper presents V3DSAM, an open-vocabulary seman-tic mapping system for feed-forward dense SLAM with two complementary association mechanisms: semantic-geometric dual-scale loop verification and geometry-anchored persis-tent instance mapping. The first mechanism identifies false-positive loops using only explicit geometry and semantic outputs, without depending on backbone-internal features. The second assigns global instance IDs to class-constrained 3D connected components and avoids inter-frame temporal ID propagation. Experiments on TUM RGB-D and ScanNet demonstrate that V3DSAM suppresses trajectory drift from false loops, achieves localization accuracy comparable to native VGGT verification, and improves long-term instance identity consistency relative to the evaluated baselines.
