ABSTRACT
Self-supervised learning relies on asymmetry between what a model observes and
what it must explain. Recent methods learn 3D geometry from unposed images by
predicting cameras and scene structure, then rendering held-out views. To avoid
trivial solutions, they impose this asymmetry in the input space, restricting how
views interact through separate branches or masked attention. We revisit this de-
sign with geometric accuracy, rather than rendering quality, as the main objective.
When a held-out view lies between context views, the context already constrains
the geometry it observes. We therefore impose the asymmetry in the 3D represen-
tation space, excluding held-out views only from the reconstructed scene while a
shared backbone uses all views for correspondence. This improves depth and pose
estimation over input-space designs. We further exploit view density: sparse and
dense observations depict the same scene but provide different amounts of corre-
spondence. Aligning sparse-context features with dense-context features supplies
a geometric training signal alongside rendering, without a pretrained geometric
teacher. We additionally align features with a frozen vision foundation model,
which brings further gains. None of these signals requires geometric annotation,
and the resulting model improves geometry estimation over prior self-supervised
methods. Controlled experiments isolate the contribution of each component, and
self-supervised pretraining also improves subsequent supervised training.

INTRODUCTION
Self-supervised learning has driven the progress in representation learning. Because it requires no
manual labels, models can be pretrained on as much data as we can collect, and their performance
continues to improve as data, model size, and compute scale (Kaplan et al., 2020). This approach
has succeeded in language (Radford et al., 2018; Devlin et al., 2019), vision (Caron et al., 2021; He
et al., 2022), and embodied control (Mu & Rhoda AI Team, 2026). In contrast, many 3D foundation
models are trained to reproduce geometric annotations recovered by optimization pipelines such
as COLMAP (Sch¨onberger & Frahm, 2016), which are costly to run and hard to scale. Recent
work (Jiang et al., 2025b; Zhao et al., 2026; Huang et al., 2026b) removes this dependence by making
novel-view synthesis (NVS) the training objective, predicting cameras and scene structure from raw
images or a video and rendering held-out views using its own predictions. These methods differ
in scene representation and how they share information across views, but evaluations focus largely
on synthesis quality. In self-supervised learning, however, the pretext task is only a means, and a
method is judged by what it learns. We therefore treat view synthesis as the pretext and geometry as
the outcome, and ask which designs make geometry learning more accurate and scalable.
We begin with the scene representation. Since the model learns about the scene only through what
it renders, the form of this representation determines how closely the learned structure reflects the
actual 3D geometry. Latent NVS methods (Jiang et al., 2025b; Mitchel et al., 2026; Prestel et al.,
2026) render held-out views from an implicit scene code, so geometry is never made explicit. They
achieve strong rendering quality, but can do so without recovering structure that corresponds to
physical 3D space, leaving geometry and camera motion only weakly constrained by the synthesis
loss. We instead use an explicit representation, 3D Gaussians (Kerbl et al., 2023) placed in physical
space, so that every rendered pixel depends directly on the predicted depth and camera pose.

Where should the asymmetry live? A self-
supervised objective needs an asymmetry be-
tween what the model sees and what it must
explain. Otherwise, trivial solutions satisfy it.
For example, in masked image modeling (He

so masking parts of it directly defines the task.
In contrast, masking a view in multi-view 3D
does not create the same asymmetry. When a
held-out view lies between context views (in-
terpolative NVS setting), the 3D scene recon-

scene that all views together describe. Remov-

nevertheless impose the asymmetry on the im-
ages the network observes1. E-RayZer (Zhao

only among themselves. Both keep held-out views out of the reconstruction, but in doing so also
withhold the correspondence those views could provide.
We instead place the asymmetry in the 3D representation space. A shared backbone lets all views
exchange information when predicting depth and pose, so every view contributes correspondence.

that a held-out view is rendered only from Gaussians predicted for context views. This is equivalent

Asymmetric feature alignment. View density provides a second source of asymmetry. The same
model predicts more accurate depth and pose when it sees more views of a scene, so a model given
fewer views is a weaker version of itself. Such gaps within a single model have been used to
bootstrap representations without any external teacher (Jiang et al., 2025a; Chefer et al., 2026).
SelfEvo (Huang et al., 2026a) applies this idea to 3D, refining a model pretrained with 3D supervi-
sion (Wang et al., 2025b; 2026c) by using the geometry and camera predictions of a dense-context
teacher as pseudo labels for a sparse-context student. We instead build this asymmetry into self-
supervised training, optimizing it jointly with the rendering objective without any pretrained geo-
metric teacher. In this setting the dense-context predictions are themselves unreliable, and matching
them can propagate their errors. We therefore align the features that produce the geometry rather
than the geometry itself. The largest gains occur in single-view depth estimation, which the render-
ing objective does not supervise directly.
Semantics as a geometric prior. Both signals above are grounded in rendered pixels. The render-
ing loss supervises the model directly, and asymmetric context alignment does so indirectly through
features shaped by rendering. Pixel agreement, however, says little about which pixels belong to-
gether, such as which regions form the same surface or object. Such high-level structure often
helps constrain geometry where photometric cues are weak, such as textureless or repetitive regions.
Vision foundation models capture it well, and aligning with their features has proven effective in
generative modeling (Yu et al., 2024; Wu et al., 2025) and supervised perception tasks (Yang et al.,
2024; Knaebel et al., 2026). We use such alignment as a semantic prior for self-supervised learning,
aligning our backbone features with those of a frozen vision foundation model (Sim´eoni et al., 2025;
Yang et al., 2026), obtaining consistent gains in geometry estimation at modest additional cost.
We combine these components into a single self-supervised geometry framework and evaluate each
through controlled experiments. Our contributions are as follows.
• Asymmetry in the 3D representation. We show that imposing the asymmetry on the recon-
structed scene rather than on the input images prevents trivial solutions while letting a shared
backbone use every view for correspondence, improving depth and pose estimation.
• Asymmetric feature alignment. We align sparse-context features with dense-context features
jointly with the rendering objective, improving geometry without a pretrained geometric teacher.
• Semantics as a geometric prior. Aligning intermediate features with a frozen vision foundation
model adds structural guidance beyond pixel agreement, improving depth and pose estimation
without geometric annotations.

RELATED WORK
Self-supervised learning with novel-view synthesis. Feed-forward 3D models recover geometry
directly from a set of images, but they are trained against camera and depth targets that an offline
pipeline must produce first (Wang et al., 2024; 2025b; 2026b;c; Lin et al., 2025). A separate line
of work has instead learned geometry from images alone. Early methods predicted depth and ego-
motion from video and used warping between neighboring frames as supervision (Zhou et al., 2017;
Godard et al., 2019; Bian et al., 2019; Lai et al., 2021), which ties learning to short baselines and
pairwise constraints. RUST (Sajjadi et al., 2023) and RayZer (Jiang et al., 2025b) removed explicit
geometry altogether, encoding a scene into a latent set (Sajjadi et al., 2022) and rendering new
views with a learned decoder. Several methods extend this latent formulation to dynamic data and
predictive (extrapolative) objectives (Chen et al., 2026; Mitchel et al., 2026; Prestel et al., 2026).
Rendering in latent space minimizes inductive bias and lets the model learn freely from data, but it
also leaves the recovered geometry only loosely tied to physical structure.
Another line of work grounds the scene in 3D space and renders it by volume rendering or rasteriza-
tion, jointly predicting poses and a NeRF (Mildenhall et al., 2021) or Gaussian scene (Kerbl et al.,
2023) under photometric losses (Chen & Lee, 2023; Fu et al., 2023; Kang et al., 2025). Recently,
E-RayZer (Zhao et al., 2026) and NAS3R (Huang et al., 2026b) scaled explicit self-supervised recon-
struction to large transformers and data, yielding representations with stronger geometric ground-
ing. To prevent shortcuts and information leakage, both restrict how information moves between
the context and held-out views, E-RayZer by separating camera and geometry prediction into two
3

backbones, NAS3R by masking view interaction in its single backbone. The restriction keeps the
objective from collapsing, but at the cost of rich correspondence. We instead investigate where this
restriction should be placed, and find that the scene representation is a better location than the input.
Self-supervised representation alignment. Aligning intermediate features to an additional target
has become a common way to improve representation learning beyond what the task loss provides.
In generative modeling, REPA (Yu et al., 2024) and follow-up work (Wu et al., 2025; Shin et al.,
2026) align diffusion transformer features (Peebles & Xie, 2023) with a frozen vision foundation
model (Oquab et al., 2023), accelerating convergence and improving sample quality. Perception
models use the same idea, aligning task features with such encoders (Yang et al., 2024; Knaebel
et al., 2026) or distilling several of them into one (Ranzinger et al., 2024; Zhu et al., 2026).
On the other hand, recent work derives the target from the model itself, comparing its own repre-
sentations across different inputs or layers (Jiang et al., 2025a; Chefer et al., 2026). SelfEvo (Huang
et al., 2026a) brings this to 3D, distilling a dense-context teacher into a sparse-context student,
though it starts from a supervised model and aligns the two branches through their predicted depth.
We exploit the same sparse-dense gap without 3D-supervised initialization, aligning features jointly
with the main rendering objective during training. We also align them with a frozen vision encoder,
providing complementary internal and external signals without geometric annotations.

Controlled comparison. We compare three placements of asymmetry. All variants share a visual
encoder (Yang et al., 2026) followed by a 12-layer transformer (Vaswani et al., 2017) with alternating
view-wise and global attention (Wang et al., 2025b). The full-view variant (ours) and the masked-
attention variant predict cameras and Gaussians from this backbone. The separate-branch variant
follows E-RayZer, predicting cameras from the backbone and Gaussians from a second 12-layer
transformer, which gives it more capacity. All variants are trained on DL3DV (Ling et al., 2024) for
100K iterations with the same data, view sampling, and optimization settings, with the number of
views varying across training batches. At evaluation, we fix the frame span at 48 frames, so fewer
views provide sparser coverage of the same scene (Fig. 4). Despite having less capacity than the
separate-branch variant, the full-view variant achieves the most accurate depth and pose at every
view count. Placing the asymmetry in the 3D representation rather than on interaction between
views lets every view contribute correspondence while still blocking the self-reconstruction path.

3.3
BEYOND RENDERING SIGNALS
Learning from context asymmetry. The preceding analysis shows that geometry estimates become
less accurate as the view set becomes sparser. Dense and sparse predictions come from the same net-
work on the same scene, so the gap reflects only what the extra views contribute, and this asymmetry
can serve as a learning signal. SelfEvo (Huang et al., 2026a) turns this gap into supervision for a
pretrained 3D foundation model (Wang et al., 2025b; 2026c), using the outputs of a dense-context
teacher, maintained as an EMA of the model, as pseudo labels for a sparse-context student.
We build on this idea with one key difference. Our model is trained entirely through self-supervision,
with no 3D supervision to anchor its predictions. In this setting, depth predicted from different
view sets shares no common scale, and the dense-context depth can itself be unreliable. In our
experiments, distilling it directly degrades geometry even with a scale-invariant loss. We therefore

3.4
TRAINING OBJECTIVES
Our model is trained with three signals. The rendering loss defines the self-supervised task, asym-
metric context alignment transfers dense-context features to sparse inputs, and semantic guidance
injects a prior from a frozen foundation model. The total objective is
L = Lnvs + λalignLalign + λsemLsem,
(5)
where Lnvs combines an L2 and a perceptual loss (Chen & Koltun, 2017), and the λ terms balance
the auxiliary losses against it. We set λalign = 0.1 and λsem = 0.2. Since the dense-context features
are only meaningful once rendering has shaped them, Lalign is introduced at 40% of training and
ramped to full weight by 60%.

EXPERIMENTS
Implementation details. Our model uses a pretrained Pixio (base) visual encoder (Yang et al.,
2026) followed by a 12-layer multi-view transformer with an alternating attention pattern, a feature
6


Preprint
dimension of 768, and a 16×16 patch size. All experiments use this same backbone, which predicts
both cameras and Gaussians. The camera head regresses each pose relative to the middle input
view and predicts one set of intrinsics shared across the scene. A DPT head (Ranftl et al., 2021;
Wang et al., 2026b) predicts per-pixel Gaussian attributes, which are lifted to 3D with the predicted
cameras. The scene is built from context-view Gaussians only, and target views are rendered at their
predicted poses by differentiable rasterization (Kerbl et al., 2023). Asymmetric context alignment
uses the four transformer layers read by the DPT head, and semantic guidance uses the encoder
output. Sparse subsets are formed by symmetrically dropping views on either side of the reference
view, and the dense branch is an EMA copy of the online network with momentum 0.999.
Datasets.
We train separate models on RealEstate10K (RE10K) (Zhou et al., 2018) and
DL3DV (Ling et al., 2024), with images resized to 256 × 256. ScanNetv2 (Dai et al., 2017) and
NRGBD (Azinovi´c et al., 2022) are used only for out-of-domain evaluation.
Evaluation. We use publicly released baseline checkpoints and follow their evaluation settings. On
RE10K, we adopt the view indices of SPFSplat (Huang & Mikolajczyk, 2025), and on DL3DV,
we follow E-RayZer (Zhao et al., 2026) and sample 10 views across a 96-frame span. For out-of-
domain evaluation, we sample 10 views at a fixed stride, spanning 64 frames on ScanNetv2 and 256
on NRGBD. We report camera pose and depth, the two geometric quantities of interest. Camera
pose is measured by relative pose accuracy (RPA) at several angular thresholds and by AUC@30.
Depth is measured by AbsRel and threshold accuracy δ < 1.25k after independent per-view median
alignment against ground-truth depth. Since DL3DV provides no ground-truth depth, our controlled
analyses on DL3DV use MoGe-2 (Wang et al., 2025c) predictions as pseudo ground truth. Multi-
view depth is predicted from the full input set, and single-view depth from each image alone.
Depth conversion. All depth metrics use planar z-depth. Our model and E-RayZer predict depth r
along each unit ray (Eq. 2), which we convert as z = r/∥ˆK−1u∥using the predicted intrinsics ˆK,
so focal-length errors are reflected in the depth metrics. For NAS3R, we use the z-depth from its
depth head. For SPFSplat, we transform its canonical point map into each view with the predicted
pose and take the z coordinate.

DISCUSSION
Design motivation. Prior pose-free methods restrict how held-out views enter the backbone, either
by excluding them from geometry prediction or by preventing context views from attending to them.
This choice is natural when rendering quality is the goal, since observing a held-out view could
reveal what the model is asked to render. Our goal is geometry, with view synthesis serving only as
the training signal. We keep the context and held-out split, but apply it to the 3D scene, so a held-out
view is never rendered from its own prediction while still contributing correspondence in the shared
backbone. For this reason, rendering metrics are not our primary basis of comparison.
All designs receive the same images during training and differ only in how they use them. In re-
stricted designs, held-out views cannot inform the context-view predictions from which the scene
is built. In ours, every view informs every other. The gain therefore comes not from more data but
from using the same views more effectively.
Conclusion and future work. We study self-supervised geometry learning with rendering as the
training objective and geometric accuracy as the outcome. Our central finding is that the asymmetry
needed for self-supervision belongs in the 3D representation rather than in the network. Building on
this, aligning sparse-context features with dense-context features turns view density into a further
learning signal, and aligning with a frozen vision foundation model adds a semantic prior that pixels
alone do not provide. Together, these choices form a simple design that improves camera pose and
depth without geometric annotations.
A key opportunity is to learn from visual data beyond annotation pipelines. Much of this data is casu-
ally captured monocular video, where the scene itself changes between frames, while our framework
assumes a static scene. Our preliminary experiment suggests that the static model already tolerates
some motion by assigning low opacity to moving content, which improves camera pose estimation
on dynamic videos. This does not model motion, however, and moving objects are simply left out
of the reconstruction. A natural next step can be an explicit dynamic representation that separates
object motion from camera motion, either with Gaussians that move over time (Wu et al., 2024; Xu
et al., 2025) or with a separate reconstruction at each timestep in a bullet-time formulation (Liang
et al., 2024). Such a representation offers a path toward self-supervised geometry learning from the
far larger supply of monocular video.

A.1
ADDITIONAL DETAILS
Training details. We train the main model for 100K iterations on RE10K (Zhou et al., 2018) and
140K iterations on DL3DV (Ling et al., 2024) on 8 NVIDIA B200 GPUs. The analysis variants
are trained for 100K iterations on DL3DV on 2 NVIDIA RTX A6000 GPUs. Images are resized to
256 × 256 and tokenized with a patch size of 16, giving 256 tokens per view. Each batch uses a
single view count from {5, 7, 9, 11}, split into (N+1)/2 context and (N−1)/2 target views, with
per-device batch sizes of {24, 20, 16, 12} to keep the number of tokens per step roughly constant.
Following RayZer (Jiang et al., 2025b), we widen the frame span from which views are sampled
over the first 80K iterations, moving from shorter to longer baselines, and keep it fixed afterward.
The span grows from 24–96 to 48–192 frames on RE10K, from 24–48 to 32–54 on DL3DV, and
from 24–32 to 32–48 for the analysis variants. We use AdamW (Loshchilov & Hutter, 2017) with
β1 = 0.9, β2 = 0.95, and weight decay 0.05, together with a cosine schedule and 3000 warm-up
steps. The learning rate is 2 × 10−4 for the main model and 1 × 10−4 for the analysis variants.
Training uses bf16 and FlashAttention-2 (Dao, 2024), with gradients clipped to a norm of 1.0.
Evaluation details.
We evaluate on 5,601 RE10K scenes (Zhou et al., 2018), 140 DL3DV
scenes (Ling et al., 2024), 9 NRGBD scenes (Azinovi´c et al., 2022), and 97 ScanNetv2 scenes (Dai
et al., 2017). We evaluate SPFSplat and NAS3R with their official evaluation code, which applies no
masking at test time. In this comparison, depth is predicted and scored on all input views for both
the baselines and our model. For E-RayZer, poses are estimated from all images and depth from the
context views only. Accordingly, when comparing with E-RayZer, our DPT head decodes only the
context views, and depth is scored on the same context views for both methods.
Architecture. Fig. 12 illustrates the pipeline. A visual encoder tokenizes each view, and a learnable
camera token is prepended to its patch tokens. Tokens from both context (C) and held-out (H) views
enter a unified estimator with alternating view-wise and global attention, so every view can interact
with every other. The resulting patch tokens feed a DPT head (Ranftl et al., 2021), which reads
four intermediate estimator layers to predict per-pixel depth and the remaining Gaussian attributes.
The camera tokens feed a relative pose head, which regresses each pose relative to the middle input
view. Context-view depths are unprojected with the predicted cameras to form the Gaussian scene,
which is then rendered at the predicted held-out poses. Since the asymmetry is imposed in the 3D
representation, attention in the estimator remains unrestricted.

Semantic guidance. Tab. 8 isolates the effect of aligning encoder features with a frozen vision foun-
dation model. We use either Pixio (Yang et al., 2026), a masked autoencoder, or DINOv3 (Sim´eoni
et al., 2025), each serving both to initialize the encoder and as the frozen model. Pretrained initial-
ization already matters substantially, as training from random initialization lowers every metric by a
wide margin. Semantic guidance improves on this for both encoders, even though the encoder starts
from the same pretrained weights it is aligned to. The largest gain is in camera pose, particularly at
strict thresholds, and depth improves as well. This suggests that initialization alone does not retain
the pretrained prior under the rendering loss, and that keeping it as a training signal helps preserve it.
Adding a projection before the alignment performs similarly, so we use the version without it. Pixio
yields clearly better pose than DINOv3 at comparable depth, and we use it in all other experiments.

Combining the two signals. Tab. 11 adds asymmetric context alignment and semantic guidance
to the self-supervised baseline, separately and together. Each signal improves every metric over
the baseline, but to different degrees. Semantic guidance gives the larger gain on most metrics,
especially camera pose at strict thresholds, whereas the gains of asymmetric feature alignment con-
centrate in single-view depth, consistent with its role of transferring dense-context features to sparse
inputs. The two are complementary. Enabling both yields the more accurate camera pose and the
best single-view depth. Multi-view depth remains on par with semantic guidance alone, so asym-
metric feature alignment adds its benefit in pose and in depth from sparse context rather than in
dense multi-view setting. Fig. 15 shows per-view pose evaulation results.

More evaluation on dynamic videos. We also evaluate the two models from the dynamic-video
experiment, one trained on DL3DV only and one on DL3DV with SpatialVID, on ORBIT (Sabour
et al., 2026). Neither model is trained on this benchmark. ORBIT renders perspective views from
360◦videos along virtual camera trajectories and provides ground-truth camera poses. Many clips
also contain moving people and objects. We used 44 clips, which come from 21 video segments of
16 YouTube videos and have 203 to 1,024 frames each. We split each clip into consecutive, non-
overlapping windows of S frames, keep only windows that fit entirely within the clip, and evaluate
each window as a separate sample. From each window we sample 10 views evenly and pass all of
them to the model. This gives 330 windows for S=64 and 220 for S=96.
Training with SpatialVID improves pose accuracy at both spans and at every threshold (Tab. 13).
Fig. 16 shows example trajectories. The model trained on DL3DV only drifts on scenes with moving
people, while the model trained with SpatialVID stays close to the ground truth. Accuracy at the
strictest thresholds are low for both, showing that the large rotations in ORBIT remain challenging.
