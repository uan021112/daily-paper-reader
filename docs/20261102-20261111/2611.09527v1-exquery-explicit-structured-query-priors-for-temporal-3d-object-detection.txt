Abstract 

Sparse query-based 3D detectors commonly encode heterogeneous semantic, geo-metric, and motion information into unified latent queries, including when explicit 3D anchors are used. We introduce ExQuery, an explicit structured query framework for temporal 3D object detection. Each decoded query is organized into a shared semantic-context slice and physical-state-specific slices for center, dimensions, orientation, and velocity. This structure is preserved from prior encoding to branch-specific regression and is reused to reconstruct temporal queries: predicted physical states are transformed by ego motion, classification scores form soft semantic priors, and the reconstructed query is fused with the stored latent instance feature through gated affine modulation. Experiments on the nuScenes benchmark show that our method achieves competitive detection performance, and ablation studies validate the effectiveness of our proposed modules. 

# 1 Introduction 

3D object detection is a fundamental component of autonomous-driving perception, provid-ing the object category, position, dimensions, orientation, and velocity required by down-stream tasks. With the rapid progress of query-based end-to-end detectors since DETR [2], vision-based BEV (bird’s-eye view) 3D object detection has also advanced significantly. Transformer-based [33] view transformation avoids hand-designed post-processing and of-fers a clean formulation for multi-view reasoning. DETR3D [38] directly manipulates sparse 3D object queries, PETR [26] encodes 3D coordinates into position-aware representations, and PETRv2 [27] introduces temporal image-feature fusion. BEVFormer [20] instead learns dense BEV queries with spatiotemporal Transformers. More recently, StreamPETR [35] and Sparse4D [22, 23] have demonstrated the efficiency of instance-centric temporal propa-gation.

Despite this progress, the role of explicit query priors in 3D detection remains less sys-tematically explored than in 2D DETR-style detectors. In 2D detection, query design has evolved from purely learned embeddings to more explicit formulations, such as reference points, dynamic anchor boxes, and anchor boxes with denoising [16, 25, 41]. These de-signs provide strong geometric guidance for the model and improve detection performance. However, directly extending this explicit-prior paradigm to 3D detection is nontrivial. A 3D object query must represent heterogeneous information, including category, center, dimen-sions, orientation, velocity, and temporal context. Naively encoding these physical states into a single query space may entangle semantic, geometric, and motion-related factors, making it difficult for different prediction branches to exploit the corresponding physical priors ef-fectively. Existing 3D detectors have introduced explicit spatial priors such as 3D centers and full 3D anchors. Building on these explicit query representations and instance-centric temporal propagation, our contribution is to preserve an attribute-aligned channel structure in the de-coded query and reuse the same structure for temporal reconstruction and branch-specific regression. This organization is maintained in the decoded query itself, providing a consis-tent representation for constructing and reading out semantic, geometric, and motion states. These observations motivate a query formulation that not only introduces explicit priors, but also preserves their structure after decoding. Simply encoding richer physical priors into a query does not guarantee that the resulting representation remains organized, since semantic, geometric, and motion-related cues may still be mixed in a single latent space. In this work, we propose ExQuery, an explicit structured query framework for sparse query-based 3D object detection. Instead of representing each object query as an undif-ferentiated vector, we decompose it into a shared semantic-context component and several physical-state-specific components, including center, dimensions, orientation, and velocity. As illustrated in Fig. 1, this formulation differs from conventional learned queries and prior-encoded queries by maintaining a structured query state after decoding. The shared com-ponent preserves category-related, contextual, and residual implicit cues, while the phys-ical components provide attribute-aligned subspaces for explicit object states. Based on this structured query state, we further make explicit priors compatible with instance-centric SUN ET AL.: EXQUERY 3

temporal propagation. For stored predictions from previous frames, the physical states are transformed to the current ego frame according to ego-motion, while semantic-context priors are constructed from classification scores. The resulting explicit query is then fused with the stored implicit instance feature through mutual gated affine modulation. In this way, we can maintain a structured propagated query that explicitly carries physical information while still benefiting from contextual latent cues. The main contributions of this work are as follows: • We propose a structured query formulation that organizes each query into a shared semantic-context component and several explicit physical components. This provides attribute-aligned inputs for branch-specific regression. • We introduce an explicit temporal propagation mechanism built on the structured query state, so that propagated queries preserve physical interpretability together with semantic cues across frames. The resulting semantic interface also supports label em-beddings during denoising training. • Experiments on the nuScenes benchmark show that the proposed method achieves competitive detection performance and validate the effectiveness of structured query modeling for temporal 3D detection. 

# 2 Related Work 

2.1 Camera-based 3D Object Detection 

Camera-based 3D object detection has developed along several major lines. Early image-centric methods, such as FCOS3D [36] and SMOKE [28], directly predict 3D attributes from perspective-view (PV) image features without constructing an explicit BEV represen-tation. While simple and efficient, they are limited by weak multi-view geometric reasoning and less explicit 3D spatial modeling. Subsequent works on multi-view 3D object detec-tion [9, 10, 17, 18, 32] construct BEV features from images through view transformation with depth estimation. But the dense depth lifting limits the accuracy, temporal modeling, and robustness. Beyond depth-based view transformation, another branch performs BEV reasoning with dense BEV queries using Transformers [13, 20, 40], eliminating vulnerable depth estimation while making spatiotemporal modeling more natural. In parallel, sparse query-based detectors [3, 24, 26, 27, 34, 38] have become increasingly attractive due to their object-centric sparse representation and end-to-end detection formulation. Unlike methods that explicitly construct dense BEV queries over the entire scene, they maintain a compact set of sparse object queries, reducing computation on empty BEV regions and improving scalability for multi-view 3D detection. 

2.2 Temporal Modeling for Multi-View 3D Detection 

Temporal information has been incorporated into camera-only 3D detection in several ways. One line performs temporal fusion in the perspective-view or image domain, where histori-cal image features are aligned and aggregated across frames [27, 31]. Another line performs temporal fusion in BEV space [9, 20, 40]. These methods benefit from explicit spatial align-ment in BEV space, but they also inherit the computation cost of dense BEV representations. 4 SUN ET AL.: EXQUERY 

OPEN [8] performs temporal aggregation inside an object-wise depth encoder and injects the resulting object-wise position embedding into the decoder. In sparse query-based detec-tion, StreamPETR [35] and QTNet [7] propagate or fuse latent query features using motion-aligned center priors, while Sparse4Dv2 [22] recurrently propagates a latent instance feature together with a full 3D anchor. Compared with image-history or dense BEV-history fusion, instance-centric temporal propagation is particularly attractive for online perception because it preserves the efficiency of sparse detectors. Inspired by the instance-centric propagation of StreamPETR and Sparse4Dv2, our temporal design re-encodes the ego-motion-aligned physical state and score-weighted semantic prior into the structured channel layout used by the decoder and regression heads, then combines it with the stored instance feature through gated fusion. Similarly, LiDAR-based methods employ motion-aware temporal fusion: MG-TANet aligns and aggregates motion-guided BEV features [14], whereas MSF propagates motion-aligned proposals and fuses their proposal features [4]. These methods operate on different input modalities and representation granularities, but provide complementary con-text for motion-aware temporal modeling. 

2.3 Query Formulation 

Query design in DETR-style detection has gradually evolved from learned queries [2, 44] to more explicit spatial priors [25, 30, 37] such as center points or anchor boxes. These designs show that explicit query priors can provide useful geometric guidance for decoder attention and box regression. Denoising-based methods [16, 41] further improve optimiza-tion by injecting noised label and box queries during training. In 3D object detection, query formulation has evolved less uniformly. Early Transformer-based methods [20, 38] largely follow learned-query formulations, while later sparse-query detectors introduce explicit pri-ors through learnable 3D center points [26, 27, 34, 35], richer 3D anchor boxes [22, 23], or 2D-guided query generation [11, 12, 39]. Compared with 2D detection, a 3D query must rep-resent more heterogeneous information, including semantic cues, physical states, and context information. Encoding them into a single query space may entangle different information, making explicit query-prior design in 3D nontrivial. Related decoupling strategies have been explored in both 2D and 3D detection. In 2D DETR literature, classification and localization decoupling has been studied to reduce interference between semantic and spatial information [6, 42]. In 3D detection, Sparse4D v3 [23] adopts decoupled attention to alleviate feature interference between anchor embeddings and instance features. Our work focuses on a struc-tured decoded query with a shared semantic-context component and physical-state-specific components for different box attributes, and preserves this organization from prior encoding through temporal reconstruction to branch-specific regression.

3.2 Structured Query State 

Instead of representing each object query as an undifferentiated latent vector, we model it as a structured query state. Specifically, the feature channels are divided into a shared semantic-context slice and several physical-state-specific slices: 

q = [ qs | qc | qd | qo | qv] , (2) where qs denotes the shared semantic-context slice, and qc, qd , qo, and qv correspond to center, dimensions, orientation, and velocity, respectively. The shared slice preserves im-plicit cues such as semantic, contextual, and temporal information, while the physical slices are aligned with explicit object states. This design provides attribute-aligned subspaces for temporal propagation and regression. Given the 3D anchor state defined in Sec. 3.1, the query encoder maps its semantic and physical priors into the query feature space. The semantic prior is a learnable embedding for standard matching queries and is replaced by a propagated semantic-context prior for temporal queries. Center and dimensions are encoded with sinusoidal positional encodings followed by lightweight projections. For orientation and velocity, we use a complex-valued positional encoding (CPE) to preserve their directional structure. # 4 Experiments 

4.1 Dataset and Metrics 

We conduct experiments on the nuScenes dataset [1], a large-scale autonomous driving benchmark containing 1000 driving scenes of approximately 20 seconds each. The dataset is officially split into 700 scenes for training, 150 scenes for validation, and 150 scenes for testing. We train our models on the training set and report results on the validation set. We evaluate our method with the official nuScenes 3D detection metrics, including mean Average Precision (mAP), nuScenes Detection Score (NDS), and five true-positive error met-rics: mean Average Translation Error (mATE), mean Average Scale Error (mASE), mean Average Orientation Error (mAOE), mean Average Velocity Error (mAVE), and mean Aver-age Attribute Error (mAAE). The mAP is computed based on center-distance matching on the ground plane, while NDS summarizes both detection accuracy and box quality. Higher mAP and NDS indicate better performance, whereas lower true-positive errors indicate more accurate localization, scale, orientation, velocity, and attribute estimation.

# 5 Conclusion and Limitations 

We presented ExQuery, which preserves a shared/physical channel organization in 3D object queries from explicit prior encoding to temporal reconstruction and branch-specific regres-sion. Experiments show competitive detection performance, while the ablations support the complementary roles of structured queries, explicit priors, and gated fusion. Despite these encouraging results, several directions remain open for further exploration. In our current design, the shared semantic-context slice is intentionally used by all prediction branches, allowing physical prediction to benefit from contextual cues. The added query en-coders and fusion module also introduce a measurable latency cost. A deeper understanding of what information is involved in the query, and how to further encourage attribute-specific specialization without losing useful contextual interaction, remains an important direction for future work. We hope this work can encourage further study of explicit, structured, and controllable query representations for 3D perception.
