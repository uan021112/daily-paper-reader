Abstract — Generative world modeling from large-scale visual data offers a promising path toward scalable robot manipu-lation. This calls for an intermediate representation that can be supervised at scale and remains actionable for downstream control. We propose 3D full-object flow, an object-centric mo-tion representation that assigns dense 3D trajectories to points across the complete surface of a target object, including its occluded regions. By extending visible-surface object flow to the full object geometry, this representation makes complete object motion explicit and applies uniformly to both rigid and de-formable objects. To realize the potential of this representation at scale, we introduce a 1210-hour full-object flow dataset that addresses the scarcity of large-scale supervision for complete 3D object motion. The dataset integrates diverse real-world videos and physical simulations, with a scalable annotation pipeline for recovering full-object motion from real-world observations and quality metrics for systematically assessing annotation quality. We then train a world model that takes an image and a task description as input and predicts dense full-object flow over the reconstructed object geometry. Experiments show reliable annotation quality, data-scalable flow prediction, and effective downstream manipulation across novel scenes and robot embodiments. I. I NTRODUCTION 

Recent progress in robot foundation models and vision-language-action (VLA) models suggests that robotic manip-ulation can benefit substantially from scale [1]–[3]. How-ever, action-labeled robot data remain costly to collect, embodiment-dependent, and far less abundant than visual data [3], [4]. Generative world models therefore offer a promising path beyond direct action supervision by learning how objects and scenes evolve from visual experience [5]– [9]. Connecting these predictions to robot execution requires an intermediate representation that is both scalable to learn and actionable for downstream control [9], [10]. Prior representations each capture useful structure but expose trade-offs. Pixel-space predictions, such as goal im-ages [11] or videos [8], preserve rich visual information, but they are indirect for control and typically require an additional grounding step. Sparse keypoint or point-based interfaces represent manipulation objectives using landmarks or affordance points [12], [13], but may miss the complete object motion. 6-DoF object poses offer metrically grounded state descriptions, but they rely on rigid-body assumptions and cannot capture non-rigid deformations [14], [15]. Recent flow-based interfaces use object flow as an intermediate arXiv:2611.11085v1 [cs.RO] 8 Nov 2026 representation for manipulation [16]–[18]. However, they mainly model motion over visible or tracked object regions, leaving unobserved surfaces outside the motion field. We refer to object flow over visible regions as partial object flow. To make object motion complete and actionable, we intro-duce 3D full-object flow, which specifies dense trajectories over the complete target-object surface as an explicit motion target for robot execution. Utilizing the reconstructed geom-etry of a target object, this representation maps dense tra-jectories over the entire object surface across time. It makes complete object motion explicit in a unified 3D geometry, while remaining grounded in object kinematics rather than robot-specific actions. The resulting dense correspondence can describe rigid motion and non-rigid deformation, and provides an object-level motion target that downstream con-trollers can optimize against. A key obstacle to adopting and scaling this complete rep-resentation is the scarcity of high-quality training data [19]– [21]. While numerous large-scale human video datasets and robotic trajectory collections exist [3], [4], [22], [23], their supervision signals are predominantly limited to semantic action labels, sparse 2D tracking, or robot-specific propri-oception. They lack the dense, unified 3D full-object flow annotations required to supervise a generalizable object-centric world model across diverse tasks and scenes. In this work, we address both the representation choice and the supervision bottleneck. We construct a 1210.1-hour 3D full-object flow dataset from diverse real-world videos and physical simulation. To build the real-world portion at scale, we introduce an automatic annotation pipeline that converts in-the-wild manipulation videos into 3D full-object flow, and we systematically assess the quality of the resulting annota-tions. On top of this dataset, we develop an object-centric world model framework that takes an image and a task description, reconstructs the initial geometry of the target object, and generates dense trajectories over the full object surface with a flow generator. The generated full-object flow is then consumed by a lightweight optimization-based execution module that translates object motion into end-effector trajectories. Experiments validate the full pipeline from annotation to downstream execution, demonstrating reliable flow supervision, improved prediction through data scaling and model design, and effective robot manipulation with transfer across environments and embodiments. 

Contributions. (i) We formulate 3D full-object flow as an object-centric interface between generative world models and downstream robot execution. (ii) We provide a 1210.1-hour 3D full-object flow dataset built from diverse real-world videos and physical simulation, together with a scalable annotation pipeline and quality assessment for the generated annotations. (iii) We develop an object-centric world model framework that predicts dense full-object trajectories from image-and-language inputs. (iv) We conduct extensive exper-iments across annotation, data-scale, prediction, and execu-tion, showing effective robot manipulation and generalization to novel scenes and embodiments. II. R ELATED WORKS 

A. World Models for Robotic Manipulation 

World models have been increasingly used in robotic manipulation to predict future states or intermediate repre-sentations for planning and control [5], [9], [10]. A common strategy is to use intermediate representations less tied to a specific action space or embodiment, such as future im-ages [11], videos [8], or keypoints [12], [13]. These abstrac-tions can improve transfer across tasks and embodiments, but are often indirect for control or sparse in object coverage. Recent work has begun to model object motion more directly. Pose-based methods use 6-DoF object poses to represent future object states or task goals [14], [15], [24], providing metric structure for rigid-object manipu-lation but not naturally capturing non-rigid deformation. Im2Flow2Act [16] uses 2D object flow over tracked image points, Dream2Flow [17] and NovaFlow [18] derive object-centric 3D flow from masked tracked points in generated videos, and PointWorld [6] predicts action-conditioned full-scene 3D point flow from RGB-D observations and robot actions. These works demonstrate the value of flow-based interfaces, while their prediction targets are typically de-fined on image tracks, masked visible regions, or partially observed scene geometry. Our work predicts full-surface 3D trajectories over a reconstructed complete target object for downstream optimization. 

B. Datasets and Scalable Supervision for 3D Object Flow 

Scalable supervised learning of dense object-centric 3D motion prediction benefits from large-scale 3D motion an-notations, yet such supervision remains limited in real-world data [6], [19], [21]. Large video datasets [4], [22], [25], [26] provide coverage of human-object interaction, but their annotations do not provide dense 3D trajectories of manip-ulated objects. Datasets with richer 3D annotations, such as HOI4D [27], DexYCB [28], ARCTIC [29], and HOT3D [30], provide object poses, meshes, contacts, or tracking signals. However, their reliance on curated capture setups, markers, or labor-intensive annotation limits their scalability for dense object-flow supervision. Large robot datasets, such as Open X-Embodiment [3], DROID [23], and AgiBot World [31], further scale real-world manipulation data, but they primar-ily provide robot observation-action trajectories rather than unified 3D full object flow annotations. To address this gap, we build a scalable annotation pipeline that converts heterogeneous real-world videos into 3D full object flow supervision, emphasizing dense target object motion rather than action labels, sparse poses, or robot-specific trajectories. B. Dataset Curation and Pipeline 1) Annotation of Real-World Videos: To enable scalable supervision, we build an annotation pipeline that converts heterogeneous in-the-wild videos into 3D full-object flow, as illustrated in Fig. 2. The pipeline does not require robot actions, depth measurements, calibrated cameras, or pre-scanned object meshes. It first uses Gemini 2.5 Pro [32] as a Vision-Language Model (VLM) to identify the target object, generate a task description, and segment each raw video into atomic manipulation clips, each corresponding to a single contact-and-separation interaction between the actor and the target object. For each clip, we use Track4World [33] with its Depth Anything 3 (DA3) backbone [34] to estimate camera poses and reconstruct per-frame point clouds in a common coordinate system anchored to the first-frame camera. We then localize the target object using VLM-based object proposals followed by SeC [35] for mask propagation. Given the propagated target masks, SAM 3D [36] reconstructs the complete object mesh, Any6D [37] estimates its initial pose, and FoundationPose [38] tracks its pose throughout the clip. To obtain full-object flow, we uniformly sample points from the reconstructed mesh in its canonical object frame and, at each timestep, transform them by composing the tracked object pose with the corresponding camera-to-reference transformation recovered by Track4World. The re-sulting dense trajectories, expressed in the first-frame camera coordinate system, constitute the full-object flow Pobj 1: T .

2) Data Filtering: To filter low-quality annotations, we evaluate the spatial and temporal consistency of the estimated object motion. At each frame, we project the reconstructed object under its estimated pose into the image plane and compute the IoU between the projected object region and the propagated target mask. We aggregate the IoU scores over the clip to identify annotations with unstable pose tracking. We manually curate a validation set of expert-labeled examples to calibrate the filtering criterion. We evaluate the consistency metric on this set and select a threshold that achieves high precision while retaining sufficient coverage according to the expert labels. We then apply the threshold across the dataset to remove low-quality annotations. 

3) Dataset Composition: Our dataset comprises 1,210.1 hours of manipulation data measured at a standardized 16 FPS: 454.5 hours of simulated trajectories and 755.6 hours of automatically annotated real-world videos. For the simulation subset, we aggregate 198,947 trajec-tories spanning 251 tasks from seven datasets: ManiSkill 3 [41], MetaFold [42], Meta-World [43], MIKASA [44], RLBench [45], RoboCasa [46], and RoboTwin 2.0 [47]. C. Full-Object Flow Prediction 

Given an initial observation and a task instruction, we pre-dict the future motion of the complete target-object surface, as illustrated in Fig. 3. Let Po ∈ RNo×3 denote the initial object surface and Ps ∈ RNs×3 the scene geometry. Our predictor outputs a dense displacement trajectory 

F = {∆Pot }Tt=1 ∈ RT ×No×3, (1) where each displacement is defined with respect to the initial object surface. This object-centric representation describes how the manipulated object evolves independently of the robot embodiment. 

a) Initial 3D observation construction: We construct an object-centric 3D observation from the first RGB-D frame. We first obtain the target-object mask using SAM2 [48] and reconstruct its complete geometry with SAM3D [36]. Any6D [37] estimates the initial object pose, which places the reconstructed mesh into the observed scene. We then sample points on the transformed mesh surface to obtain the complete object point set Po. In parallel, the scene point cloud Ps is obtained by back-projecting the observed depth map using the camera intrinsics. Thus, the model receives both a complete object-centric geometric representation and the observed scene geometry from the initial frame. 

b) Multimodal observation encoding: We encode se-mantic and geometric information through complementary visual-language and 3D pathways. A vision-language en-coder processes the initial RGB image together with the task instruction and produces task-conditioned visual features and language tokens. For each object point, we project its 3D co-ordinate into the image and sample the corresponding visual feature, providing a point-wise semantic representation. In parallel, we jointly encode the object and scene point clouds using Point Transformer V3 (PTv3) [40]. Joint 3D encoding allows the object representation to incorporate its surrounding geometric context. For each object point poi , we construct an object token by combining its spatial embed-ding, point-wise visual-language feature, and 3D feature:

d) Training with Heterogeneous Data: We train the flow predictor on heterogeneous simulated and real-world data, which introduces inconsistencies in coordinate orien-tation and temporal scale. To standardize orientation, we estimate gravity with GeoCalib [49] and rotate each scene such that the z-axis points opposite to gravity, applying the same transformation to both 3D points and object-flow trajectories. This normalization provides a consistent gravity-aligned coordinate frame across datasets, which is important because manipulation dynamics depend on gravity [24]. To normalize temporal scale, we uniformly resample each action segment into T frames, such that object flow represents spatial evolution over normalized action progress rather than absolute execution time.

We introduced 3D full-object flow as an object-centric interface between predictive world models and downstream robot execution. By assigning dense trajectories to the complete target-object surface, this representation captures both visible and occluded object motion while remaining independent of a specific robot embodiment. We further built a large-scale full-object flow dataset from real-world videos and simulation, and trained a world model that predicts complete object motion from image-and-language inputs. Experiments demonstrate reliable annotation quality, improved flow prediction with scalable data, and effective downstream manipulation across simulation and real-world settings. A. VLM-based Annotation and Action Segmentation 

Given a raw manipulation video, we use Gemini 2.5 Pro [32] to identify manipulation events and divide the video into atomic action clips. Each clip represents a single contact-and-separation interaction between the actor and the manipulated object. For each clip, the VLM outputs the target object category, a natural language task description L, and the temporal boundaries of the action. These annotations guide subsequent object-centric processing.

The module outputs per-frame depth estimates, camera intrinsics, camera poses, and temporally tracked scene points. We denote the camera coordinate system at time t by Ct

C. Target Object Segmentation 

Given the target object category from the VLM annota-tions and the RGB action clip, we localize the actively ma-nipulated object using a two-stage strategy. First, the VLM proposes and scores target-object bounding boxes across candidate frames. The highest-scoring proposal identifies the target instance. The explicit localization stage helps disambiguate the manipulated instance when multiple objects share the same category.

We further evaluate two architectural choices in our full-object flow predictor: visual-language conditioning and joint object-scene geometric encoding. All configurations are evaluated on the same fixed supplementary evaluation set, comprising 2,048 samples. Table X reports the mean endpoint error (EPE) and per-point accuracy at 5 cm and 10 cm thresholds. 

Visual-language conditioning. We examine the contribution of visual-language conditioning by removing both the visual features extracted by Qwen2.5-VL and the language-token context, leaving a predictor conditioned only on 3D object and scene geometry. As shown in Table X, this increases final-frame EPE by 4.21 cm and reduces Acc@10 by 20.5 percentage points. While 3D geometry provides spatial infor-mation, visual-language conditioning supplies complemen-tary semantic and task context for determining the intended object motion. The results highlight its importance for task-dependent full-object flow prediction. 

Joint object-scene geometric encoding. We further in-vestigate whether object and scene geometry should be encoded jointly or independently. Unlike the full model, the separate PTv3 variant processes object and scene point clouds independently before integrating their features in the decoder. Joint encoding achieves better overall prediction accuracy, reducing final-frame EPE from 13.46 to 12.69 cm and improving Acc@10 from 45.9% to 52.0%. This suggests that incorporating surrounding scene geometry during initial object feature extraction enables more effective object-scene interactions and improves full-object flow prediction.
