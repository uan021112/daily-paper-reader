## 摘要
前馈式 3D 基础模型能够从未标定姿态的图像中重建场景，但全局注意力的二次计算成本限制了其扩展至大型视图集合的能力。我们提出 Zebra3D，这是一种逐层稀疏线性混合注意力框架，无需从头训练即可提升预训练 3D 基础模型的效率。在 VGGT、HunyuanWorld-Mirror 和 $π^3$ 上，我们观察到一种普遍一致的深度方向模式：早期阶段对线性替换相对耐受，而较为敏感的中后期阶段往往表现出更集中的注意力。Zebra3D 利用这一结构，在耐受阶段采用以线性注意力为核心的机制，在敏感阶段采用分块稀疏注意力，并借助地标摘要保留未选中的上下文。闭式仿射拟合实现了无需训练的转换；可选的转换后训练则结合任务监督、输出蒸馏与关系特征蒸馏。在这三种骨干模型上，Zebra3D 在高注意力稀疏度下仍能实现出色的重建精度与相机位姿精度，且无需训练的版本与对应的稠密模型表现接近。端到端加速比随输入视图数量增加而提升，在 1,024 个视图时最高可达 $7.1\times$。经过转换后训练，Zebra3D-VGGT 在平均注意力稀疏度为 94\% 时，RealEstate10K 上的 AUC@30 达到 80.5\%，与使用相同数据和训练计划微调的稠密 VGGT 相差不超过 1.1 个百分点。

## Abstract
Feed-forward 3D foundation models reconstruct scenes from unposed images, but the quadratic cost of global attention limits their scalability to large view sets. We present Zebra3D, a layerwise sparse-linear hybrid attention framework that improves the efficiency of pretrained 3D foundation models without training from scratch. Across VGGT, HunyuanWorld-Mirror, and $π^3$, we observe a broadly consistent depth-wise pattern: early stages are relatively tolerant to linear replacement, while sensitive middle-to-late stages tend to exhibit more concentrated attention. Zebra3D exploits this structure by assigning linear-centered attention to tolerant stages and tile-sparse attention to sensitive stages, using landmark summaries to preserve unselected context. Closed-form affine fitting enables training-free conversion, while optional post-conversion training combines task supervision with output and relational feature distillation. Across all three backbones, Zebra3D achieves strong reconstruction and camera-pose accuracy at high attention sparsity, with training-free variants remaining close to their dense counterparts. End-to-end speedups increase with input view count, reaching up to $7.1\times$ at 1,024 views. After post-conversion training, Zebra3D-VGGT reaches 80.5\% RealEstate10K AUC@30 at 94\% mean attention sparsity, within 1.1 percentage points of dense VGGT fine-tuned on the same data and schedule.

# Zebra3D 论文总结

## 1. 核心问题与整体含义

- **研究问题**：前馈式三维重建模型可以从多张未标定、未定姿图像中直接预测场景几何与相机位姿，但其跨视图全局注意力的计算量随 token 数近似按平方增长。视图越多，推理成本越高，限制了模型处理长序列和大规模图像集合的能力。
- **研究动机**：已有加速方法常在整个网络中统一使用稀疏注意力、线性注意力或上下文压缩，但不同深度的预训练层对注意力近似的耐受程度并不相同。统一替换可能在某些层造成明显精度损失。
- **整体思路**：Zebra3D 不从头训练模型，而是分析预训练模型各全局注意力层的敏感性，再按层分配不同注意力机制：对线性化较耐受的层使用线性注意力，对敏感层保留选定区域的精确 softmax 注意力，并压缩未选区域的上下文。由此在尽量维持模型能力的同时降低长视图序列的计算成本。

## 2. 方法论：核心思想与关键技术

### 2.1 按层敏感度分配注意力类型

- 作者分别对 VGGT、HunyuanWorld-Mirror（HYWM）和 π³ 的全局注意力层进行分析。
- 具体做法是：每次只将一个全局注意力层替换为线性注意力，比较学生层输出与原始稠密模型输出的偏差，并综合点图、深度图、相机位姿等输出的偏差，得到该层的敏感度排序。
- 论文观察到一个跨模型的规律：**中间层通常更敏感，且注意力较集中；一些前段与后段层相对耐受线性近似，注意力分布也更分散。**
- 给定线性层比例 \(p\)，将敏感度较低的 \(pL\) 层分配给线性注意力，其余层采用分块稀疏注意力。各骨干模型分别计算层排序，而不是强行使用同一套层位安排。

### 2.2 线性中心注意力与闭式拟合

- 在被判定为“线性化耐受”的层中，保留预训练模型已有的 Q/K/V 投影、位置编码、归一化与输出投影，仅将 softmax 注意力替换为线性注意力。
- 论文使用通道维 softmax 特征映射，将注意力运算改写为先聚合键值、再对查询计算读出的形式，避免显式构造 \(N\times N\) 注意力矩阵，降低长序列上的计算成本。
- 为减少线性算子与原 softmax 输出之间的偏差，作者对注意力输出相对于 value 均值进行中心化，再施加仿射变换。直观上，value 均值作为稳定基线，仿射映射用于校正各 token 的残差信息。
- 仿射参数不是通过梯度训练获得，而是使用校准场景上的稠密教师输出与线性输出，逐层求解带正则项的最小二乘问题。因此该转换可以在**不进行梯度更新**的情况下完成。

### 2.3 分块稀疏注意力与地标摘要

- 对线性替换敏感的层，模型保留选定空间区域内的精确 softmax 交互。
- 每张图像的 patch token 被映射到二维网格，并划分为不重叠的 \(8\times8\) tile，每块包含最多 64 个 token。相比直接按展平序列切块，这样的分块对应图像中的连续空间区域。
- 对每个 query tile，根据其均值 query 与各 key tile 均值 key 的相似度选择高分 tile；被选中的 tile 保留 token 级精确注意力。
- 未选中的 tile 不会被直接丢弃，而是由其均值 key、均值 value 和 token 数构成一个**地标（landmark）摘要**。计算注意力时，地标与选中 token 在同一 softmax 归一化中参与竞争，并用 token 数校正摘要的权重，从而压缩但保留未选区域的全局上下文。
- 特殊 token 保持稠密访问，patch query 也保留自身 key。论文实现了 Triton 稀疏注意力内核，避免显式构造完整注意力矩阵。

### 2.4 可选的转换后蒸馏训练

- Zebra3D 转换后可以直接使用；作者也提供了可选的 3,000 步后训练。
- 训练目标包括：
  - 原任务的几何与相机监督；
  - 教师模型最终输出的蒸馏；
  - 中间特征的 \(L_1\) 匹配；
  - 同一视图内 token 特征的余弦对齐；
  - 跨视图 token 关系蒸馏，即匹配教师与学生特征之间的相似度关系。
- 蒸馏关系采用抽样方式，而非构造完整的跨视图关系矩阵，以控制训练开销。蒸馏权重在训练期间从 1.0 逐步降低至约 0.6。
- 蒸馏只增加训练时的教师前向计算，不增加推理时的计算。

### 2.5 配置记法

- 论文的 \(xL/yS\) 表示：约 \(x\) 比例的阶段采用线性注意力，其余稀疏阶段的注意力稀疏比例为 \(y\)。
- 例如，**0.5L/0.8S** 表示一半阶段线性化，另一些阶段仅保留约 20% 的 key tile 精确交互，其余由地标摘要表示。论文报告的整体平均注意力稀疏度还考虑了特殊 token、地标和其他保护项。

## 3. 实验设计、数据集与对比方法

### 3.1 模型与评测任务

- **骨干模型**：VGGT、HunyuanWorld-Mirror（HYWM）和 π³。
- **主要任务**：

### 3.2 数据集与场景

- **相机位姿**：RealEstate10K、CO3Dv2，主要使用十视图评测协议。

### 3.3 对比方法

- 原始稠密骨干模型，以及同训练数据和步数下微调的稠密 VGGT 控制组（VGGT + GT-FT）。
- 加速或高效注意力方法：FastVGGT、SAF3R、RegimeVGGT、Block Sparse 3D、Lite3R、A3D（AVGGT 的架构匹配实现）。
- 另在附录中与直接多视图重建模型 Fast3R、MUSt3R、Spann3R 比较。
- 作者对不支持某骨干的基线省略结果；对 A3D、Block Sparse 3D 等方法，在部分骨干上采用架构匹配移植实现，因此这些结果并非全部来自原论文发布的官方实现。

### 3.4 代表性结果

- 在约 **79% 平均注意力稀疏度**的训练免转换配置（0.5L/0.6S）下，RealEstate10K AUC@30 相对各自稠密骨干的差距约为：
  - VGGT：0.007；
  - HYWM：0.004；
  - π³：0.006。
- 训练免转换版本在 CO3Dv2 AUC@30 上，在论文评测的非稠密方法中分别对各骨干取得较好结果。
- 经后训练后，VGGT 的 0.7L/0.8S 配置在约 **94% 平均注意力稀疏度**下，RealEstate10K AUC@30 达到 0.805；与同数据、同训练计划微调的稠密 VGGT 相差约 1.1 个百分点。

- 宽基线实验显示，0.5L 配置整体比 0.7L 更稳健；尤其 π³ 在宽基线数据上采用 0.7L 时出现更明显的重建退化。

  4. 稀疏算子消融（SGA、块稀疏、tile 稀疏及是否使用地标）；
  5. 层位分配消融（敏感度引导、前/后段稀疏、均匀、反向和随机）；
  6. 蒸馏目标消融；
  7. 校准集变化下的层敏感度排序稳定性测试；
  8. 长序列速度—精度、宽基线迁移，以及与直接多视图模型的附加比较。
- **充分性判断**：对论文提出的核心主张——逐层分配优于统一替换、地标摘要有助于保留上下文、速度收益随视图数增加——实验提供了多种互补证据，整体较充分。尤其是在多个骨干和多种任务上重复观察到相似趋势，增加了结论可信度。
- **公平性方面的优点**：主要基线使用相同的数据加载、帧选择、对齐和指标代码；蒸馏模型与稠密 VGGT 控制组使用相同训练数据、训练步数和任务监督；推理计时在同一 MI355X 上对比，并说明了预热、测量次数和计时范围。
- **仍需谨慎之处**：
  - 部分基线是作者实现或架构匹配移植，可能与原论文官方实现存在差异；
  - 速度比较集中在 AMD MI355X 与 Triton 实现，不能直接推断其他 GPU 或推理栈上的收益；
  - 文中没有系统报告主结果的多随机种子方差、置信区间或显著性检验；
  - 不同方法的模型训练数据、实现成熟度和优化程度不一定完全等价，尽管论文设置了若干较公平的控制实验；
  - 主加速优势主要体现在长序列，短序列上的收益相对有限。

## 6. 主要结论与发现

- 预训练 3D 重建模型的全局注意力层在深度方向上并非同质：不同层对线性近似的敏感程度不同，敏感层往往具有更集中的注意力。
- 因此，**耐受层线性化、敏感层稀疏化**，比在所有层统一使用同一种近似更有效。固定预算的层位消融显示，敏感度引导分配在三种骨干上优于均匀、随机及反向分配。
- 线性注意力的中心化与闭式仿射拟合有助于匹配稠密教师；稀疏注意力中，地标摘要能显著缓解直接丢弃未选上下文造成的性能损失。
- 训练免转换已经能在较高稀疏度下接近稠密模型；后训练可进一步改善部分任务和配置，但收益依赖骨干与数据集，并非所有指标都会提升。
- Zebra3D 的效率优势随视图数上升而扩大；对长序列而言，可在较高加速比与较好几何重建质量之间提供可调折衷。
- 宽基线结果提示，视频式连续视图上的结论不能无条件外推到大基线采集场景；较保守的 0.5L 配置通常更可靠。

## 7. 优点与亮点

- **针对预训练模型内部差异进行设计**：不是只选择一种通用加速算子，而是先测量层敏感度，再按层分配计算机制。
- **无需从头训练**：闭式最小二乘拟合支持训练免转换，降低了将方法应用于已有模型的门槛。
- **兼顾细节与全局上下文**：tile 稀疏注意力保留空间连贯区域的精确交互，地标摘要则避免简单丢弃未选区域的信息。
- **跨骨干验证**：同一框架应用于 VGGT、HYWM 和 π³，且层分配可按模型调整。
- **评测维度多样**：不仅报告位姿和短序列几何，也包含 1,000 视图长序列、宽基线场景和端到端速度。
- **实现细节较充分**：论文说明了 Triton 内核、校准、训练目标、数据划分、评测协议与稀疏度计算方式，便于复现和审查。
- **明确区分转换与蒸馏的作用**：训练免转换证明方法本身可用，后训练则作为可选的精度恢复手段，而不是把全部收益归因于额外训练。

## 8. 不足与局限

- **层分配是固定的**：它基于单层替换产生的边际敏感度，不考虑多个层同时替换时的交互，也不根据具体输入动态调整。
- **校准与域迁移仍有限**：论文测试了多个校准集上的排序稳定性，但尚不足以证明该规律可推广到更广泛的架构、成像域或采集方式。
- **宽基线场景下激进配置有风险**：尤其 π³ 的 0.7L 配置在 Tanks and Temples、ETH3D 和 DTU 上出现明显退化，说明高稀疏度不一定适用于所有场景。
- **后训练可能造成任务间权衡**：VGGT 蒸馏训练改善 RealEstate10K 位姿指标，但部分 NRGBD 或 CO3Dv2 指标会下降；论文也观察到稠密模型控制组有类似变化，因此这更像训练数据适配带来的分布权衡，而非稀疏化独有的问题。
- **短序列加速有限**：视图较少时，全局注意力不是总运行时间的主要部分，图像编码器和预测头会限制端到端加速。
- **硬件与软件支持范围较窄**：优化内核和速度数据主要针对 Triton 与 AMD MI355X，其他加速器上的性能、移植成本和收益尚未验证。
- **训练成本信息不完整**：虽报告了 8 张 GPU 和 3,000 步训练，但没有训练墙钟时间、GPU 小时或能耗数据。
- **实验不确定性报告有限**：主结果缺少系统的多次运行统计与置信区间；在没有这些信息时，接近稠密模型的小幅差异应谨慎解读。
- **应用仍需安全与隐私考量**：三维重建可用于空间感知、AR/VR 等场景，也可能涉及隐私敏感或监控用途，应遵守数据授权、同意与相关法律要求。
