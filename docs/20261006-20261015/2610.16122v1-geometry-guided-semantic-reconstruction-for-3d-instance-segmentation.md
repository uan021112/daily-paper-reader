## 摘要
3D实例分割需要兼具几何结构性与语义判别性的表征。纯3D编码器能够较好地建模空间结构，但往往缺乏强大的外观语义；而通过拼接直接将2D先验提升至3D，虽能引入丰富语义，却无法确保这些语义与底层3D结构良好对齐。本文将这一问题表述为一种\textbf{掩码语义重建}任务，以实现从2D到3D的语义迁移。具体而言，我们对提升后的2D先验中的一部分背景区域进行掩码，并训练3D编码器恢复缺失的语义先验，从而为将丰富的2D语义蒸馏到3D骨干网络提供显式监督。我们进一步提出\textbf{几何调制语义注入}方法，在稀疏编码之前利用原始3D几何调制提升后的2D先验，使几何信息能够显式控制语义注入，并缓解2D语义特征与3D几何特征之间的分布差异。在两个基线框架上的实验表明，所提出的方法在ScanNetV2和ScanNet200的全数据与少样本设置下均取得了最先进的结果。代码已公开发布于https://github.com/yharoldsu0627/Geometry_Guided_Semantic_Reconstruction。

## Abstract
3D instance segmentation requires representations that are both geometrically structured and semantically discriminative. Pure 3D encoders model spatial structure well but often lack strong appearance semantics, while directly lifting 2D priors into 3D by concatenation injects rich semantics without ensuring that they align well with the underlying 3D structure. In this paper, we address this problem by formulating 2D-to-3D semantic transfer as a \textbf{masked semantic reconstruction} task. Specifically, we mask a subset of background lifted 2D priors and train the 3D encoder to recover the missing semantic priors, providing explicit supervision for distilling rich 2D semantics into the 3D backbone. We further propose \textbf{geometry-modulated semantic injection}, which uses raw 3D geometry to modulate lifted 2D priors before sparse encoding, so that geometry explicitly controls semantic injection and alleviates the distribution gap between 2D semantic features and 3D geometric features. Experiments on two baseline frameworks demonstrate that the proposed method achieves state-of-the-art results in both full-data and few-shot settings on ScanNetV2 and ScanNet200. Code is publicly available at https://github.com/yharoldsu0627/Geometry_Guided_Semantic_Reconstruction

## 1. 核心问题与整体含义

- **研究问题：**如何把二维图像模型提供的丰富语义有效融入三维点云实例分割，同时避免二维外观特征与三维几何结构不匹配？
- **研究动机：**
  - 纯三维编码器较擅长建模空间结构，但受限于三维标注规模，语义表征能力可能不足。
  - 将二维特征提升到三维后直接拼接，虽然增加了语义信息，却没有明确机制保证这些信息与三维结构对齐，也缺少促使编码器主动吸收二维语义的监督。
- **整体思路：**论文将二维到三维的语义迁移视为一种“掩码后再重建”的学习任务，并在编码前用三维几何调制二维语义特征。前者提供显式语义迁移监督，后者让几何信息参与控制语义注入。

## 2. 方法论

### 2.1 整体流程

- 输入多视角 RGB 图像与点云，使用预训练 **DINO-X** 提取图像特征，并通过相机投影将图像特征关联到可见三维点。
- 将点云划分为超点（superpoints），对同一超点内的二维特征求平均，得到超点级二维语义先验。
- 训练时随机遮蔽一部分**背景超点**的二维特征；保留未遮蔽特征作为输入，并保存原始特征作为重建目标。
- 用原始三维输入生成调制参数，调制二维特征后送入稀疏 3D U-Net 编码器。
- 编码器输出聚合回超点。一方面送入 DETR 风格查询解码器预测实例掩码；另一方面用于重建被遮蔽超点的二维语义特征。
- 重建分支只在训练期间使用，推理时移除。

### 2.2 几何调制语义注入

- 对每个三维体素的原始几何特征，通过共享的三层 MLP 预测缩放参数 \(\gamma\) 和偏置参数 \(\beta\)，再对对应二维语义特征执行仿射调制：
  \[
  v^{(2)} \leftarrow (1+\gamma)\odot v^{(2)}+\beta
  \]
- 因而，三维几何不是作为另一组特征被动拼接，而是明确参与改变二维语义特征的注入方式。作者认为，这有助于缓解二维语义特征与三维几何特征之间的分布差异。

### 2.3 背景掩码语义重建

- 设背景超点集合为 \(B\)，训练时从中均匀随机选取一部分 \(M\)，以掩码比例 \(r\) 将这些超点所含点的二维特征置零。论文默认 \(r=0.1\)。
- 三维编码器需要利用调制后的表示、周围上下文及几何信息，推断被遮蔽位置缺失的二维语义。
- 编码器的超点级特征经三层 MLP 投影回二维特征空间，重建损失结合 Smooth L1 距离与余弦距离：
  \[
  L_{\mathrm{rec}}=\frac{1}{|M|}\sum_{i\in M}
  \left[sL1(\hat f_i,f_i)+1-\cos(\hat f_i,f_i)\right]
  \]
- 总训练目标为基线实例分割损失与重建损失的加权和：
  \[
  L=L_{\mathrm{base}}+\lambda_{\mathrm{rec}}L_{\mathrm{rec}}
  \]
  默认 \(\lambda_{\mathrm{rec}}=1.0\)。
- 作者选择只遮蔽背景区域，是为了避免直接破坏前景实例特征、造成辅助任务与实例分割任务冲突。

## 6. 主要结论与发现

- 单纯向三维网络提供二维语义特征，并不必然使这些语义得到有效利用；**几何调制与掩码重建结合**，比被动拼接更有效。
- 背景掩码重建能够促使编码器从上下文和几何中恢复缺失语义；消融结果显示，调制与重建组合时表现最好，作者认为二者存在协同作用。
- 掩码位置对性能影响明显：背景掩码效果较好，而前景掩码会显著损害实例分割表现，符合“避免破坏关键实例线索”的设计动机。
- 方法在 ScanNetV2、ScanNet200 及 ScanNet200 少样本设置中均报告相对基线的提升，说明该设计在论文测试范围内具有一定跨框架适用性。
- 超点级二维特征表示可以明显降低特征存储与载入成本，但其效果仍建立在预先提取并正确关联的二维先验之上。
