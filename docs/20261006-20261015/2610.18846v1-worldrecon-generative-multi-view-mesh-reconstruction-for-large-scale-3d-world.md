## 摘要
从无位姿的多视角图像重建大规模场景的完整、高质量网格，既要求准确还原几何结构，也要合理补全未观测到或仅被稀疏采集的表面。我们提出 WorldRecon，这是一种生成式多视角重建框架，可从无位姿 RGB 图像中恢复完整的大规模 3D 场景网格。WorldRecon 将重建模型根据输入图像估计得到的粗糙、带噪全局点云及相机位姿作为全场景生成的全局支架，并将场景划分为相互重叠的空间块。为稳健利用这些不完美的几何先验，我们为原生 3D 生成模型 TRELLIS.2 配备了专用的基于重建的条件架构，根据每个空间块的局部点云裁剪及与该块相关的图像观测生成该块，从而生成稀疏结构、精细几何和 PBR 材质。为保持场景级一致性，我们引入了邻域感知潜变量修复，以及一种因果式世界生成流程，在重叠空间块之间传播结构、几何和材质上下文。这些设计共同使多视角生成式重建能够扩展至大规模场景，并生成连贯、统一的网格。大量实验表明，WorldRecon 达到了最先进的重建性能；在合成室内场景和真实室内场景上，与最强基线相比，其 Chamfer 距离分别降低了 14.9% 和 43.1%，F-score 分别提高了 17.3% 和 12.0%，展现出忠实且完整的生成式重建能力，以及强大的仿真到真实泛化能力。项目主页：https://kszpxxzmc.github.io/WorldRecon-website/。

## Abstract
Reconstructing complete, high-quality meshes of large-scale scenes from unposed multi-view images requires faithful geometric grounding while plausibly completing surfaces that are unobserved or only sparsely captured. We present WorldRecon, a generative multi-view reconstruction framework for recovering complete, large-scale 3D scene meshes from unposed RGB images. WorldRecon uses a coarse, noisy global point cloud and camera poses estimated from the input images by a reconstruction model as a global scaffold for whole-scene generation and partitions it into overlapping spatial blocks. To robustly leverage these imperfect geometric priors, we equip the native 3D generative model TRELLIS.2 with a dedicated reconstruction-based conditioning architecture that generates each block from its local point-cloud crop and block-relevant image observations, producing sparse structure, detailed geometry, and PBR materials. To maintain scene-level coherence, we introduce neighbour-aware latent inpainting and a causal world-generation procedure that propagates structural, geometric, and material context across overlapping blocks. Together, these designs scale multi-view generative reconstruction to large-scale scenes, yielding coherent, unified meshes. Extensive experiments demonstrate that WorldRecon achieves state-of-the-art reconstruction performance, reducing Chamfer distance by 14.9% and 43.1% while improving F-score by 17.3% and 12.0% over the strongest baselines on synthetic and real-world indoor scenes, respectively, thereby demonstrating faithful and complete generative reconstruction as well as strong sim-to-real generalization. ## 1. 核心问题与整体含义

- **研究问题**：如何仅从一组无位姿、无序且稀疏的多视角 RGB 图像，重建出完整、几何可信、细节丰富的大规模室内场景网格，并合理补全未被观测到的区域。
- **研究动机**：
  - 传统重建方法能利用图像恢复可见表面，但容易受到遮挡、视角稀疏和相机位姿误差影响，造成几何缺失、噪声和表面细节不足。
  - 生成式方法能补全未观测区域，但多数方法针对单个物体或较小场景；扩展到大场景后，模型容量、场景布局和区块间一致性成为难题。
  - 一些场景级方法依赖准确相机位姿，将图像特征投影到三维特征体中，因此在位姿不准确时容易出现跨视角冲突。
- **整体思路**：WorldRecon 将重建模型提供的粗糙点云与相机估计作为全局空间支架，再以区块为单位调用 3D 生成模型补足细节和缺失表面，通过邻域上下文传递及潜变量融合，尽量兼顾观测忠实度、生成完整性和场景整体连贯性。

## 2. 方法论

### 2.1 总体流程

1. 输入任意数量的无标定 RGB 图像。
2. 使用 **VGGT-Ω** 估计相机参数、深度和全局点云，并进行置信度筛选、离群点移除及场景方向和尺度对齐。
3. 按场景范围划分为相互重叠的空间块；论文主要设置为边长 **4 米**，相邻块重叠约四分之一。
4. 对每块选择相关图像和局部点云，输入经改造的 TRELLIS.2，依次生成稀疏结构、几何和材质。
5. 按因果顺序逐块生成，并利用已完成邻块的潜变量进行修补和融合，最后解码、合并为场景级 PBR 网格。

### 2.2 重建条件与生成模型

- **基础模型**：以原生 3D 生成模型 **TRELLIS.2** 为基础，将物体级生成模型微调为场景区块生成器。其表示采用稀疏体素结构 O-Voxel，生成分为三个阶段：
  - 稀疏结构阶段：预测哪些体素处于激活状态；
  - 几何阶段：生成激活体素中的几何潜变量；
  - 材质阶段：生成与几何对齐的材质潜变量，并解码为 PBR 属性。
- **多视图图像条件**：
  - 使用冻结的 DINOv3 提取图像 patch 特征；
  - 将相机信息表示为若干条 Plücker 射线，经 MLP 编码为相机 token；
  - 通过跨注意力模块融合不同视图，形成固定长度的多视图条件表示。
- **点云条件**：
  - 对局部点云进行 Fourier 位置编码，并投影为点云 token；
  - 点云主要作为稀疏结构阶段的粗略几何先验；
  - 训练时随机丢弃点云条件，使模型能够适应条件缺失，并支持 classifier-free guidance。
- **关键设计**：方法并非直接把图像特征严格投影到三维体素中，而是通过多视图条件编码器与局部点云共同引导生成，试图降低不准确位姿和点云对最终生成的破坏。

### 2.3 邻域感知潜变量修补

- 每个新生成区块需要延续已生成邻块的结构、几何和材质。论文将其建模为 3D 潜变量修补任务。
- 修补模型额外接收：
  - 二值掩码：区分已知潜变量和待生成区域；
  - 已知区域的潜变量内容。
- 训练时随机模拟一个或两个邻块提供上下文的情况；双邻块时采用 L 形邻接布局，以匹配推理中的区块生成顺序。
- 推理时保留邻块重叠区域的大部分潜变量作为已知上下文，并在边界留出较窄的过渡带，让模型有机会调整接缝附近的内容。

### 2.4 因果式世界生成与区块融合

- 根据区块点云占用情况选择种子区块，再按连通前沿逐步扩展；生成顺序限制每个新块最多有两个已生成的四邻接块，以匹配修补训练设置。
- **稀疏结构阶段**：生成新块时，在去噪过程中将已知重叠潜变量钳制回其对应的前向流轨迹，避免已生成结构在后续生成中被改写。
- **几何和材质阶段**：逐块生成后，按潜变量位置到区块边界的距离进行线性羽化加权融合；区块角点处通过多个轴的权重形成平滑过渡。
- 最终从共享的世界级潜变量中提取区块表示并解码，再将区块网格变换到统一坐标系中合并。

## 3. 实验设计

### 3.1 数据集与评测场景

- **3D-FRONT**：从中选取 30 个未见过的合成室内场景进行测试。测试场景平均约 7.1 个房间、62.1 平方米；输入为 32 张无位姿 RGB 图像。
- **ScanNet++**：选取 30 个真实室内场景进行测试，同样使用 32 张输入 RGB 图像，并在 50 个留出视角上评测深度和法线等结果。
- **训练数据**：使用 3D-FRONT 与 SAGE-10k 构建合成区块训练集，论文报告约 11.7 万个训练区块。测试集与训练场景区分。
- **评测指标**：
  - 3D：Chamfer Distance（CD）、10 厘米阈值 F-score、法线一致性（NC）及完整度；
  - 2D：深度 RMSE、AbsRel、深度与法线渲染的 LPIPS/CLIP，以及法线角误差和完整度。
  - 评测前根据对应相机中心估计 Sim(3) 对齐；因此评价反映的是对齐后的几何表现，而非直接要求预测坐标系与真值坐标系一致。

### 3.2 对比方法

论文将 VGGT-Ω 的预测作为共同几何先验，并与以下方法比较：

- **VGGT-Ω + TSDF**：将预测 RGB-D 与相机参数进行 TSDF 融合；
- **Murre**：基于点云条件改善单目深度，再融合为网格；
- **MonoSDF**：按场景优化神经隐式表面；
- **FineRecon**：基于多视图深度引导的前馈 TSDF 回归；
- **GenRecon**：通过区块划分及图像特征投影进行生成式场景重建。

此外，论文还通过附录定性比较了一个 GPT-6 Astra 智能体基线，但它不是主表中标准化的定量基线。

## 4. 资源与算力

- 训练使用 **32 张 NVIDIA GPU**；论文未说明 GPU 的具体型号，也未提供训练总时长、总 GPU 小时或推理耗时。
- 训练设置包括：
  - 稀疏结构与几何阶段采用全量微调；
  - 材质阶段采用 rank-8、scale-16 的 LoRA；
  - 数据使用 BF16 混合精度、AdamW 优化器。
- 推理设置为 12 步 Heun 采样，最多使用 4 张局部图像，每块使用 8192 个点云点。
- 附录称其相较于智能体基线，WorldRecon 可在单张 GPU 上执行推理；但没有进一步提供该 GPU 的型号或具体推理耗时。智能体实验报告了调用成本估算，但这不等价于严格的运行时间或硬件成本对照。

## 5. 实验数量与充分性

- **核心定量评测**：2 个数据集、各 30 个场景，共 60 个场景；覆盖合成室内场景与真实室内场景。
- **消融实验**：4 个组件逐步加入——重建条件稀疏结构生成、几何与材质生成、邻域修补、世界级潜变量拼接与融合。消融使用 15 个 3D-FRONT 场景和 15 个 ScanNet++ 场景。
- **定性实验**：展示了不同方法的场景和细节对比、较大规模多房间场景、智能体基线比较及失败案例。
- **充分性与公平性评价**：
  - 优点是同时包含 3D 与 2D 指标、合成与真实数据，以及明确的组件消融；各基线大体使用同一 VGGT-Ω 几何输入，增强了比较可解释性。
  - 但定量测试场景规模有限，未报告多次随机运行、置信区间或显著性检验；部分评价依赖相机中心对齐，可能弱化全局尺度与坐标误差。
  - 基线虽共享 VGGT-Ω 输入，但其原始方法和输入适配方式不同，无法保证所有方法在训练数据、计算预算和调参资源上完全一致。对于训练式基线，文中也没有给出全面的算力或训练成本比较。
  - 因此实验能支持方法在所选室内基准上的优势，但尚不足以证明对所有场景类型、输入分布和资源预算都普遍占优。

## 6. 主要结论与发现

- 在 3D-FRONT 上，WorldRecon 的 CD 为 **0.1583**、F-score 为 **0.7271**；相对最强对比结果，论文报告 CD 降低 **14.9%**、F-score 提高 **17.3%**。
- 在 ScanNet++ 上，CD 为 **0.0638**、F-score 为 **0.8363**；论文报告相对最强基线 CD 降低 **43.1%**、F-score 提高 **12.0%**。
- 在论文报告的主要表格中，WorldRecon 在两类数据的多数几何、深度和法线指标上取得最佳结果。
- 消融结果显示，重建条件生成是性能提升的重要基础；邻域修补可加强区块间上下文传递；最终的世界级潜变量钳制与融合进一步改善接缝和全局一致性。
- 论文还表明，模型只在合成室内数据上训练，仍能在 ScanNet++ 真实室内场景上取得较好结果，体现出一定的仿真到真实泛化能力。

## 7. 优点

- **结合重建与生成**：粗点云提供空间锚定，生成先验负责补全缺失表面，兼顾几何忠实度与完整性。
- **针对大场景设计**：以重叠区块扩展生成容量，避免单个高分辨率 3D 表示难以覆盖整场景的问题。
- **明确处理区块一致性**：通过邻域修补、去噪轨迹钳制和潜变量羽化融合，形成从生成到拼接的完整跨块协调机制。
- **考虑先验不完美**：训练中同时使用带扰动的深度反投影点云和 VGGT-Ω 点云，使模型更接近测试时的噪声条件。
- **输出形式实用**：生成的是带 PBR 材质的网格，而不只是用于渲染的隐式表示或无结构点元，便于下游编辑与内容生产。
- **实验覆盖多维度**：同时考察合成与真实场景、3D 几何和 2D 渲染指标，并通过消融解释主要模块的贡献。

## 8. 不足与局限

- **应用范围有限**：训练数据仅覆盖室内环境，户外场景的泛化能力尚未验证。
- **垂直方向受限**：当前使用单层、约 4 米高的区块表示，适用于单层室内场景，不适用于多层建筑，也没有沿竖直方向扩展区块生成。
- **依赖全局重建支架**：VGGT-Ω 的严重位姿或点云错误仍可能导致区域缺失或错位。论文的失败案例也显示，输入覆盖不足、多个视角定位错误时，模型仍会缺失几何；生成先验不能可靠恢复完全没有观测支持的真实细节。
- **生成补全存在不确定性**：未观测区域由生成先验推断，可能得到合理但与真实场景不一致的结构；论文指标主要评估与数据集真值的几何和渲染差异，未系统衡量补全结果的语义真实性或不确定性。
- **区块化仍有工程约束**：固定区块尺寸、重叠比例及最多两个已生成邻块的顺序，限定了生成拓扑和边界条件；复杂结构或更一般的三维邻接关系未充分验证。
- **实验规模和算力报告不完整**：场景数量有限，缺少统计显著性、多次试验和详细推理效率报告；GPU 型号、训练时长及完整资源成本未披露。
- **公平性边界**：不同基线的机制和适配流程并不完全一致，且主表使用共同 VGGT-Ω 先验虽有助于控制输入，却不能完全排除数据、调参和计算预算差异带来的影响。
- **论文自身指出的后续方向**：扩展到户外、多样化场景、多层环境，并支持沿垂直方向生成区块。
