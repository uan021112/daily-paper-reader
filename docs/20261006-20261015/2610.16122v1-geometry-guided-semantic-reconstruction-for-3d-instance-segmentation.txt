## Abstract 

3D instance segmentation requires representations that are both geometrically struc-tured and semantically discriminative. Pure 3D encoders model spatial structure well but often lack strong appearance semantics, while directly lifting 2D priors into 3D by concatenation injects rich semantics without ensuring that they align well with the underlying 3D structure. In this paper, we address this problem by formulating 2D-to-3D semantic transfer as a masked semantic reconstruc-tion task. Specifically, we mask a subset of background lifted 2D priors and train the 3D encoder to recover the missing semantic priors, providing explicit supervision for distilling rich 2D semantics into the 3D backbone. We further propose geometry-modulated semantic injection , which uses raw 3D geometry to modulate lifted 2D priors before sparse encoding, so that geometry explicitly controls semantic injection and alleviates the distribution gap between 2D semantic features and 3D geometric features. Experiments on two baseline frameworks demonstrate that the proposed method achieves state-of-the-art results in both full-data and few-shot settings on ScanNetV2 and ScanNet200. Code is pub-licly available at https://github.com/yharoldsu0627/Geometry_Guided_ Semantic_Reconstruction 

## 1 Introduction 

3D scene understanding from point clouds is a fundamental capability for applications such as autonomous driving and robotics [35, 41]. As a central problem in point cloud learning [8], 3D instance segmentation aims to identify and delineate individual object instances in complex scenes, providing the geometric and semantic information needed for downstream reasoning and decision-making [11, 33]. Pure 3D encoders usually model spatial structure well, but their appearance-level semantics are still limited [2, 39]. At the same time, the high cost of 3D annotation makes it difficult to learn strong semantic representations directly in 3D space [4, 36, 46]. In contrast, priors from 2D foundation models often contain much richer semantics learned from large-scale image data, yet they lack inherent 3D geometric awareness [28]. This creates a central question for 3D instance segmentation: how can we inject the rich semantics from 2D priors into the 3D encoding process while ensuring that the resulting representations remain aligned with the underlying 3D structure? 

Existing methods mainly follow two directions, but neither fully resolves this geometry-semantic tension. One line takes only 3D geometric features as encoder input and learns scene representations directly in 3D [11, 33, 18]. These methods preserve structure well, but their semantic expressiveness is still bounded by what can be learned from limited 3D supervision (see Figure 1(a)). Another line transfers semantics from 2D priors by lifting them into 3D and fusing them with 3D features [24, 1, 27].

However, when this fusion is implemented by direct concatenation or similarly lightweight injection, the encoder must discover cross-modal interactions from concatenated features without explicit guidance on how geometry should regulate semantic injection [27, 15] (see Figure 1(b)). Direct concatenation often fails to produce stable joint representations, as shown in prior work [15, 44, 45]. Moreover, simply providing extra 2D cues introduces no explicit supervision that encourages the encoder to exploit geometry and context to absorb them [24]. As a result, semantically rich but geometrically misaligned 2D priors are difficult to transform into representations that are well aligned with the underlying 3D structure [6]. To address these limitations, we move beyond both pure 3D encoding and direct con-catenation by formulating 2D-to-3D semantic trans-fer as a masked seman-tic reconstruction problem with geometry-modulated semantic injection (see Fig-ure 1(c)). Specifically, we mask a subset of back-ground 2D priors and train the encoder to recover the missing semantic priors, which provides explicit su-pervision for distilling rich 2D semantics into the 3D backbone. Masking is re-stricted to background pri-ors so that the auxiliary ob-jective does not directly dis-turb foreground instance cues. At the same time, it forces the encoder to infer missing semantics from context. To make this reconstruction objective more effective, we further use raw 3D geometry to modulate the lifted 2D priors before they enter the encoder. In this way, geometry explicitly controls semantic injection and helps alleviate the distribution gap between 2D semantic features and 3D geometric features, as supported by Table 4 and Table 6. Under this design, the encoder is encouraged to combine 3D structure with surrounding semantic context to recover the missing priors instead of relying directly on local and potentially geometrically inconsistent 2D cues, as supported by Table 4 and Table 7. Extensive experiments on two baseline frameworks further demonstrate consistent improvements across both benchmarks, and Table 1 and Table 2 show that the full design consistently outperforms direct concatenation. Our main contributions are summarized as follows: 

1) A masked semantic reconstruction objective for 2D-to-3D transfer. By masking a subset of background 2D priors and training the encoder to recover the missing semantic priors, the method turns semantic transfer from simple feature injection into a supervised reconstruction objective. 

2) A geometry-modulated semantic injection design that uses raw 3D geometry to modulate lifted 2D priors before they are fed into the encoder. This helps bridge the distribution gap between 2D semantic features and 3D geometric features, while allowing geometry to explicitly regulate how 2D semantics enter the 3D backbone. 

3) Extensive experiments on two baseline frameworks showing that the proposed method achieves state-of-the-art results in both full-data and few-shot settings on ScanNetV2 and ScanNet200. 

## 2 Related Work 

3D Instance Segmentation with 2D Priors. Previous work on 3D instance segmentation has ex-plored a broad spectrum of paradigms, including proposal-based, grouping-based, superpoint-based, 2kernel-based, and transformer-based methods [12, 7, 11, 9, 47, 38, 17, 33, 37, 19, 20, 13]. More recent instance-centric designs have further advanced the benchmark frontier. Spherical Mask for-mulates instances with a spherical coarse-to-fine representation to improve spatial localization [34]. EASE introduces language-guided semantic priors and edge-aware supervision to better separate adjacent instances with similar appearance [31]. Relation3D strengthens query reasoning by ex-plicitly modeling inter-instance relations in a DETR-style decoder [18]. IKNE further enhances candidate features through instance-wise knowledge aggregation and structural guidance [30]. To strengthen semantic understanding, recent methods have also introduced 2D priors into 3D pipelines. SegDINO3D concatenates lifted DINO image and object features with raw 3D inputs before the sparse encoder [27]. Open3DIS and Any3DIS use multi-view 2D masks to generate or refine 3D instance proposals [22, 21]. OpenScene, GeoPurify, and SAS transfer 2D priors through feature distillation or geometry-aware refinement [24, 6, 16]. While these approaches demonstrate the value of 2D guidance, they mainly rely on direct concatenation, mask lifting, or fixed-target distillation, all of which treat lifted 2D priors as side information rather than signals that must be actively integrated with 3D geometry. A key limitation is that such lightweight fusion strategies provide little explicit supervision for the encoder to absorb and integrate 2D semantics with 3D structure. 

Reconstruction-Based 3D Representation Learning. Reconstruction has become a widely adopted strategy for learning 3D representations. Point-BERT [40], Point-MAE [23], and Point-M2AE [42] recover masked point tokens or local geometry to learn contextual 3D features. Cross-modal variants further incorporate image-derived supervision, such as ACT [5], I2P-MAE [43], and Contrast with Reconstruct [26]. These works establish reconstruction as an effective self-supervised learning signal. However, they are primarily designed for generic 3D representation learning rather than supervised instance segmentation. Bringing reconstruction into downstream instance segmentation therefore requires careful task-specific design. The reconstruction target should complement rather than compete with the primary objective, and the auxiliary supervision should enhance rather than disrupt the learned representations. 

Conditional Modulation for Cross-Modal Fusion. Conditional modulation offers an adaptive mech-anism for cross-modal fusion, where one signal reshapes another through learned affine parameters. Representative formulations include FiLM [25] and AdaIN [10], which have proven effective across vision and multimodal tasks. However, its use in 3D instance segmentation remains limited, especially for controlling how 2D priors are injected into sparse 3D encoders. In our context, modulation is not merely a generic fusion operator. Rather, it provides a way for geometry to regulate semantic injection so that lifted 2D priors are integrated more consistently with the underlying 3D structure.

3.3 Masked Semantic Reconstruction 

Lifted 2D priors alone do not provide explicit supervision for semantic transfer, so we introduce a masked semantic reconstruction objective on top of the encoder features. A natural question is which regions to mask . Masking foreground superpoints would directly corrupt the instance-level cues that the downstream decoder relies on, creating a conflict between the reconstruction and segmentation objectives. We therefore restrict masking to background superpoints M ⊆ B as defined in Sec. 3.2. This design creates a complementary learning signal. The encoder must infer missing background semantics from surrounding context and geometry, strengthening its contextual reasoning without 4disturbing the foreground features that drive instance prediction (validated in Table 7). Masking is performed independently for each scene in the batch, so that the masked subset varies across iterations. The original per-point 2D features {pj } are kept aside as reconstruction targets. 3.4 Training Objective 

The aggregated superpoint features {gi} are projected to the decoder channel and fed into the inherited DETR-style query decoder [18, 27]. The base set-prediction loss Lbase is inherited unchanged from the underlying base framework. The overall objective combines the base loss with the proposed reconstruction loss, 

L = Lbase + λrec Lrec , (8) Here λrec balances the two terms. Lrec is applied only at the encoder side and shares no parameters with the decoder. Thus it acts purely as an auxiliary supervision signal that shapes the encoder features while leaving the inherited matching, decoder architecture, and inference path unchanged. 

## 4 Experiments 

4.1 Experimental Setup Datasets and Metrics. We evaluate on ScanNetV2 [4] and ScanNet200 [32], two large-scale 3D indoor scene datasets with dense instance annotations. ScanNetV2 (1,201 training / 312 validation scenes, 18 categories) serves as the primary benchmark for standard 3D instance segmentation evaluation. ScanNet200 (198 instance classes) presents a more demanding evaluation scenario with a pronounced long-tail distribution, where the majority of classes are underrepresented. This imbalanced setting is particularly suited to our method, as the geometry-modulated reconstruction objective is designed to strengthen contextual reasoning and semantic transfer—capabilities that are especially valuable when discriminating rare object categories. We report mean Average Precision (mAP) by averaging precision across IoU thresholds [50%, 95%] at 5% intervals, following standard protocol. We additionally report AP@50 and AP@25 to assess performance at specific localization tolerances. All results are evaluated on the official validation sets.

Efficiency of Superpoint-Level Representation 

A key design choice in our method is to use superpoint-level 2D priors rather than point-level priors. Figure 3 compares the loading time and memory footprint of three input represen-tations on ScanNetV2 scenes. Point-level 2D priors incur the highest overhead, with 263.3 ms loading time and 475.5 MB per scene. In contrast, superpoint-level aggregation reduces loading time to 0.4 ms and memory to 0.8 MB per scene, corresponding to about 658 × faster loading and about 594 × lower memory usage. This efficiency makes caching lifted 2D priors practical while retaining competitive performance in the main results.

## 5 Conclusion 

This paper addresses the challenge of injecting rich 2D semantics into 3D instance segmentation while maintaining geometric consistency. We demonstrate that passive concatenation of lifted 2D priors is insufficient, and propose a geometry-aware framework combining masked semantic reconstruction and geometry-modulated semantic injection. The masked reconstruction objective provides explicit supervision for semantic transfer, while geometry modulation ensures that 3D structure explicitly regulates how 2D priors enter the encoder. Extensive experiments validate the generality of our approach, achieving state-of-the-art results on both ScanNetV2 and ScanNet200, with consistent 9improvements in few-shot settings on ScanNet200. These results establish that effective 2D-to-3D semantic transfer requires explicit, geometry-aware distillation rather than simple feature fusion. 

Limitations. The method depends on the quality and availability of lifted multi-view 2D priors, and evaluation is centered on indoor RGB-D benchmarks. Extending to noisier 2D priors, outdoor scenes, and more open-world 3D understanding remains an important direction for future work.
