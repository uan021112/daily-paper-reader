## 摘要
开放词汇 3D 高斯分割通常通过逐场景梯度训练（1–4 小时）或近期提出的闭式蒸馏，将语义特征绑定到每个高斯基元的状态上。这两种方法都会将每个基元固定为单一特征；因此，跨越多个 2D 实例的边界高斯被迫作出硬性判定，导致检索精度下降，并在渲染时产生不稳定的掩码边界。我们提出 DIGS，这是一种无需训练的两阶段框架，包含类别无关映射与多模态编码，可将实例发现与语言命名解耦。在高斯层面，我们提出一种融入分布信息的表示，为每个基元显式维护一个包含前 $M$ 个标签的分布，并通过温度化 Dirichlet 规则进行更新；在边界基元处保留多峰标签分布，使后期取 argmax 的渲染器能够恢复清晰的实例边界。双向状态机将这些分布聚合为持久的类别无关实例本体。随后，实例级编码阶段融合每个实例独立 3D 区域的 CLIP 视觉嵌入，以及由 LLM 生成的属性描述对应的 CLIP 文本嵌入，从而区分视觉上相似的实例。在单张 A100 上，DIGS 可在 LERF-OVS 上完成映射与实例编码，每个场景耗时 1.0–3.2 分钟，具体取决于是否启用 LLM 融合；原生 3D 查询的响应时间为 5.4 毫秒。DIGS 在 LERF-OVS 上达到 71.95% 的平均 mIoU，优于无需训练的 SFS 和基于训练的 LaGa 基线方法。在各自的评估协议下，DIGS 在 LERF-Mask 和 3D-OVS 上也取得最高平均 mIoU，并在 Replica 上优于 Gaga 和 ObjectGS。代码见 https://github.com/ZephyrZos/DIGS。

## Abstract
Open-vocabulary 3D Gaussian segmentation typically binds semantic features to the per-Gaussian state via per-scene gradient training (1-4 h) or the more recent closed-form distillation. Both commit each primitive to a single feature; therefore, boundary Gaussians spanning multiple 2D instances are forced into a hard decision that degrades retrieval accuracy and yields unstable mask boundaries at render time. We present DIGS, a training-free framework with two stages, class-agnostic mapping and multi-modal encoding, that decouples instance discovery from linguistic naming. At the Gaussian level, our distribution-informed representation maintains an explicit top-$M$ label distribution per primitive, updated by a tempered Dirichlet rule; preservation of multi-peaked label distributions at boundary primitives allows a late-argmax renderer to recover clean instance boundaries. A bidirectional state machine aggregates these distributions into a persistent class-agnostic instance ontology. The instance-level encoding stage then fuses the CLIP visual embedding of each instance's isolated 3D footprint with the CLIP-text embedding of an LLM-generated attribute description, disambiguating visually similar instances. On a single A100, DIGS completes mapping and instance encoding on LERF-OVS in 1.0-3.2 min per scene, depending on whether LLM fusion is enabled, and serves native 3D queries in 5.4 ms. It reaches 71.95% mean mIoU on LERF-OVS, outperforming both the training-free SFS and training-based LaGa baselines. DIGS also achieves the highest mean mIoU on LERF-Mask and 3D-OVS and surpasses Gaga and ObjectGS on Replica under their respective evaluation protocols. Code is available at https://github.com/ZephyrZos/DIGS.

## 2. 方法论

### 2.1 两阶段处理流程

1. **类别无关映射**：输入固定的 3DGS 场景和相机帧序列。每帧用 SAM 生成类别无关的实例掩码，再将这些掩码与渲染得到的 3D 实例区域关联，形成跨帧持续的实例 ID。
2. **多模态实例编码**：对映射后筛选出的稳定实例，分别计算其孤立 3D 区域的 CLIP 视觉特征，以及 LLM 根据实例渲染图生成描述的 CLIP 文本特征。融合后的实例特征用于自然语言检索。

### 2.2 每个高斯维护前 \(M\) 个标签分布

- 渲染时，方法取得每个像素的前 \(K\) 个贡献高斯及其 alpha 合成权重。
- 每个高斯维护标签证据累积量 \(H_{i,j}\)，并保留其中得分最高的 \(M\) 个标签。实验默认 \(M=3\)。
- 这些标签证据归一化后形成高斯的 top-\(M\) 标签分布。若一个边界高斯同时支持两个实例，它可以保留这两个标签，而非立刻选定其中一个。

### 2.3 温度化 Dirichlet 更新

对高斯 \(i\)，令当前累计证据总量为 \(S_i\)，当前帧分配给它的总投票权重为 \(W_i^{(t)}\)，温度参数为 \(\tau>0\)。更新率定义为：

\[
\eta_i^{(t)}=\frac{\tau}{S_i+W_i^{(t)}+\tau},
\]

再将当前帧对标签 \(j\) 的权重 \(W_{i,j}^{(t)}\) 按比例加入证据：

\[
H_{i,j}\leftarrow H_{i,j}+\eta_i^{(t)}W_{i,j}^{(t)}.
\]

论文给出的性质是：**单帧注入的总证据小于 \(\tau\)**，即 \(\eta_i^{(t)}W_i^{(t)}<\tau\)。这限制了单帧大权重观测的影响，并使已有证据越多时更新越谨慎。作者也明确指出，这个界限不等同于正确关联、收敛或纠错保证。

### 2.4 Late-Argmax 渲染与实例状态机

- 对像素 \(p\)，先按 alpha 合成权重汇总其贡献高斯对各实例的标签分布，**最后才对实例分数取 argmax**。这样边界高斯可以同时向相邻实例投票，最终由像素级的综合支持决定标签。
- 方法通过 Hungarian 匹配将当前帧的 SAM 掩码与预测实例区域对齐；低重叠掩码可分配新 ID，并用生命周期计数管理实例。长期缺失的实例会被标记为 zombie，必要时回收 ID。
- 对可见高斯实施可见性感知衰减；对遮挡或不在视野中的高斯则尽量保留既有证据。
- 这种状态机是双向的：高斯的标签分布支持实例区域预测，实例匹配结果又反过来更新高斯证据。

### 2.5 实例级多模态编码与查询

- 对稳定实例的孤立 3D 区域进行多视角渲染，裁剪目标区域并计算 CLIP 图像嵌入。
- LLM 基于上下文图与孤立渲染图生成属性描述，再由 CLIP 文本编码器得到文本嵌入。
- 视觉与文本特征按权重线性融合；查询时将文本提示与实例表示做余弦相似度匹配，输出相应 3D 实例掩码。映射阶段不绑定特定语言模型，因此可以在映射完成后更换语言侧组件。
- 当评估协议提供测试帧 RGB 时，论文还使用 GroundingDINO 和 SAM 做可选的检测桥接，以将 2D 检测结果与 3D 实例区域匹配。

- **Replica**：GG、Gaga、ObjectGS；并分别遵循不同基线的评测协议，而不是统一协议下的直接横向比较。

### 3.3 消融与补充实验

- LERF-OVS 上逐步启用稳定性筛选、分布保留设计和 LLM 融合。
- 另外测试温度化更新与朴素更新、不同 top-\(M\)、不同 \(\tau\)、不同视觉—文本融合权重，以及检索阈值。
- 附录还报告了 Replica 的分场景结果、映射规模与时间，以及透明物体和 SAM 粒度导致的失败案例。

## 4. 资源与算力

- 论文报告实验使用 **一张 NVIDIA A100**。
- 3DGS 场景几何由固定的 Mip-Splatting 模型预先重建并冻结；相关重建使用 30,000 次迭代。DIGS 的语义映射阶段本身不进行逐场景梯度训练。
- 在 LERF-OVS 上，论文报告：
  - 纯映射约 **0.91 分钟/场景**；
  - 加 CLIP 实例编码约 **1.00 分钟/场景**；
  - 再启用 LLM 融合约 **3.2 分钟/场景**，其中 LLM API 调用与 I/O 是重要耗时来源。
  - 原生 3D 查询约 **5.4 毫秒**；表中也报告从提示到 2D 掩码约 28.1 毫秒。
- Replica 的 ObjectGS 协议下，1,750 帧映射平均约 **6.3 分钟/场景**。
- 作为参照，论文称训练式基线通常需约 **1–4 小时**逐场景优化。需要注意，这一对比涉及不同方法和配置，不能单独视作严格的同硬件、同实现成本对照。

## 5. 实验数量、充分性与公平性

- **覆盖范围较广**：涉及 4 个基准、20 个数据集场景，并包含多种评测指标、两个 Replica 协议、消融与超参数分析。对方法的速度、边界质量和开放词汇检索能力都有一定检验。
- **消融较系统**：作者分别考察稳定性筛选、top-\(M\) 分布、LLM 融合和温度化更新的影响，也分析了 \(\tau\)、\(M\) 与融合权重等参数。
- **公平性方面的积极做法**：论文称在基准内部遵循既有协议，并尽量匹配不同方法的评估设置；Replica 的结果也明确按 Gaga 与 ObjectGS 各自协议分别报告。
- **仍有比较限制**：
  - 不同协议使用的监督输入和评估流程不完全相同，特别是 Replica 不能将两列协议结果当成完全等价的直接比较。
  - LERF-Mask 和 3D-OVS 的检测桥接模式使用测试帧 RGB、GroundingDINO 与 SAM，衡量的不只是 DIGS 的文本检索能力，也包含外部检测器的贡献。
  - 表格混合了论文报告结果、重评结果和作者复现结果；来源虽有标注，但跨来源数字仍可能受实现和设置差异影响。
  - 结果未提供误差条、置信区间或统计显著性检验；论文在 checklist 中也明确表示没有报告统计显著性信息。
  - 场景数量有限，且文中没有报告不同随机种子或重复运行结果。因此，充分性主要体现在多基准和组件分析，而不是统计稳健性验证。

## 6. 主要结论与发现

- 在 **LERF-OVS** 上，DIGS 的 LLM+CLIP 配置平均 mIoU 为 **71.95%**，高于论文报告的 SFS（65.10%）和 LaGa（64.00%；另有作者复现结果 60.55%）。CLIP-only 配置为 66.85%。
- 在 **LERF-Mask** 上平均 mIoU 为 **91.71%**，高于表中 ObjectGS 的 88.4%；平均 mBIoU 为 86.91%。
- 在 **3D-OVS** 上平均 mIoU 为 **96.45%**，与 ObjectGS 的 96.4% 接近且略高。
- 在 **Replica** 上，DIGS 在 Gaga 协议下的 IoU 为 51.39%，高于 Gaga 的 46.21%；在 ObjectGS 协议下 IoU 为 91.46%，高于 ObjectGS 的 88.39%。两项均应结合各自协议理解。
- 消融结果显示，作者认为 top-\(M\) 分布保留是边界改善的主要来源之一，LLM 文本融合有助于区分视觉相似实例，温度化更新则有助于缓解跨视角掩码不稳定。
- 整体结论是：在固定 3DGS 几何的前提下，基于分布的高斯状态和实例级后处理编码，可以在不进行逐场景梯度训练的情况下，兼顾映射速度、边界表现和开放词汇检索。

## 7. 优点

- **问题定位清楚**：将边界模糊追溯到每个高斯只能存储单一语义模式，而不是仅把问题归因于训练技巧或优化时长。
- **表示与渲染设计相互配合**：top-\(M\) 标签分布保留边界不确定性，late-argmax 则延后最终判定，形成从高斯状态到像素标签的完整设计。
- **映射与语言解耦**：类别无关本体可以复用于不同文本查询，不必把某个语言模型特征训练进每个场景的高斯状态。
- **计算开销较低**：语义映射采用逐帧的闭式更新，避免长时间逐场景梯度优化；作者也给出了查询延迟和显存数据。
- **验证维度较多**：除检索精度外，还报告了边界指标、不同协议结果、速度、超参数敏感性及失败案例。
- **理论界限表述相对谨慎**：论文说明单帧注入上界不等价于关联正确性或闭环收敛保证，避免把局部性质夸大为整体理论保证。

## 8. 不足与局限

- **依赖上游模型与输入质量**：SAM 的掩码粒度限制可发现的实例层级；CLIP、LLM 和可选检测器的能力共同限制语言区分效果。SAM 若把物体部件与整体合成一个掩码，部件级查询就难以得到独立区域。
- **透明物体存在系统性错误**：alpha 合成权重可能让透明表面后的背景高斯也获得投票，造成实例范围向背景扩散。
- **固定几何不参与语义阶段优化**：DIGS 冻结预重建的高斯几何，无法通过语义信号修正薄结构或边界几何；作者也指出透明、细薄结构可能仍需进一步改进。
- **top-\(M\) 是有损截断**：被剪出前 \(M\) 的标签会丢失证据，且作者承认 top-\(M\) 剪枝不是严格的贝叶斯后验更新。虽然实验默认 \(M=3\)，但不同场景的标签复杂度未必都适合相同截断规模。
- **温度更新的保证范围有限**：它限制单步投票注入，却不保证数据关联正确或闭环一定收敛。附录还指出，在某些低可见度投票与衰减条件下，不存在普遍的累计状态上界。
- **多模态处理引入额外依赖与成本**：LLM 融合提升属性区分，但带来 API 调用、缓存和模型服务依赖；LLM 描述的准确性也可能影响检索。CLIP-only 的效果与 LLM+CLIP 并不相同。
- **评测的统计稳健性不足**：未报告置信区间、误差条或显著性检验，场景数量也有限；目前结果支持论文所测基准上的有效性，但对更广泛场景的泛化程度仍需更多实验。
- **复现实验需留意结果口径**：论文同时使用原论文数字、重评结果和作者复现结果，并针对不同数据集沿用不同协议。解读横向比较时需核对具体行和协议，尤其是使用 2D 检测桥接的结果。
