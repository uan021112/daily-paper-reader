## 摘要
文本驱动的3D室内场景生成已经从基于数据集的布局建模发展到使用大语言模型和视觉-语言模型的开放词汇合成。然而，现有方法仍然有限：一次性生成器往往产生几何上无效的布局，繁重的后期优化成本高昂且不稳定，而仅依赖提示的规划器缺乏可用于功能分组和物体关系的可复用布局先验。我们提出了ScenePilot，一个检索增强的生长-修复框架，将场景生成表述为基于先验引导的增量生长与学习矫正。给定一个提示，分层检索增强规划（HRAP）模块检索房间级、组级和锚点级布局先验，以支持功能组规划。然后，一个文本驱动的基础生成器顺序插入对象组，而强化多模态修复（RMR）模块在每次插入后执行轻量级局部矫正，并在完成后执行最终全局修复。为了训练该策略，我们构建了SceneReverse-17k，一个修复轨迹数据集，通过对高质量3D场景进行位置、旋转和缩放的扰动，然后使用逆操作作为可执行的矫正目标来构建。该策略从渲染视图、场景状态、检索到的先验和编辑历史中预测结构化的移动-旋转-缩放动作。通过将HRAP与RMR相结合，ScenePilot提供了一种高效替代一次性生成和重度全场景优化的方法，在保持多样性的同时，提高了物理合理性、功能连贯性和可控性。

## Abstract
Text-driven 3D indoor scene generation has advanced from dataset-bound layout modeling to open-vocabulary synthesis with large language and vision-language models. Yet existing methods remain limited: one-pass generators often yield geometrically invalid layouts, heavy post-hoc optimization is costly and unstable, and prompt-only planners lack reusable layout priors for functional grouping and object relations. We propose \textbf{ScenePilot}, a retrieval-augmented \textbf{Grow-and-Repair} framework that formulates scene generation as prior-guided incremental growth with learned rectification. Given a prompt, the Hierarchical Retrieval-Augmented Planning (HRAP) module retrieves room-, group-, and anchor-level layout priors to support functional group planning. A text-driven base generator then inserts object groups sequentially, while the Reinforcement Multimodal Repair (RMR) module performs lightweight local correction after each insertion and a final global repair after completion. To train this policy, we construct \textbf{SceneReverse-17k}, a repair-trajectory dataset built by perturbing high-quality 3D scenes in position, rotation, and scale, then using inverse operations as executable rectification targets. The policy predicts structured \emph{move--rotate--scale} actions from rendered views, scene state, retrieved priors, and edit history. By combining HRAP with RMR, ScenePilot offers an efficient alternative to one-shot generation and heavy full-scene optimization, improving physical plausibility, functional coherence, and controllability while preserving diversity.

## 1. 论文的核心问题与整体含义

- **研究动机**：3D室内场景生成是室内设计、具身AI、机器人仿真和虚拟世界创作的基础性任务。但与传统物体或图像生成不同，室内场景生成必须同时满足**物理合理性**（物体落地、不重叠、在房间边界内）、**结构连贯性**（功能分区合理）和**功能可用性**（家具可正常被使用）。
- **核心问题**：现有文本驱动3D室内场景生成方法存在三重局限——
  - 一次性生成方法往往只预测最终布局，容易产生几何无效的中间状态且错误会传播放大；
  - 后处理优化方法修复成本高、不稳定，无法在早期错误传播前及时纠正；
  - 仅依赖文本提示的规划器缺少可复用的功能分组与空间关系先验。

- **整体含义**：作者提出“过程感知式”场景生成的新思路——场景构建本质上是**顺序的、路径依赖的**：早期放置的“锚点物体”（如床、沙发、餐桌）位置一旦出错，会严重影响后续所有物体摆放。因此，不应只预测一个合理的最终布局，而应在生成的**中间状态**就进行规划、监督与纠正。ScenePilot 通过“先检索先验 → 按功能组增量生长 → 组间即时局部修复 + 最终全局协调”的方式，替代了一次性生成和全场景重优化范式。

## 2. 论文提出的方法论

**总体架构**：ScenePilot = HRAP（分层检索增强规划）+ 基础生成器 + RMR（强化多模态修复策略）+ 全局修复。

### 2.1 分层检索增强规划（HRAP，Hierarchical Retrieval-Augmented Planning）
- **锚点先验记忆构建**：从干净3D场景中挖掘以“锚点物体”为中心的功能组。床、沙发、餐桌等作为锚点，邻近兼容物体按类别兼容性、距离、支撑关系等分配为该组的成员。
- **先验统计提取**：存锚点-成员对的局部坐标偏移、平面距离、相对朝向、成员类别计数签名（如餐桌旁4把椅、床旁2个床头柜）等。
- **三层检索**：房间级（全局布局倾向）、组级（功能组合模式）、锚点级（局部物体-锚点关系），通过 FAISS 与文本嵌入做 Top-5 相关先验检索。
- **功能组规划**：将用户文本提示解析成有序的功能组集合，每个组包含组名、锚点物体、物体列表、区域提示（靠墙/角落/中部等）和插入优先级。
- **关键设计**：先验仅作为“软提示”提供给规划器，不做硬性坐标约束，不被复制为场景布局，不注入修复评分函数。

### 2.2 强化多模态修复策略（RMR，Reinforcement Multimodal Repair）

- **多模态观测**：顶视图渲染 + 对角透视图渲染 + 带标注的顶视图 + 场景结构化JSON + 此前尝试的编辑历史。
- **受限动作空间**：仅三类原子修复操作——
  - `MOVE: (i, Δx, Δy, Δz)`
  - `ROTATE: (i, Δθ)`
  - `SCALE: (i, Δsx, Δsy, Δsz)`
- **局部修复执行**：每插入一个功能组后，仅允许修改该组物体加少量邻近锚点物体，运行至多 K<sub>local</sub> 轮修复。候选动作必须提升一个综合质量分 Q 才会被接受（确定性判定公式），以避免修复策略产生有害漂移。
- **全局修复**：全部组插入完成后，以更大搜索预算处理跨组冲突、动线瓶颈、整体对齐等问题。
- **两阶段训练**：
  - **阶段一**：对 SceneReverse-17k 逆修复轨迹做监督微调，学习动作序列的格式和粗粒度纠错能力。
  - **阶段二**：GRPO 强化学习优化，奖励函数分解为格式有效、可执行性、物理改善、VLM视觉语义反馈四个子项，物理改善项权重最大。

### 2.3 SceneReverse-17k 数据集的构建

- 选取高质量 3D-FRONT 房间布局，通过位置平移、旋转、缩放、混合扰动四种方式制造“可恢复的”退化中间状态。
- **监督信号**：将扰动的逆操作按顺序翻转，形成从损坏状态恢复到干净状态的“修复轨迹”。
- **波动性过滤**：剔除变化过小的无信息步，按“剩余修复难度”分层采样（轻度/中度/重度退化），以平衡不同退化程度样本。
- 每个修复步由观察（渲染图+JSON）与可执行的动作目标构成，用于训练策略学习“如何从不合法状态逐步恢复到合法布局”。

## 7. 优点

- **过程式监督的设计理念新颖性**：不把“修复”当后处理工具，而是将其作为整个生成流程中的一等公民，显式建模中间场景状态并进行监督训练。数据集构造的思想与测试目标对齐，使训练与推理的行为高度一致。
- **可控性与可解释性好**：将动作空间限制到 move/rotate/scale 三种结构化操作，配合确定性质量门控（Q评分改善才接受），抑制了自由式生成所固有的不可控漂移。
- **检索先验与生成策略解耦**：先验只作软上下文，不直接参与打分函数，不会引入硬约束求解困难，同时仍能为短提示提供功能分组所需的场景常识，实用性较好。
- **多模态观测设计匹配真实部署场景**：对顶视图、对角视图、标注视图、JSON状态的综合运用，既利用了视觉线索又保留了数值精度。
- **逆向扰动生成数据的方案可扩展且干净**：相比人工标注修复动作，用可逆扰动+反转构造监督信号，生产训练数据自动化程度高，标注噪声低。

## 8. 不足与局限

- **奖励设计不覆盖美学层面**：论文自述修复评分集中在物理合法性、关系一致性与功能可用性上，美感或风格层面反馈缺失，可能导致生成结果“正确但不好看”的情况。
- **RAG记忆覆盖度受限**：先验记忆依赖输入数据的覆盖范围与质量；检索较弱时可能引入无关关系，或使输出偏向常见配置、牺牲多样性。对洗衣房这类少数房型，因场景记录极少，增强收益大打折扣。
- **数据集房型不平衡**：3D-FRONT 本身以卧室/客厅为主，稀有房型的统计噪声大，泛化到极端或新颖房型的可信度有限。
- **数据泄漏风险提示且需严格隔离**：RAG先验由源场景统计分析而来，尽管存的是聚合统计而非整场景，但评估场景未经显式排除仍可能导致检索先验泄漏并高估生成质量，论文在附录E.5对此作专门提醒。
- **人类主观评估规模有限**：仅50份问卷且是方法级均值对比，未提供心理测量学统计检验或分组方差讨论。
