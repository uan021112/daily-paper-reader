## 摘要
我们提出 PanoSeg3R，一种用于3D全景语义分割的前馈框架。与面向透视输入设计的现有方法不同，PanoSeg3R 在单次前向传播中联合预测3D几何与多视角语义分割。基于支持全景图像的预训练重建骨干网络，我们的方法通过基于查询的掩码解码器扩展了前馈式3D重建。此外，我们引入自动全景数据策管流水线，利用现成基础模型的互补优势生成可靠的伪语义标注，大幅扩展训练数据并提升零样本泛化能力。PanoSeg3R 在全景3D语义分割上达到最先进性能，在 ScanNet++ 上将3D mIoU提升最多16.02，而策管后的训练数据在 Stanford2D3D 和 ToF-360 上进一步将零样本性能分别提升最多4.26和43.28 mIoU。网站：https://harryyoon777.github.io/PanoSeg3R/

## Abstract
We present PanoSeg3R, a feed-forward framework for 3D panoramic semantic segmentation. Unlike existing methods designed for perspective inputs, PanoSeg3R jointly predicts 3D geometry and multi-view semantic segmentation in one single forward pass. Built upon a pretrained reconstruction backbone that supports panoramic images, our approach extends feed-forward 3D reconstruction with a query-based mask decoder. Furthermore, we introduce an automatic panorama data curation pipeline that leverages the complementary strengths of off-the-shelf foundation models to generate reliable pseudo semantic annotations, substantially expanding the training data and improving zero-shot generalization. PanoSeg3R achieves state-of-the-art performance on panoramic 3D semantic segmentation, improving 3D mIoU by up to 16.02 on ScanNet++, while the curated training data further improves zero-shot performance by up to 4.26 and 43.28 mIoU on Stanford2D3D and ToF-360, respectively. ## 一、核心问题与整体含义

- **研究动机**：3D 场景理解对沉浸式媒体、机器人、自主导航等应用至关重要。近期基于学习的前馈多视图方法（PanSt3R、IGGT、Uni3R 等）能从 RGB 观测中同时完成几何重建与语义预测，但它们均针对**透视图像**设计，视野有限，需大量重叠观测才能覆盖大场景，采集效率低。
- **全景图像的优势与困境**：全景相机单视角即可捕获 360° 场景信息，但全景图通常采用等距柱状投影（ERP），存在严重畸变。现有 ERP 语义分割方法多针对**单张图像**，无法产生多视图一致的 3D 分割；将 ERP 转为立方体贴图或切平面投影又会引入额外计算开销，并损害跨视图的几何与语义一致性。
- **数据瓶颈**：全景图像缺乏高质量语义标注，人工逐像素标注成本高、劳动密集，难以构建大规模数据集。
- **整体含义**：PanoSeg3R 是**首个无需 ERP 转透视投影、直接在多视图全景图像上做前馈式 3D 语义分割**的方法，并配套提出自动数据策管流水线，以缓解全景标注稀缺问题并提升零样本泛化能力。

## 二、方法论

### 2.1 核心思想
- 基于预训练的 **Wid3R**（支持宽视场相机的全景 3D 重建骨干）扩展前馈重建能力，加入**基于查询的掩码解码器**，在单次前向传播中联合预测 3D 几何与多视图语义分割。
- 使用**冻结的 SigLIP 文本编码器**将类别名编码到共享嵌入空间，以支持跨数据集（不同语义类别集）联合训练。

### 2.2 全景特征与几何提取
- 给定多视图全景图，Wid3R 将每张全景编码为图像 token 序列，经交替的帧内注意力和全局注意力层处理，得到多尺度表示。
- 每张全景预测密集**射线方向图** $R_i$ 与**径向距离图** $D_i$，3D 点图为 $P_i = R_i \odot D_i$（逐元素相乘）。射线方向用球谐函数编码，对全景畸变鲁棒。

### 2.3 语义掩码预测与分类
- **查询精炼**：引入 $N_q$ 个可学习语义查询，共享于所有输入视图，经解码器与最终层 token 做交叉注意力及自注意力，得到精炼查询 $\hat{Q}_n$。
- **语义分类**：将 $\hat{Q}_n$ 线性投影到文本嵌入空间，与 $J$ 个类别的 SigLIP 文本嵌入 $t_j$ 计算余弦相似度 $p_{n,j} = \text{sim}(q_n^{cls}, t_j)$。
- **语义掩码预测**：用 DPT 头聚合多尺度 token，得到每视图的密集特征图 $F_i$。
- **低层特征注入**：由于 ERP 图每个 patch 覆盖视野远大于透视图，细粒度细节易丢失，故设计 **image stem**（跨步卷积 + 残差卷积块 + 1×1 投影）提取低层特征 $S_i$，并采用**循环填充**保持 ERP 水平连续性；融合方式为 $\tilde{F}_i = H(F_i + S_i)$。
- **掩码生成**：$M_{n,i} = \text{Sigmoid}\left((q_n^{mask})^\top \tilde{F}_i\right)$。
- **训练损失**：遵循 Mask2Former，$\mathcal{L} = \lambda_c \mathcal{L}_{cls} + \lambda_d \mathcal{L}_{dice} + \lambda_b \mathcal{L}_{bce}$。

### 2.4 自动全景数据策管流水线（四阶段）
1. **预处理**：将 ERP 图投影为 5 张方位角间隔 72° 的无畸变透视图像，每张再分高/中/低 3 个裁剪，共 **15 个裁剪**（含水平/垂直重叠），以降低 ERP 畸变影响。
2. **掩码生成**：**SAM3** 直接在 ERP 图上生成类无关掩码（边界精确但无标签）；**PanSt3R** 处理 15 个裁剪，输出粗语义区域（固定 100 类 ScanNet++ 词表）。
3. **掩码聚合**：将 PanSt3R 区域重投影回 ERP 空间，与 SAM3 掩码做 **IoU 形状—标签匹配**（阈值 $\tau_{IoU}$），为每个 SAM3 掩码分配最高 IoU 的 PanSt3R 标签，保留 SAM3 的精确边界。
4. **VLM 过滤**：以 **Qwen3-VL-8B** 对每个带标签掩码的局部 RGB 裁剪（目标区域红色高亮）进行链式思维验证，移除标签不一致的掩码，得到最终伪标注。

## 六、主要结论与发现

- **3D 语义分割 SOTA**：在 ScanNet++ 上 3D mIoU 超越 PanSt3R、IGGT、Uni3R 分别 **8.02、14.98、16.02**；在 Matterport3D 2D 上取得 49.77 mIoU，与全景专用方法竞争力相当。
- **零样本泛化显著提升**：Stanford2D3D 2D mIoU 达 65.15（+4.26），ToF-360 2D mIoU 达 56.51（+43.28）；Stanford2D3D 3D mIoU 达 34.83，超 PanSt3R、Uni3R、IGGT 分别 22.79、28.08、31.42。
- **数据策管有效**：Realsee3D 与 OmniScenes 两组策管数据提供互补的语义与场景多样性；+SAM3 精炼边界使 Stanford2D3D/ToF-360 分别提升 1.41/1.04 mIoU；VLM 过滤虽降低 mIoU，但能移除约 19.7%/26.6% 的错误掩码（代价是误删 5.2%/3.6% 正确掩码）。
- **Image stem 有效**：循环填充优于零填充，2 个残差块配置最佳，主要提升 2D 分割（对 3D mIoU 影响较小）。
- **效率优势明显**：处理 8 张共视全景仅需 9.56GB 显存、1.10s 推理；而基线需 48 张立方体面或 120 个裁剪，峰值内存与耗时显著更高，IGGT/Uni3R 在 15-crop 下直接 OOM。

## 七、优点

- **首创性**：首个**全景原生**的前馈 3D 语义分割框架，无需 ERP-to-perspective 投影，从源头避免投影带来的几何/语义不一致。
- **统一架构**：单次前向同时完成几何重建与多视图语义分割，端到端且高效。
- **跨数据集训练设计**：借助冻结 SigLIP 文本编码器与共享嵌入空间，优雅地解决不同数据集类别集不一致的问题。
- **数据策管流水线**：巧妙组合 SAM3（精确边界）、PanSt3R（粗语义）与 VLM（验证过滤）的互补能力，实现无需人工像素级标注的伪标注生成，显著提升零样本泛化。
- **细节设计扎实**：image stem 针对 ERP patch 视野大、细节丢失的问题引入循环填充保持水平连续性；射线方向 + 球谐编码对全景畸变鲁棒。
- **实验全面**：涵盖 2D/3D、域内/零样本、多组消融与效率对比，评估协议严格且对 VLM 过滤的负面影响做了诚实分析。

## 八、不足与局限

- **应用场景受限**：数据策管流水线的类别集基于室内数据集（ScanNet++ 100 类），主要面向室内环境，对室外场景泛化差（失败案例显示常误判室外物体）。
- **标注类型单一**：仅支持语义标注，不支持实例级或全景（panoptic）标注。
- **VLM 过滤存在副作用**：VLM 只能移除掩码，无法恢复漏检（FN），且误删正确掩码会将 TP 转为 FN，导致最终 mIoU 可能下降。
- **资源信息不完整**：论文未明确说明训练所用 GPU 数量与训练总时长，复现成本评估受限。
- **零样本评估类别有限**：为公平比较仅评估共享类别（7 类/9 类），未覆盖完整类别集，泛化结论的全面性有一定局限。
- **3D 评估范围**：ToF-360 因缺少相机位姿仅能进行 2D 评估，3D 泛化能力在该数据集上未得到验证。
- **伪标注质量依赖基础模型**：策管流水线效果受 PanSt3R、SAM3、VLM 本身性能制约，存在误差传播风险。
