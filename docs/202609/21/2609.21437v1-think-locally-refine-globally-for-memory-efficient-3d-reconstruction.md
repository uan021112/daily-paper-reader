## 摘要
我们提出 LoG-VGGT，一个面向长序列三维重建的内存高效框架，平衡了局部时序建模与全局相机一致性。不同于依赖完全全局注意力，我们的方法在少量 Transformer 块中引入跨窗口注意力，从而在保持内存使用有界的同时，实现相邻时间窗口间的有效信息传播。为缓解长期位姿漂移，我们进一步设计了一个全局相机一致性精化模块，其中相机 token 通过交叉注意力与紧凑的寄存器 token 交互，以在整个序列上施加场景级约束。该设计能够联合优化相机表示，并显著提升长时程位姿稳定性，而无需承担全序列注意力的高昂代价。大量实验表明，LoG-VGGT 在多个长序列基准上实现了更高的深度精度和鲁棒的相机位姿估计，同时提供有竞争力的流式重建性能。

## Abstract
We propose LoG-VGGT, a memory-efficient framework for long-sequence 3D reconstruction that balances local temporal modeling with global camera consistency. Instead of relying on full global attention, our method introduces cross-window attention at a small subset of transformer blocks, enabling effective information propagation across adjacent temporal windows while keeping memory usage bounded. To mitigate long-term pose drift, we further design a global camera consistency refinement module, where camera tokens interact with compact register tokens via cross-attention to enforce scene-level constraints across the entire sequence. This design enables joint optimization of camera representations and significantly improves long-horizon pose stability without incurring the high cost of sequence-wide attention. Extensive experiments demonstrate that LoG-VGGT achieves improved depth accuracy and robust camera pose estimation across multiple long-sequence benchmarks, while delivering competitive streaming reconstruction performance.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：以 VGGT（Visual Geometry Grounded Transformer）为代表的端到端前馈三维重建，在联合深度、相机位姿与三维点云估计上表现强劲，正成为 SLAM、3D 编辑、具身智能等任务的基础。但其全局注意力对时空 token 呈二次复杂度 $O(N^2)$，计算与显存随序列长度急剧增长，难以扩展到长时程/流式场景。
- **现有两条路线及其困境**：
  - **离线批处理**（VGGT、VGGT-Long 等）：全序列联合处理，全局一致性好，但计算与显存开销巨大。
  - **内存高效/流式方法**：保留全部历史 token（StreamVGGT 缓存全部 KV，长序列 OOM）或将历史压缩为全局状态（WinT3R 的持久全局隐状态、InfiniteVGGT 的滚动内存+逐层 token 淘汰），内存有界但存在灾难性遗忘与长期位姿漂移。
- **核心张力**：能否在保留足够时序上下文以保证几何一致性的同时，避免无界内存增长与长期误差漂移？
- **核心洞见**：有效长序列建模不需要在每一层都做无限制全局交互；只需在少量几何关键层引入跨窗口注意力即可隐式诱导弱全局一致性；而相机位姿的长期漂移需要单独的轻量全局精化来纠正。由此提出 **"局部思考、全局精炼"（Think Locally, Refine Globally）** 的 LoG-VGGT 框架。

## 2. 方法论

### 2.1 整体思想
- 将 VGGT 改造为**重叠滑动窗口**流式骨干：窗口内保持 VGGT 交替注意力，窗口间通过**跨窗口注意力（CWA）**传播信息，序列级用**全局相机一致性精化（GCCR）**抑制位姿漂移。内存与计算与总序列长度 $T$ 解耦，仅与窗口大小 $K$ 相关。

### 2.2 重叠滑动窗口与有界复杂度
- 将序列划分为重叠窗口 $\mathcal{W}_i=\{I_i,\dots,I_{i+K-1}\}$，窗口大小 $K=4$、步长 2。
- 窗口内交替执行 frame attention 与 window-level global attention，全局注意力被限制在窗口内，复杂度 $O(K^2)$，与序列总长无关。

### 2.3 跨窗口注意力（CWA）
- 仅在**少量关键层** $\mathcal{L}_{key}$ 引入跨窗口交互。关键层沿用 VGGT 中 DPTHead 用于几何预测的固定 4 层：`block4DPT_idx = [4, 11, 17, 23]`，从而与原始架构保持一致并复用几何相关表征。
- 处理完窗口 $\mathcal{W}_{i-1}$ 后缓存其关键层 token $\tilde{H}^{(l)}_{i-1}$；处理当前窗口时将其作为额外 K/V 注入对应层：
  $$H^{(l+1)}_i = \mathcal{F}\big(Q(H^{(l)}_i),\; K([H^{(l)}_i,\tilde{H}^{(l)}_{i-1}]),\; V([H^{(l)}_i,\tilde{H}^{(l)}_{i-1}])\big)$$
- 通过相邻窗口重叠帧的显式对齐，保持局部时序与几何连续性，并沿受限路径逐步传播，隐式形成弱全局一致性；无需存储完整 token 历史。

### 2.4 全局相机一致性精化（GCCR）
- 设计依据：深度估计依赖局部时序连续性与渐进传播，滑动窗口已足够；相机位姿对长时程误差累积敏感，易漂移。
- 收集所有窗口与时间步的寄存器 token 构成全局寄存器集 $\mathcal{R}=\{r^t_j\}$，对每个相机 token $c_t$ 做交叉注意力：
  $$c'_t = \mathrm{Attn}\big(Q(c_t),\; K(\mathcal{R}),\; V(\mathcal{R})\big)$$
- 在紧凑 token 上完成序列级联合优化，避免重新引入全序列注意力；深度不做显式全局精化，实现**局部几何推理与全局相机对齐的解耦**。

### 2.5 训练目标
- 多任务联合：$\mathcal{L}=\mathcal{L}_{camera}+\mathcal{L}_{depth}$，两项量级相当，无需额外加权。
- **相机损失**：多阶段（$S$ 阶段）带时间衰减因子 $\gamma$ 的 $\ell_1$ 监督，姿态误差为平移、旋转四元数、焦距的加权 $\ell_1$ 之和。
- **深度损失**：沿用 DUSt3R，建模偶然不确定性，包含深度项、深度梯度项与不确定性正则项 $\alpha\log\Sigma_D$；虽无显式点图损失，但三维点由深度与相机参数确定并受隐式约束。
- **训练策略**：两阶段——先以 12 帧 batch 训练 100 epoch 稳定局部几何，再以 64 帧 batch 微调 10 epoch 增强长程时序一致性。

## 6. 主要结果与结论

### 6.1 三维重建
- 在 7-Scenes 与 NRGBD 上，随子序列从 200 增至 1000 帧，LoG-VGGT 的 Acc / Comp / NC 保持稳定或仅轻微退化，而多数流式基线（StreamVGGT、InfiniteVGGT 等）在 500/1000 帧时出现明显退化或 OOM。
- 与离线方法相比，LoG-VGGT 在长序列上以远低得多的显存与计算代价取得接近甚至更优的重建精度，体现"局部思考"对几何一致性的保持能力。

### 6.2 视频深度估计
- 在 Sintel、Bonn、KITTI 上，LoG-VGGT 的 Abs Rel 与 $\delta<1.25$ 总体优于或持平于流式基线；在附录的 200/500 帧长序列中优势更明显，说明窗口内交替注意力 + CWA 的渐进传播足以支撑长时程深度连续性。
- 深度不引入显式全局精化仍能保持稳定，验证了"深度依赖局部时序、相机依赖全局对齐"这一解耦设计的合理性。

### 6.3 相机位姿估计
- 在 ScanNet、TUM-D、CO3Dv2 上，RRA@30 / RTA@30 / AUC@30 全面领先流式基线，且随输入视图数增加，ATE 增长显著慢于无 GCCR 的变体，直接证明 GCCR 对长期漂移的抑制效果。
- 附录中随视图数变化的 ATE 曲线显示：无 GCCR 时误差近似线性累积，加入 GCCR 后趋于平缓，量化了"全局精炼"的收益。

### 6.4 效率
- FPS 在 100/200/500/1000 帧上基本保持稳定，内存与计算近似与序列长度解耦；运行时分解显示 GCCR 占比可控，在线变体进一步降低延迟。
- 与 Fast3R、FastVGGT 等高效基线相比，LoG-VGGT 在相近或更低开销下取得更好的几何与位姿精度。

### 6.5 消融
- 去除 CWA：短序列（10 帧）影响有限，长序列（200 帧）重建与位姿显著退化，甚至 OOM，说明跨窗口信息传播是长序列一致性的关键。
- 去除 GCCR：重建退化相对温和，但位姿漂移明显加剧，印证两项组件各司其职、互补而非冗余。
- GCCR 的"每 50 帧 / 每 100 帧周期"变体以较小精度损失换取更低延迟，为实际部署提供精度–效率折中。

### 6.6 核心结论
- **有效长序列几何建模无需逐层全局交互**：在少量几何关键层做跨窗口注意力即可隐式获得弱全局一致性。
- **局部几何与全局相机对齐可解耦**：深度靠窗口内传播，位姿靠轻量全局寄存器精化，二者分别处理可同时兼顾精度与有界内存。
- 由此在长序列重建、深度与位姿三任务上同时取得优于现有流式方法的综合表现。

## 7. 优点与局限

### 7.1 优点
- **问题定位精准**：清晰刻画"全局一致性 vs. 有界内存 vs. 长期漂移"的三方张力，并给出对应机制，而非笼统堆叠模块。
- **设计简洁且架构友好**：CWA 复用 DPTHead 固定关键层（[4, 11, 17, 23]），GCCR 仅作用于紧凑寄存器 token，改动小、易与 VGGT 生态兼容。
- **复杂度有界**：窗口内 $O(K^2)$ 与序列长度解耦，缓存仅保留前一窗口关键层 token，工程可实现性强。
- **实验覆盖广**：三任务、多数据集、多序列长度、消融与效率分析齐备，结论有据可依。

### 7.2 局限
- **算力与训练成本披露不足**：仅给出 16×H20 集群与两阶段 epoch 数，缺少总时长、GPU 小时、推理硬件等，复现与能耗评估受限。
- **部分基线结果异常或缺失**：个别指标（如 WinT3R 在 Sintel 上 $\delta<1.25$）异常偏低，且部分基线未报告全部指标或长序列结果，横向对比的完整性受影响。
- **关键层选择的依据未充分展开**：沿用 DPTHead 的 4 层是否最优、对更少/更多关键层的敏感性，论文未系统给出。
- **GCCR 周期设置偏经验**：50/100 帧周期缺乏理论或自适应依据，面对剧烈运动或长静止场景时的鲁棒性有待验证。
- **深度无显式全局约束**：在超大尺度或强回环场景下，仅靠局部传播是否足以避免深度尺度漂移，尚需更多极端场景验证。

## 8. 启示与展望

- **"少而关键"的全局交互**：LoG-VGGT 表明长序列建模的瓶颈未必在于全局注意力的缺失，而在于其被无差别地施加于所有层；将全局交互集中于几何关键层是更高效的归纳偏置。
- **解耦式精化范式**：将"稠密几何（局部传播）"与"稀疏全局状态（位姿/尺度对齐）"分而治之，可推广到 SLAM、流式重建、具身导航等需要长期一致性的任务。
- **可探索方向**：
  - 自适应关键层与自适应 GCCR 触发（按不确定性或漂移检测触发），替代固定层与固定周期；
  - 将 GCCR 扩展到深度尺度/回环一致性，形成统一的全局精化；
  - 结合显式回环检测或位姿图优化，进一步抑制超长序列漂移；
  - 在更多动态、剧烈运动与大尺度户外场景中验证鲁棒性，并公开训练/推理成本以便公平比较。
