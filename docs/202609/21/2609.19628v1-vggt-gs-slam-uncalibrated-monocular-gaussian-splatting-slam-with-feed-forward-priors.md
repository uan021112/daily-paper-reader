## 摘要
我们提出了VGGT-GS SLAM，一种面向未标定视频设计的单目3D高斯泼溅SLAM系统。以VGGT的前馈位姿和深度先验为起点，我们的系统执行子图可微光束法平差，联合优化相机位姿与3D高斯地图，同时通过解析标定雅可比优化子图共享的内参和径向-切向畸变。为提高全局一致性，我们引入高斯原生对齐（GNA），用于序列子图之间以相机为锚的尺度细化以及回环候选验证。在标准室内基准上的大量实验表明，在未标定设置下定位精度持续提升且渲染质量强，为未标定高斯SLAM建立了强基线。

## Abstract
We present VGGT-GS SLAM, a monocular 3D Gaussian Splatting SLAM system designed for uncalibrated videos. Starting from feed-forward VGGT pose and depth priors, our system performs submap differentiable bundle adjustment that jointly refines camera poses and a 3D Gaussian map, while optimizing submap-shared intrinsics and radial--tangential distortion through analytic calibration Jacobians. To improve global consistency, we introduce Gaussian-native alignment (GNA) for camera-anchored scale refinement between sequential submaps and verification of loop-closure candidates. Extensive experiments on standard indoor benchmarks show consistent improvements in localization accuracy and strong rendering quality under uncalibrated settings, establishing a strong baseline for uncalibrated Gaussian SLAM.

## 2. 方法论

### 2.1 核心思想
- 沿用 VGGT-SLAM 的子图组织方式，将 VGGT 位姿与深度预测**从初始化升级为可微优化变量**；
- 子图内做**标定感知的高斯光束法平差**（BA），子图间用**高斯原生对齐（GNA）** 做尺度细化与回环验证，最终在 Sim(3) 位姿图上做全局优化。

### 2.2 子图与初始化
- **子图窗口**：每个映射窗口含 `S + O` 帧（`S=24` 为新增关键帧，`O=1` 为重叠帧）。
- **VGGT 初始化**：对每个窗口预测外参 `{T^{c←w}_i}`、内参 `{K_i}`、深度-置信度 `{D_i, C_i}`；共享内参 `K` 取 `{K_i}` 均值，畸变系数初始化为 0。
- **高斯初始化**：按 MonoGS 策略，反投影有效深度像素（`D_i(p) > 1e-8`）得到世界点 `μ_j`，SH 颜色来自 `I_i(p)`，旋转为单位旋转，不透明度 `α_j = 0.5`（logit 为 0）；各向同性对数尺度为
  - `ℓ_j = log(0.1 · d_{nn,j})`，其中 `d_{nn,j}` 为同帧采样点最近邻距离。

### 2.3 联合光束法平差
- **优化变量**：高斯表示、相机位姿、逐帧仿射亮度参数、所有帧共享的相机模型；
- 固定首帧位姿作为子图参考系，其余位姿用左乘 SE(3) 增量更新 `T^{c←w}_i ← exp(ξ_i) T^{c←w}_i`，`ξ_i ∈ R^6`；
- 共享内参用**对数空间焦距更新 + 加性主点更新**；
- 五参数径向-切向畸变通过**有界参数化**约束：`k_j = s_k tanh(ρ_{k_j})`（j=1,2,3）、`p_j = s_p tanh(ρ_{p_j})`（j=1,2）。

**损失函数**：`L_BA = L_rgb + λ_depth · L_depth + λ_iso · L_iso`
- **光度损失**：仿射曝光补偿 `I'_i(p) = exp(a_i) I_i(p) + b_i`，`L1 + DSSIM` 组合；另设"曝光稳定变体"固定 `a_1 = b_1 = 0` 作为亮度参考，避免曝光与可学习颜色之间的"共同变暗歧义"。
- **深度损失**：以 VGGT 深度为弱几何先验，用带死区容差的相对残差 `r_i(p) = [|D̂_i - D_i| / max(D_i, ε) - τ_depth]_+`，并用中值归一化并截断的置信度 `C̃_i` 加权。
- **各向同性正则**：`L_iso = (1/3M) Σ ||s_j - s̄_j·1_3||_1`，抑制高度各向异性的高斯。

### 2.4 解析标定雅可比
- 在 gsplat 的可微高斯投影中，对完整标定向量 `θ_cal = (f_x, f_y, c_x, c_y, k_1, k_2, k_3, p_1, p_2)` 求解析导数；
- 相机模型：归一化坐标 `u=x/z, v=y/z`，径向因子 `d = 1 + k_1 r^2 + k_2 r^4 + k_3 r^6`，切向畸变项后得 `(U,V) = (f_x u_d + c_x, f_y v_d + c_y)`；
- **投影中心雅可比**：`∂m_2d/∂q = (∂D/∂q) m_d + D (∂m_d/∂q) + ∂c/∂q`；
- **投影协方差雅可比**：`J = D A B`，`Σ_2d = J Σ_3d^c J^T`，其导数由 `∂J/∂q = (∂D/∂q) A B + D (∂A/∂q) B` 组合得到；
- CUDA 核返回物理系数梯度，自动微分再施加有界参数链式法则（如 `∂L/∂ρ_k = (∂L/∂k) s_k (1 - tanh²ρ_k)`）。

### 2.5 高斯原生对齐（GNA）
- **相机锚定初始化**：相邻子图共享重叠关键帧，由共享图像位姿确定旋转 `R`，由同像素深度对应关系确定初始尺度 `s_0`，由相机中心 `c_A, c_B` 固定平移 `t_0 = c_A - s_0 R c_B`；**固定 R，仅优化对数尺度** `u = log s`；
- **变换公式**：`μ^{B→A}_j(u) = c_A + s R (μ^B_j - c_B)`，`Σ^{B→A}_j(u) = s² R Σ^B_j R^T`；
- **匹配核**：对参考高斯 `i` 与变换后源高斯 `j`，定义 `d_ij`、`S_ij = Σ^A_i + Σ^{B→A}_j + (ε + τ²)I_3`，采用对数核 `κ_ij(u) = -½ (d_ij^T S_ij^{-1} d_ij + λ_det log|S_ij|)`；
- **双向得分**：以不透明度与观测次数加权 `w_i = max{α_i²/[1+log(1+n_i)], 1e-6}`，对 `k` 近邻做归一化得 `ℓ_{B→A}` 与反向得分；
- **优化目标**：`L_GNA(u) = -ℓ_{B→A}(u) - ℓ_{A→B}(u) + λ_sp (u - log(m_A/m_B))²`，其中最后一项为密度敏感的先验；尺度更新被限制在初始化附近，且仅在改进归一化目标时保留，否则保留 `s_0`。

### 2.6 回环闭合与高斯原生验证
- 用 SALAD 描述子对历史子图做检索，排除直接前驱，保留描述子距离低于阈值 `τ_r` 的最近配对；
- 检索到的图像仅追加到**独立的联合 VGGT 回环推理批次**，其深度对应初始化子图间 Sim(3)；
- **GNA 在回环中仅用于验证**（不做变换精化）：接受条件为 `L* = L_GNA(u*) ≤ τ_L` 且 `Δs = |log(s*/s_0)| ≤ τ_s`，另加旋转一致性检查（与序列链偏差不超过 90°）；
- 接受的回环**保留原始 VGGT 桥接变换**；位姿图节点为局部-全局子图变换 `G_i ∈ Sim(3)`，优化仅更新 `G_i`，不改动局部高斯、位姿与标定，子图不合并。

### 2.7 实现细节
- **关键帧选择**：LK 跟踪点平均像素位移超过 `τ_disp = 30 px` 或有效轨迹少于 10 条时选新关键帧；
- **高斯精化**：按 MonoGS 周期性克隆/分裂（基于累积图像空间梯度）与剪枝低不透明度高斯；
- **非关键帧位姿估计**：使用该帧之前最新起始关键帧的局部子图（非全局合并地图），固定高斯地图与标定，SE(3) 优化 90 次迭代。
