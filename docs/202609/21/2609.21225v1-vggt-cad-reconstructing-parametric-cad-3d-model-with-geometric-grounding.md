## 摘要
参数化CAD重建需要从视觉观测中同时恢复精确的几何形状和可编辑的建模操作，这使它在视角有限且模糊的情况下颇具挑战。现有方法主要依赖二维外观线索，缺乏强有力的多视角几何先验。在本工作中，我们提出VGGT-CAD，一种用于单视角和多视角观测下参数化CAD重建的几何感知框架。我们通过将相机参数编码为条件标记，并与图像标记联合建模，将预训练的三维几何先验迁移到CAD重建中。为了处理不同数量的视角，我们引入可变视角的跨视角上下文聚合模块，以自适应融合多视角特征。我们进一步开发了一种免训练的几何感知视角选择策略，在推理时选择互补且可靠的帧。所得表示使用非自回归解码器解码为CAD命令序列。我们还开发了VideoCAD，一个通过多视角重渲染从现有CAD数据衍生的大规模多视角视频基准。大量实验证明了VGGT-CAD在不同观测配置下用于视觉CAD重建的有效性。

## Abstract
Parametric CAD reconstruction requires recovering both precise geometry and editable modeling operations from visual observations, making it challenging under limited and ambiguous views. Existing methods mainly rely on 2D appearance cues and lack strong multi-view geometric priors. In this work, we present VGGT-CAD, a geometry-aware framework for parametric CAD reconstruction from single- and multi-view observations. We transfer pretrained 3D geometric priors into CAD reconstruction by encoding camera parameters as condition tokens and jointly modeling them with image tokens. To handle varying numbers of viewpoints, we introduce a variable-view cross-view context aggregation module that adaptively fuses multi-view features. We further develop a training-free geometry-aware view selection strategy to select complementary and reliable frames during inference. The resulting representation is decoded into CAD command sequences using a non-autoregressive decoder. We also develop VideoCAD, a large-scale multi-view video benchmark derived from existing CAD data through multi-view re-rendering. Extensive experiments demonstrate the effectiveness of VGGT-CAD for visual CAD reconstruction under different observation configurations.

## 二、论文提出的方法论

### 核心思想
- 将大规模 3D 视觉理解中的几何感知先验迁移到 CAD 重建任务中，通过相机条件化的视觉建模，统一处理单视图与多视图输入。
- 核心流程：几何感知视图选择 → 相机条件编码 → 几何多视图视觉编码 → 跨视图上下文聚合 → 非自回归 CAD 序列解码，并辅以相机位姿重建的辅助监督。

### 关键技术细节

**1. 问题形式化**
- 输入：单目视频 V（划分为 T=36 帧），训练时随机采样 N∈[2,8] 帧构成多视图集合 I，以及对应的相机内外参 P。
- 输出：长度为 Nc 的操作序列 M = [C₁, C₂, …, C_Nc]，每个命令 C_j 包含离散命令类型 t_j 和参数向量 p_j。
- 建模为条件概率生成模型：p(M|I, P, Θ) = ∏ p(t_j, p_j|I, P, Θ)。

**2. 命令序列表示**
- 聚焦草图（Sketch）和拉伸（Extrude）两类核心操作。
- 参数统一堆叠为固定长度 16 维向量 p_j = [x, y, α, f, r, θ, φ, γ, p_x, p_y, p_z, s, e₁, e₂, b, u]，未使用槽位填充 −1。
- 将模型包围盒归一化到 [−1,1]³，所有连续参数量化为 256 个离散等级，将回归问题转化为分类问题。

**3. 网络架构（五大模块）**
- **相机条件编码器**：对第 i 个视角，计算相机到世界的位姿编码，结合内参与图像尺寸生成初始位姿特征，经 MLP 映射后送入深度 L_cam 的 Transformer 主干，输出相机 token c_i ∈ R^d。
- **几何多视图视觉编码器**：采用 VGGT 的多视图视觉编码结构作为骨干，将相机 token 与图像 patch token 沿序列维度拼接 S_i = [c_i ‖ x_{i,1}, …, x_{i,M}]，在每个视角内进行自注意力计算，并在特定层进行跨视图自注意力交互，使相机方向信息自然传播到所有图像特征。输出拆分得到相机特征和图像特征（重塑为 h×w×d 特征图）。
- **相机条件解码器**：用两层全连接网络加三个独立预测头，分别回归平移向量、旋转四元数和水平/垂直视场角，并转换为焦距，构造辅助位姿重建监督信号。
- **跨视图上下文聚合器**：因输入视角数 N 动态变化（2–8），采用共享权重 2D 卷积编码器压缩每个视角特征为 1D 向量 v_i，再通过基于 MLP 的注意力网络计算各视角注意力权重 α_i（softmax 归一化），加权求和得到融合特征，最后线性投影为固定维度的全局隐向量 z。
- **序列解码器**：采用非自回归 Transformer，以可学习常量嵌入 E ∈ R^{Nc×dE} 作为查询，通过交叉注意力与全局隐向量 z 交互，输出经两个并行线性预测头，分别预测命令类型分布和 16 个参数的 256 类概率分布。

**4. 优化与训练**
- 总损失 L_total = L_CAD + λL_cam，其中 λ = 1.0。
- CAD 序列生成损失包含命令类型交叉熵和参数交叉熵，β = 2 平衡两者权重，使用有效性掩码排除无效槽位和填充位置。
- 相机损失包含平移损失 L_t、旋转损失 L_q（考虑四元数双重覆盖性质取 min）和焦距损失 L_f（除以图像尺寸归一化）。
- 训练策略：使用 LoRA 微调几何多视图视觉编码器骨干（rank r=32），其余模块（相机编解码器、跨视图聚合器、序列解码器）从头训练，以避免灾难性遗忘。

**5. 几何感知确定性视图选择（免训练）**
- 将测试时帧选择建模为固定基数预算下的确定性观测子集优化问题，近似最大化信息增益 I(S; G)。
- 边际选择分数：Δ(i|S_{t-1}) = λ_c·C(i|S_{t-1}) + λ_q·Q(i) − λ_r·R(i|S_{t-1})。
- **几何覆盖增益 C**：综合光轴夹角、相机中心基线距离和水平方位角差异，鼓励选择能观测新表面的帧。
- **图像质量项 Q**：基于拉普拉斯方差的清晰度、亮度熵和前景占比，优先选择视觉证据稳定的帧。
- **冗余惩罚项 R**：基于位姿相似度建模边际收益递减，抑制重复观测。
- 采用确定性贪心策略逐步构建视角集合，不引入额外网络参数。

## 六、论文的主要结论与发现

- VGGT-CAD 在单视图和多视图设置下均取得最优整体性能：多视图下 ACC_cmd 达 0.8213、ACC_param 达 0.7104、Mean CD 降至 0.0670、IR 为 0.3020，显著优于 DeepCAD-Mv 和 Hunyuan3d-Mv。
- 显式相机位姿约束不可或缺：完整相机条件架构相比无相机基线 Mean CD 降低 34.02%。
- LoRA 微调远优于全量 SFT：不仅减少 11.4 倍可训练参数，还避免了预训练几何先验的灾难性遗忘，ACC_cmd 从 0.7202 提升至 0.8213。
- 跨视图上下文聚合器优于传统池化方法，能根据信息密度和遮挡状态动态分配融合权重。
- 增加输入视角数量总体提升性能，从 1 到 6 个视角 Mean CD 显著下降，6–8 个视角后趋于平稳。
- 视图选择中几何覆盖项贡献最大，质量项应作为辅助线索，冗余项主要抑制近重复视图。
