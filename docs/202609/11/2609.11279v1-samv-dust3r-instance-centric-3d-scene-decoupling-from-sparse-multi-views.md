## 摘要
随着从3D场景中解耦物体的需求日益增长，我们提出了SAMV-DUSt3R，一种将SAM2的2D掩码注入MV-DUSt3R重建的端到端模型。Cross Flow Mask Block利用这些掩码引导网络关注目标实例，在无需多阶段流程的情况下同时提升形状精度并实现对象级解耦。为确保重建稳定性，轻量级Spatial RankGNN选择最佳参考视角，选择准确率为73.5%。大量实验表明，与最先进的基线相比，我们的方法在多种指标上将平均重建精度提升了11%。这些结果揭示了强大的实例解耦能力，并对驾驶、机器人、AR/VR和文化遗产数字化具有明显益处。

## Abstract
With the rising demand to decouple objects from 3D scenes, we propose SAMV-DUSt3R, an end-to-end model that injects SAM2 2D masks into MV-DUSt3R reconstruction. A Cross Flow Mask Block uses these masks to steer the network toward the target instance, jointly improving shape accuracy and achieving object-level disentanglement without multi-stage pipelines. To ensure reconstruction stability, a lightweight Spatial RankGNN selects the optimal reference view with a selection accuracy of 73.5\%. Extensive experiments demonstrate that our method boosts average reconstruction precision by 11\% across various metrics compared to state-of-the-art baselines. These results reveal a strong instance-disentanglement capability and clear benefits for driving, robotics, AR/VR, and heritage digitisation.

## 2. 方法论
### 2.1 总体思想
- **端到端实例中心 3D 解耦**：输入为多张无序、未标定 RGB 图像和用户提示；SAM2 生成目标在多视角下的分割掩码与掩码嵌入；MV-DUSt3R 编码器-解码器生成点图与置信图。
- **输出三元组**：每个输入视图对应预测点图 \(X\)、置信图 \(C\)、分割掩码 \(M\)，即 \((X, C, M)\)。
- **核心模块**：
  - **Spatial RankGNN**：自动选择最佳参考视图，提升重建稳定性。
  - **Cross Flow Mask Block**：将 SAM2 掩码信息融入 MV-DUSt3R 解码特征，引导网络关注目标实例。
  - **Masked Confidence Loss**：在目标掩码区域内重新加权并正则化置信分布，缓解低置信问题。

### 2.2 Spatial RankGNN：自动参考视图选择
- **问题建模**：将多视图间的立体信息交换建模为图结构，每个视图为节点，视图间共视点数量为边权；提供信息更多的视图更适合作为参考视图。
- **网络结构**：
  - 输入为 MV-DUSt3R 编码器产生的图像嵌入。
  - 使用多层 `RankMessagePassing`，基于多头自注意力进行全局节点消息传递。
  - 每个像素/空间位置可视为节点参与跨图像注意力，复杂度为 \(O(LN^2)\)，其中 \(N\) 为视图数，\(L\) 为层数。
  - 经过空间平均池化得到图像级嵌入，再由两层 MLP 与 Sigmoid 输出归一化排序分数。
- **训练数据与损失**：
  - 使用 SfM 管线处理 3600 个多视图场景，视图数为 4/12/24，分布比例 5:8:23。
  - GT 分数由相邻节点共视点数量求和后 Min-Max 归一化到 [0,1]。
  - 损失为 Score Rank Loss：  
    \[
    L_{\text{scorerank}} = \alpha \cdot L_{\text{mse}} + (1-\alpha)\cdot L_{\text{marginranking}},\quad \alpha=0.2
    \]
  - 预测排序与 GT 排序差在 \([-1,0,1]\) 内视为正确；4 视图场景不采用该容忍准则。
  - 最终参考视图选择准确率为 **73.5%**。

### 2.3 Cross Flow Mask Block：掩码引导的跨注意力融合
- **目标**：用 2D 目标掩码增强序列级重建特征，使网络显式关注目标物体区域。
- **输入来源**：
  - MV-DUSt3R 编码器-解码器产生的序列嵌入。
  - SAM2 生成的 2D 物体掩码，经轻量 CNN adapter 转换为 token 对齐表示。
- **机制**：
  - 以 MV-DUSt3R 序列 token 作为 query。
  - 以掩码卷积特征作为 key 和 value。
  - 通过多头跨注意力实现 3D 场景理解与 2D 掩码先验的细粒度空间对齐。
  - 后续加入残差连接、LayerNorm 和前馈网络，保持表示保真与梯度流动。
- **作用**：作为 mask-aware attention filter，以可微、数据驱动方式引导全局序列表示聚焦目标区域。

### 2.4 Masked Confidence Loss：缓解置信度盆地
- **问题**：目标物体像素在整体重建中可能出现低置信，直接提升置信并不能改善底层 3D 位置回归。
- **基础置信损失**：沿用 DUSt3R 类模型中的置信加权回归损失：
  \[
  L_{\text{conf}}=\sum_{v}\sum_{p} C^{v,r}_p \ell_{\text{regr}}(v,p)-\beta \log C^{v,r}_p
  \]
- **前景加权**：
  - 定义二值前景掩码 \(M^v_p=1\) 表示像素属于目标。
  - 引入权重 \(w^v_p=1+\gamma M^v_p\)，其中 \(\gamma=0.2\)。
  - 回归损失变为 \(C^{v,r}_p w^v_p \ell_{\text{regr}}(v,p)\)，提高目标像素权重但保留背景监督。
- **掩码内置信均匀正则**：
  - 计算每个视图掩码区域平均置信 \(\bar{C}_v\)。
  - 加入正则项：
    \[
    L_{\text{msk conf}}=L_{\text{conf}}+\lambda\sum_v\sum_p M^v_p(C^{v,r}_p-\bar{C}_v)^2,\quad \lambda=0.01
    \]
  - 该正则鼓励掩码内置信均匀，同时原 \(-\beta \log C\) 项确保置信被提升而非抑制。
- **训练策略**：分别训练两个专用模型——用于参考视图选择的 Spatial RankGNN，以及用于增强点图回归的 Cross Flow Mask Block。
