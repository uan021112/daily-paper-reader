## 摘要
参数化CAD重建需要从视觉观测中恢复精确几何与可编辑建模操作，这使其在视角有限且存在歧义时颇具挑战。现有方法主要依赖二维外观线索，缺乏强多视角几何先验。本文提出VGGT-CAD，一个几何感知框架，用于从单视角和多视角观测中进行参数化CAD重建。我们将预训练的三维几何先验迁移到CAD重建中：将相机参数编码为条件token，并与图像token联合建模。为处理不同数量的视角，我们引入可变视角跨视角上下文聚合模块，自适应融合多视角特征。我们进一步提出一种无需训练的几何感知视角选择策略，在推理时选择互补且可靠的帧。所得表示通过非自回归解码器解码为CAD命令序列。我们还构建了VideoCAD，一个大规模多视角视频基准，通过多视角重渲染从现有CAD数据派生而来。大量实验证明了VGGT-CAD在不同观测配置下用于视觉CAD重建的有效性。

## Abstract
Parametric CAD reconstruction requires recovering both precise geometry and editable modeling operations from visual observations, making it challenging under limited and ambiguous views. Existing methods mainly rely on 2D appearance cues and lack strong multi-view geometric priors. In this work, we present VGGT-CAD, a geometry-aware framework for parametric CAD reconstruction from single- and multi-view observations. We transfer pretrained 3D geometric priors into CAD reconstruction by encoding camera parameters as condition tokens and jointly modeling them with image tokens. To handle varying numbers of viewpoints, we introduce a variable-view cross-view context aggregation module that adaptively fuses multi-view features. We further develop a training-free geometry-aware view selection strategy to select complementary and reliable frames during inference. The resulting representation is decoded into CAD command sequences using a non-autoregressive decoder. We also develop VideoCAD, a large-scale multi-view video benchmark derived from existing CAD data through multi-view re-rendering. Extensive experiments demonstrate the effectiveness of VGGT-CAD for visual CAD reconstruction under different observation configurations.

## 2. 方法论

### 2.1 核心思想
- 将预训练 3D 几何先验（VGGT）迁移到参数化 CAD 重建，通过**相机条件化的视觉建模**实现外观、空间布局与跨视图一致性的联合推理。
- 统一端到端框架，支持**单图像或多视图视频**输入，输出可被标准 CAD 内核执行的可编辑参数化命令序列。

### 2.2 问题形式化
- 给定单目视频 V，采样为 T=36 帧；每次训练随机采样 N∈[2,8] 帧构成多视图输入集 I={I₁,…,I_N}，并输入对应相机外参与内参 P={P₁,…,P_N}。
- 目标为生成操作序列 M=[C₁,…,C_{Nc}]，每个命令 C_j=(t_j, p_j)，其中 t_j 为离散命令类型，p_j 为参数向量。
- 整体建模为条件概率生成模型：p(M|I,P,Θ)=∏_{j=1}^{Nc} p(t_j,p_j|I,P,Θ)。

### 2.3 命令序列表示
- 将边界表示（B-Rep）转化为类自然语言命令序列，聚焦**草图（Sketch）**与**拉伸（Extrude）**两类核心操作。
- 每个命令参数统一堆叠为固定 16 维向量 p_j=[x,y,α,f,r,θ,φ,γ,p_x,p_y,p_z,s,e₁,e₂,b,u]，覆盖 2D 坐标、角度、拉伸距离、布尔类型等；未用槽位以 −1 填充。
- 将模型包围盒归一化到 [−1,1]³，并将连续参数**量化为 256 个离散等级**，把连续回归转为离散分类，便于网络优化。

### 2.4 网络架构（五大模块）
1. **几何感知确定性视角选择（GAD View Selection）**：推理时选择信息量大、互补且可靠的帧。
2. **相机条件编码器（Camera Condition Encoder）**：
   - 对第 i 个视角，由相机外参/内参计算相机到世界位姿编码，结合内参与图像尺寸生成初始位姿特征向量；
   - 经 MLP 映射与深度为 L_cam 的 Transformer 主干迭代精炼，LayerNorm 后输出相机 token c_i∈R^d。
   - 实践中可用 ARCore/ARKit/AREngine 实时估计相机位姿。
3. **几何多视图视觉编码器（Geometric Multi-View Visual Encoder）**：
   - 以 VGGT 多视图视觉编码结构为骨干，引入其多视图 3D 理解几何先验；
   - 图像分块为 token 序列 X_i，与相机 token 拼接为 S_i=[c_i‖x_{i,1},…,x_{i,M}]；
   - 在骨干中既做视角内自注意力，也在特定层做**跨视图自注意力**：Attention(x_k^(i),X)=Softmax(Q_k^(i)Kᵀ/√d)V，其中 K、V 来自所有视角 token，使视角方向信息自然传播；
   - 输出后按位置拆分出相机特征 c_i 与图像特征 F_i，并将 1D 图像 token 重塑为 h×w×d 的 2D 特征图。
4. **相机条件解码器（Camera Condition Decoder）**：用两层全连接网络加三个预测头，分别回归平移向量 t_i∈R³、旋转四元数 q_i∈R⁴、水平/垂直视场角 f_i^FOV∈R²（ReLU 保证非负），再由 FOV 换算为像素焦距：f̂_x=W/(2tan(FOV_w/2))、f̂_y=H/(2tan(FOV_h/2))，作为辅助位姿重建监督。
5. **可变视角跨视图上下文聚合器（Cross-View Context Aggregator）**：
   - 用共享权重 2D 卷积编码器 + 自适应平均池化，将各视角特征压成 1D 向量 v_i；
   - 用基于 MLP 的注意力网络计算各视角权重并 softmax 归一化：α_i=exp(MLP_attn(v_i))/Σ_j exp(MLP_attn(v_j))；
   - 加权求和得 f_fused=Σ_i α_i v_i，再经线性投影输出固定维全局隐向量 z∈R^{dz}。
6. **序列解码器（Sequence Decoder）**：
   - 采用**非自回归** Transformer，以 Nc 个可学习常量嵌入 E 作为查询，经交叉注意力与全局隐向量 z 交互；
   - 第 l 层更新：H^(l)=FFN(CrossAttn(SelfAttn(H^(l−1)), z))；
   - 两个并行预测头：命令分类头输出命令类型分布，参数分类头输出 16×256 维（每个参数独立预测 256 类）。

### 2.5 训练与优化
- 总损失 L_total = L_CAD + λL_cam，取 λ=1.0。
- CAD 序列损失：L_CAD = L_type + βL_param（β=2），均为交叉熵；通过 Validity Mask 排除无效参数槽位与序列尾部填充。
- 相机损失 L_cam = L_t + L_q + L_f，其中旋转损失用 min 处理四元数双覆盖（q 与 −q 表示同一旋转），焦距损失按图像宽高归一化。
- **LoRA 微调**：仅对几何多视图视觉编码器骨干使用 LoRA（r=32），避免全参数微调破坏预训练几何先验与灾难性遗忘；相机编解码器、跨视图聚合器、序列解码器从头训练。

### 2.6 几何感知确定性视角选择
- 将测试时帧选择形式化为**固定基数预算下的观测子集优化**问题：S* = argmax_S I(S;G) s.t. |S|=K；因真实 CAD 结构不可见，用可计算的代理边际效用近似，并用确定性贪心策略增量构建。
- 边际选择得分：Δ(i|S_{t−1}) = λ_c·C(i|S_{t−1}) + λ_q·Q(i) − λ_r·R(i|S_{t−1})，其中 C、Q、R 均归一化到 [0,1]。
  - **几何覆盖增益 C**：由相机光轴夹角、相机中心基线、水平方位角差三项组成，鼓励选择能观察新表面、补充侧/后结构的帧。
  - **图像质量项 Q**：由 Laplacian 方差（清晰度）、亮度熵（纹理/曝光）、前景占比三项组成。
  - **冗余惩罚项 R**：由光轴方向、相机中心、方位角与已选集合的相似度组成，抑制近重复帧。
- 该模块不增加网络参数，仅改善输入证据条件。

## 7. 局限性

- **命令空间受限**：仅建模 Sketch + Extrude 两类操作，未覆盖倒角、圆角、布尔运算、旋转、放样等更复杂的 CAD 操作，无法表达真实工业 CAD 的完整命令流。
- **参数量化误差**：将连续参数离散化为 256 等级虽便于分类优化，但引入量化误差，对高精度工程场景可能不可接受。
- **依赖相机位姿**：框架假设可获得相机内参/外参（尽管作者指出可用 ARCore/ARKit 等实时估计），在纯单图无位姿场景下需退化为估计模式，精度受位姿估计质量影响。
- **数据域偏移**：VideoCAD 由 DeepCAD 与自采数据渲染合成，与真实拍摄的工业零件图像在纹理、光照、背景上存在差距，跨域泛化能力未充分验证。
- **评测维度局限**：主要使用 CD、命令/参数准确率与无效比例，未评估拓扑正确性（如面/边/顶点数量一致性）、可编辑性质量或下游 CAD 任务（如仿真、装配）的可用性。
- **训练成本与规模**：虽采用 LoRA 降低开销，但全文未披露总训练时长、总 GPU 小时与完整训练曲线，复现成本与收敛行为不够透明。

## 8. 潜在影响与启示

- **方法论层面**：将大规模 3D 视觉基础模型（VGGT）的几何先验迁移至结构化程序生成任务，为"视觉基础模型 → 参数化 CAD"这一跨模态方向提供了可复用范式，提示未来可将更多 3D 基础模型（如 DUSt3R、MASt3R 等）引入 CAD 重建。
- **任务定义层面**：VideoCAD 基准（20.8 万模型、751 万帧、36 视角）填补了"视频/多视图 → 参数化 CAD"的数据空白，有望推动社区从单图 CAD 重建向更贴近真实拍摄流程的多视图设定迁移。
- **工程应用层面**：单图与多视图统一、可输出标准 CAD 内核可执行序列的设计，使其具备逆向工程、AR 辅助设计、快速原型等落地潜力；GAD 视角选择作为无参数模块，易于插入其他多视图任务。
- **效率与可持续性层面**：LoRA 微调与轻量视角选择的组合，为在有限算力下训练大几何模型提供了成本友好方案，呼应绿色 AI 的诉求。
- **未来方向**：扩展命令空间至完整 B-Rep 操作集、引入连续/扩散式参数解码以消除量化误差、结合真实工业扫描数据做跨域评测、以及探索无位姿条件下的联合位姿-CAD 优化，均是自然延伸。
