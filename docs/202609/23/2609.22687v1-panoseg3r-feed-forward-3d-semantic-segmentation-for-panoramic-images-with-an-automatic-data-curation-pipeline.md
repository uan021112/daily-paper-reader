## 摘要
我们提出 PanoSeg3R，一种用于三维全景语义分割的前馈式框架。与面向透视输入设计的现有方法不同，PanoSeg3R 在单次前向传播中联合预测三维几何与多视角语义分割。基于一个支持全景图像的预训练重建骨干网络，我们的方法通过基于查询的掩码解码器扩展了前馈式三维重建。此外，我们引入了一种自动全景数据整理流水线，利用现成基础模型的互补优势生成可靠的伪语义标注，显著扩展训练数据并提升零样本泛化能力。PanoSeg3R 在全景三维语义分割上取得了最先进的性能，在 ScanNet++ 上将 3D mIoU 最高提升 16.02，而整理后的训练数据进一步将 Stanford2D3D 和 ToF-360 上的零样本性能分别最高提升 4.26 和 43.28 mIoU。网站：https://harryyoon777.github.io/PanoSeg3R/

## Abstract
We present PanoSeg3R, a feed-forward framework for 3D panoramic semantic segmentation. Unlike existing methods designed for perspective inputs, PanoSeg3R jointly predicts 3D geometry and multi-view semantic segmentation in one single forward pass. Built upon a pretrained reconstruction backbone that supports panoramic images, our approach extends feed-forward 3D reconstruction with a query-based mask decoder. Furthermore, we introduce an automatic panorama data curation pipeline that leverages the complementary strengths of off-the-shelf foundation models to generate reliable pseudo semantic annotations, substantially expanding the training data and improving zero-shot generalization. PanoSeg3R achieves state-of-the-art performance on panoramic 3D semantic segmentation, improving 3D mIoU by up to 16.02 on ScanNet++, while the curated training data further improves zero-shot performance by up to 4.26 and 43.28 mIoU on Stanford2D3D and ToF-360, respectively. ## 1. 核心问题与研究动机

- **背景**：3D 场景理解对沉浸式媒体、机器人、自主导航等应用至关重要。近期基于学习的前馈式多视图方法（PanSt3R、IGGT、Uni3R 等）已能同时完成三维几何重建与稠密语义预测，但它们主要面向**透视（perspective）图像**。
- **痛点一：视场受限**。透视图像视场角有限，需要大量重叠观测才能覆盖大场景，采集效率低。全景相机（ERP 等距柱状投影表示）单视角即可覆盖 360°，信息更丰富。
- **痛点二：全景方法无法直接复用**。透视模型若处理全景输入，必须先经立方体贴图（cubemap）或切平面投影转换为透视视图，这会带来额外计算开销，并破坏跨视图的几何与语义一致性（论文 Figure 1 直观展示）。
- **痛点三：标注数据稀缺**。全景图像的像素级语义标注成本高、劳动密集，缺乏大规模标注全景数据集，制约了该方向的发展。
- **核心问题**：如何实现**全景原生（panorama-native）**的前馈式多视图 3D 语义分割，并解决训练数据不足的问题。
- **论文含义**：据作者所述，PanoSeg3R 是**首个无需 ERP 到透视投影**即可完成 3D 语义分割的方法，同时提出自动伪标注流水线以扩充训练数据、提升零样本泛化。

## 2. 方法论

### 2.1 整体思路
- 在支持全景输入的前馈式重建骨干 **Wid3R** 之上，扩展一个**基于查询（query-based）的掩码解码器**，单次前向传播同时输出三维几何与多视图语义掩码。
- 采用冻结的 **SigLIP 文本编码器**统一表示不同数据集的类别名称，从而支持跨数据集（类别集合不同）联合训练。
- 提出四阶段**自动全景数据整理流水线**，用现成基础模型生成可靠伪语义标注。

### 2.2 全景特征与几何提取
- Wid3R 将每个像素表示为**相机光线**，用球谐函数编码光线方向，对全景畸变更鲁棒（区别于直接预测点图的透视方法）。
- 多视图全景图像 $\{I_i\}_{i=1}^{N}$ 被编码为图像 token 序列 $T_i^{(0)} \in \mathbb{R}^{K \times d_T}$，经交替的帧内注意力与全局注意力层处理，得到第 $l$ 层表示 $T_i^{(l)}$（$1 \le l \le L$）。
- 每个全景图预测稠密**光线方向图** $R_i$ 与**径向距离图** $D_i$，三维点图为 $P_i = R_i \odot D_i$。

### 2.3 语义掩码预测与分类
- **查询精炼**：引入 $N_q$ 个可学习语义查询 $Q_n^{(0)} \in \mathbb{R}^{d_Q}$，在解码器中与最终层 token $T^{(L)}$ 做交叉注意力、并做自注意力，得到精炼查询 $\hat{Q}_n = \mathrm{Dec}(Q_n^{(0)}, T^{(L)})$。
- **语义分类**：SigLIP 将 $J$ 个类别名编码为文本嵌入 $\{t_j\}$；查询经线性投影头得 $q_n^{cls} = \mathrm{Lin}_{cls}(\hat{Q}_n)$，分类分数为余弦相似度：$p_{n,j} = \mathrm{sim}(q_n^{cls}, t_j)$。
- **掩码预测**：用 DPT 头聚合多尺度 token 表示，解码为稠密特征图 $F_i \in \mathbb{R}^{d_F \times \frac{H}{2} \times \frac{W}{2}}$。
- **低级特征注入（Image Stem）**：由于 ERP 图像每个 patch token 覆盖的视场远大于透视图像，细粒度空间细节在 token 化时丢失。因此设计图像主干（跨步卷积 + 残差卷积块 + 1×1 投影）提取 $S_i$，**所有卷积层使用循环填充（circular padding）**以保持 ERP 水平连续性。
- **特征融合与掩码生成**：$\tilde{F}_i = \mathcal{H}(F_i + S_i)$；掩码 $M_{n,i} = \mathrm{Sigmoid}\big((q_n^{mask})^\top \tilde{F}_i\big)$，其中 $q_n^{mask} = \mathrm{MLP}_{mask}(\hat{Q}_n)$。
- **训练损失**：沿用 Mask2Former 形式 $L = \lambda_c L_{cls} + \lambda_d L_{dice} + \lambda_b L_{bce}$。

### 2.4 自动数据整理流水线（四阶段）
1. **预处理**：ERP 图像按方位角每 72° 均匀投影为 5 张无畸变透视图，每张再垂直切分为高/中/低 3 块，共 **15 个透视图块**（分辨率 $c_w \times c_h$，水平/垂直重叠 $o_h, o_v$），降低 ERP 投影畸变。
2. **掩码生成**：**SAM3** 直接在 ERP 图上生成类别无关掩码 $M_{SAM3}=\{m_k\}$（边界精确但无语义）；**PanSt3R** 处理 15 个图块，输出限定于 100 个 ScanNet++ 类别的语义区域 $(r_i, c_i)$（有语义但边界粗糙）。
3. **掩码聚合**：将 PanSt3R 区域反投影回 ERP 空间得 $\tilde{er}_i$，对每个 SAM3 掩码计算亲和度 $A_{k,i} = \mathrm{IoU}(m_k, \tilde{er}_i)$；当 $A_{k,i} > \tau_{IoU}$ 视为有效匹配，取 IoU 最大的区域标签 $\hat{c}_k = c_{i^*}$，否则掩码保持无标签。
4. **VLM 过滤**：对每个已标注掩码裁出局部 RGB 区域并用红框高亮，用 **Qwen3-VL-8B** 配合思维链提示判断标签是否正确，删除被判为 "Incorrect" 的掩码。

### 2.5 训练细节
- 冻结 Wid3R 骨干，仅训练语义分割头；AdamW 优化器，峰值学习率 $1\times10^{-4}$；$\lambda_c=0.5$、$\lambda_d=1$、$\lambda_b=1$。
- ERP 输入缩放到 518×336；整理流水线使用 1024×512 的 ERP，切分为 15 块（$c_w=256, c_h=192, o_h=85, o_v=64$），$\tau_{IoU}=0.7$。
- 采用 Wid3R 的采样与增强策略：同场景内基于距离采样相邻视点以保证重叠；几何增强同步作用于 RGB 与 GT 掩码，光度增强只作用于 RGB。

## 4. 实验结果

### 4.1 有监督（域内）3D 语义分割
- 在 ScanNet++ 与 Matterport3D 上，PanoSeg3R 在 **3D mIoU / mAcc** 上均优于全部对比方法。
- 与透视前馈方法（PanSt3R、IGGT、Uni3R）相比，优势主要来自：全景原生处理避免了 cubemap 六面转换带来的边界不连续与重叠区域语义冲突；单视角覆盖范围大，跨视图对应更稳定。
- 与全景 2D 专用方法（PanoSAMic 等）相比，PanoSeg3R 是前馈式 3D 输出，几何与语义在同一框架内联合预测，无需额外融合或后处理。

### 4.2 零样本跨数据集泛化
- 在 Stanford2D3D 与 ToF-360 上做零样本迁移评测（仅共享类别），PanoSeg3R 显著优于基线。
- 关键结论：**伪标注数据（Realsee3D、OmniScenes）的加入对零样本性能提升最明显**，说明自动整理流水线能有效扩充类别与场景多样性，缓解全景标注稀缺问题。
- 值得注意的是，纯用官方标注数据训练时，模型在跨域场景下退化较快，凸显数据规模与场景多样性对泛化的重要性。

### 4.3 2D 语义分割
- 在 ERP 图像上直接评测 2D mIoU / mAcc，PanoSeg3R 同样取得领先或可比结果，说明其语义头在全景投影域内也是有效的，而非仅依赖 3D 几何对齐。

### 4.4 消融结论
- **训练数据组成**：Base + OmniScenes + Realsee3D（Both）效果最佳，验证伪标注的互补价值。
- **Image Stem**：去掉后细粒度边界明显变差；使用**循环填充**优于零填充（避免 ERP 左右边界出现断裂）；保留末端残差单元略有增益；残差块数量存在最优值，过多反而引入冗余。
- **数据整理流水线**：SAM3 提供精确边界、PanSt3R 提供语义、VLM 过滤剔除错标，三者缺一不可。VLM 过滤能显著降低噪声标签比例，且对正确掩码的误删率较低。
- **裁剪配置**：15 块（5 方位角 × 3 高度）是精度与开销的较好折中；块数过少畸变残留多，过多则冗余计算且引入重复区域冲突。
- **效率**：全景原生单次前向相比 cubemap 六次前向（或切平面多视图）显著降低时延与显存，且精度更高。

## 5. 贡献与创新点
1. **首个全景原生前馈式 3D 语义分割框架**：无需 ERP→透视投影，直接在 ERP 上完成几何重建与语义分割。
2. **基于查询的语义解码器 + SigLIP 文本对齐**：统一类别表示，支持类别集合不同的多数据集联合训练。
3. **Image Stem 与循环填充**：针对 ERP patch 视场过大导致的细节丢失问题，恢复细粒度空间信息并保持水平连续性。
4. **四阶段自动全景数据整理流水线**：结合 SAM3、PanSt3R 与 VLM 过滤，自动生成高质量伪语义标注，显著提升零样本泛化。

## 6. 局限与未来工作
- 伪标注仍依赖 ScanNet++ 的 100 类闭集，类别体系受限于教师模型，开放词汇能力有限。
- VLM 过滤成本较高，流水线整体吞吐受基础模型推理速度制约。
- 评测主要集中在室内场景，室外大尺度全景场景的泛化性尚未验证。
- 未来可探索更大规模、开放词汇的全景标注，以及将框架扩展到视频流/时序全景输入。

## 7. 总体评价
- **优点**：问题定位清晰（全景原生 + 数据稀缺双痛点），方法设计环环相扣（Wid3R 骨干 + 查询解码 + Image Stem + 自动标注流水线），实验覆盖有监督、零样本、2D/3D 多维度，消融充分。
- **意义**：为全景 3D 语义分割提供了可复用的前馈式范式，并通过自动标注流水线缓解了该领域的数据瓶颈，具备较强的工程与学术参考价值。
