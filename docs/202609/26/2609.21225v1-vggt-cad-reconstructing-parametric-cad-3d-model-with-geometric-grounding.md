## 摘要
参数化 CAD 重建需要从视觉观测中恢复精确几何与可编辑建模操作，这使其在视角有限且存在歧义时颇具挑战。现有方法主要依赖 2D 外观线索，缺乏强多视角几何先验。在这项工作中，我们提出 VGGT-CAD，一个用于从单视角和多视角观测进行参数化 CAD 重建的几何感知框架。我们通过将相机参数编码为条件 token，并与图像 token 联合建模，将预训练 3D 几何先验迁移到 CAD 重建中。为处理视点数量变化，我们引入可变视角跨视角上下文聚合模块，自适应融合多视角特征。我们进一步开发了一种无需训练的几何感知视角选择策略，在推理时选择互补且可靠的帧。所得表示通过非自回归解码器解码为 CAD 命令序列。我们还开发了 VideoCAD，这是一个大规模多视角视频基准，通过对现有 CAD 数据进行多视角重渲染得到。大量实验证明了 VGGT-CAD 在不同观测配置下进行视觉 CAD 重建的有效性。

## Abstract
Parametric CAD reconstruction requires recovering both precise geometry and editable modeling operations from visual observations, making it challenging under limited and ambiguous views. Existing methods mainly rely on 2D appearance cues and lack strong multi-view geometric priors. In this work, we present VGGT-CAD, a geometry-aware framework for parametric CAD reconstruction from single- and multi-view observations. We transfer pretrained 3D geometric priors into CAD reconstruction by encoding camera parameters as condition tokens and jointly modeling them with image tokens. To handle varying numbers of viewpoints, we introduce a variable-view cross-view context aggregation module that adaptively fuses multi-view features. We further develop a training-free geometry-aware view selection strategy to select complementary and reliable frames during inference. The resulting representation is decoded into CAD command sequences using a non-autoregressive decoder. We also develop VideoCAD, a large-scale multi-view video benchmark derived from existing CAD data through multi-view re-rendering. Extensive experiments demonstrate the effectiveness of VGGT-CAD for visual CAD reconstruction under different observation configurations.

## 1. 核心问题与整体含义
- **研究动机**：参数化 CAD 重建不仅要求恢复三维形状，还要求输出可编辑、可执行的建模命令序列（如 sketch、extrude），并保证结构、拓扑和参数正确。
- **核心难点**：现有方法主要依赖单视图 2D 外观线索，缺乏强多视图几何先验；在遮挡、视角有限或几何歧义严重时，容易产生背面结构幻觉、拓扑缺失和参数不稳定。
- **整体含义**：论文提出 **VGGT-CAD**，将预训练 3D 视觉几何先验迁移到参数化 CAD 重建中，统一支持单视图和多视图输入，目标是直接从图像/视频前馈式恢复可编辑 CAD 命令序列和三维实体模型。

## 2. 方法论
- **核心思想**：把 CAD 重建建模为条件概率生成问题：给定图像集 \(I\) 与相机参数 \(P\)，预测 CAD 命令序列 \(M\)，即 \(p(M|I,P,\Theta)\)。命令由离散命令类型和 16 维参数向量组成，参数归一化并量化到 256 个离散等级，未使用槽位填 -1。
- **网络架构**：框架包含五个模块：
  - **几何感知确定性视图选择**：推理阶段从视频帧中选择信息量大、互补且可靠的视图。
  - **相机条件编码器**：将相机内参、外参编码为 camera token。
  - **几何多视图视觉编码器**：以 VGGT 为视觉骨干，将 camera token 与图像 patch token 拼接，进行帧内注意力和跨视图注意力，传播视角几何关系。
  - **可变视图跨视图上下文聚合器**：对每个视图特征做共享 CNN 编码和池化，得到 \(v_i\)；用 MLP 注意力计算权重 \(\alpha_i\)，softmax 归一化后加权求和，再线性投影为全局隐向量 \(z\)。该设计支持 2–8 个可变输入视图。
  - **非自回归序列解码器**：以可学习 query 为输入，通过 Self-Attention、Cross-Attention 与 \(z\) 交互，并经过 FFN；两个预测头分别输出命令类型分布和每个参数的 256 类分布。
- **辅助相机监督**：额外设置相机条件解码器，从 camera token 预测平移、旋转四元数和 FOV，并转换为焦距；损失为 \(L_{cam}=L_t+L_q+L_f\)。
- **训练目标**：总损失 \(L_{total}=L_{CAD}+\lambda L_{cam}\)，其中 \(L_{CAD}=L_{type}+\beta L_{param}\)，文中取 \(\lambda=1.0\)、\(\beta=2\)。命令类型和参数均用交叉熵，并通过 Validity Mask 忽略无效参数和 padding。
- **微调策略**：几何多视图视觉编码器使用 LoRA 微调，仅更新 12.52M 参数；相机编解码器、跨视图聚合器和序列解码器从头训练。
- **推理视图选择**：将测试时选帧建模为固定预算 \(K\) 下的子集优化，用贪心策略最大化边际得分：
  \[
  \Delta(i|S_{t-1})=\lambda_c C(i|S_{t-1})+\lambda_q Q(i)-\lambda_r R(i|S_{t-1})

  其中 \(C\) 为几何覆盖增益，\(Q\) 为图像质量，\(R\) 为视角冗余惩罚。最佳权重为 \(\lambda_c=0.50,\lambda_q=0.35,\lambda_r=0.15\)。
