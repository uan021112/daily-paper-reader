## 摘要
可再照明的交互式场景重建旨在从不同物体排列的扫描中构建可编辑的3D模型，并在新颖光照下渲染新的布局。现有方法要么将光照烘焙到外观中，要么仅针对固定场景恢复材质和光照，导致编辑后的布局存在不一致的阴影和间接光照。我们提出了LightFuse，一个2D高斯框架，通过显式的材质-光照分解和基于物理的再照明扩展了交互式场景重建。LightFuse首先跨状态融合观测以重建共享背景和可移动物体，然后进行面向射线追踪的几何精化，以产生更完整和一致的表面。在精化后的几何上，使用可微的单次反弹射线追踪进行分阶段训练，将共享的金属-粗糙度材质与状态特定的环境光照分离。所得场景支持物体重排、材质编辑和再照明，而射线追踪在每次交互后重新计算外观。跨合成场景的实验展示了最先进的再照明质量，平均比最强基线高出+9.74分贝的PSNR和+0.121的SSIM。项目页面：https://zhn202.github.io/LightFuse/

## Abstract
Relightable interactive scene reconstruction aims to build an editable 3D model from scans of different object arrangements and render new layouts under novel illumination. Existing methods either bake lighting into appearance or recover material and illumination only for fixed scenes, leaving edited layouts with inconsistent shadows and indirect lighting. We present LightFuse, a 2D Gaussian framework that extends interactive scene reconstruction with explicit material-illumination decomposition and physically based relighting. LightFuse first fuses observations across states to reconstruct a shared background and movable objects. It then conducts ray-tracing-oriented geometry refinement to produce more complete and consistent surfaces. On the refined geometry, staged training with differentiable one-bounce ray tracing separates shared metallic--roughness material from state-specific environment lighting. The resulting scene supports object rearrangement, material editing, and relighting, while ray tracing recomputes appearance after each interaction. Experiments across synthetic scenes demonstrate state-of-the-art relighting quality, outperforming the strongest baseline by +9.74\,dB PSNR and +0.121 SSIM on average. ## 2. 方法论

### 2.1 整体流程

LightFuse 采用“**重建 → 几何细化 → 逆渲染**”三阶段流水线：

1. **交互式场景重建**：融合多状态观测，得到共享背景 + 可动对象的 2D 高斯场景表示；
2. **面向光线追踪的几何细化**：对几何施加跨状态约束，使其适合光线追踪（而非仅适合光栅化）;
3. **多状态逆渲染**：固定几何，用可微单次反弹路径追踪分离共享材质与状态特定环境光照；
4. 最终支持物体重排、材质编辑和重照明，每次交互后重新计算可见性与光传输。

## 6. 主要结论与发现

- LightFuse 在合成场景重照明上达到 **25.38 dB PSNR / 0.852 SSIM**，比最强基线 ReCap (Adapted) 高 **+9.74 dB PSNR** 和 **+0.121 SSIM**，优势显著。
- 在自采真实数据集（布局+光照都变化）上 LightFuse 取得最佳 PSNR（24.20 dB），比 ReCap (Adapted) 高 +1.40 dB，验证了多光照状态下材质-光照分解的有效性。
- 消融实验证明四项几何正则化（覆盖率、尺度、深度、法线）**均不可缺失**——移除任何一项都会产生明显几何伪影（漏光、遮挡错误、低纹理区表面错误、法线不光滑）。
- 渐进式采样（8→16→32 spp）和 Cycles 启发的 MIS 路径估计器有明显增益，固定低采样率会降低材质-光照分解的稳定性。
- 核心结论：**共享几何/材质 + 状态特定光照 + 光传输重算**是实现可重照明交互场景重建的有效方式。

## 7. 优点（亮点）

- **问题新颖且定位明确**：首次将多扫描交互式重建与物理重照明结合，填补了“可编辑场景无法重照明”的空白。
- **方法论上设计完备**：采用三阶段流水线，每个阶段有明确目标和配套损失函数；几何优化专门面向光线追踪（而非光栅化），路径追踪的梯度由 PRB 技术保障稳定。
- **显式材质–光照分解**：金属-粗糙度材质跨状态共享，环境光逐状态独立，逻辑清晰且物理合理。
- **交互编辑支持完整**：支持物体重排、材质替换/调整、新环境光重照明，且每次交互后可见性与光传输都会重算，这是已有方法未同时支持的能力。
- **实验比较严谨**：对 ReCap 做了适配以公平对比；消融实验覆盖了所有核心设计项；合成数据包含 11 个未见环境图，评估了泛化性。

## 8. 不足与局限

- **依赖分割质量**：物体组件划分依赖多视角 mask 和 GaussianCut，分割误差会传播到几何、材质和光照估计中，影响最终质量。
- **计算开销较大**：光线追踪和传输感知的光照优化计算成本高，尚未达到实时交互的算力门槛。
- **光传输深度受限**：只考虑一次间接反弹，无法精确模拟长时间路径的全局光照、焦散、透射和锐利镜面链。
- **生成数据集场景有限**：合成数据仅 4 个室内场景，真实数据仅 4 个场景；缺乏室外、复杂各向异性材质等更多样的验证。
- **适用条件受限**：在光照不变的 IGFuse 真实数据集上表现不如仅做外观重建的 IGFuse，说明多次光照变化约束对方法效果至关重要；当训练状态间光照无变化时，材质-光照解耦的信息不足。
- **部分实现细节未在正文展开**：具体的正则化权重 λ 值、训练步数、几何优化迭代次数等依赖补充材料，正文信息不够自足。
