## 摘要
精确的立体匹配在病态区域（如精细结构、反射或透明物体）中仍然具有挑战性，因为这些区域的外观线索往往模糊或不可靠。为了解决这一问题，我们提出了PhasorNet，一个轻量级而强大的框架，通过频域线索增强几何判别能力。其核心是相位增强Transformer（PAT），将傅里叶导出的相位信息注入注意力机制，生成光度鲁棒且保持结构的特征，在困难区域优先考虑结构一致性。此外，我们开发了几何上下文融合细化模块（GCFRM），将全分辨率卷积流与轻量级基于注意力的流（利用WQA和CDGA块）相结合，在不过度增加开销的情况下有效保留精细细节和物体边界。训练进一步通过多尺度边缘引导的高误差区域（EHR）损失增强，该损失自适应地聚焦于高误差和边缘区域的优化，引导分层代价体细化。仅使用5.3M参数，PhasorNet在具有挑战性的ETH3D基准上实现了最先进的性能，同时在KITTI上表现出优异的跨域泛化能力，为精确的实时立体匹配提供了高效实用的解决方案。

## Abstract
Accurate stereo matching remains challenging in ill-posed regions such as fine structures, reflective, or transparent objects, where appearance cues are often ambiguous or unreliable. To tackle this, we propose PhasorNet, a lightweight yet powerful framework that boosts geometric discrimination via frequency-domain cues. At its core, the Phase-Augmented Transformer (PAT) injects Fourier-derived phase information into the attention mechanism, yielding photometrically robust, structure-preserving features that prioritize structural consistency in difficult areas. Additionally, we develop a Geometry-Context Fusion Refinement Module (GCFRM) that combines a full-resolution convolutional stream with a lightweight attention-based stream (leveraging WQA and CDGA blocks) to efficiently preserve fine details and object boundaries without excessive overhead. Training is further enhanced by a multi-scale Edge-guided High-Error Region (EHR) loss that adaptively focuses optimization on high-error and edge regions, guiding hierarchical cost volume refinement. With only 5.3M parameters, PhasorNet achieves state-of-the-art performance on the challenging ETH3D benchmark while exhibiting excellent cross-domain generalization on KITTI, delivering an efficient and practical solution for accurate real-time stereo matching.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：立体匹配（Stereo Matching）是自动驾驶、机器人、增强现实等 3D 感知任务的基础。尽管深度学习方法已取得显著进展，但在**病态区域**（如精细结构、反射/透明物体、弱纹理表面）中，外观线索往往模糊或不可靠，导致匹配精度严重下降。
- **现有方法的三大挑战**：
  - **特征表示几何信息不足**：CNN/Transformer 骨干网络多针对语义识别优化，提取的特征“语义丰富但几何模糊”，在玻璃、无纹理墙面等表面易产生歧义。
  - **代价体处理效率低**：传统 3D 卷积代价聚合方法（如 GC-Net、PSMNet）内存/计算开销大；迭代细化方法（如 RAFT-Stereo）虽然精度高，但延迟高且容易过度平滑边界。
  - **边界与细节保持困难**：高精度方法在迭代更新中常丢失高频细节，难以同时兼顾速度、内存和精度。
- **核心动机**：利用**频域信息**弥补外观线索的不足——特别是傅里叶变换的**相位分量**，它抗光度变化、直接编码结构轮廓与视差位移关系，非常适合病态区域的鲁棒匹配；同时用小波变换提供局部高频细节，实现全局结构一致性与局部边界锐化的互补。
- **整体意义**：提出一个仅 5.3M 参数的轻量级实时立体匹配网络，在 ETH3D 上达到 SOTA，并在 KITTI 上展现优秀的跨域泛化，为资源受限场景提供高效实用的解决方案。

## 2. 提出的方法论

### 2.1 总体架构

- 输入左右校正图像 \(I_L, I_R \in \mathbb{R}^{H \times W \times 3}\)，输出最终视差图 \(d_{final}\)。
- 三个主要组件：
  1. **特征提取**：Phase-Augmented Transformer（PAT）从双视图提取多尺度特征。
  2. **代价体构建与粗到细细化**：在 1/4 分辨率构建初始代价体，经 Coarse-to-Fine Cost Volume Refinement (C2FCVR) 逐步细化到 1/2 和全分辨率；匹配代价用归一化内积计算。
  3. **视差细化**：Geometry-Context Fusion Refinement Module (GCFRM) 输出最终视差。

### 2.2 Phase-Augmented Cross-Attention（PAC）

- **核心思想**：对左右特征图计算**相位重建**（幅度归一化傅里叶逆变换）：
  \[
  \phi(x) = \mathcal{F}^{-1}\left( \frac{\mathcal{F}(x)}{|\mathcal{F}(x)| + \epsilon} \right)
  \]
  该操作保留高频结构线索（边缘、轮廓），抑制外观相关变化。
- **注入方式**：将相位特征作为残余增强加到交叉注意力的 Query 和 Key 上：
  \[
  Q'_L = Q_L + \phi(X_L), \quad K'_R = K_R + \phi(X_R)
  \]
  仅增强 Query/Key 而不改 Value，保持上下文信息完整性。
- **注意力计算**：带可学习温度参数的 softmax 交叉注意力，再经残差连接和 FFN 细化。
- **作用**：相位信息在光度变化（光照、反射）下保持稳定，显著提升反射/弱纹理区域的匹配鲁棒性。

### 2.3 代价体构建与 C2FCVR

- 在 1/4 分辨率用归一化内积构建初始代价体：
  \[
  CV^i(d,h,w) = \frac{1}{N} \langle f^4_L(h,w), f^4_R(h, w-d) \rangle
  \]
- 完全**去除 3D 卷积**，改用 2D 操作在多个尺度上细化代价体；每阶段上采样并与左视图特征融合，经轻量卷积（LeakyReLU）保持几何一致性。

### 2.4 几何-上下文融合细化模块（GCFRM）

- **双流结构**：
  - **卷积流（Stream-1）**：全分辨率上处理左图特征和初始视差，6 个阶段，每阶段 3 层卷积+ReLU，逐步将细节注入第二流。
  - **Transformer 编码器-解码器流（Stream-2）**：3 个编码器阶段+3 个解码器阶段，共 6 个 transformer 块，每块与卷积流对应尺度特征融合。
- **Wavelet-Based Query Attention（WQA）**：
  - 仅对 Query 应用 DWT（db3 小波）分解为 LL/LH/HL/HH 四个子带，经深度可分离卷积处理后再由 IDWT 重建为增强 Query。
  - 不对称设计（只处理 Query）既去噪增强结构线索，又保留 Key/Value 原始上下文，比对称 WQA 更高效（见表 9）。
- **Cross-Dimensional Gated Attention（CDGA）**：
  - 使用跨维度 3×3 卷积（CDC3），在空间、通道、滤波器、核四个维度上应用注意力权重，选择性抑制不可靠特征，改善编码器-解码器融合。
- **输出**：解码器最后输出全分辨率特征，经 1×1 卷积生成视差残差，与初始视差相加得到最终视差。

### 2.5 多尺度 EHR Loss（Edge-guided High-Error Region Loss）

- **边缘感知视差损失 \(L_{edge}\)**：用 Canny 边缘图（GT 和预测）对误差加权，预测边缘项权重 0.1 作为软正则，避免早期训练强化误检。
- **高误差区域损失 \(L_{her}\)**：选取绝对误差最大的 top \(k\%\) 像素（\(k=7\%\)，经敏感性分析确定）计算 L1 损失，梯度只流过选中像素，mask 使用 stop-gradient。
- **总损失**：\[
  L_{total} = \sum_{s=1}^{S} (L^s_1 + L^s_{EHR})
  \] 并采用两阶段训练策略：Stage 1 训练特征+代价体，Stage 2 冻结前两者只训练细化模块，使用带衰减权重的多阶段回归损失。

### 2.6 实现细节

- PyTorch 实现，AdamW（β1=0.9, β2=0.999, weight decay 1e-4），OneCycle 学习率（峰值 2e-4），batch size 4，训练于 Scene Flow 全量 35454 对图像。

## 6. 主要结论与发现

- **频率相位线索显著提升结构判别力**：将傅里叶相位注入 Transformer 注意力（PAT）后，在反射、透明、弱纹理区域的匹配鲁棒性明显增强。
- **小波查询注意力对边界保持有效**：不对称 WQA（只处理 Query）比对称 WQA 精度更高、延迟更低，说明“去噪 Query + 保持 Key/Value 上下文”的设计更优。
- **CNN+注意力双流细化优于纯卷积或纯 Transformer**：GCFRM 在保留细节的同时不引入过多开销。
- **EHR 损失比均匀 L1 更有效**：聚焦边缘和高误差区域的监督方式进一步降低 D1 误差，且对 top-k 选择不敏感（k=7% 最优）。
- **轻量级+高精度可兼得**：5.3M 参数、108 ms 推理、2.08 GB 内存即可在 ETH3D 达到 SOTA（Bad 1.0 0.41%），并在 KITTI 零样本上接近重型方法（MonSter），远超其他轻量级方法。
- **不依赖迭代细化**：单次推理仍保持较高精度，非常适合实时应用。
