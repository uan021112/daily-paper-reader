## 摘要
在线三维重建模型在长视频上表现不佳。这是因为相对于固定首帧锚点回归位姿会迫使外推远远超出训练分布。小的漂移累积并放大为显著的几何塌陷。然而，我们观察到每帧深度在整个失败过程中保持稳定。骨干网络的局部几何结构保持完整；只有全局位姿头崩溃。受这种解耦的启发，我们引入了Scal3R。该方法将在线重建重新表述为多参考相对位姿查询。我们使用轻量级可学习标记，其参数量约占1%，并通过非对称注意力将其注入完全冻结的骨干网络。该设置查询相对于多个过去关键帧的位姿。带有回环检测的在线位姿图优化系统抑制了长距离漂移。Scal3R在单个GPU上8小时内达到收敛。与在线基线相比，在KITTI上平均ATE降低了超过60%。它还在Virtual KITTI、Sintel、TUM-Dynamic、ScanNet和7-Scenes上取得了最先进的性能。项目页面：https://linjohnss.github.io/scal3r/

## Abstract
Online 3D reconstruction models perform poorly on long videos. This happens because regressing poses relative to a fixed first-frame anchor forces extrapolation far beyond the training distribution. Small drifts accumulate and amplify into significant geometric collapse. However, we observe that per-frame depth remains stable throughout this failure. The backbone's local geometry remains intact; only the global pose head breaks down. Motivated by this decoupling, we introduce Scal3R. This approach reformulates online reconstruction as multi-reference relative pose querying. We use lightweight learnable tokens, which make up about ~1% of the parameters, and inject them into a completely frozen backbone via asymmetric attention. This setup queries poses relative to multiple past keyframes. An online pose-graph optimization system with loop closure suppresses long-range drift. Scal3R reaches convergence in 8 hours on a single GPU. It reduces the average ATE by over 60% on KITTI compared to the online baseline. It also achieves state-of-the-art performance across Virtual KITTI, Sintel, TUM-Dynamic, ScanNet, and 7-Scenes. Project page: https://linjohnss.github.io/scal3r/

## 1. 论文的核心问题与整体含义

- **研究背景**：大规模前馈式在线 3D 重建模型（如 CUT3R、STream3R）通过将每帧几何解码到统一全局坐标系来实现实时重建，其核心是将当前帧相对固定首帧进行绝对位姿回归。
- **核心问题**：这种"全局锚点"范式在**短序列**上表现良好，但在**长视频/千米级轨迹**上会严重失效。论文指出两个根源性问题：
  1. 现有 3D 训练数据集场景规模有限，模型被迫向远超训练分布范围的全局坐标外推，导致几何崩溃；
  2. 真实场景轨迹多样且无界，以固定首帧为锚的位姿回归在理论上无法随序列增长而扩展。
- **关键观察**：通过误差相关分析，论文发现一个重要的**解耦现象**——在长序列的分布外区域，全局位姿误差剧烈发散，但每帧深度预测持续稳定。这说明骨干网络的**局部几何表征完好**，真正崩溃的只是**全局位姿回归头**。
- **整体含义**：该观察表明冻结骨干网络后仅改造位姿接口即可解决长序列崩溃问题，为在线重建提供了一个高参数效率、低训练成本且可扩展的新方向。

## 2. 论文提出的方法论

### 2.1 核心思想
将在线重建从"全局位姿回归"重新定义为一个**多参考相对位姿查询**（Multi-Relative Pose Query）问题：不再直接回归第一帧坐标系下的绝对位姿，而是查询当前帧相对于多个历史参考关键帧的相对变换，并通过在线位姿图优化（PGO）汇总为全局一致的轨迹。

### 2.2 技术架构细节

- **冻结骨干保留局部几何**：构建于完全冻结的在线重建骨干（CUT3R 或 STream3R）之上，保留其 DINOv2 编码器 + Transformer 解码器中的时空几何先验。

- **多参考相对位姿 Token 组装**：维护一个 pose token buffer 存储历史关键帧的相机 token，通过轻量 MLP 将参考帧相机 token 投影到特征空间并做加性融合生成查询 token：
  \[
  \tilde{q}_k = q + \text{MLP}(c_{r_k})
  \]
  其中 q 为共享基础查询 token，ck 是第 k 个参考帧的相机 token。K 可自由伸缩，推理时可扩展而不需重训练。

- **非对称注意力注入（Asymmetric Attention）**：这是方法的关键设计。位姿查询 token 仅作为 Query 参与注意力，用于从图像 token 中提取几何线索；图像 token 只在自己之间做 self-attention，不反过来注意位姿 token。这保证图像特征的表征空间与原冻结模型完全一致，避免破坏点图重建质量，且无需额外注意力掩码。公式如下：
  \[
  \tilde{q}_k^{\ell+1} = \text{Attention}(Q=\tilde{q}_k^\ell, K=X^\ell, V=X^\ell), \quad X^{\ell+1} = \text{SelfAttention}(X^\ell)
  \]

- **相对位姿解码与损失**：位姿 token 经多层交换后由轻量 MLP 头解码为 SE(3) 变换，采用 6D 旋转表示保证连续性，旋转和位移分别监督，并按损失公式进行尺度对齐后计算总损失：
  \[
  \mathcal{L} = \sum_{k=1}^{K} \left( \lambda_R \|R^{pred}_k - R^{gt}_k\|_F + \lambda_t \|t^{pred}_k - t^{gt}_k\|_2 \right)
  \]

- **在线位姿图优化（PGO）后端**，包含三个组件：
  1. **关键帧选择**：基于 3D 重叠分数的 KD-tree 空间索引策略，只有覆盖新几何且深度可靠（overlap < τ、置信度 > τ）的帧成为关键帧并更新 KV 缓存；
  2. **增量 PGO**：用 iSAM2 对因子图增量优化，采用 gap 相关噪声模型（σ = σbase·Δ⁰·⁵）和 Huber 鲁棒核抑制异常约束；序列每 Nreset 帧重置状态并通过最后一帧重新喂入保持连通；
  3. **回环闭合（Loop Closure）**：DINOv2 + SALAD 聚合生成场景级描述子，FAISS 在线索引检索，回环候选的相机 token 直接注入 buffer 作为额外参考槽，让冻结模型天然预测长程相对位姿约束。
- **新增参数占比**仅约骨干模型参数的 **~1%**。

## 6. 论文的主要结论与发现

1. **局部几何与全局姿态的解耦是可行的突破口**——深度预测稳定意味着可以在不改动骨干的前提下修复位姿估计。
2. **多参考相对查询优于单参考链式推断**——训练的参考数从无到 1 到 3 个连续大幅降低 ATE；推理时 K 从 4 增长至 12 也持续改进精度（15.75 → 5.63）。
3. **PGO + 回环闭合有效抑制长程漂移**——回环闭合在 KITTI 上将平均 ATE 从 143.45 降至 75.01（改善 48%），在 KITTI 07 上从 49.83 降至 6.44。
4. **极高参数效率与训练效率**：仅 1% 参数、单卡 8 小时微调即可达到乃至超越大规模离线方法；在 KITTI 上相比最强在线基线 TTT3R 平均 ATE 降低超过 60%。
5. **可即插即配**：与 TTT3R 零样本方案兼容且叠加后进一步提升（KITTI 69.73 → 62.05）。

## 7. 优点

- **洞察深刻、定位清晰**：直指全局锚点回归的根本缺陷——外推不稳而非特征退化，并给出了清晰的误差解耦证据，是从问题诊断到方法设计的完整闭环。
- **设计轻巧优雅**：非对称注意力注入以极小代价（~1% 参数、8 小时单卡）实现位姿查询，完全不触碰冻结权重，保留原始点图重建质量，这在全参微调容易引发几何先验崩溃的背景下非常有吸引力。
- **框架兼容性强**：可插件化地适配 CUT3R 和 STream3R 两类骨干，且回环闭合天然融入多参考查询架构，无需改造模型结构。
- **可与零样本测试时训练技术互补**，形成方法层面的正交叠加关系，表现出良好的生态兼容性。
- **实验全面、自省充分**：对模型在无纹理、动态场景等挑战条件下的行为做了分析（注意力图显示自动压低动态目标权重），并主动补充与经典 SLAM 和并发的 LongStream 的对比与定位，学术透明性较高。

## 8. 不足与局限

- **性能受冻结骨干上限的约束**：在遮挡、无纹理等骨干本来就会失败的区域，Scal3R 无法超越其表征能力。
- **回环检测依赖外观描述子**：极端光照变化或视角差异会导致回环漏检，系统因此缺少轻量几何校验或时空一致性确认机制。
- **超参数手工设定较多**：关键帧选择的 overlap/conf 阈值、回环的相似度/时间间隔阈值、噪声模型的 σbase 等均需人工设置，不同场景的泛化调整成本较高。
- **训练数据与推理 K 之间存在差距**：训练仅用 K=3、4 视图，推理默认 K=12，且实验表明当 K 增至 24 时代理性能不升反降（ATE 12.16），说明模型的参考数外推范围仍有限。
- **动态场景的鲁棒性更多是"自然涌现"而非"显式建模"**：注意力图显示与无动态 mask 时类似的效果来自隐式机制，缺乏显式动态对象分割或运动一致性约束，在极端动态场景下的保障机制不足。
- **方法未规避单目尺度歧义**：评测通过 Sim(3) 对齐放宽了这一约束，在真正的度量尺度（metric-scale）设定下室外精度（vKITTI 9.25 / KITTI 88.66）仍有明显下降。
