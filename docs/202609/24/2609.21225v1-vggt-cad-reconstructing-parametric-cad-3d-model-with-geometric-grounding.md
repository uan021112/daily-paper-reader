## 摘要
参数化CAD重建需要从视觉观测中同时恢复精确几何与可编辑的建模操作，这使其在视角有限且存在歧义的情况下颇具挑战。现有方法主要依赖二维外观线索，缺乏强多视角几何先验。在本工作中，我们提出VGGT-CAD，一个用于从单视角和多视角观测进行参数化CAD重建的几何感知框架。我们通过将相机参数编码为条件token，并与图像token联合建模，将预训练的三维几何先验迁移到CAD重建中。为处理不同数量的视点，我们引入可变视角跨视角上下文聚合模块，以自适应融合多视角特征。我们进一步提出一种免训练的几何感知视角选择策略，在推理时选择互补且可靠的帧。所得表示通过非自回归解码器解码为CAD命令序列。我们还开发了VideoCAD，一个通过多视角重渲染从现有CAD数据构建的大规模多视角视频基准。大量实验证明了VGGT-CAD在不同观测配置下用于视觉CAD重建的有效性。

## Abstract
Parametric CAD reconstruction requires recovering both precise geometry and editable modeling operations from visual observations, making it challenging under limited and ambiguous views. Existing methods mainly rely on 2D appearance cues and lack strong multi-view geometric priors. In this work, we present VGGT-CAD, a geometry-aware framework for parametric CAD reconstruction from single- and multi-view observations. We transfer pretrained 3D geometric priors into CAD reconstruction by encoding camera parameters as condition tokens and jointly modeling them with image tokens. To handle varying numbers of viewpoints, we introduce a variable-view cross-view context aggregation module that adaptively fuses multi-view features. We further develop a training-free geometry-aware view selection strategy to select complementary and reliable frames during inference. The resulting representation is decoded into CAD command sequences using a non-autoregressive decoder. We also develop VideoCAD, a large-scale multi-view video benchmark derived from existing CAD data through multi-view re-rendering. Extensive experiments demonstrate the effectiveness of VGGT-CAD for visual CAD reconstruction under different observation configurations.

## 2. 方法论

### 2.1 核心思想
- 把**相机内外参编码为条件 token**，与图像 token 联合送入基于 VGGT 的几何多视图视觉编码器，使网络在特征空间中同时推理外观、空间布局与跨视图一致性；
- 用**可变视图跨视图上下文聚合器**把 2~8 个视点的特征压缩为固定维度的全局隐向量；
- 用**非自回归 Transformer 解码器**并行预测离散 CAD 命令与量化参数；
- 训练时加入**辅助相机重建目标**增强编码器空间感知；
- 推理时用**免训练的几何感知确定性视图选择**（GAD）挑选互补且可靠的帧。

### 2.2 问题形式化与命令表示
- 给定单目视频 $V$，先采样为 $T=36$ 帧；每次训练迭代随机抽取 $N\in[2,8]$ 帧构成输入集 $I=\{I_1,\dots,I_N\}$，并附对应相机参数 $P=\{P_1,\dots,P_N\}$；
- 生成目标为长度 $N_c$ 的操作序列 $M=[C_1,\dots,C_{N_c}]$，每条命令 $C_j=(t_j,p_j)$ 含离散命令类型与参数向量；
- 整体建模为条件概率生成模型：$p(M\mid I,P,\Theta)=\prod_{j=1}^{N_c} p(t_j,p_j\mid I,P,\Theta)$；
- **命令字典**：控制符（SOL 循环开始、EOS 序列结束）、2D 草图基元（Line、Arc、Circle）、3D 拉伸（Extrude）；
- **参数统一化**：所有参数堆叠为固定 16 维向量 $p_j=[x,y,\alpha,f,r,\theta,\phi,\gamma,p_x,p_y,p_z,s,e_1,e_2,b,u]$，未使用的槽位填充无效值 $-1$；
- **归一化与量化**：将模型包围盒归一化到 $[-1,1]^3$，连续参数量化为 256 个离散等级，把连续回归转化为更易优化的**离散分类问题**（避免直接回归破坏几何约束）。

### 2.3 网络架构（五个模块）

1. **相机条件编码器**
   - 由外参/内参矩阵计算逆仿射变换得到 camera-to-world 位姿编码，结合内参与图像尺寸生成初始位姿特征；
   - 经 MLP 映射后送入深度 $L_{cam}$ 的 Transformer 主干迭代精化，LayerNorm 后输出相机 token $c_i\in\mathbb{R}^d$；
   - 实际部署中相机位姿可由 ARCore / ARKit / AREngine 实时估计。

2. **几何多视图视觉编码器**
   - 以 VGGT 多视图视觉编码结构为核心骨干，迁移其多视图三维理解几何先验；
   - 图像分块得到 token 序列 $X_i$，与相机 token 在序列维拼接：$S_i=[c_i \parallel x_{i,1},\dots,x_{i,M}]$；
   - 每个视点内部做视图内自注意力，在特定 Transformer 层进行跨视图自注意力（Q 来自本视点 token，K/V 来自所有视点 token），使相机朝向信息自然传播到所有图像特征；
   - 输出按索引拆分：相机特征 $c_i$ 与图像特征 $F_i$（reshape 为 $h\times w\times d$ 保留空间结构）。

3. **相机条件解码器（辅助监督）**
   - 两层全连接 + 三个独立预测头：平移向量 $t_i\in\mathbb{R}^3$、旋转四元数 $q_i\in\mathbb{R}^4$、水平/垂直视场角 $f^{FOV}_i\in\mathbb{R}^2$（ReLU 保证非负）；
   - 由 FOV 换算像素焦距：$\hat f_{x,i}=\frac{W}{2\tan(FOV_{w,i}/2)}$、$\hat f_{y,i}=\frac{H}{2\tan(FOV_{h,i}/2)}$，在焦距空间监督。

4. **跨视图上下文聚合器**
   - 因视点数 $N$ 动态变化而解码器需固定维度全局表示，故用共享权重 2D 卷积编码 + 自适应平均池化得到每视点一维特征 $v_i$；
   - MLP 注意力网络计算各视点权重并 softmax 归一化（$\alpha_i=\frac{\exp(\mathrm{MLP}_{attn}(v_i))}{\sum_j \exp(\mathrm{MLP}_{attn}(v_j))}$）；
   - 加权求和得 $f_{fused}$，再经线性投影降维输出全局隐向量 $z\in\mathbb{R}^{d_z}$。

5. **序列解码器**
   - 采用前馈非自回归 Transformer：以 $N_c$ 个可学习常量嵌入为 query，通过 SelfAttn → CrossAttn(与 $z$) → FFN 逐层更新；
   - 两个并行预测头：命令类型分类
