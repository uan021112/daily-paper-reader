## 摘要
我们提出 VGGT-GS SLAM，一种面向未标定视频设计的单目 3D 高斯泼溅 SLAM 系统。从 VGGT 的前馈位姿与深度先验出发，我们的系统执行子图可微光束法平差，联合优化相机位姿与 3D 高斯地图，同时通过解析标定雅可比优化子图共享的内参和径向-切向畸变。为提高全局一致性，我们引入高斯原生对齐（Gaussian-native alignment, GNA），用于序列子图之间以相机为锚的尺度细化以及闭环候选验证。在标准室内基准上的大量实验表明，在未标定设置下，定位精度持续提升且渲染质量良好，为未标定高斯 SLAM 建立了强基线。

## Abstract
We present VGGT-GS SLAM, a monocular 3D Gaussian Splatting SLAM system designed for uncalibrated videos. Starting from feed-forward VGGT pose and depth priors, our system performs submap differentiable bundle adjustment that jointly refines camera poses and a 3D Gaussian map, while optimizing submap-shared intrinsics and radial--tangential distortion through analytic calibration Jacobians. To improve global consistency, we introduce Gaussian-native alignment (GNA) for camera-anchored scale refinement between sequential submaps and verification of loop-closure candidates. Extensive experiments on standard indoor benchmarks show consistent improvements in localization accuracy and strong rendering quality under uncalibrated settings, establishing a strong baseline for uncalibrated Gaussian SLAM.

## 2. 方法论

### 2.1 总体框架

- 沿用 VGGT-SLAM 的**子图组织方式**：关键帧按窗口大小 `S + O` 分组（S 为子图帧数，O 为重叠帧数）。
- 每个窗口用 **VGGT** 预测外参、内参 `{Ki}`、深度-置信图 `{Di, Ci}`；内参初始化为 `{Ki}` 的均值，畸变系数初始化为 0。
- 子图内执行**可微光束法平差（BA）**，子图间用**高斯原生 Sim(3) 约束**接入全局位姿图。

### 2.2 高斯初始化（源自深度）

- 沿用 MonoGS 策略：将有效深度像素反投影为世界坐标下的 3D 高斯（固定步长下采样，过滤 `Di(p) > 1e-8`）。
- 颜色用该像素的 SH 系数表示；旋转取单位阵，不透明度取 0.5（logit 为 0）。
- 各向同性对数尺度按最近邻距离设定：`ℓj = log(0.1 · d_nn,j) / 3`，使初始支撑适应当地采样密度。

### 2.3 联合 BA（子图内）

- **优化变量**：高斯表示、相机位姿、逐帧仿射亮度参数、以及**所有帧共享的相机模型**；固定首帧位姿定义子图参考系，其余位姿用左乘 SE(3) 增量更新。
- **参数化技巧**：
  - 内参：焦距用**对数空间**更新，主点用加性更新。
  - 畸变：径向 `kj = sk·tanh(ρkj)`（j=1,2,3）、切向 `pj = sp·tanh(ρpj)`（j=1,2），以**有界**方式约束取值范围。
- **总目标**：`L_BA = L_rgb + λdepth·L_depth + λiso·L_iso`（AdamW，参数级学习率）。
  - **光度损失**：DSO 式仿射曝光补偿 `I' = exp(a_i)I + b_i`，在有效像素上取 L1 与 DSSIM 的加权组合；提出**曝光稳定变体**（局部 BA 固定 a1=b1=0 作亮度基准，后续地图细化时冻结全部曝光参数）。
  - **深度损失**：VGGT 深度作为**弱几何先验**，采用带容忍死区的相对残差（`τdepth`），并用中值归一化+截断（`cmax`）的置信度加权；置信度缺失时置 1。
  - **各向同性正则**：惩罚高斯物理尺度的各向异性（`L_iso`）。

### 2.4 解析标定雅可比（关键贡献之一）

- 在 gsplat 的可微高斯投影中，**解析求导**投影 2D 高斯中心 `m2d` 与协方差 `Σ2d` 对完整标定向量 `θcal = (fx, fy, cx, cy, k1, k2, k3, p1, p2)` 的梯度。
- **相机模型**：归一化坐标 `(u,v)` → 径向+切向畸变 `(ud, vd)` → 像素 `(U,V) = (fx·ud+cx, fy·vd+cy)`；记 `m2d = D·md + c`，`J = D·A·B`，`Σ2d = J·Σ3d·Jᵀ`。
- **投影中心雅可比**：`∂m2d/∂q = (∂D/∂q)md + D(∂md/∂q) + ∂c/∂q`。
- **投影协方差雅可比**：`∂Σ2d/∂q = (∂J/∂q)Σ3d Jᵀ + JΣ3d (∂J/∂q)ᵀ`。
- CUDA 核返回对物理系数的梯度，再由自动微分套用**有界参数链式法则**（如 `∂L/∂ρk = (∂L/∂k)·s·(1−tanh²ρ)`），从而让渲染损失**端到端**优化全部 9 个标定参数。

### 2.5 高斯原生对齐 GNA（子图间）

- **相机锚定初始化**：相邻子图共享重叠帧，由其位姿确定旋转 `R`；由恒等像素深度对应关系确定初始尺度 `s0`，平移为 `t0 = cA − s0·R·cB`；**固定 R，仅优化对数尺度 u = log s**。
- 变换关系：`μB→A(u) = cA + sR(μB − cB)`，`ΣB→A(u) = s²RΣB Rᵀ`。
- **协方差感知匹配**：按不透明度、锚视图可见性、空间尺度筛选高斯；对参考高斯 i 与变换后源高斯 j，定义 `dij`、`Sij = ΣA + ΣB→A + (ε+τ²)I₃`，使用对数核 `κij(u) = −½(dᵀS⁻¹d + λdet·log|S|)`。
- 由不透明度与观测数定义权重 `wi`，在 k 近邻上做**双向（B→A 与 A→B）方向性打分**；带宽 τ 退火，每个带宽阶段内邻域固定。
- 目标函数 `L_GNA(u) = −ℓB→A(u) − ℓA→B(u) + λsp(u − log(mA/mB))²`，其中第三项为密度敏感的**间距先验**；尺度更新有界，且仅在改善归一化目标时才保留，否则回退 `s0`。

### 2.6 回环与全局优化

- **回环检测**：用 SALAD 描述子匹配历史子图（排除紧邻前驱），保留描述子距离低于阈值 `τr` 的最近对；检索帧仅加入**独立的 VGGT 联合回环推理批次**，其深度对应初始化子图间 Sim(3)。
- **GNA 仅用于验证**：以最终匹配损失 `L*` 与尺度修正量 `Δs` 作为接受准则（`L* ≤ τL`、`Δs ≤ τs`）；**接受的回环保留原始 VGGT 桥接变换**，不做变换细化。
- 附加**旋转一致性检查**：拒绝与先前序列链差异超过 90° 的桥接。
- 位姿图节点为子图局部→全局 Sim(3) 变换 `Gi`，仅优化 `Gi`，不改动局部高斯/位姿/标定；**子图不做合并**（全局高斯均值与协方差按 `sRμ+t`、`s²RΣRᵀ` 变换）。
- **其他实现细节**：Lucas–Kanade 平均位移超过 `τdisp` 或有效跟踪点少于 10 时选新关键帧；BA 中周期性克隆/分裂/剪枝高斯；序列级建图与图优化后，用固定地图与标定对非关键帧做 90 次 SE(3) 位姿优化以生成逐帧轨迹。
