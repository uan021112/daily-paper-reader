## 摘要
可靠地理解周围环境的3D结构是自动驾驶的核心要求。多视图环绕相机装置提供了广泛的场景覆盖，但空间上相邻的图像通常仅有极小的重叠。因此，大多数像素的深度必须从单目外观线索中推断。这些线索在不同图像中可能表现不同，因此深度估计模型可能对其做出不同解释。我们针对跨图像不一致性的两个主要来源：相机内参的差异和每幅图像有限的感受野。我们通过基于逐像素相机感知光线嵌入来调节特征，从而解决前者，使网络能够考虑单目线索中依赖相机的变化。我们通过将每个像素的上下文扩展到其自身图像之外，利用受几何合理区域约束的跨图像注意力（由标定后的相机装置推导）来解决后者。模型基于光度一致性以完全自监督的方式进行训练。在DDAD和nuScenes上的评估表明，在域内和跨域评估中，与最先进的自监督方法相比，整体深度精度和跨图像深度一致性均有提升。代码可在 https://abualhanud.github.io/CrossDepthPage/ 获取。

## Abstract
Reliable 3D understanding of the surrounding environment is a core requirement for autonomous driving. Multi-view surround camera rigs provide broad scene coverage, but the spatially adjacent images typically overlap only minimally. Consequently, the depth of most pixels must be inferred from monocular appearance cues. These cues can appear differently across images and may therefore be interpreted differently by the depth estimation model. We target two main sources of cross-image inconsistency: differences in camera intrinsics and the limited receptive field of each image. We address the former by conditioning the features on per-pixel camera-aware ray embeddings, enabling the network to account for camera-dependent variations in monocular cues. We address the latter by extending each pixel's context beyond its own image through cross-image attention constrained to geometrically plausible regions, derived from the calibrated rig setup. The model is trained in a fully self-supervised manner based on photometric consistency. Evaluations on DDAD and nuScenes show improved overall depth accuracy and cross-image depth consistency over state-of-the-art self-supervised methods under in-domain and cross-domain evaluation. Code is available at https://abualhanud.github.io/CrossDepthPage/.

# CrossDepth：用于可泛化多视图环绕深度估计的几何约束注意力——论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：可靠的三维环境理解是自动驾驶（路径规划、定位、场景仿真等）的核心需求。相比 LiDAR 等直接测距传感器，基于多目相机的三维重建成本更低、信息更稠密。环绕式多相机系统（Surround-view rig）可提供 360° 覆盖，且相机间存在空间基线，可利用重叠区域的光度一致性进行自监督训练。
- **核心问题**：环绕相机装置中，相邻图像空间重叠极小，大多数像素的深度只能依赖单目外观线索（如物体大小、语义、遮挡、透视等）推断。这带来两个主要挑战：
  1. **相机内参差异问题**：不同相机可能有不同的内参（如焦距），导致同一三维物体在不同图像中呈现不同的视角和表观尺寸，深度模型难以一致地解读单目线索，容易产生跨图像的深度不一致。
  2. **单图感受野有限问题**：每个像素的上下文被限制在自身图像内，缺乏来自相邻视角的几何与语义信息，导致跨相机预测深度不连贯。
- **核心目标**：在**完全自监督**（仅依赖光度一致性，无需深度真值标签）的条件下，实现高精度且**跨图像一致**的环绕深度估计，并具有良好的跨域泛化能力。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **总体框架**：采用编码器-解码器架构。编码器为预训练的 DINOv3 ViT（视觉 Transformer），特征经"跨图像特征聚合模块"处理后送入 DPT 风格解码器；解码器各阶段融合相机感知射线嵌入，最终为每个输入图像预测稠密度量深度图。
- **核心思想一：两阶段前向推理 + 几何约束的跨图像注意力**：
  1. **第一次前向**：启用不带跨图像注意力的编码器，预测一张初始深度图。
  2. **圆柱投影**：利用该初始深度、相机内参和外参，将每个特征 token 从各相机图像映射到共享的**圆柱坐标系**上（坐标由角坐标 θ 和垂直坐标 h 表示）。
  3. **空间离散化**：将圆柱表面离散化为 Bθ×Bh 的 2D 网格（Bθ=360，Bh=128），每个 token 获得网格坐标 (u,v)。相比 CylinderDepth 中对所有 token 间距离进行穷举搜索的做法，该离散化方法允许直接从局部窗口高效检索候选 token，极大降低了计算开销。
  4. **第二次前向**：启用跨图像注意力。每个查询 token 只关注其他图像中落在以自身为中心的 KW×KW 窗口（KW=5）内的候选 token，剔除几何上不合理（特征空间可能相似但不构成真实对应）的候选。窗口跨越角度边界时可环绕。设每个网格单元最多存储 Kmax 个 token，候选键数量 M ≤ K²·Kmax，交互次数从 Z² 降为 ZM（M≪Z）。
  5. 跨图像注意力为**多头注意力**（Nh=8），query/key/value 由每个编码器层的特征线性投影得到，并用 softmax 计算注意力权重后加权聚合。注意力**仅在跨图像 token 之间进行**，图内交互已由编码器 ViT 的自我注意完成。该模块作用于**全部送入解码器的编码器层特征**，而非仅单个粗糙层。
- **核心思想二：相机感知射线嵌入（Camera-Aware Ray Embedding）**：
  - 根据每台相机的内参，为每个 token 构造对应的**射线方向向量** Bt∈R^{N×Hp×Wp×3}。
  - 采用 NeRF 式正弦位置编码 γ(·) 将射线方向编码为高维嵌入 Rt。
  - 通过 CAMFusion 模块（3×3 卷积）将射线嵌入与编码器特征拼接融合。
  - **意义**：使解码器能将单目外观线索与对应的相机内参关联起来，学习外观—内参—度量深度之间的**非线性映射**，而非像传统方法那样仅用焦距归一化和全局深度缩放因子做线性补偿。这能显著减少相机内参差异引起的跨图像深度不一致。
- **自监督训练**：损失函数综合了多种光度一致性约束：
  - **空间监督（Spatial）**：由相邻相机图像渲染目标图，提供度量尺度监督；
  - **时间监督（Temporal）**：由前一/后一帧的同一相机图像渲染（通过位姿网络预测车辆运动）；
  - **时空监督（Spatio-temporal）**：由相邻相机在相邻时间步的图像渲染；
  - 另加**边缘感知平滑损失 Lsm、稠密深度一致性损失 LDCCL、多视图重建一致性损失 LMVRCL**。总损失为各分量加权求和。
- **自监督的度量尺度来源**：相机基线的公制平移量提供了绝对尺度参考，使网络无需深度真值标签也能回归度量深度。

## 6. 主要结论与发现

- 论文提出的 CrossDepth 在 DDAD 和 nuScenes 的**域内与跨域评估**中，其整体深度精度、重叠区域精度和跨图像深度一致性均优于现有的五种自监督方法（在多数指标上）。以 DDAD 域内全图为例：Abs Rel 0.185（对比 CylinderDepth 0.207，SurroundDepth 0.208），RMSE 11.87 m，Depth Cons 4.60 m（对比 CylinderDepth 5.68 m，CVCDepth 5.89 m）。
- **几何约束注意力优于无约束注意力**：将跨图像注意力限制在几何上合理的局部范围内，可降低聚合不相关特征的风险，在**不损害**深度精度的前提下显著提升跨图像一致性。且局部约束的计算高效性使其能在所有解码器层特征上应用（不同于 CylinderDepth 仅作用于单层粗糙特征）。
- **相机感知射线嵌入优于焦距缩放**：相比用一个全局缩放因子补偿焦距差异，逐像素射线嵌入允许网络学习空间变化、非线性的内参—深度关系，从而更有效地消除相机内参差异带来的深度不一致。
- **轻量骨干微调（LoRA）收益较小**：预训练的 DINOv3 特征已编码大量单目深度估计所需的视觉信息，LoRA 微调仅带来小幅改进——这与此前研究结论一致。
- CrossDepth 在相似精度水平下，显存占用相比若干 SOTA 方法更具竞争力，体现了离散化几何约束注意力的工程有效性。

## 7. 优点与亮点

- **问题定位精准**：明确区分了跨图像不一致的两个正交来源（相机内参差异、单图上下文局限），并针对性地设计了两种互补的解决模块，问题—方法对应清晰。
- **方法创新体现在工程细节上的有效性**：
  - 将圆柱空间离散化为 2D 网格，把 CylinderDepth 的穷举式近邻搜索转化为局部窗口检索（O(ZM) 而非 O(Z²)），使跨图像注意力能够在所有特征层上部署，这是一个实质性改进。
  - 先做一次无注意力前向得到初步深度（"深度引导注意力"），再据此约束注意力范围，形成一种优雅的"由粗到细"的结构。
  - 使用可学习的注意力权重而非 CylinderDepth 中基于圆柱距离的固定权重，表达能力更强且输出更锐利。
- **自监督与泛化并重**：不依赖深度标签，训练范式紧跟实际应用需求；并主动以双向跨域实验（DDAD↔nuScenes）验证方法可泛化性。
- **度量尺度有保障**：利用标定基线的公制尺度提供绝对参考，网络可直接回归度量深度，便于直接部署于驾驶任务中。
- **消融对照设计可信**：每个核心组件的收益通过消融（尤其"约束注意力 vs. 无约束"）得到有效量化；表 1 中同时报告全图与重叠区域指标，可揭示方法在关键重叠区域上的真实增益。
- **效率意识强**：报告显存占用并展示了离散化设计带来的内存优势，对实际部署有参考价值。

- **评估风险/偏差**：
  - 自监督重叠区域监督在**极端相机交叠区域**（如近距离车头区域）可能存在较差的渲染效果或遮挡问题，导致深度预测在边界处不稳定，而这类问题并未被作者显式分析。

  - 第一次前向的初始深度质量决定了注意力范围的几何有效性。若初始深度出现系统性错误（如尺度偏移），候选窗口需要足够宽才能覆盖，但这取决于 KW 的预设值——作者未讨论不同误差情境下邻域半径的自适应性。
  - 圆柱投影依赖相机外参的全局一致性，若标定存在微小误差或车辆颠簸引起外参扰动，投影网格可能错位，降低跨图像注意力的可靠性。
  - 对内存的节省依赖于每个网格 token 数的阈值 Kmax 与窗口尺寸 KW 的支持；这两个超参数的协同敏感性和在不同分辨率输入下的扩展性未做充分研究。
- **适用边界**：
  - 方法需要准确的相机内外参（用于投影与射线嵌入）。这对无标定的在线系统（如户外手持采集或低成本消费级多相机）不适用，限制了更广部署场景。
  - 相对深度或非度量深度不能完全享受射线嵌入带来的度量尺度 benefit，但论文未讨论该方法对尺度假设的依赖条件。

## 9. 对人工智能领域/学术研究的借鉴意义与启发

- **关键启示一：几何约束可作为视觉注意力的路标**。本文在“语义注意力的自由匹配”之外，以相机位姿与初始深度为桥梁，将候选键限制在物理上可能对应的局部区域。其成功说明，当模型目标为三维一致表示时，将几何先验以“gate/过滤”的形式注入 Transformer 注意力，比纯数据驱动的全局注意力更高效、更可控。
- **关键启示二：跨图像交互不需要全部层**。作者巧妙将计算复杂度的立方增长，通过两步法降为近线性，使得编码器的全部特征都可利用跨图像上下文信息。这种“先粗估计—再动态裁剪”的两阶段模式，对于多视图 Transformer 任意特征层的上下文高效交互均是一种可复用的参考范式。
- **关键启示三：处理相机内参差异时，逐像素/逐射线条件优于单标量条件**。相机感知射线嵌入将内参外参转化为逐 token 的条件向量，从源头去除了传感器配置差异对单目特征解读的混淆效应。这一思路对“传感器无关的深度模型”、多任务自监督学习中的 sensor-alignment 研究具有参考价值。
- **关键启示四：自监督环绕图像中包含了极丰富的监督信号**。光度一致性不仅存在于单机相邻相机间，还可扩展到时空立方体（同一相机邻帧、邻相机邻帧）。将这种时空—视觉联合的一致损失纳入训练，强化了度量深度的一致性，而该方法做对了这一点：它按数据模式组织了个性化 loss，相当于“自监督的 teacher 信号集合”。
- **对生态系统的贡献**：公开可复现的训练配置与显存数据，为后继研究者提供了可比的硬件/效果的 baseline；同时是一种基于最小数据集也能获得较好结果的探索模式（只须 4× RTX 3090）。

## 10. 潜在改进方向与未来工作可能

- **扩大验证范围**：在更多自动驾驶数据集之外，将该方法迁移至诸如 KITTI-360、Argoverse2（城市复杂道路）或室内/桌面级环形相机系统；测试不同图像分辨率与极短/极长基线的泛化鲁棒性。
- **融合点云或雷达先验**：将跨图像注意力的“几何候选”从深度先验扩展到“基于稀疏雷达/广域测距形成的候选 mask 关注图”，以克服首轮深度估计误差同时保持低计算成本。
- **引入交互式动态深度更新**：第二次前向只用了首轮深度作为固定锚点注意力 mask；可将两次前向改为可迭代式或沿中间层逐步更新 mask，使各层特征的注意力范围随特征更新而柔性优化。
- **构建统一的在线标定与自回归深度机制**：若取消对外参的隐式依赖，则可结合在线位姿估计算法（如 DROID-SLAM 式的可微分 bundle adjustment）或量化预测深度本身的位置——这会使 CrossDepth 可作为通用多相机系统的一部分。
- **更细颗粒度的 loss 设计**：对深度不一致性的惩罚仅停留在“重建一致性”或“深度一致性”的均方意义上；可进一步尝试感知加权、前景/物体级别一致性约束，改进物体边缘附近的动态深度伪影。

## 11. 个人结论/评价（选择与理论基础之上的态度）

从研究角度，这工作在“多视图深度自监督估计”这一相当拥挤的领域里，做出了非常清晰、直接的贡献：它揭示了旋转相机架中的两个不同于传统重建的问题——内参不一致与单目上下文收敛域——而非仅推广现成的单目—多视图基线，并为每个问题设计了一个轻量的、可解释的模块。本文最强的证据是消融组“无约束全局注意力→几何约束局部注意力”的一致性提升——充分说明了“几何引导 + 软注意力”在保持性能的同时能更干净地约束交叉视图线索。这种设计也更贴近生物视觉中“用运动视差和极性约束建立由点到投影的关联”的基本启发模型。

该方法并不旨在超越大模型式的单目 monocular 网络；它不依靠强大外部先验，而依靠一种优雅的自监督结构约束获得泛化。在受约束的计算预算下，在多个数据集与跨域测试上达到了与当前 best-performing 相当或更优的一致性指标，这是一项工程与算法底蕴兼备的贡献。

不可否认的是，实验只集中在两个驾驶数据集上，“跨域泛化”也只在极为相似的都市驾驶数据之间进行。如果以“通用多视图深度估计”来主张贡献，证据必须更广泛；同时其注意力机制不能穿越图像边缘重叠（在某些圆盘式多相机配置下可能相邻图像不共享任何有效内容），使得该设计空间仅适用于 strict surround 配置。这类局限性说明，CrossDepth 虽优于现有 SOTA 的一种强可行的配置，但位置性仍受应用场景的严格限制。

总体而言，是一篇“问题—方法—证据”逻辑严谨，设计细节落地价值高，并且在纯自监督系统中让几何先验产生实际变现的论文。它的价值在意促使我们反思：将模型嵌入物理约束（几何坐标、标定矩阵、时空视角）不一定需要破坏学习成分的表达力，反而可以以更经济、更可控的方式获得稳定性与一致性。
