## 摘要
无位姿前馈式3D高斯泼溅使得从未标定的多视角图像进行新视角合成成为可能。尽管更多视角理应提升性能，但现有方法在稠密视角输入下常常性能下降，因为全局注意力将注意力分散到大量令牌上，且朴素的体素融合将众多高斯平均化，导致表示过于平滑。我们提出AVSplat，一个将额外视角转化为可靠信号以同时用于聚合和表示的框架。在全局注意力之前，每个视图仅与一组基于相关性和多样性选取的辅助视图进行一次轻量级交互，缓存的特征提供了聚焦的场景上下文，从而稳定对应关系。在表示方面，我们采用自适应温度感知的体素融合，在高占用率下通过占用度和点置信度指导来锐化归属。关键在于，AVSplat恢复了正向视角缩放，即随着输入视角数量的增加，性能保持稳定或提升，而非在稠密视角区域下降。消融实验表明，辅助视图预条件主要负责防止稠密视角退化，而占用度引导的体素融合贡献了大部分单点图像质量提升。

## Abstract
Pose-free feed-forward 3D Gaussian Splatting enables novel view synthesis from uncalibrated multi-view images. Although more views should improve performance, existing methods often degrade with dense-view inputs because global aggregation spreads attention over many tokens, and naive voxel fusion averages many Gaussians into overly smooth representations. We present AVSplat, a framework that turns additional views into reliable signals for both aggregation and representation. Before global attention, each view performs a single lightweight interaction with a small set of Assist Views chosen for relevance and diversity, and the cached features provide a focused scene context that stabilizes correspondence. For representation, we use adaptive temperature-aware voxel fusion that sharpens attribution under high occupancy, guided by occupancy and point confidence. Crucially, AVSplat restores positive view scaling where performance remains stable or improves as more input views are added, instead of degrading in the dense-view regime. Ablations show that Assist View Preconditioning is primarily responsible for preventing dense-view degradation, while Occupancy-guided Voxel Fusion contributes most of the single-point image-quality gains.

## 1. 论文的核心问题与整体含义

- **研究动机**：无位姿（pose-free）前馈式 3D 高斯泼溅（Feed-Forward 3D Gaussian Splatting, 3DGS）能够从无标定多视角图像直接进行新视角合成。直觉上，增加输入视角数量应提升重建质量，但现有前馈管线在"稠密视角"下反而出现性能退化（dense-view degradation），即额外视角变成了干扰而非增益。
- **退化原因**：
  - **全局注意力稀释**：在未知位姿条件下，主干网络（如 VGGT）依赖全局 softmax 注意力来发现跨视角对应关系。视角数增加意味着 token 数量爆炸，注意力质量分散到大量不相关候选上，正确匹配的权重被稀释，跨视角一致性变差（复杂度为 \(O((SP)^2)\)）。
  - **朴素体素融合平均化**：不同视角产生的逐像素高斯在落入同一体素后被简单地归一化平均。大量弱贡献者稀释少数强贡献者，相当于低通滤波，造成高频细节丢失；且融合权重无法根据置信度和几何一致性自适应调整。
- **核心含义**：AVSplat 通过"前置全局聚合"和"改进体素属性归属"两条途径，将增加的视角数转化为可靠信号，从而恢复**正向视图缩放（Positive View Scaling）**——即在稠密视角范围内，输入视角越多，重建性能保持稳定或持续提升。

## 2. 论文提出的方法论

### 2.1 整体流程
- 输入未标定多视角图像 → 图像编码器生成 patch token → 全局聚合（含新增加的辅助视图预条件） → 解码出相机位姿、深度及高斯参数 → 可微分光栅化渲染监督。
- 方法建立在 VGGT 风格的几何 Transformer 主干及 AnySplat 体素级前馈高斯预测框架之上。
- 新增两个关键模块：**Assist-View Preconditioning（AVP）** 与 **Occupancy-guided Voxel Fusion（OVF）**。

### 2.2 Assist-View Preconditioning（辅助视图预条件，AVP）

**目标**：防止全局注意力因 token 过多而稀释，稳定跨视角匹配。

**覆盖驱动的辅助视图选取（Coverage-driven Assist Selection）**
- 每个视角通过平均池化获得视角描述子 \(z_s \in \mathbb{R}^d\)；
- 以描述子余弦相似度找到 \(M\) 个最近邻候选视图 \(\mathcal{N}(s)\)；
- 通过**次模贪心最大化**一个结合四项目标的得分，选出 \(K\) 个辅助视图：
  - token 级覆盖增益（当前视图每个 patch token 与辅助视图的最佳 token 相似度）；
  - 描述子与目标视图的直接相似度；
  - 视图间的多样性（惩罚冗余的辅助视图）；
  - 视图可靠性（token 方差）。
- 公式表达为覆盖目标函数 \(F(\mathcal{A})\)，包含 token 覆盖项、可靠性项和多样性惩罚项；因单调次模性，贪心选择有近优保证。辅助视图选择在 detached token 上完成，不可导但计算开销小。

**轻量级条件交互（Lightweight Conditioning）**
- 每个视图对选出的辅助视图特征做**单次 cross-attention**：
  \[
  \tilde{X}_s = \mathrm{softmax}\left(\frac{Q_s K_s^\top}{\sqrt{d}}\right) V_s
  \]
  即 Query 来自当前视图、Key/Value 来自辅助视图；
- 通过**门控残差**融合原始与条件化 token：
  \[
  X_s^{out} = X_s + \gamma(g)\tilde{X}_s
  \]
  其中门控系数 \(\gamma(g)\) 随训练步数从 0 渐增至 1；训练初期用 stop-gradient 稳定优化。
- 每个视图只与很少量（如 4 个）上下文辅助视图交互，计算开销低；关键洞察是"把发现匹配的工作从全局模块前移到选择阶段"，让全局聚合专注于长程对齐而非搜索。
- 稀疏视角下（如 3/6 视角）不足以组成有意义的辅助集合，此模块被禁用。

### 2.3 Occupancy-guided Voxel Fusion（占用引导的体素融合，OVF）

**目标**：消除朴素体素平均带来的过度平滑。

**自适应温度公式**：
- 对体素 \(v\)，定义候选高斯集合 \(\mathcal{G}_v\) 和占用数 \(n_v = |\mathcal{I}_v|\)；
- 体素温度：
  \[
  \tau_v = \mathrm{clip}\left(\tau_{\min}, \tau_0 \left(\frac{n_v}{n_{ref}}\right)^{-\alpha} \psi_v, \tau_{\max}\right)
  \]
  其中 \(\psi_v = 1/(1+\lambda \sigma_v^2)\) 为几何一致性因子，\(\sigma_v^2\) 为体素内 3D 点位置方差；
- 原理：**高占用率体素采用低温，使权重分布尖锐化**，高置信度、几何一致的候选主导融合结果；**低占用率体素使用较高温度，融合保持包容性**，避免脆弱的赢家通吃。

**权重与融合**：
- 候选的高斯以置信度 \(c_i\) 与温度形成 logits \(\ell_i = c_i/\tau_v\)，经 softmax 归一化得到权重；
- 按权重降序截断至累计质量阈值（如 0.8），剔除低权重离群点后重新归一化；
- 融合后的体素位置与特征为加权平均 \(p_v = \sum_i w_i p_i,\ f_v = \sum_i w_i f_i\)；
- 全程可微，可端到端联合训练。

## 6. 论文的主要结论与发现

- **稠密视角退化可逆**：AVSplat 在 32/48/64 视角下持续优于 AnySplat（DL3DV 上分别高 0.49、0.56、0.53 dB），且 PSNR 从 21.54 持续升至 21.67 dB，而基线基本饱和甚至振荡。
- **正向缩放恢复**：在高重叠 ACID 上，AnySplat 从 48 视角（23.12 dB）降至 72 视角（22.45 dB），AVSplat 则从 23.15 升至 23.24 dB——额外冗余视图不再有害，78 个实验点在密度上体现了一致趋势。
- **AVP 是抗稠密退化的关键**：去除 AVP 后全局注意力熵更高（0.693 vs 0.642）、epipolar GeoMass 显著低于 AVSplat（0.286 vs 0.374），对应的注意力集中度从接近随机基线的约 2.9× 提升至 3.7×。
- **OVF 主要贡献单点图像质量**：在固定 64 视角下，单独加入 OVF 带来 PSNR 0.43 dB 的提升，进一步叠加 AVP 再增加 0.10 dB，因此 OVF 对当前点位的精度增益主要作用，而 AVP 影响的是跨视角规模鲁棒性。
- **消融完整模型将两种贡献解耦**：两个模块缺一不可——AVP 保"缩放稳定性"，OVF 保"绝对精度"。

## 7. 优点

- **问题定位准确**：精准指出了稠密视角下前馈 3DGS 退化的两个结构性原因（注意力稀释与体素融合过度平滑），且通过实验证据（注意力熵、GeoMass）进行了验证，分析链完整。
- **方法设计轻量且有效**：
  - AVP 只做单次轻量交互（4 个辅助视图），门控残差、梯度停止等设计体现了对训练稳定性的关注；
  - 辅助视图选取融合了"相关性→多样性→可靠性→覆盖度"多维标准，有良好的可解释性，并利用次模贪心控制了开销。
  - OVF 采用可学习联合调节的温度机制，将占用数与几何一致性融合进 softmax 温度，概念简洁，数学表达清晰，且完全端到端可微。
- **评估较全面**：除常规交叉数据集评测外，还设计了注意力集中度诊断、高重叠视图压力测试、性能-视角数全程缩放曲线，提供了理解"为何改进"的直接证据。
- **讨论诚实**：明确说明 AVP 在稀疏视角下禁用、与 OVF 的贡献分离，不回避稠密/稀疏下的性能差异。

## 8. 不足与局限

- **跨域零样本规模偏小**：Mip-NeRF 360 和 VR-NeRF 各只有 4 个评测场景，场景类型与光照变化有限，跨域结论的统计强度较弱。
- **稀疏视角性能不占优**：在 DL3DV 3 视角下 PSNR 明显低于 AnySplat（14.41 vs 15.04），说明方法的稀疏视角鲁棒性尚不足；尽管作者声明 AVP 被禁用，但 OVF 在极其稀疏条件下的增益并不明显，甚至略有反效果，缺少深入解释。
- **缺少效率对比与可扩展性量化：未报告推理时间、显存消耗、模型参数量**与 Attention 复杂度量化对比。AVP 与 OVF 均引入额外计算，但文中只在文字上称"轻量"，缺乏数据支撑。
- **训练-推理分布不一致**：训练时输入视角数≤24，却推理到 32–72 视角；虽然显示了扩展能力，但也意味着稠密视角测试实际上超出了训练分布，在消融和基线比较中可能引入不确定因素。
- **注意力诊断依赖真值位姿**：GeoMass 的 epipolar band 计算使用了 ground-truth poses（论文明确说明仅用于度量）。这使诊断手段不能直接作为无位姿条件下的在线质量信号。
- **应用范围有限**：仅评估了前馈重建/新视角合成质量，没有展示在下游任务（位姿估计、动态场景、编辑等）上的影响，ACID 等自然场景评测也只是局部的多样性覆盖。
