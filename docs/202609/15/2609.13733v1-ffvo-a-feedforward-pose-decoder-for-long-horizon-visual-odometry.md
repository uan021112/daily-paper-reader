## 摘要
稳定可靠的4D空间理解是自动驾驶系统的基础。尽管前馈重建网络能够一次估计相机运动和3D结构，但长视频中的位姿估计仍面临计算成本、长上下文歧义和时间不稳定性的挑战。为应对这些挑战，我们提出前馈视觉里程计（FFVO），一种对联合重建架构进行位姿专门化适配的方法，用于高效且时间稳定的相机位姿估计。FFVO使用：（i）紧凑的相机token表示，以实现计算高效的时间聚合；（ii）分层局部到全局的时间解码器，通过将短程运动聚合与序列级整合分离来缓解几何歧义；（iii）中间轨迹监督，以提升时间稳定性。在Waymo开放数据集（WOD）、KITTI以及一个大规模专有基准上的广泛评估表明，我们的方法相较现有前馈方法表现更优，并大幅减少了抖动和漂移。这些结果支持FFVO作为长时程视觉里程计场景中有效的前馈相机位姿解码器。

## Abstract
Stable and reliable 4D spatial understanding is fundamental for autonomous driving systems. While feedforward reconstruction networks can estimate camera motion and 3D structure in one pass, pose estimation over long videos remains challenged by computational cost, long-context ambiguity, and temporal instability. To address these challenges, we propose Feedforward Visual Odometry (FFVO), a pose-specialized adaptation of joint reconstruction architectures for efficient and temporally stable camera-pose estimation. FFVO uses (i) a compact camera-token representation for computationally efficient temporal aggregation, (ii) a hierarchical local-to-global temporal decoder that mitigates geometric ambiguity by separating short-range motion aggregation from sequence-level integration, and (iii) intermediate trajectory supervision that promotes temporal stability. Extensive evaluation on the Waymo Open Dataset (WOD), KITTI, and a large-scale proprietary benchmark demonstrates that our method performs favorably against existing feedforward approaches, and greatly reduces jitter and drift. These results support FFVO as an effective feedforward camera-pose decoder in long-horizon visual odometry settings.

# FFVO 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：自动驾驶需要稳定可靠的 4D 空间理解（建图、定位、运动预测、长时场景理解，以及为世界模型生成"轨迹–视频"配对数据）。近年来 VGGT、π³、Depth Anything 3 等基于 Transformer 的前馈重建模型，能够在**单次前向传播**中同时回归相机位姿与稠密几何（深度/点图），成为迭代式多视角优化（BA、SLAM）的可扩展替代方案。
- **核心矛盾**：这类前馈预测**局部几何精度高，但全局轨迹一致性差**。在长时程驾驶序列（数百至数千帧）中，位姿估计会出现**抖动（jitter）、片段化（fragmentation）、漂移（drift）**，导致跨帧点图错位——论文图 2 中 π³ 对静态结构（路牌、护栏）产生"重影/重复"，即局部几何对齐但全局被位姿误差撕裂。
- **根本原因**：
  - 标准注意力复杂度随序列长度**二次增长**，直接扩展到长序列不可行；
  - 无约束的全局注意力在**重复场景结构**（车道线、植被）、运动模糊、动态目标存在时会产生**几何歧义**。
- **研究定位**：论文提出 **FFVO（Feedforward Visual Odometry）**，将联合重建架构改造为"**位姿专用**"的前馈解码器，在保持计算效率的同时兼顾长程上下文与局部稳定性；超长轨迹上再与 VGGT-Long 的分段后优化结合，形成 **FFVO-Long**，实现公里级重建（图 1）。

## 2. 方法论

### 2.1 核心思想
- 从预训练 π³ 出发，**冻结**其几何特征聚合模块与点图（几何）通路，**从头训练**一个专用位姿解码分支。这样既保留已学到的局部几何表征，又重塑位姿头以应对长轨迹的时序复杂性。
- 三项关键设计：紧凑相机 token、局部到全局层级时序解码、中间局部轨迹监督。

### 2.2 关键技术细节

- **相机 token 化（Camera Tokenization）**
  - 每帧有 N 个冻结图像 token $X_t=\{x_t^{(j)}\}_{j=1}^N\in\mathbb{R}^{N\times D}$；将图像划分为 M 个粗网格区域 $R_i$，在区域内做平均池化初始化相机 token $C_t=\{c_t^{(i)}\}_{i=1}^M$（M≪N，式 1）。
  - 相机 token 作为紧凑位姿查询，既压缩相机状态，又保留区域级特征。默认 **M=14**。

- **局部到全局时序位姿解码器**
  - **帧内自注意力**：仅在同一帧的 token 间做注意力，更新图像 token 与相机 token（式 2）。
  - **时序交叉注意力**：只有相机 token 作为 Query，去查询时间邻域 $N(t)=\{t':|t'-t|\le w\}$ 内的所有图像/相机 token（式 3），默认 **w=20**。
  - **层级结构**：两个局部窗口时序阶段 + 一个全局整合阶段 + 两个帧自注意力层；辅助局部轨迹头挂在第二个局部阶段之后。
  - **复杂度**：交叉注意力为 $O(T^2M(N+M))$，因 M 固定且 N≫M，退化为 $O(T^2N)$；相比稠密全图像 token 时序自注意力 $O(T^2N^2)$ 大幅降低。

- **位姿参数化与读出**
  - 将 M 个相机 token 平均池化为 $\bar c_t$，经轻量 MLP 头（与 π³ 相同）预测平移 $\hat t_t\in\mathbb{R}^3$ 与 **6D 旋转表示** $\hat r_t\in\mathbb{R}^6$；6D 经归一化与正交化映射到 $\hat R_t\in SO(3)$，组装 $\hat T_{w\leftarrow c_t}$（式 4）。**不假设已知相机内参**，且采用无参考帧（reference-free）形式。

- **训练目标**
  - **相对位姿监督**（避免固定参考帧）：由预测绝对位姿导出相对变换 $\hat T_{c_{t'}\leftarrow c_t}=\hat T_{w\leftarrow c_{t'}}^{-1}\hat T_{w\leftarrow c_t}$（式 5）；损失 = SO(3) 上的**测地旋转距离** + 平移 **ℓ1 损失**（式 6），权重 **λ_R=1、λ_t=100**（沿用 π³）。
  - **中间局部轨迹监督**：在第二个局部窗口阶段后接辅助头，用线性层预测同一邻域 $N(t)$ 内的局部相对位姿轨迹，施加同样的相对位姿损失（式 7），促使相机 token 在网络的**早期**就编码自身状态与邻近帧运动。
  - 总损失 $L=L_{rel}+L_{aux}$（式 8）：中间层保证局部一致运动，最终全局阶段保证长程轨迹一致。

## 3. 实验设计

- **数据集 / 场景**
  - **Waymo Open Dataset (WOD)**：9 个城市驾驶场景评测，**不用于训练**。
  - **KITTI Odometry**：11 个长序列，轨迹长度 393.65–5067.23 m，**不用于训练**。
  - **专有驾驶数据集 (PDD)**：13,140 段、每段 100 帧，覆盖多样天气、昼夜光照与不同车速；90/10 划分 → 11,826 训练 / 1,314 测试。**仅在 PDD 上训练**，序列长度 T=100 与推理段长一致。
- **指标（Benchmark 协议）**
  - **ATE (RMSE)**：逐序列 Sim(3) 对齐（Umeyama）后相机位置的欧氏距离 RMSE（米）。
  - **RPE (Δ=1 帧)**：相邻帧相对位姿误差，报告平移 RMSE（米）与旋转 RMSE（度）。
- **对比方法**
  - 前馈几何基线：**VGGT、π³、π³-finetuned（在 PDD 微调）**；长时程前馈流水线：**VGGT-Long、π³-Long、DA3-Streaming**（后处理协议与 FFVO-Long 一致，保证公平）。
  - ATE-only 的既有结果：DROID-SLAM、MASt3R-SLAM、CUT3R、SCE-SLAM、VGGT-Motion、Scal3R、HyVGGT-VO、LingBot-Map、MVOFormer、PoseFM+PWC，以及经典方法 ORB-SLAM2（有/无回环）、LDSO、DROID-VO、DPVO、DPV-SLAM/++。
- **数据增强**：将前视 + 前左 + 前右相机拼接为 **85° 水平 FoV** 的宽视场流，与标准前视流一同训练；论文中 "FFVO" 表示含增强，"FFVO w/o augmentation" 为不含增强。

## 6. 主要结论与发现

- **WOD**：FFVO ATE **0.862 m**（无增强 0.714 m），优于 π³（1.150）、VGGT（1.359）、π³-finetuned（1.170）；RPEt **0.114–0.118 m** 优于 π³ 的 0.156 m，旋转误差持平。相比 π³-finetuned 的提升说明收益**来自架构设计而非仅训练数据**。
- **PDD**：FFVO ATE **2.494 m**，大幅优于 π³-finetuned（5.720）、π³（7.928）、VGGT（10.194）；RPEt 0.621 m vs 1.773–2.713 m，验证跨天气/光照/车速的鲁棒性。
- **KITTI**：FFVO-Long 平均 ATE **12.960 m，为整体最优**，优于 DA3-Streaming（18.630）、π³-Long（21.180）、VGGT-Long（25.600）、Scal3R（14.550）、SCE-SLAM w/ LC（14.070），说明其位姿解码器能与既有后优化流水线良好集成。
- **定性**：KITTI Seq. 02 中 π³-Long 出现局部轨迹自相交（两次经过重叠），π³-Long 与 DA3-Streaming 在另处出现曲线过度贴近/合并，而 FFVO-Long 更好保留轨迹分离与整体形状（图 7）；PDD 长轨迹上 FFVO 与 GT 贴合更紧（图 6）。
- **消融结论**：局部窗口时序注意力贡献最大（ATE 相对 π³-finetuned 提升 **55.78%**），相机 token 交叉注意力提升 26.35%，辅助监督再提升至 29.98%；M 由 14 增至 24 收益有限（7.070→7.060）。

## 7. 优点

- **问题切中要害**：明确指出"局部几何精度"与"全局轨迹稳定性"之间的鸿沟，并用点图重影等可视化给出直观证据，动机链条清晰。
- **架构高效且可扩展**：用少量相机 token 替代稠密全 token 时序注意力，将复杂度从 $O(T^2N^2)$ 降至 $O(T^2N)$，在保持长程上下文的同时控制算力。
- **层级解码设计合理**：局部窗口先行聚合稳定短程运动线索以缓解歧义，再由全局阶段整合序列级上下文，符合长序列建模范式（Longformer / Video Swin）且针对 VO 做了适配。
- **中间监督带来时序稳定性**：辅助相对位姿头迫使早期层的相机 token 编码邻近帧运动，属于轻量且有效的正则化手段。
- **工程与实验规范**：冻结几何主干、只训位姿分支，训练成本可控；与后优化流水线组合时使用统一协议对比，跨域评测（训练于 PDD、测试于 WOD/KITTI）增强了泛化结论的可信度；消融逐项拆解，归因清楚。
- **实用性**：无需已知相机内参、无参考帧的

形式使其易于嵌入现有流水线，对未标定相机同样适用，具备实际部署潜力。

## 8. 局限与不足

- **效率评估缺失**：论文核心卖点之一是"计算高效"，却未报告推理时延、吞吐量、峰值显存，也未与 DROID-SLAM、DPVO 等迭代式方法做速度对比。在"效率"被作为主要动机的语境下，这一空缺削弱了论证闭环；相机 token 数量 M、局部窗口 w 等关键超参也仅以"显存约束经验选取"一笔带过，缺少显式的精度–效率曲线。
- **尺度与对齐协议的可解释性**：ATE 采用逐序列 Sim(3) 对齐，说明方法本身**不输出度量尺度**（单目/无内参设定下的固有属性）。这使 ATE 数值部分吸收了尺度误差，跨方法比较时"谁更准"需谨慎解读；论文也未单独报告尺度误差或与 GT 尺度对齐后的结果。
- **动态物体与运动模糊未做针对性处理**：论文将重复结构、动态目标、模糊列为全局注意力的歧义来源，但方法层面仅通过局部窗口 + 层级聚合隐式缓解，未见显式的动态掩膜、运动分割或不确定性建模，也缺少动态场景（如 WOD 中大量运动车辆）的专项分析。
- **数据增强的收益不明确**：85° 拼接宽视场流训练在 WOD/PDD 上反而略降（作者归因于与标准前视评测视角不匹配）。这既说明评测协议与训练输入存在错配，也意味着"增强"这一项的净收益未被清晰证明，读者难以判断该设计应保留还是舍弃。
- **后优化阶段依赖外部流水线**：FFVO-Long 的公里级重建依赖 VGGT-Long 式的分段后优化，增益中有多少来自位姿解码器、多少来自后优化本身，论文虽以统一协议控制变量，但缺少"FFVO 原始输出 vs 后优化输出"的分段定量拆解（如各段 ATE 的分布、漂移随帧数增长的曲线）。
- **对比基线的不完整性**：ATE-only 的既有方法条目缺少 RPE，KITTI 部分方法逐序列值缺失（‡），导致主表在"旋转精度""局部抖动"这两个恰好是论文核心痛点的维度上对比不足；同时未与同期更强的长序列前馈方法（若有）做全面交叉验证。
- **训练数据规模与泛化边界**：仅在 PDD（13,140 段 × 100 帧）上训练，序列长度 T=100 与推理段长一致。**长于 100 帧的序列完全依赖分段拼接与后优化**，模型本身并未在更长窗口上训练，因此"长程一致性"在架构层面是否真正成立，尚缺乏"直接用更长窗口推理"的对照实验。
- **消融分辨率偏低**：消融在 224 px 低分辨率下进行，与主实验的 518 px 设置不一致，组件相对贡献（尤其依赖精细几何线索的相机 token 交叉注意力）在满分辨率下是否保持同样排序，未经验证。

## 9. 可能的改进方向与后续工作

- **补齐效率维度**：报告不同 M、w 与输入分辨率下的延迟/显存/精度三元曲线，给出面向车载实时（如 ≥10 FPS）的推荐配置。
- **尺度与不确定性**：引入度量尺度头或与 IMU/轮速计的轻量融合，输出逐帧位姿协方差，使长时程后端可做加权优化而非等权拼接。
- **动态与歧义显式建模**：加入运动掩膜或可学习的动态 token，抑制运动车辆对相机 token 聚合的干扰；针对重复结构引入几何一致性/回环检测的显式约束。
- **更长的训练窗口与课程学习**：以 100 帧为起点逐步扩展到 200–500 帧的训练课程，检验架构在超长上下文中的可扩展性，并与后优化方案做"端到端 vs 分段"的公平对比。
- **后优化的可微化/一体化**：将分段后优化改为可微模块或轻量在线 BA，避免两阶段误差累积，并明确各阶段贡献。
- **评测协议统一**：同时报告 Sim(3) 与 SE(3)/尺度对齐结果，补全 RPE 与逐序列明细，提供漂移随里程增长的曲线，便于社区横向复现。
- **数据增强的再设计**：使训练视角与评测视角一致（或在评测中同步使用宽视场），从而真正验证宽 FoV 对 VO 稳定性的价值。

## 10. 总体评价与启示

- **定位清晰、贡献聚焦**：FFVO 并不试图重造重建模型，而是准确识别出"前馈几何已够好、位姿才是瓶颈"这一现状，把改动集中到位姿解码分支，属于**高性价比的架构级改进**。其"冻结几何、重训位姿"的思路对 VGGT、π³、DA3 等系列模型具有可迁移性。
- **设计有据可依**：相机 token 化 + 局部窗口时序注意力 + 全局整合的层级结构，本质是把 NLP/视频理解中成熟的稀疏注意力范式（Longformer、Video Swin 式的窗口化建模）迁移到 VO 场景，并针对"相机状态是低维、图像是稠密"的不对称性做了 M≪N 的降维设计，复杂度从 $O(T^2N^2)$ 降到 $O(T^2N)$ 的论证简洁有力。
- **中间监督是亮点**：在局部阶段就施加相对位姿监督，等价于让相机 token 在早期层即"锚定"自身状态与邻近运动，是一种轻量、通用、几乎无额外推理开销的正则化，值得在其他时序位姿任务中复用。
- **实验的说服力与短板并存**：跨域（PDD 训练 → WOD/KITTI 评测）、统一后优化协议、逐项消融，三点共同支撑了主要结论；但效率、尺度、漂移曲线、动态场景四方面的空白，使其离"完整可信的系统级验证"尚有距离。消融显示局部窗口时序注意力贡献最大（55.78% 相对提升），也提示后续工作可优先深挖这一模块（如自适应窗口、多尺度窗口）。
- **实践启示**：对于长时程 4D 理解任务，与其一味加长序列或堆叠后优化，不如**先修位姿**——位姿的全局一致性是点图、建图、世界模型数据生成的共同前置条件；同时，把"局部稳定的短程先验"与"长程的稀疏整合"分层处理，是控制算力与精度权衡的通用范式。
- **一句话总结**：FFVO 以少量相机 token 与层级时序解码，把前馈重建模型的"几何强、位姿弱"短板显著补齐，并在公里级驾驶序列上达到 SOTA 级别的轨迹一致性；其主要待补项在于效率量化、尺度处理与动态/超长上下文的系统验证。
