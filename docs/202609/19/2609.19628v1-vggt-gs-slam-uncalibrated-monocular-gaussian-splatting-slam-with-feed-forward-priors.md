## 摘要
我们提出了 VGGT-GS SLAM，一个面向未标定视频设计的单目3D高斯泼溅SLAM系统。基于前馈VGGT位姿和深度先验，我们的系统执行子图可微光束法平差，联合优化相机位姿与3D高斯地图，同时通过解析标定雅可比优化子图共享的内参和径向-切向畸变。为提高全局一致性，我们引入高斯原生对齐（GNA），用于顺序子图之间以相机为锚的尺度细化以及回环候选验证。在标准室内基准上的大量实验表明，在未标定设置下定位精度持续提升且渲染质量高，为未标定高斯SLAM建立了强基线。

## Abstract
We present VGGT-GS SLAM, a monocular 3D Gaussian Splatting SLAM system designed for uncalibrated videos. Starting from feed-forward VGGT pose and depth priors, our system performs submap differentiable bundle adjustment that jointly refines camera poses and a 3D Gaussian map, while optimizing submap-shared intrinsics and radial--tangential distortion through analytic calibration Jacobians. To improve global consistency, we introduce Gaussian-native alignment (GNA) for camera-anchored scale refinement between sequential submaps and verification of loop-closure candidates. Extensive experiments on standard indoor benchmarks show consistent improvements in localization accuracy and strong rendering quality under uncalibrated settings, establishing a strong baseline for uncalibrated Gaussian SLAM.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：3D Gaussian Splatting（3DGS）已能实现实时渲染与高保真新视角合成，催生了一批联合估计相机轨迹与场景地图的高斯 SLAM 系统。
- **核心痛点**：
  - 现有高斯 SLAM 大多**假设相机已完成标定**，且不少方法依赖 **RGB-D 输入**才能可靠初始化高斯。
  - 在仅有普通单目相机、缺少标定元数据与深度传感器的场景下，相机内参与畸变必须与运动、场景结构**联合在线估计**，而非事先给定。
- **前馈先验的局限**：DUSt3R、MASt3R、VGGT 等前馈重建模型虽能提供强位姿与稠密几何先验，但这些预测**仅是初始化**：
  - 标定误差会被错误地吸收进场景几何中；
  - 独立重建的子图之间**尺度不一致**，序列累积会产生相对尺度漂移。
- **论文定位**：提出 VGGT-GS SLAM，一个面向**未标定单目视频**的高斯泼溅 SLAM 系统，把 VGGT 的位姿/深度先验转化为可优化的高斯子图，在子图内联合精化位姿、高斯与相机标定，并通过高斯原生对齐（GNA）解决子图间尺度一致性与回环验证问题。

## 二、方法论

### 1. 核心思想
以 VGGT 前馈位姿与深度为初始化，在**子图内做可微光束法平差（BA）**，联合优化高斯属性、相机位姿、曝光参数与子图共享的相机模型（内参 + 径向-切向畸变）；在**子图间用高斯原生对齐（GNA）** 做相机锚定的尺度细化与回环候选验证，最后用 Sim(3) 位姿图优化获得全局一致性。

### 2. 关键技术细节

- **子图划分与初始化**
  - 关键帧按 `S + O` 分组（默认 S=24，O=1），每个窗口送入 VGGT 推理。
  - VGGT 输出相机外参 `{T_c←w_i}`、内参 `{K_i}` 与深度-置信度 `{D_i, C_i}`；共享内参 K 取 `{K_i}` 均值，畸变系数初始化为 0。
  - 高斯初始化沿用 MonoGS 策略：按固定步长下采样有效深度像素（`D_i(p) > 10^-8`），反投影到世界系作为高斯中心，SH 颜色取自输入像素，旋转设为单位四元数，不透明度 α=0.5，各向同性对数尺度 `ℓ_j = log(0.1·d_nn,j)`。

- **子图内联合 BA**
  - 固定首帧位姿定义子图参考系，其余位姿用左乘 SE(3) 增量 `T ← exp(ξ_i)T`（ξ_i ∈ R⁶）。
  - 内参采用**对数空间焦距更新 + 加性主点更新**；畸变采用**有界参数化** `k_j = s_k·tanh(ρ_kj)`、`p_j = s_p·tanh(ρ_pj)`，保证系数在设定范围内。
  - 总损失：`L_BA = L_rgb + λ_depth·L_depth + λ_iso·L_iso`。
    - **光度损失**：仿射曝光补偿 `I'_i(p) = exp(a_i)·I_i(p) + b_i`，结合 L1 与 DSSIM；另有“曝光稳定”变体固定 `a_1=b_1=0` 作为亮度参考。
    - **深度损失**：以 VGGT 深度为弱几何先验，定义带死区容差的相对残差 `r_i(p) = [|D̂-D|/max(D,ε) - τ_depth]_+`，并用中值归一化、截断后的置信度 `C̃_i` 加权。
    - **各向同性正则**：`L_iso = (1/3M)Σ_j ||s_j - s̄_j·1_3||_1`，抑制过度各向异性高斯。

- **解析标定雅可比（核心贡献之一）**
  - 在 gsplat 可微高斯投影中，对完整标定向量 `θ_cal = (fx, fy, cx, cy, k1, k2, k3, p1, p2)` 解析求导。
  - 相机模型：`(u,v) = (x/z, y/z)`，`r² = u²+v²`，径向因子 `d = 1 + k1r² + k2r⁴ + k3r⁶`，畸变归一化坐标含径向+切向项，最终像素坐标 `(U,V) = (fx·u_d + cx, fy·v_d + cy)`。
  - **投影中心雅可比**：`∂m_2d/∂q = (∂D/∂q)m_d + D(∂m_d/∂q) + ∂c/∂q`。
  - **投影协方差雅可比**：`J = DAB`，`Σ_2d = JΣ_3d^c Jᵀ`，对 q 求导得 `∂Σ_2d/∂q = (∂J/∂q)Σ_3d^c Jᵀ + JΣ_3d^c(∂J/∂q)ᵀ`。
  - CUDA 核返回物理系数梯度，自动微分再施加有界参数链式法则（如 `∂L/∂ρ_kj = (∂L/∂k_j)·s_k·(1-tanh²ρ_kj)`）。

- **高斯原生对齐（GNA）**
  - **相机锚定初始化**：由共享重叠帧位姿确定旋转 R，由恒等像素深度对应确定初始尺度 s₀，平移 `t₀ = c_A - s₀·R·c_B`；固定 R，仅优化对数尺度 `u = log s`。
  - **协方差感知高斯匹配**：将源高斯按尺度变换到参考子图，`μ^{B→A}_j(u) = c_A + sR(μ^B_j - c_B)`，`Σ^{B→A}_j(u) = s²RΣ^B_j Rᵀ`。
  - 对参考高斯 i 与变换后源高斯 j，定义 `d_ij` 与 `S_ij = Σ^A_i + Σ^{B→A}_j + (ε+τ²)I₃`，使用对数核 `κ_ij(u) = -½(d_ijᵀ S_ij⁻¹ d_ij + λ_det·log|S_ij|)`。
  - 结合不透明度与观测计数的权重 `w_i`，在 k 近邻上构造**双向得分** `ℓ^{B→A}`、`ℓ^{A→B}`。
  - 最终目标：`L_GNA(u) = -ℓ^{B→A}(u) - ℓ^{A→B}(u) + λ_sp(u - log(m_A/m_B))²`，其中 `m_A, m_B` 为中值最近邻间距。
  - 尺度更新被**限制在初始化附近**，仅当归一化目标改善时才保留，否则退回 s₀。

- **回环闭合与高斯原生验证**
  - 用 SALAD 描述子检索历史帧（阈值 τ_r，排除直接前驱），检索到的图像仅加入**独立的联合 VGGT 回环推理批次**。
  - GNA 仅用于**验证**，不用于变换精化；接受条件为 `L* ≤ τ_L` 且 `Δs ≤ τ_s`，并附加**旋转一致性检查**（与前序链差异 >90° 则拒绝）。
  - 接受的回环**保留原始 VGGT 桥接变换**，进入全局 Sim(3) 位姿图；位姿图节点为子图局部-全局变换 `G_i`，优化只更新 `G_i`，不合并子图，局部高斯/位姿/标定保持不变。

- **其他实现细节**
  - 关键帧选取：LK 光流平均位移 > τ_disp（30 像素）或有效轨迹 <10 条。
  - 高斯精化：按累积图像空间梯度做 clone/split，并剪枝低不透明度高斯。
  - 非关键帧位姿估计：固定高斯图与标定，用最近起始关键帧所在子图做 SE(3) 优化（90 次迭代）。
