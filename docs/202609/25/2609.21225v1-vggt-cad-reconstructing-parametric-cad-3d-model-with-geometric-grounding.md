## 摘要
参数化CAD重建需要从视觉观测中同时恢复精确几何和可编辑建模操作，这使得其在视图有限且存在歧义的情况下极具挑战。现有方法主要依赖二维外观线索，缺乏强多视角几何先验。在本工作中，我们提出VGGT-CAD，一种用于从单视角和多视角观测中进行参数化CAD重建的几何感知框架。我们将预训练的三维几何先验迁移到CAD重建中，通过将相机参数编码为条件token，并与图像token联合建模。为处理不同数量的视点，我们引入可变视角跨视角上下文聚合模块，自适应融合多视角特征。我们进一步提出一种无需训练的几何感知视图选择策略，以在推理时选择互补且可靠的帧。所得表示使用非自回归解码器解码为CAD命令序列。我们还开发了VideoCAD，一个通过多视角重渲染从现有CAD数据构建的大规模多视角视频基准。大量实验证明了VGGT-CAD在不同观测配置下用于视觉CAD重建的有效性。

## Abstract
Parametric CAD reconstruction requires recovering both precise geometry and editable modeling operations from visual observations, making it challenging under limited and ambiguous views. Existing methods mainly rely on 2D appearance cues and lack strong multi-view geometric priors. In this work, we present VGGT-CAD, a geometry-aware framework for parametric CAD reconstruction from single- and multi-view observations. We transfer pretrained 3D geometric priors into CAD reconstruction by encoding camera parameters as condition tokens and jointly modeling them with image tokens. To handle varying numbers of viewpoints, we introduce a variable-view cross-view context aggregation module that adaptively fuses multi-view features. We further develop a training-free geometry-aware view selection strategy to select complementary and reliable frames during inference. The resulting representation is decoded into CAD command sequences using a non-autoregressive decoder. We also develop VideoCAD, a large-scale multi-view video benchmark derived from existing CAD data through multi-view re-rendering. Extensive experiments demonstrate the effectiveness of VGGT-CAD for visual CAD reconstruction under different observation configurations.

## 2. 方法论

- **核心思想**：把相机内外参编码为条件 token，与图像 token 联合输入 VGGT 风格的多视角视觉编码器；再通过可变视角跨视图聚合得到固定维度全局表示，最后用非自回归 Transformer 解码器并行预测 CAD 命令序列与量化参数。
- **问题形式化**：给定多视角图像集合 \(I=\{I_1,\dots,I_N\}\) 和对应相机参数 \(P=\{P_1,\dots,P_N\}\)，目标是生成命令序列 \(M=[C_1,\dots,C_{N_c}]\)。整体建模为条件概率 \(p(M|I,P,\Theta)=\prod_j p(t_j,p_j|I,P,\Theta)\)，其中 \(t_j\) 为命令类型，\(p_j\) 为参数向量。
- **CAD 命令表示**：
  - 主要覆盖 **sketch** 与 **extrude** 两类核心操作，命令包括 SOL、EOS、Line、Arc、Circle、Extrude 等。
  - 每个命令参数统一堆叠为 16 维向量，包含 2D 坐标、角度、半径、草图平面姿态、挤出距离、布尔类型等；未使用槽位用 -1 填充。
  - 将模型包围盒归一化到 \([-1,1]^3\)，连续参数量化为 256 个离散等级，把回归问题转为分类问题。
- **网络架构**：包含五个模块。
  - **相机条件编码器**：将相机外参、内参和图像尺寸编码为相机 token \(c_i\)，经 MLP 与 Transformer 主干细化。
  - **几何多视角视觉编码器**：采用 VGGT 多视角 ViT 作为骨干，将相机 token 与图像 patch token 拼接，进行帧内自注意力和跨视图自注意力，使相机方向信息传播到所有图像特征。
  - **辅助相机条件解码器**：从相机特征预测平移、旋转四元数和 FOV，并转为焦距，用于训练时辅助监督。
  - **可变视角跨视图上下文聚合器**：对每个视角特征用共享 2D 卷积编码，再用 MLP 注意力计算视角权重并加权融合，输出全局隐向量 \(z\)，从而适应 2–8 个可变输入视角。
  - **序列解码器**：非自回归 Transformer，以可学习查询 \(E\) 为输入，通过 self-attention 和 cross-attention 与 \(z\) 交互，最后用两个并行头预测命令类型分布和 16×256 参数分布。
- **训练与损失**：
  - 总损失 \(L_{\text{total}}=L_{\text{CAD}}+\lambda L_{\text{cam}}\)，\(\lambda=1.0\)。
  - \(L_{\text{CAD}}=L_{\text{type}}+\beta L_{\text{param}}\)，\(\beta=2\)，两者均为交叉熵；无效参数槽和 padding 通过 Validity Mask 排除。
  - 相机损失 \(L_{\text{cam}}=L_t+L_q+L_f\)，分别监督平移、旋转四元数和归一化焦距；旋转损失考虑四元数双覆盖性质。
