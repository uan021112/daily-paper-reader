## 摘要
我们提出了 VGGT-GS SLAM，一种面向未标定视频设计的单目 3D 高斯泼溅 SLAM 系统。从 VGGT 的前馈位姿与深度先验出发，我们的系统执行子图可微光束法平差，联合优化相机位姿与 3D 高斯地图，同时通过解析标定雅可比优化子图共享的内参与径向-切向畸变。为提高全局一致性，我们引入高斯原生对齐（Gaussian-native alignment, GNA），用于序列子图之间以相机为锚的尺度细化以及回环候选验证。在标准室内基准上的大量实验表明，在未标定设置下，定位精度持续提升且渲染质量优异，为未标定高斯 SLAM 建立了强基线。

## Abstract
We present VGGT-GS SLAM, a monocular 3D Gaussian Splatting SLAM system designed for uncalibrated videos. Starting from feed-forward VGGT pose and depth priors, our system performs submap differentiable bundle adjustment that jointly refines camera poses and a 3D Gaussian map, while optimizing submap-shared intrinsics and radial--tangential distortion through analytic calibration Jacobians. To improve global consistency, we introduce Gaussian-native alignment (GNA) for camera-anchored scale refinement between sequential submaps and verification of loop-closure candidates. Extensive experiments on standard indoor benchmarks show consistent improvements in localization accuracy and strong rendering quality under uncalibrated settings, establishing a strong baseline for uncalibrated Gaussian SLAM.

# VGGT-GS SLAM 论文总结

## 1. 核心问题与研究动机

- **背景**：3D Gaussian Splatting（3DGS）实现了实时、高保真的渲染，推动了 Gaussian-SLAM 类系统（同时估计相机轨迹与场景地图）的发展。但绝大多数现有方法**假设相机已完成标定**，且不少依赖 RGB-D 输入来可靠初始化高斯。
- **现实痛点**：消费级单目相机通常既无标定元数据、也无深度传感，导致这些方法难以落地。此时相机标定必须与运动、场景结构**一并估计**，而不能预先给定。
- **前馈先验的局限**：DUSt3R / MASt3R / VGGT 等前馈重建模型可提供强位姿与稠密几何先验，GeoGS-SLAM 等已将其与高斯建图结合；但这些预测**仅被当作初始化**：标定误差会被吸收进场景几何中，且独立重建的子图之间**不共享一致尺度**。
- **本文定位**：保留 VGGT-SLAM 的子图组织方式，把 VGGT 的位姿/深度预测转化为**可优化的高斯子图**，在子图内联合精化标定与几何，并显式处理子图间对齐——为"未标定高斯 SLAM"建立强基线。

## 2. 方法论

### 2.1 核心思想
以 VGGT 前馈位姿/深度为初始化，通过**标定感知的高斯光束法平差（calibration-aware Gaussian BA）**在子图内联合优化位姿、高斯属性、内参与径向-切向畸变；再以**高斯原生对齐（GNA）**完成子图间相机锚定尺度细化与回环验证，最终在 Sim(3) 位姿图上做全局优化。

### 2.2 子图与初始化
- **滑窗划分**：沿用 VGGT-SLAM，将关键帧分为含 S 个新帧 + O 个重叠帧的窗口（默认 S=24、O=1）。
- **VGGT 初始化**：每个窗口经 VGGT 预测外参、内参、深度与置信度图；共享内参 K 取各帧 K_i 的平均，畸变系数置零。
- **高斯初始化**（参考 MonoGS）：将有效深度像素（D_i(p) > 1e-8）按固定步长下采样并反投影到世界系；SH 颜色取自 I_i(p)，旋转为单位阵，不透明度 α_j = 0.5；各向同性对数尺度设为 ℓ_j = log(0.1·d_nn,j)/3，d_nn,j 为同帧采样点的最近邻距离。

### 2.3 子图内联合 BA
- **优化变量**：高斯表示、相机位姿、逐帧仿射亮度参数、跨帧共享的相机模型。首帧位姿固定以定义子图参考系，其余位姿用左乘 SE(3) 增量 T ← exp(ξ_i)T，ξ_i ∈ R⁶。
- **参数化技巧**：焦距在对数空间更新、主点加性更新；5 个径向-切向畸变系数用 tanh 有界重参数化 k_j = s_k·tanh(ρ_kj)、p_j = s_p·tanh(ρ_pj)。
- **总目标**：L_BA = L_rgb + λ_depth·L_depth + λ_iso·L_iso（默认 λ_depth=0.3、λ_iso=10）。
  - *光度项*：仿射曝光补偿 I' = exp(a_i)I + b_i，结合 L1 与 DSSIM 混合；针对"曝光-颜色变暗歧义"，有一个曝光稳定变体在局部 BA 中固定 a₁=b₁=0，并在后续建图精化中冻结曝光参数。
  - *深度项*：VGGT 深度作为**弱几何先验**，采用带死区的相对残差 r_i(p) = [ |D̂−D| / max(D,ε) − τ_depth ]₊（τ_depth=0.03），并按中值归一化并截断（c_max=5）的置信度加权。
  - *各向同性正则*：惩罚过于各向异性的高斯，使三个尺度分量趋近其均值。

### 2.4 解析标定雅可比
- 在 gsplat 的可微高斯投影中，**解析地**求投影中心 m_2d 与二维协方差 Σ_2d 对完整标定向量 θ_cal = (f_x, f_y, c_x, c_y, k₁, k₂, k₃, p₁, p₂)（共 9 个参数）的导数。
- 相机模型含径向畸变因子 d = 1 + k₁r² + k₂r⁴ + k₃r⁶ 与切向项；令 A = ∂(u_d,v_d)/∂(u,v)、B = ∂(u,v)/∂(x,y,z)、J = DAB、Σ_2d = JΣ_3d^c Jᵀ，则
  - ∂m_2d/∂q = (∂D/∂q)m_d + D(∂m_d/∂q) + ∂c/∂q；
  - ∂Σ_2d/∂q = (∂J/∂q)ΣJᵀ + JΣ(∂J/∂q)ᵀ。
- CUDA 核返回对物理系数的梯度，自动微分再套用有界参数链式法则（如 ∂L/∂ρ_kj = (∂L/∂k_j)·s_k(1−tanh²ρ_kj)）。

### 2.5 高斯原生对齐（GNA）
- **相机锚定初始化**：相邻子图共享重叠关键帧 → 由共享图像位姿确定旋转 R；由 identity-pixel 深度对应确定初始尺度 s₀；平移由相机中心定为 t₀ = c_A − s₀Rc_B。固定 R，仅优化 u = log s。
- **变换方式**：源高斯均值与协方差按 μ^B→A(u) = c_A + sR(μ_B − c_B)、Σ^B→A(u) = s²RΣ_BRᵀ 变换，因而**协方差携带点中心之外的空间形状/朝向信息**。
- **匹配核**：先按不透明度、锚视图可见性、空间尺度筛选并做鲁棒场景尺度归一化；定义 d_ij、S_ij = Σ_i^A + Σ_j^B→A + (ε+τ²)I₃，使用对数核 κ_ij = −½(d_ijᵀ S_ij⁻¹ d_ij + λ_det·log|S_ij|)，其中 τ 为退火带宽。
- **双向得分**：以不透明度与观测次数构造权重 w_i，对源中心 j 的 k 近邻做加权软最大聚合得到 ℓ_{B→A}，反向同理。
- **目标**：L_GNA(u) = −ℓ_{B→A}(u) − ℓ_{A→B}(u) + λ_sp(u − log(m_A/m_B))²；尺度更新被限制在初始化附近，**仅当目标改善时才保留**，否则退回 s₀。

### 2.6 回环检测与验证
- 用 SALAD 描述子对历史子图检索（阈值 τ_r），排除紧邻前驱，保留最近的一对；检索帧仅加入**单独的联合 VGGT 回环推理批次**，其深度对应初始化子图间 Sim(3)。
- GNA 在此**只用于验证而非变换精化**：接受条件为 L* ≤ τ_L（1000）且 |Δs| ≤ τ_s（0.20），并附加旋转一致性检查（与前序链差异超过 90° 则拒绝）；被接受的回环**保留原始 VGGT 桥接变换**。
- 位姿图节点为子图到全局的 Sim(3) 变换 G_i，仅优化 G_i（局部高斯、位姿、标定不变），子图**不合并**。
