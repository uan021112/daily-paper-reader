## 摘要
3D 场景图通过将物理实体及其包含关系和空间关系组织成层次化地图，为语言引导的导航提供支持。构建此类结构化地图需要一种场景表示，能够在不同视角下稳定地区分语义区域和对象实例。为此，我们提出 PanoGraphGS，这是一种统一框架，将全景全景分割与分层 3D 场景图构建相结合，并基于 3D 高斯表示进行学习。该框架在共享的高斯几何结构上学习语义特征和实例特征。基于原型的语义学习与基于关联的实例学习，可生成跨视角一致的全景预测。学习得到的表示支持新视角全景分割以及直接在高斯层级进行全景解码。语义感知场景图模块进一步恢复由楼层、房间、场景内容物和对象组成的层次结构，并推断包含关系和空间关系。我们还发布了 NaviGS，这是一个用于全景场景理解的真实世界数据集，提供 3DGS、网格、RGB、语义和深度数据。在 3D 场景图识别方面，与所评估的最强基线相比，PanoGraphGS 在 Replica 和 NaviGS 上的对象节点准确率平均高出 50 多个百分点。在所评估的方法中，PanoGraphGS 在 2D 全景分割方面也达到了最先进的性能。这些结果表明，PanoGraphGS 在分层 3D 场景理解和 2D 全景分割方面均具有良好效果。项目网站：https://github.com/gaojh0333/PanoGraphGS。

## Abstract
3D scene graphs support language-guided navigation by organizing physical entities and their containment and spatial relations into hierarchical maps. Building such structured maps requires a scene representation that consistently distinguishes semantic regions and object instances across viewpoints. To this end, we present PanoGraphGS, a unified framework that integrates panoptic 3D Gaussian representation learning with hierarchical 3D scene graph construction. The framework learns semantic and instance features on shared Gaussian geometry. Prototype-based semantic learning and association-based instance learning produce consistent panoptic predictions across viewpoints. The learned representation supports novel-view panoptic segmentation and direct Gaussian-level panoptic decoding. A semantic-aware scene graph module further recovers a floor-room-stuff-object hierarchy with containment and spatial relations. We further release NaviGS, a real-world dataset for panoramic scene understanding. The dataset provides 3DGS, mesh, RGB, semantic, and depth data. For 3D scene graph identification, PanoGraphGS outperforms the strongest evaluated baseline in object-node accuracy by more than 50\% points on average across Replica and NaviGS. PanoGraphGS also achieves state-of-the-art performance among the evaluated methods in 2D panoptic segmentation. These results demonstrate the effectiveness of PanoGraphGS in both hierarchical 3D scene understanding and 2D panoptic segmentation. The project website is available at: https://github.com/gaojh0333/PanoGraphGS.

## 1. 核心问题与整体含义

- **研究目标**：为语言引导的机器人导航构建结构化三维地图，使系统不仅能识别“是什么”，还能记录对象属于哪个房间、房间属于哪一层，以及实体之间的空间关系。
- **核心挑战**：
  - 多视角下的遮挡和可见性差异会造成监督不均，语义预测容易不一致。
  - 同一物体在不同图像中可能被赋予不同的局部实例编号，导致跨视角身份混乱。
  - 现有全景分割与三维场景图构建通常分开处理，且不少方法依赖 RGB-D 点云；语义、实例身份与层级关系难以在同一表示中统一。
- **论文的整体思路**：以 3D 高斯泼溅（3DGS）作为共享三维表示，在高斯几何上联合学习语义和实例特征，再据此构建“楼层—房间—场景内容物—对象”的层级场景图。作者称这里的 *stuff* 为结构性或非独立实例的场景内容，如墙、地面等。

## 2. 方法论

### 2.1 共享高斯表示与多视角监督

- 每个高斯除位置、尺度、旋转、不透明度和颜色外，还附加独立的语义特征与实例特征，二者共享同一套高斯几何和可见性。
- 通过可见性感知的 alpha 合成，将高斯特征渲染到图像像素上。这样，来自多视角图像的监督可以作用于共享的三维特征场。
- 输入是带相机位姿的 RGB 图像，论文使用 SAM3 生成的分割掩码作为语义和实例监督；这些掩码可能含噪，且实例编号可能只在单帧内有效。

### 2.2 基于原型的语义学习

- 为每个语义类别维护一个可学习原型向量。渲染得到的像素特征先经过残差式 MLP 投影和归一化，再与类别原型计算相似度，得到类别 logits。
- **关键设计**是同一个投影与分类机制既用于图像像素特征，也用于单个高斯的三维特征：训练时兼顾 2D 渲染监督和 3D 高斯级预测，推理时可直接解码高斯语义。
- 语义损失由几部分组成：带置信度的分类损失、区域级对比学习、特征与类别原型对齐，以及特征范数正则化。

### 2.3 基于关联的实例学习

- 实例分支为全局持久实例身份设置可学习原型；论文实现中使用 **256 个实例原型**。
- 对每个视图，将局部实例区域内像素对各全局原型的预测概率汇总，构成“局部实例—全局身份”的匹配代价。
- 使用**匈牙利算法**求解每个视图内局部实例与全局身份的一对一分配。由此把视图局部的伪实例编号映射到跨视角持久身份，而不是直接逐对匹配相机视图。
- 实例损失也采用置信度加权、区域级对比学习和原型对齐等机制。完成学习后，可在图像像素层或高斯层预测实例身份。

### 2.4 置信度加权与联合训练

- 对语义和实例监督分别估计像素置信度：依据其特征与所属类别或实例的特征中心的相似度，并考虑类内特征离散程度。
- 置信度较低的像素对训练目标贡献较小，旨在减轻遮挡、边界和错误伪标签的干扰。
- 联合目标由 RGB 外观重建损失、语义损失和实例损失组成。外观损失遵循标准 3DGS 设置，结合 L1 与结构相似性损失；文中给出的权重参数为 \(\mu=0.2\)。

### 2.5 层级场景图构建

1. 对每个高斯解码语义类别和持久实例身份。
2. 将具有相同持久身份的高斯聚合为对象；将同类结构性语义高斯聚合为 *stuff* 实体。
3. 根据地面和天花板语义及其垂直分布识别楼层；利用墙、门、窗等结构语义及其空间组织划分房间。
4. 将各房间相机视角渲染出的图像与 CLIP 结合，为房间赋予卧室、厨房等功能类别。
5. 依据对象支撑高斯落在候选房间包围盒内的数量投票，将对象关联到房间；最终建立楼层—房间以及房间—对象等包含关系，并表示实体间空间关系。

## 6. 主要结论与发现

- PanoGraphGS 在共享高斯几何上联合学习语义类别和持久实例身份，使同一表示同时支持新视角 2D 全景预测与高斯级实体解码。
- 场景图评测中，作者报告其对象节点准确率在 Replica 和 NaviGS 上均明显高于所比较方法：Replica 为 **89.90%**，NaviGS 为 **98.36%**。论文摘要称，相比最强评估基线，平均高出 50 多个百分点。

- 消融结果表明，实例关联对对象准确率提升尤其显著；置信度加权也改善了 Replica 上的分割指标和对象识别表现。
- 作者指出当前方法的局限包括开放式空间（如开放厨房）难以明确划分房间，以及目前的场景图构建是离线流程，尚未实现连续观测下的在线增量构图。

## 7. 优点

- **任务整合较完整**：把语义分割、实例身份维护和层级场景图构建纳入一个共享三维表示，而不是将分割结果与图结构后处理拼接。
- **针对跨视角实例错配设计了明确机制**：通过局部实例到全局原型的匈牙利匹配，处理不同视图中的局部实例编号不一致问题。
- **兼顾二维与三维解码**：同一语义预测机制可作用于渲染像素和高斯特征，支持图像级预测及高斯级实体抽象。
- **考虑伪标签噪声**：置信度加权机制面向边界、遮挡等不可靠监督区域，且同时用于语义与实例分支。
