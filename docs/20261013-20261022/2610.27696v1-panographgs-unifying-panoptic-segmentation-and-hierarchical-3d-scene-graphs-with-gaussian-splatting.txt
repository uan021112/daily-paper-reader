# PanoGraphGS: Unifying Panoptic Segmentation and Hierarchical 3D Scene Graphs with Gaussian Splatting 

Jinghan Gao ∗, Siyu Wang ∗, Dongyu Feng, Yiyuan Pan, Rong Xiong 

Abstract — 3D scene graphs support language-guided navi-gation by organizing physical entities and their containment and spatial relations into hierarchical maps. Building such structured maps requires a scene representation that consis-tently distinguishes semantic regions and object instances across viewpoints. To this end, we present PanoGraphGS, a unified framework that integrates panoptic 3D Gaussian representation learning with hierarchical 3D scene graph construction. The framework learns semantic and instance features on shared Gaussian geometry. Prototype-based semantic learning and association-based instance learning produce consistent panoptic predictions across viewpoints. The learned representation sup-ports novel-view panoptic segmentation and direct Gaussian-level panoptic decoding. A semantic-aware scene graph mod-ule further recovers a floor-room-stuff-object hierarchy with containment and spatial relations. We further release NaviGS, a real-world dataset for panoramic scene understanding. The dataset provides 3DGS, mesh, RGB, semantic, and depth data. For 3D scene graph identification, PanoGraphGS outperforms the strongest evaluated baseline in object-node accuracy by more than 50% points on average across Replica and Nav-iGS. PanoGraphGS also achieves state-of-the-art performance among the evaluated methods in 2D panoptic segmentation. These results demonstrate the effectiveness of PanoGraphGS in both hierarchical 3D scene understanding and 2D panoptic segmentation. The project website is available at: https: //github.com/gaojh0333/PanoGraphGS .

I. INTRODUCTION Panoptic 3D scene reconstruction is fundamental to language-guided robotic navigation. Successful navigation requires embodied agents to recognize semantic categories, maintain persistent instance identities, and reason about spatial organization in a globally consistent map. Such tasks require reasoning over nested containment and spatial re-lations. A 3D scene graph formalizes this organization by representing physical entities as nodes and their containment and spatial relations as edges [1], [2]. 3D Dynamic Scene Graphs [3], Hydra [4], and HOV-SG [5], have advanced structured spatial mapping. However, these pipelines com-monly rely on per-pixel RGB-D observations or depth-derived geometry. Incomplete or noisy depth can degrade object-extent estimation, cross-view association, room par-titioning, and spatial-relation inference. Moreover, existing methods typically construct scene graphs and dense panoptic representations separately, requiring an additional stage to associate panoptic predictions with graph entities. These limitations motivate a unified 3D representation that preserves geometry, semantic categories, and persistent

A. 3D Gaussian Segmentation 

3DGS-based segmentation has progressed from open-vocabulary semantics and instance grouping to panoptic understanding. Open-vocabulary methods embed vision–language features into 3D Gaussian primitives. LangSplat [11] learns language-aligned Gaussian features, while OpenGaussian [12] and OVGaussian [13] extend this paradigm to point-level open-vocabulary segmentation. Mask-lifting methods transfer 2D masks and instance information into Gaussian representations. Gaussian Grouping [14] learns identity-aware Gaussian features for object grouping, while Unified-Lift [8] combines Gaussian- and object-level representations with association learning for 3D instance segmentation. More recently, PLGS [15] jointly learns semantic and instance attributes from multi-view supervision, and PanoSLAM [16] integrates panoptic Gaussian learning with sequential RGB-D mapping. Similarly, PanoGS [17] combines open-vocabulary semantics with instance segmentation, while PanopticSplatting [18] introduces query-guided cross-view label refinement for panoptic segmentation. Despite these advances, existing methods mainly focus on novel-view panoptic prediction, with feature optimization restricted to either the 2D or 3D domain. In contrast, PanoGraphGS jointly optimizes 2D and 3D features, enabling both panoptic segmentation and direct Gaussian-level decoding. 

B. Hierarchical 3D Scene Graphs

Gaussian-Graph [9] novelly constructs structured scene graphs directly from Gaussians. However, these approaches commonly rely on per-pixel RGB-D observations for geometry and primarily focus on object-level recognition. A. Overall 

As illustrated in Figure 2, we employ SAM3-generated [6] masks from posed RGB images as supervision, which may contain noisy labels and inconsistent instance IDs across frames. We first augment the Gaussians with semantic and instance features (Section III-B). We jointly optimize the appearance, semantic, and instance branches. The prototype-based semantic learning predicts semantic categories (Sec-tion III-C), while the association-based instance learning aligns view-local instance masks with persistent instance identities (Section III-D). The joint supervision strategy is described (Section III-E). During panoptic decoding, stuff predictions are obtained from the semantic branch, whereas object predictions combine semantic and instance. The re-sulting panoptic Gaussian representation supports novel-view 2D panoptic segmentation and direct Gaussian-level panoptic decoding. Finally, the semantic-aware hierarchi-cal scene graph construction module organizes the learned panoptic Gaussians into a floor–room–stuff–object hierarchy with containment and spatial relations (Section III-F).

The resulting instance objective Lins follows the same four-term formulation as the semantic objective.

Node attributes are grounded in the learned panoptic features and Gaussian geometry, with directed edges encoding hierarchical containment and spatial relations.

EXPERIMENTS We first compare PanoGraphGS on 3D scene graph con-struction and 2D panoramic segmentation, with qualitative visualizations provided for both, followed by ablation studies of its key components. 

A. Experimental Setup 

Datasets. We evaluate on two public datasets, Scan-Net++ [31] and Replica [32]. In addition, we release Nav-iGS , a real-world dataset comprising RGB and semantic scenes. NaviGS is acquired using two fisheye cameras and a handheld LiDAR device. LiDAR-assisted acquisition pro-vides accurate camera poses and a sparse point cloud for Gaussian initialization. Both scene collections provide 3DGS models, meshes, RGB, camera poses, and depth; semantic scenes additionally include scene graphs. To evaluate hi-erarchical scene graph construction, we select multi-room layouts from Replica and NaviGS that support evaluation of the floor-room-stuff-object hierarchy. 

Evaluation Metrics. Scene graph performance is evalu-ated by floor-, room-, and object-level accuracy. All com-pared methods use the same SAM3-generated segmentation masks as supervision. Since OP3DSG, BBQ, and Concept-Graphs do not support floor-room recognition, they are evaluated only at the object level. For KeySG, HOV-SG, and PanoGraphGS, floor, room, and object recognition are manually verified under a hierarchical criterion: a room is correct only when its floor and room identities and semantic category are correctly identified, while an object is correct only when its floor, room, and object identities are all correct. Panoptic segmentation is evaluated using mIoU for region overlap and mBIoU for object and structural boundaries. For instance-only methods such as Unified-Lift, these metrics are computed after per-image optimal instance matching without semantic categories. For panoptic methods, including PanopticRecon++ and PanoGraphGS, a match is correct only when both instance identity and semantic category are correctly predicted, yielding a stricter criterion. 

Implementation Details. Training and evaluation are per-formed on an RTX 5880 GPU using Python and PyTorch. Each scene is optimized for 30,000 iterations with Adam at a learning rate of 2.5 × 10 −3. The number of semantic prototypes is determined by the categories present in each scene, whereas the instance branch maintains K = 256 

prototypes, sufficient for all evaluated scenes. 

B. Comparative Evaluation 

3D scene graph evaluation. Table I compares PanoGraphGS with representative scene graph methods, while Fig 4 shows qualitative comparisons on multi-room scenes from Replica and NaviGS. All compared methods rely on per-pixel RGB-D observations, whereas PanoGraphGS constructs scene graphs without depth input or depth projection. PanoGraphGS achieves strong floor, room, and object recognition, with object-node accuracy exceeding existing methods by more than 50% and reaching 98.36% on NaviGS. Compared with HOV-SG [5], which also supports the floor-room-stuff-object hierarchy, PanoGraphGS achieves higher floor and room recognition accuracy, reducing cross-floor and cross-room association errors and improving object recognition. The 100% floor accuracy of HOV-SG on Replica does not demonstrate multi-floor reasoning, as the evaluated scenes contain no multi-floor layouts. These results highlight the effectiveness of our Semantic-Aware Floor and Room Reasoning module, which combines structural semantics with geometric cues rather than relying primarily on point-cloud density, distance thresholds, or watershed-based segmentation. C. Ablation Study 

We evaluate the effectiveness of the individual compo-nents of PanoGraphGS on the public Replica dataset, which contains multi-room layouts. The comprehensive results are reported in Table III. With the introduction of the semantic branch, EXP1 achieves a 2.11% improvement in object accu-racy over EXP0, demonstrating the effectiveness of jointly optimizing shared features across the 2D and 3D domains and enhancing semantic discrimination across views. EXP2 further validates the necessity of the instance branch, achiev-ing the largest performance improvement of 27.22% in object accuracy. Compared with EXP0, it substantially reduces false positives and missed detections caused by inconsis-tent annotations and supervision across frames, highlighting the importance of aligning view-local instance IDs with persistent identities to maintain consistent instance regions and boundaries across views. EXP4 further introduces the Confidence-weighted Mechanism on top of EXP3, improving object accuracy by 3.57%. These results demonstrate that the confidence-weighted mechanism suppresses noisy supervision and stabilizes labels near region boundaries at the semantic level, while filtering unreliable identity targets and reducing conflicts around instance bound-aries at the instance level. V. CONCLUSION In this study, we present PanoGraphGS, a unified frame-work integrating panoptic 3D Gaussian representation learn-ing with hierarchical 3D scene graph construction. Prototype-based semantic learning jointly optimizes shared 2D and 3D features to mitigate noisy semantic supervision, while association-based instance learning aligns view-local masks with persistent object identities. The learned panoptic Gaus-sian field supports novel-view 2D panoptic segmentation and direct Gaussian-level decoding, while Semantic-Aware hier-archical 3D scene graph construction enables a semantically and geometrically grounded floor-room-stuff-object hierar-chy. Extensive experiments show that PanoGraphGS achieves state-of-the-art performance among the evaluated methods in both 2D panoptic segmentation and 3D scene graph con-struction. We further release NaviGS with RGB and semantic scene data for panoramic scene understanding. PanoGraphGS nevertheless has several limitations. Open-plan spaces such as open kitchens lack explicit spatial boundaries, making room delineation challenging. Moreover, the current scene graph construction operates offline, and we will investigate online feed-forward scene graph construction for incremental scene understanding during continuous observations.
