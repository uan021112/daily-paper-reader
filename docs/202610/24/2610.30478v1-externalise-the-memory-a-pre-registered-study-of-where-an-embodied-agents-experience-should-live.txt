# Externalise the Memory: A Pre-Registered Study of Where an Embodied Agent’s Experience Should Live 

Cheng-Yin Tu Nikon Research Corporation of America 

chengyin.tu@nikon.com 

Abstract 

Should an embodied agent’s accumulated experience be baked into its policy weights, or kept external and retrieved at inference? We test this directly. A memory-augmented teacher (a VLM that retrieves lessons, with their episode images, from its own past attempts) pro-duces trajectories on a vision-conditioned single-arm reach task; from the same trajectories we distil LoRA student policies and evaluate them under matched protocols, including one that re-attaches the teacher’s frozen retrieval buffer to a fixed set of student weights — a clean parametric-vs-contextual-memory contrast on identical weights. Because the headline result is a null, we pre-registered the hypotheses, arms, tests, and analysis rules before training and be-fore any p-value. Distilling the memory-augmented behaviour into weights beat an action-only control by only +1 pp (n.s.); the registered test proves underpowered for its own minimum effect, so we withdraw — rather than refute — the memory-in-weights claim. By contrast, at-taching retrieval to a fixed set of student weights added +34 pp ( z = 5 .15 ), reaching the pooled memory-augmented teacher reference (49.3%); the pre-registered protocol contrast agrees ( +23 

pp, z = 3 .36 ); under a pre-registered auto-reset sensitivity count the two are +36 and +29 pp. An exploratory behavioural probe with pre-registered per-arm predictions is consistent with a mechanism: behavioural distillation transfers the marginal correction (a static prior every arm adopts) but not the conditional , situation-specific correction that prompt-retrieved memory supplies. The recipe that follows is to externalise the memory: in follow-up controls registered before they ran, the same frozen buffer lifts the base model with no adapter to 48% (sensitiv-ity 48%) and each of the other three adapters from 19–26% to 53–55% (sensitivity 17–21% to 50–55%), so the retrieval effect does not depend on the adapter, and the adapter adds nothing detectable once the buffer is attached. On a second, harder task in the same family, the retrieval advantage points the same direction but falls short of significance ( +6 pp, 95% CI [−4.5, +16 .4] ); exploratory diagnostics tie the attenuation to memory coverage and a distance-gated conversion threshold, suggesting the effect scales with the amount of retrievable success experience. 

# 1. Introduction 

Opening problem 

When an embodied agent accumulates experience, where should that experience live: folded into the policy’s parameters, or kept outside and retrieved when needed? The question is old and unresolved. The parametric view is seductive: a fluent agent, like a fluent human, should not have to look things up mid-task; skill that has been practised enough becomes automatic, and automaticity feels like something written into the substrate. The contextual view is pragmatic: retrieval systems that keep experience external and look it up have repeatedly matched or beaten parametric memorisation in 1arXiv:2610.30478v1 [cs.RO] 21 Oct 2026 language tasks. For embodied agents the question is structural: a retrieval context grows with every experience the agent accumulates, while its weights do not, so “bake it into the weights” is architecturally convenient as well as philosophically appealing. Whether it works is an empirical question that, to our knowledge, has not been asked for embodied skill under controlled conditions. 

Why this test bed answers it 

We ask it with a design that isolates the variable of interest. A memory-augmented teacher (a VLM that retrieves lessons, with their episode images, from its own past attempts) produces trajectories on a vision-conditioned single-arm reach task (an Isaac Lab bimanual rig with the right arm frozen). From those same trajectories we distil student policies whose training targets differ only in whether retrieved-lesson content is present, and we evaluate them under matched protocols, including one that re-attaches inference-time retrieval to a fixed set of student weights. The teacher’s experience buffer is thus routed to the student either as distillation targets (lesson gist in text) or as retrieval context at inference (lesson text with its episode image). The critical pair shares identical adapter weights and differs only in protocol: memory supplied by baking it into those weights during distillation, versus memory supplied through a retrieval context at inference. This makes “parametric vs contextual memory” a controlled contrast on one axis. 

Pre-registration as a stance 

Because the headline outcome is a null, and nulls are the most easily disbelieved result in machine learning, we pre-registered in two locked layers. The hypotheses, comparison arms, primary tests, and their directionality were registered before any adapter trained ; the final analysis rules (the pairing-integrity gate and its mechanical test-selection fallback) were locked after collection but before any p-value was computed . That locked rule kept the raw success counts, which were visible in the collection logs, out of the test-selection decision. The pre-registration lets a reader take the null as evidence rather than as a failure to find an effect we wanted. Every result below is labelled confirmatory or exploratory against that registered plan. 

Contributions 

1. A design criterion for where experience should live : marginal knowledge (the correction that holds on average across situations) transfers into weights, while conditional knowledge (the correction that depends on the current situation) belongs in context, because weights can only approximate a conditional function with a constant whereas context conditions on it for free. We name and operationalise this marginal/conditional distinction; the split we observe is consistent with it. (This is the transferable takeaway; the results below are consistent with it.) 

2. The withdrawal is scoped to this recipe (single-round SFT + composable-KTO), this task, this data scale, and this adapter capacity (LoRA rank-16). A no-training diagnostic (§4.4b) finds no detectable conditional trace at round 1; whether more data of the same kind would grow one remains open. 23. Summary 

The two headline results are one finding: distillation moves the average, and retrieval supplies the situation. The recipe is therefore to externalise the memory; with the buffer attached, the adapter adds nothing detectable (§4.2b). 

# 2. Related Work 

Parametric vs. retrieved knowledge in language models. A large line compares injecting knowledge into weights (fine-tuning) against keeping it external and retrieving it (RAG [Lewis et al., 2020]), repeatedly finding retrieval competitive or superior, though not uniformly: for LM-based world modelling fine-tuning wins most settings while retrieval is more data-efficient [Ashok et al., 2026], and a holistic comparison of memory substrates finds none dominant [Huang et al., 2026]; recent work on self-editing / self-adapting weights (e.g. SEAL [Zweiger et al., 2025]) pushes the parametric pole. Our contribution is the embodied, controlled analogue of this comparison: same weights, memory supplied two ways. 

Agent memory and experiential learning. Voyager [Wang et al., 2024], ExpeL [Zhao et al., 2024], and Agent-Workflow-Memory [Wang et al., 2025] accumulate and reuse experience as external, retrievable artifacts (skills, lessons, workflows); this is the external-memory pole our T4 result supports. A parallel line folds agent experience into weights instead: ASCENT [Lu and Gong, 2026] self-distils verified trajectories into the weights at test time, EDGE [Xie et al., 2026] treats retrieved experience as a training-time scaffold and distils its gains into the policy so that retrieval is not needed at inference, and UniMem [Xia et al., 2026] routes recurring patterns to weights and sparse ones to an episodic store. Closest to our question, Wu et al. [2026a] compare fine-tuning and prompt retrieval on the same experience items for GUI agents and find that the destination depends on the item: state facts and procedures do better in context, locators and lessons in the weights, predicted by the item’s recurrence and state-conditionality. Their state-conditionality rule parallels our marginal/conditional split; their lessons-in-weights result differs from ours, where retrieved lessons (with their episode images) helped only in context. We differ in isolating, under pre-registration and in an embodied teacher-to-student setting with identical weights in both arms, whether that experience can instead be consolidated into weights. 

Memory for VLAs and embodied policies. A fast-moving line gives embodied policies explicit memory. Some keep it external and retrieved : ExpReS-VLA [Syed et al., 2026] specialises VLAs 3through experience replay and retrieval, Retrieve-then-Steer [Zhao et al., 2026] keeps an online success memory for test-time adaptation, and STRAP [Memmel et al., 2025] / RAEA [Zhu et al., 2024] retrieve sub-trajectories or augment embodied agents; MemoryVLA [Shi et al., 2026] builds a perceptual-cognitive memory into the architecture, and RoboMME [Dai et al., 2026] benchmarks memory for generalist policies; for in-context retrieval in VLAs, no retrieval method dominates across settings [Liu et al., 2026], and test-time retrieval helps most where the frozen policy lacks the relevant action prior [Jeong and Yoon, 2026]. Others fold experience into weights : RECAP / π∗ 

> 0.6

[Physical Intelligence et al., 2025] learns from experience via advantage-conditioned post-training. Our contribution is orthogonal: rather than proposing a memory system, we hold the 

same retrieved memory fixed and ask which substrate carries it, under pre-registration. 

VLA post-training and RL. Recent vision-language-action work refines pretrained policies with RL and preference signals (e.g. SimpleVLA-RL [Li et al., 2025] and related); our students are distilled and KTO-refined VLAs, and our null speaks to what such post-training does and does not move into parameters. 

Lifelong / continual LoRA. CORAL [Luo et al., 2026], TAIL [Liu et al., 2024], and related study adapter-based continual adaptation; our marginal/conditional distinction offers a lens on 

what such adapters can absorb: a static prior readily, but not a conditional map (at this recipe and capacity). 

Reasoning distillation. Distilling Step-by-Step [Hsieh et al., 2023], Embodied-CoT [Zawalski et al., 2025], and fast/slow thinking-action work distil chain-of-thought into cheaper students; our rationale-in-target arms (A_ctrl_rat, B_main) are instances of this, and our finding that self-produced rationale at inference did not help ( +1 pp) while retrieved content did ( +23 pp) qualifies when rationale externalisation pays. 

Pre-registration in ML. We adopt pre-registration [Nosek et al., 2018, Bertinetto et al., 2021] as a methodological stance: registering hypotheses, tests, and analysis rules before seeing outcomes is what converts a null from a non-result into evidence. We do not claim primacy; we claim only that the study is explicitly pre-registered with a full, amendment-tracked chain, which is uncommon in embodied learning and is what licenses the null’s interpretation. Every design choice below is traceable to a pre-registration section or a numbered amendment; the full amendment chain is in Appendix A1. 

# 3. Methods 

3.1 Task and environment 

We use a vision-conditioned single-arm reach task (L0a-Left) in an Isaac Lab [Mittal et al., 2023] bimanual manipulation rig with the right arm held frozen throughout, a controlled setting in which only the left end-effector is actuated toward a target cube. An episode succeeds when the active end-effector comes within 0.05 m of the target; each episode runs up to a fixed round budget (and is subject to an inherited 24 s environment auto-reset, §3.5), where a round is one VLM reasoning step followed by an inverse-kinematics servo to the emitted target. All evaluation runs use –freeze_level (no curriculum auto-advance) so every arm sees the identical task distribution. 43.2 Teacher and memory pipeline 

The teacher is Gemma-4-31B-it [Gemma Team, 2024] (multimodal, 4-bit) served via llama.cpp, aug-mented with an image-anchored episodic memory: after each episode it writes a self-recap; at round 1 of a new episode it retrieves the top-K visually-and-state-similar past recaps (DINOv2 [Oquab et al., 2024] image embedding, state-aware ranking) and injects them as a PAST_LESSONS pream-ble: each retrieved episode’s lesson text and outcome, together with that episode’s initial camera image. 1 The memory-augmented teacher’s trajectories are the distillation source; its retrieval buffer, frozen at a fixed snapshot (SHA-pinned), is what the C_retrieval protocol later reuses at student inference. The recap prompt received an unformatted {target_color} instruction template (dis-closed in §4.5); the lessons themselves are unaffected. 

3.3 Students, arms, and the 2 ×2 factorial 

Students are LoRA [Hu et al., 2022] adapters (rank-16, α=32, dropout 0.05) on the same Gemma-4-31B-it base, targeting the language-model attention and MLP projections only ( self_attn. {q,k,v,o}_proj , mlp.{gate,up,down}_proj ); the vision tower is untouched. Each arm is trained in two stages on the same pinned trajectory pool: SFT (stage 4-A, 992 desirable progress-rounds, 1 epoch, lr 2e-4) followed by composable-KTO [Ethayarajh et al., 2024] refinement (stage 4-B, 992 desirable + 1799 undesirable rounds, 1 epoch, lr 5e-5, β=0.1, auto-balanced class weights) with the frozen SFT adapter as the KTO reference (the C.3-B composable dual-adapter scheme). All arms share this recipe and hyperparameter set; per-arm effective step counts are logged for audit. 2

The four training arms form a 2 ×2 factorial over two binary factors: retrieved-lesson gist in the target, and the teacher’s native thought in the target. All four terminate in the same canonical action lines, synthesised from parsed coordinates by a single synthesiser across arms, so output format is not a between-arm confound: no gist with gist

# 4. Results (Experiment 1) 

4.1 A pre-registered null: memory does not bake into weights (T1) 

Two timestamps matter and we keep them separate. The hypothesis T1 was registered before any training (pre-registration §2, filed 2026-07-06; refined by Amendments 9–10 which sharpened the arm semantics and reallocated α). The analysis rules (pairing gate, test-selection fallback, two-sided form) were locked after collection but before any p-value was computed (Amendment 14). The raw success counts are visible in the collect logs; A14 froze only how they would be tested, and the hypothesis predates it. T1: a student distilled from memory-augmented-teacher trajectories with retrieved-lesson gist in its target ( B_main ) would exceed a student distilled from the same trajectories with action-only targets ( A_action_only ), evaluated with zero inference-time retrieval. The pre-registered rejection region was ∆ SR ≥ +10 pp and statistically significant (two-sided, α=0.020), with an explicit falsification clause. This contrast is confirmatory. B_main scored 26/100 and A_action_only 25/100, with no de-tectable effect: +1 pp (z=0.16, p=0.87, two-sided; Newcombe 95% CI [ −11.0, +13.0]; McNemar sensitivity p=1.0, agreeing). Auto-reset sensitivity (§3.5): 19 vs 21, −2 pp (z= −0.35, p=0.72), same verdict. We are deliberate about what this licenses. The registered minimum effect (+10 pp) lies inside 

8the confidence interval, and a post-hoc minimum-detectable-effect calculation is unforgiving: at n=100 per arm with SR ≈0.25, significance at the registered two-sided α=0.020 requires ∆ ≥ 14.2 pp, so an observed +10 pp difference could not reach significance, and the design has only about one-in-four power for its own registered +10 pp effect. This is a flaw in our registered design, and we disclose it. Accordingly, per the registered clause we withdraw the memory-in-weights claim (we stop asserting it), but we do not assert the strong null at the success-rate level , which would read absence of evidence as evidence of absence. The claim that the conditional 

structure specifically fails to transfer does not rest on this underpowered SR test; it is carried by the R1 mechanism probe (§4.3) and, at round 1, by the residual diagnostic (§4.4b), whose round-1 null is not subject to the SR power problem (with its own |r| < 0.20 caveat; later rounds are confounded, §4.4b). Scope: this null concerns this distillation recipe , namely single-round SFT + composable-KTO on the L0a-Left reach task, at this data scale and adapter capacity (LoRA rank-16). §4.4b and §4.5 sharpen the data- and capacity-scope respectively. It does not claim that baking-in is impossible. Stronger consolidation (multi-round, replay, surprise-gated writing) is untested and named as future work (§6). 

4.2 The reversal: retrieval on fixed weights nearly triples success 

Two contrasts speak to bake-in versus retrieval (Figure 1); we report both with their exact adapter relationships. 

The identical-weights contrast (exploratory, decisive). The genuine same-weights com-parison is C_retrieval vs A_ctrl_rat : C_retrieval is A_ctrl_rat ’s adapter, run with an inference-time frozen-buffer retrieval preamble; A_ctrl_rat is the same adapter with none. On fixed student weights, attaching retrieval moved success from 15/100 to 49/100 (auto-reset sensitivity 12 to 48, +36 pp, z=5.56), a difference of +34 pp (z=5.15, p ≈2.6 ×10 −7; Newcombe 95% CI [+21, +45]) . This was not pre-registered as a primary test, so we mark it exploratory. At p ≈3×10 −7 it survives any multiplicity correction; exploratory here means “not registered”, not “fragile”. 

The registered protocol contrast (confirmatory). The pre-registered T4 is C_retrieval vs 

B_main , a protocol contrast in which each arm carries its own adapter (C_retrieval = A_ctrl_rat’s weights + retrieval; B_main = the gist+thought-baked weights, no retrieval). The confirmatory result is 49/100 vs 26/100, a difference of +23 pp (z=3.36, p=7.8 ×10 −4; McNemar p=1.0 ×10 −3,agreeing), significant at the pre-registered α=0.010 (auto-reset sensitivity 48 vs 19, +29 pp, z=4.35). This contrast varies both adapter and protocol, so it under-states the pure retrieval effect the identical-weights contrast isolates. In one line: on fixed student weights, attaching retrieval added +34 pp (exploratory, z=5.15); the registered consolidation-vs-retrieval protocol contrast was +23 pp (confirmatory, z=3.36). Both point the same way: memory supplied through context at inference vastly outperforms the same memory routed through distillation into weights. The pre-registration §4 had anticipated a small 

C_retrieval −B_main gap (“bake-in replaces retrieval”); the interpretation inverts, while the test itself is unchanged.

The significance threshold for T4 (α=0.010) was set in Amendment 1 (restated in Amendment 11), also before collection. A14 restated the two-sided form; it did not introduce it. At matched memory conditions the student tracks the teacher on both rungs; what fails is specifically the middle step, consolidating the memory advantage into weights . A student carrying a frozen retrieval buffer reaches the memory-teacher’s own rung (49% vs 49.3%; sensitivity 48% vs 47.5%), whereas routing that same memory through distillation into weights lands it back on the no-memory rung. The competence half of the recipe (“distil the competence”) does not survive the Amendment 15 controls (§4.2b): with the buffer attached, the base model with no adapter does as well (48 vs 49 of 100; sensitivity 48 vs 48).

4.4b Is the null just too little data? A no-training diagnostic

The concern is well-founded. The marginal/conditional asymmetry has a sample-complexity asymmetry built in, and this is arguably the cause of our headline split rather than a threat to it. 4.5 Limitations 

• Rationale-fabrication is a measurement gap, not a null. The D11 collect did not persist raw VLM text (the constrained-decode path stored only parsed coordinates), so per-arm rationale-fabrication rate and self-produced-gist content are not computable from these runs. We do not substitute a proxy. The replay schema now stores reset-time pose + seed; paper 2’s re-run adds raw-response logging. • Pairing gate literal failure. The confirmatory analysis used the pre-registered mechanical fallback (two-proportion z) because the pairing-integrity gate failed its literal check: replay does not persist pre-action cube pose and trajectory[0] is already one servo-step in. A frozen-arm diagnostic (seed identical 100/100, frozen right-arm identical 100/100, active left-arm 1/100) shows the pairing is physically real; the reported McNemar sensitivity (agreeing with z on all contrasts) recovers the design’s power. Per the pre-registration, the z verdict governs. • Adapter capacity is a sibling explanation to data quantity. A rank-16 LoRA may lack the capacity to represent a conditional function from situation to correction even with unlimited data. This limitation is parallel to, not subsumed by, the data-scaling diagnostic in §4.4b (that probe holds capacity fixed and varies data; this holds data fixed and varies capacity). We do not run a rank sweep here. Together these sharpen the scope of the T1 null to: this recipe, at this data scale and this adapter capacity .16 • No inference-cost advantage (measured; descriptive, non-inferential). Amendment 1 §3 defined the per-arm training target (scored arm only); Amendment 3 matches the

The evaluation was initially wired to parse, step and gate on both arms (the level’s active-arm resolver returned None for L2_dual_push , selecting the bimanual path), the joint definition that produced SR = 1/100 and motivated the per-arm re-score. Asking a single-arm model for both arms measures format adaptation, not task competence (an out-of-distribution probe). The per-arm eval resolves this: 1. The prompt asks only for the scored arm’s slot, matching the training target in structure (position only; no RPY or non-scored-arm line). 20 2. Non-scored arm frozen at its initial pose by the existing V4 active_arm hold-in-place mask. 3. Success gated on the scored arm only (∥EE_scored − target_scored ∥ < 0.05 m), reusing the L0a single-arm success branch.

# 6. Discussion 

6.1 What the results say to a system builder: externalise the memory 

The two headline results are one finding seen from two sides. Baking the memory-augmented teacher’s behaviour into student weights bought +1 pp over an action-only control (T1, null; sensi-tivity −2 pp); attaching an inference-time retrieval context to a fixed set of student weights bought +34 pp (identical-weights contrast, z=5.15; the registered protocol contrast agrees, +23 pp, z=3.36; sensitivity +36 / +29 pp) and reached the pooled memory-teacher reference (49% vs 49.3%; sensi-tivity 48% vs 47.5%). Competence tracks the teacher at each memory rung (§4.2); what distillation fails to move into weights is specifically the memory advantage. We resist reading this as “distillation fails”. The exploratory mechanism probe (§4.3) suggests 

why the split is principled, and turns it into a design criterion. Memory’s operational value here is a 

conditional correction: a different adjustment for each episode’s situation (the C_retrieval R1 ∆Xsignature: mean pulled toward zero ( −7.1), σ=14.4, per-episode variable). Baking a conditional function into a fixed weight delta forces a single static approximation of it; the four distilled arms all collapsed onto one ≈ − 16.7 (grid-unit) prior regardless of the episode in front of them. A context channel, by contrast, is a natural conditioning pathway: it can present a different retrieved context (a past episode’s lesson and image) per situation at inference with no parameter change. The answer to “where should this knowledge live” therefore depends on the knowledge’s own structure. Marginal knowledge (the average correction that holds across situations) transfers into weights; conditional knowledge (the correction that depends on the situ-ation) belongs in context, because weights approximate it with a constant and context conditions on it for free. This is the criterion D11 was ultimately built to test, and it is the transferable claim we carry out of a single-recipe study across two tasks (the L0a reach and the harder L2 position-goal reach in a 6-DoF control space, §5.9.3). The claim is not that retrieval beats baking-in as a general law; it is a decomposition of which component of an experience each substrate can hold. What the recipe does not buy at our scale is speed. Teacher and student share the 31B base and both generate a rationale before the action, so per-step cost is of the same order for all three protocols, and decode time dominates each step (§4.5). A latency advantage requires a smaller student or a learned action decoder that emits actions without generating text. The decomposition says what such a decoder should hold: the marginal prior can move into it, while the memory stays in context. 

6.2 Two poles, a bridge, and a loop 

The literature splits into two substrate poles; our contribution is the bridge between them, and the open frontier is the loop that closes over both. 

Pole 1: external memory (we supply supporting evidence). The retrieval-augmented pole, in which competence is distilled and experience is kept external and looked up, is the world-view our results support: on fixed student weights, attaching retrieval added +34 pp (sensitivity +36) (identical-weights contrast, z=5.15; the registered protocol contrast agrees at +23 pp). Embodied retrieval-augmented policies already exist: behaviour/skill retrieval and episodic-memory agents (Voyager [Wang et al., 2024], ExpeL [Zhao et al., 2024], AWM [Wang et al., 2025]; ASPIRE [Lu 25 et al., 2026]) show external-memory gains, so we do not claim primacy for the idea. What we add is a 

pre-registered embodied comparison that isolates substrate: the same retrieved memory routed into weights vs into context, with the exploratory mechanism probe suggesting why the routing matters (marginal vs conditional). ASPIRE’s code-as-reusable-skill and our lesson-and-image retrieval are two instantiations of external memory; our data support the pole, not any single implementation. 

Pole 2: parametric memory (we bound our null and leave the question open). Our T1 null is a statement about a behavioural distillation recipe (single-round SFT + composable-KTO, LoRA), not about parametric memory in general. Titans-style architectural writing [Behrouz et al., 2025] (surprise-gated updates that write only the unexpected, with decay) and parametric self-evolution (TMEM [Ren et al., 2026]) are mechanisms our recipe lacks: they consolidate conditionally 

(what to write depends on the situation’s surprise), which is exactly the component §4.3 shows our recipe drops. MemHarness [Wu et al., 2026b] makes the same point from the other side, treating memory as reconstructed rather than replayed. Whether such a mechanism can bake the conditional structure that flat distillation could not is untested here and is the most direct architectural follow-up our null points to. The case for it is strengthened because the data route is not closed either: our no-training diagnostic excludes a conditional trace only at round 1, while later rounds show a positive but confounded signal (§4.4b). A conditional component may be present but under-consolidated by a flat recipe, which is the regime surprise-gated (Titans) and self-evolving (TMEM) writers target. 

Provenance caveat (an open question). C_retrieval is fed the teacher’s frozen experience buffer, not the student’s own. For the question D11 asks (the same memory, routed to weights vs context), buffer source is a controlled constant (B_main was distilled from trajectories the teacher produced while retrieving from the frozen buffer, and C_retrieval retrieves from that same buffer), so the buffer is held fixed across the substrate contrast. What reaches the student differs in form: B_main’s target carries the lesson gist as text, whereas C_retrieval’s context carries each retrieved lesson with its episode image. What we do not test is whether a student retrieving its 

own self-generated buffer would win by the same margin; self-produced recap quality is unknown and connects to the epiphenomenal self-gist finding (§4.3). We flag this as future work rather than a resolved claim: externalisation as the mechanism and teacher memory quality can be separated only by a student-own-buffer arm, which we have not run. 

The bridge: which component of an experience each substrate carries. The two poles are usually argued as rival systems; our data turn the choice into a decomposition. Marginal struc-ture (the average correction) consolidates into weights; conditional structure (the situation-specific correction) is what retrieval supplies and distillation drops (§4.3). This is substrate-agnostic: it pre-dicts what a parametric mechanism would have to capture (the conditional component) to match retrieval, which is what the surprise-gated and self-evolving writers above target. The criterion connects the two poles rather than choosing one. More speculatively, if the criterion holds, it pre-dicts the apparently opposite finding of Wu et al. [2026a], where lessons did better in the weights: lessons that state situation-independent rules are marginal knowledge and should favour the weights, whereas ours are per-situation corrections, retrieved together with their episode images, and favoured context. 

The loop: closing experience back into the policy. The frontier is agents that keep improving by folding their own rollouts back in, as in closed-loop iterative fine-tuning (CLIFT [Chen et al., 2026]) and self-evolving parametric memory (TMEM). Our result bears on that loop: it suggests the loop’s write step (consolidation) loses the conditional component unless built to preserve it, so a naive rollout-then-distil loop would be expected to plateau at the marginal. A follow-up paper (J-Space / J-lens, in preparation) develops the instrument for the mechanistic half: our exploratory R1 μ-branch result (§4.3) suggests behaviourally that the correction’s carrier is the 26 action distribution, not the memory content ( B_main still emits PAST_LESSONS text yet it bought +1 pp, suggesting it is epiphenomenal). Ablating B_main ’s self-produced gist (prediction: action unchanged), and ablating the text versus the image component of C_retrieval ’s retrieved context (which the present design cannot separate), would give a mechanistic account of the 23 pp gap and identify which component carries the conditional correction. This is the target of the follow-up paper and is not a result claimed here. 

6.3 Why this does not extend to contact-rich manipulation (a bounded feasibility probe) 

Before extending the memory result to contact-rich tasks we ran a bounded feasibility gate, porting the identical prompted-VLM-teacher interface to LIBERO [Liu et al., 2023] and asking whether it clears the task before committing a full study. It did not, and the negative result is precise. Across grasping (three objects) and non-grasping (push, knob-twist) tasks the teacher’s spatial reasoning stayed intact (round-0 targets matched true object positions to within millimetres and phase identification was correct throughout), yet success was 0 in every task. A staged intervention (adding oracle-sourced subgoal vectors, then a hover-descend-grasp primitive, then raising camera resolution from 128 to 256 px; details and per-stage success in the supplementary feasibility branch) cleared every candidate cause above the point of contact while success remained pinned at zero, which points to two separable boundaries (exploratory). The first is a contact-precision ceiling :on free-object contact (grasp and push alike) the open-loop position servo drives the end-effector into the object and the rigid-body contact impulse ejects it, so the same wall that blocks grasping also blocks pushing. The second is a primitive-expressivity gap : the “turn on the stove” success predicate is satisfied by rotating a hinged knob past ≈0.5 rad, a degree of freedom our macro vocabulary (reach / grasp / release) does not express, so a position servo to the knob applies zero moment about the hinge and cannot actuate it even with perfect targeting. Both boundaries are properties of this interface paradigm (integer-coordinate subgoals over an OSC position servo with a fixed macro-primitive set), not of the prompted-VLM teacher , whose reasoning layer was sound in every failure; the walls sit at the control-stack and primitive-vocabulary layers, the layers this single-manipulator study does not claim to solve. This bounds the contribution and indicates the next step: closed-loop contact control and an expanded primitive vocabulary are the two extensions a richer task suite would require. An expert-iteration loop (the follow-up paper) would need the same enrichment to generate contact-rich experience worth externalising. 

6.4 The open problem: consolidating a conditional function, not a marginal prior 

The broadest reading connects back to the study’s motivating question: whether the knowledge a system reads can be folded, through embodiment, into its parameters. This is the systems-consolidation question in machine form, the slow transfer of a fast episodic store into structured, automatic competence that complementary-learning-systems theory describes [McClelland et al., 1995, Kumaran et al., 2016]. Human skill automation is the existence proof that it can: a fluent pianist’s playing is automatic yet still conditional , responding note-by-note to what is in front of them. Automation preserves the conditional structure; it does not collapse the skill to its average. Our distillation product kept only the average. That reframes the open problem. T4 appears to settle “baked-in vs retrieved”, but it settles only the question of substrate under one consolidation recipe. The problem underneath is how to consolidate a conditional function rather than a marginal prior . That single question explains all three of our results at once: T1 failed because flat distillation consolidates the marginal; 27 T4 succeeded because context still carries the conditional; and the paths beyond (surprise-gated writing, per-round distillation targets that supervise the situation-specific correction rather than its average, and workspace-readout probes that check whether a consolidated correction is actually used) are all attempts on that same problem. The null on substrate thus reformulates “where should memory live” as “what would it take to consolidate memory’s conditional structure at all”, a question embodied continual learning has yet to answer. 

6.5 The cross-task result (Experiment 2, L2) 

The second experiment (§5) tests whether the identical-weights retrieval effect crosses to a harder task. It connects to the substrate account in four ways, each tied to the pre-registered analysis: • The marginal/conditional split on a second task (direction-consistent, post hoc). 

L2 is consistent with the mechanism : distillation transfers a magnitude-deficient marginal prior (R1 −4.8), and retrieval on identical weights restores the teacher’s conditional correction (−17.2 ≈ − 17.1; post-hoc, as the registered σ test was null, §5.9.3b). The end-task effect stays below the MDE (+6 pp, n.s.). The substrate account points the same way in mechanism and direction, which is not a replication; the effect size does not reach significance on this harder task with its thinner buffer. • Marginal transfer is dose-dependent (exploratory). L2’s ≈72%-short marginal (§5.9.3b) adds a dimension to the marginal/ conditional frame: even the static prior has a data floor below which it is under-learned. It is cheap but not free. • The memory success-floor / minimum-viable-competence law. L2 at 1% joint SR sits near the floor: memory conditions the correction but does not manufacture the multi-step competence to execute it from far configurations (§5.9.3c). You cannot externalise a competence the teacher does not have. Here the statement sharpens to: retrieval sets the initial direction; whether that pays off depends on how far the corrected trajectory still has to travel. We state this as an exploratory hypothesis for a follow-up study, unifying observations across the teacher, the buffer and the student; it is not a result of this paper. • A link between the two experiments (exploratory). This matches D11’s recovery-timing null: both datasets suggest retrieval’s value is front-loaded : it sets the initial direction (L2’s start-distance gate is its range limit; D11’s monotonic-from-R1 convergence is its timing signature). Note the contact-rich boundary (§6.3) and this cross-task result are independent: §6.3 bounds where the interface can go, §6.5 reports how the memory finding travels within the reach family.
