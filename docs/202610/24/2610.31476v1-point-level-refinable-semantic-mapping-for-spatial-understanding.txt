# Point-Level Refinable Semantic Mapping for Spatial Understanding 

Taimeng Fu 1∗, Yi Du 1∗, Zitong Zhan 1, Qiwei Du 1, Shaoshu Su 1, Zhipeng Zhao 1, and Chen Wang 1

Abstract — Open-vocabulary 3D semantic maps have emerged as a key spatial memory representation for long-horizon robot autonomy, enabling robots to reason about objects, their spatial relationships, and past observations across time. However, existing object-centric semantic maps are primarily designed for static environments and rely on an append-only point integration strategy, where newly observed points are accu-mulated but previously integrated points are rarely reevalu-ated. Consequently, perception errors accumulate over time, and outdated points persist after objects move or disappear. Although recent dynamic mapping methods update object-level representations in changing scenes, they do not explicitly revise noisy or obsolete points within each object. We propose an online refinable semantic mapping framework that continuously refines object representations through probabilistic point-level confidence updating. Each object point maintains a confidence score that is updated online using multi-view temporal evi-dence: consistent observations reinforce reliable points, while inconsistent segmentation masks, depth measurements, and visibility cues suppress spurious and outdated points. Combined with object tracking and re-identification to preserve instance identities under motion and relocation, our framework enables object-centric semantic maps to be continuously refined rather than monotonically accumulated. Experiments demonstrate improved mapping accuracy over the previous method by 3.46% on Replica and 2.55% on ScanNet, show robustness in dynamic environments and under perception noise, and provide an effective spatial memory for object navigation and embodied question-answering with success rates of 82.4% and 76.7%. 

I. I NTRODUCTION 

Open-vocabulary 3D semantic maps have emerged as a key spatial memory representation for robot autonomy [1] by grounding open-ended semantic concepts in 3D space [2]. They enable robots to localize task-relevant objects, reason about object relationships, and maintain persistent spatial context for embodied tasks, e.g., vision-language navigation [3] and mobile manipulation [4]. Recent open-vocabulary mapping systems [5], [6], [7] construct object-centric 3D semantic maps by integrating RGB-D observations with open-vocabulary perception mod-els. However, real-world robotic deployment requires long-term operation in dynamic environments, where objects are frequently moved, removed, or rearranged. Existing methods are largely designed for static scenes and rely on an append-only point integration strategy: newly observed points are continuously added to object instances, while previously integrated points are rarely revisited or revised. As a result, local artifacts introduced by perception errors or stale observations can remain embedded in the object representation, degrading long-term mapping quality. To address both dynamic environments and noisy percep-tion, we propose an online refinable open-vocabulary se-mantic mapping framework that continuously refines object-centric maps over time. The key idea is to maintain a probabilistic confidence estimate for every object point, rather than treating integrated points as permanent entries. Each confidence score is updated online using multi-view temporal evidence: points consistently supported by new observations are reinforced, while those inconsistent with segmentation masks, depth measurements, or visibility cues are progressively down-weighted and eventually removed. To evaluate its effectiveness as an online spatial memory for autonomous robots, we integrate the proposed semantic mapping framework into a vision-language navigation (VLN) framework [11] and evaluate it on object navigation and em-bodied question answering tasks in real-world environments. A. Open-Vocabulary Semantic Mapping 

Semantic mapping augments geometric reconstruction with object labels, instance structure, and region-level se-mantics for navigation and manipulation [2]. Earlier metric-semantic systems [12] rely on closed-set detectors [13], while recent vision-language foundation models [14], [15] enable open-vocabulary maps that can be queried with free-form language. Building on these advances, recent works integrate open-vocabulary semantic maps with large language models (LLMs) for embodied reasoning and long-horizon planning [5], [6], [7]. These approaches demonstrate the value of structured semantic memory for language-guided robotic rea-soning. However, they mainly focus on semantic abstraction and typically assume that fused object points remain valid once inserted. As a result, erroneous or old points introduced by noisy perception or object motion are difficult to revise through later observations. 

B. Dynamic Semantic Map Updating 

Real robotic environments are dynamic, where task-relevant objects may be moved, removed, or re-observed at different locations. Dynamic semantic mapping systems reason about environmental changes using geometric con-sistency and object relations. Khronos [8] uses ray-casting to verify geometric changes, but its verification is primarily object-level and does not explicitly refine erroneous points within an otherwise valid instance or suppress false semantic instances using semantic inconsistency. OpenIN [9] and DualMap [10] maintain movable objects through relations to relatively stable anchors. Such relation-based updating depends on the existence of a suitable anchor and suffi-ciently complete re-observation of that anchor. In contrast, our method maintains each instance independently without requiring predefined object-to-anchor relations. III. M ETHOD

D. Dynamic Object Tracking and Re-Identification 

Downstream tasks such as VLN and manipulation require stable instance identities even after objects move. We there-fore use 2D tracking for in-view object motion and feature-based re-identification for out-of-view object relocation to maintain consistent instance IDs. 

1) Tracking Moving Objects in the Camera View: For real-time efficiency, we use BoT-SORT [20], a lightweight 2D tracker, to associate detections across frames. When a new detection is first observed, it is matched to an existing instance or a new one is created according to Section III-B.3. Subsequent tracked detections with the same tracking ID are directly fused into this instance. This prevents a moving object from being repeatedly initialized as new instances and preserves its instance ID during the motion. Trailing points left at previous locations are removed by the confidence update mechanism (Section III-B.4) within the next 1-2 frames, as they contradict later depth observations. 

2) Re-Identification of Relocated Objects: When an object relocates outside the camera’s field of view, its motion cannot be directly tracked. E. Integration with VLN framework 

We integrate the proposed semantic mapping method into VL-Nav [11] as a compact symbolic-spatial memory for LLM-based robotic agents. In this framework, Qwen2.5-VL 7B [21] serves as the central coordinator, interpreting language instructions, querying the semantic map for object layouts, and invoking skills such as object navigation and embodied question answering (EQA). The semantic map is constructed online during robot operation to maintain up-to-date scene information. It supports fuzzy semantic queries by computing CLIP similarity between query terms generated by the LLM and stored instance features. The query returns metadata of the top-K matched objects in JSON format, which the LLM uses to plan skill execution. For object navigation, if the target exists in the map, the navigation skill invokes a planner to generate a path and navigate to it; otherwise, the robot performs frontier-based exploration to collect more observations. For EQA, the LLM reasons over the exploration progress and conversation history to decide whether sufficient information has been gathered to answer the question or whether further exploration is needed. C. Computational Efficiency 

Table II compares memory usage and runtime on the same hardware platform. Our method uses less CPU memory because incremental refinement does not require storing previous observation buffers, and less GPU memory by back-projecting only valid mask regions rather than expanding full-resolution depth tensors. Despite additional visibility reasoning and confidence updates, it achieves lower average time-per-frame (TPF) through implementation optimizations such as batched object processing, parallel feature extraction, and pipelined execution of perception and mapping.

H. Real-World Evaluation on VLN Tasks 

We evaluate the proposed semantic map as online spa-tial memory for real-world VLN tasks. Experiments are conducted on a Boston Dynamics Spot robot with RGB-D cameras and LiDAR-based localization. 

1) Benefit of Map Refinement: We first evaluate whether map refinement benefits downstream tasks when the envi-ronment changes. An initial semantic map is built from a teleoperated sequence, after which the objects are rearranged. The robot then autonomously executes 7 sequential object navigation tasks using the original map as initialization. We compare the full system with an ablation that disables map refinement. Both systems complete all 7 tasks, but the full system travels only 76.41 m compared with 103.22 m with-out map refinement. Continuous map updates remove stale objects during execution, preventing subsequent tasks from repeatedly selecting and revisiting obsolete object locations. 

2) Broader VLN Evaluation: We further evaluate the complete system in three unseen environments, Hallway ,

Office , and Outdoor . We consider both object navigation and embodied question answering (EQA). For object navigation, the LLM queries the map for matching object instances and their 3D locations, while continuing exploration if the target has not yet been observed. For EQA, the LLM retrieves relevant object instances, semantic labels, locations, and spatial context, and explores further when the current map is insufficient to answer the question. Representative examples are shown in Fig. 9. As reported in Table VI, the robot achieves an average success rate of 82.4% for object navi-gation and 76.7% for EQA, demonstrating that the proposed map can serve as effective online spatial memory for both goal-directed navigation and semantic-spatial reasoning in previously unseen environments. V. C ONCLUSION 

We presented a dynamic open-vocabulary semantic map-ping framework that turns object-centric maps from append-only accumulators into point-level probabilistic representa-tions. By assigning each object point a log-odds confidence score and updating it with multi-view observation evidence, our method reinforces stable points while suppressing per-ception artifacts and removing old points caused by object motion. It also preserves moved-object identities through tracking and re-identification. Experiments on Replica, Scan-Net, and dynamic-object scenarios show improved semantic mapping accuracy, robustness to perception errors, and effec-tive handling of moved or removed objects.
