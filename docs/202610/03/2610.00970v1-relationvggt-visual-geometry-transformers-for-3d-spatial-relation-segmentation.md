## 摘要
近年来，3D重建的进展已从逐场景优化转向前馈推理，语义场景理解也随之发展——然而现有方法仍局限于以对象为中心的感知，忽略了对象之间的空间关系。我们将3D空间关系分割形式化为一个前馈、无需位姿的多视角设定：给定视觉指定的主体和关系文本查询，模型在跨视角中分割目标，且不接收其类别名称。为此，我们提出RelationVGGT，一种新颖的前馈框架，它将来自视觉基础模型的语义特征与来自3D几何基础模型的几何感知表示相结合，并利用关系Transformer进行以主体为条件、跨视角的关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们提供了一个基于ScanNet++、利用VLM和LLM构建的全自动标注流水线，从而能够为这一新任务生成可扩展的训练数据。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与整体含义

- **研究动机**：3D 重建已从逐场景优化（NeRF、3DGS）转向前馈推理（DUSt3R、VGGT），语义场景理解也沿同一轨迹发展（LangSplat、OpenGS、PanSt3R、Uni3R）。但现有方法几乎都停留在**以物体为中心**的感知层面，将场景视为孤立实体的集合，忽略了物体之间的空间关系。
- **问题本质**：理解环境不仅需要识别物体，还要理解物体之间的空间排布（如"显示器放在桌上"、"杯子在键盘旁边"）。这种关系推理是空间问答、具身智能体等高层任务的基础能力。
- **任务形式化**：论文提出 **3D 空间关系分割（3D spatial relation segmentation）**，设定为前馈、无需位姿的多视角场景：
  - 输入：多视角图像 + 参考视图中的主体掩码（视觉指定 subject）+ 关系文本查询（如 "resting on"）；
  - 输出：在所有目标视图中一致地分割满足该空间关系的目标物体；
  - 关键约束：**不接收目标物体的类别名称**，且无需逐场景优化或已知相机位姿。
- **与已有工作的区别**：
  - RelationField 在辐射场上学习关系，但依赖场景特定优化与标定位姿，难以泛化；
  - 视频-语言模型可做多视角关系推理，但缺乏 3D 场景表示，在大视角变化下难以维持物体对应；
  - 3D 指代分割（如 ReferSplat）用文本指代目标，而本文用视觉掩码指定主体、仅以文本给出关系，目标身份须从"主体–关系"对中推断。

## 2. 方法论

### 2.1 核心思想

- 将先前工作在**体素 3D 空间中的关系搜索**（RelationField 的 gθ(x,z)→r 需在场景体积中逐点评估）重新表述为**目标视图图像网格上的逐像素关系预测**，以参考视图主体为条件，从而消除体积搜索与场景特定 3D 优化的需求。
- 定义逐视图关系特征图：R_t = {r_t(u) | u ∈ I_t}，其中 r_t(u) ∈ R^D 编码目标视图位置 u 与参考主体之间的空间关系；将其对齐到语言嵌入空间后，即可通过特征–文本相似度实现开放词汇关系查询。
- 学习目标函数：fθ(I_r, M^s, I_tgt, u) → R^t。

### 2.2 架构流程

1. **特征提取**：对每张图像 I_n，分别用 DINOv2 提取语义特征 E^D_n、用 Pi3 编码器（取其预测头之前的 token）提取几何感知特征 E^P_n；两者在通道维拼接后经输入混合器 M_θ（线性投影 + 带 RoPE 位置编码的若干 Transformer 块）融合为联合表示 F_n ∈ R^{P×d_f}。
2. **主体表示**：不将主体压缩为单一池化向量，而是保留参考视图全部 patch token，并用下采样到 patch 网格的主体掩码 M̄^s 做逐元素相乘，得到 F^s_r = M̄^s ⊙ F_r，从而保留主体的空间布局与细粒度语义。
3. **关系 Transformer**：将各目标视图 token 堆叠为序列 Z^0，交替执行
   - 主体条件交叉注意力：Z̄^ℓ = CrossAttn_ℓ(Z^ℓ, F^s_r)；
   - 多视图全局自注意力：Z^{ℓ+1} = SelfAttn_ℓ(Z̄^ℓ)；
   使表示同时具备主体条件性与多视图感知性。
4. **解码**：经 L 层后，将 token 重塑回各视图 patch 网格，用 DPT 头（mask decoder）上采样为像素对齐的关系特征图 R_t = Dec(Z^L_t)，并实现与语言嵌入空间的对齐。
5. **3D 几何**：用 Pi3 点解码器为每个目标视图预测点图与置信度图，由于 R_t 像素对齐，每个关系特征可关联对应 3D 点，形成置信度感知的跨视图 3D 关系表示。

### 2.3 训练与推理

- **多查询监督**：同一空间关系常有多种等价表述（"standing on"/"on"/"supported by"）。论文将同一目标掩码配以多个兼容关系查询，每个查询独立用 sigmoid focal loss 监督，避免单标签分类惩罚语义合理的替代表达。
- **总损失**：L_mask = w_focal · L_multi-qfocal + w_dice · L_dice，其中 focal 参数 α=0.75、γ=1.5。
- **推理**：逐像素计算相关性 logit z_t(u;q) = r_t(u)^T e(q)，经 sigmoid 得分数 S_t(u;q)，以固定阈值 τ=0.3 二值化得掩码。无需对正负文本嵌入做 softmax 归一化。

### 2.4 自动标注流水线

- 在 ScanNet++ 上构建：以 3D 实例为节点初始化场景图，将实例掩码投影到已定位 RGB 帧，用 Set-of-Mark（SoM）提示查询 VLM 得到逐帧关系提议。
- **多视图一致性过滤**：对每个物体对统计预测某关系的帧数，少于 K=3 帧则拒绝。
- **几何过滤**：利用 3D 包围盒与实例质心，剔除包围盒不重叠且质心距离超阈值的物理上不合理关系（如远处物体间的接触/支撑）。
- **LLM 改写**：VLM 倾向保守、词汇单一，故用 LLM 将验证过的三元组（主体, 关系, 目标）改写为多样表达（如 TV–hanging on–wall → "mounted on"/"installed on"）。

## 6. 主要结论与发现

- 本方法在三个 benchmark 上取得最高平均 mIoU 0.382、mAcc 0.549，显著优于最强基线 RelationField（0.303 / 0.480）；在 Replica（0.446 mIoU）与 ScanNet++（0.445 mIoU）上提升明显，在密集杂乱的 LERF 上与 RelationField 相当（0.254 vs 0.276），但优于 RelationField†（0.230）。
- **跨相机基线稳定性**：随相机基线增大，UniPixel 等视频模型性能明显退化，而本方法在各基线分组（Small/Medium/Large）均保持稳定（mIoU 0.417/0.404/0.366），归因于 3D 基础模型骨干提供的多视图感知特征而非帧间对应。
- **无需显式 3D 表示**：尽管未使用辐射场或 3DGS，预测在视角变化下仍保持视觉一致，说明关系 Transformer 从多视图输入中隐式捕获了视角不变的关系语义。
- **消融发现**：
  - 去掉 Pi3 几何特征比去掉 DINOv2 语义特征下降更严重（DINOv2 单独缺乏多视图感知）；
  - 用 3D pointmap + 位置编码替代 Pi3 特征反而下降，说明
