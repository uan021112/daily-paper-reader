## 摘要
近年来，三维重建的进展已从逐场景优化转向前馈推理，语义场景理解也随之发展——然而现有方法仍局限于以物体为中心的感知，忽略了物体之间的空间关系。我们在前馈、无需位姿的多视图设定下形式化三维空间关系分割：给定视觉指定的主体和关系文本查询，模型在未获得目标类别名称的情况下跨视图分割出目标。为此，我们提出 RelationVGGT，一种新颖的前馈框架，它将视觉基础模型的语义特征与三维几何基础模型的几何感知表示相融合，并利用关系Transformer进行以主体为条件的跨视图关系预测——既不需要逐场景优化，也不需要已知的相机位姿。此外，我们基于 ScanNet++ 构建了一个使用 VLM 和 LLM 的全自动标注流程，可为这一新任务实现可扩展的训练数据生成。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与整体含义

- **背景**：三维重建与语义理解正从"逐场景优化"（NeRF、3DGS、LangSplat 等）转向"前馈推理"（DUSt3R、VGGT、Pi3 等几何基础模型；PanSt3R、Uni3R 等前馈语义分割）。
- **核心痛点**：现有方法几乎全部是**以物体为中心（object-centric）**的感知，把场景视为孤立实体的集合，忽略了物体之间的空间关系（如"显示器放在桌子上""杯子在键盘旁边"）。而关系推理是空间问答、具身智能体行动等高层任务的基础能力。
- **任务定义（新任务）**：**3D 空间关系分割（3D Spatial Relation Segmentation）**，在前馈、无位姿（pose-free）多视图设定下：
  - 输入：多视图图像 $I=\{I_i\}_{i=1}^N$、参考视图 $I_r$ 中的主体二值掩码 $M_s$、关系文本查询 $q$（如 "resting on"）；
  - 输出：在其余目标视图 $I_{tgt}$ 上一致地分割出满足该空间关系的**目标物体**；
  - **关键约束**：不给目标物体的类别名，目标身份必须由"主体 + 关系"推断；不依赖逐场景优化，也不需要相机位姿。
- **与既有范式的区别**：
  - RelationField 需逐场景优化 + 标定位姿，且在 3D 体积中做关系搜索，泛化性差；
  - 视频-语言模型缺乏 3D 场景表示，大视角变化下难以维持物体对应；
  - 3D referring segmentation（如 ReferSplat）用文本指代目标（可含类别/属性），而本文**用掩码视觉指定主体，仅用文本给关系**，二者接口不同。

## 2. 方法论

### 2.1 核心思想

- 将前人**体积式关系搜索**（在 3D 空间逐点查询 $g_\theta(x,z)\to r$）**重构为图像网格上的逐像素关系预测**：在目标视图上定义关系特征图 $R_t=\{r_t(u)\mid u\in I_t\}$，其中 $r_t(u)$ 编码目标视图位置 $u$ 与参考主体之间的空间关系。
- 学习映射：$f_\theta(I_r, M_s, I_{tgt}, u)\to R_t$；推理时用关系特征与文本嵌入 $e(q)$ 的相似度得到相关性图，再阈值化得掩码。
- 好处：摆脱体积搜索与场景专属 3D 场，天然支持开放词汇与新场景泛化。

### 2.2 网络架构（图 1）

1. **特征提取（冻结的双流）**
   - 语义流：DINOv2 提供稠密 patch 级语义特征 $E_n^D$；
   - 几何流：Pi3 编码器 token $E_n^P$（取其任务头之前的表示，保留通用多视图几何信息）；
   - 二者按通道拼接，经 **Input Mixer**（线性投影 + 若干带 RoPE 的 Transformer block）得到联合 token $F_n\in\mathbb{R}^{P\times d_f}$，$P=H_pW_p$。
2. **关系 Transformer（主体条件 + 跨视图）**
   - **主体表示**：不做池化压缩，而是保留参考视图全部 patch token，并用下采样到 patch 网格的主体掩码 $\bar M_s$ 做逐元素相乘，$F_r^s=\bar M_s\odot F_r$，保留主体的空间布局与细粒度语义；
   - 目标视图 token 堆叠为单序列 $Z^0=\mathrm{Concat}(\{F_t\})$；
   - 每层交替执行：**主体条件交叉注意力** $\bar Z^\ell=\mathrm{CrossAttn}^\ell(Z^\ell,F_r^s)$，再**全局自注意力** $Z^{\ell+1}=\mathrm{SelfAttn}^\ell(\bar Z^\ell)$；使表示同时具备主体条件性与多视图感知性。
3. **掩码解码**：关系 Transformer 在 patch 分辨率上操作，用 DPT head 上采样为像素对齐的关系特征图 $R_t=\mathrm{Dec}(Z_t^L)$，并对其齐到语言嵌入空间。
4. **3D 几何**：用 Pi3 点解码器预测每视图的点图与置信度图，使每个 $r_t(u)$ 可关联到对应 3D 点，形成置信度感知的跨视图 3D 关系表示。

### 2.3 训练目标

- 同一空间关系常有多种合法表述（"standing on"/"on"/"supported by"），故采用**多查询监督**而非单标签分类：
  - 每个兼容查询独立做二值预测，用 sigmoid focal loss（$\alpha=0.75$，$\gamma=1.5$）；
  - 损失在像素与查询两个维度上平均：$L_{\text{multi-q focal}}=\frac{1}{|Q||\Omega_t|}\sum_q\sum_u \ell_{\text{focal}}$；
  - Dice loss 亦逐查询独立计算后对 $Q$ 平均；
  - 总损失 $L_{\text{mask}}=w_{\text{focal}}L_{\text{multi-q focal}}+w_{\text{dice}}L_{\text{dice}}$。

### 2.4 推理

- 相关性 logit $z_t(u;q)=r_t(u)^\top e(q)$，掩码得分 $S_t=\sigma(z_t)$；
- 与特征场方法不同，**不需要正/负文本嵌入的 softmax 归一化**，直接 sigmoid 即可；
- 固定阈值 $\tau=0.3$ 得二值掩码，所有实验不做后处理。

### 2.5 自动标注流水线（基于 ScanNet++，图 2）

- 以 3D 实例级点标注初始化场景图（节点=物体，边暂空）；
- 将实例掩码投影到带位姿的 RGB 帧，用 **Set-of-Mark (SoM) 提示**让 VLM 逐帧提出有向关系（VLM：Qwen3-VL-8B）；
- **多视图一致性过滤**：同一物体对需在 ≥ K=3 帧被一致预测才保留为候选边，再传播到所有共视帧；
- **几何过滤**：用 3D 包围盒与实例质心剔除几何上不合理的关系（如远距离物体的接触/支撑）；
- **LLM 复述（GPT-5.2）**：把验证过的三元组改写为多样表述（如 TV–hanging on–wall → "mounted on"/"installed on"），提升查询词汇多样性，同时约束在同一关系族内。
- 人工审计结果：Stage-1 提案精度 36.4%，Stage-2 过滤后精度提升至 **67.2%**，剔除了 92.0% 的错误提案，但仅保留 28.5% 的正确提案（保守、牺牲召回换精度）；两位标注者一致率 83.1%（Cohen's κ=0.670，排除歧义后 κ=0.816）。

## 6. 主要结论与发现

- **性能**：平均 mIoU **0.382**、mAcc **0.549**，显著超过最强基线 RelationField（0.303 / 0.480）；在 Replica（0.446 vs 0.326）和 ScanNet++（0.445 vs 0.307）上优势明显，在 LERF 上与之相当。
- **不依赖目标物体查询**：仅靠关系推理即可定位目标，是与此前方法的关键差异。
- **跨视角稳定性**：随相机基线增大，视频模型（UniPixel 等）性能明显下降，而本文保持稳定，归因于 3D 基础模型主干提供的多视图感知特征而非帧间对应。
- **组件有效性**：
  - 去掉 DINOv2 掉点明显（语义丢失），去掉 Pi3 掉点更严重（丧失多视图感知）；
  - 用原始 pointmap 坐标 + 位置编码替代 Pi3 特征反而更差（0.370 vs 0.445）；
  - 交替式"交叉 + 自注意力"优于仅交叉注意力（0.399）与 VGGT 式交替注意力（0.394）；
  - 多查询监督显著优于单标签监督（0.445 vs 0.406）；
  - 去掉几何边过滤降至 0.398，说明几何校验对监督质量重要。
- **鲁棒性**：SAM2 单点/单框提示的主体掩码几乎不损失性能（说明不要求精确边界，只要求实例正确）；对同义改写几乎无损，对稀有/未见同义仅有轻微下降（−0.022 / −0.031 mIoU），说明关系预测不绑定训练中出现的字符串。
- **效率**：前馈推理 26 ms vs RelationField 的 288 s + 3 小时优化，量级差异巨大。

## 7. 优点

- **任务新颖且定义清晰**：首次在"前馈 + 无位姿多视图"下形式化 3D 空间关系分割，并用"视觉指定主体 + 仅给关系文本、不给目标类别"的接口明确区分于 3D 指代分割。
- **问题重构巧妙**：把体积式 3D 关系搜索改写为图像网格上的逐像素关系预测，直接绕开体积重建与场景专属坐标编码，是方法论上最核心的洞察。
- **架构设计合理**：DINOv2（语义）× Pi3（几何）的双流融合互补；主体不做池化而保留掩码 patch token，保留空间布局；交叉 + 自注意力交替同时实现主体条件化与跨视图信息交换。
- **训练目标贴合语言学事实**：多查询 sigmoid focal loss 避免了对语义等价表述的惩罚，符合"关系是多对一"的本质。
- **数据方案可扩展**：SoM 提示 + 多视图一致性 + 几何过滤 + LLM 复述的全自动流水线，配合人工审计给出精度/召回权衡的量化证据（精度 36.4%→67.2%）。
- **鲁棒性验证扎实**：对主体掩码来源、同义改写、意义改变三类扰动都做了对照，证据链完整。
- **效率优势突出**：26 ms vs 288 s + 3 小时优化，实用价值明显。

## 8. 不足与局限

- **数据依赖与标注偏差**：
  - 流水线依赖 ScanNet++ 这类带实例级标注的数据集，难以直接扩展到无标注或 in-the-wild 场景；
  - 过滤后精度仅 67.2%，保留集**仍然含噪**，且只保留 28.5% 的正确提案，覆盖度被刻意牺牲；
  - 训练谓词分布**强长尾**，VLM 倾向产出保守的规范表述，靠 LLM 复述扩充词汇，可能引入复述偏差或与视觉证据脱钩的措辞。
- **任务范围有限**：只建模物体–物体空间关系，未涉及功能关系（functional relations），也未与全景/节点预测结合以联合恢复完整场景图。
- **实验覆盖与公平性风险**：
  - LERF 上未超过 RelationField（后者在测试时还额外知道目标类别名），说明在密集桌面小物体场景中仍有明显差距；
  - 与 RelationField / MVGGT / ReferSplat 的对比存在接口、预训练数据、是否逐场景优化的多重差异，不是严格 matched-input 消融；
  - 未报告随机种子方差或误差棒；部分结论（如主体不可见子集）样本量极小（23 视图），统计支撑弱；
  - 全部评测在室内场景（ScanNet++ / Replica / LERF），户外、大规模、动态场景未验证。
- **技术限制**：
  - 依赖固定阈值 $\tau=0.3$ 且不做后处理，阈值对未见域是否稳健未做敏感性分析；
