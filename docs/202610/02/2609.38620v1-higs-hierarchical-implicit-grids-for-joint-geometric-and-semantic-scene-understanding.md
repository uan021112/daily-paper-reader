## 摘要
神经隐式表示通过使机器人能够构建连续、可微且高保真的三维地图，对场景重建产生了显著影响。大多数现有工作聚焦于几何重建，缺乏用于高层空间理解和任务规划的语义信息。此外，随着环境规模和复杂度的增加，神经表示在后端优化中面临保持计算效率的挑战。为解决这两个挑战，我们引入一种分层神经场，利用多分辨率子图实现高效且可扩展的隐式表示，并引入统一的查询与解码机制以支持几何和语义特征。更具体地说，可学习的地图特征可通过查询与解码过程转换为输出，用于训练和推理。对于大规模表示，我们将场景分解为重叠子图，并在每个局部子图内进行分层优化，从而实现可扩展计算。为进一步提高效率，我们设计特征编码器来预测初始分层网格特征，从而大幅减少从头优化子图特征所需的时间。为校正子图之间的估计漂移，我们在隐式特征空间中完全对齐并融合它们，通过避免解码最终输出而显著加速。基于这种高效的分层表示，我们将几何特征和视觉-语言潜在特征都嵌入地图中，并在有符号距离场（SDF）构建和开放词汇物体定位上进行了验证。我们的方法显著提高了计算和内存效率，保持了高估计精度，并在大规模真实世界基准上赋予机器人空间感知能力。

## Abstract
Neural implicit representations have had a significant impact on scene reconstruction by enabling robots to build continuous, differentiable, and high-fidelity 3D maps. Most existing works focus on geometric reconstruction and lack semantic information for high-level spatial understanding and task planning. Also, as the scale and complexity of the environment increase, neural representations face the challenge of maintaining computational efficiency in back-end optimization. To resolve these two challenges, we introduce a hierarchical neural field that leverages multiresolution submaps to achieve an efficient and scalable implicit representation, and a unified query and decoding mechanism to support both geometric and semantic features. More specifically, the learnable map features can be converted to the output with the query and decoding process for both training and inference. For large-scale representation, we decompose a scene into overlapping submaps and do hierarchical optimization within each local submap, thus enabling scalable computation. To further improve efficiency, we design feature encoders that predict initial hierarchical grid features to substantially reduce the time needed to optimize the submap features from scratch. To correct estimation drift among submaps, we align and fuse them entirely within the implicit feature space, leading to substantial acceleration by avoiding the need to decode the final output. Building upon this efficient hierarchical representation, we embed both geometric features and vision-language latent features into the map, and demonstrate it on both Signed Distance Field (SDF) construction and open-vocabulary object grounding. Our approach significantly improves computation and memory efficiency, maintains high estimation accuracy, and endows the robot with spatial awareness on large-scale real-world benchmarks.

  - **规模化效率瓶颈**：随着环境规模与任务时间增长，后端优化问题不断膨胀，计算与内存效率难以维持实时性。
- **核心思路**：借鉴 SLAM 中层次化表示的经典思想，利用多分辨率网格显式解耦粗/细信息，并在隐式特征空间中完成大部分后端优化，从而同时解决“语义”与“效率”两大问题。
- **整体含义**：HIGS（Hierarchical Implicit GridS）旨在提供一种统一的层次化 3D 表示与优化框架，将几何特征与视觉-语言特征共同嵌入地图，支持 SDF 构建与开放词汇物体定位两类任务，并具备可扩展的 SLAM 能力。

## 2. 方法论

### 2.1 核心思想
- 用**多分辨率特征网格**（coarse-to-fine）作为统一特征场，同一套查询与解码机制同时支持几何（SDF）与语义（vision-language）特征。
- 解码器离线预训练、在线固定；机器人只需在线优化网格特征，避免灾难性遗忘与在线训练负担。
- 场景分解为**重叠子图**，在局部子图内做层次化优化，在隐特征空间完成子图对齐与融合，避免解码最终输出带来的昂贵开销。

### 2.2 关键技术细节

**（1）层次化 3D 网格与查询解码**
- 定义 L > 1 层规则网格，分辨率从粗到细递增；每层存储特征 $F_l$。
- 连续特征场由核函数（三线性插值）加权得到：$f_l(x) = \sum_i k_l(x, z_{l,i}) f_{l,q_l(i)}$。
- 输出由解码器拼接各层特征后得到：$h(x;F,\theta) = D_\theta(\oplus_l f_l(x))$。
- 两种网格形式：
  - **稠密网格**：用于低维特征（如 SDF），每个网格均有特征，索引 $q_l(i)$ 直接线性映射。
  - **稀疏网格**：用于高维特征（如 vision-language），仅存储近表面网格特征，用查找张量 $Q_l$ 实现 O(1) 索引，无效索引返回 0。
- 默认设置：2 层，粗层 0.5 m、细层 0.1 m；SDF 特征维度 4，vision-language 特征维度 64。

**（2）损失函数设计**
- **SDF**：
  - 近表面点直接监督：$c_j^{sdf} = w_j^{sdf}|h^{sdf}(x_j) - y_j^{sdf}|$。
  - 自由空间点施加上下界约束：下界用指数惩罚，上界用线性惩罚；不引入 Eikonal 正则（因其对精度影响有限且拖慢优化）。
- **Vision-language**：仅考虑表面点，使用余弦相似度损失 $c_j^{vl} = 1 - \cos(h^{vl}(x_j), y_j^{vl})$。

**（3）层次化特征初始化**
- 核心直觉：每一层的有效初始化可借助上一层的优化残差获得。
- **理论分析（命题 1）**：在线性解码器 + 二次代价的特殊情况下，最优初始化有闭式解 $F_l^\star = -[J^\top J]^\dagger J^\top r_{1:l-1}(x)$，即残差的线性函数。
- **一般情形**：用神经网络编码器 $E_{\phi_l}$ 近似该映射：$F_l^\star \approx E_{\phi_l}(r_{1:l-1}(x))$，逐层递归初始化。
- 编码器输入为带残差特征的点云，先体素化池化，SDF 用 3D CNN 处理，vision-language 用 Fast Point Transformer（FPT）处理，最后经 MLP 预测网格特征。
- 训练时模拟位姿噪声（1° / 1 cm 标准差），增强测试鲁棒性。

**（4）开放词汇物体定位**
- **SDF 引导的注意力机制**：由于网格坐标均匀分布、未必落在物体表面，直接使用会丢失细粒度结构信息。利用 SDF 特征近似“网格坐标到最近表面的投影向量” $t_i \approx \text{MLP}_1(d_i)$，将投影后的坐标用于位置编码：$g_i = f_i + \delta_{abs}(c_i - v_i) + \delta_{sdf}(d_i)$。
- 解码器位置编码同样加入 SDF 嵌入：$pe_i = \text{MLP}(c_i) + \text{MLP}(d_i)$。
- 输出 256 个物体候选，包括目标词置信度、3D 包围盒、网格坐标掩码；使用匈牙利匹配 + focal loss / L1 / GIoU / 交叉熵 / dice loss 训练。
- **免训练推理**：网格地图可作为内存高效表示，被现成点云物体定位模型（如 Locate-3D）直接查询使用。

**（5）SLAM 扩展**
- **相机位姿优化**：将位姿作为优化变量，加入基于信赖域的位姿正则项 $\rho(\hat{T},T) = w_\rho \max(\|\text{Log}(\hat{T}^{-1}T)\|^2 - \tau, 0)$；跟踪与建图交替进行。
- **层次化子图对齐**：
  - 特征层面：逐层比较两子图在重叠区域的特征（SDF 用 L2，vision-language 用余弦距离），形成位姿图优化问题（式 29）。
  - 预测层面：在特征对齐基础上，用解码后的 SDF / vision-language 预测值进一步精调（式 31）。
  - 算法 2：逐层求解，粗层结果作为细层初始化，最后加一个预测精调阶段。
- **子图融合**：对查询点处各子图特征做加权平均，再送入解码器得到全局预测。

## 6. 主要结论与发现

- **效率显著提升**：SDF 构建相比 iSDF / Neural Points 实现最高 **40× 加速**（0.7–1.5 s vs 20–70 s），同时 Chamfer 误差更低、F-score 更高。
- **内存大幅压缩**：层次化 3D 网格地图相比原始点云特征存储实现 **超过 20× 内存压缩**，定位精度仅损失约 1%–3%。
- **几何特征增强语义理解**：引入 SDF 特征后，物体定位在 Acc@50 上提升 **最高 15 个百分点**，弥补了均匀网格坐标缺乏表面结构信息的问题。
- **语义特征辅助子图对齐**：CLIP 特征可改善子图对齐的旋转误差，但对局部相机位姿跟踪几乎无帮助（位姿估计与几何耦合更紧密）。
- **层次化对齐鲁棒性强**：在较大初始误差下，HIGS 明显优于 MIPS、VFPP、ICP，且因大部分迭代在特征空间完成，速度更快。
- **户外可扩展**：在 Newer College 数据集上达到与 KISS-ICP / PIN-SLAM 相当的水平，验证了子图对齐与融合对全局一致性的有效性。

## 7. 优点

- **统一表示**：同一套层次化网格 + 查询解码机制同时支持几何与语义特征，架构简洁且通用。
- **效率设计精巧**：预训练解码器 + 预训练编码器初始化 + 子图分解 + 特征空间对齐，多管齐下显著降低在线优化成本。
- **理论支撑**：命题 1 从线性最小二乘闭式解出发，为学习式层次初始化提供了清晰的理论动机。
- **跨模态协同**：明确展示了几何特征与语义特征的双向增强效应（SDF 提升定位、CLIP 辅助对齐）。
- **实验覆盖全面**：室内外、多任务、多基线、消融实验齐全，定量与定性结合。
- **兼容性强**：网格地图可作为内存高效表示被现成模型（Locate-3D）免训练使用，具备良好的生态兼容性。
