## 摘要
近年来，3D重建的进展已从逐场景优化发展到前馈推理，语义场景理解也紧随其后——然而现有方法仍局限于以物体为中心的感知，忽视了物体之间的空间关系。我们将3D空间关系分割形式化为一种前馈、无位姿的多视图设定：给定一个视觉指定的主体和关系文本查询，模型在未获得目标类别名称的情况下跨视图分割目标。为此，我们提出RelationVGGT，一种新颖的前馈框架，它将来自视觉基础模型的语义特征与来自3D几何基础模型的几何感知表示相结合，并利用关系Transformer进行以主体为条件的跨视图关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们提供了一个基于ScanNet++、利用VLM和LLM构建的全自动标注流程，能够为这一新任务实现可扩展的训练数据生成。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与整体含义

- **研究背景**：3D 重建与神经渲染经历了从 NeRF、3DGS 的逐场景优化，到 DUSt3R、VGGT 等视觉几何模型的前馈推理转变；语义场景理解也随之从 LangSplat、OpenGS 等场景优化方法转向 PanSt3R、Uni3R 等前馈方法。
- **核心问题**：现有 3D 场景理解方法仍以**物体为中心**，将场景视为孤立实体的集合，忽视了物体之间的空间关系（如"显示器放在桌上"、"杯子在键盘旁边"）。而整体场景感知、空间问答和具身智能体都需要关系推理能力。
- **任务形式化**：论文提出 **3D 空间关系分割（3D Spatial Relation Segmentation）**，设定为前馈、无位姿的多视图场景：
  - 输入：多视图图像、参考视图中的主体掩码 $M_s$、关系文本查询 $q$（如 "resting on"）；
  - 输出：在所有目标视图中一致地分割出满足该空间关系的目标物体；
  - 关键约束：**不提供目标类别名称**，目标身份必须从"主体–关系"对中推断。
- **与既有工作的区别**：
  - RelationField 依赖逐场景优化和标定相机位姿，可扩展性差；
  - 视频语言模型缺乏 3D 场景表示，在大视角变化下难以保持物体对应关系；
  - 3D 指代分割（如 ReferSplat）用文本指定目标（可能含类别），而本文用视觉掩码指定主体、仅用文本给出关系。

## 2. 方法论

### 2.1 核心思想
- 将先前工作 RelationField 的**体积式关系搜索**（在 3D 体积中遍历所有候选位置 $g_\theta(x,z)\to r$）重新表述为**目标视图图像网格上的逐像素关系预测**，条件化于参考视图主体。
- 学习函数 $f_\theta(I_r, M_s, I_{tgt}, u) \to R_t$，其中 $R_t = \{r_t(u)\}_{u\in I_t}$ 为逐视图关系特征图，$r_t(u)\in\mathbb{R}^D$ 编码位置 $u$ 与参考主体的空间关系。

### 2.2 架构流程
- **特征提取**：对每张输入图像 $I_n$，分别用 DINOv2（语义）和 Pi3 编码器（几何）提取稠密 patch 表示 $E_n^D$、$E_n^P$，通道拼接后经输入混合器 $M_\theta$（线性投影 + 带 RoPE 的 Transformer 块）融合为联合 token $F_n \in \mathbb{R}^{P\times d_f}$。
- **关系预测（Relation Transformer）**：
  - 主体表示：保留参考视图全部 patch token，用下采样后的主体掩码 $\bar{M}_s$ 做逐元素乘法，得到 $F_r^s = \bar{M}_s \odot F_r$，**保留主体的空间布局与细粒度语义**，而非压缩为单一向量；
  - 目标视图 token 堆叠为序列 $Z^0 = \text{Concat}(\{F_t\})$；
  - 关系 Transformer 交替执行**主体条件交叉注意力**与**多视图全局自注意力**：$\bar{Z}^\ell = \text{CrossAttn}^\ell(Z^\ell, F_r^s)$，$Z^{\ell+1} = \text{SelfAttn}^\ell(\bar{Z}^\ell)$；
  - 经 L 层后 reshape 回逐视图 patch 网格，用 DPT 头解码为像素对齐的关系特征图 $R_t$。
- **3D 几何**：用 Pi3 点解码器预测每视图的点图与置信度图，使每个 $r_t(u)$ 可关联到对应 3D 点，形成置信度感知的 3D 关系表示。

### 2.3 训练目标
- 观察到同一空间关系常有多种有效表达（如 "standing on" / "on" / "supported by"），若作为单标签分类会惩罚语义合理的替代表达。
- 对同一目标掩码用**多个兼容关系查询独立监督**，采用 sigmoid 焦点损失 + Dice 损失：
  - $\mathcal{L}_{mask} = w_{focal}\mathcal{L}_{multi\text{-}q\,focal} + w_{dice}\mathcal{L}_{dice}$；
  - 多查询焦点损失对像素和查询双重平均，$\alpha=0.75$，$\gamma=1.5$。

### 2.4 推理
- 计算关系特征与文本嵌入的相似度：$z_t(u;q) = r_t(u)^\top e(q)$；
- 掩码分数 $S_t(u;q)=\text{sigmoid}(z_t(u;q))$，固定阈值 $\tau=0.3$ 得到二值掩码；
- 无需负提示归一化或 softmax。

### 2.5 自动标注流程
- 基于 **ScanNet++** 的实例级 3D 点标注构建场景图（节点为物体，边为空）；
- 将实例掩码投影到 RGB 帧，使用 **Set-of-Mark（SoM）提示**查询 VLM 获取帧级关系提议；
- **多视图一致性过滤**：同一物体对需至少 K=3 帧一致预测才保留；
- **几何过滤**：用 3D 边界框与实例质心剔除几何上不可能的关系（如远处物体间的接触/支撑）；
- **LLM 改写**：VLM 倾向保守、词汇单一，故用 LLM 将验证过的三元组改写成多样化表达（如 TV–hanging on–wall → "mounted on" / "installed on"），且限定在同一关系族内。

## 6. 主要结论与发现

- **性能领先**：平均 mIoU **0.382**、mAcc **0.549**，显著优于最强基线 RelationField（0.303 / 0.480）；在 Replica（0.446 / 0.640）与 ScanNet++（0.445 / 0.675）上优势明显。
- **LERF 上相当**：在密集杂乱的桌面场景中，与可访问目标类别名的 RelationField 性能相当，且优于仅用关系嵌入的 RelationField†。
- **跨视角稳定性**：按相机基线分组对比视频基础模型，UniPixel 在小基线尚可但随基线增大明显退化，本文方法在三档基线下均保持稳定，归因于 3D 基础模型骨干提供多视图感知特征。
- **无需显式 3D 表示**：尽管不使用辐射场或 3DGS，预测在大视角变化下仍视觉一致，说明关系 Transformer 能隐式捕获视图不变的关系语义。
- **主体掩码鲁棒**：单点/单框 SAM2 提示与 GT 掩码性能几乎一致（mIoU 0.382 vs 0.383），说明不需要精确主体边界；Qwen3-VL+SAM2 全自动定位仍保留大部分性能。
- **谓词表达鲁棒**：同义改写仅带来约 −0.004~−0.006 的 mIoU 变化，罕见/未见同义词也仅 −0.022~−0.031；但语义改变的关系会使 mIoU 下降 0.158~0.276，证明模型确实依赖关系文本语义。
- **标注流程有效**：过滤将提议精度从 36.4% 提升至 67.2%，剔除 92.0% 的人类判定错误提议，但保守策略仅保留 28.5% 的正确提议（以覆盖率换可靠性）。

## 7. 优点

- **任务形式化新颖**：首次将 3D 空间关系分割定义为前馈、无位姿多视图设定，且目标类别不可见，与指代分割形成清晰区分。
- **方法设计巧妙**：将体积式关系搜索重构为逐像素关系预测，避免显式 3D 重建与场景特定优化，推理速度提升约 4 个数量级（26 ms vs 288 s + 3 h 优化）。
- **特征融合合理**：DINOv2 提供物体级语义、Pi3 提供多视图几何感知，消融证明二者互补且缺一不可。
- **主体表示保留空间布局**：不做池化而是保留掩码后的全部参考 token，配合交叉注意力，使目标视图即使看不到主体也能正确推理。
- **多查询监督贴合语义**：认识到空间关系是一对多的，避免单标签监督惩罚合理同义表达。
- **数据可扩展**：全自动 VLM+LLM 标注流程基于 ScanNet++，解决了该新任务训练数据稀缺问题，并提供提示词全文。
- **实验全面**：横跨三大数据集、多类基线、多维消融与鲁棒性分析，且进行了人工标注质量审计与双标注者一致性统计（Cohen's κ）。

## 8. 不足与局限

- **数据依赖**：标注流程依赖具有实例级标注的数据集（如 ScanNet++），难以直接扩展到无标注或野外场景。
-
