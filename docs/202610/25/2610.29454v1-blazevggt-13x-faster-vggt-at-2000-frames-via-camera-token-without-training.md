## 摘要
以 VGGT 为代表的前馈式视觉几何模型通过稠密全局注意力展现出强大的多视图重建能力。然而，由此产生的全视图两两交互计算会随着输入视图数量呈二次增长；由于高度重叠的观测之间存在大量帧级冗余，长序列推理尤其耗费计算资源。我们发现，VGGT 的相机 token 呈现出一种“先拓扑、后几何”的演化规律：浅层 token 能够可靠地捕捉局部视图邻域，而深层 token 则逐步编码全局组织的视图间几何关系。受此启发，我们提出 BlazeVGGT，这是一种无需训练、具备结构感知能力的帧级键值稀疏化框架。在每个全局注意力模块中，BlazeVGGT 根据相机 token 之间的关系构建视图级相似性核，并采用贪心行列式点过程推理，选出一组紧凑且彼此互补的视图。所选视图构成键值上下文，同时保留所有输入帧作为查询。这种非对称注意力设计在维持逐帧稠密预测的同时，消除了冗余的跨视图计算，使我们的方法能够作为即插即用模块直接集成到预训练 VGGT 中，无需更新参数。序列越长，其优势越显著：在 2,000 帧时，BlazeVGGT 的推理速度约为 VGGT 的 13 倍，同时将 Chamfer 距离从 0.41 降至 0.32。大量实验表明，该方法在点云重建和相机位姿估计中实现了良好的精度—效率权衡；它与 FastVGGT、LiteVGGT 等现有 VGGT 加速方法兼容，并可迁移至 StreamVGGT、PAGE-4D 等基于 VGGT 的模型。代码已公开发布于 https://github.com/MagiciannnY/BlazeVGGT.git。

## Abstract
Feed-forward visual geometry models, exemplified by VGGT, have demonstrated strong multi-view reconstruction capabilities through dense global attention. However, the resulting all-to-all cross-view computation scales quadratically with the number of input views, making long-sequence inference particularly expensive due to substantial frame-level redundancy among highly overlapping observations. We uncover a topology-first, geometry-later evolution in VGGT camera tokens: shallow-layer tokens reliably capture local view neighborhoods, whereas deeper-layer tokens progressively encode globally organized inter-view geometry. Motivated by this observation, we introduce BlazeVGGT, a training-free framework for structure-aware frame-level key--value sparsification. At each global-attention block, BlazeVGGT constructs a view-level similarity kernel from camera-token relations and employs greedy determinantal point process inference to select a compact set of mutually complementary views. The selected views constitute the key--value context, while all input frames are retained as queries. This asymmetric attention design preserves dense per-frame predictions while eliminating redundant cross-view computation, allowing our method to be directly integrated into pretrained VGGT as a plug-and-play module without parameter updates. Its advantages become increasingly pronounced with sequence length: at 2,000 frames, BlazeVGGT achieves approximately 13$\times$ faster inference than VGGT while reducing the Chamfer Distance from 0.41 to 0.32. Extensive experiments demonstrate a favorable accuracy--efficiency trade-off in point-cloud reconstruction and camera-pose estimation, compatibility with existing VGGT accelerators such as FastVGGT and LiteVGGT, and transferability to VGGT-based models including StreamVGGT and PAGE-4D. Codes are publicly available at https://github.com/MagiciannnY/BlazeVGGT.git.

# 1. 核心问题与整体含义

- **研究对象**：VGGT 是一种前馈式视觉几何模型，可从多张图像联合预测相机参数、深度、点云等几何结果。它借助全局注意力让不同视图交换信息，但若每帧含有 \(P\) 个 token、输入 \(S\) 帧，跨视图注意力的主要计算量约随 \(S^2\) 增长。
- **核心问题**：长序列中相邻帧通常高度重叠，提供了大量重复信息；但 VGGT 仍会让所有视图彼此进行全局交互，导致推理时间和显存开销快速增加。已有加速方法多压缩空间 token、改变注意力结构或进行模型训练，未必直接针对完整视图之间的冗余。
- **论文的整体思路**：利用 VGGT 内部的相机 token 识别哪些帧重复、哪些帧互补，只让一小部分代表性帧提供全局注意力的键和值（KV）；所有输入帧仍保留为查询（Query），继续接收信息并生成预测。作者报告，在 2,000 帧设置下，该方法相较 VGGT 快约 13 倍，点云重建 Chamfer Distance（CD）由约 0.42 降至约 0.33。

# 2. 方法论

## 2.1 核心观察：相机 token 从局部拓扑发展到全局几何

- 作者分析 VGGT 各全局注意力层中的相机 token，发现其表征随网络深度变化：
  - **浅层**：较能保留视图之间的局部邻域关系，适合判断哪些视图彼此相似、可能冗余。
  - **深层**：视图关系逐渐更符合全局相机几何组织，尤其是旋转关系；平移距离的全局度量对应性相对较弱。
- 因此，作者认为不必在每一层都依赖精确的相机位姿：浅层可用于抑制近邻冗余，深层则有助于选择覆盖更广的视图。

## 2.2 相机 token 相似核与贪心 DPP 选帧

在每个全局注意力块中，BlazeVGGT 大致执行以下步骤：

1. 对所有帧的相机 token 做序列均值中心化，并进行归一化，以突出帧间差异。
2. 用归一化相机 token 的余弦距离衡量视图差异：
   \[
   d_{ij}=1-\hat c_i^\top\hat c_j.
   \]
3. 将距离转成 RBF 相似核：
   \[
   L_{ij}=\exp(-d_{ij}/s),
   \]
   其中 \(s\) 是根据当前层视图间距离自适应估计的尺度。
4. 用 DPP 的行列式衡量一个视图集合的多样性：集合的核矩阵行列式越大，表示视图在特征空间中共同覆盖的方向越丰富，彼此冗余越少。
5. 从一个锚点视图开始，使用贪心策略逐步加入能带来最大增量多样性的帧。候选帧的边际贡献可由 Schur 补得到：
   \[
   r_j=L_{jj}-l_j^\top L_{\mathcal S}^{-1}l_j.
   \]
   当最大的残差 \(r_j\) 低于阈值 \(\epsilon\)，或达到最大视图预算 \(K\) 时停止。实现中通过增量 Cholesky 更新避免每轮重新计算矩阵逆。

因此，选取帧数不是固定值：表示中冗余较多时倾向于保留更少视图；视图差异更丰富时则可能保留更多，且受到 \(K\) 的上限约束。

## 2.3 非对称 Query–KV 注意力

- **所有输入帧都保留为 Query**，因此所有帧仍会获得跨视图更新，并保持逐帧密集预测。
- **只有选中的帧构成 KV 上下文**，且每个入选帧的完整 token 块都会保留，而不是仅保留零散空间 token。
- 若第 \(\ell\) 层保留 \(K^{(\ell)}\) 个视图，注意力主要计算量由约
  \[
  O(S^2P^2C)
  \]
  降为
  \[
  O(SK^{(\ell)}P^2C).
  \]
  当保留视图数相对序列长度较小且受预算约束时，跨视图计算可由近似二次增长转向更接近线性增长。
- 方法不增加可学习参数，不需要训练或输入特定优化；原则上可直接插入预训练 VGGT。

# 6. 主要结论与发现

- VGGT 相机 token 的层级表征可用于免训练视图筛选：浅层适合利用局部视图邻域消除冗余，深层更能支持全局视图覆盖。
- 将完整帧作为选择单位、让所有帧继续担任 Query、只稀疏化 KV，是 BlazeVGGT 降低跨视图计算的关键设计。
- 在长序列重建中，BlazeVGGT 能以较低推理时间维持有竞争力的点云和位姿精度；作者报告的收益随序列长度增加而更加显著。
- 该方法可与已有 VGGT 加速器组合，也可以迁移至 StreamVGGT 和 PAGE-4D；不过迁移后的质量收益并非对所有数据集和指标都一致。

# 7. 优点

- **免训练、易集成**：不修改预训练权重、不新增可学习参数，也无需额外位姿估计器。
- **针对帧级冗余**：不是单纯压缩空间 token，而是直接减少冗余视图作为跨视图信息源的机会。
- **保留逐帧预测能力**：所有输入帧仍作为 Query，避免通过直接删帧而失去其预测结果。
- **保持帧内证据完整**：入选帧的完整 token 块进入 KV，有利于保留帧内空间结构。
- **选择具有集合多样性意识**：DPP 的行列式目标关注所选视图的联合互补性，而不是独立打分后可能重复选中相似帧。
- **评估范围较广**：包含多数据集、多序列长度、位姿任务、流式推理、不同模型迁移及与其他加速方案组合的实验。

# 8. 不足与局限

- **速度收益依赖序列冗余和选中规模**：如果视图本身差异很大，或 DPP 在某些层保留了较多视图，KV 长度不会显著下降，加速幅度可能受限。Top-K 有助于控制上限，但不能保证所有场景都达到相同收益。
- **选帧本身有额外开销**：方法需要计算两两相似度并执行贪心选择。论文未充分拆分这部分开销及其与注意力节省之间的关系，超长序列时该开销的占比值得进一步评估。
- **精度并非普遍单调改善**：2,000 帧主结果中 CD 优于基线，但部分位姿指标和扩展任务存在不同趋势；PAGE-4D 在 500 帧 Bonn 设置下有较明显精度退化，说明长上下文稀疏化仍可能丢失任务相关证据。
- **公平比较存在解释空间**：2,000 帧评估使用双 A800，其他设置多为单卡；StreamVGGT 的基线和加入 BlazeVGGT 后显存、延迟表现也受具体实现和在线上下文策略影响。论文说明了部分硬件差异，但仍缺少更完整、统一的计时拆解。
- **消融和机制验证仍有限**：阈值、预算、层范围已有对照，但对自适应尺度选取、锚点选择、不同 DPP 变体、各层保留数量与误差之间的关系，尚未进行全面比较。
- **在线场景有额外设计要求**：原方法的核尺度依赖全序列距离统计，无法直接用于不能访问未来帧的单遍流式推理；论文为 StreamVGGT 固定尺度建立基线，并提出双记忆方案作为建议。这表明在线部署需要额外处理因果性和记忆管理问题。
- **结论适用范围仍需扩展**：实验主要集中在室内重建及特定 VGGT 系模型，尚不足以证明其在所有场景、动态物体密集视频、不同相机运动分布或其他视觉几何架构上都具有同等效果。
- **论文状态**：所给版本标注为“UNDER REVIEW”，结论应视为该版本报告的实验结果，仍可等待后续审稿与复现检验。
