## 摘要
4D 场景重建需要稳健地处理动态物体，但现有流式方法通常假设场景静态，导致长序列中出现位姿漂移和鬼影伪影。我们提出 Stream4D，这是一种无需训练、运动解耦的流式重建框架，可直接集成到因果 Transformer 主干网络（如 StreamVGGT、Stream3R）中。我们的关键观察是，因果注意力会在 KV 缓存中隐式编码丰富的时序运动线索。我们从多个注意力层和多个时间窗口中自适应地聚合这些线索，并将其与深度先验融合，以处理遮挡和无纹理区域等复杂情况，从而生成精确的动态掩码，实现静态区域与动态区域的解耦。随后，我们采用软键掩码方案，利用这些动态掩码抑制因果注意力中动态区域的干扰，从而提高相机位姿估计的准确性。Stream4D 继承了因果注意力的高效性，并与现有流式架构兼容。在多种动态场景基准测试中，Stream4D 显著提升了相机位姿估计和静态场景重建质量，生成可靠的动态掩码，并有效缓解了长序列中的鬼影现象。

## Abstract
4D scene reconstruction requires robust handling of dynamic objects, yet existing streaming methods commonly assume static scenes, leading to pose drift and ghosting artifacts over long sequences. We introduce Stream4D, a training-free, motion-decoupled streaming reconstruction framework that can be directly integrated into causal Transformer backbones (e.g., StreamVGGT, Stream3R). Our key observation is that causal attention implicitly encodes rich temporal motion cues within the KV cache. We adaptively aggregate these cues from multiple attention layers and across temporal windows, and fuse them with depth priors to handle challenging cases such as occlusions and textureless regions, producing precise dynamic masks that decouple static and dynamic regions. We then apply a soft key masking scheme that leverages these dynamic masks to suppress interference from dynamic regions in causal attention, thereby improving camera pose estimation accuracy. Stream4D inherits the efficiency of causal attention and remains compatible with existing streaming architectures. On diverse dynamic-scene benchmarks, Stream4D significantly improves camera pose estimation and static-scene reconstruction quality, yields reliable dynamic masks, and effectively mitigates long-sequence ghosting.

# 1. 核心问题与整体含义

- **研究问题：**流式 4D 重建需要逐帧处理视频并持续更新场景与相机状态，但现有流式重建方法通常假设场景静态。行人、车辆等动态物体会破坏跨帧几何和外观一致性，干扰相机位姿估计；在因果注意力的 KV 缓存中，这些动态特征还会随时间累积，造成位姿漂移和长序列重影。
- **研究背景：**全局注意力方法可以利用整段视频的信息，但每加入新帧通常需要重新处理大量历史内容，不利于在线推理。因果 Transformer 通过 KV 缓存实现高效增量计算，却缺少适用于动态场景的运动解耦机制。
- **论文主旨：**Stream4D 不重新训练重建骨干，而是从流式因果注意力及其 KV 缓存中提取运动线索，生成动态区域掩码，再利用掩码抑制历史缓存中动态区域对后续重建的干扰。作者称这一框架可直接接入 StreamVGGT、Stream3R 等因果流式架构。

# 2. 方法论

## 2.1 核心流程

1. 输入视频按时间顺序逐帧进入因果 Transformer。
2. 当前帧的查询与历史帧缓存的键进行注意力计算；模型同时从多层、多时间范围的注意力结果中提取运动显著性。
3. 将注意力显著性与深度相关线索融合，平滑并二值化，得到当前帧的动态掩码。
4. 将动态掩码映射到缓存中的图像 token，对历史键进行软抑制，使后续帧的注意力较少受历史动态区域影响。
5. 继续增量更新相机位姿与场景几何，并优先将高置信度静态点加入静态场景点云。

## 2.2 注意力运动线索

- 对第 \(l\) 层，当前帧查询 \(Q_t^{(l)}\) 与历史缓存键 \(K_{1:t-1}^{(l)}\) 计算因果注意力。
- 论文的经验观察是：动态区域往往表现为**注意力均值较低、跨时间方差较高**，而静态区域通常均值较高、方差较低。
- 方法在自适应选择的历史帧集合 \(H_t\) 上统计每个 token 的注意力均值和方差，构造单层显著性：
  \[
  S_t^{(l)}=(1-\bar{\mu}_t^{(l)})\odot\bar{\sigma}_t^{(l)}.
  \]
- 再将浅层、中层和深层等多个注意力层的显著性加权融合：
  \[
  S_t^{\mathrm{attn}}=\sum_{l\in L}w_l S_t^{(l)},
  \]
  文中称权重偏向中层语义特征。多层、多历史帧统计的目的，是避免只依赖相邻帧或单层注意力带来的不稳定。

## 2.3 深度融合与掩码生成

- **深度前景先验：**假设较近的区域更可能是前景，通过深度分位数与当前深度的差构造显著性：
  \[
  S_t^{\mathrm{depth-prior}}
  =\operatorname{Sigmoid}\bigl(\beta(\operatorname{Quantile}(D_t,q)-D_t)\bigr).
  \]
- **深度时间变化：**在时间窗口 \(\tau\) 内统计深度变化，并归一化，以反映几何随时间的不一致。
- **多源融合：**将注意力显著性、深度前景先验和深度变化按经验权重融合：
  \[
  S_t=\alpha_{\mathrm{attn}}S_t^{\mathrm{attn}}
  +\alpha_{\mathrm{depth}}
  (\alpha_{\mathrm{prior}}S_t^{\mathrm{depth-prior}}
  +\alpha_{\mathrm{change}}S_t^{\mathrm{depth-change}}).
  \]
- 随后对显著性做时间平滑，使用 Otsu 阈值和形态学处理生成二值动态掩码 \(M_t\)。作者认为深度线索可补充注意力在遮挡或无纹理区域中的不足。

## 2.4 软键屏蔽

- 对缓存中的历史键应用动态掩码：
  \[
  \tilde K_i=K_i\odot(1-\gamma M_i), \qquad \gamma\in(0,1).
  \]
- 也就是说，动态 token 对应的键被软抑制，而值 \(V_i\) 不变；后续帧用修改后的缓存执行因果注意力。
- 文中称该处理主要施加在前几层解码器中，并维护掩码缓存，以保证历史帧的抑制状态在后续推理中保持一致。
- 论文还描述了将光度和几何一致性约束限制在静态区域，以及增量加入高置信度静态点的做法。不过，给出的实验部分并未完整呈现相应优化目标如何在具体预训练骨干的推理流程中实现；因此不宜把公式中的损失项直接理解为论文进行了额外训练。

# 6. 主要结论与发现

- 因果注意力及 KV 缓存中包含可用于动态区域识别的跨帧统计线索。
- 将多层、多历史窗口的注意力统计与深度先验结合，可以在不额外训练的情况下生成动态掩码。
- 对历史缓存键进行软屏蔽，有助于减轻动态区域对后续位姿估计和静态场景融合的干扰。
- 在作者报告的实验中，Stream4D 的流式分割指标优于所比较的流式基线，DyCheck 位姿指标较 Stream3R 有小幅改善，并在长序列效率测试中保持接近线性的耗时增长。
- 论文认为，这些设计可以减少长序列重影，同时保留因果流式架构的在线推理优势。

# 7. 优点

- **针对性强：**直接处理流式重建中的动态物体干扰和历史信息累积问题，而非仅改进离线视频重建。
- **免训练、易集成：**不依赖额外动态场景训练数据，目标是作为插件接入现有因果 Transformer 骨干。
- **利用缓存信息进行解耦：**将 KV 缓存不仅作为计算加速机制，也作为提取时间运动线索的来源。
- **线索互补：**注意力变化与深度前景、深度时间变化结合，试图覆盖单一线索在遮挡、无纹理区域的弱点。
- **评估覆盖多个维度：**包含分割精度、位姿误差、长序列耗时和定性重影展示，且明确区分因果流式与离线比较。

# 8. 不足与局限

- **实验验证不够完整：**所给材料没有可见的消融实验和超参数敏感性分析；“多模块共同有效”的结论缺少模块级证据。
- **量化重建证据有限：**论文强调静态场景重建质量和重影改善，但表格中主要给出的是位姿指标；重建几何质量缺少足够的量化指标和完整评估细节。
- **深度先验有适用边界：**“较近区域更可能是动态前景”的假设在近距离静态物体、远距离运动物体或复杂遮挡场景中可能不成立。
- **注意力统计未必具有普适性：**注意力均值和方差与运动之间的关联是经验观察，可能依赖具体骨干、层结构、分辨率和场景类型；论文尚未充分展示跨骨干泛化。
- **基线适配带来比较风险：**没有原生分割能力的流式方法需经作者改造才能产生掩码；其实现方式可能影响比较结果。离线方法使用未来帧，结果不能直接与严格在线方法等同。
- **长序列验证有限：**效率测试扩展到 200 帧，但未展示更长时间运行中的漂移、缓存管理、显存占用和长期稳定性量化。
- **动态对象建模不是重点：**该方法主要抑制动态区域对静态场景重建的影响，并不直接重建物体的完整动态几何或运动轨迹。论文也将扩展动态对象重建列为未来方向。
