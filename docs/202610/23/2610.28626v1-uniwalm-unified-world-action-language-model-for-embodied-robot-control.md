## 摘要
受人类能够整合语言、感知与行动经验这一能力的启发，我们提出 UniWALM，一种统一的世界—行动—语言模型。该模型在单一共享表征中学习视频、动作和语言，其中每种模态既是条件信号，也是监督目标。我们探究：联合生成语言能否丰富这一共享表征，从而提升操作能力并支持依赖记忆的行为？不同于以往将推理模型或视觉语言模型接入视频—动作骨干网络、并将二者分阶段运行的方法，UniWALM 在单一混合 Transformer 骨干网络中统一三种模态；各模态的扩散头同步进行联合去噪，在同一轮处理中与动作一并解码子任务和文本记忆，无需单独的规划阶段。生成的语言会在下一步重新输入模型，由此形成“语言即记忆”的闭环，无需外部规划器或记忆库。为确保在这一更丰富的目标下动作流仍然可靠，我们进一步提出带校正的流匹配（Flow Matching with Correction，FMC），这是一种训练目标，使模型学会从受扰动的动作轨迹中恢复，且不增加推理时开销。在组合式拾取与放置任务（MolmoSpaces）以及 RMBench 中依赖记忆的子集上，UniWALM 均持续优于采用相同骨干网络的基线模型（例如 FastWAM）。在 RMBench 上，UniWALM 无需任何预训练语言或推理模型便达到 34.5%，并且仅使用单个锚定帧，就超过了配备关键帧的 Mem-0 设置（28.5%）。在真实世界的“寻找物品”任务中，生成文本记忆使成功率从 11.1% 提升至 61.1%；而当前最先进的视觉语言动作模型（VLA）的表现仍不高于随机水平（≤33.3%）。

## Abstract
Motivated by the human ability to integrate experience across language, perception, and action, we introduce UniWALM, a unified world-action-language model that learns video, action, and language in a single shared representation, where each modality is both a conditioning signal and a supervision target. We ask: can jointly generating language enrich this shared representation, improving manipulation and supporting memory-dependent behavior? Unlike prior approaches that attach a reasoning or vision-language model to a video-action backbone and run them as distinct stages, UniWALM unifies all three modalities inside a single mixture-of-transformers backbone whose per-modality diffusion heads co-denoise synchronously, decoding subtask and textual memory in the same pass as action with no separate planning stage; the generated language is re-consumed on the next step, closing a language-as-memory loop without an external planner or memory bank. To keep the action stream reliable under this richer objective, we further introduce Flow Matching with Correction (FMC), a training objective that teaches recovery from perturbed action trajectories at no inference-time cost. UniWALM consistently improves over same-backbone baselines (e.g., FastWAM) on compositional pick-and-place (MolmoSpaces) and across the memory-dependent subset of RMBench, where it reaches 34.5% without any pretrained language or reasoning model and exceeds Mem-0's keyframe-equipped setup (28.5%) using only a single anchor frame. On a real-world Find-the-Item task, generating textual memory lifts success from 11.1% to 61.1%, while state-of-the-art VLAs stay at or below chance (<=33.3%).

## 2. 方法论

### 2.1 统一的视频—动作—语言模型

- UniWALM 采用 **混合 Transformer（Mixture of Transformers, MoT）**，包含视频、动作和语言三个模态专家。
- 每种模态有独立的 DiT（Diffusion Transformer）处理分支，但各分支通过统一自注意力共享特征；模型还结合任务指令和本体感觉状态等条件信息。
- 给定当前观测、机器人状态、任务指令，以及可选的视觉记忆，模型联合预测：
  - 未来视频帧；
  - 一段未来动作；
  - 语言字符串，包括当前或下一子任务，以及可选的文本记忆；
  - 动作向量中附加的任务完成信号 β。
- 视频骨干初始化自预训练的 Wan2.2；动作和语言 DiT 从头训练。训练时视频、动作、语言共同提供监督；**推理时关闭视频生成**，语言与动作仍同步生成。

### 2.2 语言生成与记忆闭环

- 语言分支使用离散语言扩散：训练时按扩散时间步随机替换部分真实文本 token，再预测正确 token，并以交叉熵训练。
- 输出语言包含“下一步做什么”的子任务，以及“已经做了什么”的文本记忆。对于依赖记忆的任务，这段语言会在下一控制步骤重新输入模型，作为内部工作记忆。
- 论文还使用两种辅助记忆机制：
  - **视觉记忆**：输入一张或多张过去关键帧；实验中通常采用任务开始时的单张锚定帧。
  - **任务完成信号 β**：随动作一起预测，在子任务完成时触发，用来控制何时更新文本记忆，避免每一步都重写历史状态。
- 这使模型能够分别表达“下一步做什么”“已经完成什么”和“何时提交一个子任务完成”。

### 2.3 带校正的流匹配（FMC）

- 对动作流匹配，常规训练将干净动作 \(x_0\) 与噪声 \(\epsilon\) 线性插值，在时间 \(t\) 得到噪声样本，目标速度为 \(\epsilon-x_0\)。
- FMC 在训练中以一定概率给干净动作额外加入扰动 \(\epsilon_1\)，构造受扰动轨迹；随后监督模型预测一个校正速度，使受扰动样本在反向去噪一步后回到干净轨迹附近。
- 论文给出的校正目标为：
  \[
  v_{\text{corr}}=(\epsilon-x_0)+\frac{1-t}{\Delta t}\epsilon_1
  \]
  第一项是标准流匹配速度，第二项用于抵消动作扰动。校正分支只在较高扩散时间启用，以限制校正幅度。
- FMC 的目标是让模型学会从动作轨迹偏差中恢复；它不增加推理阶段的采样步数、额外条件或模型容量。

- UniWALM 使用单张初始锚定帧和生成的文本记忆；Mem-0 的带关键帧结果使用其相应配置。

### 3.3 真实机器人任务

- 使用两台 Flexiv Rizon 机械臂与灵巧手，评估三项任务：Cube Pick&Place、Empty Container，以及记忆任务 Find the Item。
- 灵巧操作任务各进行 20 次测试，Find the Item 进行 18 次，共 58 次 rollout。
- 比较 π0.5、GR00T-N1.7、FastWAM、MolmoBot 和 UniWALM。
- Find the Item 中，物品会在中途被遮盖，机器人需要记住物品与位置的对应关系；该实验不使用锚定帧，记忆主要来自模型自身生成并重新输入的文本。

## 4. 资源与算力

- MolmoSpaces 主实验的训练使用 **12 个 H200 节点，每节点 8 张 GPU**，共 96 张 H200，训练约 **44 小时**；使用 8-bit AdamW。
- RMBench 专门模型训练使用 **10 个 H100 节点**，约 **36 小时**，批量大小为 448，训练 100k 步。
- 论文还报告主要配置包含 221K 条 MolmoSpaces 混合轨迹、批量大小 3840、约 15k 步等信息；但不同实验配置并不完全相同。
- 推理速度方面，生成长度为 32 的动作块、采用 10 个去噪步骤时，未优化版本约为 **不带语言 76 ms、带语言 123 ms**。
- 论文没有在所给内容中明确提供完整训练能耗、总 GPU 小时、峰值显存或推理硬件配置，因此不能据此估算能耗或部署成本。

## 5. 实验数量与充分性

- **主评测覆盖**：MolmoSpaces 约 5 项任务、RMBench 4 项记忆任务、真实机器人 3 项任务；总计涉及多种仿真与现实场景。
- **消融实验**：
  - Pick&Place 上比较基础模型、加入语言、再加入 FMC、再加入 LoRA 的 4 种配置。
  - RMBench Press Button 上比较语言记忆、视觉记忆、二者组合及不同训练步数，约 5 种配置。
  - FMC 在 2D 轨迹任务中比较 5 种配置，覆盖 7 类轨迹。
- **充分性评价**：任务类型较丰富，既有组合抓放、双臂灵巧操作，也有遮挡与试错导致的记忆需求；并且包含同骨干对照及模块消融，能为语言生成和 FMC 的作用提供一定证据。
- **公平性需要谨慎解读**：
  - UniWALM 与 FastWAM 的骨干和动作专家较接近，是较有价值的对照；但 UniWALM 还涉及语言分支、FMC、LoRA 等变化，主实验的性能差距不能全部归因于单一因素。
  - RMBench 中 UniWALM 和部分基线所用记忆配置并不相同；论文指出 UniWALM 只用单张锚定帧，但不同方法的模型规模、预训练数据与训练流程也不完全一致。
  - 真实 Find the Item 仅有 18 次测试，置信区间较宽；真实世界结果有较强说明力，但仍需要更多重复和场景验证。

## 6. 主要结论与发现

- 在 MolmoSpaces 上，UniWALM 的五项任务成功率分别为 **49.2%、51.0%、68.0%、70.8%、38.8%**。相较 FastWAM，平均提高约 **14.8 个百分点**；提升尤其集中在组合式放置任务。对两个短时抓取任务，UniWALM 则不如部分基线。
- 在 RMBench 记忆子集上，UniWALM 平均成功率为 **34.5%**，高于同骨干 FastWAM 的 **13.3%**；也高于 Mem-0 配备关键帧设置的 **28.5%**。不过 WLA-0 报告了更高的 **56.5%**，论文将其视为采用不同预训练和模块化流水线的系统。
- 真实 Find the Item 任务中，UniWALM 达到 **61.1%**，FastWAM 为 **11.1%**，MolmoBot 为 **33.3%**。结果支持文本记忆对该任务的重要性，但样本数较小，结论仍需更大规模验证。
- 消融结果显示，在 Pick&Place 子集上，加入语言、FMC、LoRA 后，成功率从基线的 **31.0%** 逐步升至 **41.0%**。RMBench Press Button 消融也显示，语言生成单独提供的记忆信号比单张视觉记忆更强，但两者结合并充分训练后效果更好。
- 总体而言，论文结果支持：联合语言生成可能同时提供任务层面的预测结构和跨步骤记忆，从而增强部分操作任务表现。

## 7. 优点

- **建模思路完整**：不仅将语言作为固定输入，而是把语言纳入与动作、视频共同学习和生成的统一表示。
- **记忆机制简单且可解释**：子任务、文本记忆和完成信号 β 各有明确作用；文本记忆能够被后续步骤重新读取。
- **对照与消融有针对性**：同骨干 FastWAM 对照、模块消融和记忆任务测试，帮助分析模型增益可能来自哪里。
- **兼顾仿真与真实机器人**：实验覆盖单臂、双臂、灵巧操作、遮挡记忆等不同情境，不只报告单一仿真任务。
- **FMC 不增加推理开销**：通过训练时的轨迹扰动与校正目标提高动作恢复能力，部署侧不需额外模型或采样步骤。

## 8. 不足与局限

- **真实世界验证规模有限**：Find the Item 只有 18 次测试；更多机器人、环境、任务和长期运行实验将有助于确认泛化性。
- **记忆能力仍较基础**：主要采用单张初始锚定帧和单一文本记忆字符串；多关键帧选择、超长任务记忆、跨回合记忆尚未充分验证。
- **动作执行仍会出错**：论文报告 β 的任务边界判断可能早触发或晚触发，例如按键次数多按一次；即使语言记忆正确，动作专家仍可能执行失败。
- **复杂抓取与杂乱场景仍是瓶颈**：论文明确指出复杂几何物体和拥挤场景会限制抓取精度。
- **推理延迟有应用限制**：带语言专家的动作块生成约 123 ms，可能不足以支持对高频闭环控制要求很高的场景。
- **归因仍不完全**：主结果同时受到语言生成、FMC、LoRA 和其他训练细节影响；尽管有消融，但并非所有因素都在所有 benchmark 上做了完整的交叉对照。
- **外推边界需留意**：UniWALM 的语言和动作专家从头训练，避免依赖预训练语言模型，但也意味着其语义能力和开放世界泛化范围仍需进一步测试。论文提出的“统一表示”是架构与训练目标上的设计主张，现有实验支持其有效性，但尚不能单独证明其内部表征具有更普遍的跨模态优势。
