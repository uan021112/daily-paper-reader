ROBOCODE: Learning Reusable Action Primitives for Robot
Manipulation
Xianyue Peng, Devi Amarsaikhan, Iman Soltani
Abstract
Recent robot manipulation policies commonly predict continuous action chunks directly from observations, without
explicitly modeling reusable structure in the action space. However, manipulation demonstrations often contain
recurring short-horizon motion patterns that are shared across tasks. We introduce ROBOCODE, which learns these
patterns through a shared soft-gated primitive action interface. Rather than assigning each action chunk to a single
discrete code, ROBOCODE represents it as a soft composition of multiple learned primitives, providing a flexible
intermediate representation of short-horizon actions. The primitive interface is learned from action chunks pooled
across multiple tasks and then frozen while task-specific state encoders are trained to map current state inputs into the
shared latent space.
Experiments on five ManiSkill manipulation tasks address three questions. First, the learned primitive interface
reconstructs action chunks with an average reconstruction MSE of 0.0187. Second, analysis of code activations
reveals structured code reuse across tasks. Third, ROBOCODE achieves the highest or tied closed-loop success rate
on all evaluated tasks, with an average success rate of 75.6%, compared with 68.8% for ACT and 41.6% for the
larger Diffusion Policy baseline. These results suggest that soft-gated primitive codebooks provide an effective and
interpretable intermediate action representation for robot manipulation.

Introduction
Robot manipulation is often modeled as a sequence of continuous actions. Across tasks, demonstrations repeatedly
contain short motion patterns such as reaching, lifting, placing, and pushing. This suggests that manipulation trajectories
may be better understood through reusable primitive structure rather than as independent action chunks.
This raises a question of action representation. Recent token-based robot policies discretize each action dimension
into bins [10], offering a simple interface but splitting coordinated actions into dimension-wise decisions. Task-level
commands and planning operators [1] provide semantic structure, but often require a large vocabulary of task-specific
actions, limiting generalization across tasks. Primitive-level representations offer a more compositional abstraction,
capturing reusable motion units while preserving coordination across action dimensions and time.
Prior work has explored reusable units for robot manipulation [17, 25, 12], including behavior segments, semantic
skill spaces, and discrete action modes. However, a single primitive may not be sufficiently expressive for a short action
chunk, since the chunk can contain multiple motion factors. Inspired by memory-augmented models [4, 23], we learn
primitive codes as entries in a shared primitive codebook and represent each chunk as a soft composition of multiple
entries.
We propose ROBOCODE, a two-stage framework for learning soft-gated primitive codebooks from robot demonstra-
tions. The first stage jointly learns an action encoder and a shared primitive action interface from multi-task action
chunks. The second stage trains task-specific observation-to-gate policies that use this frozen interface to generate
continuous action chunks for execution.
Our aim is to study whether soft-gated primitive codebooks provide an effective intermediate action representation
for robot manipulation. The method does not require manually designed primitives, task rewards, or task labels during
primitive learning; it discovers reusable action components directly from demonstrations. Our contributions are:
• We introduce a soft-gated primitive action representation that represents short-horizon manipulation actions as
compositions of multiple learned primitives, rather than direct continuous predictions or single-code assignments.
• The proposed two-stage framework learns a shared primitive action interface from pooled multi-task demonstra-
tions and reuses the frozen interface for task-specific closed-loop control.

Related Work
2.1
Imitation Learning for Robot Manipulation
Imitation learning has become a widely used paradigm for acquiring robot manipulation behaviors directly from expert
demonstrations. Many behavior-cloning policies formulate control around predicting a current low-level action from
the current observation. Implicit Behavioral Cloning (IBC) [3], for example, models state–action relationships through
an energy-based policy, providing an expressive alternative to explicit action regression. Perceiver-Actor (PerAct) [20]
predicts the next discretized 6-DoF action from language-conditioned 3D observations for multi-task manipulation.
BC-Z [6] extends behavior cloning to large collections of tasks through language- and video-conditioned policies; its
closed-loop policy executes the current predicted action while also incorporating future open-loop trajectory prediction
during training.
More recent methods increasingly model temporally extended actions directly. Action Chunking with Transformers
(ACT) [24] predicts sequences of future actions as chunks, reducing the effective prediction horizon for fine-grained
manipulation. Diffusion Policy [2] models action sequences through conditional diffusion and supports receding-
horizon execution. Temporally extended action prediction has further scaled to generalist robot policies: Octo [21]
learns from diverse robot embodiments and tasks, while RDT-1B [15] employs a diffusion Transformer to model
complex action distributions for bimanual manipulation.
Together, these developments expand imitation learning from current-action prediction toward joint modeling of
temporally extended robot behavior. Beyond predicting such behaviors, a related line of work investigates whether
recurring structure within manipulation trajectories can be captured and reused through motion primitives and skill
abstractions.
2.2
Motion Primitives and Skill Learning
Motion primitives and skill abstractions organize robot behavior into reusable units between task objectives and
low-level control. Hierarchical manipulation approaches decompose multi-phase tasks into reusable skills and learn
their selection and adaptation across different phases [11]. Other methods define primitives around physical interaction
structure. Tactile Dexterity [5] combines manipulation primitives with tactile feedback for contact-rich manipulation,
while HACMan++ [7] introduces spatially grounded parameterized motion primitives that combine discrete primitive
selection with continuous grounding and execution parameters. Motion primitives have also been integrated with
planning and reinforcement learning [8].
Recent approaches increasingly learn reusable behavioral units directly from demonstrations or experience.
DexSkills [17] segments long-horizon manipulation demonstrations into skills using multimodal sensory information.
XSkill [22] discovers cross-embodiment skill prototypes from unlabeled human and robot manipulation demonstrations
and transfers the learned representations to robot control. Mao et al. [16] learn reusable manipulation mechanisms
from demonstrations and self-play that can be compositionally integrated into task-and-motion planning. Recent
methods further explore semantic and hierarchical manipulation abstractions [25, 14] and object-centric interaction
primitives [18].
These methods differ substantially in what constitutes a reusable behavioral unit, ranging from parameterized
motion primitives to segmented, semantic, and cross-embodiment skills. They nevertheless share the broader objective
of capturing recurring structure that can be reused across manipulation behaviors. A further question is how such
reusable structure participates directly in policy learning and action generation.
2.3
Structured Action Representations and Codebooks
Recent approaches increasingly incorporate structure into the intermediate representations through which policies
generate robot actions. OpenVLA [9] discretizes individual continuous action dimensions into tokens for autoregressive
prediction. FAST [19] instead encodes temporally extended action sequences into compact discrete tokens through
2


frequency-domain transformation and compression. PF-DAG [12] separates coarse and fine action generation by
representing action chunks through discrete coarse modes followed by mode-conditioned continuous action generation.
Learned codebooks provide another mechanism for placing reusable structure within the action-generation process.
STAR [13] learns reusable robot skill abstractions through residual vector quantization and models dependencies among
the resulting skill representations for action generation. In these approaches, structured representations serve not only
as descriptions of robot behavior, but also as intermediate variables through which low-level actions or action sequences
are generated.
ROBOCODE similarly places reusable structure within the action-generation interface, but adopts a continuous
soft-compositional representation. Inspired by memory-augmented representation models [4, 23], we treat learned
codebook entries as primitive codes and use similarity-based gates to activate multiple entries simultaneously. Their
weighted combination forms a continuous latent representation that is decoded into an action chunk. As illustrated in
Fig. ??, the primitive codebook therefore acts as a shared intermediate action interface between observation-conditioned
policy learning and continuous action-chunk generation.

Closed-Loop Execution
During inference, ROBOCODE operates in a receding-horizon manner. Given the current state input xm
t , the task-
specific state encoder produces ˆzm
t , and the frozen primitive interface converts it into a predicted action chunk ˆum
t . The
controller executes only the first part of the length-H chunk before observing the environment again and replanning.
This allows temporally extended action chunks to be executed with closed-loop feedback.
5
Experiments
We evaluate ROBOCODE on multi-task robot manipulation. Specifically, we ask three questions: (i) whether action
chunks can be reconstructed through a shared primitive codebook, (ii) whether the learned codes capture reusable
motion patterns across tasks, and (iii) whether the resulting policies improve closed-loop control.

5.3
Closed-Loop Evaluation
We evaluate ROBOCODE, ACT, Diffusion Policy, and DP-Large in closed-loop ManiSkill environments. ROBOCODE
follows a receding-horizon execution scheme. At each decision point, the task-specific state encoder maps the current
state input into the shared latent space, and the frozen primitive interface converts the resulting representation into
a length-H action chunk. The controller executes the first eight actions before observing the environment again
and replanning. All methods are evaluated under the same episode initialization protocol, task-success criteria, and
maximum episode horizon of 50 environment steps.
We report three complementary metrics in Table 4. Success rate measures the reliability of task completion and
serves as the primary metric. Average return is computed over all evaluation episodes and provides an auxiliary
indication of partial task progress, including unsuccessful trials. Because accumulated return depends on the task
reward, episode duration, and termination behavior, it should not be interpreted as a direct measure of execution
efficiency. Steps to success are therefore reported separately and averaged over successful episodes only.
ROBOCODE achieves the highest or tied success rate on all five tasks. Its average success rate is 75.6%, compared
with 68.8% for ACT, 41.6% for DP-Large, and 18.8% for the compact Diffusion Policy. The clearest advantage over
ACT occurs on LiftPegUpright, where ROBOCODE improves success from 56% to 80%. It also improves PickCube
from 86% to 92%, while achieving results comparable to ACT on PokeCube and StackCube and tying ACT at 98% on
PushCube. These results show that ROBOCODE remains competitive with a substantially stronger ACT baseline while

Increasing the Diffusion Policy capacity produces a consistent improvement in success rate across all five tasks.
DP-Large raises the average success rate from 18.8% to 41.6%, with particularly large gains on PickCube, PushCube,

DP-Large remains below ACT and ROBOCODE on every task, suggesting that model capacity alone does not close the
performance gap.
The average-return results provide a complementary view of task progress. ROBOCODE achieves the highest return
on PickCube, PokeCube, and StackCube, while ACT obtains the highest return on LiftPegUpright and the compact
Diffusion Policy obtains the highest return on PushCube. In particular, ROBOCODE and ACT both achieve 98%
success on PushCube despite having lower average returns than the diffusion baselines. This discrepancy illustrates that
accumulated return is affected by task-specific reward shaping, episode duration, and termination behavior, and should
therefore be treated as a supplementary metric rather than a monotonic measure of policy quality.
Steps to success further separate reliability from execution speed. ROBOCODE requires the fewest steps on
PickCube, PushCube, and StackCube, while DP-Large is fastest on PokeCube and the compact Diffusion Policy has
the lowest conditional average on LiftPegUpright. These averages are computed only over successful episodes and
should be interpreted together with success rate; for example, the compact Diffusion Policy succeeds on only 14% of
LiftPegUpright episodes. Overall, ROBOCODE provides the strongest average completion reliability while maintaining
competitive execution efficiency.
6
Conclusion
We presented ROBOCODE, a two-stage framework for learning reusable primitive action structure from multi-task robot
demonstrations. Stage 1 jointly trains an action encoder and a shared primitive action interface that represents action
chunks through soft compositions of learned primitive codes. Stage 2 freezes this interface and trains task-specific
state encoders to map current observations into the shared latent space. Experiments on five ManiSkill manipulation
tasks show that the learned interface reconstructs action chunks accurately and exhibits structured code reuse across

tasks. ROBOCODE achieves the highest or tied success rate across all five tasks, with an average success rate of 75.6%,
compared with 68.8% for ACT and 41.6% for DP-Large. These results support soft-gated primitive codebooks as an
effective and interpretable intermediate action representation for robot manipulation.
The current evaluation is limited to simulation, leaving open the question of how the learned primitive interface
transfers under real-world perception, dynamics, contact, and control uncertainty. Moreover, because the task-specific
state encoders are trained by offline imitation learning, closed-loop execution may encounter state distributions that
differ from those in the expert demonstrations, leading to compounding prediction errors. Future work may address
these sim-to-real and distribution-shift challenges through domain randomization, interactive data collection, and
reinforcement-learning-based policy refinement.
