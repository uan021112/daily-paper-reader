## 摘要
我们提出一种系统，可将稀疏的多视图渲染结果整合为一张连贯的纹理图像，为在几何处理流程中集成图像生成生成模型提供了一个框架。给定一个具有纹理图集的三角网格，以及一组附带相机参数的渲染图像，我们按以下步骤生成纹理图像：（1）将渲染图像反向投影到网格上，得到颜色归一化且带有置信度的纹理图像；（2）在网格上求解光流场，使各图像中的颜色相互对齐，并将相应的置信度纳入考量；（3）采用梯度域拼接，将对齐后的颜色融合为一张纹理图像，同时再次纳入置信度。我们的方法补充了现有的多视图图像生成技术，利用基于网格的光流和纹理空间拼接。由此，我们解决了这样一个难题：现代图像生成流程虽然能够生成极具真实感的渲染结果，却难以保证不同视角下渲染结果的一致性。代码可在 https://github.com/hliuw/TextureConsolidation 获取。

## Abstract
We present a system for consolidating a sparse set of multi-view renderings into a single coherent texture image, providing a framework for integrating generative models for image generation within the geometry-processing pipeline. Given a texture-atlased triangle mesh and a set of renderings with associated camera parameters, we generate the texture image by: (1) back-projecting the renderings onto the mesh to obtain texture images with normalized colors and confidences; (2) solving for flow-fields on the mesh that align the colors to each other, taking into account the associated confidences; and (3) fusing the registered colors into a single texture image using gradient-domain stitching, again incorporating confidences. Our approach complements existing techniques for multi-view image generation, leveraging mesh-based optical flow and texture-space stitching. In doing so it addresses the challenge that while modern image generation pipelines generate highly convincing renderings, they struggle to produce renderings that are consistent across views. Code is available at https://github.com/hliuw/TextureConsolidation.
