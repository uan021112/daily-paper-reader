## 摘要
近期三维重建的进展已从逐场景优化发展到前馈推理，语义场景理解也紧随其后——然而现有方法仍局限于以对象为中心的感知，忽视了对象之间的空间关系。我们将3D空间关系分割形式化为一种前馈、无需位姿的多视图设置：给定一个由视觉指定的主体和一个关系文本查询，模型跨视图分割出目标，而无需接收其类别名称。为此，我们提出RelationVGGT，一种新颖的前馈框架，它融合来自视觉基础模型的语义特征与来自3D几何基础模型的几何感知表示，并利用关系Transformer进行以主体为条件的跨视图关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们提供了一个基于ScanNet++、利用VLM和LLM的全自动标注流程，从而能够为这一新任务可扩展地生成训练数据。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与研究动机

- **背景趋势**：3D 重建已从逐场景优化（NeRF、3DGS）走向前馈推理（DUSt3R、VGGT、Pi3）；语义场景理解也沿此路径演进（LangSplat、OpenGS、PanSt3R、Uni3R），但仍以**物体中心感知**为主，把场景视为孤立实体的集合。
- **被忽视的能力**：真实场景理解依赖物体间的空间关系（显示器放在桌上、杯子在键盘旁），这是空间问答、具身智能体行动的核心能力。
- **任务定义**：提出 **3D 空间关系分割**（feed-forward、pose-free 多视图设定）。输入为多视图图像、参考视图中的**主体掩码** $M^s$、以及关系文本查询 $q$（如 "resting on"）；要求在所有目标视图中一致地分割出满足该空间关系的**目标物体**，且**不提供目标类别名称**。
- **与已有工作的差异**：
  - RelationField 在辐射场上学习物体间关系，但需**逐场景优化 + 已标定相机位姿**，依赖显式体积重建，泛化性受限。
  - 视频-语言模型（VideoLISA、SA2VA、UniPixel）无 3D 场景表示，大视角变化下难以维持物体对应。
  - 3D 指代分割（ReferSplat、MVGGT）用文本描述目标（含类别/属性），而本文仅给主体掩码 + 关系，目标身份需从"主体–关系"对中推断。
- **核心观察**：体积式关系搜索是不必要的——给定参考视图主体掩码后，可把目标定位改写为**目标视图图像网格上的逐像素关系预测**问题。

## 2. 方法论

### 2.1 核心思想
将关系建模函数从 $g_\theta(x,z)\to r$（3D 坐标对）改写为逐视图关系特征图 $R_t=\{r_t(u)\mid u\in I_t\}$，学习 $f_\theta(I_r, M^s, I_{tgt}, u)\to R_t$，再通过特征–文本相似度做开放词汇分割，从而**无需体积搜索、无需场景特定 3D 场、无需位姿**。

### 2.2 特征提取（双流融合）
- 语义流：DINOv2 密集 patch 特征 $E^D_n$（物体级语义）。
- 几何流：Pi3 编码器在预测头**之前**的 token $E^P_n$（保留多视图几何信息）。
- 二者按通道拼接，经 Input Mixer（线性投影 + 带 RoPE 的 Transformer 块）得到联合 token $F_n \in \mathbb{R}^{P\times d_f}$，$P$ 为 patch 数。

### 2.3 主体条件的关系推理
- **主体表示**：不做池化，保留参考视图全部 patch token 并用下采样掩码置零非主体 patch：$F^s_r = \bar{M}^s \odot F_r$，以保留主体的空间布局与细粒度语义。
- **序列构建**：所有目标视图 token 堆叠为 $Z^0$。
- **关系 Transformer**：交替执行
  - 主体条件交叉注意力 $\bar{Z}^\ell = \mathrm{CrossAttn}^\ell(Z^\ell, F^s_r)$
  - 全局自注意力 $Z^{\ell+1} = \mathrm{SelfAttn}^\ell(\bar{Z}^\ell)$
  使表示同时具备主体条件性与多视图一致性。
- **掩码解码**：用 DPT head 上采样为像素对齐的关系特征图 $R_t = \mathrm{Dec}(Z^L_t)$，对齐语言嵌入空间。

### 2.4 3D 几何与推理
- 用 Pi3 point decoder 预测点图与置信度图，使每个 $r_t(u)$ 关联到对应 3D 点，得到置信度感知的 3D 关系表示。
- 推理：$z_t(u;q) = r_t(u)^\top e(q)$，$S_t=\sigma(z_t)$，固定阈值 $\tau=0.3$ 二值化；实证发现**无需负提示归一化**（无需 softmax）。

### 2.5 训练目标（多查询监督）
- 空间关系常有多义表达（"standing on" = "on" = "supported by"），故对同一目标掩码用多个兼容查询独立监督。
- 多查询 sigmoid focal loss（$\alpha=0.75,\gamma=1.5$，对像素与查询双重平均）+ Dice loss：
  $\mathcal{L}_{mask}=w_{focal}\mathcal{L}_{multi\text{-}q\,focal}+w_{dice}\mathcal{L}_{dice}$。

### 2.6 自动化标注流程（基于 ScanNet++）
- 初始化场景图（实例为节点、边为空）；将实例掩码投影到已定位 RGB 帧，用 **Set-of-Mark** 提示查询 VLM（Qwen3-VL-8B）获取逐帧有向关系提议。
- **多视图一致性过滤**：同一物体对需至少 $K=3$ 帧一致预测才保留，并传播到所有共视帧。
- **几何过滤**：基于 3D 包围盒与实例质心，剔除包围盒不重叠且质心过远的物理不合理关系。
- **LLM 改写**：用 GPT-5.2 对通过验证的三元组做同族改写，提升查询词汇多样性。

## 7. 主要贡献与创新点

- **任务层面**：首次形式化 **前馈、无位姿、开放词汇的 3D 空间关系分割**，把"给定主体 + 关系文本 → 跨视图目标分割"作为独立问题提出，区别于需要类别名的 3D 指代分割与需要逐场景优化的关系场方法。
- **方法层面**：
  - 提出将体积式关系搜索**降维为逐视图逐像素关系预测**的核心观察，规避了显式 3D 场与位姿依赖。
  - 设计**双流（DINOv2 语义 + Pi3 几何）融合 + 主体条件关系 Transformer + DPT 关系特征图**的架构，兼顾物体级语义与多视图几何一致性。
  - 引入**多查询监督**与**置信度感知 3D 关系表示**，缓解空间关系表达的多义性。
- **数据层面**：构建基于 ScanNet++ 的**自动化场景图关系标注流程**（VLM 提议 + 多视图一致性过滤 + 几何过滤 + LLM 改写），产出 900 场景训练集与 3 个 benchmark（共 119 条查询、28 个谓词），为该方向提供可复用资源。

- **评测规模有限**：benchmark 总查询量（119 条）与部分子集（LERF 3 场景、主体不可见 23 视图）偏小，主结果缺少误差棒与显著性检验，统计效力受限。

- **潜在方向**：扩展到更丰富的关系谓词体系、引入时序/交互关系、与具身智能体的下游任务（空间问答、操作规划）闭环验证、降低对主体掩码质量的依赖。

## 9. 总体评价

RelationVGGT 的核心价值在于**问题重构**：通过"主体掩码 + 关系文本"的设定，把 3D 空间关系理解从依赖显式重建与位姿的范式，转为前馈、开放词汇的逐像素预测，并以 3D 几何基础模型主干保证跨视角一致性。实验在三个数据集、多类基线与多组消融/鲁棒性测试上显示出稳定优势，尤其对主体掩码来源与谓词改写具备实用性鲁棒性；语义改变谓词的对照实验进一步证明模型确实建模了关系语义而非视觉捷径。主要不足在于评测规模偏小、部分比较输入不对等、缺少统计显著性，以及标注与训练成本披露不完整。整体上，该工作为**关系感知的前馈 3D 场景理解**提供了清晰的任务定义、有效的方法与可复用的数据管线，是该方向有代表性的推进。
