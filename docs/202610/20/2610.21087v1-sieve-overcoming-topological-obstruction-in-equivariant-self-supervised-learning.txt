Abstract
We identify a theoretical incompatibility between 3D point cloud masked autoen-
coding and SE(3)-equivariant networks. We prove that standard masking triggers
a topological collapse, effectively forcing the model to hallucinate orientation
without a reference frame. To resolve this, we introduce SIEVE (Scalar Invariant
Extraction Via Equivariance), an SE(3)-equivariant self-supervised framework that
compresses point cloud geometry into invariant scalar embeddings. At its core
is the spherical projection mask, which preserves global pose while obfuscating
local semantics, sidestepping the obstruction by construction. Experiments con-
firm that SIEVE circumvents the predicted collapse where constant and noise
masks fail. On downstream point cloud tasks, the resulting embeddings improve
over coordinate-based baselines and hand-crafted geometric descriptors, with the
largest gains on generalization to unseen shape categories. Code is available at
https://github.com/voltwin-dev/SIEVE_NeurIPS26

Introduction
Point clouds serve as the fundamental data structure for 3D understanding in various domains,
including robotics [18] and autonomous driving [6]. Unlike 2D images, where position (the pixel
grid) and content (RGB values) are naturally disentangled, point clouds present a unique challenge:
the geometry is the feature. The coordinate x ∈R3 encodes both the local structure and the global
spatial location. This entanglement necessitates representations that are not only topologically rich, a
goal also pursued in graph representation learning [12, 13], but also consistent under global rigid-body
transformations.
This separation naturally motivates the use of SE(3)-equivariant neural networks, whose architectures
are constrained to ensure that a rigid-body transformation applied to the input results in an identical
transformation of the output [3–5, 16, 39]. However, because these models cannot rely on absolute
coordinate “shortcuts” [43, 47], they often face more difficult optimization landscapes than their
non-equivariant counterparts [49]. We propose self-supervised learning (SSL) as the path forward:
the equivariant pipeline can distill geometric structure into SE(3)-invariant embeddings that enrich
downstream representations, sidestepping the need to impose equivariance on the downstream model.
However, we identify a fundamental theoretical flaw when applying standard masking strategies
to SE(3)-equivariant neural networks. Conventional SSL methods replace masked features with
a learnable, isotropic token [24, 32, 50]. Utilizing the theory of pullbacks of vector bundles, we
demonstrate that the use of such constant tokens induces a topological obstruction, leading to a
collapse in the vector pipeline that inhibits the reconstruction of the input point cloud. We empirically

To resolve this, we propose the equivariant SSL framework SIEVE (Scalar Invariant Extraction Via

masking scheme is a direct consequence of our vector bundle analysis: it materializes the pullback of
non-trivial vector bundles that standard masking cannot reconstruct. We validate these embeddings
on several downstream point cloud tasks, where SIEVE improves over coordinate-based baselines
and hand-crafted descriptors with the largest gains appearing on generalization to unseen categories.

Theoretical Framework
2.1
Preliminaries: Vector Bundles
Effective analysis of properties of 3D point clouds rests upon understanding entanglement between
position and content. For this purpose, we seek suitable mathematical concepts or frameworks that
encompass both topological features of 3D point clouds as well as contents measured over such point
clouds as real vectors. We pay particular focus on using vector bundles from algebraic topology
among many possible candidates that can harbor the subtlety of analyzing such entanglements.
Definition 2.1. Let X be a topological space. An n-dimensional vector bundle π : V →X is a
topological space satisfying the following conditions. (1) The map π is a continuous surjection.
(2) For every x ∈X, the fiber π−1(x) is isomorphic to Rn. (3) For every x ∈X, there exists an
open neighborhood U ⊂X such that satisfies the following three conditions. (3a) There exists a
homeomorphism φ : U × Rn →π−1(U). (3b) For every v ∈Rn, we have π(φ(x, v)) = x. (3c)
Every isomorphism Rn →π−1(x) can be rewritten as an invertible n × n real matrix.
Interested readers may refer to Appendix A.1 for a detailed motivation for using the notion of vector
bundles to formulate strengths and capabilities of deep learning algorithms. Given a vector bundle
π : V →X, a continuous function f : X →V such that π(f(x)) = x for every x ∈X is called a
global section. With these definitions, we propose the following topological reformulation of 3D

point clouds, up to some perturbations or negligible errors. (1) 3D point clouds correspond to points
on a smooth compact orientable 3-dimensional manifold Y embedded inside R3, whose boundary
X := ∂Y is a smooth compact orientable surface embedded inside R3. (2) Because 3D Point clouds
consist of discrete set of points, we may require all the point clouds to lie over a complement of a
small tubular neighborhood of the wedge sum of some circles ∨g
i=1S1 inside Y , where g is the genus
of X. Such a space, denoted as Y ′, is homotopy equivalent to X × I. (3) Measurements consisting
of n-dimensional feature vectors over each point cloud x ∈Y ′ corresponds to global sections of an
n-dimensional vector bundle V →Y ′.
It is natural to understand vector bundles that can harbor non-trivial entanglements between geometry
and intrinsic semantics which 3D point clouds contain. This brings us to the notion of trivial vector
bundles over topological spaces.
Definition 2.2. Let X be a topological space. An n-dimensional trivial vector bundle V →X is
a vector bundle over X which is isomorphic to the vector bundle X × Rn →X. Any continuous
function f : X →Rn is a global section of the trivial vector bundle.
The geometry of X does not impose any restrictions on the image of the global section f : X →Rn.
We hence obtain the following insight: trivial vector bundles over topological spaces are suitable for
analyzing data whose position and content are disentangled. We also observe that vector bundles over
topological spaces which are non-trivial are potential candidates that can illuminate entanglements
between geometry and intrinsic semantics of 3D point clouds. In light of these insights, we ask the
following question: What are effective ways to learn global sections of real oriented non-trivial
vector bundles over a given topological space Y (or Y ′)?
2.2
Interpretation: Simplifications with Projections to S2 using Pullback of Vector Bundles
To understand the question, we analyze vector bundles over Y (or Y ′) that may be underlying spaces
for 3D point clouds. The problem of classifying real oriented vector bundles over smooth manifolds,
however, is a highly non-trivial problem. Nevertheless, we can construct some of these desired vector
bundles by using pullbacks of vector bundles between topological spaces.
Definition 2.3. Given a continuous map f : X →Y , and a vector bundle π : V →Y , the pullback
of V is the vector bundle f ∗π : f ∗V →X, where f ∗V := {(x, e) ∈X × V : f(x) = π(e)} . The
fiber of f ∗V at x ∈X is isomorphic to the fiber of V at f(x) ∈Y .
Without loss of generality, we consider an auxiliary (possibly unknown) n-dimensional vector bundle
VY →Y ′ underlying 3D point clouds, where n ≥3. Because Y ′ and X are homotopy equivalent,
there exists a bijection of isomorphism classes of vector bundles of Y ′ and X (see Corollary 1.8
of [23]). Hence, we can identify the n-dimensional vector bundle VY →Y ′ with an n-dimensional
vector bundle VX →X. (This is one of the reasons why we chose Y ′ instead of Y , because we may
reduce the dimension of the underlying topological space of our interest from 3 to 2.)
We can use pullbacks of vector bundles to construct trivial and non-trivial vector bundles over X.
Given any continuous map f : X →S2, we can pullback some n-dimensional vector bundle V →S2
to construct a vector bundle f ∗V →X. Thankfully, the classification of real oriented vector bundles
over S2 is very well understood, whose proof is in Appendix A.2.
Theorem 2.4. Let V →S2 be a real oriented vector bundle of dimension n ≥3. Suppose V is
a non-trivial vector bundle, i.e. V contains the tautological bundle πt : T →S2 as a sub-vector
bundle (see Appendix A.2 for its definition). Then V is isomorphic to the unique non-trivial vector
bundle of dimension n, whose fibers are isomorphic to Rn−2 ⊕π−1

There are two isomorphism classes of vector bundles over X we can construct using pullback of
vector bundles of S2: the trivial vector bundle X × Rn →X, obtained as a pullback of the trivial
vector bundle S2 × Rn →S2, and a non-trivial vector bundle VX →X, obtained as a pullback of
the unique non-trivial vector bundle V →S2.

With the theoretic framework in place, we shall analyze potential topological obstructions imposed
on certain masking functions. Given an integer N, let m : X →RN be a masking function that
does not lift to a section of a non-trivial vector bundle VX →X. As an example, we may consider
constant and randomized masking functions, which are default choices for reconstruction based SSL
in both images and point clouds. We note that the image m(x) is chosen randomly independent of
the geometric features of x. We can hence interpret the application of the masking function m as
replacing VX with RN × X. Because the trivial vector bundle over X is the pullback of the trivial
vector bundle over S2, the masking operator by m corresponds to replacing VX with f ∗(RN × S2).
There is a wide class of non-trivial vector bundles over X which may not admit a smooth embedding
inside f ∗(RN × S2). A summary of our aforementioned findings, focusing on constant masking
functions, leads to the following result, whose proof is in Appendix A.3.

m cannot effectively approximate global sections of any non-trivial vector bundles V ′

3
SIEVE: Scalar Invariant Extraction Via Equivariance
To circumvent the topological obstruction stated in Theorem 2.6, we propose SIEVE, an SSL
framework that utilizes the spherical projection mask to maintain a continuous section in the vector
bundle, thereby ensuring the representational completeness of the equivariant pipeline. SIEVE adopts
a framework inspired by the Masked Autoencoder (MAE), comprising an encoder, a geometric
masking operator, and a decoder [24]. The framework is based on two core design principles.
Equivariant Feature Streams. We leverage SE(3)-equivariant neural networks to process the data
through two streams: a vector pipeline and a scalar pipeline (Figure 2). The encoder maps the
input point cloud X to an SE(3)-invariant scalar embedding scode, capturing semantic information
independent of the point cloud’s global pose.
Semantic-Geometric Decomposition. Unlike standard MAE, which masks a subset of nodes entirely,
SIEVE employs a spherical projection mask. This operator maps all the points in X to a unit sphere,
obfuscating local semantic features (the “what”) while preserving global spatial properties such as
orientation and position (the “where”). This sidesteps the topological obstructions of constant or
randomized vector masks, admitting a wider range of geometric entanglements for reconstruction.

3.4
A Mathematical Reformulation of SIEVE
Using the theoretical motivation for SIEVE, we deduce theoretical strengths of our proposed method
in comparison to other masking schemes, whose proof is in Appendix A.4.
Theorem 3.1. Let Y ′ be the underlying 3-dimensional smooth orientable manifold constructed from
Section 2.2. Then SIEVE can approximate global sections of any vector bundles which are isomorphic
to pullbacks of any vector bundles of S2.
The idea of the proof originates from an observation that application of SphericalMask corresponds
to utilizing pullback of vector bundle V →S2 which contains the tautological bundle T →S2 as a
vector sub-bundle. We thus deduce that SIEVE, unlike constant or random masking techniques, has
theoretical capabilities in approximating all possible vector bundles over a wide range of classes of
2-dimensional or 3-dimensional closed oriented manifolds which arise from pullback of both trivial
6


and non-trivial vector bundles over S2. To support this, we present experimental demonstrations of
SIEVE’s theoretical capabilities in Section 4.2.

4.2
Empirical Verification of Collapse
In Section 2, we theoretically established that SE(3) equivariant networks cannot output two point
clouds of different topology with a constant or noise vector token as input. To verify this, we perform
an experiment using a synthetic dataset of two objects with differing topologies: a solid cuboid
(homeomorphic to the 3-disk D3) and a square toroid (homeomorphic to S1 × S1). The dataset
consists of 120 instances per class, partitioned into a 100/20 train-test split. Failure on a dataset this
simple indicates a fundamental representational issue rather than a capacity or data limitation.
To demonstrate that this limitation is inherent to the equivariance constraint rather than a specific
architecture, we evaluate two distinct backbones: GATr [5] and SE(3)-Transformer [16]. We compare
three masking strategies: a constant vector mask utilizing a learnable isotropic token, an ellipsoid
noise mask sampled from an ellipsoid spectrally aligned with the point cloud’s principal components
(and thus is SE(3)-equivariant), and our proposed spherical projection mask. All three models use
identical initialization and hyperparameter settings to ensure a fair comparison.

4.3
Downstream Tasks
This section evaluates whether scode contains useful, transferable geometric information. We do
not target SOTA on any specific benchmark, as SOTA architectures are heavily tuned to their target
tasks. Instead we test whether SIEVE consistently improves generalist point cloud architectures
(PointNet++, DGCNN [37, 45]). Integration is minimal: the SIEVE encoder is frozen, and scode is
concatenated with the raw coordinates at the input layer. This drop-in usage is enabled by SIEVE’s
node-level granularity, which aligns one-to-one with input points, unlike patch-based SSL. We
therefore evaluate on downstream tasks where such granularity is critical.
4.3.1
Molecular Segmentation
We first evaluate the learned representations on the molecular segmentation task which consists of
640 RNA molecules segmented into 120 categories [36]. Following the protocol in [21] we resample
each mesh to 2048 points and utilize the standard 80-20 train test split.
To demonstrate that SIEVE embeddings transfer across architectures, we evaluate with three distinct
architectures: PointNet++ [37], DeltaNet [46], and DiffusionNet [40]. For each model, the frozen
SIEVE scalar embedding scode is concatenated with the raw node coordinates xi as input. We compare
our learned representation against two SE(3)-invariant geometric representations: the distance from
mean r and curvature κ1, κ2. As shown in Table 1, SIEVE embeddings consistently outperform the
“position-only” baselines and the geometry-enhanced models across all three architectures.

4.3.3
Geometric Registration
Geometric registration is the prediction of a rigid body transformation to align one shape to another.
We follow the task and architecture in Deep Closest Point (DCP) [44]. A point cloud is sampled from
the ModelNet40 dataset [48], which is then cloned, point order shuffled, then transformed with a
random rigid body transformation. We embed the SIEVE embeddings to DCP baseline and test with
two train-test splits: one where all 40 categories are in both sets, and the other where 20 are used in
train and the other 20 are reserved for testing.
The results show that SIEVE embeddings improve both the shared and separate category registration,
with more dramatic gains in the separate category. The geometric registration performance with
SIEVE is much more robust to unseen objects. This pattern is consistent with the 3D-EPN results:
SIEVE embeddings encode intrinsic geometric structure that transfers across categories.

Conclusion
In this work, we theoretically established that conventional masking strategies in geometric self-
supervised learning induce a representational collapse when applied to SE(3)-equivariant architectures.
Using the theory of vector bundles, we showed that isotropic or randomized masking functions which
ignore innate geometric features of point clouds do not have enough capabilities to reconstruct such
point clouds, because they cannot effectively reconstruct a wide range of classes of non-isomorphic
vector bundles.
Based on these theoretical observations, we proposed SIEVE, a pioneering framework that bridges the
gap between equivariance and SSL for point clouds. By utilizing a novel spherical projection masking
strategy, SIEVE circumvented the topological obstructions inherent in isotropic masking, enabling
robust geometric reconstruction. Our experiments empirically confirmed the representational collapse
and demonstrated that SIEVE learns highly generalizable embeddings that outperform traditional
descriptors in downstream tasks. To our knowledge, SIEVE is the first framework to combine
self-supervised learning with SE(3)-equivariant networks for general point cloud geometry, and we
hope it spurs further work at this intersection.

over topological spaces.

A.1
Motivation for using vector bundles
We motivate the formulation of deep learning techniques as an approximator of global section of
vector bundles by utilizing insights from the main results of Park et al [33].
Universal approximation theorem: The classical formulations of universal approximation theorem
states that a feedforward neural network of arbitrary depth with non-polynomial activation function
can approximate any given continuous function f : Rm →Rn. Such an approximation theorem
ensures a neural network with arbitrary depth (or arbitrarily many weights and parameters) to find
any auxiliary relation among collections of datasets, as long as they embed in Euclidean space Rm.
However, such a formulation of the universal approximation theorem does not necessarily imply that
a neural network with arbitrary depth (or arbitrarily many weights and parameters) can find auxiliary
relations among collections of datasets defined over manifolds M which are not homeomorphic to
Rm. For example, given a manifold M with open affine charts {Uα}α∈A, a neural network can
approximate a continuous function fα : Uα →Rm for each α ∈A, but one cannot guarantee that
such a neural network will learn how to coherently glue such functions fα : Uα →Rm. In terms of
datasets associated to 3D point clouds, the functions fα : Uα →Rm correspond to measurements
taken over 3D point clouds which constitute a part of (but not all) underlying geometric space.
Using vector bundles: By using the notion of vector bundles (see Definition 2.1 for its definition),
we can reformulate the problem of gluing functions fα as follows. Given a vector bundle V →M,
each function fα : Uα →Rm corresponds to local sections of the vector bundle restricted to the
open affine chart Uα. Here, the term “local” means that the function fα is only well defined over
the neighborhood Uα, and it is not necessarily defined over M. One can construct a global section
f : M →V by ensuring that the collection of functions {fα}α∈A satisfy the condition that given any
two indices α, β ∈A, the restrictions of functions fα and fβ over Uα ∩Uβ are equal. By allowing
such a condition to hold, one extends the function from Uα to Uα ∪Uβ. Iterating the procedure for
all indices α ∈A allows us to construct the global section f : M →V .
Non-triviality of vector bundles: We note that the global section need not be a function f : M →
Rm. If a global section is given by a function f : M →Rm, then the vector bundle V →M is a
trivial bundle, i.e. V ∼= M × Rm. Otherwise, we say that the vector bundle V →M is non-trivial.
Such non-triviality of vector bundle implies that there are obstructions in naively gluing local sections
fα : Uα →Rm. These obstructions can be detected by computing topological invariants of vector
bundles, such as their homology or cohomology groups. Loosely speaking, a global section of a
non-trivial vector bundle can be thought of as of datasets whose measurements depend crucially on
their underlying geometric space (or an underlying manifold M). Meanwhile, a global section of a
trivial vector bundle can be considered as of datasets whose measurements can be well approximated
by classical deep neural networks without making significant reference to underlying geometric
space of the datasets. In particular, this observation hints that even if the measurements of 3D point
clouds defined over an underlying manifold M take values in Rm, we cannot guarantee that such
measurements can be continuously extended to a function f : M →Rm.
Strength of deep learning algorithms: We note that there are variants of universal approximation
theorem which regards approximating functions between differentiable manifolds with neural net-
works of arbitrary width and depth, see for example the work of Kratsios and Papon [26]. On the
other hand, deep learning algorithms of finite depth and width may not have enough capabilities to ap-
proximate global sections of any vector bundle V →M of a manifold. In light of this vein, the main
result of Park et al [33] (see for example Theorem 1.2, Sections 2 and 3) gives a presheaf/copresheaf
theoretic characterization of capabilities of message passing neural networks: they approximate global
sections of presheaf (and copresheaf) of continuous functions induced from direct sums of skyscraper
cosheaves (and respectively sheaves). The obstructions of these presheaves (and copresheaves) from
being sheaves (and cosheaves, respectively) can be utilized to explain limitations of a wide range of
classes of deep learning algorithms, such as non-unique gluing of local sections of such presheaves
(and copresheaves), and adversarial attacks.
Deep learning algorithms and vector bundles: Given that limitations of such deep learning
algorithms originate from obstructions of a presheaf (and copresheaf) from being a sheaf (and
respectively cosheaf), the paper hence calls for a need to design neural networks which are capable
of approximating global sections of sheaves (or cosheaves) other than the aformentioned classes of
presheaves and copresheaves. In particular, vector bundles over manifolds are examples of sheaves
14


over manifolds. A neural network which has capabilities to approximate global sections of vector
bundles over manifolds hence has potential to overcome limitations that other previously studied
deep learning algorithms may have experienced. We can ask a valid question on what isomorphism
classes of vector bundles V →M of a manifold a given neural network can approximate their
global sections. The capability that a neural network can effectively analyze dataset dependent on its
intrinsic geometry can be rephrased as the capability to approximate global sections of non-trivial
isomorphism classes of vector bundles over M. In turn, it implies that the neural network has
capabilities in detecting exotic underlying geometric features of a given dataset, and can perform on
par with or beyond other neural network algorithms.

A.5
Theoretical Limitations
Our theoretical results suggest that SIEVE is capable of approximating global sections of a wide range
of classes of non-trivial vector bundles over manifolds. Nevertheless, as similar to other state-of-the-
art techniques, SIEVE has some theoretical limitations, in that it does not guarantee outperformance
in analyzing datasets which are global sections of vector bundles which do not contain pullback of
tautological bundles as vector sub-bundle. For instance, there may be many non-trivial isomorphism
classes of vector bundles over manifolds which do not originate from pullback of non-trivial vector
bundles over S2. Further studies would be required to devise new neural networks which are capable
of approximating such global sections of nontrivial vector bundles.
B
Implementation Details
B.1
Pre-Training
Model Parameters: The backbone of pre-trained SIEVE is GATr, a model based on multivector
representations [5]. We embed the position of each node as a trivector inside the multivector.
The encoder comprises a 9-layer GATr with 16 multivector and 64 scalar channels. The input is
1 multivector and 1 scalar channel and the output is 1 multivector and 32 scalar channel. The
32-dimensional scalar output constitutes the SIEVE embedding scode. The encoder has 949,825
parameters.
The decoder is a 3-layer GATr with 16 multivector and 64 scalar channels. The input is 1 multivector
and 1 scalar channel and the output is a single-channel multivector and scalar output for coordinate
reconstruction. The decoder has 318,690 parameters.
Note that for variants of SIEVE trained with ShapeNet [8], the model parameters from Table 4 are
used.
Training Method: The model is trained for 10 epochs using the AdamW optimizer with a batch size
of 200. To accelarate training, bf16 quantization is used. We employ a cosine learning rate schedule
with a warm-up phase, reaching a maximum learning rate of 3 × 10−4. To stabilize training, we
apply gradient clipping with a maximum norm of 10. We train on a single Nvidia B200 GPU over 4
days. Memory consumption with a batch size of 200 is 154 GB.
Additional Techniques: Three distinct pre-training strategies have been tested on the smaller
ShapeNet dataset [8].
The first strategy utilizes simple position reconstruction as outlined in the main text, with pre-training
performed on a volumetric ShapeNet dataset. The standard deviation of the spherical projection mask
noise is σ = 0.02.
The second strategy is to reconstruct the normal vector and the curvature in addition to the position of
the node. The normal vector is the output multivector’s vector, and the curvature is the output scalar.
The reconstruction loss for this strategy is
L = L1(PredPos, Pos) + 10 · (1 −cos(PredNorm · Norm) + 5 · L1(PredCurv, Curv).
(16)
We use the surface ShapeNet dataset for this strategy, as neither curvature and normal vectors can be
defined in the interior.
The third strategy involves the application of a nearest-neighbor attention mask within the decoder.
To ensure the encoder extracts global embeddings, the decoder is forced to reconstruct the nodes
18


without local information by masking 70% of the nearest nodes during self-attention. This strategy is
implemented on a volumetric ShapeNet dataset.
As discussed in Appendix C.3 and Table 6, the third strategy of using a nearest-neighbor attention
mask yielded the best results. Therefore, the final OpenShape [30] pretrained SIEVE utilizes a nearest
neighbor attention mask with ratio 0.7 along with a spherical projection mask.

Mask Details: The constant mask is a single vector or multivector token that is applied uniformly
over all of the nodes. This token is trainable. The noise mask is a uniform sample of points on an
ellipsoid surface with semi-axes (2, 1, 0.5). The ellipsoid is centered at each point cloud’s centroid,
and the orientation is determined by PCA of the original point cloud: x-axis for the largest variance
direction, y-axis for the middle, and z-axis for the smallest. This ensures that the noise mask is also
an equivariant operator. The spherical projection mask is as described in Section 3.1, but no noise is
added to the projected position.
Training Method: Both models are trained with a simple L1 loss on predicted node positions. The
models are trained over 200 epochs, with a batch size of 4. We employ a cosine learning rate decay
that reaches a maximum learning rate of 3 × 10−4 after a 10% warm up period. To ensure numerical
stability, the gradients are clipped at a threshold of 10.0. No weight decay is applied.
B.3
Downstream Tasks
Each downstream task utilizes a domain specific architecture. For the 3D-EPN point cloud completion
task, we utilize PCN [51]; for the point cloud registration task on ModelNet40, we utilize DCP [44].
All downstream models use the hyperparameters specified in their original publications and official
implementations. The only modification made is to the input channel to accommodate the additional
32-dimension scode embeddings. The SIEVE embeddings are concatenated along with the position
as the input. The SIEVE encoder is frozen when used in a downstream task; we do not fine-tune
it. The RNA segmentation task and the geometric registration task use the OpenShape pretrained
encoder, and the 3D shape completion task uses the ShapeNet pretrained encoder with the "simple
noise" setting.
The added downstream task training time is a single forward pass through the frozen SIEVE encoder.
On the RNA segmentation task with PointNet++, memory increases from 2134 MiB to 2166 MiB,
and per-epoch time from 92s to 123s (+31s). On 3D-EPN with PCN, per-epoch time increases from 4
min 56s to 5 min 43 sec (+47s). The absolute overhead is comparable in both cases, so its relative
share falls as the downstream backbone becomes more expensive: 34% for PointNet++ against 16%
for PCN.
