## 摘要
我们提出 ReDT，这是一种前馈式视觉几何 Transformer，旨在将多视图重建扩展至高清（HD）输入。现有视觉几何 Transformer 通常在固定的标准清晰度（SD）分辨率下训练，面对高分辨率输入时，重建质量会下降，计算扩展性也较差。尽管近期的高效架构降低了帧间注意力的复杂度，但开销较大的帧内注意力和编码器注意力仍基本未得到解决，因此现有架构难以实现高清重建。ReDT 采用一种具备分辨率感知能力的架构来应对这两项局限，从而能够扩展至高分辨率输入。ReDT 的核心思想是：首先将每个视图映射为一组固定大小的基底 token，在紧凑且大小恒定的基底空间中计算对应关系，随后再将输出投影回原始分辨率，以进行稠密预测。通过在注意力计算过程中将内部表示与输入分辨率解耦，ReDT 大幅降低了高分辨率三维重建的计算成本，并提升了模型在各种分辨率下的性能。在涵盖 SD 至全高清（FHD，2K）的多个数据集上进行的大量实验表明，ReDT 在重建质量和计算效率方面均优于当前最先进的视觉几何 Transformer。例如，在 ETH3D（2K）数据集上，与 VGGT-Ω 相比，ReDT 实现了 16 倍加速、峰值 GPU 内存使用量降低 34%，以及倒角距离降低 33%。项目网站：https://redt.github.io。

## Abstract
We introduce ReDT, a feed-forward visual geometry transformer designed to scale multi-view reconstruction to high-definition (HD) inputs. Existing visual geometry transformers are typically trained at fixed, standard definition (SD) resolutions and exhibit degraded reconstruction quality and poor computational scaling to high input resolutions. While recent efficient architectures reduce the complexity of inter-frame attention, expensive intra-frame and encoder attention remain largely unaddressed, making HD reconstruction impractical with existing architectures. ReDT addresses both limitations with a resolution-aware architecture designed to scale to high-resolution inputs. The key idea of ReDT is to first map each view to a fixed-size set of basis tokens, compute correspondences in this compact constant-size basis space, and then project the outputs back to the original resolution for dense prediction. By decoupling the internal representation from input resolution during attention, ReDT substantially reduces the computational cost of high-resolution 3D reconstruction and improves model performance at all resolutions. Extensive experiments on multiple datasets spanning SD to FHD (2K) show that ReDT outperforms state-of-the-art visual geometry transformers in both reconstruction quality and computational efficiency. For instance, on the ETH3D (2K) dataset, ReDT achieves a $16\times$ speedup, a $34\%$ reduction in peak GPU memory usage, and a $33\%$ reduction in chamfer distance over VGGT-$Ω$. \href{https://redt.github.io}{Project Website.}

# 1. 核心问题与整体含义

- **研究背景**：前馈式视觉几何 Transformer（如 VGGT、VGGT-Ω）能够一次性处理多视图并预测三维几何，但通常在固定的标准分辨率上训练。输入分辨率提高后，模型不仅推理开销迅速增加，重建质量也可能下降。
- **主要瓶颈**：标准点积注意力的计算和显存开销随 token 数量近似二次增长。已有高效方法主要降低跨视图注意力的成本，却仍保留开销较高的编码器注意力和帧内注意力，因此没有解决高清输入下的整体扩展问题。
- **论文的核心主张**：模型的中间特征有效秩在不同分辨率和视图数量下大致稳定，意味着几何推理不一定需要在所有高密度空间 token 上直接进行。ReDT 据此把内部推理表示与图像分辨率解耦：每个视图先映射到固定数量的基底 token，在紧凑空间中推理，再将结果映射回空间 token，以支持稠密预测。

# 2. 方法论

## 2.1 整体流程

ReDT 在 VGGT 系列架构上作了三类改动：

1. **自适应可变尺寸 patch 编码**：依据图像局部信息量，压缩冗余区域、保留细节区域。
2. **DIVA（Discretization-Invariant Visual Attention）**：将空间 token 映射至固定规模的基底 token，在低维表示上进行注意力和对应关系推理。
3. **在紧凑空间中使用 TTT**：通过测试时训练（test-time training, TTT）更新跨视图推理过程，随后把特征投影回空间 token，供原有稠密预测头使用。

## 2.2 自适应 patch 编码

- 先在编码器原生 patch 网格上提取特征，并为每个 patch 计算图像空间熵。
- 使用类似四叉树的递归划分，将相邻低熵 patch 合并为更大的区域；高熵、细节较多的区域则保留较细的 patch。
- 因而生成的是**长度可变、空间支持范围不同**的 token 序列：信息密集处使用更多 token，冗余处使用更少 token。
- 合并后的特征进入 ViT 编码。对于后续稠密预测，模型将每个 token 广播回其对应空间区域，再经卷积平滑后输入 DPT 解码器。

## 2.3 DIVA：固定基底空间中的注意力

设一层中有 \(N\) 个空间 token，基底数为 \(K\)。DIVA 根据查询特征和键值特征分别预测空间 token 到基底的分配矩阵：

\[
A_Q=\operatorname{softmax}_K(f_Q(Q)),\qquad
A_{KV}=\operatorname{softmax}_K(f_{KV}(K)).
\]

这里的 softmax 沿基底维度进行。对于每个空间 token \(i\)，还使用 \(c_i\) 表示它所覆盖的空间面积，因此不同大小的 patch 对聚合结果的贡献按面积加权。以查询为例，第 \(k\) 个基底特征为：

\[
\tilde Q_k=
\frac{\sum_{i=1}^N c_i A^Q_{ik}Q_i}
{\sum_{i=1}^N c_i A^Q_{ik}+\epsilon}.
\]

键和值也以类似方式聚合。该面积权重用于处理自适应 patch 带来的不等面积 token。

- **推理阶段**：注意力及跨视图对应关系在固定大小的 \(K\)-token 表示上计算，而不是在所有 \(N\) 个空间 token 之间计算。论文在此采用 ZipMap 提出的 TTT 程序。
- **回投影阶段**：将基底空间输出映射回原始空间 token 网格，供密集预测使用。
- CLS、register、camera 等不对应明确空间面积的特殊 token，不参与面积加权压缩，而是与压缩后的基底 token 拼接。
- 论文默认图像编码器基底数为 512、聚合模块基底数为 64。

论文的复杂度分析指出，DIVA 单层计算包含约 \(O(nDk)\) 的基底构造与投影，以及 \(O(\tau kD^2/h)\) 量级的 TTT 更新项；相较标准注意力中的 \(O(n^2D)\) 项，可显著减少对 token 数的二次依赖。对于固定架构超参数，论文给出的整体复杂度为 backbone 约 \(O(NP)\)，完整模型约为 \(O(NP+N^2)\)，其中完整模型的二次项来自未替换的 DPT 预测头。

## 2.4 分辨率一致性的依据

- 作者通过特征有效秩分析观察到：随着图像分辨率和视图数增加，中间特征的 99% 能量有效秩仍大致稳定。
- DIVA 的面积加权聚合意在近似连续空间上的积分，使不同采样密度下的基底表示趋于一致。
- 论文将这种性质称为“离散化不变”，同时说明更准确地说是**渐近离散化一致性**，并不意味着有限分辨率间严格相同。该理论论证针对 backbone，且依赖基底、采样、位置表示等一致性假设；作者明确指出它不直接保证预测头具有同样性质，也不代表对增加视图数不变。

# 6. 主要结论与发现

- ReDT 在高分辨率输入下，将注意力推理从随图像分辨率增长的空间 token 集合转移至固定规模基底空间，降低了分辨率增长带来的计算负担。
- 在所测试的高清重建数据集上，ReDT 系列整体取得有竞争力的重建精度和推理效率；ReDT-Ω在论文报告的多项高清重建和几何任务中表现尤其突出。
- ETH3D 2K 对比中，ReDT-Ω相较 VGGT-Ω 的表格结果对应约 16 倍加速、约 34% 显存降低和约 33% CD 降低。
- 消融结果表明，基底投影对高分辨率下的显存可行性和精度很重要；移除它后，ETH3D 4K 会出现 OOM。自适应 tokenizer 和 TTT 也对指标有稳定贡献。
- 在 ScanNet、7-Scenes 等标准/次高清基准上，ReDT 仍保持具有竞争力的精度和较快推理速度，并非只在高分辨率设置下有效。

# 7. 优点

- **问题定位清晰**：不仅关注跨视图注意力，也指出编码器和帧内注意力仍是高分辨率扩展瓶颈。
- **设计与诊断相联系**：有效秩分析支撑固定基底表示；高分辨率采样敏感性分析支撑离散化一致性的设计动机。

- **考虑不等面积 token**：面积权重使基底聚合能够适应自适应 patch 合并产生的不同空间支持范围。
