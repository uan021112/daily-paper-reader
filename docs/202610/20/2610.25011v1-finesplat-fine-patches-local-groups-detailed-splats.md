## 摘要
前馈式 3D Gaussian Splatting（3DGS）有望实现即时场景重建与高质量新视角合成。然而，精细几何结构与外观仍难以恢复，因此我们重新审视前馈模型表示、聚合和细化精细视觉信息的方式。我们提出 FineSplat，这是一种以细粒度图像块为核心的前馈式 3DGS 框架。由于在如此高的 token 分辨率下进行全局多视图注意力计算的代价过高，我们设计了一种双重分组策略，结合两种互补的局部性机制：按视图分组可实现相邻视图间的高效交互；3D 空间分组则通过将 token 映射到 3D 场景空间，重新连接几何相关、但在按视图分组下可能从未发生交互的 token。我们还利用重建误差作为直接反馈，提供基于显式渲染的信号，以恢复精细结构与外观，从而克服单次前馈预测的局限。最后，我们采用紧凑的高斯生成方案，在避免原语数量不必要增长的同时，保留细粒度特征的优势。上述设计使 FineSplat 能够恢复更丰富的几何结构与外观，同时保持高效和紧凑；在高斯数量预算相同或更低的情况下，其表现仍大幅领先于现有方法，达到当前最先进水平。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) promises instant scene reconstruction with high-quality novel-view synthesis. Yet, fine-grained geometry and appearance remain difficult to recover, motivating us to revisit how feed-forward models represent, aggregate, and refine detailed visual information. We introduce FineSplat, a feed-forward 3DGS framework built around fine-grained image patches. Since global multi-view attention becomes prohibitively expensive at such high token resolutions, we develop a dual-grouping strategy that combines two complementary forms of locality: view-wise grouping enables efficient interaction among neighboring views, while 3D spatial grouping reconnects geometrically related tokens that may never have interacted under view-wise grouping by lifting them into the 3D scene space. We further leverage reconstruction error as direct feedback, providing an explicit rendering-based signal to recover fine-grained structures and appearance, thereby overcoming the limitations of one-pass feed-forward prediction. Finally, a compact Gaussian generation scheme preserves the benefits of fine-grained features without unnecessarily increasing the number of primitives. Together, these designs enable FineSplat to recover richer geometry and appearance while remaining efficient and compact, achieving state-of-the-art results by a substantial margin, under the same or smaller Gaussian budgets than existing methods.

# FineSplat 论文总结

## 1. 核心问题与整体含义

- **研究背景**：传统 3D Gaussian Splatting（3DGS）通常通过逐场景迭代优化获得高质量新视角合成，但每个场景都要单独优化，计算成本较高。前馈式 3DGS 希望直接由输入图像预测高斯表示，从而快速重建场景。
- **核心问题**：前馈预测通常只有一次生成机会，难以充分处理多视图歧义，也容易遗漏细小结构、边缘和纹理。现有方法常用较粗的图像块，虽然有利于全局几何推理，却会损失细节；若改用细粒度图像块，全局多视图注意力的计算量又会迅速增大。
- **论文主张**：FineSplat 以细粒度图像块保留视觉细节，并以“视图局部交互 + 3D 空间局部交互”控制计算成本；随后利用渲染误差反馈修正初始预测，并以紧凑的高斯生成策略控制表示规模。其目标是在不增加、甚至减少高斯数量的情况下，改善重建质量。

## 2. 方法论

### 2.1 总体流程

FineSplat 接收多张上下文图像，输入相机位姿可以已知，也可以未知。模型分为两个阶段：

1. **阶段一：按视图分组的细粒度编码**，从图像中提取高分辨率 token，并在受限的视图范围内进行交互。
2. **阶段二：3D 空间分组与误差反馈**，先预测高斯并渲染输入视图，再将 token 映射到 3D 场景空间，结合重建误差更新 token，重复预测与修正。

### 2.2 阶段一：细粒度 token 与视图分组

- 将每张图像划分为 **4×4 图像块**，形成细粒度 token。
- 阶段一采用多视图金字塔架构 MVP，融合不同空间分辨率的特征：细尺度特征保留局部细节，粗尺度特征提供更广范围的场景和跨视图信息。
- 细粒度注意力仅在相邻的小组视图内进行，避免对所有视图的高分辨率 token 执行全局注意力。文中默认将相邻视图按 **每组两帧**处理；更粗尺度的 token 则可以跨所有视图交互。
- 这种设计降低计算成本，但不同视图组之间的细粒度 token 仍可能无法直接交流，因此需要阶段二弥补。

### 2.3 阶段二：3D 空间分组、重建误差与迭代更新

- **初始高斯预测**：轻量级线性 Gaussian head 将每个 token 解码为多个高斯及其属性。阶段二每个 token 对应 **4 个高斯**。
- **将 token 提升至 3D**：以该 token 所预测高斯中心的均值作为其 3D 位置：
  \[
  p_j^{(i)}=\frac{1}{K}\sum_{k=1}^{K}\mu_{jk}^{(i)}
  \]
  其中，\(K\) 是每个 token 预测的高斯数，\(\mu_{jk}^{(i)}\) 是第 \(i\) 次更新中 token \(j\) 的第 \(k\) 个高斯中心。这样，每个 token 都成为带有特征的 3D 点。
- **计算渲染误差**：将当前高斯渲染回各输入视图，得到渲染图与输入图之间的像素误差；同时计算预训练 ResNet-18 特征空间中的差异，并与阶段一的细尺度图像特征结合。
- **跨视图收集误差信息**：
  - 每个 token 获取其来源视图上的自身误差特征 \(e_{\text{self}}\)；
  - 通过视锥和遮挡检查，筛选实际可见该 token 的其他视图，并聚合其误差特征 \(e_{\text{agg}}\)。
  - 遮挡检查使用当前渲染深度，允许 token 深度最多比渲染表面深 15%。
- **3D 邻域交互**：将 token 映射到 3D 后，依据空间邻近关系分组，再使用序列化注意力在局部 3D 邻域内进行信息交换。该方法借鉴 Point Transformer V3 的空间序列化思路，避免对所有点进行显式 k 近邻搜索。
- **残差更新与重复预测**：注意力输出经线性层转为 token 残差并加回原 token，再由共享 Gaussian head 生成新一轮高斯。该过程共执行 **4 步**，每一步重新渲染图像、计算误差并更新 3D 分组。

### 2.4 紧凑的 patch-aligned 高斯生成

- 每个 4×4 token 预测 4 个高斯，分别对应四个不重叠的 **2×2 子块**。
- 每个高斯可以学习子块内的二维图像坐标偏移，并通过双曲正切函数限制偏移范围，使高斯仍位于对应子块内，同时支持亚像素级定位。
- 这种方案在保留图像局部结构和射线对应关系的同时，避免按每个像素生成高斯所带来的过大原语数量。
- 此外，论文根据高斯对上下文视图渲染的贡献进行剪枝，形成更紧凑的表示。

## 6. 主要结论与发现

- FineSplat 在 DL3DV 的 posed 和 pose-free 结果中均取得明显较好的新视角合成质量；论文报告相较 2Xplat，PSNR 最多提升约 **2.88 dB（posed）**和 **2.75 dB（pose-free）**，同时高斯数量约少四倍。
- 在 RE10K 零样本测试中，FineSplat 取得有竞争力的结果；在 Mip-NeRF 360 上，各输入视图数量下均取得最高 PSNR，并能随上下文视图增加持续提升。
- ScanNet++ 的实验也显示，FineSplat 在较多输入视图时具有较强跨域表现；作者报告在 posed 设置下，随着视图数量增加，其相对部分 DL3DV 训练基线的优势扩大。
- 阶段二能显著改善阶段一的初始预测：在 DL3DV 上，单步更新即带来约 **0.85–1.04 dB** 的 PSNR 提升，四步时效果进一步改善；继续增加到 16 步则出现下降。
- 视图组外的观测对误差反馈有实际价值，且输入视图越多，3D 空间交互对跨组信息整合越重要。
- 这些结果支持论文的核心判断：**细粒度图像特征本身还不够，模型还需要将跨视图的几何相关信息在 3D 空间中重新连接，并借助渲染误差进行修正。**

## 7. 优点

- **设计针对性强**：直接回应细粒度 token 与全局注意力计算成本之间的矛盾。
- **双重局部性互补**：视图分组保留相邻视图间高效交互，3D 分组弥补固定视图分组造成的跨组信息断连。
- **利用显式重建反馈**：不是只靠一次前馈回归，而是将渲染误差转化为 token 更新信号，形成受控的多步修正。
- **关注细节与表示规模的平衡**：细粒度特征没有简单地转化为像素级高斯爆炸，而是采用 patch-aligned 子块高斯和贡献度剪枝。
- **实证链条较完整**：主结果、跨域测试和针对关键组件的消融共同支持方法解释。
- **训练监督相对精简**：FineSplat 不依赖深度监督来训练高斯重建模块，场景尺度归一化也以输入相机位姿为依据。

## 8. 不足与局限

- **依赖可靠的 3D 位置和相机估计**：阶段二需要将 token 提升到场景坐标并进行空间分组；在位姿预测或几何定位误差较大时，邻域关系可能被错误构造。
- **迭代仍有额外代价**：虽然不是传统逐场景优化，但阶段二需要重复渲染、误差提取、空间注意力和高斯解码；论文没有完整报告这些操作在不同视图数下的统一推理耗时和显存开销。
- **适用范围仍待扩展**：主要训练于 DL3DV，虽然提供了多个跨域测试，但不同场景类型、极端光照、动态物体、严重遮挡以及更高分辨率的表现仍需进一步验证。
