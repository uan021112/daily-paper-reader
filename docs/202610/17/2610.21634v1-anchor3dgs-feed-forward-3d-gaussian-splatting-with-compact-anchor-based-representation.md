## 摘要
近期的前馈式 3D 高斯泼溅（3DGS）方法通过单次前向传播预测高斯基元，实现了有效的多视图 3D 重建。然而，现有方法主要采用像素对齐范式，即为每个输入像素预测一个高斯，从而使高斯数量与输入分辨率及视图数量相耦合。这也会导致无纹理区域出现冗余基元，而几何结构复杂的区域覆盖不足。我们提出 Anchor3DGS，这是一种免位姿的前馈式 3DGS 框架，以紧凑的基于锚点的表示取代像素对齐预测。在信息熵的引导下，我们在场景中布置一组 3D 锚点，使其集中于视觉复杂度较高的区域，同时保持广泛的空间覆盖。每个锚点都会对多视图图像特征进行具备遮挡感知能力的聚合，与其他锚点交换信息，并解码为一组局部高斯。此外，轻量级特征增强模块可进一步优化高斯泼溅生成的粗略 RGB 输出，提升渲染保真度。在多个不同基准数据集上的大量实验表明，Anchor3DGS 仅使用少一个数量级的高斯基元，便实现了当前最先进的新视角合成质量。

## Abstract
Recent feed-forward 3D Gaussian Splatting (3DGS) methods have enabled effective multi-view 3D reconstruction by predicting Gaussian primitives in a single forward pass. However, existing approaches predominantly adopt a pixel-aligned paradigm that predicts one Gaussian per input pixel, coupling the Gaussian count to the input resolution and number of views. This also leads to redundant primitives in textureless regions and insufficient coverage in geometrically complex areas. We present Anchor3DGS, a pose-free feed-forward 3DGS framework that replaces pixel-aligned prediction with a compact anchor-based representation. Guided by information entropy, our method places a set of 3D anchors in the scene, concentrating them in regions of higher visual complexity while maintaining broad spatial coverage. Each anchor performs occlusion-aware aggregation of multi-view image features, exchanges information with other anchors, and is decoded into a set of local Gaussians. A lightweight feature enhancement module further refines the coarse RGB output from Gaussian splatting and improves rendering fidelity. Extensive experiments on diverse benchmark datasets demonstrate that our Anchor3DGS achieves state-of-the-art novel view synthesis quality while only using an order of magnitude fewer Gaussian primitives.

- **论文主旨**：作者提出 **Anchor3DGS**，将表示单元从输入像素转为场景空间中的一组固定预算三维锚点。锚点按视觉复杂度分配，并汇集多视图信息，最终解码为局部高斯，以期在保持或提升新视角合成质量的同时显著压缩表示规模。

# 2. 方法论

## 2.1 整体流程

输入为未标定的多视图图像。方法先估计相机与深度，建立三维场景支架；随后在支架上采样固定数量的锚点；每个锚点聚合多视图特征并与其他锚点交互；最后每个锚点解码出若干局部高斯，经过 3DGS 光栅化和图像增强模块得到最终渲染结果。

## 2.2 几何初始化与锚点采样

- **几何支架**：使用基于 VGGT 的几何骨干网络，从未标定输入中预测相机外参、内参和逐视图深度图。利用相机和深度将像素反投影到三维空间，得到场景点集。
- **信息熵引导采样**：
  - 将图像转为灰度并量化，在局部滑动窗口内统计灰度直方图，以 Shannon 熵估计每个像素附近的视觉复杂度：
    \[
    E(u)=-\sum_b p_b(u)\log p_b(u).
    \]
  - 将三维点与其对应图像位置关联，采样时结合两种策略：粗网格采样保证场景的广泛空间覆盖；按熵值加权采样，使高纹理、边界等复杂区域得到更多锚点。
  - 锚点总预算固定，与输入分辨率、视图数量解耦。论文默认设置为 \(N=32{,}768\) 个锚点。
- **局部间距**：计算每个锚点到其 \(k\) 个近邻的平均距离 \(d_n\)，作为局部密度尺度。后续高斯偏移按该尺度缩放，使不同密度区域能够解码出不同空间范围的局部表示。

## 2.3 多视图聚合与锚点交互

- 将锚点投影到各输入视图，在相应特征图上双线性采样，得到每视图特征。
- **遮挡感知加权**：比较锚点在相机坐标系中的深度与该投影位置的预测深度。若锚点明显位于可见表面之后，则降低该视图特征的权重。论文以深度相对差异计算遮挡权重，并将其加入跨视图注意力权重中。
- 每个锚点根据其几何嵌入和各视图特征计算权重，融合得到多视图特征；再通过锚点间自注意力交换信息。这样，观测不足区域的锚点可以借助邻近、观测更充分锚点的上下文。

## 2.4 锚点解码与渲染增强

- 每个锚点与一组共享的可学习槽位向量组合，通过解码器生成局部高斯。
- 对锚点 \(a_n\) 的第 \(k\) 个高斯，其中心为：
  \[
  x_{n,k}=a_n+d_n\Delta x_{n,k},
  \]
  其中偏移 \(\Delta x_{n,k}\) 由锚点特征和槽位向量解码，局部间距 \(d_n\) 调节偏移范围。
- 默认每个锚点解码 \(K=8\) 个高斯，因此每个场景约有 \(N K\approx 0.26\) 百万个高斯。
- 每个高斯预测不透明度、协方差、基础 RGB 颜色及外观特征。基础颜色和特征图使用相同的 3DGS 光栅化与 alpha 合成权重；特征图再输入轻量级 UNet 预测 RGB 残差，形成最终渲染结果。
- 训练损失由像素 MSE、LPIPS 感知损失和高斯渲染深度与骨干网络深度之间的一致性损失组成。

# 3. 实验设计

## 3.1 训练数据与评测基准

- **训练数据集**：DL3DV、ScanNet++、Hypersim、BlendedMVS 和 Waymo，覆盖真实与合成、室内与室外、物体级与街景场景。
- **主要新视角合成评测**：
  - VR-NeRF：论文列出 4 个场景；
  - MipNeRF360：论文列出 4 个场景；
  - DL3DV：使用与训练集不重叠的 10 个测试场景。
- **额外相机位姿评测**：Co3Dv2，采用相对位姿 AUC 指标，阈值为 10°、20°、30°。
- **测试视图设置**：主要比较 3、6 个输入视图的稀疏视图设置，以及 32 个视图的稠密设置；附录另报告 64 视图结果。指标为 PSNR、SSIM、LPIPS，并统计高斯数量；稠密设置还报告存储大小和推理时间。

## 3.2 对比方法

- 稀疏视图比较：NoPoSplat、FLARE、DA3（Depth Anything 3）、AnySplat。
- 稠密视图比较：DA3、AnySplat，以及需要逐场景优化的 VGGT+3DGS。
- 附录还比较了原始 VGGT、AnySplat 与本文方法的相机位姿估计结果，并进行像素对齐预测头对照实验。

# 4. 资源与算力

- 训练使用 **8 张 NVIDIA H20 GPU**，共训练 **30,000 次迭代**，论文报告耗时约 **2–3 天**。
- 优化器为 AdamW，最高学习率 \(2\times10^{-4}\)，预热 1,000 步；训练输入最长边最大为 448 像素，训练时上下文视图数在 2 至 16 之间随机采样。
- 推理时间在单张 **H800 GPU** 上报告：32 视图时约 2.9 秒（VR-NeRF）和 3.1 秒（DL3DV）。64 视图下的渲染速度评测使用单张 H20 GPU。
- 论文没有完整给出端到端推理各模块的分项耗时或不同硬件之间的统一比较。其“推理时间”与“逐场景优化耗时”属于不同工作范式，不能简单视为完全同口径的速度比较。

# 5. 实验数量与充分性

- 主实验覆盖 3 个新视角合成基准、2 种稀疏视图设置、1 种主要稠密视图设置；另含 64 视图扩展、Co3Dv2 位姿评测、多个消融和效率分析。
- 消融包括移除图像增强模块、锚点自注意力、遮挡感知聚合、熵引导采样；还考察锚点数 \(N\) 和每锚点高斯数 \(K\) 的变化。
- 附录进一步在固定几何骨干下对比锚点解码头与像素对齐解码头，并在 DL3DV 的 3、6、32 视图设置下给出组件消融。
- **充分性判断**：实验对核心方法设计有较系统的消融支撑，并覆盖稀疏与稠密输入、重建质量、紧凑性、速度及位姿估计，整体较完整。
- **公平性与客观性需要留意**：
  - 若干评测集的场景数较少（例如 VR-NeRF 和 MipNeRF360 各 4 个场景），结果的跨场景统计稳健性仍有限。
  - 不同基线支持的输入视图数与方法定位不同；NoPoSplat 还需对目标位姿进行测试时优化，比较协议并非完全一致。
  - 位姿评测、图像质量评测与渲染速度使用的流程和硬件不同，跨表格结果应分别解读。
  - 文中给出了多项均值指标，但所提供内容未见置信区间或跨随机种子的方差报告。

# 6. 主要结论与发现

- 在 3、6 视图的稀疏设置中，Anchor3DGS 在 VR-NeRF、MipNeRF360 和 DL3DV 上总体优于所比较方法。论文报告其相较各设置下最佳基线，在 MipNeRF360 和 DL3DV 上尤其有显著提升，部分 PSNR 增益超过 2 dB。
- 在 32 视图设置下，Anchor3DGS 在 VR-NeRF 上取得 24.56 PSNR、0.815 SSIM、0.297 LPIPS；在 DL3DV 上为 19.52 PSNR、0.593 SSIM、0.364 LPIPS。其指标并非在每个数据集、每项指标上都绝对领先，但整体达到相近或有竞争力的渲染质量。
- 默认配置下每场景约 **0.26M** 个高斯。32 视图对比中，AnySplat 使用约 3.98M–4.75M 个高斯，DA3 使用约 6.42M 个；作者报告 Anchor3DGS 在较高视图数下仍能以显著更少基元保持竞争力。
- 消融结果显示，熵引导采样、遮挡感知特征聚合、锚点间注意力和渲染增强模块均对性能有贡献；在稀疏视图条件下，锚点表示相对像素对齐表示的优势尤其明显。

# 7. 优点

- **表示数量与输入规模解耦**：固定锚点预算避免高斯数量随图像分辨率和视图数直接膨胀。
- **容量分配有针对性**：均匀覆盖与熵引导采样结合，兼顾空间覆盖和高复杂度区域的细节表达。
- **显式利用多视图可见性**：通过深度差异估计遮挡权重，减少不可见视图对锚点特征的干扰。
- **支持上下文补偿**：锚点间自注意力可传播邻域信息，对观测不充分区域提供更连贯的预测。
- **实验覆盖较广**：包含质量、紧凑性、速度、位姿估计及模块消融，并提供了像素解码头对照，有助于区分骨干网络与表示方式的作用。
- **兼顾几何与外观**：基础 3DGS 表示负责几何一致的颜色，特征增强模块补充高频细节；附录还专门检查了增强模块对多视图一致性的影响。

# 8. 不足与局限

- **依赖几何骨干质量**：锚点位置、可见性判断和后续投影均依赖 VGGT 预测的位姿与深度；若几何初始化有噪声，锚点布局和渲染都可能受影响。
- **固定预算未必适合所有场景**：固定锚点数便于控制资源，但对尺度差异很大的场景、无界场景或极复杂场景，可能出现容量不足或分配不够灵活的问题。作者也将场景自适应预算列为未来方向。
- **视觉熵不等于几何复杂度**：熵主要反映图像局部外观变化，可能将纹理丰富但几何简单的区域判定为高复杂度，也可能忽略低纹理但几何重要的结构。
- **增强网络的跨视角影响仍需关注**：作者报告其对重投影一致性的影响较小，但该模块本质上仍是二维 UNet；对更复杂视角、遮挡变化或分布外场景，其一致性与细节泛化仍需更多验证。
- **评测规模有限且场景覆盖不均**：主要评测集场景数不多，尽管训练集多样，仍不足以完全说明对所有场景尺度、相机运动和极端稀疏输入的泛化能力。
- **系统效率报告不完整**：给出了部分推理时间、存储和渲染 FPS，但缺少端到端耗时分解及统一硬件上的完整基线比较；高斯数量减少也不必然意味着所有环节的计算量同比例下降。
- **应用风险**：与其他逼真重建技术类似，可能被用于制造误导性视觉内容，也可能涉及私人空间或个人影像的隐私问题。
