## 摘要
从单个运动相机重建随时间变化的动态三维场景（4D 重建），是机器人和 AR/VR 应用的核心任务。然而，当前最先进的前馈方法仅依赖 RGB 帧，因此也继承了传统相机的失效模式，包括快速或非均匀的相机与物体运动所导致的运动模糊和时间混叠。事件相机以微秒级分辨率异步报告逐像素亮度变化，能够提供互补信号，且基本不受这些伪影影响；但在不对架构进行全面重新设计的情况下，能否将这一模态融入现有的基于 RGB 的 4D 重建流程，仍是一个开放问题。在这项初步研究中，我们探索了一种最小化扩展方案：为现有的纯 RGB 4D 重建模型 Monst3R 增加一个事件相机输入分支，同时保持其余架构不变。在 3 个基准数据集上，与纯 RGB 的 Monst3R 基线相比，这种简单的 RGB-事件融合平均降低了 3.4% 的 Abs Rel；敏感性分析还表明，随着相机和物体运动幅度增大，性能提升也随之增大，其中在物体运动幅度较大的条件下提升最为显著，因为此时纯 RGB 重建的性能退化最严重。这些初步结果表明，即使采用轻量、非侵入式的事件数据融合，也能切实提升 4D 重建的鲁棒性，并为未来更深入的架构研究提供了动力。

## Abstract
Reconstructing dynamic 3D scenes over time (4D reconstruction) from a single moving camera is central to robotics and AR/VR applications, yet state-of the-art feed-forward methods rely solely on RGB frames and therefore inherit the failure modes of conventional cameras, including motion blur and temporal aliasing under fast or non-uniform camera and object motion. Event cameras report per-pixel brightness changes asynchronously at microsecond resolution, offering a complementary signal that is largely immune to these artifacts, but whether this modality can be incorporated into existing RGB based 4D reconstruction pipelines without a full architectural redesign remains an open question. In this preliminary study, we investigate a minimal extension: we augment Monst3R, an existing RGB-only 4D reconstruction model, with an additional event-camera input branch, leaving the rest of the architecture unchanged. Across 3 benchmark datasets, this simple RGB-event fusion reduces Abs Rel by 3.4% on average relative to the RGB-only Monst3R baseline, and a sensitivity analysis shows that the improvement grows with the magnitude of camera and object motion, with the largest gains observed under high object motion conditions where RGB-only reconstruction degrades most. These early results suggest that even a lightweight, non-invasive fusion of event data can meaningfully improve 4D reconstruction robustness, motivating a more thorough architectural investigation in future work.

# 2. 方法论

## 核心思想与网络结构

- 以 **MonST3R** 为基础，在保留原有解码器、预测头等结构的情况下，增加事件数据输入。
- 对每个视角，模型接收一张 RGB 图像和对应的事件体素网格：
  - RGB：3 个通道；
  - 事件体素：5 个时间分箱；
  - 拼接后得到 8 通道张量。
- 由于预训练 ViT 编码器期望输入为 3 通道，作者加入一个轻量卷积适配层，将 8 通道输入投影为 3 通道表示。之后输入共享的 Siamese ViT 编码器，并沿用 MonST3R 原有解码器与预测头。
- 融合方式较直接，主要是在输入端拼接 RGB 与事件体素；没有设计专门的事件编码器、跨模态注意力或动态门控机制。

## 事件表示与数据流程

- 原始事件表示为一段时间内的事件集合，每个事件包含极性、像素坐标和时间戳：
  \[
  e_i=(p_i,x_i,y_i,t_i)
  \]
  其中极性 \(p_i\) 表示亮度增加或减少。
- 作者将事件流划分为 \(B=5\) 个时间分箱，在对应的像素和时间箱中累积事件极性，形成稠密事件体素网格。可概括为：**按时间戳确定分箱、按像素位置定位、累积事件正负极性**。
- 训练与测试数据集原本只有 RGB 序列，因此作者使用 **V2E** 从视频合成事件流：先插值生成中间帧，再依据亮度变化模拟事件，最后转换为体素网格。
- 训练数据包括 **PointOdyssey、TartanAir 和 Spring**，训练配置沿用 MonST3R 的设置。

# 3. 实验设计

## 数据集与 benchmark

- **训练数据集**：PointOdyssey、TartanAir、Spring。事件数据由 V2E 从 RGB 视频合成。
- **评估数据集**：Sintel、Bonn、KITTI、PointOdyssey。
- 评估任务及指标包括：

  - **运动敏感性分析**：在 PointOdyssey 测试集子集上，依据真值相机位姿和深度变化划分不同相机运动、物体运动等级，比较 Log RMSE。

## 对比方法

论文以 MonST3R 为基础，比较四种输入方案：

1. **RGB**：原始预训练 MonST3R，使用原始 RGB 图像。
2. **RGB（HyperE2VID）**：先用 HyperE2VID 从事件数据重建 RGB，再输入 MonST3R。
3. **Ev. Vox.**：仅使用事件体素训练的 MonST3R 变体。
4. **RGB + Ev. Vox.**：使用 RGB 与事件体素融合训练的 MonST3R 变体。

## 主要结果举例

- 深度估计中，RGB+事件体素相较 RGB 基线的 Abs Rel：

- Sintel 位姿估计中，RGB+事件体素的 ATE、RPE translation、RPE rotation 分别为 0.106、0.038、0.476，均优于其余表中方案。
- PointOdyssey 的敏感性分析显示，融合方案在不同相机运动等级下均有较低 Log RMSE；物体运动较强时优势更明显。论文报告高物体运动类别的 Log RMSE 低 **0.327**。
