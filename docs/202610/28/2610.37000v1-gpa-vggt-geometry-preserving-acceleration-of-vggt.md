## 摘要
VGGT 等前馈几何模型能够通过一次前向传播，从一个到数百个视图中恢复相机参数、深度图和点图，因此是多视图三维感知的强大骨干网络。然而，VGGT 的全局注意力计算量随帧数呈二次增长，在长序列上的端到端运行时间中占主导地位，因此催生了多种无需训练的高效化方法，例如 token 合并。但这些方法会造成精度下降，难以替代 VGGT。我们提出 GPA-VGGT，这是一种无需训练的加速方法：在早期模块中，以帧注意力替代全局注意力，并辅以共享的跨帧 K/V 集；在其余模块中，仅合并键和值，同时保留所有查询，恢复每个合并键所代表的 token 的注意力质量，并将匹配度量随机投影至 128 维以降低匹配开销。在多种多视图几何任务中，GPA-VGGT 在提供与既有方法相当加速效果的同时，无需训练地保留精确几何估计所需的信息；在 AUC@3 指标下，其位姿精度达到 VGGT 的 99% 以上。

## Abstract
Feed-forward geometry models such as VGGT recover camera parameters, depth maps, and point maps from one to hundreds of views in a single forward pass, making them powerful backbones for multi-view 3D perception. However, VGGT's global attention is quadratic in the number of frames and dominates end-to-end runtime on long sequences, which has motivated a range of training-free efficiency methods such as token merging. These methods, however, come with a drop in accuracy that makes them hard to use in place of VGGT. We propose GPA-VGGT, a training-free acceleration method that replaces global attention in early blocks with frame attention augmented by a shared cross-frame K/V set. In the remaining blocks, we merge only keys and values while preserving all queries, restore the attention mass of the tokens each merged key represents, and randomly project the matching metric to 128 dimensions to reduce matching cost. Across diverse multi-view geometry tasks, GPA-VGGT provides training-free acceleration at speedups comparable to prior work while preserving the information required for precise geometric estimation, retaining over 99% of VGGT's pose accuracy under AUC@3.

# 1. 核心问题与整体含义

- **研究背景：** VGGT 是一种前馈式多视图几何模型，可在一次前向传播中，根据多张未标定图像预测相机参数、深度图、点图及跟踪特征。其全局注意力的计算量会随视图数量近似二次增长，因此长序列推理成本较高。
- **核心问题：** 既有免训练加速方法虽能减少计算，但可能损害精细几何信息，尤其在严格的相机位姿指标 AUC@3 下精度下降明显。论文认为，问题不仅是“合并多少 token”，也在于合并了什么、是否保留跨视图信息，以及注意力权重是否正确校正。
- **整体思路：** GPA-VGGT 不额外训练模型，而是重新设计注意力加速方式：早期层保留紧凑的跨帧上下文，后续层压缩 K/V、保留全部查询，并校正合并 token 的注意力权重，力求在降低推理时间的同时保留几何估计精度。

# 2. 方法论

## 2.1 早期层：带共享跨帧上下文的帧注意力

- VGGT 的早期全局注意力被替换为帧内注意力，以降低跨帧全局交互成本。
- 为避免完全失去跨帧信息，GPA-VGGT 为每个帧的查询加入一个**共享跨帧 K/V 集**，包含：
  - 所有帧的相机 token 和 register token；
  - 所有帧的图像 patch 汇总 token。
- 图像汇总采用内容自适应聚类：以步长为 8 的网格位置作为初始代表点，将 patch token 分配给余弦相似度最高的代表点，再对簇内 K/V 求平均。多头注意力中，各头独立聚类。
- 论文指出，单纯将全局注意力改成帧注意力会导致各视图表征产生不一致漂移；共享 K/V 可缓解这一问题，恢复视图间较一致的几何参考。

## 2.2 后续层：仅合并 K/V，保留所有查询

- 传统做法可能同时合并查询、键和值，再把合并后的输出复制回多个 token。这会使组内 token 共享同一输出，损失每个 token 的独立预测。
- GPA-VGGT **只合并键和值，保留全部查询**。因此，每个查询仍使用自己的特征，对缩减后的 K/V 集计算注意力，注意力计算规模由原来的 \(N\times N\) 降为 \(N\times N_{\text{merged}}\)。
- 对于被合并到同一组的 \(s_j\) 个 token，论文将其 K/V 分别取均值，并在对应注意力 logit 上加上 \(\log s_j\)，补偿该合并键代表多个 token 所应获得的注意力质量。其形式可概括为：
  \[
  o_i=\sum_j \operatorname{softmax}_j
  \left(\frac{q_i^\top \bar{k}_j}{\sqrt d}+\log s_j\right)\bar{v}_j .
  \]
  当同一组中的键相同时，这种质量补偿可使合并后的注意力与未合并情形一致。
- VGGT 的第 13–16 块对合并较敏感，论文在这些核心块使用较弱的合并设置（合并率 0.2），其他合并块使用 0.9。

## 2.3 降低匹配成本与工程实现

- 合并前需按特征相似度匹配 token。作者将 1024 维匹配特征投影至 128 维，再计算余弦相似度并执行 argmax；投影矩阵为固定高斯随机矩阵，在各块与输入间共享。
- 128 维投影下，只有 76.6% 的 token 与全维度匹配选择相同目标，但相似度损失仅为 0.56%，说明多数差异来自相近候选之间的选择变化。
- 作者实现了两个 Triton 自定义内核：一个在在线 softmax 中直接加入 \(\log s\) 偏置，另一个只输出匹配的最大值与索引，避免存储完整相似度矩阵。

# 6. 主要结论与发现

- GPA-VGGT 在 CO3D 上的 AUC@3 为 56.94，原版 VGGT 为 57.49；在 RE10K 上分别为 44.45 和 44.78，均保留了约 99% 的原模型 AUC@3。
- 在 CO3D 的 64、100、200 帧设置下，GPA-VGGT 的 AUC@3 与 vanilla VGGT 接近，精度差距没有随序列变长而明显扩大。

- 消融结果支持作者的解释：恢复合并 token 的注意力质量是精度恢复的重要因素；保留查询则避免组内 token 输出坍缩；早期跨帧 K/V 有助于修复帧注意力造成的跨视图表征漂移。

# 7. 优点

- **针对误差来源设计方法：** 不只是压缩 token，而是分别处理查询合并、注意力质量失真和早期跨帧上下文丢失。
- **无需训练：** 直接使用原模型检查点，适合希望在不增加训练成本的情况下加速部署的场景。
- **兼顾精度与速度：** 在严格 AUC@3 下仍接近原模型，且长序列有明显加速。
- **实验维度较丰富：** 同时评估位姿、点图、不同序列长度、运行时间、显存及关键组件消融。
- **工程实现有针对性：** 自定义内核避免了注意力偏置导致的慢速后端回退，并降低匹配阶段的临时显存需求。

# 8. 不足与局限

- **仍有精度差距：** GPA-VGGT 并非完全无损，且不同任务、数据集和合并配置下的效果并不一致。
- **显存改善有限：** 其注意力计算更快，但峰值显存与 vanilla VGGT 基本相当，无法解决所有长序列显存瓶颈。
- **速度优势依赖实现与硬件：** 自定义 Triton 内核、特定 GPU 和软件栈可能影响实际加速效果；论文只在单张 A6000 上报告主要结果。
- **对比存在复现不确定性：** AVGGT 使用自行复现版本，且其数据子集和采样方案不可公开核验，降低了比较的完全可复现性。
- **评估覆盖仍有限：** 主要集中于 CO3D、RE10K、7-Scenes、NRGBD，以及少量迁移骨干；对更广泛的真实部署场景、极端视角变化及其他硬件的表现尚未充分验证。
- **方法有额外实现复杂度：** 内容聚类、随机投影匹配和自定义内核带来实现与维护成本；随机投影虽经消融验证，但其在不同模型、数据分布和设置下的稳健性仍值得继续检验。
