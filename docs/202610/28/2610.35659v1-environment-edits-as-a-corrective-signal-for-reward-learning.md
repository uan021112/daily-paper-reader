## 摘要
机器人纠正允许人们调整机器人的行为，但单次纠正会改变许多特征。此外，关于物体属性以及物体间关系的偏好无法通过移动机器人来表达。我们提出将环境编辑作为一种互补的反馈形式。人在编辑场景时，机器人的运动保持不变，因此，对编辑的唯一解释就是被移动的物体。我们提出环境与机器人关系编辑轨迹特征学习（Feature Learning from Environmental and Robot-Relational Edit Traces，FERRET），从机器人纠正和环境纠正中学习偏好。我们表明，环境编辑能够消除特征歧义，并学习仅凭机器人纠正无法学到的偏好。

## Abstract
Robot corrections allow people to adjust a robot's behavior, but a single correction changes many features. Also, preferences about object attributes and relationships between objects cannot be expressed by moving the robot. We propose environment edits as a complementary form of feedback. The robot's motion is held constant as the human edits the scene, so the only explanation for the edit is the moved object. We introduce Feature Learning from Environmental and Robot-Relational Edit Traces (FERRET), which learns preferences from both robot and environment corrections. We show that environment edits are able to disambiguate features and learn preferences that robot corrections alone cannot.
