## 摘要
多机器人控制需要整合分布式摄像头视角，同时预测彼此独立的动作序列。大多数视觉-语言-动作模型和世界-动作模型都面向单个机器人。仅仅组合多个视角，并不能建立它们之间的空间对应关系。World Dreamer v5-lite 是一种多机器人世界-动作模型，其核心是构建共享世界状态，以预测各机器人专属的动作。预训练视频编码器提取的特征经过标定后，以工作空间坐标填充该状态；随着视角增加，其空间尺寸保持不变。视觉-语言模型提供场景上下文，并为每个机器人生成一个查询。各查询读取共享状态并交换感知位姿的信息，同时各自的动作流保持独立。采用掩码视角的协同训练时，会从两个视觉分支中屏蔽选定的摄像头视角，同时保留所有动作目标，从而促使模型利用其他机器人共享的观测信息。预训练使用了来自 20 种仿真机器人、RoboFactory 和真实机器人的逾 10,000 小时轨迹数据。在 RoboFactory 上，World Dreamer v5-lite 的平均成功率达到 74.0%，比评测中表现最强的基线高出 23.7 个百分点。在四项真实机器人任务中，其平均成功率达到 78.8%，领先 13.8 个百分点。在 RoboCasa365 上，其总体得分也达到 58.08%。

## Abstract
Multi-robot control requires integrating distributed camera views while predicting separate action sequences. Most vision-language-action and world-action models target one robot. Combining multiple views alone does not establish spatial correspondence between them. World Dreamer v5-lite is a multi-robot world-action model built around a shared world state for robot-specific action prediction. Calibrated features from a pretrained video encoder populate this state in workspace coordinates; its spatial size remains fixed as views are added. A vision-language model provides scene context and one query per robot. The queries read the shared state and exchange pose-aware information, while their action streams remain separate. Masked-view cooperative training withholds selected camera views from both visual branches while retaining all action targets. This encourages the use of observations shared by other robots. Pretraining uses more than 10,000 hours of trajectories from 20 simulated robot types, RoboFactory, and real robots. On RoboFactory, World Dreamer v5-lite achieves 74.0% mean success, 23.7 percentage points above the strongest evaluated baseline. Across four real-robot tasks, it reaches 78.8% mean success, a margin of 13.8 points. It also reaches 58.08% overall on RoboCasa365.

## 1. 核心问题与整体含义

- **研究问题**：多机器人协作操作需要同时处理分布在不同机器人上的摄像头视角，并为各机器人预测独立但相互协调的动作。现有视觉-语言-动作（VLA）和世界-动作模型大多面向单机器人；直接拼接多路图像特征，既不能保证不同视角中的特征对应同一工作空间位置，也难以让机器人有效利用队友的观测。
- **研究动机**：多机器人系统面临三类挑战：
  - **观测分散**：机器人各自携带摄像头，且相机随机器人移动，视野有限。
  - **控制分开、决策关联**：机器人可能具有不同的本体和动作空间，但各自动作取决于其他机器人的状态与行为。
  - **观测不完整**：遮挡或视角限制可能使某个机器人无法看到任务所需信息。
- **整体思路**：World Dreamer v5-lite 将经相机标定的多视角特征整合到一个共享的工作空间状态中，再让每个机器人通过专属查询读取该状态、与其他机器人交换信息，同时保留各自独立的动作预测流。

## 2. 方法论

### 2.1 多模态输入与机器人查询

- 视觉-语言模型（VLM）处理指令和当前可用相机图像，并为预设的每个机器人槽位设置一个可学习查询。
- 查询由共享嵌入与机器人槽位嵌入相加得到。一次 VLM 前向过程生成：
  - 每个机器人的上下文查询状态；
  - 供动作解码器共享的场景前缀键值缓存。
- 未出现的机器人槽位通过掩码处理。视频分支则处理各摄像头的近期 RGB 历史；摄像头槽位与机器人槽位相互独立，因此一个机器人可以对应多个视角，也可以加入工作空间摄像头。

### 2.2 共享工作空间状态 \(\phi\)

- 预训练视频编码器提取图像块特征。相机内参、外参及可选深度信息将图像块映射到统一的工作空间坐标系。
- 若有有效深度，图像块映射为三维点；若无深度，则沿相机射线在工作空间内选取 8 个候选点，以学习其特征贡献。训练时以 25% 概率丢弃深度，使模型同时适应有深度和无深度输入。
- 特征与几何位置编码融合后，通过加权双线性 splatting 写入 **XY、XZ、YZ 三个平面**。这些平面构成固定尺寸的空间表示，避免因相机数量增加而扩张，也避免把不同视角中不对应的图像块直接混合。
- 状态随观测帧迭代更新：学习到的门控控制新特征替换旧特征的程度；当前帧不可见的位置则由可见性掩码保持不变。最终状态为
  \[
  \phi\in\mathbb{R}^{3\times16\times16\times256}.
  \]
  因而，状态大小不随摄像头数量变化。
- 视频编码器使用 3 个观测潜变量步；训练时另提供 2 个带噪未来潜变量步作辅助视频流匹配监督。注意，未来视频特征不进入动作预测使用的状态，推理时无需生成未来视频。

### 2.3 独立动作流与机器人间交互

- 每个机器人有独立的动作流，但所有机器人使用同一个解码器。动作和本体状态填充到通用维度，分别为 \(D_a=18\)、\(D_s=20\)；目标动作块长度 \(H=30\)。
- 动作采用条件流匹配训练：将高斯噪声动作与目标动作按流时间插值，模型预测从噪声到目标动作的速度；推理时用 5 步 Euler 积分生成动作块。
- 解码层按以下顺序处理：
  1. **场状态读取**：机器人查询通过交叉注意力读取 \(\phi\)，并利用与本机器人相机位置相关的偏置倾向读取自身视角附近的信息，同时不排除远处区域。
  2. **场景条件解码**：各机器人动作流分别读取共享 VLM 场景缓存，并在自身流内进行因果注意力；不同机器人动作流不直接混合。
  3. **位姿感知交互**：机器人查询之间通过注意力交换信息。相对位姿描述包含三维平移、连续 6D 旋转表示和欧氏距离，经过 MLP 转换为注意力偏置。仅查询参与机器人间交互，动作流仍保持分离。
- 解码器共有 36 层。推理时，每个决策步计算一次初始查询、共享状态和场景缓存，再通过 5 次解码器评估积分得到动作块。

### 2.4 掩码视角协同训练

- 训练时随机屏蔽某个机器人的全部摄像头，或屏蔽随机子集；同一视角会同时从 VLM 图像输入和视频状态构建分支中移除。
- **所有机器人仍保留动作监督目标**，包括摄像头被屏蔽的机器人。这样，模型需要尝试利用其他机器人的观测完成预测，而不只是依赖本机视角。
- 总目标包含动作流匹配损失、未来视频预测损失和场状态重建辅助损失，权重分别为 \(0.5\)、\(0.2\) 和随训练从 \(0.1\) 线性降至 \(0.02\) 的场状态项系数。

## 6. 主要结论与发现

- 将经标定的多视角视频特征映射到统一工作空间状态，使多个机器人能够共享空间证据，而状态尺寸不随视角数增加。
- 机器人专属查询能够读取共享状态并通过相对位姿交换信息；保持动作流独立，则有助于支持不同机器人各自的控制空间。
- 掩码视角训练使模型在部分摄像头不可用时仍保留所有机器人的动作监督，提供了促使模型利用队友观测的训练机制。
- 在所评测的 RoboFactory 与四项真实机器人任务中，模型超过对比基线；在 RoboCasa365 上也取得了较高总体分数。总体而言，结果支持共享空间表征用于多机器人控制的可行性，但尚不能单凭现有实验确认各设计模块分别带来的收益。

## 7. 优点

- **问题设定贴近协作需求**：明确处理分布式视角、异构控制和观测缺失，而非将多机器人任务简单化为多图像输入。
- **空间对齐设计清晰**：用相机几何将图像特征写入工作空间坐标，避免仅凭图像序列拼接推断视角对应关系。
- **共享与个体控制兼顾**：共享状态和查询交互提供协作通道，独立动作流保留机器人各自的动作结构。
- **考虑移动相机与局部可见性**：通过可见性门控累积状态，避免当前不可见区域的历史特征被直接清除。
- **训练机制针对协作瓶颈**：掩码视角同时作用于两条视觉分支，并保留全部动作目标，与“依靠队友观测”的目标相对应。
- **评测类型较丰富**：包含多机器人仿真、家庭操作基准以及真实机器人任务，且涉及不同团队规模和机器人组合。

## 8. 不足与局限

- **依赖准确标定与几何信息**：相机内外参和统一工作空间是空间状态构建及位姿交互的重要基础。若标定误差较大或几何关系变化，性能可能受影响；论文未系统量化对标定噪声的鲁棒性。
- **没有模块消融**：缺少对共享状态、三平面表示、可见性门控、位姿偏置、掩码训练及辅助视频损失的逐项验证，难以判定性能提升的来源和必要组件。
