## 摘要
随着第一人称视角视频日益丰富，如何将这一低成本、可扩展的数据来源转化为机器人操作能力，成为一个重要的研究问题。第一人称视角视频天然蕴含丰富的上下文信息，有助于高层任务理解；而包含腕部观测和动作标注的真实机器人示范，则能为细粒度动作对齐提供监督。我们提出 Ego-CEVR，这是一种面向数据原生的分层视觉表征学习框架，为全局表征与交互表征设置不同的学习目标。全局模块通过对第一人称视角视频进行未来预测，学习物体关系、任务状态和时间进程。交互模块则结合全局上下文解读腕部观测，并通过机器人动作监督学习局部对齐信息和接触线索。两条独立的残差路径将这两种表征分别提供给动作策略，使其在获取细粒度执行信息的同时，仍能直接利用任务上下文。Ego-CEVR 支持在大规模人类第一人称视角视频以及来自多种机器人本体的视频上，对全局视频模块进行独立预训练，无需机器人动作标签或配对的腕部观测。

## Abstract
As egocentric video becomes increasingly available for embodied learning, an important research question is how to turn this low-cost, scalable source of data into robot manipulation capabilities. Egocentric videos naturally provide rich context for high-level task understanding, while real-robot demonstrations with wrist observations and action annotations provide supervision for fine-grained action alignment. We present Ego-CEVR, a data-native framework for hierarchical visual representation learning that assigns distinct learning objectives to global and interaction representations. The global module learns object relations, task state, and temporal progress through future prediction on egocentric video. The Interaction module interprets wrist observations in global context and learns local alignment and contact cues through robot action supervision. Separate residual paths expose both representations to the action policy, preserving direct access to task context alongside fine-grained execution information. Ego-CEVR supports independent pretraining of its global video module on large-scale human egocentric videos and videos from diverse robot embodiments, without requiring robot action labels or paired wrist observations.

## 1. 核心问题与整体含义

- **研究问题**：如何把容易规模化获取、但通常没有机器人动作标注的人类第一人称视频，转化为机器人操作能力？
- **研究背景**：不同类型的具身数据提供的信息并不相同：
  - 人类第一视角视频和机器人头部相机视频包含任务过程、物体关系和场景变化，适合学习任务层面的视觉语境，但通常缺少精细动作标签和腕部观测。
  - 机器人演示包含头部与腕部观测及动作标注，可以监督细粒度的动作执行，却较难像网络或人类视频一样大规模收集。
- **论文主张**：不应要求所有数据源都具备相同的标注和视角，而应针对各自的信息特点设计不同学习目标。Ego-CEVR 将“理解任务全局进展”和“学习局部动作执行”分开建模，再让策略同时使用二者。

## 2. 方法论

### 2.1 核心思想：分层视觉表征

Ego-CEVR 包含三个主要部分：

1. **全局视频表征模块**：从当前的人类第一视角或机器人头部相机图像及语言指令中，提取全局表征 \(G_t\)，重点学习任务状态、物体关系和时间进程。
2. **交互表征模块**：将机器人腕部图像特征 \(W_t\) 与全局表征 \(G_t\) 结合，得到交互表征 \(I_t\)，重点学习局部对齐和接触等执行线索。
3. **动作策略**：保留基座策略原有的观测、语言和机器人状态上下文 \(P_t\)，并通过两条相互独立的残差交叉注意力路径读取 \(G_t\) 和 \(I_t\)，预测机器人动作。

其结构上的关键点是：**腕部交互特征以全局任务语境为条件，而全局表征本身不依赖腕部特征计算**；动作策略则可以直接访问全局和交互两类表征。

### 2.2 全局表征学习：通过未来视频预测

- 视觉骨干采用预训练 Wan2.2 视频模型中的 DiT，视觉 VAE 编码器被冻结。
- 给定当前头部／第一视角图像 \(I_t^H\) 和语言指令 \(\ell\)，VAE 将当前图像编码为潜变量 \(z_t\)。模型从 DiT 的若干中间层抽取注意力值特征，拼接为全局表征 \(G_t\)。
- 训练时，模型预测当前图像之后的视频潜变量。对未来潜变量 \(Z_{t+1:t+h}\) 加入噪声：
  \[
  Z^\tau_{t+1:t+h}=(1-\tau)Z_{t+1:t+h}+\tau\epsilon,\quad
  \epsilon\sim\mathcal{N}(0,I).
  \]
  DiT 根据当前图像、语言指令和噪声时间步预测向量场，以条件流匹配损失训练：
  \[
  \mathcal{L}_{\text{pred}}
  =\mathbb{E}_{\tau,\epsilon}
  \left[w(\tau)\,\mathrm{MSE}
  \big(u_v,\epsilon-Z_{t+1:t+h}\big)\right].
  \]
- 这一预训练过程只需视频及相应文本条件，不需要机器人动作标签、共同动作空间或配对腕部观测。**未来视频仅用于训练；推理时从当前观察提取表征，不生成未来视频。**

### 2.3 交互表征与动作学习：由机器人动作监督落地

- 腕部观测 \(I_t^W\) 经冻结 VAE 和共享的视频 DiT 提取为 \(W_t\)，再通过交互网络读取全局表征：
  \[
  I_t=F_I(W_t,G_t).
  \]
- 动作专家在原有策略上下文 \(P_t\) 上处理带噪动作序列，得到隐藏状态 \(h_t\)。随后分别通过针对 \(G_t\) 和 \(I_t\) 的交叉注意力分支进行残差融合：
  \[
  \tilde h_t=h_t+
  \alpha\,\mathrm{CrossAttn}_G(h_t,G_t)+
  \beta\,\mathrm{CrossAttn}_I(h_t,I_t).
  \]
  两个可学习缩放系数 \(\alpha,\beta\) 初始化为零。
- 动作序列使用流匹配训练。将真实动作 \(A_t\) 与高斯噪声线性插值得到带噪动作 \(A_t^\tau\)，模型预测相应向量场，最小化动作损失 \(\mathcal{L}_{\text{act}}\)。
- 机器人示范阶段的总训练目标为：
  \[
  \mathcal{L}_{\text{total}}
  =\mathcal{L}_{\text{act}}
  +\lambda_{\text{pred}}\mathcal{L}_{\text{pred}}.
  \]
  其中，动作监督训练动作专家及交互网络；视频预测则继续约束全局表征。

### 2.4 训练与迁移流程

论文将训练概括为分阶段过程：

- **多源视频预训练**：利用人类第一视角视频和不同机器人本体的头部视频学习全局表征。
- **真实机器人中训练**：用单一本体、跨任务和场景的机器人示范，将全局表征与腕部局部信息、精细动作联系起来。
- **少样本跨本体后训练**：在新机器人上使用少量同任务示范，对动作映射进行适配。论文示例使用 5 条新本体示范，并与 50 条源本体示范及视频数据结合。

## 6. 主要结论与发现

- 将任务级视频理解与局部动作执行表征分开学习，并在动作策略中分别利用二者，是 Ego-CEVR 的核心设计。
- 分层结构在多个基准上表现出较好成绩；消融结果尤其显示其在 LIBERO-Plus 视觉扰动下的增益明显。
- 对头部视角进行未来预测、而由机器人动作监督腕部交互表征，优于同时预测头部和腕部视频的设定在 LIBERO-Plus 上的表现。这支持论文关于“不同视角应承担不同学习目标”的设计判断。
- 人类第一视角视频能够为机器人操作提供有益信息，并在跨任务及跨本体设置中带来一定提升；但少量目标本体演示仍承担关键的动作对齐作用。
- 论文将人类到机器人的迁移视为更广义跨本体学习的一种，并强调视频知识需要通过机器人动作监督落地到具体执行。

## 7. 优点

- **数据与目标匹配明确**：不要求人类视频具备机器人动作标签或腕部配对数据，避免将异构数据强行统一成同一种监督形式。
- **表征层级设计清晰**：区分任务全局语境和局部交互线索，同时以独立残差路径送入动作策略，减少某一类表征完全覆盖另一类信息的风险。
- **预测训练与部署解耦**：未来视频预测用于塑造表征，但推理时无需生成未来视频，避免部署阶段承担完整视频生成成本。
- **实验类型较完整**：除标准操作评测外，还包括扰动鲁棒性、双臂任务、消融和真实机器人迁移实验。
- **对腕部预测目标进行了检验**：论文没有预设“更多预测监督一定更好”，而是报告了腕部视频预测可能损害扰动泛化的结果。

## 8. 不足与局限

- **规模化效果尚未验证**：作者明确指出，受资源限制，未在大规模人类第一视角视频上进行预训练，也未系统研究数据规模与模型规模变化下的 scaling 行为。
- **人类视频收益具有任务差异**：在 Plug Insertion、Water Pouring 和 Package Sorting 上，人类视频虽带来提升，但总体低于额外机器人头部视频；不能据此认为人类视频在所有任务中都同样有效。
- **跨本体证据有限**：真实少样本跨本体实验主要展示 G2 到 G1 的同任务迁移，尚不足以覆盖不同机器人形态、传感器布局、动作空间和任务类型。
- **真实场景覆盖有限**：真实机器人任务数量较少，任务迁移与跨本体迁移的场景也较集中，实际部署中的长时序、故障恢复和安全性等问题未在所给内容中充分评估。
- **统计和资源报告不足**：未提供显著性分析、重复次数及明确算力信息，给实验可靠性评估和复现带来限制。
- **外部基线的可比性需谨慎**：表格列出多项近期方法，但所提供内容未完整证明所有结果都来自完全一致的训练预算和运行条件。
- **仍依赖目标本体动作示范**：框架可以利用无动作标签视频学习全局知识，但细粒度的目标机器人动作映射仍需动作监督；论文展示的是少样本适配，而非完全无示范迁移。
