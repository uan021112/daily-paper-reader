## 摘要
相交两个多面体的操作可转化为使用由另一个多面体构造的一系列平面对一个多面体进行裁剪，这一操作是基于相交的网格插值和材料界面重建的核心。R3D 是一个用于此类操作的鲁棒库，实现了 Sugihara 算法。本文介绍 J3D，这是 Sugihara 裁剪算法的一种新实现，其性能较 R3D 有显著提升。

## Abstract
The operation of intersecting two polyhedra, which can be reduced to clipping one polyhedron with a series of planes formed from another polyhedron, is central to intersection based mesh interpolation and material interface reconstruction. R3D is a robust library for such operation which implements the algorithm of Sugihara. In this paper, we present J3D, a new implementation of the clipping algorithm of Sugihara that provides substantial performance improvements over R3D.
