ABSTRACT
Single-image 3D scene construction is a fundamental problem in 3D vision. Re-
cent methods such as SAM-3Dfy enable end-to-end reconstruction of 3D assets
and their scene layouts, but still struggle with fine-grained scene geometry and
asset quality. Meanwhile, specialized 3D object generators provide detailed ob-
ject geometry, while 3D foundation models offer strong and generalizable spatial
understanding. We propose Easy-3Dfy, a compositional workflow that decou-
ples object generation from scene layout estimation, allowing specialized models
to fully exploit their respective strengths. An RPF-based aligner then bridges
these capabilities by establishing geometric correspondence between object-local
meshes and partial scene pointmaps, recovering object layout for scene composi-
tion. Without requiring complete scene-level supervision, the proposed workflow
consistently outperforms SAM-3Dfy across multiple geometric metrics on Scene-
Maker and 3D-FUTURE200.
Our results demonstrate that explicit geometric
composition can effectively combine high-quality object generation with strong
spatial understanding, while enabling the workflow to benefit independently from
advances in both 3D object generation and foundation models. Project page and
code release: https://easy3dfy.github.io.

INTRODUCTION
Single-image 3D scene construction is a fundamental problem in 3D vision, aiming to recover a
set of complete 3D object assets and arrange them in a common metric coordinate system from a
single image. Recent advances have made substantial progress toward this goal. In particular, SAM-
3Dfy (SAM 3D Team et al., 2025) provides an end-to-end framework that jointly addresses openset
object asset generation and scene layout estimation, demonstrating the feasibility of reconstructing
complete 3D scenes from a single image. However, jointly addressing these capabilities within a
scene-level pipeline can limit the fine-grained quality of both generated assets and spatial layouts.
The object assets produced by such scene-oriented systems can remain less detailed than those from
specialized 3D object generation models, while the lack of explicit geometric alignment can lead to
interpenetrating and floating object layouts.

Meanwhile, recent progress in 3D foundation models has provided strong alternatives for the two
complementary capabilities involved in scene construction. In particular, 3D object generation mod-
els can produce increasingly complete and detailed object assets, while monocular pointmap recon-
struction models provide strong scene-level spatial cues. Such decoupling allows each type of model
to fully exploit its specialized capability, while making the overall scene construction workflow nat-
urally extensible to future advances in either direction.
Building on these complementary capabilities, we introduce Easy-3Dfy, a compositional workflow
that reformulates single-image 3D scene construction as an object-level point cloud registration
problem. Specifically, given a complete object asset and the corresponding partial scene point cloud,
the goal is to estimate the transformation from the asset-local coordinate system to the scene coor-
dinate system. To address this, Easy-3Dfy incorporates a Rectified Point Flow Model (RPF) aligner
to resolve geometric correspondence and recover the relative transform parameters between the two
point sets. Specifically, RPF operates as a generative registration model that directly synthesizes
surface-aligned point clouds conditioned on the object asset and the scene point cloud, establishing
robust point-to-point relationships. This aligner acts as a critical geometric bridge, allowing the in-
dependent object generation and scene reconstruction modules to function collaboratively within a
unified framework.
To compare and validate the scene geometric construction capability of Easy-3Dfy, we first evaluate
the quality of asset composition and scene layout produced by Easy-3Dfy and SAM-3Dfy using
the same generated object assets on Scene-Maker (Shi et al., 2025) and 3D-FUTURE200 (Fu et al.,
2021). Easy-3Dfy consistently improves multiple geometric metrics at the scene-level, demonstrat-
ing that explicit geometric alignment is effective for high-quality scene construction. Furthermore,
by replacing the underlying 3D object generation models, we observe that Easy-3Dfy can further
benefit from improvements in upstream object generation, indicating the scalability of the proposed
decoupled workflow.
Our contributions are summarized as follows:
• We propose Easy-3Dfy, a compositional workflow for single-image 3D scene construction
that decouples object asset generation from scene-level spatial reconstruction, allowing
specialized models to fully exploit their respective strengths.
• We introduce an RPF-based geometric aligner that formulates scene construction as an
object-level point cloud registration problem and establishes geometric correspondence be-
tween object assets and partial scene point clouds, enabling explicit transformation estima-
tion from the object-local coordinate system to the scene coordinate system.
• We systematically validate the effectiveness and scalability of compositional scene con-
struction.
Controlled comparisons show that explicit geometric composition improves
scene geometric quality even with identical object assets, while experiments with differ-
ent object generation models demonstrate that the proposed workflow can independently
benefit from advances in upstream 3D object generation.

RELATED WORK
2.1
SINGLE-OBJECT IMAGE-TO-3D GENERATION
Image-to-3D models provide object-local geometry, texture, and topology that can serve as reusable
asset priors. Representative systems improve object-level shape quality, material synthesis, native
mesh generation, or generation efficiency (Tencent Hunyuan3D Team, 2025; Xiang et al., 2025;
Wang et al., 2026a; Xu et al., 2026). Image-generation models such as FLUX-2, GPT-Image-2, and
Gemini Image can further provide completed object images before asset generation (Black Forest
Labs, 2025; OpenAI, 2026; Google, 2025). These advances change the role of object generation in
scene construction: rather than requiring a scene model to synthesize every asset internally, a com-
positional system can obtain an object-local mesh from a specialized provider and focus separately
on scene placement. In our formulation, these models serve as upstream providers. Easy-3Dfy does
not claim to improve their outputs; it discards every provider pose or layout output and estimates a
local-to-pointmap-scene transformation from scene geometry.
2.2
MONOCULAR GEOMETRY ESTIMATION AND POINT-CLOUD ALIGNMENT
Geometry reconstruction models such as DUSt3R, VGGT, π3, Lotus-2, MogeV2 and Depth Any-
thing V3 estimate depth, pointmaps, normals, camera parameters, or ray representations from input
images (Wang et al., 2024; 2025a; 2026b; He et al., 2026; Wang et al., 2025b; Lin et al., 2025).
These outputs provide scene-level visible geometry, but do not directly define an object’s complete
layout because of partial visibility, depth uncertainty, and object boundaries. Classical and learned
registration methods recover rigid or similarity transforms from correspondences, local features, or
iterative refinement (Fischler & Bolles, 1981; Besl & McKay, 1992; Qin et al., 2022). However,
when registering partial point clouds derived from monocular depth estimates to full point clouds
produced by 3D generative models, their effectiveness can be limited by the domain gap between
the two geometry sources. Generative registration methods such as RPF and RAP offer a comple-
mentary formulation for ambiguous and partial point-cloud alignment (Sun et al., 2025; Pan et al.,
2025). Easy-3Dfy uses an RPF-based direct layout aligner, but shifts its role from generic registra-
tion to object-level geometric composition: rendered partial observations and layout augmentation
provide alignment supervision without requiring complete calibrated scenes for the alignment stage.
Rather than seeking a new general-purpose registration backbone, we train a registration module
specialized for single-image 3D scene construction, matching partial query point clouds extracted
from monocular pointmaps to object-local anchor geometry.
2.3
SINGLE-IMAGE 3D SCENE GENERATION AND LAYOUT PREDICTION PARADIGMS
Existing single-view scene-generation systems combine object assets and layouts in different ways.
Joint methods generate multiple assets and relative poses in one end-to-end process, thereby ex-
ploiting global image context while coupling asset generation, layout prediction, and scene-level
supervision. Two-stage or post-hoc systems instead assemble objects after asset generation using
geometric, physical, differentiable render-and-compare, or relation-aware constraints. CAST, 3D-
RE-GEN, MIDI, SceneGen, and SAM-3Dfy exemplify distinct points in this design space (Yao et al.,
2025; Sautter et al., 2025; Huang et al., 2025; Meng et al., 2025; SAM 3D Team et al., 2025). These
systems commonly operate under an object-conditioned protocol with automatic, user-provided, or
precomputed masks. Scene-Maker first decouples the de-occlusion model from 3D object genera-
tion; however, it still relies on scene-level supervision to enhance layout prediction performance (Shi
et al., 2025). Easy-3Dfy more strictly decouples object-asset generation from geometric alignment:
it retains reusable asset and geometry priors, discards provider layout outputs, and learns the re-
maining local-to-pointmap-scene composition directly in the point-cloud domain.

METHOD
3.1
PROBLEM FORMULATION
Given an input image I and N object masks {Mi}N
i=1, Easy-3Dfy predicts a pixel-aligned scene
pointmap P ∈RH×W ×3 and surface-normal map N ∈RH×W ×3. Here, Mi denotes the visible


region of object i; mask estimation is an upstream component and is not studied in this work. Ap-
plying Mi to I, P, and N yields the object image Ii, object-specific partial query point cloud Pi,
and its surface normals Ni. Easy-3Dfy converts Ii into an object-local mesh asset Xi and uses the
pointmap scene coordinate system as the common reference frame.
For each pair (Xi, Pi), Easy-3Dfy predicts a transform Ti that maps the complete object-local mesh
to a position consistent with the geometric surface represented by Pi. We parameterize Ti as a
uniform-scale similarity transform:
Ti(x) = siRix + ti,
(1)
where si > 0 is a uniform scale, Ri ∈SO(3) is a rotation matrix, and ti ∈R3 is a translation in
the pointmap scene coordinate system. Applying Ti to each complete object-local mesh yields the
assembled scene.
Easy-3Dfy is connected by three explicit interfaces: object-local meshes, a scene pointmap, and
local-to-pointmap-scene transforms. These interfaces make the geometric composition stage ex-
plicit, separating reusable asset and scene-geometry modules from placement estimation while al-
lowing each module to be replaced without redefining the composition problem.
3.2
CONSTRUCTING OBJECT ASSETS FROM A SINGLE IMAGE
As illustrated in Fig. 2, Easy-3Dfy first converts the input image into object-local mesh assets. For
a specific object, the following three-stage workflow constructs its asset.
Object extraction.
Object-mask estimation is outside the scope of this work. Easy-3Dfy accepts
masks from an upstream automatic or user-prompted segmentation model, such as SAM (Kirillov
et al., 2023), and uses each Mi to define the visible object region and crop box. In our benchmark
experiments, the masks are provided by the datasets as shared inputs for consistent comparison
across scene-construction methods.
Occlusion-aware completion.
For each object, a prompted image-editing model completes oc-
cluded regions. Its reference inputs include the original image, the object crop, and the crop with
the object masked. These inputs provide global image context, information about neighboring oc-
cluders, and the object’s outline, facilitating recovery of occluded appearance and shape cues.
Image-to-3D asset generation.
Finally, an image-to-3D generative model generates the complete
object-local mesh asset Xi conditioned on the completed object image.
By applying this workflow to each object to be constructed, Easy-3Dfy produces the mesh-asset set
{Xi}N
i=1. We use each module according to its original inference protocol; the concrete providers
and implementation settings are specified in the appendix.
3.3
LAYOUT ESTIMATION AND SCENE ASSEMBLY
Object-specific partial query construction.
Following Sec. 3.1, Mi selects object i from the
scene pointmap and normal map. Rule-based filtering removes boundary artifacts, outliers, and
interpolation contamination, yielding the visible object-specific partial query (Pi, Ni) in the scene
coordinate system. From the complete object-local mesh Xi, we sample the anchor point cloud and
normals (Ai, N A
i ). These anchor and query pairs form the geometric input to RPF; filtering, normal
construction, and sampling details appear in the appendix.
RPF-based aligner and direct registration.
RPF (Sun et al., 2025) is a DiT-based conditional
generative model whose condition is divided into anchor and query groups. Each point is represented
by its XYZ coordinates and surface normal. Given the anchor geometry (Ai, N A
i ) and partial query
(Pi, Ni), RPF predicts, for every query point pij ∈Pi, a correspondence position baij in the anchor
coordinate system. Intuitively, if pij represents a visible headlamp in the input image, baij localizes
the matching headlamp region on the complete car asset. The predicted pairs {(pij, baij)}j therefore
establish pointwise query-to-anchor correspondences. Figure 3 illustrates how this correspondence
predictor is trained from object-level data.

Pose recovery and scene assembly.
RPF pairs each query point pij with a predicted correspon-
dence position baij on the anchor geometry. We apply Umeyama fitting to these correspondences and
compose the fitted transform with the preprocessing transforms to recover the local-to-pointmap-
scene transform Ti in Eq. 1. The point-set normalization, fitting procedure, and numerical safe-
guards are detailed in the appendix. Finally, we apply Ti to the complete object-local mesh, rather
than only to its sampled anchors, and assemble all transformed meshes into the output scene.

Object-level alignment-pair construction.
As illustrated in Fig. 3, each training sample starts
from a single object mesh. We sample an anchor point cloud Ai and its surface normals N A

from
the mesh surface, and render the object from randomly sampled viewpoints to obtain pixel-aligned
RGB and depth images. We apply the same monocular geometry model used by Easy-3Dfy to each
rendered RGB image, obtaining the partial query point cloud Pi and surface normals Ni. Random
occlusions are then applied to the partial query to simulate the incomplete geometry encountered at
inference time.
The ground-truth correspondence positions x0 are recovered from the rendered depth image at the
retained pixels. Because the RGB and depth renders are pixel-aligned, each query point in (Pi, Ni)
is paired with one position in x0 on the complete object surface. To expose RPF to changes of
coordinate frame and object pose, we divide the training variables into a query-side group (Pi, Ni)
and an anchor-side group (Ai, N A
i , x0), and apply independent random rotations, scales, and trans-
lations to the two groups. We additionally apply random axis-wise scaling to perturb object shape,
improving robustness to geometric variation across mesh providers. The appendix provides the
detailed rendering, occlusion, sampling, and augmentation settings.
Unlike scene-level 3D generation pipelines, Easy-3Dfy learns point-cloud registration at the object
level. Its training data therefore require neither complete scene-level data nor explicit modeling


of inter-object relationships during data construction. This object-level formulation substantially
simplifies training-pair synthesis and allows the dataset to be scaled efficiently.
3.5
IMPLEMENTATION SUMMARY
Our implementation instantiates each interface with a set of interchangeable foundation models. For
monocular scene geometry, we use MogeV2 (Wang et al., 2025b) and Depth Anything V3 (Lin et al.,
2025). MogeV2 directly predicts the surface-normal map together with scene geometry, whereas for
Depth Anything V3 we estimate surface normals from its predicted pointmap. The partial geometric
observations used to train RPF are constructed with MogeV2. The training meshes are drawn from
the publicly released synthetic 3D asset collection introduced by Orient Anything V2 (Wang et al.,
2026c), which was created through its generative 3D asset pipeline.
The main comparison uses MogeV2 for scene geometry and SAM-3Dfy (SAM 3D Team et al., 2025)
meshes as object assets. In the modular provider studies, occlusion-aware completion uses FLUX-
2-pro (Black Forest Labs, 2025) and GPT-Image-2 (OpenAI, 2026), while object-local meshes are
generated with Hunyuan3D-2.0 and Hunyuan3D-3.1 (Tencent Hunyuan3D Team, 2025; Tencent
Cloud, 2026), TRELLIS-2.0 (Xiang et al., 2025), Meshy-T2 (Xu et al., 2026), and Tripo-V3 (Tripo
AI, 2026). All mesh providers are used only to supply object-local assets: Easy-3Dfy does not
consume provider-specific pose or layout predictions.
The appendix reports the completion prompt, sampling rules, RPF training and inference settings,
geometric augmentation, similarity fitting, and evaluation-time alignment.
4
EXPERIMENTS
4.1
EXPERIMENTAL SETUP
Datasets.
We evaluate on 1,000 scenes sampled from Scene-Maker (Shi et al., 2025) and 200
scenes sampled from the 3D-FUTURE (Fu et al., 2021) test set, denoted 3D-FUTURE200. Scene-
Maker covers broader, more open-set object categories, whereas 3D-FUTURE200 primarily con-
tains indoor furniture scenes. Because mask estimation is outside our scope, all methods receive the
object masks provided by each dataset, isolating scene construction from segmentation quality and
ensuring consistent comparison.
Compared methods.
We compare Easy-3Dfy with SAM-3Dfy (SAM 3D Team et al., 2025),
MIDI (Huang et al., 2025), and SceneGen (Meng et al., 2025). In the main Easy-3Dfy setting, we
use the SAM-3Dfy meshes as object assets and estimate their layouts from the mesh and pointmap
geometry. We further evaluate the effect of the RPF design, mesh provider, and pointmap and
occlusion-aware completion models through the ablations below.
Metrics.
We report Scene-CD, Scene-FScore, Object-CD, Object-FScore, and scene-aligned per-
object 3D bounding-box IoU. Chamfer Distance (CD) is the sum of the two non-squared mean
nearest-neighbor distances between sampled point sets (Fan et al., 2017). F-score is the harmonic
mean of nearest-neighbor precision and recall under a distance threshold τ (Knapitsch et al., 2017);
we use τ = 0.1, following the scene-level threshold used by MIDI (Huang et al., 2025). We use
the same definitions for scene- and object-level point sets. The evaluation-time scene and object
alignment procedures, point-sampling settings, averaging rules, and the interpretation of object-level
diagnostics are common evaluation details and are specified in the appendix.

4.3
ABLATIONS
We ablate three components that determine the final constructed scene: the geometric preprocessing
and input channels of RPF, the pointmap and occlusion-aware completion models, and the object
mesh provider. These studies respectively measure sensitivity to the design of the alignment module
, scene-geometry estimation and object completion, and asset quality.
Alignment design.
We further ablate point-cloud preprocessing and RPF input channels. Rule-
based cleaning suppresses boundary and interpolation noise but may also remove useful geometry.
As RPF is trained on augmented data and tolerates moderate noise, omitting cleaning has only
a small effect at the reported precision, primarily a slight decrease in Scene-FScore. Removing
surface-normal conditioning degrades all three layout metrics. Full results appear in Appendix A.4.

5
ANALYSIS AND METRIC INTERPRETATION
5.1
WHAT DOES DIRECT ALIGNMENT IMPROVE?
Figure 5 compares these methods with matched inputs and views, exposing differences in the scale,
orientation, ordering and relationships of contact of the object. MIDI (trained on 3D-FRONT) and
SceneGen (trained on 3D-FUTURE) generally recover the object categories in a multi-object image,
but often distort relative orientation, ordering, and spacing in openset.


Compared with previous methods, SAM-3Dfy is able to predict the approximate positions and or-
dering of objects in the scene in an open-set setting. However, as shown in Figure 5, its predicted
layouts still exhibit noticeable geometric inconsistencies. Some objects suffer from interpenetration,
such as the pillow floating behind the sofa backrest, while the tabletop and chairs are not properly
aligned with the flat ground plane. These artifacts indicate that SAM-3Dfy still struggles to pre-
serve fine-grained spatial relationships and contact relationships between objects. Using the same
SAM-3Dfy meshes, Easy-3Dfy instead registers each asset to its pointmap-derived partial query,
substantially improving the spatial consistency of object layout and resolving the aforementioned
ambiguities of spatial relationships.
Note that small or severely occluded objects, contaminated masks, and unreliable pointmaps for
reflective or transparent surfaces can leave the transform underconstrained, producing an inaccurate
pose. Appendix A.7 analysis failure patterns of these cases.

5.3
WHAT GEOMETRY-CENTRIC LAYOUT METRICS OMIT
The preceding ablations and analyses demonstrate both the effectiveness and the scope of the cur-
rent evaluation. Scene-CD, Scene-FScore, and scene-aligned 3D bounding-box IoU improve with
asset quality and registration accuracy, showing that they effectively measure geometric fidelity and
spatial arrangement. However, they do not directly reflect appearance fidelity, texture and material
quality, semantic identity, scene completeness, or perceptual plausibility. Even within geometry,
point-set distances and bounding-box overlap have limited sensitivity to topology and fine surface
structure.
The close-ups in Figure 4 and Figure A1 make this boundary explicit: a scene can achieve a better
layout score while retaining blurred textures or local details, whereas a visually detailed asset can
remain geometrically incompatible with the observed scene. Future evaluation protocols should
therefore combine geometric, visual, semantic, and completeness criteria to provide a more complete
measure of generated-scene quality.
6
CONCLUSION
We presented Easy-3Dfy, a modular framework that formulates single-image 3D scene construction
as object-level geometric composition across replaceable object assets, scene geometry, and metric
layout alignment. To address the core layout-alignment problem, we train an RPF aligner on scalable
object-level data to recover local-to-scene transforms, improving layout accuracy without requiring
complete scene supervision. Experiments demonstrate consistent gains under the shared-mask pro-
tocol and applicability across mesh providers. We also identify limitations of geometry-centric
metrics and motivate more complete evaluation protocols for generated 3D scenes.

A.1
ADDITIONAL IMPLEMENTATION DETAILS
Occlusion-aware completion prompt.
The completion model receives three reference images.
We use the following prompt:
Complete the redrawing and restoration of the target object using the three pro-
vided reference images:
1. The first image is the original cropped region, containing the target object
together with its local foreground and background.
2. The second image is the crop-aligned target mask. White denotes the target,
and black denotes non-target regions.
3. The third image is the complete scene image, which provides global context
and a reference for the target’s actual appearance in the scene.
Use these inputs to extract the target object precisely and restore it intelligently:
1. Structural completion and de-occlusion: Completely ignore and remove
any foreground objects occluding the target. Infer the occluded regions from
the geometric cues visible on the target and seamlessly reconstruct its com-
plete 3D structure.
2. Strict preservation of intrinsic attributes: Faithfully preserve the target’s
intrinsic material, texture, color distribution, and overall shape characteristics
from the original image.
3. Isolation on a pure black background: Center the complete, unobstructed
target object on a pure black (#000000) background.
4. Neutral-lighting reconstruction: Remove complex environmental high-
lights, reflections, and strong cast shadows inherited from the original scene.
Strictly avoid generating any foreground occluders, broken edges, truncated struc-
tures, environmental light spots, complex backgrounds, extraneous objects outside
the masked target, implausible perspective distortion, blurred textures, or overlays.

A.3
EVALUATION-TIME ALIGNMENT AND METRIC PROTOCOL
Before computing metrics, we align each predicted scene and its ground-truth counterpart using
scene bbox chamfer rt. The coarse bounding-box alignment first fixes the uniform scale as
the ratio between the ground-truth and predicted aggregate AABB diagonals, s = dgt/dpred, and
translates the center of the scaled predicted AABB to the ground-truth AABB center. This scale
remains fixed thereafter. Starting from the scaled and translated prediction, we use Adam for 60
iterations to optimize only a rigid rotation and translation (R, t) under the Chamfer objective. The
resulting single global transform is applied to every predicted object in that scene. Scene-CD, Scene-
FScore, and scene-aligned per-object bounding-box IoU are then computed in this common frame.
Object-CD and Object-FScore instead use independent object-local normalization followed by Fil-
terReg/ICP rigid registration; they are therefore asset-geometry diagnostics rather than evidence
about layout. For the small number of failed scenes or objects, CD is not included in the corre-
sponding CD aggregation, whereas F-score and bounding-box IoU are assigned zero and retained in
the average.

A.6
INFERENCE EFFICIENCY
The overall inference time of Easy-3Dfy is primarily determined by the runtime of its individual
modules and the degree of parallelism. For example, completing a single object using the official
FLUX-2-pro API takes on the order of tens of seconds. Low-poly mesh generators such as Meshy-
T2 can produce geometries suitable for registration within 10 seconds, whereas more sophisticated
models such as Hunyuan3D-V3.1 require approximately 1 minute to generate a complete textured
asset. Our RPF-based aligner introduces only a small additional runtime overhead: it supports par-
allel inference and registration of multiple meshes, with each batch processed within a few seconds.
A.7
REPRESENTATIVE FAILURE CASES
Layout estimation can easily become underconstrained or fail when object-specific partial geometry
is severely degraded or insufficient. Such geometric information loss typically arises from visual
challenges, including tiny object scales, severe occlusions, motion or defocus blur, and unreliable
depth maps. As illustrated in Figure A2, different paradigms exhibit distinct failure patterns under
these challenging scenarios: baseline methods (such as SAM-3D-like frameworks) often suffer from
severe drift in scale and translation due to brittle pointmap regression, whereas Easy-3Dfy maintains
much better spatial bounded bounds but occasionally experiences rotation instability when geomet-
ric constraints become severely underdetermined.
