## 摘要
自监督视觉 Transformer（ViT）（如 DINO）能够编码丰富的语义信息，因此无需训练即可将物体与背景分割开来，并通过特征聚类发现物体部件。本文聚焦于部件发现，即将前景物体划分为语义部件。现有方法生成的部件边界不够精确。我们将这一问题归因于 DINO 训练中采用的固定 ViT 图像块网格：跨越边界的图像块包含来自多个部件的像素。尽管基于不变性的 DINO 训练或许能够将这种像素级混合吸收到清晰的特征表示中，但对超过 2.6 万个前景图像块的实验表明，事实并非如此：与边界重叠的图像块会产生熵更高、分配置信度更低的特征，从而使预测的部件边界变得模糊。与其耗费大量精力在几何一致的区域上重新训练 DINO，不如直接从边界检测器获取边界，以补充 DINO 特征所缺乏的几何信息。受此启发，我们提出 Part-DINO，这是一种无需训练的框架，将低级图像分割得到的边界与 DINO 的语义特征相结合。我们利用边界将图像划分为区域，在每个区域内汇聚 DINO 特征，并对这些特征进行分组以发现部件。Part-DINO 无需任何训练即可生成结构连贯的部件分配，在四个标准基准（CUB、CelebA、PartImageNet-OOD、PartImageNet-Seg）上优于无需训练的基线方法，同时性能可与弱监督及无监督方法相媲美。

## Abstract
Self-supervised Vision Transformers (ViTs) like DINO encode rich semantics, enabling training-free segmentation of objects from the background and discovery of their parts via feature clustering. This paper focuses on part discovery: partitioning a foreground object into semantic parts. Existing approaches produce imprecise part boundaries. We trace this to the rigid ViT patch grid used in training DINO, where patches straddling boundaries contain pixels from multiple parts. While DINO's invariance-based training could absorb this pixel-level mixing into clean features, experiments with over 26K foreground patches show it does not: boundary-overlapping patches produce features with higher entropy and lower assignment confidence, blurring predicted part boundaries. Rather than make the massive effort of retraining DINO over geometrically coherent regions, an easier approach is to take boundaries directly from a boundary detector, which supplies the geometric information DINO's features lack. Motivated by this, we introduce Part-DINO, a training-free framework that combines boundaries from low-level image segmentation with DINO's semantic features. We use the boundaries to partition the image into regions, pool DINO features within each region, and group them to discover parts. Without any training, Part-DINO produces structurally coherent part assignments, outperforming training-free baselines across four standard benchmarks (CUB, CelebA, PartImageNet-OOD, PartImageNet-Seg) and remaining competitive with weakly-supervised and unsupervised methods.

## 1. 核心问题与整体含义

- **研究任务**：将前景物体划分为跨实例语义一致的部件，例如鸟的头、翅膀和身体，且不依赖部件标注进行训练。
- **核心问题**：基于 DINO 特征聚类的免训练部件发现方法，虽然能捕捉语义信息，但预测的部件边界往往模糊、不够准确。
- **作者的解释**：ViT 将图像切分为固定大小的方形图像块（patch）。一个 patch 若跨越两个部件边界，就会混入两侧像素；这种像素混合会传递到特征表示中，使边界处的特征更难分类。
- **总体思路**：不重新训练 DINO，而是让两类信息分工互补：用低层图像结构确定“边界在哪里”，用冻结的 DINO 特征判断“区域属于哪个语义部件”。

## 2. 方法论

### 核心流程

Part-DINO 是一个无需训练的框架，主要包含区域生成、全局原型生成和区域分配三个阶段：

1. **前景提取**  
   使用 SAM3 获取物体前景掩码，排除背景区域。

2. **结构边界与原子区域生成**  
   - 对输入图像计算 RAMP（Ramp Transform）结构边缘图。该变换从图像强度变化中估计局部对比度，使用 \(0^\circ、45^\circ、90^\circ、135^\circ\) 四个方向。
   - 在边缘图上应用 Watershed（分水岭）算法，将前景切分为边界贴合图像结构的区域。
   - 将小于设定面积阈值的微小区域合并到特征最相似的邻区。默认最小区域面积为 10 像素。合并只会移除已有边界，不会新增边界。

3. **区域特征池化**  
   - 用冻结的 DINOv2 ViT-B/14（带 registers）提取 patch 特征，并双线性上采样到图像分辨率。
   - 对每个区域内像素的特征做平均池化，再进行 \(L_2\) 归一化，得到区域表示。可概括为：
     \[
     \hat f_r=\frac{1}{|r|}\sum_{p\in r} F_p
     \]
     其中 \(F_p\) 表示像素位置 \(p\) 对应的 DINO 特征。

4. **全局部件原型生成**  
   - 从参考图像集合中提取所有区域特征。
   - 按类别分别对区域特征运行 K-Means，形成 \(K\) 个部件原型。\(K\) 是预先指定的部件粒度。

5. **测试图像区域分配**  
   - 对测试图像重复前景提取、区域生成和特征池化。
   - 根据区域特征与原型的余弦相似度，将每个区域分配给最相近的原型：
     \[
     k^*=\arg\max_k \hat f_r^\top c_k
     \]
   - 同一区域内的像素得到同一标签，因此输出边界继承自分水岭生成的结构边界。

### 多类别情形

对于包含多个物体类别的数据集，方法为每个类别分别建立部件原型。测试时用 DINO 的 CLS 特征与各类别参考图像的平均 CLS 特征比较，先确定类别，再使用该类别对应的部件原型。

### 关键分析依据

作者分析了 PartImageNet 中 **26,459 个前景 patch**，发现 patch 越靠近部件边界：
- 空间纯度越低；
- 特征熵越高；
- 最相近与次相近部件原型的相似度差（top-2 margin）越小。

这支持了“patch 网格造成的边界混合会降低特征判别可靠性”这一方法动机。

## 6. 主要结论与发现

- 作者的边界分析显示，ViT patch 靠近真实部件边界时，其空间纯度下降，特征熵上升，分配置信度降低；边界处的表示质量问题并非仅限于图像像素层面。
- 将图像结构边界用于确定区域、将 DINO 特征用于区域语义分组，可以弥补固定 patch 网格的空间局限。
- 与 patch-based 免训练基线相比，Part-DINO 在多个数据集上整体取得更好的部件发现结果：
  - CUB 上 \(K=16\) 时，NMI 从 56.92 提高到 65.45，ARI 从 35.10 提高到 46.00；
  - CelebA 上，Part-DINO 明显改善了基线几乎失效的聚类表现；
  - PartImageNet-Seg 上，各粒度下均优于免训练基线，并在 \(K=8\) 时超过 MPAE 的 NMI 和 ARI；
  - PartImageNet-OOD 上，ARI 通常提升，但 NMI 有时略低，说明结构连贯性与更细碎的聚类之间存在权衡。
- 在 CUB 上，结构边缘优于 DINO 语义边缘；RAMP + Watershed 也优于 SLIC，支持“边界定位由图像结构提供、语义归类由 DINO 提供”的设计。

## 7. 优点

- **问题诊断具体**：不仅指出部件边界模糊，还用 26K 余个 patch 的统计分析检验边界混合与特征不确定性的关系。
- **方法简单且免训练**：不需要针对目标数据集优化大型模型，主要通过区域生成、池化和聚类完成推理。
- **语义与几何分工清晰**：DINO 负责语义相似性，RAMP 与 Watershed 负责空间边界，避免用同一类特征同时承担边界定位和语义归类。
- **实验维度较丰富**：包含多数据集、多粒度、方法对比、消融和运行时间分析。
- **推理成本增量有限**：相对于 DINO 与 SAM3 本身的耗时，区域生成带来的额外延迟较小。

## 8. 不足与局限

- **依赖图像对比度**：RAMP 依赖局部强度变化。在部件间低对比、纹理少或光照均匀的图像中可能无法形成足够边界；阴影、反光或强光照梯度则可能引入与部件无关的边缘。
- **需要预先指定部件数 \(K\)**：当类别间的部件粒度不同，或实际部件数未知时，使用固定 \(K\) 会限制适用性。
- **前景提取依赖外部模型**：实验使用 SAM3 获取前景掩码；因此总体性能和运行时间会受到前景模型质量与成本影响，不能简单理解为完全不依赖预训练工具。
- **聚类仍是无语义命名的**：方法输出的是无标签部件簇；若要得到“头、眼睛、翅膀”等可解释名称，还需额外的语义标注或视觉语言模型。
- **NMI 与 ARI 的权衡**：区域化方法倾向于提升空间一致性，但在部分设置中 NMI 会下降，说明不同指标关注的聚类性质不完全一致。
- **统计不确定性报告不足**：缺乏多次运行方差或置信区间，难以判断小幅指标差异的稳定性；论文将结果可重复性主要归因于使用聚类中心，但这并不能完全替代对抽样和聚类随机性的统计报告。
- **实验覆盖有限**：虽覆盖四个基准，但不同类型图像、极端光照、低对比边界和更广泛的真实场景并未系统验证；部分消融主要集中在 CUB。
- **资源报告不完整**：给出了单图延迟和一组硬件配置，但没有汇总所有实验的总算力、显存或完整复现环境信息。
