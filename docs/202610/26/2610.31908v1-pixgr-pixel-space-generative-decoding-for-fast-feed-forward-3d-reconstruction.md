## 摘要
我们提出 PixGR，这是一种高效框架，将轻量级像素空间生成建模融入前馈式 3D 高斯重建，以建模场景不确定性。上下文观测仅需编码一次，得到场景潜在表示；该表示用于条件化生成式解码，使模型能够从含噪目标视图生成共享的 3D 高斯表示。我们采用像素空间流匹配来表述这一过程，通过可微渲染实现对 3D 重建的端到端优化，并直接施加像素空间生成监督。这避免了基于 VAE 的潜变量压缩，以及以往两阶段流程中固有的误差传播。为保持前馈推理的效率，PixGR 会缓存场景表示，并使用轻量级 DiT 解码器进行迭代推理。实验表明，在具有挑战性的稀疏视图设置中，尤其是观测视角间隔较大及进行视角外推时，PixGR 的表现优于基于回归的方法。同时，它将推理时间控制在亚秒级，且性能可与规模大得多的预训练生成模型相媲美。项目主页：https://ranrhuang.github.io/pixgr/。

## Abstract
We present PixGR, an efficient framework that integrates lightweight pixel-space generative modeling into feed-forward 3D Gaussian reconstruction to model scene uncertainty. Context observations are encoded once into a scene latent representation, which conditions generative decoding from noisy target views to produce a shared 3D Gaussian representation. We formulate this process using pixel-space flow matching, enabling end-to-end optimization of 3D reconstruction with direct pixel-space generative supervision through differentiable rendering. This avoids VAE-based latent compression and error propagation inherent in previous two-stage pipelines. To preserve feed-forward efficiency, PixGR caches the scene representation and performs iterative inference using a lightweight DiT decoder. Experiments demonstrate that PixGR outperforms regression-based approaches in challenging sparse-view settings, particularly with widely spaced observations and view extrapolation. Meanwhile, it maintains sub-second inference and remains competitive with substantially heavier pretrained generative models. Our project page is available at https://ranrhuang.github.io/pixgr/.

## 1. 核心问题与整体含义

- **研究问题**：如何从少量图像快速重建可用于新视角合成的三维场景，尤其是在输入视角稀疏、视角间隔较大，或目标视角超出观测范围时。
- **研究动机**：
  - 前馈式回归方法能快速预测 3D 表示，但稀疏观测下场景几何和外观往往存在多种合理解释。确定性回归难以表示这种不确定性，可能产生模糊结果，或在遮挡、未观测区域重建失败。
  - 既有生成式重建方法通常将“生成图像”和“重建 3D”分成两阶段，可能在阶段间传播误差；部分方法还依赖 VAE 潜空间，可能损失细节，并使用计算量较大的生成模型。
- **整体思路**：PixGR 将轻量级生成建模直接融入前馈式 3D 高斯重建。它先把上下文图像编码为 3D 感知的场景表示，再以含噪目标视图为输入，迭代预测一个可共同支持上下文视角与目标视角的 3D 高斯场景。其目标是在具备一定生成能力的同时，避免传统两阶段流程的误差传递，并保留较快推理速度。

## 2. 方法论

### 核心框架

PixGR 由两部分构成：

1. **场景编码器**：将上下文图像及相机参数编码为场景潜在表示。论文使用以 VGGT 为基础的编码器，借助其预训练的 3D 几何能力提供场景条件信息。
2. **生成式高斯解码器**：接收场景表示、目标视角的含噪图像、目标相机参数和时间步，预测像素对齐的 3D 高斯参数。

关键设计是：上下文图像只编码一次，所得场景表示在生成迭代中缓存复用；生成过程不是先生成一组彼此独立的图像再重建 3D，而是持续预测一个共享的 3D 高斯表示，并通过渲染约束各视角的一致性。

### 像素空间流匹配

训练时，将干净目标图像 \(x\) 与高斯噪声 \(\epsilon\) 按时间步 \(t\) 线性混合：

\[
z_t = t x + (1-t)\epsilon
\]

其中 \(t=0\) 时样本为噪声，\(t=1\) 时为干净图像。模型采用 **x-prediction**，直接预测去噪后的目标图像；对应速度为：

\[
v_\theta = \frac{x_\theta-z_t}{1-t}
\]

训练目标等价于按时间加权的图像重建损失。推理时，从纯噪声出发，利用预测速度求解常微分方程，将目标图像逐步更新至去噪结果。论文使用 Euler 求解器。

### 通过 3D 高斯实现生成与重建的联合

- 解码器把上下文场景 token 和目标视图 token 合并后，送入 DiT 风格 Transformer，使用全局自注意力进行跨视角信息聚合。
- 相机参数被编码为 Plücker 射线图，与图像拼接后形成带有逐像素相机条件的输入。
- 解码器输出像素对齐的高斯参数及深度图，再利用相机参数将深度提升为 3D 高斯中心。
- 对预测高斯进行可微渲染，得到目标视角去噪结果；渲染出的图像直接接受像素空间监督，因此生成目标与 3D 重建通过同一表示相连。

训练损失包括目标视角的加权像素重建损失、上下文视角与辅助新视角的重建损失，以及所有视角上的 LPIPS 感知损失。论文设定 \(\lambda_{\text{LPIPS}}=0.1\)，目标视角像素损失权重为 \((1-t)^{-2}\)，其他视角采用普通重建权重。

### 推理流程与模型规模

1. 将目标视角图像初始化为高斯噪声。
2. 编码上下文图像一次并缓存场景表示。
3. 进行多步去噪：解码器根据当前含噪目标图像、相机信息及缓存场景表示预测高斯；渲染高斯得到去噪图像，并更新目标图像。
4. 返回最终的共享 3D 高斯表示。

默认使用三个目标关键帧和 10 个采样步。生成式 DiT 解码器包含 12 个 Transformer 块、隐藏维度 768，参数量约为 131M。

## 7. 优点

- **将生成与 3D 重建置于统一表示中**：生成目标视图时直接预测共享 3D 高斯，有助于约束多视角一致性，减少两阶段处理带来的误差传递。
- **直接在像素空间进行生成监督**：避免 VAE 压缩带来的潜空间信息损失，并通过可微渲染把图像级目标直接传回 3D 表示。
- **效率设计明确**：上下文场景表示只编码一次并缓存，迭代生成部分使用轻量 DiT；可从一个 3D 表示渲染多个视角，减少重复生成。
- **针对不确定场景进行验证**：插值、外推、单视图及目标关键帧消融等实验，较直接地检验了方法在观测不足时的效果。
