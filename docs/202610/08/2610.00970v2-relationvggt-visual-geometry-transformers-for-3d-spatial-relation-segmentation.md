## 摘要
近年来，三维重建的进展已从逐场景优化转向前馈推理，语义场景理解也随之发展——然而现有方法仍局限于以物体为中心的感知，忽略了物体之间的空间关系。我们将三维空间关系分割形式化为一种前馈、无需位姿的多视图设定：给定视觉上指定的主体与关系文本查询，模型在未获得目标类别名称的情况下跨视图分割出目标。为此，我们提出 RelationVGGT，一种新颖的前馈框架，它将视觉基础模型提供的语义特征与三维几何基础模型提供的几何感知表示相融合，并利用关系 Transformer 进行以主体为条件的跨视图关系预测——既不需要逐场景优化，也不需要已知的相机位姿。此外，我们基于 ScanNet++，利用 VLM 和 LLM 构建了一个全自动标注流程，从而能够为这一新任务可扩展地生成训练数据。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 2. 方法论

### 核心思想
- 将先前工作中的**体素式关系搜索**，重构为**目标视图图像网格上的逐像素关系预测**，并以参考主体为条件。
- 定义每视图关系特征图 $R_t = \{r_t(u) \mid u \in I_t\}$，通过将关系特征对齐到语言嵌入空间，实现开放词汇的关系查询与分割。

### 关键技术细节

- **特征提取**：
  - 语义特征：DINOv2 密集 patch 特征 $E^D_n$。
  - 几何特征：Pi3 编码器 token $E^P_n$（保留多视图几何信息）。
  - 二者通道拼接后经**输入混合器**（线性投影 + 带 RoPE 的 Transformer 块）融合为联合 token $F_n$。

- **主体表示**：不用池化向量压缩主体，而是保留参考视图全部 patch token，并用下采样后的主体掩码 $\bar{M}_s$ 逐元素相乘，得到主体掩码 token $F^s_r = \bar{M}_s \odot F_r$，保留主体的空间布局与细粒度语义。

- **关系 Transformer**：将目标视图 token 拼接为序列 $Z_0$，交替执行：
  - 主体条件交叉注意力：$\bar{Z}_\ell = \text{CrossAttn}_\ell(Z_\ell, F^s_r)$
  - 全局自注意力：$Z_{\ell+1} = \text{SelfAttn}_\ell(\bar{Z}_\ell)$
  - 使表示同时具备主体条件性与多视图感知能力。

- **掩码解码**：用 DPT head 将 patch 级 token 上采样为像素对齐的关系特征图 $R_t$。

- **3D 几何**：用 Pi3 点解码器预测点图与置信度图，使每个关系特征可关联到对应 3D 点，形成置信度感知的 3D 关系表示。

- **训练目标**：
  - 同一目标掩码由多个语义兼容的关系表达监督，每条查询独立计算 sigmoid focal loss（$\alpha=0.75, \gamma=1.5$）。
  - 总损失：$\mathcal{L}_{\text{mask}} = w_{\text{focal}} \mathcal{L}_{\text{multi-qfocal}} + w_{\text{dice}} \mathcal{L}_{\text{dice}}$。

- **推理**：以特征-文本相似度计算相关性 logit $z_t(u;q) = r_t(u)^\top e(q)$，经 sigmoid 后以固定阈值 $\tau=0.3$ 二值化，无需负提示归一化或后处理。

- **自动标注流程**：基于 ScanNet++，将实例掩码投影到帧上并用 SoM 提示查询 VLM（Qwen3-VL-8B）获取帧级关系提议；通过多视图一致性（K=3 帧一致）与几何过滤（3D 边界框重叠、质心距离）提纯；再由 LLM（GPT-5.2）对三元组进行语义等价改写以增加语言多样性。
