## 摘要
流式 3D 重建不仅需要一系列几何预测：它还需要一种持久场景状态，能够纳入新证据，并在观测到达时保持可渲染。潜在空间令牌为此提供了一种有前景的表示，但从图像集合构建它们仍留下一个问题：如何在线维护它们，其中每个观测既可能重访已知区域，也可能揭示新内容。我们提出 S2Tok，一个前馈框架，可从无标定图像流中维护尺寸自适应、持久的场景状态。其核心思想是区分对现有表示的更新与选择性扩展。一个空间信息驱动的 Transformer 将每个传入观测与持久场景令牌整合，而一个学习到的准入模块选择性地扩展表示以限制冗余存储。分层解码器和高斯头将演化状态转换为非像素对齐的 3D 高斯，从而无需缓存先前帧即可实现新视角渲染。在四个基准上的实验表明，以紧凑高斯表示实现了有竞争力的流式渲染质量。这些结果支持潜在空间令牌作为在线 3D 重建的持久计算状态，将学习到的场景更新与显式高斯渲染相结合。

## Abstract
Streaming 3D reconstruction requires more than a sequence of geometric predictions: it requires a persistent scene state that can incorporate new evidence and remain renderable as observations arrive. Latent spatial tokens offer a promising representation for this purpose, but constructing them from an image collection leaves open how to maintain them online, where each observation may both revisit known regions and reveal new content. We introduce S2Tok, a feed-forward framework that maintains a size-adaptive, persistent scene state from uncalibrated image streams. Its central idea is to distinguish updates to the existing representation from selective expansion. A spatially informed transformer integrates each incoming observation with the persistent scene tokens, while a learned admission module selectively expands the representation to limit redundant storage. A hierarchical decoder and Gaussian head convert the evolving state into non-pixel-aligned 3D Gaussians, enabling novel-view rendering without caching previous frames. Experiments across four benchmarks demonstrate competitive streaming rendering quality with compact Gaussian representations. These results support latent spatial tokens as a persistent computational state for online 3D reconstruction, combining learned scene updates with explicit Gaussian rendering.

## 1. 核心问题与整体含义

- **研究动机**：流式 3D 重建的目标是随着图像逐步到达而恢复场景，而非等完整视频序列结束后再离线重建。这对交互式场景捕获、具身智能建图等场景至关重要——重建结果在观测尚未完成时就应可用，以帮助评估覆盖度、指导下一视角选择或动作决策。

- **核心挑战**：每个新观测既可能**重访已知区域**（提供更好的几何/外观证据），也可能**揭示新内容**（此前被遮挡的区域）。因此，系统必须维护一个可在线修订、持续可渲染的**持久场景状态**，而不仅是逐帧输出几何预测。

- **现有工作的割裂**：
  - **Token-based 方法**（ZipSplat、TokenGS、GlobalSplat）：能将潜在场景 token 解码为非像素对齐高斯，但 token 是通过**联合处理一组给定图像**构建的，属于离线范式。
  - **Recurrent 方法**（CUT3R、Point3R、Spann3R、StreamVGGT）：能随图像到达更新持久记忆，但标准流程是用该记忆**预测逐帧点图**并累积成场景，而非解码为显式可渲染表示。
  - 两者的能力未被统一：前者有显式渲染但无在线维护，后者有在线维护但无统一的可渲染表示。

- **关键矛盾**：维护自适应场景状态需要区分**状态更新**（对已有 token 的修订）与**状态扩展**（新增 token）。若保留所有输入 token，会累积大量重叠冗余；若固定 token 数量，又会随观测增多形成容量瓶颈。此外，在无相机标定的情况下，模型还需自行推断新观测与累积场景之间的对应关系。

- **整体含义**：论文主张将**潜在空间 token 作为在线 3D 重建的持久计算状态**，把「学习式场景更新」与「显式高斯渲染」统一到同一表示中，为流式重建提供新范式。

## 2. 方法论

### 2.1 核心思想

S2Tok 是一个前馈框架，从**无标定图像流**中维护一个**尺寸自适应**的潜在空间 token 集合作为持久场景状态。核心设计原则是：**将「对现有表示的更新」与「选择性扩展」解耦**。

- 每步接收一帧图像 I_i，更新已有场景 token，同时**有选择地**接纳携带新内容的帧 token；
- 累积场景在每一步**重新解码**为共享参考坐标系下的非像素对齐 3D 高斯；
- 推理时**不缓存历史帧**，仅携带 token 状态向前。

### 2.2 关键组件与流程

**（1）Encoder**
- 使用 ViT 将输入图像 I_i 分块编码为帧 token `f_i ∈ ℝ^{H/w × W/w × D}`（patch size w=14，特征维度 D=1536）。
- 帧 token 隐式编码在其自身相机坐标系中。

**（2）Stream-Spatial Transformer（SS-Transformer）**
- 作用：将已有空间 token `S_{i-1}` 适配到新观测，同时将 `f_i` 隐式对齐到 `S_{i-1}` 的参考坐标系。
- 包含 27 个 block，每 block 由三层注意力组成：
  - **全局注意力 A_global**：`s ⊕ S_{i-1} ⊕ f_i` 三者互相注意，无位置编码，用于跨表示关系建模；
  - **场景局部注意力 A_scene**：仅作用于 `s ⊕ RoPE_3D(S_{i-1})`，用**3D 版 RoPE** 编码空间 token 之间的空间关系。3D 坐标由上一时刻每个空间 token 所解码高斯中心的**透明度加权几何中位数**给出（用 Weiszfeld 迭代近似，可微分）；
  - **帧局部注意力 A_frame**：仅更新 `f_i`，用 **2D RoPE** 以 patch 网格坐标为位置输入。
- **归一化尺度 token s**：场景空间范围随观测增加而增长，为缓解尺度相关的分布外问题，引入可学习的 scale token，让模型隐式感知每步的场景尺度变化。其输出 `s'` 经 MLP 预测 log 归一化尺度，由伪 GT 尺度监督。

**（3）学习式准入模块（Learned Admission）**
- 结构：一层 cross-attention + 一层 self-attention + MLP 分类器，维度投影到 256。
- 以 `f'_i` 为 query，`S'_{i-1}` 为 key/value，输出准入 logits `π`；当 `σ(π) > τ`（τ=0.5）时将帧 token 追加到场景状态：
  `S_i = S'_{i-1} ⊕ f'_i[σ(π) > τ]`
- **两阶段学习策略**：
  - **阶段一（蒸馏初始化）**：由于硬选择不可微，先用**基于深度的几何新意 oracle** 蒸馏监督（类别加权 BCE 损失），提供稳定初始化。该 oracle 通过深度重投影新意测试标记观测到几何未见过区域的 patch（相对深度容差 ε_geo=0.08，新意像素比例阈值 τ_geo=0.3，仅与已观测前缀比较，保证因果性）。
  - **阶段二（SCST 策略梯度）**：用 **Self-Critical Sequence Training** 优化准入策略。对同一模型参数做两次前馈 rollout：确定性掩码 `a_d = 1[p > τ]`（无梯度，作基线）和从 Bernoulli 策略采样的掩码 `a_b ~ Bernoulli(p)`。以重建误差差定义自批判优势 `A = e_b - e_d`（A<0 表示采样决策优于基线），并采用 **reward-to-go** 的逐步形式；梯度只回传到准入模块（输入 detach）。同时引入 **KL 正则** `L_KL = β_KL D_KL(Q ‖ P_θ)`，Q 为标签平滑后的 oracle 分布（0.95/0.05），β_KL 从 1.0 线性退火到 0.1。

**（4）分层解码器与高斯头**
- 取 SS-Transformer 第 7、17、27 层的 token 集合 S_I、S_II、S_III（每层均拼接该层空间 token 与该层被接纳的帧 token）。
- 分层解码器逐层自注意力处理并以残差加法融合到解码流（初始化自 S_III），每次残差加后再接一层自注意力。
- 高斯头将结果解码为高斯 `G ∈ ℝ^{h(M+δ)×23}`，每个 token 对应 h=32 个高斯；每个高斯含均值 μ∈ℝ³、尺度∈ℝ³、四元数 q∈ℝ⁴、不透明度 o∈ℝ、1 阶 SH 系数 c∈ℝ^{4×3}。

**（5）Color-Skip 分支（附录）**
- 适配流式设定改造 ZipSplat 的 color-skip 分支：建立与场景记忆同步的 **per-token color bank**，只有新接纳的 patch 对当前帧 color token 做一次 cross-attention。
- **非对称更新**：场景 token 每步被 backbone 重新上下文化（持续演化）；color bank 条目是**写一次即冻结**的（不重算、不过 backbone、无循环更新），推理时复用，不重访历史图像。

**（6）损失函数**
- **渲染损失**：`L_render = L_rgb + λ_lpips·L_lpips + λ_depth·L_depth + R`，R 为尺度>0.1、不透明度<0.01、中心超出 [-10,10]³ 的正则惩罚；同时对 f'_i 单独解码做 solo 渲染监督以保留逐帧梯度。
- **Chamfer 损失**：单方向 Chamfer，只把从未被任何监督视图渲染过的高斯中心拉向伪 GT 点云。
- **归一化尺度损失**：`L_scale = λ_scale(ℓ̂ - log ℓ)²`。
- **类别加权 BCE 损失**：监督准入 logits。
- **SCST 损失**：策略梯度损失（见上）。

**（7）训练三阶段（附录 D.3）**
- 阶段一：用 oracle 选择帧 token，训练各模块 + 准入模块蒸馏，损失 = L_render + L_chamfer + L_scale + L_bce，100 epochs；
- 阶段二：启用 SCST，用准入模块自身输出选择，损失 = L_render + L_chamfer + L_scale + L_scst，100 epochs；
- 阶段三：冻结准入模块参数，其余组件在确定性准入规则下训练，损失 = L_render + L_chamfer + L_scale，74 epochs。

## 3. 实验设计

### 3.1 数据集与场景

- **训练数据集（仅 2 个）**：DL3DV、RealEstate10K。

### 3.2 Benchmark 设定

- **两种评估设置**：
  - **Final**：处理完整上下文序列后，用最终重建渲染所有目标视图；
  - **Intermediate**：每步之后仅用截至当前的观测渲染对应目标视图。
- **两种序列长度**：12 views 与 50 views。
- **视图采样**：上下文视图按时间顺序采样，每对相邻上下文视图之间保留一个目标视图；12 视图设定在 8 个 DL3DV、8 个 RealEstate10K、9 个 Mip-NeRF 360、8 个 ScanNet++ 场景上评估；50 视图设定使用全部留出评估集。
- **指标**：PSNR↑ / SSIM↑ / LPIPS↓，并报告平均高斯/点数（#GS/PT）、每视图重建时间与峰值 GPU 显存。
- **点图预测方法**使用 point-splat rendering 获得渲染性能。

### 3.3 对比方法

- **非流式**：ZipSplat（r=1 与 † 调整压缩比）、TokenGS、GlobalSplat、AnySplat、DepthSplat-B；
- **流式**：MonoGS（非前馈，优化式）、CUT3R、StreamSplat、Spann3R、Point3R、StreamVGGT。
- 注：StreamSplat 仅在 Intermediate 下评估（其时间条件重建不产生全局相机对齐的最终场景）。

### 3.4 消融实验

在 50 视图 DL3DV 评估集上做 5 组消融：
- w/o RoPE_3D、w/o Admission（接纳全部帧 token）、w/o SCST、w/o SCST（匹配高斯预算）、w/o scale token s，与 Full Model 对比。

## 6. 主要结论与发现

- **流式渲染质量**：在 4 个基准上，S2Tok 在所比较的**前馈流式方法**中取得最高 PSNR（Final 与 Intermediate 两种设定），同时高斯表示非常紧凑：
  - DL3DV：12 视图 36K 高斯，50 视图 66K 高斯，Final PSNR 18.00 / Intermediate 19.11；
  - RealEstate10K：17K / 21K 高斯，Final 23.86（12v）/23.62（50v），Intermediate 25.03/25.04；
  - Mip-NeRF 360：43K / 82K 高斯；
  - ScanNet++：41K / 71K 高斯，Final 表现最佳且高斯数最少。
- **无需缓存历史帧**：推理仅依赖当前观测与携带的 token 状态，不保存历史帧或 KV cache。
- **消融发现**：
  - 去掉 RoPE_3D 或 scale token 会降低渲染质量；
  - 接纳全部帧 token（w/o Admission）Intermediate PSNR 提升（19.11→20.39），但高斯数从 66K 暴增到 518K，Final PSNR 反而下降（18.00→17.50）；
  - 去掉 SCST 渲染质量略升但高斯数几乎翻倍（66K→120K）；在匹配 66K 高斯预算下，完整模型在所有报告的 Final/Intermediate 指标上更优，说明 SCST 在相同预算
