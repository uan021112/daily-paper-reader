## 摘要
从稀疏、未标定且具有宽基线的 RGB 全景图中重建准确的相机位姿与平面图布局，仍是一项具有挑战性的开放问题。在这种场景下，直接预测多房间平面图尤为困难：位姿、几何、语义与全局布局结构紧密耦合，而将完整平面图作为单一全局输出进行学习也颇具难度。我们的核心洞见是严格限制模型预测的局部性。多视图有序墙实例分割（Multi-view Ordered Wall Instance Segmentation，MOIS）正是围绕这一理念设计的。每个全景图列仅预测其观测到的墙面，以及按顺时针方向排列的后续两个相邻墙面。通过对重叠的局部预测进行确定性聚合，可生成全局墙面划分、房间布局和共享坐标。基于 MOIS，我们提出多视图平面图前馈网络（Multi-view floor-plan Feed-Forward Network，MvFFN），联合预测粗略相机位姿、稠密全局几何以及逐墙语义输出。随后，利用下游布局串接（Layout Chaining，LC）后处理流程，将这些预测组装成具有共享全局坐标、一致墙面身份和连通房间结构的多房间平面图。与组合式模块化基线相比，稠密的 MOIS 预测能够更准确地恢复跨视图墙面身份及房间内局部连通性；组装后的布局在墙面级和交汇点级准确率上也显著优于以往方法。我们还提出 ZInD-CrossView 数据集，在 ZInD 的基础上扩展了全局唯一的墙面实例及适用于该任务的跨视图分割标签。

## Abstract
Reconstructing accurate camera poses and floor-plan layouts from sparse, unposed, wide-baseline RGB panoramas remains a challenging open problem. Direct multi-room floor-plan prediction is especially difficult in this setting: pose, geometry, semantics, and global layout structure are tightly coupled, yet a complete floor-plan is hard to learn as a single global output. Our key insight is to keep the model's predictions strictly local. Multi-view Ordered Wall Instance Segmentation (MOIS) is designed around this concept. Each panorama column predicts only the wall it observes plus the next two adjacent walls in clockwise order. The global wall partition, room layouts, and shared coordinates emerge from deterministic aggregation of overlapping local predictions. Building on MOIS, we propose Multi-view floor-plan Feed-Forward Network (MvFFN), which jointly predicts coarse camera poses, dense global geometry, and per-wall semantic outputs. A downstream Layout Chaining (LC) post processing pipeline then assembles these predictions into multi-room floor-plans with shared global coordinates, consistent wall identities, and connected room structure. The dense MOIS predictions recover cross-view wall identity and local within-room connectivity more accurately than composed modular baselines, and the assembled layouts substantially outperform prior methods on wall and junction level accuracy. We also introduce the ZInD-CrossView dataset, which augments ZInD with globally unique wall instances and cross-view segmentation labels for this task.

# 论文总结：MvFFN——面向无位姿宽基线全景图的多视图平面图重建

## 1. 核心问题与整体含义

- **研究任务**：从稀疏采集、相机位姿未知、视角基线较大的室内 360° 全景图中，同时恢复相机位姿和多房间平面图。
- **研究动机**：房间布局重建需要整合多视角信息，因为单张全景图会受到遮挡和视野限制；但位姿、几何、墙体语义和房间结构彼此耦合。若直接把完整多房间平面图作为单一全局输出，局部预测错误可能不断累积，尤其容易出现墙体重复、遗漏或交点错误。
- **论文主张**：把全局布局问题拆解为可监督的局部跨视角关系，再将重叠的局部结果组装为全局结构。论文据此提出 **MOIS**（Multi-view Ordered Wall Instance Segmentation，多视图有序墙实例分割）和相应的 **MvFFN** 网络。
- **整体流程**：网络预测相机位姿、几何信息和局部墙实例关系；后处理模块 **Layout Chaining（LC，布局串接）** 将局部预测聚合为墙体身份一致、处于共享坐标系中的多房间布局。

## 2. 方法论

### 2.1 核心表示：MOIS

- 对全景图中的每个图像列选取一个锚点。锚点对应的视线确定当前房间中的一面墙，即“当前墙”。
- 每个锚点预测一个有序的局部墙体元组，默认 **K=3**：
  1. 锚点所指向的当前墙；
  2. 当前房间内沿顺时针方向相邻的第一面墙；
  3. 顺时针方向相邻的第二面墙。
- 预测目标是这些墙体在**所有输入全景图列**中的归属，形成跨视图的稠密墙实例分割结果。由此，模型不仅要判断哪些像素列属于同一墙体，还要编码房间内部的墙体邻接关系。
- 对门洞的处理依赖其状态和视线交点：若视线穿过关闭的门，则将门归属于附着墙体；若穿过开放门洞，则根据首先看到的墙体确定当前房间。

### 2.2 MvFFN 网络结构与训练

- **几何分支**：每张全景图经 EfficientNet-v2 特征提取和高度压缩模块（HCM）转为按列组织的特征；加入角度和相机位置编码后，通过交替进行帧内与跨帧注意力的多视图 Transformer，预测：
  - 相机的 3-DoF 位姿：平面位置与朝向；
  - 每列的地面边界；
  - 地面点图及其不确定度；
  - 墙线参数。
- **语义分支**：另设语义编码器，将图像特征与几何分支特征融合。对采样的锚点建立分组查询，每组包含 K 个有序墙槽查询；解码器通过自注意力建模墙槽之间的关系，并对所有视图的列特征进行交叉注意力，输出跨视图墙槽归属概率。
- 概率形式可概括为：对锚点 \(m\)、视图 \(j\)、图像列 \(d\) 和墙槽 \(r\)，将锚点墙槽查询向量与该列特征做内积，再通过 sigmoid 得到归属概率：
  \[
  \hat S_{m,j,d,r}=\sigma(\langle \tilde t^q_{m,r},\tilde t^I_{j,d}\rangle).
  \]
- **两阶段训练**：
  1. 先训练几何分支，监督点图、地面边界和绝对/相对相机位姿；
  2. 冻结几何分支，再训练语义分支，以墙体是否属于锚点局部结构的存在性损失和有序墙槽分类损失进行监督。
  
  作者认为，几何和语义目标在联合训练时存在优化冲突，分阶段训练能提高稳定性。
- **数据稀缺下的先验**：利用两视图 CovisPose 的结果提供相机旋转先验，并基于其跨视图对应关系限制早期全局注意力的搜索区域；对明显不可共视的视图对屏蔽注意力。
- **Layout Chaining 后处理**：
  1. 在单视图内，根据当前墙预测之间的掩码相似度聚类，得到局部墙实例；
  2. 根据跨视图墙体预测的重叠关系合并为全局墙实例，并建立列到墙的映射；
  3. 根据 MOIS 的相邻墙槽生成有向房间墙体图，利用几何一致性过滤边，再通过最长路径提取房间墙序列；
  4. 将点图和墙线参数按全局墙实例汇总，拟合墙线并求相邻墙的交点，得到房间布局。
- 论文还尝试以预测的像素—墙体对应关系进行下游平面布局束调整（BA）或 BADGR 优化。

## 3. 实验设计

### 3.1 数据集与场景

- **ZInD-XV**：论文的主要基准，源自 Zillow Indoor Dataset，扩展了全局唯一墙实例、多房间墙序列以及全景图列级墙体标签。包含 **2,706 层楼、66,834 张全景图**。论文将其作为主要训练和评测数据集。
- **HM3D-XV**：由 HM3DSem 室内场景构建的辅助跨域基准，包含 **372 层楼、17,943 张全景图、180 个场景**。数据更小、噪声更大，且标注列更稀疏，用来测试在家具较多、网格渲染场景中的迁移表现。
- 主要评测设置为 **5-view** 和 **8-view** 全景输入；位姿实验另与既有方案进行 N 视图位姿比较。布局指标包括墙体和交点的实例级 Precision、Recall、F1，以及匹配墙体定位距离；位姿指标为位置误差和旋转误差。

### 3.2 对比方法

- **位姿估计**：CovisPose + Greedy Spanning Tree（GST）、VGGT；MvFFN 也报告自身表现。
- **布局估计**：模块化基线包括 CovisPose 位姿或真值位姿、LGT-Net 边界预测，以及 LGT-Net 后处理（LGT-PP）、RoomFormer 或 PolyRoom 等布局向量化方案。
- **中间 MOIS 预测**：将 LGT-Net 与 CovisPose 组合，构造跨视图墙槽预测基线，比较有序墙槽 IoU。
- **布局细化**：测试平面 BA 和 BADGR 对 MvFFN 输出的改进效果。

## 4. 资源与算力

- 训练使用 **8 或 16 张 NVIDIA A100 GPU，每张 40GB 显存**。
- 几何阶段训练约 **80,000 次迭代、耗时约 2 天**；语义布局阶段约 **80,000 次迭代、耗时约 2.5 天**。
- 文中还报告按输入视图数设置不同 batch size（2、3、5、8 视图分别为 10、7、4、2）。
- 这些是论文给出的主要资源统计；没有提供完整的逐实验 GPU 时长、总计算成本或能耗数据，因此难以精确比较不同方法的计算开销。

## 5. 实验数量与充分性

- 论文覆盖了多个互补实验维度：
  - **两个数据集**：ZInD-XV 主基准和 HM3D-XV 跨域基准；
  - **两个主要布局输入规模**：5 视图与 8 视图；
  - **位姿估计、最终布局、中间 MOIS 质量、下游细化**等任务；
  - 架构消融：共享编码器、去除几何—语义融合、单阶段训练、完整两阶段模型；
  - 归纳偏置消融：旋转先验和对应关系注意力掩码；
  - MOIS 窗口消融：3、5、7 面墙；
  - 定性结果与失败案例分析。
- 总体而言，实验能够分别检验局部 MOIS 表示、网络结构、布局组装和跨域表现，覆盖较完整。尤其报告了真值位姿控制组，有助于区分位姿误差与布局方法本身的影响。
- 公平性方面，作者尽量在相同输入和公共后端下比较模块化方案，并对 RoomFormer、PolyRoom 等在 ZInD-XV 上进行针对性微调。不过，这些基线接收的是预先构造的几何输入，而 MvFFN 可直接融合多视图图像、几何与语义信息，输入形式和信息路径并不完全相同；因此对比能说明整体系统效果，但不完全等价于单一模块的严格对照。
- HM3D-XV 的位姿比较只在 CovisPose 可用且能形成连通位姿图的子集上进行，且 MvFFN 使用了特定先验设置；结果不应直接外推到未筛选的完整跨域场景。

## 6. 主要结论与发现

- 在 ZInD-XV 上，MvFFN 的墙体和交点指标明显优于论文所比较的模块化布局基线。例如：
  - 5 视图墙体 F1 为 **88.1**，交点 F1 为 **73.3**；
  - 8 视图墙体 F1 为 **88.4**，交点 F1 为 **75.0**。
- MvFFN 不仅改善最终布局，也提升了中间跨视图墙槽预测质量。5 视图下，当前墙、相邻第一墙、相邻第二墙的 pooled IoU 分别为 **81.9%、71.1%、57.8%**，明显高于 LGT + CovisPose 组合基线的 **63.7%、37.8%、20.3%**。
- 位姿估计方面，MvFFN 与 CovisPose+GST 总体相近：CovisPose+GST 在部分中位数误差上更低，而 MvFFN 的误差均值、方差或困难案例表现具有优势；不能据此认为 MvFFN 在所有位姿统计指标上都占优。
- 平面 BA 能改善多数样本，但总体距离提升较小；BADGR 对初始化和对应关系更敏感，在全体样本上未稳定带来收益。
- HM3D-XV 上也观察到布局指标改善，但该基准较小、较嘈杂，而且采用混合训练与先验条件，说明有跨域适应潜力，尚不足以证明对广泛室内域的普遍泛化能力。

## 7. 优点

- **表示设计清晰**：将难学的全局布局拆解为跨视图的局部墙体身份和房间内邻接关系，针对性地缓解全局序列误差累积问题。
- **结合语义与几何**：利用图像语义识别墙体身份和连通关系，同时以位姿、点图和墙线参数提供几何支撑，不局限于几何融合。
- **局部预测可全局聚合**：MOIS 为每个锚点提供冗余、重叠的局部证据，再通过 Layout Chaining 形成统一墙体实例和房间序列。
- **设计有消融支撑**：去除几何—语义融合或改为单阶段训练会造成明显退化，窗口长度实验也支持使用较短的 3 墙局部目标。
- **建立结构化评测资源**：ZInD-XV 提供全局墙实例及跨视图标签；HM3D-XV 进一步提供不同来源场景的辅助验证，有助于后续研究。
- **报告失败和使用限制**：论文讨论了错误墙体关联、几何误差传播、先验依赖及隐私问题，而非只呈现成功案例。

## 8. 不足与局限

- **对输入条件有要求**：假设输入是校正后的 360° 全景图，属于单一连通室内位姿图，邻近视图有足够共视区域，且相机相对高度已知。极稀疏、严重遮挡或高度信息不准时，性能可能下降。
- **依赖外部先验**：训练和推理使用两视图 CovisPose 的旋转与对应关系先验；域转移时先验质量可能成为瓶颈。HM3D-XV 部分实验还使用真值对应关系作为注意力偏置，实际部署条件更难。
- **全局组装仍偏启发式**：Layout Chaining 依赖图聚类、几何过滤和最长路径等规则。若 MOIS 墙体身份预测错误，错误可能传播为墙体合并、连通关系或房间几何错误，后处理纠错能力有限。
- **完整性受可见性限制**：观察不足时方法会输出开放或部分房间布局；不能保证始终恢复闭合、完整的楼层平面图。
- **适用结构有限**：强非曼哈顿、曲面墙、凸窗等结构可能超出训练覆盖；家具、标注不一致、低纹理或低照度也可能导致错误。
- **跨域证据有限**：HM3D-XV 规模小、监督较稀疏，且测试与先验筛选条件会影响结果；对非住宅、真实移动视频或更复杂采集条件的泛化仍待验证。
- **资源与扩展性**：每个图像列都作为锚点进行稠密 MOIS 推理，张量和注意力开销随视图数、列数增大；论文明确提示大规模输入时需考虑显存与运行时间，但未给出完整推理速度和计算成本。
- **隐私与安全风险**：准确室内平面图可能泄露私人空间结构；作者建议仅用于经同意的研究和重建，并避免用于未经授权的空间测绘或高风险决策。
