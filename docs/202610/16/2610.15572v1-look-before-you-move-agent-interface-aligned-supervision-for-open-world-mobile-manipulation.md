## 摘要
开放世界移动操作要求机器人根据语言指令寻找物体、接近物体，并将其移动到目标容器中。为训练视觉语言模型（VLM）智能体完成此类任务，需要同时提供动作选择和主动视觉方面的示范。现有流程通常将规划轨迹转换为高层动作标签，但沿最短路径取得的进展，对于决定观察位置所提供的监督有限。我们提出智能体接口对齐（Agent-Interface Data Alignment，AIDA），这是一种数据采集流程，其中教师直接通过已部署智能体的技能接口选择并执行动作。针对移动操作，我们设计了能够保持目标可见、找回丢失目标，并在抓取或放置前接近目标的教师。我们还加入基于模板的空间推理监督，并使用共享运行框架，在训练和推理期间组织观测、历史记录与输出。由此得到的智能体 AIDA-OWMM 在 170 个留出 OWMM 回合中取得了 71.76% 的完整任务成功率。教师敏感性分析表明，主动视觉示范能够提升学生智能体的成功率。仿真训练的智能体无需额外训练，便在真实移动机器人上实现了 38% 的端到端成功率。将 AIDA 应用于 EmbodiedBench 的导航子集，进一步验证了该流程在导航任务中的实用性。

## Abstract
Open-world mobile manipulation requires a robot to find an object, approach it, and move it to a target receptacle from a language instruction. Training vision-language model (VLM) agents for these tasks requires demonstrations of both action selection and active vision. Existing pipelines often convert planned trajectories into high-level action labels, but shortest-path progress provides limited supervision for deciding where to look. We introduce Agent-Interface Data Alignment (AIDA), a data collection pipeline in which a teacher directly selects and executes actions through the deployed agent's skill interface. For mobile manipulation, we design teachers that maintain target visibility, recover lost targets, and approach for picking or placing. We add template-based spatial reasoning supervision and use a shared harness to organize observations, history, and outputs during training and inference. The resulting agent, AIDA-OWMM, achieves 71.76% full-task success on 170 held-out OWMM episodes. Teacher sensitivity analysis shows that active-vision demonstrations improve student success. The simulation-trained agent achieves 38% end-to-end success on a real mobile robot without additional training. Applying AIDA to a navigation subset of EmbodiedBench further demonstrates the pipeline's utility for navigation tasks.

## 1. 核心问题与整体含义

- **研究任务**：开放世界移动操作（Open-World Mobile Manipulation，OWMM）要求机器人根据自然语言指令，在家庭或办公环境中找到指定物体、移动到合适位置、完成抓取，并将物体放到指定容器或表面。
- **核心挑战**：任务不仅需要理解指令和选择动作，还需要机器人在移动过程中主动调整视角：
  - 接近物体时尽量让目标保持在视野内；
  - 目标离开视野后能够重新寻找；
  - 判断何时已经足够接近，可以抓取或放置。
- **既有方法的不足**：常见做法是先规划或执行轨迹，再将轨迹转换为高层动作标签。论文认为，这类标签往往主要反映路径进展，较难教会模型“该看哪里”“如何找回丢失的目标”等主动视觉行为。
- **论文的整体主张**：训练数据应直接对应实际部署时智能体需要做出的决策。为此，论文提出 **Agent-Interface Data Alignment（AIDA）**：教师通过与学生相同的高层技能接口，逐步选择并执行动作，再用这些交互记录训练视觉语言模型（VLM）智能体。

## 2. 方法论

### 2.1 AIDA：通过部署接口采集示范

- 教师不是在事后从运动轨迹中推导高层动作，而是在每一步观察环境后，直接选择一种技能及其参数，执行后再根据新观测决定下一步。
- 教师在数据采集阶段可使用模拟器的特权信息，例如目标位置、分割掩码和导航几何信息；但**这些特权信息不输入学生模型**。学生训练和部署时使用的是可获得的图像、任务指令、技能说明、动作历史以及搜索阶段的场景关键帧。
- 这种设置旨在使训练监督与实际智能体的决策接口相匹配，同时避免让学生依赖部署时不可用的模拟器状态。

### 2.2 技能接口与任务流程

教师和学生共用五类高层技能，由固定执行器将高层调用转换为底层机器人动作：

- **搜索场景关键帧**：选择一个场景关键帧，机器人前往其对应位置。
- **转向**：指定旋转角度，以调整观察方向。
- **移动到点**：指定图像中的归一化像素坐标，执行器结合深度信息和相机位姿，将其转换为导航目标。
- **抓取**：指定物体上的像素坐标，由操作控制器执行抓取。
- **放置**：指定目标表面上的像素坐标，由控制器完成放置。

任务通常分为寻找并接近物体、抓取、寻找并接近目标位置、放置等阶段。教师的导航决策会根据目标是否可见、相对方向和距离，选择转向或移动，而不只是单纯缩短到目标的距离。

### 2.3 主动视觉教师

论文设计并比较了不同导航策略的教师：

- **距离贪心教师**：选择能够缩短到物体或目标位置距离的导航点。
- **可见性教师**：在接近目标的同时，优先选择运动后仍能保持目标可见的位置。
- **目标恢复教师**：除保持可见外，还能在目标离开视野后依据先前观测和方向信息重新获取目标。

教师在导航中使用目标掩码、方位角、投影路径等信息。文中给出的部分规则包括：方位误差超过约 \(15^\circ\) 时转向；较大的航向误差会拆分为多次转向。模拟数据采集时，抓取要求目标距离不超过约 1 米且可见掩码面积超过 100 像素；这些是教师采集规则，不等同于部署时由模型直接接收的输入。

### 2.4 空间状态与推理监督

- 轨迹采集后，离线标注器利用模拟器记录的信息，通过确定性模板为每个动作生成前置空间推理标签。
- 标签主要描述：
  - 当前任务阶段及进度；
  - 目标是否可见；
  - 目标相对于机器人位于左侧、中央或右侧；
  - 机器人与目标的距离或技能就绪程度，例如“还需接近”“已可抓取”；
  - 上述判断如何支持下一步动作。
- 可见目标的方向由掩码确定；不可见时则依据机器人位姿和目标位置估计方向。该监督将“空间状态判断”明确纳入动作预测过程。

### 2.5 训练与推理流程

- 共享运行框架统一处理提示词、动作历史、场景关键帧和输出格式，训练和部署使用相同接口。
- 模型输出包括状态估计、推理、动作类别、动作参数和步骤摘要；历史中保留先前技能调用及其参数，不将生成的步骤摘要递归纳入后续历史。
- 使用 **Qwen3-VL-8B-Instruct** 作为基础模型，通过 LoRA 进行监督微调。目标是最大化每一步输出在给定观测与上下文条件下的似然：
  \[
  \mathcal{L}_{\mathrm{SFT}}(\theta)
  = -\sum_t \log p_\theta(y_t\mid x_t),
  \]
  其中 \(x_t\) 是当前提示、图像与历史，\(y_t\) 包括空间推理、动作和参数等输出。

## 6. 主要结论与发现

- 通过部署时技能接口直接生成并执行教师动作，可以构造与学生实际决策形式相匹配的示范。
- 对目标保持可见、目标离开视野后的恢复，以及面向抓取和放置的接近行为，能够带来比单纯按距离接近更好的学生表现。
- 动作历史和空间推理监督均有助于提升 OWMM 任务表现；场景关键帧在搜索阶段尤其有用。
- AIDA-OWMM 在 170 个留出 OWMM 回合中达到 **71.76%** 完整任务成功率；仿真训练模型无需额外训练，在真实机器人上达到 **38%** 端到端成功率。
- 将 AIDA 用于 EmbodiedBench 导航子集也取得较高结果，说明该数据采集思路不局限于移动操作，但目前证据主要来自短程导航任务。

## 7. 优点

- **监督目标贴近部署接口**：直接记录技能选择及参数，而非仅从底层轨迹事后推断动作标签。
- **关注闭环主动视觉**：不把导航简化为路径跟随，而是明确处理保持视野、重新定位和操作就绪等问题。
- **方法组件清晰且可分析**：教师策略、空间推理标注和共享运行框架分别承担数据生成、状态解释和训练—推理对齐的功能。
- **提供针对性消融**：通过不同教师和框架配置的比较，分析了主动视觉、动作历史、关键帧和推理监督的贡献。
- **包含跨模拟与真实机器人测试**：尽管真实成功率仍有限，但零额外训练的实机结果提供了有价值的迁移证据。
- **数据规模与流程信息较具体**：说明了数据筛选过程、训练样例数、LoRA 设置及部分评测配置，便于理解实验实施方式。

## 8. 不足与局限

- **教师依赖模拟器特权信息**：离线教师使用目标位置、掩码等信息，示范质量受教师规则和模拟器状态准确性的影响；学生虽不直接接收这些信息，但数据覆盖仍可能带有教师策略偏差。
- **模拟与真实操作存在差距**：模拟器抓取机制较简化，不能充分覆盖接触、滑移、力控及失败恢复等问题；真实机器人上低层抓取失败是主要瓶颈之一。
- **真实机器人实验规模有限**：只报告一个办公环境、一种机器人平台和 38% 成功率，尚不能说明对多种机器人、传感器和场景的稳健性。
- **任务与场景覆盖有限**：OWMM 实验基于预先建图和已知定位；EmbodiedBench 仅覆盖较短的单房间导航任务，尚未证明适用于长程指令导航、跨楼层搜索或更复杂环境。
- **对照公平性仍需谨慎解读**：部分基线来自先前工作的报告结果，可能与本文在数据、基础模型和评估细节上不完全一致；较有说服力的机制比较主要来自共享训练设置下的内部实验。
- **算力与复现信息不完整**：未报告训练硬件型号、训练 GPU 数量和训练耗时；论文也未给出置信区间或显著性检验，限制了对成本和统计稳定性的判断。
- **方法价值不等于模型能力全面提升**：结果支持特定接口、技能执行器和任务设定下的数据对齐策略有效，但不能直接推出对任意 VLM、操作接口或长程任务均有同样收益。
