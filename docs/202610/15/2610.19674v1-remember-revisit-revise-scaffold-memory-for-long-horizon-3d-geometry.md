## 摘要
几何基础模型能够从视频序列中估计相机位姿和三维场景结构，但要在长时间跨度内保持重建一致性仍面临挑战。前馈模型将长序列划分为相互独立、长度固定的帧窗口进行处理，并对各窗口的预测结果进行对齐，因此位姿和重建误差会在窗口间不断累积。流式模型保留过去帧的信息以指导未来预测，但当后续观测揭示早期估计存在错误时，它们无法修正这些估计。为解决这一问题，我们提出可修订支架记忆（Scaffold MemOry for Revision，SMORE），这是一种为冻结的几何基础模型配备可修订外部记忆、以支持长时程推理的框架。SMORE 的设计受到生物大脑海马体联想记忆机制的启发；该机制将空间情境与感官体验联系起来。SMORE 将观察者所处的位置与其观测内容相关联，使过去的观测得以存储、检索、依据新证据进行验证，并在检测到不一致时加以修订。我们在五个数据集上使用八种具有竞争力的几何模型评估 SMORE，任务涵盖相机位姿估计、多视角深度估计、三维点云重建、同时定位与建图（SLAM）以及新视角合成。在所有评估模型中，SMORE 均能持续提升长序列位姿估计性能，将多视角深度误差最高降低 58%，将三维点云重建的 Chamfer 距离最高降低 43%，并在长时程 SLAM 中实现低至 2.9 厘米的平均轨迹误差。通过保留经过校正的位姿和观测，SMORE 还能进一步提升大规模三维场景重建的保真度与空间一致性。这些结果表明，可修订外部记忆是一种灵活的接口，能够将预训练几何模型从固定上下文预测扩展至面向长视觉序列的迭代式纠错推理。

## Abstract
Geometry foundation models estimate camera poses and 3D scene structure from video sequences, but maintaining consistent reconstructions over long horizons remains challenging. Feed-forward models process long sequences as independent, fixed-length frame windows and align their predictions, causing pose and reconstruction errors to accumulate across windows. Streaming models retain information from past frames to inform future predictions, but cannot revise earlier estimates when later observations reveal errors. To address this, we introduce Scaffold MemOry for Revision (SMORE), a framework equipping frozen geometry foundation models with a revisable external memory for long-horizon inference. Inspired by hippocampal associative memory in biological brains, which links spatial context with sensory experience, SMORE associates where an observer is with what it observes, enabling past observations to be stored, retrieved, verified against new evidence, and revised when inconsistencies are detected. We evaluate SMORE with eight competitive geometry models on five datasets spanning camera pose estimation, multi-view depth estimation, 3D point-cloud reconstruction, simultaneous localization and mapping (SLAM), and novel view synthesis. Across all evaluated models, SMORE consistently improves long-sequence pose estimation, reduces multi-view depth error by up to 58%, reduces Chamfer distance for 3D point-cloud reconstruction by up to 43%, and achieves average trajectory error as low as 2.9 cm in long-horizon SLAM. By retaining corrected poses and observations, SMORE further improves the fidelity and spatial consistency of large-scale 3D scene reconstruction. These results establish revisable external memory as a flexible interface for extending pretrained geometry models beyond fixed-context prediction toward iterative, error-correcting inference over long visual sequences.

## 1. 核心问题与整体含义

- **研究问题**：如何让几何基础模型在长视频、长轨迹中保持相机位姿和三维场景重建的一致性，并能根据后续观测修正早期错误？
- **研究背景**：
  - 前馈式模型通常把长序列切成固定长度窗口，分别预测后再拼接；窗口对齐误差会逐渐累积。
  - 流式模型能保留历史信息以辅助后续预测，但通常不会回头修正已输出的旧位姿和几何。
- **论文主张**：记住历史并不等于能够纠正历史。SMORE（Scaffold MemOry for Revision）在冻结的几何模型之外增加一套可更新、可回访、可修订的外部记忆，使模型从一次性或单向预测转为长时程的迭代纠错。
- **整体意义**：论文试图把“长期一致性与事后纠错”从几何模型本身的训练问题，转化为可复用的外部记忆与推理机制问题。

## 2. 方法论：SMORE 的核心思想与流程

### 2.1 总体结构

SMORE 由两部分构成：

- **内容库（content bank）**：保存历史帧及其所属窗口、局部相机位姿和三维点图等几何预测。
- **空间支架（spatial scaffold）**：将观测的空间状态与视觉内容关联起来，允许新观测以视觉线索检索历史记录。

几何基础模型和 DINOv2 特征提取器均保持冻结；在线更新发生在外部记忆及窗口的全局放置上。

### 2.2 窗口化重建与坐标管理

- 默认使用 **32 帧窗口、16 帧重叠**。相邻窗口先通过重叠帧的相机位姿进行相似变换对齐。
- 每帧只存储一次，归属于其首次出现的“源窗口”。帧的局部位姿和点图保持不变，窗口的全局变换决定其在整体场景中的位置。
- 因此，修订窗口放置时，窗口内相机和几何会一起移动；这主要纠正**窗口之间**的相对位置，而不直接改写窗口内部的局部几何。

### 2.3 空间—视觉关联记忆

- 每帧的空间状态由相机位置和姿态组成：位置通过多个不同周期的空间模块编码，偏航、俯仰、滚转分别编码为周期环。
- 空间状态经固定随机投影映射为 **1024 维记忆地址**，再保留最大的 **64 个激活**并归一化，以形成稀疏地址、降低记忆干扰。
- 图像由冻结的 **DINOv2 ViT-S/14** 提取 384 维视觉描述符。视觉描述符与记忆地址之间建立双向映射，并通过递归最小二乘（RLS）随新帧到来在线更新。
- 视觉检索只用于提出候选回访，不直接把回忆出的空间状态当作当前位姿。

### 2.4 “存储—检索—核验—修订”流程

1. **存储**：保存新帧、局部几何预测及其空间—视觉记忆关联。
2. **检索**：以当前帧视觉特征预测记忆地址，取最相似的最多 5 个历史候选；排除时间上过近、来自紧邻窗口或视觉相似度低于 0.5 的候选，并要求至少相隔 64 帧。
3. **核验**：每个候选与同一源窗口内相邻帧组成一对；使用来自不同源窗口的两对历史帧。几何模型联合处理当前窗口和 4 个检索帧，据此估计当前窗口的两个独立全局放置提议。
   - 两个提议的旋转差须不超过 **10°**；
   - 平移差须不超过当前窗口空间尺度 \(E_k\)。
   不满足条件则拒绝此次回访。通过核验后，再用两对历史帧联合拟合一个鲁棒的修正放置。
4. **修订**：将当前估计放置与修正放置之间的 Sim(3) 变换作为纠错量，并沿历史参考窗口至当前窗口逐步增加修正权重。文中通过相似变换的对数—指数映射实现插值，而不是直接线性缩放变换矩阵。
5. **最终优化**：附录还描述了序列结束后的窗口位姿图优化，用顺序窗口连接和已接受的回访连接联合细化窗口放置。但论文主要结果强调在线设置；不同实验与附录中是否采用最终优化，需按各自协议区分。

## 4. 资源与算力

- **硬件**：计算与显存评估使用 **1 张 RTX 6000 Ada GPU**，测试显存预算为 46 GB，batch size 为 1。
- **新视角合成解码器训练**：每个解码器训练 12K 步，AdamW，约 **1 小时 / 解码器**。每种几何模型分别训练基线和 SMORE 解码器；几何基础模型和 SMORE 本身不通过该损失训练。

- **限制说明**：论文提供了单卡测试与具体运行数据，但没有给出所有实验的完整 GPU 数量、总训练时长或总能耗统计；也不能据此推断 SMORE 在不同硬件上的普遍效率。

## 6. 主要结论与发现

- SMORE 在多种前馈和流式几何模型上改善了长序列位姿估计；收益通常在序列更长、回访机会更多时更明显。RE10K 以向前运动为主，回访较少，提升相对有限。
- 论文报告多视角深度误差最高降低约 **58%**，点云重建 Chamfer 距离最高降低约 **43%**；长时程 7-Scenes SLAM 中，VGGT-Ω 的平均 ATE RMSE 从 **4.5 cm** 降至 **2.9 cm**。
- 新视角合成总体上得到更高 PSNR、SSIM 和更低 LPIPS，但提升因模型和数据集而异；部分模型的 PSNR 增益较小或不稳定。
- SMORE 能以窗口化推理降低几何模型的活跃 GPU 工作集，使一些原生流式推理会 OOM 的长序列仍可处理，但代价是额外的检索、联合推理与轨迹修订开销。

## 7. 优点

- **针对性明确**：区分“利用历史信息”与“回头修正历史预测”，切中了长时程重建的关键困难。
- **模块化、无需微调**：冻结几何模型，仅增加外部记忆与修订机制，便于跨模型复用。
- **候选检索与几何核验分离**：不把视觉相似度直接当作回访事实，而是通过两个不同历史窗口的几何一致性进行筛选。
- **局部几何与全局放置解耦**：修订窗口全局位置时，窗口内原有的局部相机与点图可整体移动，设计清楚、实现上较易兼容现有模型。
- **评估相对全面**：既测位姿、稠密几何和 SLAM，也测下游视图合成，并分析显存、运行时间及错误案例。
- **局限意识较明确**：附录讨论了误检、联合推理改变局部预测、记忆增长和局部几何无法修复等问题，没有把方法描述成无条件有效。

## 8. 不足与局限

- **主要修订对象是窗口级全局放置**：SMORE 不直接纠正窗口内部的深度、局部相机关系或点图错误；若误差来自局部几何预测，单纯移动窗口难以消除。
- **依赖可用的视觉回访线索**：重复纹理、外观变化、遮挡、视角差异或缺少回访都会削弱检索；顺序向前运动场景中的潜在收益可能较小。
- **核验并非正确性的保证**：两组历史证据仍可能因重复场景结构或错误历史放置而产生一致但错误的提议；相似变换拟合使用的两相机对几何约束也有限。
- **联合推理本身可能影响当前局部预测**：附录展示了即使回访修订被拒绝，加入历史帧进行联合预测仍可能改变当前窗口估计；旋转门控不能保证平移、尺度或稠密几何也稳定。
- **记忆并非无界且无成本**：外部记忆随序列增长；论文提供了记忆裁剪诊断，但没有建立无界序列下的容量保证或最优压缩方案。
- **工程开销与模型依赖**：核验可能触发额外几何模型前向推理，SMORE 并非计算免费的插件；其实际速度受基础模型推理成本主导。
- **实验外推仍有限**：评测集中于给定数据集与室内/物体中心轨迹，尚不足以证明在任意动态场景、长期户外导航、强光照变化或大规模真实部署中的效果。
- **结果解读需注意协议差异**：主实验多强调在线修订，而附录还报告序列结束后的位姿图优化；不同结果是否使用最终优化必须按具体实验协议区分。新视角合成的改进也同时涉及分别训练的解码器，不能完全归因于几何修订本身。
