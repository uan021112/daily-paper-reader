## 摘要
我们提出 Unravel，这是一种无需训练的框架，可将单张图像转化为可交互的 3D 场景，其中每个物体都是独立且可移动的资产。现有生成器要么生成一个纠缠在一起、无法移动任何物体的整体几何体，要么通过一次前馈过程预测所有物体，导致错误猜测无法被检测或修正。Unravel 则采用不同的方法：先拆解场景，再将其重新组装。从输入图像出发，智能体式流程逐层剥离图像，并以点云作为恢复空间关系的主要模态。具体而言，视觉语言模型负责规划哪些物体完整可见，图像编辑器则将这些物体移除并修复被遮挡区域。每次编辑都会经过验证，之后才纳入重建过程。通过这一流程，场景中被遮挡的部分逐步转化为直接观测，使物体能够在暴露最充分时得到重建，而非仅凭原始图像进行幻觉式推断。随后，场景按照移除顺序的逆序重新构建，使支撑物体自然地先于其所支撑的物体放置。由于单视角图像只能呈现物体的一部分，我们将观测到的点视为物体尺寸的下界：资产可以扩展以覆盖这些点，但不能缩小到无法覆盖它们。最后，我们通过物理仿真使重建场景达到稳定状态，以消除悬浮物体和相互穿插现象，随后再由智能体进行审查，修正残余的摆放错误。在多种室内场景上的大量实验表明，与现有方法相比，Unravel 能够恢复更多物体，更忠实地摆放物体，并生成物理合理性更高的场景。

## Abstract
We present Unravel, a training-free framework that turns a single image into an interactive 3D scene, where every object is an independent and movable asset. Existing generators either produce one entangled geometry in which no object can be moved, or predict all objects in one feed-forward pass, where a wrong guess cannot be detected or repaired. Unravel instead takes a different approach: it first takes the scene apart, and then puts it back together. Starting from the input image, an agentic harness that iteratively peels the image layer by layer, and adopts point cloud as major modality for spatial relationship recovery. Specifically, a vision-language model plans which objects are fully visible, an image editor removes them and restores the occluded regions. Every edit is verified before being incorporated into the reconstruction. This process gradually turns occluded parts of the scene into direct observation, allowing objects to be reconstructed when they are best exposed rather than hallucinated from the original image alone. The scene is then rebuilt in reverse removal order, so that the supporting objects are naturally placed before the objects they support. Since a single-view image only reveals part of an object, we treat the observed points as a lower bound on its size: an asset may grow to cover its points, but can not shrink away from them. Finally, we physically settle the reconstructed scene to remove floating objects and interpenetrations, followed by an agentic audit that corrects remaining placement errors. Extensive experiments on diverse indoor scenes show that Unravel recovers more objects, places them more faithfully, and produces scenes that are more physically-plausible than existing methods.

# 论文总结：Unravel——从单张图像恢复可交互的 3D 场景

## 1. 核心问题与整体含义

- **研究目标**：从一张室内场景图像恢复一个可交互的 3D 场景，其中每个物体都是独立资产，可以单独移动、替换或重新摆放。
- **研究动机**：
  - 传统场景重建常得到连在一起的整体几何，难以对单个物体进行操作。
  - 一次性预测场景中所有物体的方法，容易在遮挡严重时猜错物体形状或位置；由于预测过程是整体性的，错误也不容易定位和修正。
  - 单视图只提供物体的部分表面信息，隐藏部分和真实尺寸存在不确定性。
- **整体思路**：Unravel 不试图一次性“猜出”完整场景，而是先逐层移除场景中的物体，让原本被遮挡的内容逐步显露；再利用这些逐步获得的观测重建物体，并按相反顺序组装场景。论文的核心主张是：把“场景拆解过程”记录下来，可作为恢复物体几何、遮挡次序和支撑关系的依据。

## 2. 方法论：核心思想与关键技术

### 2.1 逐层拆解图像

- 一个智能体式流程由视觉语言模型（VLM）规划移除目标，并标出需要保护的物体。
- 图像编辑器移除当前可见的目标，并对其腾出的区域进行修复，以露出后方内容。
- 每次编辑后由验证器检查是否存在：
  - 目标未被移除；
  - 非目标物体被误删；
  - 编辑产生不合理或虚构内容。
- 验证通过后，编辑才进入下一轮重建。物体在移除前、显露程度较高时被分割并提取，作为该物体的最佳观测快照。

### 2.2 对齐并融合各轮点云

- 对原图及编辑后的图像分别运行单目几何模型，得到逐像素点图和置信度。
- 固定相机内参，并将每轮点图对齐到首轮坐标系。对齐使用未被此前编辑影响、且两轮均有效的像素作为锚点，通过最小化点间误差估计相似变换（尺度、旋转、平移），采用 Umeyama 闭式解；对残差较大的锚点剔除后再拟合。
- 融合时保留未编辑区域已有点，只把上一轮编辑区域在新图像中显露出的点加入累积点云。这样既保留已经观察到的物体表面，也逐步补充原本被遮挡的表面。

### 2.3 利用拆解顺序给点云分配物体标签

- 对同一像素，拆解过程中不同轮次可能观察到同一条视线上的不同深度表面。Unravel 因而保留每个点的“轮次—像素”来源，而不是只给像素分配一个标签。
- 每个点根据该轮仍在场的物体实例掩码及其移除顺序，分配给视线方向上最前方的候选物体；若没有候选物体，则归为房间结构。
- 由此得到每个物体的点簇，以及用于拟合地面和墙面的环境外壳。

### 2.4 生成资产并按逆序组装

- 每个物体的最佳观测图像先转成规范化图像，再输入图像到 3D 模型生成独立网格资产。
- 由于规划通常先移除容器中的物体、后移除容器本身，论文据此推断支撑次序，并按移除顺序的逆序组装：先放支撑物，再放置其上的物体。

### 2.5 单侧尺寸约束与物理沉降

- 将生成资产的表面点与对应点云簇配准，使用双向中位数 Chamfer 距离衡量匹配程度，并通过截断相似变换 ICP 进一步细化。
- 单视图中被遮挡的方向只知道尺寸下界。对这些“欠观测轴”，要求配准后的资产跨度**不小于**观测点簇跨度；资产可以变大以覆盖观测点，但不能缩小到遗漏这些点。变换仍受限于相似变换及有界轴向调整，而不是任意仿射变换。
- 配准后，通过小幅平移进行物理沉降：
  - 使可移动物体有地面或其他物体支撑；
  - 避免物体间相互穿插；
  - 限制调整幅度，并要求物体不能比原位置离观测点簇更远。
- 最后由智能体检查渲染结果，对剩余摆放错误作局部修正，再进行沉降。

## 6. 主要结论与发现

- 逐层移除物体并在最佳显露时提取资产，能改善物体分割覆盖和生成资产的保真度。
- 在 5 个场景、160 个物体的消融中，Unravel 的平均资产保真度为：VLM 评分 **8.2**、人工评分 **8.6**；直接重建分别为 **4.7** 和 **4.9**。
- 对后续轮次移除的物体，Unravel 相较直接重建提高了可用观测覆盖：论文报告融合点云的平均点数从 **1.53M** 增至 **2.81M**；直接重建对相关物体点簇的平均覆盖率为 **76.9%**，其中 **10.1%** 的物体覆盖率低于 70%。
- 定性比较显示，Unravel 更能保留被遮挡物体的布局，并减少悬浮、穿插和摆放偏差。
- 这些结果支持论文的总体观点：对于单图场景恢复，显式记录并利用拆解过程，能够为重建和组装提供比一次性整体预测更可检查、可修正的依据。

## 7. 优点

- **流程可检查、错误可局部化**：每轮编辑都经过验证，避免将单次失败直接传播到完整场景。
- **显式利用遮挡信息**：移除前景对象后，原本被遮挡的表面转为新的图像观测，而不只是依赖生成模型从原图补全。
- **拆解与组装相互利用**：轮次和像素来源既帮助点云对齐、实例归属，也帮助推断物体顺序和支撑关系。
- **尊重单视图的不确定性**：将欠观测方向的几何约束视为尺寸下界，避免把部分观测错误地当成完整物体尺寸。
- **结合数据驱动生成与几何、物理约束**：独立资产由现成 3D 模型生成，位置则由点云配准和物理沉降校正，模块职责相对清晰。
- **实用目标明确**：输出是独立、可移动资产构成的场景，而不只是外观相似的整体几何。

## 8. 不足与局限

- **依赖图像编辑质量**：论文明确指出，复杂拥挤场景中，编辑器可能改变剩余物体外观或位置；这种漂移可能跨轮累积，影响点云对齐和资产位置。
- **依赖多个基础模型的稳定性**：规划、编辑、分割、单目几何估计、资产生成和最终审查任何一环出错，都可能影响结果；验证流程只能降低风险，不能保证完全消除错误。
- **单视图信息存在根本限制**：不可见侧、内部结构及真实尺寸无法从图像直接确定，最终几何仍依赖生成先验；“观测跨度下界”也不能解决完全未观测部分的真实性问题。
- **评测规模与量化指标有限**：核心数值消融只覆盖 5 个场景；大量额外结果是定性展示。缺少统一、全面的场景级定量基准，使几何精度、摆放精度及物理有效性难以精确比较。
- **评测偏差风险**：资产评分使用 VLM 作为一类评审；人类评审虽采用盲评和随机顺序，但评分仍带主观性。对场景摆放效果的主要论据也来自可视化。
- **成本与时延未报告**：多轮编辑和生成可能带来较高的 API 成本及处理时间，但论文未给出相关数据。
- **应用范围尚待验证**：主要面向室内场景；对室外环境、动态场景、强反射透明物体、非刚体、严重遮挡或需要精确交互碰撞的任务，文中没有充分验证。
