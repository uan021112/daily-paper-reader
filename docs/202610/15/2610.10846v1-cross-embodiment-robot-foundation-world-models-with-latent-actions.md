## 摘要
机器人本体形态与动作空间的多样性，使得构建能够跨不同本体形态泛化的机器人世界模型颇具挑战。我们提出潜在动作条件机器人世界模型（Latent Action-Conditioned Robot World Model，LAC-WM），该模型在一个学习得到的统一潜在动作空间中运行，该空间由多种本体形态共享。适配至此前未见过的机器人本体形态时，这一统一动作空间能够提升世界模型的性能。我们将 LAC-WM 与显式动作条件世界模型（Explicit Action-Conditioned World Model，EAC-WM）进行比较，后者以显式运动标签为条件。实验结果表明，显式动作条件会导致不同本体形态之间的动作表征彼此割裂，从而限制模型适配新机器人时的下游性能。我们在灵巧操作任务和经过修改的 LIBERO 基准上评估了这两种模型。在灵巧操作任务和 LIBERO 上，LAC-WM 的下游性能分别较 EAC-WM 提升最高达 46.7% 和 11.7%。至关重要的是，统一的潜在动作空间使 LAC-WM 的下游性能能够随着预训练所用本体形态数量的增加而提升。相比之下，EAC-WM 中彼此割裂的动作空间会导致性能随着预训练本体形态数量增加而下降。这些结果凸显了统一动作空间对于高效跨本体形态学习的重要性，并回应了机器人领域的一项关键挑战。项目网站：https://lacwm.github.io/

## Abstract
The diversity of robot embodiments and action spaces makes it challenging to build robot world models that generalize across different embodiments. We introduce the Latent Action-Conditioned Robot World Model (LAC-WM), which operates within a learned unified latent action space shared across diverse embodiments. This unified action space improves the world model's performance when adapted to previously unseen robot embodiments. We compare LAC-WM with an Explicit Action-Conditioned World Model (EAC-WM), which conditions on explicit motion labels. Our results show that explicit action conditioning leads to disjoint action representations across embodiments, limiting downstream performance when adapting to new robots. We evaluate both models on dexterous manipulation tasks and a modified LIBERO benchmark. LAC-WM improves downstream performance over EAC-WM by up to 46.7% on dexterous manipulation and 11.7% on LIBERO. Crucially, the unified latent action space allows LAC-WM's downstream performance to scale positively with the number of embodiments used during pretraining. In contrast, the disjoint action space in EAC-WM leads to decreased performance as the number of pretraining embodiments increases. These results highlight the importance of a unified action space for efficient cross-embodiment learning, addressing a key challenge in robotics. Project website: https://lacwm.github.io/

## 1. 核心问题与整体含义

- **研究问题：**不同机器人在身体结构、传感器、执行器和控制方式上差异很大，动作空间往往彼此不兼容。因此，世界模型即使能在某些机器人上预测动作后的视觉变化，也未必能把学到的知识迁移到训练中未见过的新机器人。
- **研究动机：**机器人世界模型可以根据候选动作预测未来观测，并据此辅助规划。但如果不同机器人使用的动作表示互不相通，跨机器人数据就难以有效共同训练。
- **论文主张：**与直接使用各机器人自己的显式动作标签相比，先学习一个跨本体形态共享的**统一潜在动作空间**，更利于整合异构数据，也更利于适配新机器人。论文通过 LAC-WM 与显式动作条件模型 EAC-WM 的比较，检验这一主张。

## 2. 方法论

### 核心思路

- 论文提出 **LAC-WM（Latent Action-Conditioned Robot World Model）**。它先从连续图像观测中提取潜在动作，以潜在动作作为条件预测未来图像特征；训练时再用动作标签辅助约束潜在动作，使其表达与实际运动相关的内容。
- 对照方法 **EAC-WM（Explicit Action-Conditioned World Model）**直接编码显式运动标签。由于不同本体形态的动作定义不同，EAC-WM为不同形态使用各自的动作编码器。

### 关键模块与训练流程

1. **视觉编码：**使用冻结的 V-JEPA 2 将图像观测 \(O_t\) 转为视觉特征 \(x_t\)。
2. **逆动力学模型（IDM）：**输入相邻时刻特征 \(x_t,x_{t+1}\)，输出潜在动作 \(z_t\)，即 \(z_t=\mathrm{IDM}(x_t,x_{t+1})\)。
3. **前向动力学模型（FDM）：**以当前特征和潜在动作预测下一时刻特征：
   \[
   \hat{x}_{t+1}=\mathrm{FDM}(x_t,z_t).
   \]
4. **运动解码器（MD）：**根据当前视觉特征和潜在动作，重建显式运动标签，例如人手姿态、机器人末端执行器动作和相机运动：
   \[
   \hat{a}_t=\mathrm{MD}(x_t,z_t).
   \]
5. **联合训练损失：**结合未来视觉特征预测损失与运动重建损失：
   \[
   \mathcal{L}=\lambda_{\mathrm{recon}}\mathcal{L}_{\mathrm{recon}}
   +\lambda_{\mathrm{motion}}\mathcal{L}_{\mathrm{motion}}.
   \]
   其中，视觉预测采用均方误差；运动解码也采用均方误差。
6. **交叉增强（cross-augmentation）：**对同一对连续观测独立增强两次，一份输入 IDM 生成潜在动作，另一份输入 FDM 做预测，以减少 IDM 直接把未来视觉信息“泄漏”进潜在动作、从而走捷径的风险。
7. **适配新本体形态：**由于推理时没有未来观测，无法直接用 IDM 生成潜在动作，模型增加一个动作投影器，将新机器人的原始动作映射到预训练的潜在动作空间。论文采用分阶段微调：先用 LoRA 微调 IDM 与 FDM，再训练动作投影器，最后联合微调投影器和 FDM。推理时使用动作投影器和 FDM进行动作条件预测。
8. **规划使用方式：**对多个候选动作序列分别进行世界模型 rollout，比较预测终态与目标图像的视觉特征距离，选择更接近目标的动作序列执行。

## 3. 实验设计

### 预训练数据与比较对象

- 使用三个预训练数据集：**EgoDex**（人类灵巧操作视频及手部姿态）、**Agibot**（双臂人形机器人）和 **DROID**（Franka 单臂机器人）。
- 每个数据集抽取约 50,000 条轨迹；动作按 5 步分块，以降低观测频率。动作信息包括末端执行器姿态、手部或夹爪动作，以及部分数据中的相机运动。
- 主要比较：
  - **LAC-WM：**通过 IDM 学习共享潜在动作，并用运动解码损失加以约束。
  - **EAC-WM：**为不同本体形态使用独立显式动作编码器。
  - 其他基线或变体包括从零训练的 EAC-WM-S、共享显式编码器 EAE*、不使用运动解码器的 IDM 变体，以及 VLA-only 的随机或均值动作基线。

### 评测场景与 benchmark

- **跨形态动作表征分析：**使用 UMAP 可视化三种数据来源的动作嵌入，并进行机器人到人类、人类到机器人的潜在动作迁移定性比较；附录还用 PCA 和聚类考察潜在动作的语义结构。
- **灵巧操作与新机器人适配：**在 RoboCasa 仿真中使用双臂 Franka 加 Allegro 手（BFA）作为预训练阶段未见的新本体形态，执行抓取、抬起并放置物体等任务。评测包括已知类别中的未见实例，以及未见物体类别。
- **动作条件图像预测：**预测未来 8 帧，用 PSNR、LPIPS、FID、FVD 等指标衡量生成质量。
- **机器人规划：**以世界模型从候选动作中选取更接近目标子图像的动作，并评估接触、抬起、任务成功率，以及与子目标的视觉特征距离。候选动作来自训练数据或一个在 BFA 数据上训练的 VLA。
- **改造版 LIBERO：**采用另一种视觉 tokenizer，在 LIBERO 轨迹上微调，并评测 5 个涉及未见物体或未见初始位置的任务；每个任务 25 次，共 125 个 episode。

## 4. 资源与算力

- 论文明确报告：主要训练约使用 **64 张 NVIDIA H200 GPU，耗时约 4 天**。
- 推理测试使用 **NVIDIA L40S**；批量大小为 10、预测 8 个未来帧时，报告的推理时间约为 **0.1 秒**。

## 5. 实验数量与充分性

- 论文包含多类实验：表征可视化与跨形态动作迁移、动作条件图像预测、灵巧操作规划、不同预训练本体数量与数据量的缩放实验、运动解码和交叉增强消融，以及更换视觉 tokenizer 后的 LIBERO 测试；附录还报告了不同微调策略和基于训练集动作候选的评估。
- **整体覆盖较丰富：**既检验了表征是否对齐，也检验了预测质量与下游规划效果，并进行了消融和跨 benchmark 验证。
- **统计支撑有限：**灵巧操作主要报告 3 个随机种子的均值与标准差；LIBERO 每任务 25 次，总计 125 次。实验规模足以支持初步趋势判断，但对较小差异的统计显著性支撑有限。
- **公平性方面有一定控制：**LAC-WM 和 EAC-WM采用相同的 FDM 主体、视觉表征和预训练数据规模；但适配新本体形态时，两者训练流程并不完全相同。作者也指出，EAC-WM采用直接微调的配置优于某种多阶段配置，说明基线结果会受微调策略影响。
- **缩放实验存在混杂因素：**部分实验在增加本体形态的同时也增加了数据量，因此不能将性能变化完全归因于本体形态数量。不过论文另有固定样本量、增加形态数量的比较，能部分缓解这一问题。

## 6. 主要结论与发现

- **潜在动作更能跨数据集对齐。**UMAP 中，IDM 潜在动作比显式动作编码呈现更强的跨数据集聚合；加入运动解码监督后，对齐效果更明显。
- **运动监督和交叉增强有助于避免无效捷径。**不使用运动解码器的模型可能把光流或视觉分布等信息编码为潜在动作，导致跨形态迁移时出现视觉伪影。
- **LAC-WM 的预测与规划表现整体优于 EAC-WM。**在 BFA 评测中，LAC-WM 的动作条件图像预测指标优于 EAC-WM；规划任务中，LAC-WM 的平均成功率为 22%，EAC-WM 为 15%，即相对提升约 46.7%。
- **LIBERO 上也有提升。**5 个任务的平均成功率从 EAC-WM 的 82.4% 提高到 LAC-WM 的 92.0%，提升 **9.6 个百分点**，相对提升约 11.7%。
- **预训练形态数量的影响因动作表示而异。**LAC-WM 的下游表现随预训练本体形态增加而改善；EAC-WM 则出现性能下降趋势。论文据此认为，统一动作空间更能利用异构预训练数据。

## 7. 优点

- **问题聚焦明确：**直接针对机器人动作空间异构这一跨本体形态学习瓶颈，而非只讨论一般的视频生成质量。
- **方法设计形成闭环：**潜在动作既由相邻观测推断，也接受显式运动标签约束，并通过动作投影器支持真实推理时的原始动作输入。
- **验证层次较完整：**从嵌入空间结构、跨形态动作迁移，到图像预测、机器人规划和 LIBERO 评测逐层验证方法主张。
- **比较与消融有助于解释机制：**设置共享显式编码器等变体，并分析运动解码和交叉增强的作用，不只报告最终成功率。
- **关注规划价值：**将世界模型用于筛选 VLA 生成的候选动作，展示了模型作为规划评估器的实际用途，而非仅作为离线视频预测器。

## 8. 不足与局限

- **尚未在真实机器人硬件上验证。**主要任务来自仿真环境，模型对真实相机噪声、接触动力学误差和执行器误差的鲁棒性仍待检验。
- **灵巧操作的绝对成功率偏低。**即便 LAC-WM 优于对照方法，论文中 BFA 规划平均成功率仍约为 22%，说明复杂任务尚未被可靠解决。
- **对运动标签仍有依赖。**论文把运动解码损失作为重要的潜在动作约束；虽然作者认为方法可扩展到无标签视频，但如何有效利用大规模无标签数据并未在本文中充分验证。
- **计算与数据需求较高。**训练使用 64 张 H200 GPU、约 4 天；预训练也依赖多个规模较大的数据集，实际复现和部署成本值得考虑。
- **实验规模与覆盖面仍有限。**跨形态预训练只涉及人类、Agibot 和 DROID 等有限来源；下游新本体形态与任务类型也较集中，无法据此断言对所有机器人类型都有效。
- **规划评价可能受候选动作来源影响。**部分评测使用专门训练的 VLA 产生候选动作，结果反映了世界模型与该候选生成器的组合效果；不同 VLA、动作采样策略或目标距离定义可能影响结论。
- **“形态数量带来提升”的因果解释需谨慎。**增加数据来源时，数据分布与数据总量也可能变化；即使论文提供固定样本量的补充实验，仍需要更多控制变量实验进一步区分其影响。
