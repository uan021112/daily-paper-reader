tldr: 机器人操作预测需要把场景几何理解与动作引发的状态变化联系起来，单靠视觉外观难以充分刻画物体的空间位置。DepState-JEPA基于RGB与深度双流，将两种观测锚定于度量三维空间并融合为共享状态，同时保留模态私有特征，以动作条件转移预测未来视觉表征。模型还利用物体轨迹、机器人本体状态和运动学一致性约束学习。实验显示，该方法提升RGB编码器迁移、特征补全、条件视觉预测与操作成功率，消融结果进一步揭示深度几何和未来状态监督的贡献。

## 摘要
用于机器人操作的预测表征应将场景几何与动作引发的状态变化联系起来。我们的直觉是，理解动作会改变什么，始于理解物体位于何处：互补的 RGB 与深度观测能够共同锚定一个场景表征，并据此推断这些变化。受此启发，我们提出 \textbf{DepState-JEPA}，一种双流 RGB--Depth 联合嵌入预测架构，通过共享潜在状态 \textbf{DepState} 将空间理解与动作条件预测联系起来。该框架基于 V-JEPA~2.1，既将深度作为互补的观测流，也利用深度将两种模态锚定于度量三维空间；它将共享信息汇聚到 DepState，同时保留模态专属特征用于解码。经射线条件化的读出模块无需目标深度即可预测局部特征；在动作条件状态转移之后，同一解码器利用预测状态和固定的初始模态专属特征预测未来 RGB 与深度特征。机器人状态读出模块提供递归本体感觉输入；物体轨迹监督与经标定的正向运动学则通过运动目标以及关节与 TCP 的一致性来塑造状态学习。对比实验表明，RGB-D 适配后，RGB 编码器迁移、特征补全、条件视觉预测及操作成功率均有所提升。模型内消融实验揭示了深度内容、度量坐标和未来状态匹配各自的作用；FK 正则化还能进一步提升控制效果。

## Abstract
Predictive representations for robot manipulation should connect scene geometry with the state changes induced by actions. Our intuition is that understanding what an action will change starts with understanding where things are: complementary RGB and depth observations ground a common scene representation from which to infer those changes. Guided by this intuition, we introduce \textbf{DepState-JEPA}, a dual-stream RGB--Depth joint-embedding predictive architecture that connects spatial understanding with action-conditioned prediction through a shared latent state, \textbf{DepState}. Built on V-JEPA~2.1, the framework uses depth both as a complementary observation stream and to ground both modalities in metric 3D space, aggregating shared information into DepState while retaining modality-private features for decoding. Ray-conditioned readouts predict local features without target depth; after an action-conditioned transition, the same decoders predict future RGB and depth features using the predicted state and fixed initial private features. Robot-state readouts provide recursive proprioceptive inputs; object-trajectory supervision and calibrated forward kinematics shape state learning through motion targets and joint--TCP consistency. Comparisons show stronger RGB-encoder transfer after RGB-D adaptation, feature completion, conditioned visual forecasting, and manipulation success. Within-model ablations identify contributions from depth content, metric coordinates, and future-state matching, with additional control gains from FK regularization.

# 论文总结：DepState-JEPA

## 1. 核心问题与整体含义

- **研究问题：**机器人操作模型不仅要识别场景中“有什么”，还需要知道物体在三维空间中的位置，并预测动作会如何改变场景。仅依赖 RGB 图像时，外观信息丰富，但几何位置与距离不够直接；深度则能提供度量空间信息。
- **研究动机：**论文希望建立一个共同的表征接口，把 RGB 与深度提供的空间信息同动作条件下的未来状态预测连接起来，从而支持空间理解、未来视觉预测和机器人控制。
- **整体思路：**以 RGB-D 构造一个深度几何锚定的共享潜在状态 **DepState**。该状态负责汇聚跨模态的共享信息、接受空间查询并随动作演化；同时，保留 RGB 和深度各自的私有特征，用于模态专属视觉解码。

## 2. 方法论

### 核心思想与架构

DepState-JEPA 建立在 V-JEPA 2.1 的视觉表征学习框架上，包含两个独立的视觉编码流：RGB 编码器和深度编码器。其主要流程如下：

1. **将观测锚定到度量三维空间**
   - 利用相机内参 \(K\)、图像位置 \(p_i\) 和有效深度 \(d_i\)，将图像 patch 反投影为相机坐标系中的三维点：
     \[
     x_i=d_iK^{-1}p_i.
     \]
   - 将由三维坐标编码得到的位置嵌入加到 RGB 与深度特征中，使两个模态在共同的度量坐标系下表达。在线建模只使用可见位置的深度；无效深度使用未知几何标记。

2. **共享—私有特征分解**
   - 每个模态的特征分别投影为共享特征和私有特征。
   - 共享特征进入状态构造与控制预测；私有特征绕过状态转移，保留 RGB、深度各自的细节，供视觉解码器使用。
   - 通过跨模态对齐、共享—私有去相关和方差约束，促使共享特征表达共性，同时减少表征坍塌。

3. **聚合得到 DepState**
   - 采用学习到的查询和注意力聚合器，将 RGB、深度的共享特征压缩为固定数量的状态 token。论文使用 **64 个宽度为 384 的学习查询**。
   - 这些 token 是通用状态槽位，不预先指定为机器人关节或特定物体。

4. **空间补全与视觉解码**
   - 空间读出器接收 DepState 和目标像素的**相机射线**，不接收目标深度或目标三维位置，从状态中读取局部特征。
   - 模态解码器将读出的共享信息与可见的私有特征结合，预测 RGB、深度编码器特征。训练时以教师网络的停止梯度特征作为目标，而非直接重建像素。
   - 空间训练目标包括密集多层级特征预测、遮挡区域共享特征补全，以及共享—私有分解正则项。

5. **动作条件状态转移与物理读出**
   - 时序 Transformer 根据当前状态、关节命令、当前关节配置、关节速度和时间间隔，预测下一状态：
     \[
     \hat S_{t+1}=T_\phi(S_t,u_t,q_t,\dot q_t;\Delta t_t).
     \]
   - 同一组空间与模态解码器读取预测状态，预测未来 RGB-D 特征；视觉解码所用的私有特征固定为初始观测中的特征，滚动过程中不输入未来图像或未来深度。
   - 物理读出头预测关节配置、关节速度和末端执行器 TCP 位姿；物体运动头预测 SE(3) 位姿增量，并累积得到物体轨迹。
   - 关节和 TCP 位姿由独立读出头预测，再通过固定、经标定的正向运动学（FK）约束二者一致。FK 是软正则项，不代表模型具有物理正确性的硬保证。

### 训练流程

- **阶段 A：RGB-D 适配。**使用图像和视频学习 DepState、空间补全及密集视觉特征预测。
- **阶段 B：机器人后训练。**在机器人轨迹上训练动作条件转移和物理读出；训练中继续穿插 RGB-D 回放，以保留阶段 A 的表征目标。
- 机器人预测时，当前状态由单帧 RGB-D 构造；未来 RGB-D 只用于训练监督，不作为推理滚动输入。训练使用 EMA 动量教师提供目标特征，并在后期逐步增加 FK 正则的权重。

## 6. 主要结论与发现

- RGB-D 适配后的 RGB 编码器在冻结探测任务中表现较强：NYUv2 上 RMSE 为 **0.316**，VOC12 上 mIoU 为 **86.0**。这类指标评估的是适配后的 RGB 编码器，推理时不直接使用 DepState 或深度输入。
- 在 LingBot-Depth 特征补全中，DepState-JEPA 的 L1 为 **0.247**、余弦相似度为 **0.951**，优于表中列出的对比方法。
- 在动作和每步记录的本体状态作为条件的时序预测中，DepState-JEPA 在 1、8、16、24、32 步各评测端点上均取得表中最佳 RGB 特征 L1 / 余弦指标；例如 32 步时 L1 为 **0.491**、余弦相似度为 **0.779**。这项评测使用记录的未来本体状态，与控制中的递归预测条件不同。
- 控制结果中，DepState-JEPA 的 DMC 平均回报为 **813.2**，MW 平均成功率为 **77.1%**（在线策略学习）和 **90.1%**（潜在空间 MPC）。真实机器人完整任务成功率为抽屉任务 **81.1%**、杯子任务 **78.9%**。
- 消融结果支持深度内容和度量坐标分别带来收益；移除未来状态匹配会降低控制表现；去掉 FK 正则后，聚合成功率从 **83.4%** 降至 **82.5%**，显示其收益存在但幅度相对有限。论文也指出，某些组件的优势并非在所有评测指标上都明显。

## 7. 优点

- **把几何与动作预测放在统一状态接口中：**DepState 同时支持空间查询和动作条件状态演化，目标不局限于多模态特征融合。
- **显式区分共享信息与模态私有信息：**共享状态服务于预测与控制，私有路径保留模态细节用于视觉解码，避免把所有内容都压入同一状态。
- **推理信息边界较清楚：**未来预测阶段不访问未来 RGB-D；空间查询不使用目标深度；论文也分别说明记录本体状态的视觉预测和递归本体状态的控制评测。
- **物理监督不只依赖单一标签：**关节、TCP、关节速度和物体轨迹监督与 FK 一致性互补；消融进一步检验了其中部分设计。
- **实验面较广：**除标准视觉基准外，还包含仿真控制和真实机器人实验，展示了从表征到操作的完整评测链条。
- **协议细节较充分：**附录描述了数据划分、掩码规则、训练目标、预测接口、物理单位与真实任务成功判据，有利于理解结果的适用范围。

## 8. 不足与局限

- **真实任务覆盖有限：**真实机器人实验集中于固定室内环境中的抽屉操作和杯子抓放，不能据此推断对更广泛物体、场景和操作技能都具有同等效果。
- **依赖固定相机与标定条件：**主要机器人协议使用经标定的外部固定相机；移动相机、仅腕部相机、跨机器人形态零样本迁移尚未验证。
- **比较的公平性有限：**不同方法的预训练、模型容量、输入模态和任务适配流程存在差异；部分时序基线是作者扩展出的 AC 版本。论文承认其跨方法结果不是严格的同容量、同预训练预算比较。
- **统计证据仍有限：**若干关键结果基于 3 个训练种子，部分表征探测与读出校准基于单个种子。真实机器人采用配对初始条件，但论文报告的边际成功率不足以进行逐试验配对统计检验。
- **视觉特征准确不等于物理动态准确：**全图特征误差可能无法充分反映关键移动区域、接触过程或物体轨迹的精度；FK 只约束关节与 TCP 预测一致，不保证接触动力学正确、无碰撞或操作安全。
- **固定私有记忆可能限制大位移预测：**未来解码一直复用初始帧私有特征，遇到大幅运动、遮挡解除或新表面显露时可能不够充分。
- **共享—私有分解不具备语义可识别性：**该结构是为了预测任务而设计的特征分工，不代表模型学到了唯一、可解释的语义分解。
- **算力透明度不足：**未报告 GPU 型号、数量和训练时长，因而难以准确评估复现实验的硬件成本和计算预算。
