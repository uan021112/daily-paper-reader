## Abstract 

Language 3D Gaussian Splatting enables open-vocabulary scene understanding by associating Gaussian primitives with language features. These semantic attributes in-crease model storage, while most existing 3DGS compres-sion methods are designed mainly to preserve RGB ren-dering quality. One straightforward approach is to ap-ply sparsification and quantization sequentially. However, pruning based only on rendering quality can remove Gaus-sians that have small RGB contributions but are important for semantic prediction. Once removed, their semantic in-formation cannot be recovered by later quantization. We propose CLUNO GS , a compact framework for Language 3DGS that combines semantics-aware Gaussian sparsifica-tion and vector quantization in a unified constrained ob-jective. Semantic supervision is used during sparsification, and the objective jointly considers rendering quality, se-mantic accuracy, and compactness. We optimize the uni-fied objective with alternating primal, sparsification, quan-tization, and dual updates. We evaluate CLUNO GS on open-vocabulary localization and segmentation using the LERF and ScanNet-10 benchmarks. Under aggressive com-pression, our unified, semantics-aware formulation sub-stantially alleviates the degradation of semantic represen-tations caused by sequential compression and semantics-agnostic Gaussian sparsification. Ablations further show that jointly coordinating sparsification and quantization better preserves semantic accuracy than applying them in-dependently. 

1arXiv:2610.30013v1 [cs.CV] 21 Oct 2026 1. Introduction 

Open-vocabulary 3D scene understanding enables objects in a 3D scene to be localized or segmented using arbitrary natural-language queries, without restricting predictions to a predefined class set [28]. This capability supports appli-cations such as AR/VR [19], autonomous driving [8], and robotic manipulation [14, 31]. Earlier neural-field meth-ods encoded semantics in implicit representations, but re-peated volumetric sampling and network evaluation made training and rendering costly [17, 36]. Language 3DGS instead attaches vision-language features to explicit Gaus-sian primitives and reuses the tile-based splatting pipeline of 3DGS to render semantic feature maps efficiently, avoid-ing repeated volumetric sampling and per-sample network evaluation [16, 30, 41]. Directly attaching high-dimensional vision-language features to individual Gaussians incurs substantial storage and rendering overhead [30, 41]. LangSplat mitigates this problem using a scene-specific low-dimensional autoen-coder, while LangSplatV2 further replaces the heavyweight decoder with sparse per-Gaussian coefficients over shared dictionaries, enabling efficient high-dimensional feature splatting [22, 30]. These advances reduce the cost of se-mantic feature representation and inference, but do not tar-get compression of the underlying RGB Gaussian scene. Consequently, a complete Language 3DGS model still con-tains the original 3DGS attributes together with additional semantic parameters. Its compression must therefore pre-serve both photometric fidelity and semantic responses. Standard 3DGS compression often combines sparsifica-tion or pruning [1, 12, 13, 38, 40] with quantization [21, 24, 25]. Applying them sequentially decouples semantic learn-ing from Gaussian selection, so RGB-driven sparsification can discard semantically important Gaussians that subse-quent stages cannot recover. Figure 1 illustrates this failure using LangSplatV2 [22], GaussianSpa, and CompGS: se-mantic representations degrade whether semantic learning occurs before or after RGB-driven Gaussian sparsification. Our unified formulation instead coordinates semantic learn-ing, sparsification, and quantization throughout optimiza-tion. To address this gap, we propose C LUNO GS ( Compact 

Language via Un ified Optimization for 3D Gaussian 

Splatting). The framework combines RGB reconstruction and semantic supervision with a cardinality constraint on Gaussian opacities and vector quantization (VQ) of selected attributes. Updating the scene parameters, sparse support, and quantized representations within the same constrained problem allows them to adapt to one another instead of in-heriting irreversible decisions from a preceding stage. We solve the resulting non-smooth problem with an alternating primal–dual procedure. Our contributions are: • We introduce a unified constrained formulation that cou-ples an RGB–semantic task objective with Gaussian spar-sification and attribute vector quantization for compact Language 3DGS. • We develop a compact Language 3DGS optimization framework and solve the unified problem using an al-ternating primal–dual procedure that coordinates differ-entiable scene optimization, sparsification, quantization, and dual updates. • We evaluate C LUNO GS on LERF and ScanNet-10 using recent language-field baselines, sequential compression and ordering controls, qualitative comparisons, and con-trolled ablations. Across the two benchmarks, C LUNO GS reduces serialized storage by 80.9–82.8% relative to the corresponding uncompressed models, with losses of at most 1.6 mIoU points, 1.1 accuracy points, and 0.07 dB PSNR. 

## 2. Related Work 

Language 3DGS. Language-aware 3D representations lift 2D foundation-model features into queryable 3D fields, with LERF providing an early NeRF-based formula-tion [17]. Language 3DGS methods mainly follow two paradigms. Render-supervised methods learn per-Gaussian features or codes by matching rendered feature maps to 2D supervision, as in LangSplat, Feature 3DGS, GAGS, and LangSplatV2 [22, 29, 30, 41]. Direct-lifting methods in-stead register or aggregate multi-view features onto recon-structed Gaussians without iterative semantic fitting, as in Dr. Splat and Occam’s LGS [7, 18]. LightSplat and Extrin-Splat further replace dense per-Gaussian embeddings with compact semantic indices or an external object-group in-dex [2, 11]. We build on LangSplatV2 because its seman-tic coefficients and RGB attributes share the same Gaussian support, allowing sparsification and attribute quantization to account for both rendering and semantic quality. 

Compact Language 3DGS. Recent work has explored compact representations for the semantic features in Lan-guage 3DGS. DF-3DGS separates RGB and semantic Gaus-sians and sparsifies the semantic field, while CF3 com-presses feature Gaussians through pruning, merging, and autoencoding [10, 20]. CSGaussian progressively entropy-codes both color and semantic attributes [34]. SCOUP represents semantic features with sparse codes, whereas CoSAG predicts and entropy-codes compact semantic bind-ings for individual Gaussians [4, 15]. These methods re-duce semantic storage through specialized feature represen-tations and coding schemes. 

General 3DGS Compression. RGB-only 3DGS com-pression reduces active primitives, attribute storage, or bit-2stream size. GaussianSpa and PUP 3D-GS sparsify opti-mized scenes using constrained or uncertainty-based crite-ria [13, 40]. Compact 3DGS, C3DGS, and CompGS use clustering or quantization to reduce attribute storage [21, 25, 26]. RDO-Gaussian jointly optimizes masks and entropy-constrained attributes, while HAC++ and LocoGS model context or local coherence for compact coding [6, 32, 35]. FCGS applies a feed-forward codec to an optimized Gaussian scene [5]. Joint sparsification and quantization are therefore established in RGB 3DGS. The concurrent GETA-3DGS preprint also studies joint structured pruning and heterogeneous quantization [39]. CLUNO GS instead optimizes opacity with both RGB and semantic supervi-sion before cardinality projection, and coordinates Gaussian sparsification with attribute vector quantization in the same constrained formulation.

## 4. Methodology: C LUNO GS 

To compact a Language 3DGS model while preserving se-mantic and RGB quality, we propose a unified compres-sion framework, C LUNO GS. Our method places semantics-aware Gaussian sparsification and vector quantization in a single constrained objective. We solve it with a primal–dual procedure that alternates among differentiable scene opti-mization, sparsification, quantization, and dual updates.

## 5. Experiments 

5.1. Settings 

Benchmarks, metrics, and baselines. We evaluate on four LERF scenes [17] and ScanNet-10 [9], reporting se-mantic accuracy, RGB PSNR, storage, and peak memory. Language baselines cover direct-lifting methods (Occam’s LGS and Dr. Splat [7, 18]) and render-supervised seman-tic fields (LangSplatV2, CCL-LGS, GAGS, and CF3 [20, 22, 29, 33]). Compression baselines pair three Gaus-sian sparsifiers (opacity Top-K, PUP 3D-GS, and Gaus-sianSpa) with CompGS or C3DGS for attribute quantiza-tion [13, 25, 26, 40]. On LERF , all query relevance maps use the same post-processing and a fixed 0.4 threshold. mIoU averages query-mask IoU, while localization Acc. checks whether the peak response lies inside a ground-truth box. On ScanNet-10 ,we follow OpenGaussian’s label protocol and the ten-scene split used by LUDVIG [23, 37]. Each method uses its na-tive decoder and scale-selection rule to render ten class-score maps. We bilinearly sample these scores at projected ScanNet points when the projected and sensor depths differ by at most 5 cm, average them over valid views, and take the pointwise argmax. Evaluation includes points observed in at least one view after applying the same 0.1 activated-opacity threshold to each RGB 3DGS. Per-scene mIoU and mAcc average class IoU and recall over the ground-truth classes present in that scene, followed by an unweighted average over the ten scenes. 

Implementation details. Each scene starts from a 3DGS model [16] trained for 30k iterations. We store all three LangSplatV2 semantic levels in one Gaussian model and optimize it for 30k iterations; the released implementation instead trains three separate level-specific models for 10k iterations each [22]. The first 20k iterations follow the original language-field training, while the final 10k activate our unified sparsification–quantization updates. All rate-matched compressed variants use the same 20% Gaussian-retention budget. Detailed schedules are provided in the supplement. Storage includes all files required for infer-ence. Dr. Splat therefore includes its PQ index, whereas LangSplatV2 includes the semantic coefficients and dictio-naries for all three levels together with one shared RGB 3DGS. Peak memory is measured from a fresh process through one native-resolution text-query rendering. 

5.2. Overall Performance 

Table 1 evaluates whether aggressive compression can pre-serve both semantic prediction accuracy and RGB rendering quality. Across LERF and ScanNet-10, we compare deploy-able systems from two Language 3DGS paradigms: direct-lifting methods and render-supervised semantic fields. Se-mantic metrics and PSNR measure quality, while storage and peak memory measure deployment cost. Compared with CF3, the smallest competitor on both benchmarks, C LUNO GS achieves over 5× storage reduc-tion while also attaining the lowest peak memory. It nev-ertheless ranks second in every semantic and RGB qual-ity metric; its maximum gaps to LangSplatV2 are only 1.6 mIoU points, 1.1 accuracy points, and 0.07 dB PSNR. The same trend on both datasets shows that this advantage is not benchmark-specific. LangSplatV2 remains the quality leader because its full model retains detailed semantic coefficients and dictionar-ies at all three scales. While direct-lifting methods are designed for efficient querying, both Occam’s LGS and Dr. Splat trail this render-supervised model in semantic quality. Occam’s LGS is also storage-intensive on both datasets and incurs the highest peak memory on LERF.
