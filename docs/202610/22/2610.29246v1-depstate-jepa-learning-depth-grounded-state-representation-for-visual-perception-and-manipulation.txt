ABSTRACT
Predictive representations for robot manipulation should connect scene geometry
with the state changes induced by actions. Our intuition is that understanding what
an action will change starts with understanding where things are: complementary
RGB and depth observations ground a common scene representation from which
to infer those changes. Guided by this intuition, we introduce DepState-JEPA,
a dual-stream RGB–Depth joint-embedding predictive architecture that connects
spatial understanding with action-conditioned prediction through a shared latent
state, DepState. Built on V-JEPA 2.1, the framework uses depth both as a comple-
mentary observation stream and to ground both modalities in metric 3D space, ag-
gregating shared information into DepState while retaining modality-private fea-
tures for decoding. Ray-conditioned readouts predict local features without tar-
get depth; after an action-conditioned transition, the same decoders predict future
RGB and depth features using the predicted state and fixed initial private features.
Robot-state readouts provide recursive proprioceptive inputs; object-trajectory su-
pervision and calibrated forward kinematics shape state learning through motion
targets and joint–TCP consistency. Comparisons show stronger RGB-encoder
transfer after RGB-D adaptation, feature completion, conditioned visual fore-
casting, and manipulation success. Within-model ablations identify contributions
from depth content, metric coordinates, and future-state matching, with additional
control gains from FK regularization.

INTRODUCTION
Learning visual world models enables anticipation of action outcomes (Ha & Schmidhuber, 2018;
Maes et al., 2026). For manipulation in real-world space, this requires relating the current spatial
arrangement to the changes an action may cause. Consider a robot reaching for a cup: RGB reveals
its appearance and context, while depth locates the cup and gripper relative to the table in three-
dimensional space. Anticipating the reach then requires reasoning about how this arrangement will
change, not merely recognizing the cup. This raises a broader question: how can the geometry
revealed by depth inform a robot’s predictions of how its actions will change the scene?
RGB JEPAs predict representations rather than pixels (Assran et al., 2023; Bardes et al., 2024):
V-JEPA 2 supports action-conditioned planning (Assran et al., 2025), while V-JEPA 2.1 strength-
ens dense visual features (Mur-Labadia et al., 2026). Depth-related JEPAs offer complementary
designs. LeMuMo-JEPA combines RGB and aligned depth features within a common Transformer
for multimodal perception (Cornelissen et al., 2026). Locate 3D’s 3D-JEPA predicts masked point-
cloud features enriched by lifted 2D features, rather than maintaining separate RGB–depth streams
(Arnaud et al., 2025); JEPADepth predicts depth from RGB with auxiliary latent supervision, rather
than encoding measured depth (Grigore & Popa, 2026). These designs target multimodal perception
or geometric estimation, but do not establish a common state interface between spatial understanding
and action-driven evolution. This motivates our work:
Can complementary observations ground a spatially queryable, temporally predictive shared
state representation while retaining modality-private features in separate decoding paths?

mentary RGB–depth observations in a shared latent state, DepState, while retaining modality-private
features for decoding. This depth-grounded state connects spatial queries with action-conditioned
prediction of future visual features, robot state, and object motion.
To answer this question, we introduce DepState-JEPA (Fig. 1), a joint-embedding predictive ar-
chitecture centered on DepState, a depth-grounded shared latent state connecting RGB–depth ob-
servations, spatial readout, and action-conditioned transition. Built on V-JEPA 2.1, an independent
Depth-Video branch provides complementary observations and metric grounding for both streams.
DepState aggregates shared information, while private paths preserve modality-specific detail for
decoding rather than forming separate evolving states. This common interface supports reading
missing spatial content and forecasting representations after robot actions. Representation learning
uses images and video; robot prediction initializes DepState from a single RGB-D frame and evolves
it under actions and proprioception, without accessing future RGB-D images.
Specifically, visible metric depth and camera intrinsics place both streams in metric 3D coordinates;
shared–private projections and learned aggregation form a compact, geometrically grounded Dep-
State. Ray-conditioned readouts query local shared features without target depth; private features
supply modality-specific decoding detail. After action-conditioned transitions, the same decoders
predict future RGB and depth features with fixed initial private memory. Robot-state readouts supply
recursive proprioception; object-motion supervision shapes the state. Calibrated forward kinematics
couples independent joint and end-effector predictions, propagating consistency gradients into the
transition alongside direct physical supervision.
Training proceeds in two stages: 1) RGB-D adaptation learns DepState from images and video clips
via masked shared-feature completion and dense modality-feature prediction, exploiting spatial and
temporal context. 2) Robot post-training learns action-conditioned transitions and physical read-
outs using future-state and feature targets, physical supervision, and kinematic regularization, while
RGB-D replay retains the adaptation objectives. Evaluation (Sec. 4) spans spatial understanding,
multi-step forecasting, and manipulation, with controlled ablations testing the roles of geometry,
feature sharing, and kinematic consistency. Our contributions are threefold:
• Dual-stream RGB–Depth Video JEPA framework. We introduce DepState-JEPA, which
connects spatial understanding and action-conditioned prediction through a shared latent state,
DepState. Independent RGB and depth encoders capture complementary observations, while
metric depth grounds both streams in a common 3D coordinate frame.
• Unified DepState construction and prediction pipeline. We aggregate shared RGB–depth fea-
tures into DepState, retaining private features for modality-specific decoding. Ray-conditioned
readouts predict missing features without target depth and are reused after action-conditioned
transitions to predict future features, with initial private memory fixed throughout rollout. Robot-
state readouts supply recursive proprioception; object-trajectory supervision and joint–TCP con-
sistency provide complementary training signals for state evolution.
• Empirical gains and controlled component analysis. RGB-D adaptation improves RGB-
encoder transfer; the full pipeline supports feature prediction and manipulation. Within-model
ablations identify contributions from depth and metric coordinates, private decoding for visual
accuracy, and future-state matching for control performance.

RELATED WORK
2.1
JOINT-EMBEDDING PREDICTIVE ARCHITECTURES
Joint-embedding predictive learning uses target representations, rather than pixels, as the objects of
prediction. I-JEPA learns image representations by predicting masked regions from visible context
(Assran et al., 2023), while V-JEPA extends this approach to spatiotemporal video features (Bardes
et al., 2024). V-JEPA 2 scales video pretraining and connects learned features to robot prediction
and planning (Assran et al., 2025). V-JEPA 2.1 further develops dense and multi-level supervi-
sion, strengthening the spatial detail retained by video representations (Mur-Labadia et al., 2026).
A complementary direction changes the unit of prediction: Causal-JEPA masks object-level latents
and infers them from surrounding context to encourage interaction-dependent prediction (Nam et al.,
2026). These approaches illustrate how prediction targets and representation structure shape what
a model learns. DepState-JEPA extends the RGB-centric video JEPA framework along the modal-
ity axis, introducing an independent Depth-Video stream. We retain V-JEPA 2.1’s dense feature-
learning design while making measured geometry an explicit input to shared-state construction,
complementing spatial cues learned from RGB.
2.2
DEPTH AND 3D REPRESENTATION LEARNING FOR JEPAS
Depth-related JEPAs differ in whether depth is predicted, used for supervision, or encoded as ge-
ometric input. JEPADepth combines masked latent prediction with photometric supervision for
monocular depth estimation (Grigore & Popa, 2026). Depth-Regularized JEPA aligns RGB fea-
tures with depth features during training while retaining RGB-only inference (Khan, 2026). Le
MuMo JEPA fuses RGB and camera-aligned LiDAR depth through learnable fusion tokens within
a shared Transformer (Cornelissen et al., 2026). 3D-JEPA in Locate 3D learns masked point-cloud
representations from RGB-D-derived geometry enriched with lifted 2D foundation-model features
(Arnaud et al., 2025). SR-JEPA predicts missing-entity features in native 3D scenes at supplied
target locations (Zhou et al., 2026). DepState-JEPA jointly encodes RGB and measured depth in in-
dependent video streams, using visible metric depth to ground both streams in camera coordinates.
Shared–private factorization retains modality-specific features alongside the shared state, whereas
ray-conditioned readout predicts missing content without target depth or a supplied 3D location.
The same state evolves under actions to predict future RGB-D features, connecting geometric rep-
resentation learning with spatial completion and temporal prediction through a common interface.
2.3
ACTION-CONDITIONED WORLD MODELS FOR ROBOTICS
Latent world models support robot control by predicting how representations change under actions.
DINO-WM learns transitions over frozen DINOv2 patch features and optimizes action sequences
toward visual goals (Zhou et al., 2024); PLDM studies JEPA-based planning from reward-free of-
fline trajectories (Sobal et al., 2025). V-JEPA 2 adapts pretrained video features through action-
conditioned robot post-training (Assran et al., 2025), whereas LeWorldModel jointly learns its en-
coder and dynamics from pixels with a distributional regularizer (Maes et al., 2026). A related
question is how physical information should shape the representation. MCR uses proprioceptive
state–action alignment for robot representation learning (Jiang et al., 2024); PSG-JEPA grounds in-
dividual states and state pairs in physical quantities (Yan et al., 2026), and physically grounded JEPA
combines inverse dynamics with state alignment (Liu et al., 2026b). DepState-JEPA studies consis-
tency among predicted physical quantities in addition to their direct supervision. Calibrated forward
kinematics couples independent joint and end-effector readouts of the predicted state; object motion
is supervised through increment-based pose trajectories. The kinematic constraint regularizes the
depth-grounded state transition without imposing hard guarantees of physically correct dynamics.
Concurrent work. Closely related recent preprints advance geometric supervision and spatial pre-
diction (Khan, 2026; Zhou et al., 2026), including geometry-conditioned video modeling (Kim et al.,
2026; DreamX Team et al., 2026); physical state grounding and physics-conditioned latent dynam-
ics (Yan et al., 2026; Liu et al., 2026a;b); and joint world modeling and action generation (Lin et al.,
2026). These directions complement our use of an explicit depth stream, depth-lifted positions, and
selectively shared RGB-D features for spatial, temporal, and robot prediction.

3.5
TRAINING AND ROLLOUT PROTOCOL
RGB-D adaptation trains state construction and readout on images and video clips using spatial
and temporal context, not causal next-frame rollouts. Robot post-training adds action-conditioned
transitions and physical heads; image/video replay continues the adaptation objective:
Ladapt = Lspatial + Lfac,
Lrobot = Ltemporal + Lfac + Lsup + λFKγ(n)LFK.
(11)
The schedule γ(n) gradually enables FK over robot updates n; supervision uses valid labels. The
stopped EMA teacher tracks the representation stack, including factorization and aggregation, but
not predictors or physical heads. Control and ablation rollouts recursively use predicted states and
proprioception with fixed initial private features; Table 2 uses recorded proprioception instead. Ap-
pendix C.1 gives weights and schedules, Appendix B.2 details the modules, and Algorithms 1–2
specify training and rollout.

4.2
SPATIAL REPRESENTATION TRANSFER AND PREDICTION
Spatial Transfer with Frozen Encoders. Following V-JEPA 2.1’s frozen dense-probing protocol
(Mur-Labadia et al., 2026), we evaluate monocular depth estimation (MDE) on NYUv2 (Silberman
et al., 2012) and semantic segmentation (SS) on VOC12 (Everingham et al., 2015). Linear probes
read normalized final-layer features. Ours uses the Stage-A RGB encoder, measuring transfer after
RGB-D adaptation with the depth branch and DepState bypassed at inference. Readouts, prepro-
cessing, and probe optimization are shared within each task; V-JEPA and ours use ViT-g. App. E.3
lists representation training and probing conditions. Tab. 1 and Fig. 3 give scores and predictions.
Masked RGB-D Spatial Feature Completion. We extend V-JEPA 2.1’s masked feature prediction
to RGB-D spatial completion (SC) on held-out LingBot-Depth scenes (Tan et al., 2026). All meth-
ods share identical RGB/depth masks, visible context, and calibration; masked depth is excluded
from geometric lifting and query construction. Tab. 1 reports masked-region L1 and cosine similar-
ity against shared frozen RGB/depth references, each averaged equally over modalities. Fig. 4(a)
shows PCA visualizations of completed features in masked regions. App. E.4 specifies synchronized
masks, frozen reference targets, and masked-token scoring.

4.3
TEMPORAL VISUAL PREDICTION
Next-Step Visual Prediction.
We evaluate next-frame features on held-out robot trajectories.
Frozen linear readouts map predictions to a shared V-JEPA 2.1 RGB reference space. Fitted on
observed training frames, readouts stay frozen across horizons. L1 and token-wise cosine similarity
score the complete prediction–readout path. App. E.5 specifies calibration, interfaces, and action-
conditioned adaptation.
Multi-Step Visual Forecasting. We evaluate recursive visual predictions at 8, 16, 24, 32 steps from
matched starting frames. Table 2 supplies recorded actions and proprioception at each step, with no
future images. DepState-JEPA keeps its initial private memory fixed. Control and internal ablation
rollouts instead use predicted proprioception (App. E.7). Fig. 4(b) shows feature forecasts across
horizons.
4.4
EMBODIED PREDICTION AND MANIPULATION
Online Policy Learning through Trajectories. Following DreamerV3 (Hafner et al., 2025), we
train an actor–critic on imagined trajectories and adapt JEPA dynamics from online replay. Evalua-
tion directly executes the actor. We use 20 DMControl (DMC) and 50 Meta-World (MW) tasks with
matched interaction budgets. Tab. 3 reports task-averaged episode return (the sum of rewards) for
DMC and averaged success for MW. App. E.6.1 specifies replay, imagination, and policy learning.
Latent Space Receding-Horizon Planning. Following TD-MPC2 (Hansen et al., 2024), we use
model predictive control (MPC): optimize action sequences through the learned latent transition
using predicted rewards and terminal values, execute the first action, and replan at every step. Task
sets, interaction budgets, and search budgets are matched across JEPA models. Tab. 3 reports both
metrics; App. E.6.2 specifies value learning and trajectory optimization.
Sim2real Manipulation Transfer. We construct matched simulation and real environments (Fig. 5)
and augment simulated depth with PRISM (Liang et al., 2026). Simulation-trained models remain
frozen for drawer and cup visual-goal MPC. Tab. 3 reports full-task success across three seeds, with
30 trials each. The 60-second robot-execution budget excludes inference and search. App. E.6.3
specifies subgoals, independent resets, and success aggregation.

ABLATION STUDY
Ex.1–Ex.15 vary components against the full Ex.16 configuration. App. E.7 defines interventions
and disaggregates completion, Drawer/Cup prediction, and controller-specific success.
Effect of Depth Content and Metric Coordinates. Ex.1–Ex.3 and Ex.16 isolate depth content
and metric coordinates under fixed backbones and supervision. Combining both reduces L1 from
0.408 to 0.340 and raises SR from 76.8% to 83.4% (Fig. 6(a)). Each factor improves prediction and
control, although their joint gains are subadditive at the reported means.
Effect of Selective Sharing and Spatial Readout. Ex.4–Ex.8 vary private decoding, alignment,
aggregation, queries, and completion (Fig. 6(b)). Removing private decoding raises L1 from 0.340
to 0.390, with SR at 83.2% versus 83.4%. Mean aggregation gives L1 0.440 and SR 77.0%. Pixel/ray
queries tie in feature scores; private decoding primarily benefits visual readout.
Effect of Temporal Modeling and Physical Supervision. Ex.9–Ex.15 vary temporal targets, phys-
ical supervision, memory, and decoders (Fig. 6(c)). Removing future-state matching lowers SR from
83.4% to 79.5%; removing FK gives 82.5% with direct labels retained. Separate decoders reach L1
0.333 and SR 83.4% with added capacity. App. E.7 relates these outcomes to each intervention.
5
CONCLUSION
DepState-JEPA connects RGB–depth geometry, shared-state evolution, and private decoding for
feature completion, conditioned forecasting, and manipulation. RGB-D adaptation improves en-
coder transfer; ablations identify contributions from geometry, local state content, and future-state
supervision. App. F discusses the remaining scope.

B
REPRESENTATION ARCHITECTURE AND SPATIAL LEARNING
This section specifies the observation interface, online representation, and momentum targets used
by the spatial and temporal objectives.
B.1
DATA INTERFACES, GEOMETRY, AND MASKING
Observation and control streams. Representation adaptation uses registered RGB-D images and
video from LingBot-Depth (RobbySim training scenes; Tan et al., 2026), with 16-frame clips sam-
pled at 4 fps. Image and video batches alternate. Depth is metric and intrinsics are associated with
each image. Clips do not cross trajectory boundaries. Robot post-training instead uses adjacent
native control records, with their actual positive time difference ∆tt. Each robot state is encoded
from a single RGB-D image at the corresponding control timestamp using the image tokenizer. It is
not encoded from a bidirectional video window containing future frames. Missing control intervals
and intervals crossing resets are excluded rather than interpolated into artificial transition targets.
The primary robot protocol uses one calibrated, fixed external RGB-D camera, and trains a separate
post-training instance for each embodiment. Consequently, the camera-ray grid can be specified
for future predictions without knowing future camera motion. Wrist-camera-only trajectories are
15


outside this protocol. Visual lifting remains in camera coordinates; TCP and object/part poses are
expressed in the robot base frame. Camera extrinsics convert annotations where necessary but do
not constitute an input of future geometry.
Actions and proprioception. We preserve the dataset’s joint-command semantics: absolute joint
position, relative joint position, or joint velocity. A three-component one-hot vector identifies the
control mode. A command is never substituted for the measured next joint state. A recorded gripper
command contributes one additional channel, mapped to the data source’s declared [0, 1] opening
range, together with an availability bit. When absent, both are zero. The action-token input therefore
has dimension nq+5. Joint positions and relative commands are divided by sq,j; velocity commands
and proprioceptive velocities by sq,j/(1 s); ∆t is expressed in seconds. The scales are defined in
Appendix C.2.
Current proprioception comprises measured qt and a synchronized instantaneous velocity when
available. Otherwise, we use the backward difference of consecutive measured configurations. This
fallback uses only past and current records, not future labels. Continuous revolute coordinates are
temporally unwrapped; bounded joints retain their physical coordinates. Fixed and mimic joints
are expanded according to the robot description; all independent joints on the TCP chain must be
available.
Image transforms and depth encoding. RGB and depth share a random resized crop with area
fraction in [0.7, 1] and aspect ratio in [0.9, 1.1]. RGB is resized bilinearly; depth and its validity
map use nearest-neighbor interpolation. The pixel-coordinate transform Aimg updates intrinsics as
K′ = AimgK. A clip or robot rollout uses one common geometric augmentation across time and
across online/target branches. We do not apply horizontal flips, time reversal, metric-scale changes,
or additional RGB-only photometric augmentation. RGB uses channel means (0.485, 0.456, 0.406)
and standard deviations (0.229, 0.224, 0.225) for intensities in [0, 1].

OPTIMIZATION, ALGORITHMS, AND INFERENCE
D.1
OPTIMIZATION PROTOCOL
RGB-D Adaptation. We initialize the state modules and modality decoders and optimize Ladapt.
During the first 2000 updates, all pretrained encoder parameters are frozen except the depth im-
age/video stems. Those stems use the new-module learning rate during this interval, while all new
modules are trainable. We then unfreeze both encoders and assign their parameters the encoder
learning rate. The last 5000 updates increase spatial resolution but retain 16-frame video input.
Robot Post-training and Replay. Robot post-training retains the adapted online and target rep-
resentation branches, adds the temporal predictor and physical readouts. Every fourth optimizer
update uses Ladapt on training-split representation data; the remaining 15,000 updates use Lrobot
on robot trajectories. Image and video replay alternate by replay index. Visible-target weights are
already at their full values. The new-module learning-rate group for robot post-training includes the
state and decoding modules learned during RGB-D adaptation. The FK consistency weight uses the
robot-update ramp in Eq. (21).

LingBot-Depth completion data and split. We evaluate synchronized RGB-D masked-feature

Synchronized masks and permitted context. A union of patch-aligned rectangular blocks cov-

seeds per evaluation image. The same spatial mask is applied to RGB and depth, and is shared across
all methods. The image geometry and common mask grid are fixed before evaluation; online tokens
whose receptive fields intersect a masked block cannot read original pixels from that block. Hid-

aggregation, or private-memory construction. Zero-filling is accompanied by an explicit visibility
mask; it is not interpreted as a valid depth measurement. Depth normalization uses fixed training
statistics, not statistics computed from the unmasked full image. Only the target encoders see com-
plete observations. Queries specify target pixels or calibrated camera rays, never hidden RGB, target
depth, or lifted target 3D coordinates. Invalid depth and synthetic masking are distinguished.
Fixed RGB and depth reference targets.
Following V-JEPA 2.1’s masked representation-
prediction objective (Mur-Labadia et al., 2026), the completion targets are features rather than re-
constructed pixels. This RGB-D benchmark and its metrics are our adaptation, not an official V-
JEPA 2.1 completion benchmark. All methods predict the same pair of frozen target encoders: the
released V-JEPA 2.1 ViT-g RGB image encoder and a separate V-JEPA 2.1 depth encoder adapted
on training-scene depth only. The latter uses the depth-stream representation-learning recipe, with
its checkpoint fixed before completion training and independently of the compared methods. Both
reference checkpoints, preprocessing transforms, feature grids, and depth-validity rules are fixed
across methods. Final-layer reference tokens are normalized with non-affine LayerNorm. Complete
RGB-D observations are processed only by these stopped target branches; their features never enter
online context.

methods requiring a new query decoder, its width is 384 with four Transformer blocks and six at-

EMBODIED PREDICTION AND MANIPULATION
Task suites and interaction budgets. Both control tracks use the same single-task evaluation:
the 20 visual DMControl tasks used by DreamerV3 (Tassa et al., 2018; Hafner et al., 2025) and
the 50 Meta-World tasks (Yu et al., 2020). Each task trains a separate agent; the latter is not the
joint-policy MT50 benchmark. The DMControl set comprises acrobot swingup; ball-in-cup catch;
cartpole balance, balance-sparse, swingup, and swingup-sparse; cheetah run; finger spin, turn-easy,
and turn-hard; hopper hop and stand; pendulum swingup; quadruped run and walk; reacher easy
and hard; and walker run, stand, and walk. Each DMControl run uses 106 environment steps,
action repeat 1, and 1,000-step episodes. Each Meta-World run uses 2 × 106 environment steps,
action repeat 2, and 200-step episodes (100 decisions), following the task horizon of TD-MPC2
(Hansen et al., 2024). An environment step here is a benchmark step before action repetition, not an
internal physics substep; repeated rewards are summed. These suite-specific budgets apply equally
to actor-only and MPC agents. We use DreamerV3’s DMControl budget and TD-MPC2’s Meta-
World protocol. The same task set, camera settings, and evaluation reset schedule are used across
compared methods within each control track.
Observation and action interfaces. All methods observe the same camera view, task goal when
required, and current proprioception. RGB methods receive RGB; multimodal methods also receive
aligned metric depth and calibration. RGB-D and proprioceptive access are explicit adaptations of
visual-only benchmarks. A common 512 × 512 rendering supplies the scene, followed by each en-
coder’s native resizing and normalization. No simulator object poses, contact labels, or privileged
full-state vectors enter the controller. Native benchmark action semantics and limits are preserved:
a task-specific projection replaces any robot-specific action interface, and the learned transition is
adapted on that task’s replay. Domain-specific proprioceptive readouts are trained only for measured
coordinates needed by the control state; robot-arm FK objectives are not applied to unrelated DM-
Control embodiments. Within imagined rollouts, proprioception is predicted, not read from future
environment states. The interaction budget counts environment transitions and remains distinct from
representation adaptation and predictor pretraining.
Evaluation and aggregation. We use three independent training seeds (0, 1, and 2), as in Ta-
ble 3, and evaluate every 50,000 environment steps on ten episodes per task and seed, with the
same held-out reset seeds across methods. Evaluation transitions are excluded from training budgets
and replay; they cannot guide checkpoint selection or hyperparameter tuning. The main table uses
the final budget checkpoint, not the best evaluation checkpoint. DMControl reports undiscounted
episode return R = P

E.6.3
SIM-TO-REAL MANIPULATION TRANSFER
Simulation-training and real-world deployment environments.
We jointly construct the
simulation-training and real-world deployment environments for the drawer and cup tasks, with
consistent robot kinematics, gripper geometry, object dimensions, workspace layout, and camera
calibration. Simulation and hardware share action units, coordinate conventions, and workspace
limits. Task-specific simulated trajectories train the manipulation models separately from the DM-
Control and Meta-World agents. The common budget is 106 simulated control steps per task and
seed, with three seeds (0, 1, and 2); trajectory splits and randomization schedules are shared across
methods. Texture, illumination, initial object pose, and friction variation are applied around the
matched setup. Model selection and controller tuning use held-out simulation scenes.
Physics-grounded depth augmentation. PRISM (Liang et al., 2026) converts rendered RGB and
ideal metric depth into sensor-realistic depth by separately modeling sensing invalidation and mea-
surement inaccuracy. Its invalidation component synthesizes missing returns, while its residual gen-
erator perturbs valid depth measurements. We use a fixed pretrained PRISM model to augment sim-
ulated training observations before feature extraction and geometric lifting. Depth-aware methods
receive the same augmented observations and validity masks; RGB-only methods retain their RGB
input. Invalid returns are excluded from point construction. Sensor-model pretraining is separate
from task-specific control training. At deployment, the controller uses measured RGB-D directly;
PRISM is a training-data augmenter and is not applied to real observations.
World-model training and planning policy. We adopt the visual-goal-conditioned latent MPC
policy used for robotic arm planning in V-JEPA 2.1 (Mur-Labadia et al., 2026). Action-conditioned
predictors are adapted on simulated observation–action sequences using teacher-forced and recur-
sive future-feature prediction. Each model retains its native representation; a fixed-size aggregation
interface is used for point-based features, with no future point coordinates provided to the predictor.
At each decision, the cross-entropy method (CEM) samples bounded action sequences, rolls them
out through the learned transition, and refines the sampling distribution using candidates with the
smallest terminal latent distance to the current visual goal. Goal and predicted features use the same
normalization and feature-distance definition within each model. We use the eight-step planning
configuration of V-JEPA 2.1, with 300 candidates and 15 refinement iterations, shared across meth-
ods. The robot executes the first action through its low-level controller, acquires a new observation,
and replans. Action limits, execution intervals, and gripper commands use a common hardware
interface. This goal-distance objective is distinct from the reward/value-based TD-MPC2 track in
App. E.6.2.
Goal specification and real-world deployment. All methods receive the same ordered visual sub-
goals, camera views, and initial conditions. Opening and closing use separate subgoals, since the
final closed state alone cannot distinguish task completion from the initial state. Cup manipulation
likewise specifies grasping, lifting, and placement stages. Goal observations provide task specifi-
cations, not action supervision; they are fixed before evaluation and excluded from training. Stage
34


transitions use observation-based goal criteria calibrated in simulation, without simulator state at de-
ployment. The subgoal order and criteria are shared across methods. All learned weights are frozen
for real trials, with no task-specific real-world finetuning.
The quantitative Sim2Real protocol contains two task families. Each family has two independently
evaluated atomic tasks and one full task. Only the full tasks enter the two Sim2Real columns in
Table 3; atomic-task scores are diagnostics.
Execution-time budget. The 60-second task budget measures cumulative robot execution time,
including the final stability checks. Model inference and CEM search time are excluded from this
budget, and no inference-time deadline is imposed. This timing convention is shared across methods;
the budget is not a 60-second wall-clock limit.
Task 1: Pull and Close Drawer. An episode starts with the drawer closed and requires an ordered
opening and closing cycle. Let d ∈[0, 1] denote travel normalized by the calibrated full stroke.
Success requires reaching d ≥0.8, then returning to d ≤0.1 and maintaining that final configuration
for one second within 60 seconds of cumulative robot execution time. Opening alone does not count
as success. The same stroke normalization and thresholds apply in simulation and real evaluation.
For the atomic Pull Drawer task, reset the drawer to its closed state and require reaching d ≥
0.8. For Close Drawer, reset it to an open state with d ≥0.8 and require reaching d ≤0.1 and
maintaining that configuration for one second. The Pull and Close (Full) task uses the ordered
cycle specified above. Each task has its own independently reset trials and the same execution-time
budget.
Task 2: Pick and Place Cup. The robot must grasp the cup, lift it clear of its initial support, and
release it upright in the designated target region. Success requires the cup center to lie within 5 cm
of the target center, its upright axis to remain within 15◦of vertical, and the released cup to remain
stable for two seconds, all within 60 seconds of cumulative robot execution time. Merely reaching
the goal while holding the cup does not satisfy the completion condition. For the atomic Pick Cup
task, reset the cup on its initial support and require a successful grasp and lift clear of that support.
For Place Cup, initialize the cup securely grasped and lifted, then require upright release in the
target region and the same two-second stability check. The Pick and Place (Full) task starts from
the cup on its support and requires the complete sequence specified above. Each task has its own
independently reset trials and the same execution-time budget. Atomic reset distributions are fixed
before evaluation and shared across methods.
Averaged success and paired trials. Each trained seed receives thirty real trials for each of the six
tasks (four atomic and two full), for 90 trials per method and task across three seeds. Atomic
trials are separate from full-task trials; they do not increase the full-task denominator.
Initial
object/robot configurations are paired across methods and trial order is randomized. Execution-

Averaged success = 100Nsuccess/Ntrials. Per-seed Sim2Real results report the number of suc-

differs between error and similarity/success metrics. Full-model superiority alone does not establish
a super-additive interaction.
Observed geometry effects. Relative to Ex.1, depth content alone (Ex.2) reduces L1 by 0.039 and
increases SR by 3.3 percentage points; coordinates alone (Ex.3) reduce L1 by 0.049 and increase SR
by 4.5 points. Ex.16 improves both further, with L1 0.340 and SR 83.4%. With coordinates already
present, depth content reduces L1 by 0.019 and raises SR by 2.1 points; with depth content already
present, coordinates reduce L1 by 0.029 and raise SR by 3.3 points. At the reported means, the
combined gains are smaller than the sums of the individual gains; the results support complementary

projection into the complete state; Ex.16 uses the original aggregator. This contrast attributes the
change to local-content access in this aggregator. Ex.4 separately tests the private decoding path,
and Ex.5 tests the combined change in alignment scope and total weight.

LIMITATIONS
Camera and task scope.
The robot protocol uses a calibrated fixed external camera and
embodiment-specific training. Real-world evaluation covers drawer opening/closing and cup pick-
and-place in matched indoor workspaces. Moving-camera prediction, zero-shot transfer across em-
bodiments, and broader object and workspace changes remain outside the demonstrated scope.
Representation and prediction scope. NYUv2 and VOC12 probes measure the adapted RGB
encoder, while RGB-D completion evaluates the shared state with its decoding paths.
The
shared/private projections encourage a division of predictive roles, not an identifiable semantic de-
composition. Temporal comparisons with recorded proprioception measure conditioned visual fore-
casting; planning and ablation rollouts use predicted proprioception. Whole-image feature accuracy
does not by itself establish action sensitivity in moving regions or accurate physical trajectories.
Memory and component interpretation. A single initial frame may omit occluded state or motion
history. Fixed initial private memory is a compact decoding choice whose adequacy under large
displacement and newly visible surfaces requires further study. The reported pixel-query and untied-
decoder variants do not support an accuracy advantage for ray queries or decoder sharing. FK is a
soft kinematic regularizer; neither it nor a valid SE(3) parameterization guarantees correct contact
dynamics or collision-free control.
