## 摘要
具身任务智能体能否利用触觉经验，在无需针对特定任务进行模型训练的情况下完成精细操作？我们通过 Tactile-ETA 系统研究这一能力。该系统借助上下文学习，将触觉经验融入具身任务智能体。成功的专家演示展示了操作过程中接触状态如何变化。我们将每段记录下来的机器人动作与对应的相机视角及双侧触觉观测配对。每个动作的触觉观测保留在其起始和结束时刻；如果触觉图像在动作过程中变化显著，则再加入两个相邻时刻的观测。智能体结合这些演示、当前视觉信息、触觉观测和本体感觉，通过通用机器人工具选择动作，且不更新模型参数。在四项模拟操作任务中，在当前感知与执行接口保持不变的情况下，向同样的两段专家演示中加入触觉观测，使平均成功率从 15.75% 提高到 24.00%。进一步实验表明，性能取决于演示中的感官内容及其表征；在相同系统配置下比较不同智能体模型时，Lift Bottle 任务的结果则显示出显著差异。在真实机器人任务中，视觉与触觉观测对齐的演示将任务成功率从 0% 提高到 60%。这些发现表明，在上下文中利用触觉经验进行精细操作是可行的，并为将具身任务智能体扩展至更多感官输入提供了可能路径。

## Abstract
Can embodied task agents use tactile experience to perform fine manipulation without task-specific model training? We investigate this capability through Tactile-ETA, a system that incorporates tactile experience into an embodied task agent through in-context learning. Successful expert demonstrations show how contact changes during manipulation. We pair each recorded robot movement with its camera views and bilateral tactile observations. We keep tactile observations at the start and end of each movement and add two neighboring time points when the tactile images change markedly in between. The agent combines these demonstrations with current vision, tactile observations, and proprioception to select actions through general-purpose robot tools, without updating model parameters. Across four simulated manipulation tasks, adding tactile observations to the same two expert demonstrations increases average success from 15.75% to 24.00%, with current sensing and execution interfaces held fixed. Further experiments show that performance depends on the sensory content and representation of demonstrations, while comparing agent models on Lift Bottle reveals substantial differences under the same system configuration. On the real-robot tasks, demonstrations with aligned visual and tactile observations increase the task success rate from 0% to 60%. These findings demonstrate the feasibility of using tactile experience in context for fine manipulation and suggest a path toward extending embodied task agents to additional sensory inputs.

## 1. 核心问题与整体含义

- **研究问题：**具身任务智能体能否在不针对具体任务微调模型的情况下，利用专家示范中的触觉经验完成精细操作？
- **研究动机：**插入、旋转、轻拿易碎物体等接触丰富的操作，往往需要根据接触状态及时调整动作；单靠视觉可能难以判断接触如何变化。另一方面，传统方法通常依赖额外训练，而具身智能体的上下文学习有望直接在部署时使用示范。
- **整体思路：**作者提出 **Tactile-ETA**，把专家示范中的动作、视觉与双侧触觉观测对齐，作为上下文提供给冻结的具身智能体。智能体再结合当前观测和执行反馈，通过通用机器人工具选择动作，全程不更新模型参数。

## 2. 方法论

### 核心流程

1. 将成功的专家操作轨迹按记录的动作边界切分为多个片段。
2. 每个片段关联：
   - 动作前后的头部相机和腕部相机画面；
   - 机器人记录的运动与状态变化；
   - 同一时间区间内左右指尖的触觉序列。
3. 将这些片段按时间顺序组成完整专家示范，并在任务开始时提供给智能体。
4. 执行时，智能体结合任务指令、示范上下文、当前视觉与触觉观测、本体状态及执行反馈，调用 `move_to`、`observe` 等通用机器人工具。机器人底层控制器执行动作，智能体参数保持固定。

### 触觉序列筛选

- 每段动作始终保留触觉序列的**起点和终点**。
- 为压缩序列同时保留接触变化，方法会在触觉图像中跟踪局部图像块的位移：图像经灰度化和缩放后，在设定的区域内跟踪网格图像块；以可靠匹配位移的第 **75 百分位数**衡量图像变化。
- 若可靠匹配不足，则改用区域内灰度图像差异作为变化度量。
- 左右指尖分别计算变化分数，以两者中较大的分数作为该时刻的变化指标。找到变化最大的相邻时刻对后，若变化达到阈值，则在起止帧之外加入该对观测；否则只保留端点。因此，每个动作片段每侧指尖最多保留四帧，左右指尖使用相同时间索引。
- 这一规则的核心目标，是在有限上下文中既呈现动作边界处的接触状态，又保留显著的中间接触变化。

### 决策形式

论文将智能体的动作选择概括为：

\[
u_t \sim \pi_\theta(\cdot \mid \ell,\mathcal{I},\mathcal{C}_K,H_t)
\]

其中，\(\ell\) 是任务指令，\(\mathcal{I}\) 是工具说明和静态任务要求，\(\mathcal{C}_K\) 是 \(K\) 个专家示范组成的固定上下文，\(H_t\) 是当前执行历史（观测、工具调用和执行反馈），\(\theta\) 是固定的模型参数。该式强调：智能体通过上下文和交互历史选择工具调用，而非通过参数更新学习任务。

## 6. 主要结论与发现

- 在四项模拟任务上，加入示范触觉后，平均成功率从视觉—动作示范的 **15.75% 提高到 24.00%**，提升 **8.25 个百分点**。两组均有当前触觉输入，因此结果支持“示范中的触觉经验提供额外指导”，但提升幅度随任务变化。
- 单有当前视觉和触觉而没有示范时，平均成功率为 **6.25%**；加入视觉—动作示范后为 **15.75%**，表明示范本身也提供了重要操作策略。
- 任务间效果并不一致：Lift Bottle 从 27% 提高到 36%，Pull Out Key 从 18% 提高到 26%，Insert Tube 从 15% 提高到 32%；Lift Can 在各配置下都较困难。
- 触觉表征会影响效果：Lift Bottle 上，Selected 为 36%，端点采样为 27%，全部触觉帧仅为 2%。因此，更多触觉帧并不必然更好，信息筛选和上下文组织可能很重要。
- 增加示范数也没有带来单调提升：平均成功率在 1、2、4 个示范下分别为 22.50%、24.00%、19.00%；不同任务的变化方向不一致。
- 相同系统配置下，不同模型在 Lift Bottle 上的成功率差异明显：GPT-6 为 36%，GPT-5.6 Sol 为 21%，GPT-5.6 Terra 为 3%，GPT-5.6 Luna 为 0%。
- 真实机器人两项任务中，无示范均为 0/5；加入一个多模态示范后，擦白板和拾取薯片均为 3/5。该结果提供了初步的现实可行性证据，但因试验次数少，应谨慎解读。

## 7. 优点

- **问题定位明确：**聚焦视觉难以充分描述的接触变化，并检验能否通过上下文而非任务微调利用触觉。
- **示范与动作时间对齐：**示范同时呈现动作、视觉和左右触觉变化，便于智能体参考“动作发生时接触如何演化”。
- **触觉序列压缩有针对性：**既保留动作边界，又通过变化阈值补入关键中间帧；实验结果也表明这种筛选优于端点采样和全帧输入。
- **主要对照较有解释力：**核心结果比较保持当前感知、示范来源和执行接口固定，使示范触觉的增量作用更容易分析。
- **同时考察行为机制：**除成功率外，还分析插入时的退让和侧向修正、拔钥匙时的阶段转换，尝试连接示范信息与具体决策行为。
- **跨越模拟与真实平台：**在真实机器人上加入多模态示范后观察到任务完成，展示了方法从模拟到实体操作的初步可行性。

## 8. 不足与局限

- **真实实验样本少：**每项任务每种配置只有 5 次，结果易受初始状态和偶然因素影响，尚不足以说明稳定可靠性。
- **归因范围有限：**主模拟对照能隔离“示范中是否含触觉”，但真实机器人比较同时从无示范变为有视觉、动作和触觉的完整示范，不能单独归因于触觉。
- **模型与任务覆盖不足：**主要结果依赖有限的模型和四项模拟任务；模型对比也只在 Lift Bottle 上进行。不同触觉传感器、任务类型和智能体架构的适用性尚未充分验证。
- **统计报告有限：**未提供置信区间或显著性检验，难以判断中小幅度差异的统计稳定性；行为案例能说明可能机制，但个案本身不能构成因果证据。
- **触觉表示依赖启发式：**变化检测通过图像块位移或灰度差阈值进行，没有学习专门的触觉语义表示；阈值和采样策略是否适用于其他传感器或接触形式，仍需检验。
- **决策频率有限：**触觉主要用于动作片段之间的决策，无法在动作执行过程中提供快速闭环触觉控制；连续接触操作仍可能受限。
- **上下文可能带来资源与干扰问题：**示范增多未必提升效果，触觉全帧输入反而大幅降低结果，说明上下文长度、信息冗余和智能体对示范的使用能力都可能成为瓶颈。
- **资源透明度不足：**未披露 GPU、推理费用和完整计算资源；同时实验覆盖受 API 可用性与推理成本限制，复现与成本评估仍不充分。
