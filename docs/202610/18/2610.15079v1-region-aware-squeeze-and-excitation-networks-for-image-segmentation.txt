Abstract
Squeeze-and-Excitation (SE) modules improve convo-
lutional networks by modeling channel-wise dependen-
cies, but collapsing all spatial structure into a single
per-channel descriptor via global average pooling lim-
its their effectiveness for dense prediction tasks such as
image segmentation. We generalize the SE framework
by replacing global pooling with spatially guided pool-
ing, enabling region-aware channel recalibration across
a family of modules with complementary cost profiles:
some add essentially no parameters, others no measur-
able latency. Within this framework, we formalize four
modules of increasing region flexibility: BASE, a for-
malization of Tiled Squeeze-and-Excite [29], partitions
the feature map into a regular grid; SPASE aggregates
over SLIC superpixels [1] for image-adaptive regions;
and, our two most novel modules, MAPSE sources its
regions from a semantic map produced by a frozen,
general-purpose network, while PLEASE learns soft re-
gion assignments end-to-end via a lightweight assign-
ment network. In every variant, each channel receives
one gate per region, so the attention at each pixel re-
flects the region it belongs to, bridging channel and
spatial attention; PLEASE further yields its soft assign-
ments as a free byproduct of its forward pass, giv-
ing structured spatial interpretability without post-
hoc analysis. Across binary segmentation (CUB [30],
DUTS [31], ECSSD [25]), semantic segmentation (PAS-
CAL VOC 2012 [2], ADE20K [38]), and classifica-
tion (mini-ImageNet [28]), our modules outperform SE
and related spatial-channel attention variants on most
benchmarks, holding the majority of best results.

Introduction
Image segmentation is a fundamental problem in com-
puter vision and medical imaging where every pixel
must be assigned a semantic label. Fully convolutional
networks [12] and encoder–decoder architectures such
as U-Net [18] are the de facto standard for this task,
learning hierarchical representations via skip connec-
tions. Nevertheless, these architectures often treat each
feature channel uniformly and rely on large receptive
fields for global context.
Squeeze-and-Excitation (SE) modules [8] improve
convolutional networks by modelling inter-channel de-
pendencies: global average pooling (squeeze) yields a
channel descriptor that is used to reweight each chan-
nel (excitation). This significantly improves classifica-
tion performance, but collapses spatial structure into
a single scalar per channel, limiting effectiveness for
dense prediction tasks such as segmentation [19]. Prior
work introduced spatial extensions such as spatial SE
(sSE) and concurrent spatial–channel SE (scSE), incor-
porating spatial attention alongside channel-wise recal-
ibration [19, 20]. These approaches still assign a single
weight per channel or per spatial location, and therefore
cannot adaptively model variation across semantically
meaningful regions.
We address this gap by formalizing a family of region-
aware Squeeze-and-Excitation modules that incorpo-
rate spatially coherent region information directly into
channel recalibration. We explore four variants of in-
creasing region flexibility, the first three each a strict
generalization of the previous: BASE, a formalization of
TSE [29], uses a regular k × k grid; SPASE aggregates
over SLIC superpixels [1] to produce image-adaptive re-
gions; MAPSE sources its regions from a semantic map
inherited from a frozen, general-purpose network never
trained specifically for the segmentation task, at no ad-
ditional training cost; and PLEASE learns soft region as-
signments end-to-end via a lightweight assignment net-
work embedded in its pipeline.
The key idea shared across all four variants is to
compute region-specific channel descriptors and project
the resulting gating signals back to pixel space. Unlike
prior SE variants, each channel receives multiple gat-
ing values (one per region) and the attention applied at
each pixel reflects the region it belongs to. This formu-
lation bridges channel and spatial attention, enabling

Related Work
2.1
Channel, Spatial, and Region At-
tention
Channel attention mechanisms have become a stan-
dard tool for improving convolutional representations.
The SE block [8] introduced global channel recalibra-
tion via GAP and a learned MLP gate. Later variants
enrich either the squeeze or excitation step: SRM [10]
augments GAP with global standard deviation to cap-
ture style-based statistics; FcaNet [16] reframes GAP as
a special case of DCT-based frequency decomposition
and proposes multi-spectral descriptors; MCA [9] ag-
gregates higher-order statistical moments via a Cross
Moment Convolution module; ECA [32] replaces the
fully connected bottleneck with local cross-channel 1D
convolutions; GCT [35] adopts a non-parametric Gaus-
sian excitation using L2-normalized channel contexts;
and EAN [11] unifies normalization and attention via
GroupNorm and L2 Norm.
Other approaches combine channel and spatial at-
tention. CBAM [33] applies channel recalibration fol-
lowed by a sequential spatial attention map. Gather-
Excite [7] aggregates feature responses from large spa-
tial neighbourhoods via a gather operator and redis-
tributes them to local features, showing that richer
spatial context in the squeeze step yields consistent
gains.
Coordinate Attention (CA) [6] factorizes 2D
global pooling into two 1D encodings along the horizon-
tal and vertical axes, producing direction- and position-
sensitive maps effective for dense prediction. EMA [15]
avoids channel dimensionality reduction by grouping
channels into parallel sub-features and fusing global
and local spatial context via a cross-dimension inter-
action. SCSA [26] similarly combines spatial and chan-
nel attention by decomposing the feature map along
its horizontal and vertical axes, applying multi-scale
1D convolutions to construct a dense spatial attention
map, and subsequently using self-attention to compute
a single image-level channel gate.
For segmentation specifically, Guha Roy et al. [19, 20]
proposed cSE, sSE, and scSE. SANet [37] similarly in-
troduces spatial awareness through an average-pooled
but not fully squeezed attention-convolution channel,
whose output is upsampled to provide dense pixel-
group-aware recalibration. PRM [13] incorporates po-
sitional information and feature propagation into chan-
nel attention, while Project-and-Excite [17] extends SE
to volumetric data by aggregating along spatial axes
rather than collapsing it entirely.
Soft region cues have also been used to guide pixel-
level attention.
SNA [3] learns soft superpixel as-
signments but uses them to modulate local grid-
based neighbourhood attention: each pixel remains a
weighted combination of neighbouring pixel features
rather than an explicitly pooled region representa-
tion. RANet [24] instead learns object-region construc-
tion and models information exchange between regions
to enhance pixel representations, but as a dedicated
semantic-segmentation architecture that uses regions
for relational context exchange, rather than a drop-in
recalibration module that pools and excites an indepen-
dent channel descriptor for each region. Despite these
novelties, none of the above methods pools features into
a set of explicit region descriptors and independently
excites each descriptor to produce a separate channel-
gating vector per region.
A notable limitation shared across SE and its vari-
ants is the absence of built-in spatial interpretability:
their channel-wise gates carry no spatial semantics, and
interpretability must be applied post-hoc via external
tools such as Grad-CAM [23].
CBAM [33] is most
commonly associated with interpretability, owing to its
explicit spatial attention map; however, that map is
channel-agnostic — a single scalar per spatial location
shared across all channels — and is not tied to any
semantic decomposition of the image.
2.2
Region Pooling and Channel Recal-
ibration
Tiled Squeeze-and-Excite (TSE) [29] replaces global av-
erage pooling with average pooling over a regular spa-
tial grid: each pooled tile descriptor passes indepen-
dently through a shared excitation function, producing
a channel vector broadcast over its tile. TSE therefore
preserves multiple spatially indexed channel descrip-
tors through the full squeeze-and-excitation operation,
rather than collapsing the feature map into one global
descriptor. We formalize this fixed-region pipeline as
BASE.
Region-wise feature aggregation has also been ex-
plored through superpixel pooling:
Schuurmans et
al. [22] pool feature vectors over externally computed
superpixel regions for semantic-segmentation predic-
tion branches, establishing superpixel pooling as an
existing image-adaptive aggregation method.
SPASE
applies this idea to produce K distinct gating values
per channel that vary meaningfully across the feature
map, integrating it into our generalised region-aware
SE framework.
Our framework unifies these operations under a com-
mon formulation in which K distinct regions are aggre-
gated into K region-specific channel descriptors, each
excited independently, with the resulting K channel-
2


gating vectors projected back to pixel space to recali-
brate the feature map. BASE formalizes the fixed-grid
case, SPASE uses SLIC computed superpixel regions,
MAPSE sources its regions from a semantic map inherited
from a frozen, general-purpose network, and PLEASE
learns soft region assignments end-to-end.
Beyond recalibration, PLEASE produces its soft re-
gion assignments P ∈RK×h×w as a byproduct of its
forward pass. Unlike CBAM’s channel-agnostic spatial
map, these K maps form a learned, spatially coher-
ent decomposition of the feature map into semantically
meaningful regions, providing structured interpretabil-
ity without post-hoc analysis.

Background
3.1
Notation and Definitions
A tensor X ∈Rc×h×w has c channels and spatial di-
mensions h, w. Scalars are unbolded (e.g. x), vectors
bolded (e.g. x), and tensors with spatial dimensions
capitalized (e.g. X). Square brackets denote indexing
(e.g. X[c, h, w]) and “:” denotes Python-style slicing,
e.g. X[:, h, w] for all channels at spatial location (h, w).
The notation [k] denotes the index set {0, 1, . . . , k −1}
on a 0-based convention.
Given an image I ∈R3×H×W , a superpixelation algo-
rithm partitions [H]×[W] into non-overlapping regions
called superpixels, encoded as a label map S ∈[K]H×W ,
where S[i, j] = k indicates pixel (i, j) belongs to super-
pixel sk = {(i, j) : S[i, j] = k}. We use SLIC [1] to
find S, which clusters pixels in joint color-spatial space
and exposes two knobs: the number of superpixels K
and a compactness m trading off color similarity and
spatial proximity, with larger m yielding more regular,
grid-like regions.
Conv1Dk and Conv2Dk×k denote 1D and 2D convo-
lutions with kernel size k and Softmax denotes the usual
normalized exponential over a vector’s components.

4
Region-Aware
Squeeze-and-
Excite Blocks
We generalize the SE framework along a single axis:
the source of its pooling regions. First, we formalize
TSE as a patchified version of SE that captures local
features within a regular grid. Then we generalize this
rigid spatial tensor partitioning to an input dependent
regional splitting via superpixelation, fixed and com-
puted offline at the network input level. Next, we re-
place this classical, task-agnostic partitioning with a
semantic map inherited from a frozen, general-purpose
deep network, allowing regions to reflect learned high-
level structure at no additional training cost. We finally
generalize this approach by learning soft regions at each
SE module, enabling optimization-driven spatial parti-
tioning. Each variant is described below and is easily
implementable and with simple PyTorch code provided
in the supplementary material.

4.3
Map Aggregation for SE
SPASE computes its regions with a classical, task-
agnostic superpixel algorithm that operates purely on
low-level color and spatial proximity, with no notion of
the semantic content of the scene. We propose Map
Aggregation for Squeeze-and-Excite (MAPSE),
which instead sources its regions from a semantic map:
a K-channel tensor that broadly localizes semantically
meaningful structure within the image, produced once
by a frozen, general-purpose deep network that was not
trained for the segmentation task at hand. Because this
semantic map already encodes learned, high-level struc-
ture rather than only low-level pixel similarity, MAPSE’s
regions can be more meaningful than SPASE’s, while
still avoiding the training cost of a fully learned parti-
tioning.

4.4
Patch Learnable Aggregation for

Both SPASE and MAPSE rely on a region partition that
is fixed before training, whether computed by a clas-
sical superpixel algorithm (e.g., SLIC [1]) or inherited
from a frozen external model. This introduces a non-
learnable component, notable computational or mem-
ory overhead, and a partition that cannot adapt to the
task or to the representation at the depth at which it
is applied.
To address these limitations, we propose
Patch Learnable Aggregation for Squeeze-and-
Excite (PLEASE), which replaces externally com-
puted region assignments with learned soft assignments
trained end-to-end with the network.

and horizontal flips (p = 0.5); evaluation uses center
crops with ImageNet normalization.
Semantic experiments use an ImageNet-pretrained
ResNet-34 [5] Semantic U-Net with dataset-specific pre-
diction heads: VOC models train on the SBD-extended
VOC trainaug split [4] and evaluate on the VOC2012
validation split; ADE20K models use the official train/-
validation splits.

Classification experiments use ResNet-50 on the 100-

5.2
Ablations
We ablate attention location and granularity, the choice
of ϕ(·), the region count K, and residual connections
in the supplementary material. From these we adopt
the following defaults: modules at U-Net encoder stages
E1–E4; ECA-style Conv1D excitation (Eq. 3); no resid-
ual connection, as in standard channel attention; and
K = 8 regions for every method except MAPSE (Grad-
CAM), which uses K = 128 top-scoring classes, and
BASE, which uses a 2 × 2 grid. We use K = 8 as a com-
mon default wherever the supplementary ablations sep-
arate settings by less than run-to-run variation, and de-
part from it only where the ablation is decisive. MAPSE
(GradCAM) is the one such case: its K indexes a stack
of top-scoring class activations rather than a partition
whose regions must each own a share of the image, so
it stays informative at far larger K.
5.3
Model Interpretability
Table 1 illustrates the spatial interpretability that
emerges during PLEASE’s forward pass. It visualizes the
learned soft-assignment maps at each U-Net encoder
layer (E1–E4) using Argmax, which assigns each pixel
its highest-probability region, and PCA, which projects
the full K-dimensional assignment vectors into RGB.
Similar PCA colors indicate similar region-membership
patterns. More visualizations are provided in the sup-
plementary material.
Successful segmentations show a clear progression:
early PLEASE layers produce broad regions driven by
low-level appearance, which deeper layers reorganize to-
ward the task objective. The ECSSD bee first splits
into bee, flower, and background before later layers
merge the first two into one foreground concept; the
ADE20K building sharpens from a coarse building/sky-
line split into meaningful scene structure. The failures
show little of this, their PCA maps staying fragmented
and never converging. These are qualitative observa-
tions on a few examples rather than a measured effect
and inform a hypothesis for future work, namely that
strong structural priors (as in SPASE) help most in early
layers and flexibility (in PLEASE) in deeper ones.

and inference latency for binary U-Net segmentation.

Binary Segmentation
Table 3 shows that region-
aware recalibration consistently improves the U-Net
baseline while preserving the lightweight character of
SE-style attention:
every proposed variant improves
over baseline on all three datasets and both metrics,
and the proposed modules take five of the six best en-
tries. Because all variants share the same ECA-style
channel excitation operator, their differences isolate
the effect of region construction.
Externally sourced
regions are the strongest:
MAPSE (GradCAM) leads
CUB on both metrics and gives the best ECSSD mIoU,
while MAPSE (DINO) leads DUTS by a clear margin
(87.15 mIoU and 68.82 Boundary F1, against 82.06
and 59.54 for baseline). Among the remaining variants,
PLEASE is the runner-up on CUB and the stronger of
the two on DUTS, while SPASE gives the better ECSSD
mIoU; and even the fixed-grid BASE improves every-
where. The exception is ECSSD Boundary F1, where
EMA is strongest and PLEASE follows. The FCN com-
parison in the supp. material behaves similarly: the
proposed modules hold the best entries, but ECSSD is
more sensitive to region type.
The proposed modules are most decisive where the
backbone already represents the data well: CUB and
DUTS reach comparatively high absolute mIoU and are
where the region-aware methods win outright, whereas
ECSSD is substantially lower across all models and
its gains are less consistent, especially at boundaries.
Region-aware recalibration is thus best understood as
a refinement over already useful features, not a substi-
tute for representational power.
Semantic Segmentation
Table 4 extends the com-
parison to multiclass semantic segmentation with a
pretrained ResNet-34 Semantic U-Net. On VOC2012,
PLEASE gives the best mIoU by a clear margin, im-
proving the baseline from 73.44 to 75.05, with MAPSE
(DINO) second; the less flexible BASE and SPASE re-
gions land slightly below baseline. On ADE20K, every
module improves mIoU, led by MAPSE (DINO) at 32.91
ahead of EMA and MAPSE (GradCAM), but nearly all
of them — ours and prior work alike — fall below the
baseline Boundary F1 of 44.25, which only CA exceeds.
Boundary quality thus trades against region overlap
in the multi-class setting: a region-level gate sharpens
which class is predicted inside a region more than it
sharpens where that region ends.
This reinforces the capacity-dependent reading of
the binary results.
VOC2012, the semantic setting
with substantially higher absolute mIoU, is where a
8


fully learned partition pays off most clearly, whereas
ADE20K, like ECSSD, stays much lower and no single
module separates cleanly.
Mini-ImageNet Classification
Table 5 extends the
comparison to image classification, where every variant
improves over the ResNet-50 baseline: region-specific
descriptors help image-level recognition even though
classification does not require the pixel-level localiza-
tion of segmentation.
SPASE is the strongest variant
needing no pretrained teacher, reaching 77.87 top-1 and
92.77 top-5 for 86 added parameters (+0.000%), against
77.46 and 92.49 for the best prior module, CA, at
+16.0%. MAPSE (GradCAM) scores higher still (80.53
and 94.13), but with a caveat: its teacher is pretrained
on ImageNet, whose label space contains all 100 mini-
ImageNet classes, so here its regions carry evidence
about the very classes being predicted — an overlap
absent from the segmentation experiments.
PLEASE
stays competitive but is the most expensive variant
(+21.3%), since its 1×1 assignment network repeats at
every residual block.
6
Conclusion
We introduced region-aware SE modules that replace
SE’s single global channel descriptor with region-
specific ones, in four variants of increasing region flex-
ibility: grid blocks (BASE), superpixels (SPASE), frozen
semantic maps (MAPSE), and learned soft assignments
(PLEASE). Every variant improves over the U-Net base-
line on all binary benchmarks, and the benefit extends
to semantic segmentation and classification, at costs
that differ by variant rather than being uniformly neg-
ligible.
Regions inherited from a frozen general-purpose net-
work are strongest across segmentation — most bi-
nary entries and the best ADE20K mIoU — suggest-
ing that importing generic semantic structure into the
squeeze step beats learning the partition from the task
loss alone, while learned assignments pay off where the
model has capacity headroom (PLEASE gives the best
VOC2012 mIoU) and expose interpretable regions for
free. The clearest limitations are boundary quality on
hard multi-class data and, for MAPSE, a teacher whose
label space may overlap the target task.
Flexibility
alone therefore does not predict performance: the re-
gion source is this framework’s main design decision.

S2
Implementation Details
This section states the full experimental configuration.
It repeats the settings given in the Experiments sec-
tion of the main paper so that the supplement is self-
contained, and adds the details of region construction
that the main paper has no space for. Demo code re-
producing the DUTS U-Net experiments accompanies
this supplement.
Binary segmentation
Experiments use the U-Net
and FCN of Fig. S1.
For each of CUB, DUTS, and
ECSSD the image/mask pairs are pooled across the
dataset’s official splits and re-partitioned 80/10/10 into
train, validation, and test sets by a seeded shuffle,
so that the partition is identical across methods and
seeds. Models train for 50 epochs on 224 × 224 inputs
with AdamW (learning rate 10−3, weight decay 10−4,
batch size 16), using random crops and horizontal flips
(p = 0.5); evaluation uses center crops with ImageNet
normalization. The objective is pixelwise binary cross-
entropy on the logits, averaged over all non-ignored pix-
els; no auxiliary Dice or boundary term is used.
Semantic
segmentation
Experiments
use
an
ImageNet-pretrained ResNet-34 Semantic U-Net with
dataset-specific prediction heads. VOC models train on
the SBD-extended VOC trainaug split [4] and evaluate
on the VOC2012 validation split; ADE20K models
use the official train/validation splits.
Training uses
random scaling in [0.5, 2.0], padding, random 512×512
crops, horizontal flips, and ImageNet normalization;
validation uses full-resolution images.
Classification
Experiments use ResNet-50 on the
100-class mini-ImageNet dataset [28], with attention
modules inserted into every residual module before the
residual addition, trained for 100 epochs with SGD
(learning rate 0.1, momentum 0.9, weight decay 10−4,
batch size 128) and a multistep schedule decayed by
0.1 at epochs 30, 60, and 90.
Training uses random
resized 224 × 224 crops and horizontal flips; validation
and testing resize to 256 then center-crop to 224 × 224,
with ImageNet normalization throughout.
Module placement
Modules are inserted at the U-
Net encoder activations after convolution and before
spatial downsampling; at the FCN skip feature tensors
immediately before decoder fusion; at the feature maps
emitted by the pretrained ResNet-34 encoder of the Se-
mantic U-Net prior to decoding; and at the ResNet-50
residual branch output immediately before the identity
addition.
Region construction
SPASE uses fast-slic on the
raw RGB image at input resolution with K compo-
nents and compactness m = 10.0; the resulting label
map is resized to each stage’s resolution by nearest-
neighbour sampling, and empty regions are skipped.
MAPSE (GradCAM) uses a frozen torchvision ResNet-
50 with IMAGENET1K_V2 weights at 224 × 224 input.
Writing A for the layer4 output activations and wk
for the classifier row of the k-th highest logit, the k-th
map is ReLU(P
c wk,cAc), so the K maps of a top-K
prediction need no backward pass; the stack is then
passed through a softmax over K.
MAPSE (DINO)
uses a frozen native DINOv3 ViT-S/16 with the LVD-
1689M checkpoint at 224 × 224 input.
Its final nor-
malized patch tokens are mean-centred per image and
decomposed by SVD; the leading K components are
given a deterministic sign (chosen so that each com-
ponent’s largest-magnitude entry is positive) and the
resulting projections are min-max normalized per com-
ponent. Both external priors are bilinearly resized to
each stage’s resolution, clamped below at zero, and
renormalized to sum to one across the K maps, with
a uniform assignment substituted wherever the total
mass falls below ε = 10−6. PLEASE builds its assign-
ment map with Conv2d(c, max(1, c/4), 1) →ReLU →
Conv2d(c/4, K, 1) followed by a softmax over K.

ECA [32]: a single Conv1d(1, 1, k) without bias applied
across the channel axis of each region descriptor, with
k set adaptively from the channel count by truncating
(log2 c + 1)/2 to an integer and incrementing it when
even, followed by a sigmoid. The MLP variant follows
SE [8]: a bottleneck c →c/r →c with reduction ratio

Ablations
Several configurations appear in more than one table
below, because each ablation carries its own reference
setting. These repeated entries are independent sets of
three training runs rather than copies of a single run, so
they differ from one another by seed-to-seed variation,

Where a repeated entry differs from the corresponding

Attention Location and Granularity
To identify
the optimal location to insert our proposed attention
modules we ran experiments inserting the SPASE mod-
ule into U-Net for binary segmentation of the DUTS
dataset.
These experiments were run with K = 8
SLIC [1] superpixels, keeping regions few while giving
SLIC more flexibility than the binary label count. Ta-
ble S1 shows that using all four encoder stages gives the
highest mIoU and boundary F1 among the tested place-
ments. The gains are not strictly monotonic with each
additional shallow block, but the E1–E4 encoder con-
figuration is stronger than the single-stage and partial-
encoder variants and stronger than applying the mod-
ule to all skip connections. If not noted otherwise, the
U-Net models in the main paper apply the respective
attention modules at the E1–E4 locations.
Table S2 examines the effect of the K hyperparam-
eter on SPASE for the same task. The effect of K is
analogous to controlling the number of regions across all
methods within our framework, in this case the number
of SLIC superpixels. Results show K = 8 as the “sweet
spot” for this task. Although the task is binary seg-
mentation, it is intuitive that the model benefits from a
slightly finer-grained regional decomposition than just
two broad regions, while performance degrades when
the attention becomes overly localized.

Residual Connections
Finally, we analyzed the
choice to allow our modules to directly weight the in-
put tensor or to enforce a residual connection. This is
the difference between the learned channel and region-
aware weights directly rescaling the input to the module
or the output being the sum of this rescaled input and
the original input.
Table S4 identifies direct reweighting of the input
as the stronger default, leaving the underlying archi-
tectures to apply residual connections where appropri-
ate. This setting gives the best mIoU for every tested
module-backbone pair, with the only boundary-F1 ex-
ception being a negligible SPASE U-Net difference in
favor of the residual variant. This design choice mir-
rors existing channel-attention formulations: standard
SE [8], ECA [32], CA [6], EMA [15], and CBAM [33]
apply their learned attention weights directly through
elementwise multiplication without an additional resid-
ual connection inside the attention block itself.

import torch
import torch.nn as nn
import torch.nn.functional as F
class BASE(nn.Module):
def __init__(self, k, phi):
# k:
grid size for block average pooling
# phi: channel excitation operator
super().__init__()
self.k = k
self.phi = phi
self.avg_pool = nn.AdaptiveAvgPool2d(k)
def forward(self, x):
B, C, H, W = x.size()
z_block = self.avg_pool(x)
w_block = self.phi(z_block.view(B, C, self.k ** 2))
w_block = w_block.view(B, C, self.k, self.k)
w = F.interpolate(w_block, size=(H, W), mode=’nearest’)
return x * w
class SPASE(nn.Module):
def __init__(self, phi):
# phi: channel excitation operator
super().__init__()
self.phi = phi
def forward(self, x, S):
B, C, H, W = x.size()
K = S.max().item() + 1
S_onehot = F.one_hot(S, K).float()
S_onehot = S_onehot.permute(0, 3, 1, 2)
counts = S_onehot.sum(dim=(2, 3))
z_sp = torch.einsum(’bchw,bnhw->bcn’, x, S_onehot)
z_sp = z_sp / counts.unsqueeze(1)
w_sp = self.phi(z_sp)
w = torch.einsum(’bcn,bnhw->bchw’, w_sp, S_onehot)
return x * w
class MAPSE(nn.Module):
def __init__(self, phi, eps=1e-6):
# phi: channel excitation operator
super().__init__()
self.phi = phi
self.eps = eps
def forward(self, x, M):
B, C, H, W = x.size()
M = F.interpolate(M, size=(H, W), mode=’bilinear’, align_corners=False)
mass = M.sum(dim=(2, 3)).clamp_min(self.eps)
z_map = torch.einsum(’bchw,bkhw->bkc’, x, M) / mass.unsqueeze(-1)
w_map = self.phi(z_map)
w = torch.einsum(’bkc,bkhw->bchw’, w_map, M)
return x * w
class PLEASE(nn.Module):
def __init__(self, c, K, phi, eps=1e-6):
# c:
number of input channels
# K:
number of soft regions
# phi: channel excitation
super().__init__()
self.phi = phi
self.eps = eps
r = max(1, c // 4)
self.pi = nn.Sequential(
nn.Conv2d(c, r, 1), nn.ReLU(), nn.Conv2d(r, K, 1), nn.Softmax(dim=1)
)
def forward(self, x):
P = self.pi(x)
mass = P.sum(dim=(2, 3)).clamp_min(self.eps)
z_soft = torch.einsum(’bchw,bkhw->bkc’, x, P) / mass.unsqueeze(-1)
w_soft = self.phi(z_soft)
w = torch.einsum(’bkc,bkhw->bchw’, w_soft, P)
return x * w
