## 摘要
许多视觉-语言-动作策略依赖带有动作标签的机器人演示数据，且缺乏显式预测未来视觉状态的机制。这些局限阻碍了模型从无动作标注视频中学习，也可能导致其过拟合演示条件，从而削弱泛化能力与鲁棒性。我们提出 TS-WAM，这是一种轻量级的教师-学生世界-动作模型，通过自监督时序学习与显式未来预测应对上述挑战。其 vlm-jepa 框架可利用异构数据进行学习，包括机器人演示和无动作标注的人类视频；该框架采用 EMA 目标分支，无需单独训练外部教师模型。通过将 vlm-jepa 与 delta-lwm 相结合，TS-WAM 学习根据当前观测和指令预测潜在动作，并利用这些潜在动作预测未来视觉特征，在推理时为动作生成提供引导。统一的端到端训练架构联合优化时序表征学习、视觉动力学和机器人控制，无需单独进行潜在动作或世界模型预训练。推理时移除 EMA 目标分支，使部署的策略保持轻量。我们在 LIBERO、LIBERO-Plus 和 SimplerEnv 上开展实验，并在 Franka Research 3 和 RevoTron 上进行真实世界操作实验，结果表明 TS-WAM 具有出色的操作性能、泛化能力和鲁棒性。

## Abstract
Many vision-language-action policies rely on action-labeled robot demonstrations and lack an explicit mechanism for predicting future visual states. These limitations hinder learning from action-free videos and can encourage overfitting to demonstration conditions, weakening generalization and robustness. We present TS-WAM, a lightweight Teacher-Student World-Action Model that addresses these challenges through self-supervised temporal learning and explicit future prediction. Its vlm-jepa framework learns from heterogeneous data, including robot demonstrations and action-free human videos, using an EMA target branch without requiring a separately trained external teacher. By coupling vlm-jepa with delta-lwm, TS-WAM learns to predict latent actions from the current observation and instruction and uses them to predict future visual features that guide action generation at inference. A unified end-to-end training architecture jointly optimizes temporal representation learning, visual dynamics, and robot control without a separate latent-action or world-model pretraining stage. The EMA target branch is removed at inference, keeping the deployed policy lightweight. Experiments on LIBERO, LIBERO-Plus, and SimplerEnv, together with real-world manipulation experiments on Franka Research 3 and RevoTron, demonstrate that TS-WAM achieves strong manipulation performance, generalization, and robustness.

## 1. 核心问题与整体含义

- **研究背景：**视觉-语言-动作（VLA）策略通常依赖带动作标签的机器人示范，动作生成器直接从示范中学习控制，却未必形成对“动作将造成何种视觉变化”的显式表征。因此，这类策略难以充分利用没有机器人动作标签的人类视频，也可能过度适应训练示范中的物体、场景和视觉条件。
- **核心问题：**如何在不单独预训练潜在动作模型或世界模型的情况下，把无动作视频中的时间信息转化为对机器人控制有用的监督，并让策略在行动前预测可能出现的视觉变化？
- **论文整体思路：**提出 TS-WAM，将时序潜在动作学习、未来视觉特征预测和机器人动作生成纳入一个端到端训练框架。人类视频提供当前—未来帧的时序监督，机器人示范则额外提供动作监督；推理时只使用当前观测，不需要未来图像或教师分支。

## 2. 方法论

TS-WAM 由三个相互耦合的部分组成：**vlm-jepa、delta-lwm 和流匹配动作策略**。

### 2.1 vlm-jepa：从当前观测预测时序潜在动作

- **在线学生分支（X-VLM）**读取当前图像和语言指令，经 VLM 得到隐藏表征，再由可学习查询 token 和轻量 Transformer 预测潜在动作 \(\hat z_t\)。
- **EMA 教师分支（Y-VLM）**在训练时读取当前帧和未来帧，生成目标潜在动作 \(z_t^Y\)。教师参数通过学生参数的指数移动平均更新，且教师输出停止梯度。
- 学生通过预测目标潜在动作来训练，核心目标可概括为最小化学生预测 \(\hat z_t\) 与归一化教师目标之间的距离。训练时教师可利用未来视觉信息；部署时则移除教师，仅保留基于当前观测和指令的学生预测路径。
- 这使模型能够从人类视频中学习时间变化，而不需要视频提供机器人动作标签。

### 2.2 delta-lwm：让潜在动作对应可预测的视觉变化

- 使用冻结的 DINOv3 编码器提取当前帧和未来帧的空间视觉特征 \(F_t\) 与 \(F_{t+1}\)，以特征差分
  \[
  \Delta F_t=F_{t+1}-F_t
  \]
  表示一步视觉变化。
- 可训练的世界模型解码器根据当前特征和潜在动作预测 \(\widehat{\Delta F_t}=D_\psi(F_t,z_t)\)，再构造预测未来特征：
  \[
  \widehat F_{t+1}=F_t+\widehat{\Delta F_t}.
  \]
- 世界模型同时接受教师潜在动作和学生潜在动作的监督，以便训练中的教师路径提供稳定目标，而部署时可用的学生路径也能预测相应视觉变化。
- 此外，论文引入**潜在动作依赖性约束**：将样本的潜在动作与其他样本的潜在动作错配，要求正确匹配的潜在动作能比错配动作更好地解释观测到的特征变化。其目的在于检验预测是否确实依赖潜在动作，而不只是依赖当前图像。

### 2.3 流匹配动作策略：利用预测未来特征生成动作

- 动作头接收当前视觉特征、预测未来特征、VLM 上下文、机器人本体状态及 embodiment 标识，输出动作块。
- 对有机器人动作标签的样本，采用条件流匹配训练：从高斯噪声与示范动作构造连续插值，并训练模型预测对应向量场；推理时数值积分该向量场得到动作块。
- 训练时可在预测未来特征与真实未来特征之间混合条件，并逐步提高使用预测特征的概率；推理时只使用预测未来特征，避免训练和部署条件不一致。
- 人类视频样本不参与动作损失，但参与时序潜在动作和视觉动力学损失。整体上，机器人样本联合优化动作、时序和世界模型目标，人类视频样本则优化后两项；共享模块在统一训练过程中共同更新。

## 3. 实验设计

### 3.1 仿真基准与任务

- **LIBERO：**评估 Spatial、Object、Goal、Long 四个套件的操作成功率。

- **SimplerEnv：**在 WindowX Robot 和 Google Robot 上评估四类任务，覆盖 Visual Matching（Spoon、Carrot）与 Visual Aggregation（Pick、Move）。

### 3.2 真实机器人实验

- **Franka Research 3：**7 自由度单臂机器人，配有两个 RGB 观测相机；任务包括堆叠碗和长程抽屉任务（开抽屉、放入物体、关抽屉）。

### 3.3 对比方法

- **LIBERO：**包括 π0、π0-FAST、π0.5、WorldVLA、LAPA、Mantis、UniVLA 和 VLA-JEPA 等。

## 6. 主要结论与发现

- **仿真操作表现较强：**LIBERO 平均成功率为 **97.0%**，略高于表中 π0.5 的 96.9%；在 Object 套件达到 99.8%。SimplerEnv 总体平均为 63.83%，在所列任务上表现优于主要对比方法。
- **分布外泛化较好：**LIBERO-Plus 总体成功率为 **75.7%**，高于表中 VLA-JEPA 的 62.9% 和 π0 的 53.6%。
- **真实机器人表现更稳健：**IND 条件下，TS-WAM 总体成功率为 72.50%，π0.5 为 55.00%。OOD 平均成功率分别为 62.92% 和 35.00%；论文报告 TS-WAM 在各 OOD 条件下均优于对比方法。
- **消融结果支持各组件作用：**移除人类视频、vlm-jepa 或预测特征差分通路均导致性能下降；去除 vlm-jepa 的影响尤其明显，表明时序自监督接口可能是将无动作视频用于控制的关键环节。
- 总体结论是：将无动作视频的时间监督、潜在动作表征、未来视觉特征预测与动作生成联合训练，有助于提升操作能力和对视觉、空间扰动的适应性。

## 7. 优点

- **监督来源灵活：**能将没有机器人动作标签的人类视频用于时序表征和视觉动力学学习，同时利用机器人示范训练具体动作。
- **因果部署路径清晰：**教师利用未来帧只发生在训练阶段；实际策略根据当前观测推断潜在动作，不依赖未来图像。
- **显式连接动作意图与视觉后果：**预测的特征变化不仅是辅助训练目标，也进入动作生成模块，使模型形成“潜在意图—视觉后果—机器人动作”的控制链条。
- **端到端联合优化：**不需要单独训练潜在动作模型或世界模型再迁移到机器人策略，减少了分阶段优化带来的目标不一致问题。
- **评估维度较多：**既有多套仿真基准，也有跨平台真实机器人实验和分布外条件测试，并设置针对数据、JEPA 架构及未来特征通路的消融。

## 8. 不足与局限

- **训练成本仍有增加：**教师分支提升训练显存需求，未来特征条件也使动作头收敛变慢；“轻量”主要体现在推理时移除教师分支，并不意味着训练开销低。
