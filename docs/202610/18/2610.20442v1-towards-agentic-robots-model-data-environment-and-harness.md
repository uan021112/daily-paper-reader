## 摘要
基础模型正在推动机器人智能发生范式转变，使其超越低层级的动作预测，迈向对数据采集、模型训练、任务规划和现实世界执行的目标导向式统筹。我们将这一新兴范式称为智能体机器人：在该范式下，智能体能够根据人类指令进行推理，与机器人环境交互，自主纠正执行错误，并动态调整操作策略。尽管这一领域发展迅速，当前研究之间的联系仍不够紧密。研究人员尚未形成关于如何将不同的智能体功能整合为完整机器人系统的一致认识。本文对智能体机器人的现有研究进行统一综述。首先，我们梳理机器人策略向智能体系统的发展历程，涵盖视觉—语言—动作模型、世界模型和世界—动作模型。随后，我们明确智能体机器人的定义与范围，并将现有研究归纳为四个功能领域中的十七个类别：模型、数据、环境和支撑框架。围绕这些领域，我们考察智能体如何影响模型学习与机器人决策、采集和整理机器人数据、构建用于学习与评估的世界、任务和测试，以及组织供机器人使用的各项能力。最后，我们讨论尚待解决的挑战，并展望未来研究方向。展望未来，我们希望本文有助于加深对智能体机器人的认识，并推动探索新的方法，使其能力更强、更可靠、更具适应性。

## Abstract
Foundation models are driving a paradigm shift in robotic intelligence, moving beyond low-level action prediction to goal-directed orchestration of data collection, model training, task planning, and real-world execution. We characterize this emerging paradigm as an agentic robots, in which agents reason over human instructions, interact with robotic environments, rectify execution errors autonomously, and dynamically adjust operational strategies. Although this field develops fast, current studies are not well connected. Researchers have no consistent view of how to combine different agentic functions into a complete robot system. This paper provides a unified overview of existing research on agentic robots. We first trace the development from robot policies to agentic systems, covering vision-language-action models, world models, and world-action models. We then clarify the definition and scope of agentic robots and organize existing research into seventeen categories across four functional domains: Model, Data, Environment, and Harness. Across these domains, we examine how agents shape model learning and robot decisions, collect and curate robot data, construct worlds, tasks, and tests for learning and evaluation, and organize capabilities for robot use. Finally, we discuss open challenges and outline directions for future research. Looking forward, we hope this work contributes to a clearer understanding of agentic robots and supports new approaches to making them more capable, reliable, and adaptive.

## 2.2 核心思路与技术脉络

- **从策略到智能体系统的演进**：
  1. 传统机器人策略主要学习从观察到动作的映射。
  2. VLA 将视觉、语言知识与动作生成结合。
  3. 世界模型和世界—动作模型（WAM）进一步预测动作造成的未来状态或视觉变化。
  4. 智能体机器人则在这些可执行能力之上，增加目标导向的规划、工具选择、执行监控和反馈驱动的调整。
- **模型侧的关键区分**：
  - 训练智能体可修改奖励、训练代码或实验流程；感知侧重点是形成可供后续决策使用的状态信息；规划负责组织子目标和行动顺序；控制把计划转为动作、位姿、程序或运动约束；适应则可通过上下文、规划器参数或模型权重吸收经验。
  - 这些功能不应混为一谈：例如，失败可能来自感知错误、规划错误或控制器无法执行，所需修复方式并不相同。
- **数据与环境的闭环**：
  - 数据流程包括经验采集、文本/空间/交互/结果标注，以及轨迹筛选和标签修订。
  - 环境流程区分场景重建、任务定义和评测设计；场景稳定不代表动力学正确，任务可执行不代表评测有效。
- **Harness 的执行闭环**：
  - 典型流程是：目标与观察输入 → 选择执行器并调用 → 机器人执行 → 返回状态、进度或失败证据 → 决定继续、换工具、重新观察、重规划或重置。
  - 记忆记录历史并按需检索；技能把经验封装为可复用的文字指导或可调用程序；基础设施定义接口、服务和安全门控；分层系统则让慢速规划器、较快的学习策略和高速解析控制器各司其职。
- **论文强调的设计原则**：
  - 智能体输出必须与执行器能力相匹配；动作调用要有明确的前置条件、返回信息和成功判据。
  - 执行器之间交接时，需要确保下一个组件面对的状态符合其要求。
  - 监控与成功判断应尽量有独立证据，不能只依赖执行组件自身报告。
  - 更长的计划适用于结果可预测的任务；不确定性高时，宜缩短计划并根据新观察调整。

- **数据与环境构建场景**：包括真实机器人数据采集、仿真轨迹生成、生成式数据合成、场景重建、可执行任务代码生成及评测器自动构造。

## 3.3 对比方法与结果的性质

- 论文讨论了多种策略、VLA、世界模型/WAM、规划器、技能编排及代码生成方法，但**没有在统一实验协议下对这些方法重新测试或排名**。
- 文中提到的示例性结果包括：引言称 GPT-6 Astra 在 RoboDojo 的 42 项仿真任务上平均成功率为 **22.48%**，并列出与若干训练策略的对照成绩。这是被引用研究报告的结果，不是本文作者开展的受控实验。
- 论文的重点是解释不同系统的接口、反馈、执行器和评测条件如何影响结果，而非得出跨论文的统一性能结论。

# 4. 资源与算力

- **本文自身的计算资源未明确报告**：没有给出 GPU 型号、数量、训练时长、推理成本或综述筛选所用算力。
- 这是与论文性质相符的：本文主要进行文献综述和分类，而非训练一个新模型。
- 文中会引用个别系统的部署或推理配置，例如部分分层模型的运行频率、VLA 推理服务和边缘—云端部署案例；这些属于被综述工作的信息，不能汇总为本文使用的统一资源配置。
- 论文指出推理延迟、通信开销、工具调用与物理执行时间都可能影响机器人效率，但没有提供对所有方法统一测量的成本分析。

# 5. 实验数量与充分性

- **本文本身没有“多少组实验”可统计**，因为未执行统一实验或消融实验。
- 综述覆盖面较大，整理了四个领域、十七个类别，以及大量代表性工作，并通过多张表格比较其输入、输出、工具、执行器、反馈和评测设置。
- 这种覆盖有助于建立全景认识，但**文献数量和分类广度不能替代实验充分性**：
  - 不同工作使用的机器人、任务、基础模型、工具、观察权限和反馈条件各异，报告的成功率通常不可直接横比。
  - 综述没有对文献进行统一复现、统计显著性分析或系统性的效应量汇总。
  - 分类依赖作者对研究功能的判断；一些工作横跨多个类别，边界可能存在解释空间。
- 因此，论文在**领域梳理和问题归纳方面较充分**，但在**验证分类有效性、量化比较方法优劣方面并不充分**。作者也明确将公平评测列为未来挑战。

# 6. 主要结论与发现

- **智能体能力不等于动作预测能力**：长时程、开放环境任务需要任务进度跟踪、主动获取信息、执行校验和失败恢复。
- **性能由系统整体决定**：模型能力必须与可用观察、执行器、工具接口、反馈质量和机器人本体约束相匹配。仅提升模型参数，不一定能带来可靠的物理执行。
- **反馈闭环是关键**：执行结果既可以用于当前任务内的恢复，也可以通过数据筛选、模型训练和技能演化改进后续任务。
- **评测必须报告系统条件**：成功率受执行器、可见信息、调用次数、重试权限和人工帮助影响；单独报告任务成功率，难以识别智能体本身的贡献。
- **可靠性与效率需共同考量**：频繁调用高层模型可增加适应性，但也会增加延迟和计算成本；何时重新规划、何时由低层控制继续执行，是重要的系统设计问题。
- **未来重点**：公平基准、真实机器人闭环验证、计算与执行效率，以及跨机器人形态泛化。

# 7. 优点

- **提供系统级视角**：将模型、数据、环境和运行时支撑框架放入同一讨论框架，避免只从单一模型或单一任务看机器人智能。
- **分类较细且可操作**：十七个类别对应机器人系统中相对明确的功能，有助于研究者定位问题和设计模块接口。
- **重视执行闭环而不止规划**：深入讨论调用协议、状态交接、成功判据、监控、恢复和记忆更新，贴近真实部署的工程需求。
- **能揭示系统性风险**：例如旧记忆可能失效、执行器报告的成功可能不可靠、仿真中的特权状态可能掩盖感知问题、自动技能更新也可能导致性能退化。
- **对评测公平性的讨论有价值**：指出相同基准名称并不代表相同评测条件，并倡导固定执行器、观察权限和交互预算进行对照，同时报告资源成本。
- **兼顾能力构建与任务执行**：不只讨论机器人如何完成当前任务，也讨论如何采集数据、改进模型、生成环境和演化技能。

# 8. 不足与局限

- **没有统一实证验证**：本文提出的分类框架尚未通过统一实验检验，也没有量化比较不同架构在相同任务下的效果。
- **文献异质性较强**：不同工作在硬件、任务、模型、指标和信息访问方面差异明显，导致结果难以直接比较；论文的示例性数字不应被理解为严格的排行榜。
- **综述范围和分类可能带有主观性**：系统往往跨越多个领域，类别边界并非天然唯一；论文也未在所给内容中展示可复核的系统性检索与筛选统计。
- **真实机器人证据仍不均衡**：不少方法主要在仿真或特定受控环境中验证。感知噪声、执行延迟、标定误差、接触不确定性和安全风险会使仿真结果难以直接迁移。
- **安全与责任边界尚未解决**：安全门控、失败验证和人工介入虽被讨论，但智能体自主修改奖励、代码、技能或评测器时，如何保证修改可靠、可审计且不损害既有能力，仍缺少统一机制。
- **资源成本讨论缺乏统一量化**：文中强调延迟和算力的重要性，但未对不同系统进行一致的成本—成功率比较。
- **跨本体泛化仍是开放问题**：高层任务策略可能复用，但具体动作、传感器、技能接口和物理限制依赖机器人形态；怎样迁移经验而不错误迁移控制细节，尚未解决。
- **对综述结论的使用需谨慎**：论文提供的是研究版图与概念组织，不是对所有方法优劣的定论，也不能据此认定某一范式已经在现实复杂环境中普遍可靠。
