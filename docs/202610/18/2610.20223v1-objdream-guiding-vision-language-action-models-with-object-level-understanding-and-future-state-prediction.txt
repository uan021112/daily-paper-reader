Abstract: Vision-language-action (VLA) models have emerged as a powerful paradigm for robotic manipulation, enabling robots to generate actions from vi-sual observations and language instructions. However, most existing VLA mod-els still operate on image-level visual representations inherited from pretrained vision-language backbones, while lacking fine-grained object understanding for manipulation. As a result, their robustness can degrade under out-of-distribution object layouts, clutter, and background variations. To address these limitations, we introduce ObjDream, an object-centric VLA framework centered on object-level understanding and future object state prediction. ObjDream uses a spatio-temporal object encoder to organize visual observations into temporal object slots, where persistent object identity and dynamic object state are represented through sepa-rate channels. These structured object representations are inserted into the token sequence of the vision-language model (VLM), where identity-guided routing mod-ulates VLM attention to the corresponding object tokens. In addition, an action-conditioned object dynamics module predicts compact future object states relevant to manipulation during training, explicitly supervising object state evolution under robot actions without requiring future prediction at inference. Experiments on LIBERO, LIBERO-Plus, and RoboTwin 2.0 show that ObjDream improves gener-alization under diverse distribution shifts and scene perturbations. Real-world robot experiments further demonstrate that ObjDream transfers to physical manipulation settings with novel object arrangements and background changes. Project page.

Robust robot policies must reliably manipulate objects in out-of-distribution environments, where their appearance, position, and surrounding context may differ from those in the training data. VLA models have made rapid progress in generalist robot control by scaling pretrained vision-language backbones, robot data, and action decoders (Brohan et al., 2023; Kim et al., 2024; Black et al., 2024; NVIDIA et al., 2025; Wang et al., 2026b). To improve generalization, recent work has sought to preserve knowledge acquired during pretraining (Guo et al., 2026; Hancock et al., 2026), use high-level plans to guide low-level control (Li et al., 2025c), or anticipate scene changes through future visual or latent-state prediction (Zhang et al., 2025; Sun et al., 2026). Although these approaches improve generalization to some extent, most VLA models still lack fine-grained object-level understanding. Their visual representations, inherited from VLMs, remain largely image-level, leaving the identity and spatial state of task-relevant objects entangled with appearance and surrounding context. This entanglement can weaken out-of-distribution robustness under shifts in object appearance, spatial layout, and background context. Object-centric approaches offer a natural way to strengthen object-level understanding by explicitly representing individual objects and their properties. Prior work incorporates object-aware visual representations to help policies focus on task-relevant regions (Zhu et al., 2023; Li et al., 2025a; Liang et al., 2026). Other methods extend object representations to relational reasoning (Hanyu et al., 2025), object-level memory (Chung et al., 2026), and long-horizon manipulation (Yang et al., 2026). Although these approaches demonstrate the value of object-level representations, they often encode persistent object identity and time-varying object state in the same slot or token. As appearance and geometry change, this coupling can obscure persistent identity cues by mixing them with dynamic object state. Recent dual-state slot models show that separating identity from dynamic appearance can improve temporal consistency in video perception by keeping identity information distinct from time-varying visual content (Tran et al., 2026). Building on this insight, we investigate whether persistent identity references can be represented alongside dynamic object states and further used to guide VLM attention for language-conditioned manipulation. Beyond modeling the current visual observation, predictive models support manipulation by anticipat-ing future observations or object states (Ferraro et al., 2025; Chen et al., 2025a; Villar-Corrales and Behnke, 2025). The choice of prediction target is important: reconstructing complete images requires modeling texture and background details that may be irrelevant to control (Zhang et al., 2025), while goal-image methods such as Goal-VLA introduce an additional synthesis stage before estimating the target object pose (Chen et al., 2025a). In contrast, object-centric world models show that scene evolution can be modeled using compact object representations (Jeong et al., 2025). Motivated by this trade-off, we use action-conditioned prediction of compact future object states, including geometry and visibility, as auxiliary supervision for VLA training without requiring future object state prediction at inference. To this end, as illustrated in Fig. 1, we introduce ObjDream, an object-centric vision-language-action framework for improving manipulation generalization. The architecture of ObjDream builds on a pretrained VLM backbone and integrates a spatio-temporal object encoder, an object-level forward dynamics module, and a flow-matching action expert. Specifically, the spatio-temporal object encoder transforms visual observations into structured object slots, where persistent object identity and dynamic object state are represented through separate channels. These factorized object representations are mapped into the VLM hidden space and inserted into the token sequence, where identity-guided routing modulates attention to the corresponding object tokens. The forward dynamics module predicts future object states during training, providing auxiliary supervision for future object state evolution under robot actions without requiring future prediction at inference. The object encoder is pretrained with automatically generated offline object supervision and frozen during VLA training. We optimize ObjDream with a joint objective combining action imitation with current and future object state supervision. Extensive evaluations on LIBERO, LIBERO-Plus, RoboTwin 2.0, and real-world robot experiments demonstrate competitive manipulation performance across diverse scene perturbations. The main contributions of this paper are listed below: • We present ObjDream, an object-centric VLA framework centered on object-level understanding and future object state prediction to improve generalization under perturbations. ObjDream 2introduces a spatio-temporal object encoder that explicitly represents persistent object identity and dynamic object state through separate channels. The resulting representations are integrated into the VLM hidden space with a novel identity-guided routing mechanism for robust language-conditioned manipulation. • We introduce an action-conditioned object-level forward dynamics module for modeling object evolution during manipulation. It predicts compact future object states during training to provide direct auxiliary object-level supervision without requiring future object state prediction at inference. We further model inter-object relations from object features and pairwise geometry to provide structured context for action generation. • Extensive evaluations on LIBERO, LIBERO-Plus, RoboTwin 2.0, and real-world robot experi-ments demonstrate competitive manipulation performance across diverse scene and environmen-tal perturbations. Ablations further assess the effects of the key architectural components. 

# 2 Related Work 

Vision-language-action models. VLA models combine pretrained language or vision-language backbones with action decoders to learn general-purpose manipulation from large-scale robot demon-strations (Brohan et al., 2022, 2023; O’Neill et al., 2024; Team et al., 2024; Kim et al., 2024; Black et al., 2024; Physical Intelligence et al., 2025). Recent work improves VLA performance through stronger action decoders and fine-tuning strategies (Chi et al., 2025; Zhao et al., 2023; Kim et al., 2025; Hou et al., 2025; NVIDIA et al., 2025; Qu et al., 2025), larger-scale cross-embodiment train-ing (Cai et al., 2026; Team et al., 2026; Wu et al., 2026a,b; Wang et al., 2026b), and better preservation or exploitation of pretrained visual-semantic and spatial priors (Guo et al., 2026; Li et al., 2026a; Wang et al., 2026c). Predictive objectives further use future images, video tokens, subgoal images, or latent states to provide temporal supervision for manipulation (Zhao et al., 2025; Zhang et al., 2025; Cen et al., 2025b,a; Li et al., 2026b). Despite these advances, existing VLA models still largely operate on dense image-level visual representations, where object-level structure is not explicitly organized for manipulation generalization. ObjDream addresses this limitation by enhancing VLA policies with object-level understanding and future object state supervision. 

World models for robot control. World models learn action-conditioned environment dynamics and support robot control by planning or learning policies from predicted futures in observation or latent spaces (Hafner et al., 2019; Wu et al., 2023). Recent work extends this paradigm through language-conditioned video generation (Du et al., 2023; Zhou et al., 2024b), pretrained visual latent dynamics (Zhou et al., 2024a; Assran et al., 2025), and world-action or unified video-action models that couple future prediction with executable actions (Ye et al., 2026; Li et al., 2026c). These approaches provide dynamics supervision by modeling anticipated scene evolution. However, prediction in pixel or video space requires modeling high-dimensional visual details and can introduce training or inference overhead. Recent approaches therefore explore more efficient formulations, including avoiding explicit future imagination at inference or exposing compact representations of scene changes (Yuan et al., 2026; Bai et al., 2026). ObjDream follows this direction by using compact future object state prediction as supervision during training, while directly generating actions at inference without explicit future object state decoding. 

Object-centric representations for manipulation. Object-centric representation learning decom-poses visual scenes into entity-level latent variables and has been widely studied in scene decom-position, temporal tracking, and structured dynamics (Locatello et al., 2020; Kipf et al., 2021; Wu et al., 2022). In robotic manipulation, object-level representations have been used to improve sample efficiency and enhance visuomotor attention and robust policy conditioning through object proposals, grounded geometry, object-centric prompting, and physically grounded object concepts (Zhu et al., 2023; Vo et al., 2025; Li et al., 2025b; Wei et al., 2026), enable efficient VLA learning through compact object-centric tokenization (Bendikas et al., 2025), and support structured control through object-centric dynamics and relational representations (Ferraro et al., 2025; Mosbach et al., 2024; Hanyu et al., 2025; Yang et al., 2026). Complementary approaches use structured affordance represen-tations to provide action-relevant object grounding, interaction localization, and geometric guidance for VLA policies (Yu et al., 2026b). Recent predictive approaches further incorporate object-aware future representations, masks, or addressable slot states into world-action learning (Wang et al., 2026a; Yu et al., 2026a; Liu et al., 2026). # 3 Method 

Following the VLA policy formulation in Sec. 3.1, Fig. 2 illustrates the architecture of ObjDream. ObjDream combines a spatio-temporal object encoder, an object dynamics module, and a flow-matching action expert. The encoder produces structured object slots that are mapped to VLM object tokens, while identity-guided routing uses cached identity references to modulate attention to these tokens (Sec. 3.2). The object dynamics module provides future object state supervision during training (Sec. 3.3), and the action expert generates action chunks.

3.4 Training Objectives Object encoder pretraining. We pretrain Eω using structured object-level supervision: 

Lenc = λmask Lmask + λgeo Lgeo + λvis Lvis + λrt Lrt . (12) Here, Lmask combines binary cross-entropy and Dice losses for object segmentation. Lgeo supervises object geometry, including boxes, centers, areas, mask–geometry consistency, and auxiliary slot attributes. Lvis supervises visibility labels derived from offline annotations; visibility is distinct from slot validity. Lrt is a bidirectional, multi-positive region–text contrastive loss between projected regional visual features and frozen CLIP text features. 

VLA training. During VLA training, we keep the pretrained object encoder Eω frozen and optimize the remaining trainable components with action imitation and auxiliary losses: 

L = wact Lact + Laux , Laux = Lcur + Lfut + Lprop + Lgate . (13) Here, Lact is the flow-matching action loss, which also optimizes the prospective object tokens through the action objective. Lcur supervises current object geometry, visibility, and mask logits, while Lfut supervises future object states predicted by the forward dynamics module. Lprop trains the auxiliary coarse action proposal against the demonstrated action chunk, while Lgate regularizes the learned slot-importance gates used for object-slot prioritization. The routing projections and gates are optimized through the existing objectives without an additional routing loss. # 4 Experiments 

Benchmarks. We evaluate ObjDream on LIBERO, LIBERO-Plus, and RoboTwin 2.0, covering both single-arm and bimanual manipulation under diverse distribution shifts. For LIBERO, we follow the standard protocol over the Spatial, Object, Goal, and Long suites (Liu et al., 2023). We further evaluate zero-shot robustness on LIBERO-Plus under seven controlled shifts in camera viewpoint, robot initialization, object layout, language, lighting, background, and sensor noise (Fei et al., 2026). For RoboTwin 2.0, we evaluate on a fixed 8-task subset: adjust bottle , click bell , grab roller , move can pot , open microwave , place can basket , scan object , and turn switch . These tasks cover diverse manipulation behaviors and object-state transitions. We report results under both Easy and Hard settings (Chen et al., 2025b). 

Implementation, training, and evaluation protocol. We use a Qwen3-VL-4B (Bai et al., 2025) backbone and a layerwise flow-matching action expert, following the StarVLA training recipe (Com-munity, 2026). Training proceeds in three stages: (1) we pretrain the spatio-temporal object encoder using offline object-level supervision; (2) with the encoder frozen, we jointly optimize the VLM, action expert, and policy-side object modules using Eq. 13; and (3) we freeze the VLM and object-related modules and refine only the action expert with Lact . Training is conducted on 8 NVIDIA H100 GPUs, while policy inference during evaluation is performed on NVIDIA RTX 4090 GPUs. Each LIBERO task is evaluated over 50 episodes, with the same checkpoint evaluated on LIBERO-Plus without additional fine-tuning. For RoboTwin 2.0, the policy is trained on 50 clean demonstrations per task and evaluated over 100 rollouts per task under both Easy and Hard settings.

4.2 Ablation and Analysis 

We conduct ablations on LIBERO-Long and LIBERO-Plus to assess the object interface, object relation modeling (ObjRel), object dynamics (ObjDyn), factorized object injection (Fact. Injection), and identity-guided routing (Id. Routing). Table 2 includes a backbone baseline without the object interface, while “w/o ObjRel & ObjDyn” retains the object tokens, factorized injection, identity-guided routing, and current state supervision. The full model outperforms the backbone baseline by 2.0 and 3.2 percentage points on LIBERO-Long and LIBERO-Plus, respectively. The object interface without ObjRel or ObjDyn provides a modest improvement over the backbone on LIBERO-Plus and comparable performance on LIBERO-Long. Among single-component removals, disabling factorized injection or identity-guided routing produces the largest decreases in LIBERO-Plus performance, from 84.4% to 82.5% and 82.6%, respectively. Removing ObjDyn reduces the overall success rate to 83.2%, while removing ObjRel results in a smaller decrease to 84.1%. Overall, factorized injection, identity-guided routing, and future object state supervision provide complementary gains.

We present ObjDream, an object-centric VLA framework combining structured object representations with action-conditioned future object state supervision. ObjDream represents objects with persistent identity cues and time-varying state features, and leverages identity-guided routing to direct VLM attention toward task-relevant object tokens. It further supervises object state evolution during training without requiring the decoding of future object states at inference. Figure 5: Automatic offline annotation pipeline for object encoder pretraining. Qwen3-VL-8B extracts task-relevant object phrases from demonstration instructions and initial observations, while a separate robot gripper label is used for robot annotation. Grounding DINO initializes the corresponding object regions, SAM2 propagates segmentation masks across frames, and DINOv2 extracts object-specific features from the initial grounded regions. Importantly, the object-level supervision is automatically generated from the demonstration trajec-tories and does not require manual frame-wise annotation of masks, boxes, geometry, or visibility. For each trajectory with instruction x and visual observations, we construct object-level supervision through phrase extraction, grounded localization, mask propagation, and automatic object-state anno-tation, yielding temporally aligned masks, geometry, visibility, and phrase–region correspondences. The offline annotation pipeline is illustrated in Fig. 5. 

Instruction-conditioned object phrases. During automatic offline annotation, Qwen3-VL-8B (Bai et al., 2025) takes the language instruction x together with the initial visual observation I0 and extracts the task-relevant phrase set P0. The extracted phrases are fixed for the entire trajectory and used as consistent semantic references across frames. When multiple instances share the same category, coarse spatial cues, such as relative left/right positions, are included when needed to distinguish them. During offline annotation, the label robot gripper is used to localize robot regions and assign their robot role. 

Phrase-grounded localization and temporal segmentation. Given P0, Grounding DINO (Liu et al., 2024) provides initial phrase-conditioned localization, and SAM2 (Ravi et al., 2025) propagates the corresponding masks across the demonstration trajectory. The phrase associated with each object remains fixed while its spatial support changes with motion, occlusion, or visibility. Boxes, centers, areas, and visibility labels are automatically derived from the propagated masks and normalized with respect to the image dimensions where applicable. DINOv2 (Oquab et al., 2023) features are pooled over the initial grounded object region to construct the visual identity reference during encoder pretraining. Thus, the masks, geometry, and visibility labels serve as automatically generated offline supervision and are not provided as policy inputs during rollout.
