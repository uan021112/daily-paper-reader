## 摘要
视觉-语言-动作（VLA）模型已成为一种强大的机器人操作范式，使机器人能够根据视觉观测和语言指令生成动作。然而，现有大多数 VLA 模型仍基于从预训练视觉-语言骨干网络继承而来的图像级视觉表征运行，缺乏面向操作的细粒度物体理解。因此，当物体布局、场景杂乱程度和背景出现分布外变化时，其鲁棒性可能下降。为解决这些局限，我们提出 ObjDream，这是一种以物体级理解和未来物体状态预测为核心的以物体为中心的 VLA 框架。ObjDream 使用时空物体编码器，将视觉观测组织为时序物体槽位，并通过独立通道分别表示持久的物体身份和动态物体状态。这些结构化物体表征被插入视觉-语言模型（VLM）的词元序列中，并通过身份引导的路由机制调节 VLM 对相应物体词元的注意力。此外，ObjDream 还包含一个动作条件化的物体动力学模块，在训练期间预测与操作相关的紧凑未来物体状态，从而在无需推理时进行未来预测的情况下，对机器人动作下的物体状态演变进行显式监督。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上的实验表明，ObjDream 在多种分布偏移和场景扰动下提升了泛化能力。真实世界机器人实验进一步证明，ObjDream 能够迁移至具有新颖物体布局和背景变化的实体操作场景。

## Abstract
Vision-language-action (VLA) models have emerged as a powerful paradigm for robotic manipulation, enabling robots to generate actions from visual observations and language instructions. However, most existing VLA models still operate on image-level visual representations inherited from pretrained vision-language backbones, while lacking fine-grained object understanding for manipulation. As a result, their robustness can degrade under out-of-distribution object layouts, clutter, and background variations. To address these limitations, we introduce ObjDream, an object-centric VLA framework centered on object-level understanding and future object state prediction. ObjDream uses a spatio-temporal object encoder to organize visual observations into temporal object slots, where persistent object identity and dynamic object state are represented through separate channels. These structured object representations are inserted into the token sequence of the vision-language model (VLM), where identity-guided routing modulates VLM attention to the corresponding object tokens. In addition, an action-conditioned object dynamics module predicts compact future object states relevant to manipulation during training, explicitly supervising object state evolution under robot actions without requiring future prediction at inference. Experiments on LIBERO, LIBERO-Plus, and RoboTwin 2.0 show that ObjDream improves generalization under diverse distribution shifts and scene perturbations. Real-world robot experiments further demonstrate that ObjDream transfers to physical manipulation settings with novel object arrangements and background changes.

- **研究动机：**视觉-语言-动作（VLA）模型通常依赖预训练视觉-语言模型提供的图像级表征，未必能稳定地区分场景中的具体物体、物体身份及其动态状态。因此，当物体位置、场景背景、光照或环境布局变化时，模型可能难以把语言指令准确关联到需要操作的物体。
- **核心问题：**如何让 VLA 模型在保留语言和视觉语义能力的同时，获得更细粒度的物体级理解，并学会动作如何引起物体状态变化，从而提升分布偏移下的操作泛化能力。
- **整体思路：**论文提出 ObjDream，将时序物体表示接入 VLM，并在训练时增加动作条件的未来物体状态预测监督。其重点不是在推理时生成未来场景，而是利用未来状态预测辅助训练，让模型学到更有利于控制的物体表征。

## 2. 方法论

### 2.1 整体架构

ObjDream 由三部分组成：

1. **时空物体编码器：**将视觉观测转化为多个物体槽位，显式表示物体及其时序变化。
2. **物体级动力学模块：**根据当前物体表征和动作信息，预测当前及未来物体状态，作为训练辅助目标。
3. **流匹配动作专家：**根据语言、图像、机器人本体状态和物体级表征，生成连续动作片段。

策略在时刻 \(t\) 接收指令 \(x\)、视觉观测 \(I_t\)、本体状态 \(s_t\) 和物体槽 \(O_t\)，经 VLM 得到上下文 \(C_t\)，再由动作专家生成动作片段 \(A_t\)。动作专家采用流匹配目标训练，推理时通过积分学习到的速度场生成动作，并以滚动时域方式执行。

### 2.2 物体槽：分离身份与动态状态

- 每个槽位由固定的任务相关短语初始化。论文使用 Qwen3-VL-8B 在回合开始时提取相关物体短语，并在后续控制过程中缓存这些短语。
- 物体身份表征结合语义信息、初始视觉特征和角色信息；动态状态表征则包括外观、几何信息和时间信息。
- 编码器使用冻结的 CLIP、DINOv2 和 SAM2 等视觉或文本模型构造特征，并通过空间查询和因果时序编码得到物体槽。
- 编码器先利用离线物体监督进行预训练，之后在 VLA 训练阶段冻结。

关键设计在于**身份与动态状态分开表示**：物体移动或外观发生变化时，身份线索不必与变化中的状态表征混为一体。

### 2.3 物体词元注入与身份引导路由

- 身份和状态分别映射到 VLM 隐空间，作为物体词元插入模型输入序列；模型还加入一个关系词元和两个前瞻物体词元。
- 关系词元汇总物体特征及物体间相对几何信息；前瞻物体词元则针对重要物体提供补充上下文。
- 身份引导路由使用缓存的物体身份参考，计算当前查询与各身份的匹配分数，并将匹配分数作为对应物体词元注意力 logit 的附加偏置。由此调节 VLM 对相关物体词元的注意力，而不替换标准的键值表征。

### 2.4 动作条件的未来物体状态预测

- 训练时，动力学模块预测非机器人物体未来若干步的几何、可见性和掩码状态；机器人槽不参与未来物体状态预测，因为机器人运动由动作片段表示。
- 动力学预测以物体词元为基础，并通过动作提议及其位置相关的时间嵌入进行条件化；训练预热阶段可用示范动作作为条件。
- 总体训练目标包含动作模仿损失，以及当前状态、未来状态、动作提议和槽重要性门控等辅助损失。
- **推理时跳过动力学辅助分支**，直接预测并执行动作，因此未来状态预测主要承担训练监督作用，而不增加推理时的未来解码流程。

### 2.5 离线监督构造

论文通过自动化流程构建物体编码器预训练数据：先由语言模型提取物体短语，再由 Grounding DINO 定位初始物体区域，使用 SAM2 跨帧传播分割结果，并由掩码得到几何、可见性等标签。文中称该流程不需要人工逐帧标注；Grounding DINO 和 SAM2 的标注流程不在策略部署时运行。

## 6. 主要结论与发现

- ObjDream 在 VLA 中引入显式物体级表征，并通过身份引导路由增强语言指令与具体物体之间的关联。
- 在报告的消融结果中，去除分解式注入或身份路由均会降低 LIBERO-Plus 表现；移除未来状态监督也会带来下降，说明这些组件可能提供互补收益。
- 学到的未来状态解码器优于重复当前状态的基线，尤其在物体发生位移时；使用原始动作条件也优于移除动作条件或使用不匹配动作条件。
- 结果整体支持这样一种设计取向：把物体身份、当前状态及其动作相关的变化纳入训练，有助于提升操作策略面对场景变化时的鲁棒性。不过，实验结果并不意味着其在所有扰动和任务上均领先。

## 7. 优点

- **问题定位明确：**针对图像级表征难以稳定支持物体操作这一局限，方法设计与泛化目标关联紧密。
- **表征结构清楚：**将持久身份与动态状态分开编码，并利用身份信息调节注意力，针对性地处理物体变化中的身份保持问题。
- **未来预测目标较紧凑：**预测与操作相关的物体状态，而非重建完整未来图像；且推理时不需要运行未来预测分支。
- **监督来源自动化：**借助检测、分割和预训练视觉特征构造离线监督，减少人工逐帧标注需求。
