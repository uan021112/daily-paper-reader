## 摘要
从少量未标定视图中恢复物体的三维结构和相机运动，是计算机视觉中的一项基础问题。经典的运动恢复结构（SfM）方法能够恢复与输入图像一致的三维几何，但无法恢复不可见区域；原生生成方法则能生成合理的三维物体，但生成结果虽与输入相关，却未必忠实于输入图像。简单串联重建与生成的方法会使误差在两个阶段间逐步累积，而无法生成同时符合数据分布和输入图像的三维物体。我们提出 GenSfM，将基于图像的三维重建与原生三维扩散模型相结合。具体而言，我们使用多模态扩散 Transformer，在共享自注意力机制下联合去噪形状潜变量和各视图的位姿潜变量，使生成的几何结构以观测视图为依据，同时利用物体级先验推断不可见区域。紧凑的原生三维 UV 体积标记化表示使视图数量增加时联合序列仍保持较小；此外，位姿感知阶段通过在恢复出的相机位姿下采样逐体素图像特征，进一步细化几何结构和纹理。在 Toys4k 和 GSO 数据集上，对于 4 个未标定视图，与强大的原生三维生成基线相比，GenSfM 将新视角 PSNR 提高了 3.2–4.5 dB，并将中位 Chamfer 距离降低了 2.8–3.8 倍；同时，无需任何外部位姿估计骨干网络、后处理优化或已知内参，即可恢复输入视图位姿，Acc@5° 超过 96%。项目页面：https://dotb1ue.github.io/GenSfm/。

## Abstract
Recovering an object's 3D structure and camera motion from a few uncalibrated views is a fundamental problem in computer vision. Classical structure from motion methods recover 3D geometry consistent with the input images but cannot recover unseen regions; native generation methods produce plausible 3D objects which are related but not necessarily faithful to the input images. Methods simply concatenating reconstruction and generation allow error to cascade across the two stages, instead of producing a 3D object consistent with both the distribution and the input. We propose GenSfM, which integrates image-based 3D reconstruction with a native 3D diffusion model. In particular, we use a multi-modal diffusion transformer to jointly denoise the shape latent and per-view pose latents under shared self-attention, grounding generated geometry in the observed views while using object-level priors to infer unobserved regions. A compact 3D-native UV-volume tokenization keeps the joint sequence small as views are added, and a pose-aware stage refines geometry and texture by sampling per-voxel image features at the recovered camera poses. On Toys4k and GSO, for $4$ uncalibrated views, GenSfM improves novel-view PSNR by $3.2$-$4.5$ dB and reduces median Chamfer distance by $2.8$-$3.8\times$ over a strong native-3D generation baseline, while recovering input-view poses over $96\%$ Acc@$5^\circ$ without any external pose-estimation backbone, post-hoc optimization, or known intrinsics. ## 1. 核心问题与整体含义

- **研究问题**：给定少量未经标定的物体图像，同时恢复物体的完整三维结构以及每张图像对应的相机位姿（外参和内参）。
- **研究动机**：
  - 经典 SfM/MVS 依靠图像间的纹理、重叠和几何一致性，通常只能可靠恢复可见区域；视角稀疏时，遮挡或未观测部分难以补全。
  - 原生三维生成模型能依靠物体先验生成完整形状，但直接根据少量图像生成时，结果可能合理却不够忠实于输入。
  - 将重建与生成简单串联，会使前一阶段的几何或位姿误差传递到后一阶段，难以保证同一个三维假设同时解释所有输入视图。
- **整体思路**：论文提出 GENSFM（文中也写作 GenSfM），将三维形状生成与多视图相机位姿恢复纳入原生三维扩散模型，在同一推理过程中联合处理：由图像证据约束已观测区域，并由三维生成先验补全未观测区域。

## 2. 方法论

### 2.1 总体流程

- 方法采用**由粗到细的两阶段生成流程**，以 TRELLIS 的原生三维生成框架为基础，并借鉴 CUPID 的三维原生位姿表示。
- 输入为 \(N\) 张未标定物体图像，主要实验取 \(N=4\)。粗阶段联合生成稀疏形状和各视角相机位姿；细阶段再依据恢复的位姿，对几何和外观进行局部细化。

### 2.2 粗阶段：联合去噪三维形状与相机位姿

- **形状表示**：粗阶段先生成 \(16^3\) 网格上的稀疏结构潜变量，解码为 \(64^3\) 占据网格，并据此确定活跃体素。
- **位姿表示**：
  - 对每个输入视角，将三维体素投影到图像平面，形成对应的 UV 体积。
  - 使用共享的位姿 VAE 将每个视角的 UV 体积压缩为 \(4^3\)、每 token 8 通道的潜变量。
  - 每个视角只需 64 个位姿 token。论文指出，这比采用 \(16^3\) 网格的表示少 64 倍 token，且对位姿恢复精度影响很小。
- **统一多模态扩散 Transformer**：
  - 将形状 token、每个视角的位姿 token，以及一组共享 register token 放入同一序列。
  - 形状与位姿通过联合自注意力交换信息；图像特征则通过交叉注意力作为条件输入。
  - 使用视角 ID embedding 将某一视角的位姿 token 与对应图像条件绑定；register token 为不同视角提供共享的信息通道。
  - 训练时使用条件流匹配（CFM）目标，预测从干净潜变量到噪声的速度场。形状和各视角位姿可采用共享或独立的噪声时间步。
- **图像条件**：每个视角结合冻结的 DINOv2 特征和多尺度 CNN 局部特征；前者提供较强语义信息，后者补充纹理和局部细节线索。
- **从潜变量恢复相机**：位姿 VAE 解码出 UV 体积后，利用活跃体素的三维坐标与对应二维 UV 坐标，通过 DLT 最小二乘求出投影矩阵，再经 RQ 分解恢复相机内外参。

### 2.3 细阶段：位姿感知的逐体素细化

- 使用粗阶段得到的相机位姿，将每个活跃体素投影到各输入图像。
- 在投影位置双线性采样图像特征：
  - DINOv2 特征经编码后作为语义条件；
  - 多尺度 CNN 特征作为纹理条件。
- 同一体素从多个视角采样到的特征取平均，再与带噪的体素结构特征拼接，输入细阶段的结构潜变量 Transformer，生成更精细的几何与外观。
- 这种设计使细阶段的图像条件与具体三维位置、相机位姿对应，而非仅依赖全局图像条件。

## 3. 实验设计

### 3.1 数据集与评测场景

- **训练数据**：Objaverse-XL（GitHub 与 Sketchfab 分区）、HSSD、3D-FUTURE 和 ABO。经过 TRELLIS 的美学筛选后，约保留 43 万个实例；每个物体按上半球均匀采样 24 个视角渲染。
- **测试数据**：
  - Toys4k：合成物体数据；
  - GSO：真实扫描物体数据。
- 两者均与训练集不重叠。每个测试集使用前 400 个物体，每个物体设置两组不重叠的四视角输入，共计每个数据集 800 个“物体—视角组”样本。
- **评测指标**：
  - 新视角图像质量：PSNR、SSIM、LPIPS；
  - 几何质量：双向 Chamfer Distance（CD）及 \(F\)-score（阈值 0.01、0.05）；
  - 位姿精度：相对旋转误差（RRE）、Acc@5°/15°、相对平移方向误差（RTE）和视场角误差（RFOV）。

### 3.2 对比方法与对齐协议

- **前馈式重建**：FreeSplatter、LucidFusion、ReconViaGen。
- **三维生成方法**：SAM 3D、TRELLIS-S、TRELLIS-M、ReconViaGen。
- **位姿预测方法**：FreeSplatter、ReconViaGen、VGGT。
- 由于各方法输出类型不同，论文按任务族采用不同的对齐协议：
  - 前馈重建：通过输入视图点图进行最小二乘相似变换对齐；
  - 位姿无关的三维生成：使用相似变换 ICP 对齐；
  - 位姿评估：比较无序视图对的相对位姿，以降低坐标系规范自由度的影响。
- GENSFM 也按对应协议重新评估，以便在同一表格内与相应基线比较。

  - 实验主要集中在四视角物体级设置，对更多输入视角、非物体中心场景及实际随手拍图像的评估有限。

## 6. 主要结论与发现

- 在 Toys4k 和 GSO 的四视图设置下，GENSFM 整体优于论文列出的前馈重建与三维生成基线。
- 相对强原生三维生成基线 TRELLIS-M，论文报告：
  - 新视角 PSNR 提高约 **3.2–4.5 dB**；
  - 中位 Chamfer 距离降低约 **2.8–3.8 倍**；
  - Toys4k 上 \(F@.01\) 从 0.56 提升至约 0.83。
- 位姿表中，预测内参设置下两数据集的 Acc@5° 分别约为 **97.2%** 和 **98.2%**；位姿误差明显低于 VGGT 等对比方法。
- 消融实验显示，完整跨视角注意力、图像视觉特征、register token 和原生多视角训练均有贡献；其中 register token 对位姿精度及严格几何阈值指标的提升较突出。
- 这些结果支持论文的核心主张：把形状和相机位姿放进同一个原生三维扩散推理过程，有助于同时利用图像证据与物体级生成先验。

## 7. 优点

- **问题设定统一**：不是先独立估位姿、再重建、最后补全，而是将形状与多视角位姿作为联合推理对象。
- **显式利用三维生成先验**：有助于补足输入图像未覆盖的区域，同时让生成结果受多视图观测约束。
- **位姿表示紧凑**：将 UV 体积压缩为每视角少量 token，降低多视角联合建模的序列长度。
- **细阶段条件更具几何对应性**：按恢复的相机将图像特征采样到具体体素，有利于细节和纹理与观测对齐。
- **评测维度较全面**：同时报告图像、几何和位姿指标，并设置了相应消融和位姿表示分辨率测试。
- **不依赖外部位姿估计器或后处理优化**，并尝试从未标定图像中恢复内参。

## 8. 不足与局限

- **输入范围有限**：主要验证对象中心、四视角设置；论文将扩展到更多视角、场景级输入和真实随手拍作为未来方向，当前证据尚不足以说明这些场景下的表现。
- **对数据分布有依赖**：模型训练于大规模公开三维资产和渲染视图，性能可能受类别分布、渲染风格和现实图像域差异影响。
- **位姿误差可能传递到细化阶段**：当分布偏移导致粗阶段相机或标定误差较大时，逐体素特征采样可能错位并损害局部细化；论文认为粗阶段形状先验仍可保留全局补全能力，但无法消除这一风险。
- **继承基础生成器的限制**：模型依赖 TRELLIS 的表示、数据分布与分辨率能力；其上限可能受基础生成模型制约。
- **评测协议存在解释边界**：不同任务族采用不同对齐方法，不能把不同表格中的结果视为同一绝对标准；位姿指标也不覆盖手性错误。
- **效率信息不完整**：虽报告 H200 数量与训练步数，却未给出训练时长、推理延迟或显存等关键信息，难以判断实际应用成本。
- **真实世界泛化证据有限**：GSO 提供真实扫描物体测试，但输入仍来自受控的多视图评测流程；对分割不准、背景复杂、遮挡严重或摄影视角任意的真实采集情形，尚未充分验证。
