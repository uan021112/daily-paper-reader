# DimFlow: Bidirectional Grid–Expert Learning for Dynamic Gaussian Reconstruction 

Gabriel Adineera and Jinoh Kim ∗

Abstract — Dynamic Gaussian reconstruction requires compact scene features to support coordinated changes in geometry and appearance. A factorized grid provides efficient local queries, but accurate interpolation alone does not ensure that the resulting dynamic attributes remain compatible across space and time. We introduce DimFlow, a framework that learns these features through bidirectional interaction between a multi-resolution grid and a coordinate-based expert branch. Feature-level adversarial alignment connects their distributions, adaptive fusion transfers complementary information, and activation-masked residual feedback refines the grid during training. Four attribute experts organize deformation, rotation, opacity, and temporal information before Gaussian rendering. In the aggregate comparison across D-NeRF, HyperNeRF, and DAVIS, DimFlow achieves 39.73 dB PSNR, improving on 4D-GS by 1.92 dB while matching its reported 85 FPS rendering speed. The model occupies 18.9 MB, compared with 18.3 MB for 4D-GS. Component and attribute-expert ablations reveal complementary contributions from feature alignment, adaptive exchange, and temporal processing. 

I. I NTRODUCTION 

Reconstructing a moving scene requires more than render-ing each observed frame accurately. A useful representation must also describe how scene elements change between observations, while retaining enough detail for a new view at a chosen time. This combination matters for interactive visualization, dynamic scene understanding, and robotic perception. The central difficulty is coordinating spatial detail, motion, and appearance within a representation that can still be queried efficiently. Neural radiance fields [1] establish a continuous formu-lation of scene appearance. Dynamic extensions [2], [3] introduce time-dependent mappings, while explicit feature representations [4]–[7] reduce the cost of querying space and time. Gaussian splatting [8] changes the rendering substrate by projecting explicit primitives into the image. Building on this representation, 4D-GS [9] combines canonical Gaussians with compact spatiotemporal features and a deformation decoder. These developments make dynamic reconstruction substantially more practical. The representation and its optimization nevertheless play different roles. A compact grid can store local variations efficiently, but image supervision must still organize those features into a useful decoding space. Likewise, a shared coordinate network can express regularities across the scene without automatically providing the local detail that a grid can retain. DimFlow addresses this question through bidirectional grid–expert learning . The grid branch supplies interpolated local features at multiple resolutions. A coordinate-based expert branch produces a complementary representation of the same spacetime query. During the forward computation, adaptive fusion transfers information between the two feature views. During optimization, adversarial alignment and feature residuals guide the grid toward a representation that remains compatible with the expert branch. Here “bidirectional” denotes forward feature enhancement and backward opti-mization feedback. We separate this feature interaction from attribute decoding. Four specialized branches organize deformation, rotation, opacity, and temporal information. Their gate controls how the corresponding responses contribute to a Gaussian update. This distinction makes the design easier to interpret: the coordinate branch supports feature learning, whereas the attribute experts structure the dynamic decoder. Temporal processing further connects neighboring feature states instead of treating every timestamp as an unrelated prediction. The aggregate comparison reaches 39.73 dB PSNR with 85 FPS rendering and an 18.9 MB representation. Relative to 4D-GS, the PSNR improves by 1.92 dB at the same reported frame rate, with 0.6 MB additional storage. A. Dynamic Radiance Fields and Explicit Representations 

NeRF [1] represents a static scene through a continuous radiance field. NeRF++ [10] and mip-NeRF [11] address different limitations of the underlying representation and sampling process. For dynamic scenes, D-NeRF [2] learns a deformation to canonical space, while HyperNeRF [3] uses an additional embedding to represent topological variation. Neural scene flow fields [12] connect scene appearance with time-dependent motion. These methods establish the importance of sharing information between observations rather than independently reconstructing each frame. Explicit and factorized features offer a different quality– cost tradeoff. TiNeuVox [4] combines voxels with temporal information; TensoRF [13] factorizes radiance-field represen-tations. HexPlane [5] and K-Planes [6] use coordinate-plane features to represent higher-dimensional fields compactly. MSTH [7] separates static and dynamic contributions through masked hash encodings. DimFlow adopts the efficient feature-query perspective and focuses on how the stored features are organized by learning and exchange. Compact visual representations also arise in other settings. HTC-VLM [14] combines appearance features and discrete semantic anchors for token compression; video encoders built on image representations [15] retain frame evidence before temporal refinement. DimFlow instead compresses and queries a dynamic scene field for Gaussian rendering. 

B. Gaussian-Based Dynamic Reconstruction 

3D Gaussian Splatting [8] enables efficient differentiable rendering with explicit anisotropic primitives. Dynamic exten-sions must additionally account for time-varying geometry and visibility. Deformable 3D Gaussians [16] and 4D-GS [9] learn temporal changes to Gaussian representations. DG-Mesh [17] couples Gaussian representations with mesh reconstruction. DrivingGaussian [18] studies composite dynamic scenes in autonomous driving, while Gaussian representations have also attracted interest in robotics [19]. Our evaluation concerns reconstruction and rendering; it does not evaluate downstream navigation or control. DepthSSC [20] aligns monocular depth and spatial evidence for voxel completion. The Tri-MARF framework in 3D-Agent [21] integrates views, text, and point clouds for object annotation. The ActPhysCause challenge [22] evaluates action-conditioned future videos. These tasks add semantic or causal requirements beyond reconstructing observed dynamic appearance. 

C. Expert Specialization and Adversarial Feature Learning 

Mixture-of-experts models [23]–[25] allocate represen-tational capacity through specialized branches. Switch-NeRF [26] learns scene decomposition with experts, and model-agnostic NeRF mixtures [27] study expert combina-tions for rendering. Beyond rendering, KABB [28] selects experts, OSC [29] adapts communication, GAM-Agent [30] uses uncertainty to trigger visual-reasoning debate, and Agora [31] exchanges structured visual uncertainty. MAT-Agent [32] coordinates training choices; failure-driven work-flow refinement [33] edits workflows from counterexamples, while DrDiff [34] schedules experts for text diffusion. Markets of Minds [35] provides a particularly relevant distinction: expert assistance is valued relative to a default continuation, with repair benefits and regression risks con-sidered under shared budgets and service capacity. Difficulty identifies possible need, whereas allocation must also account for competing uses of the same resources. DimFlow’s attribute gate blends responses within one model. Section IV-E uses this distinction to clarify what its weights and ablations establish. Adversarial learning [36] provides a way to compare learned distributions. GANeRF [37] uses discriminators to optimize radiance fields, and NeRF–GAN distillation [38] connects generative and radiance-field representations. Dim-Flow places the discriminator between two feature branches. Distribution alignment, pointwise feature consistency, and image reconstruction therefore supply distinct constraints on the same representation. Visual faithfulness has different operational meanings across tasks. CF-VLM [39] uses counterfactual edits for causal sensitivity, MM-CoT [40] tests visual consistency and logical coherence, and top-down semantic refinement [41] plans image captions. Our evaluation measures rendered-image agreement and dynamic diagnostics rather than language-generation fidelity. III. B IDIRECTIONAL GRID –E XPERT LEARNING

The formulation separates three questions: whether the two feature branches have compatible distributions, whether corresponding queries agree, and whether their combination supports accurate rendering. We derive simple properties of the feature operations to clarify how these constraints interact. 

A. Distribution Matching Does Not Fix Correspondence 

Consider a finite set of queries qi = ( xi, t i) sampled uniformly. A permutation ρ of their coordinate-expert features preserves the empirical feature distribution: 

Fg (qi) = Fe(qρ(i)) = ⇒ { Fg (qi)}ni=1 = {Fe(qi)}ni=1 . (22) A feature discriminator observing only these samples cannot distinguish the branches from this distribution alone. Yet the feature assigned to a particular scene location can be wrong whenever ρ(i)̸ = i. Pointwise consistency and image reconstruction therefore retain roles that distribution alignment cannot replace. Conversely, matching individual features without a use-ful rendering objective can make the branches agree on an uninformative representation. The coordinate branch is consequently trained with the scene, and its usefulness is determined jointly with reconstruction. This also explains why visual overlap in Figure 1 is interpreted together with the component ablation, rather than as an independent accuracy guarantee.

D. Training and Rendering Costs 

The discriminator adds feature-classification work dur-ing training. Rendering instead queries the learned feature branches, combines attribute responses, updates Gaussians, and performs splatting. A gate that scales four expert responses does not by itself imply sparse execution: evaluating all four responses still incurs all four branch costs. The frame-rate comparison measures the resulting pipeline and should not be interpreted as evidence of a particular dispatch policy. Similarly, the parameter footprint includes the stored scene representation and its decoder, whereas optimization also uses activations and training-only components. Model storage, peak training memory, and rendering latency describe different resources. We report the available storage and timing measurements separately instead of combining them into a single efficiency score.

The present results support coordinated feature learning, without assuming that a larger residual or gate weight certifies greater marginal value. V. E XPERIMENTS 

A. Evaluation Settings a) Data and hardware.: We evaluate synthetic motion with D-NeRF [2] and real sequences with HyperNeRF [3] and DAVIS [42]. The aggregate comparison covers eight D-NeRF scenes, eight HyperNeRF scenes, and ten DAVIS sequences. Experiments use NVIDIA A100 GPUs. The compared methods are K-Planes [6], TiNeuVox-B [4], Hex-Plane [5], 4D-GS [9], MSTH [7], and DG-Mesh [17]. Baseline training follows the corresponding configurations used in the comparison. 

b) Metrics.: We report PSNR, SSIM [43], and LPIPS [44] for image quality, together with training time, ren-dering frame rate, and model storage. Higher PSNR and SSIM and lower LPIPS indicate better image agreement. Results include the reported variation at the displayed precision. The aggregate table and the two ablation settings have different evaluation populations and are analyzed separately. The attribute-expert experiment additionally reports optical-flow consistency error (FlowsME), temporal SSIM fluctuation (TSV), and elastic deformation error (EDE). These are diagnostic quantities from that setting, rather than additional terms in the image-quality average. That experiment uses AdamW with an initial learning rate of 3 × 10 −4 and reports means over five runs. 

B. Reconstruction Quality and Efficiency 

Table I reports the aggregate comparison. DimFlow achieves 39.73 dB PSNR, compared with 37.81 dB for 4D-GS and 38.32 dB for DG-Mesh. The corresponding improvements are 1.92 and 1.41 dB. DimFlow also reaches 0.98 SSIM and 0.02 LPIPS, matching the best values at the displayed precision. The improvements are therefore most clearly distinguished by PSNR; the rounded SSIM and LPIPS values contain several ties. The frame rate is 85 FPS, equal to the 4D-GS result in this comparison. DimFlow uses 18.9 MB of storage, versus 18.3 MB for 4D-GS: a 0.6 MB increase, or about 3.3%. Its reported training time is eight minutes, compared with seven for 4D-GS. The quality gain consequently comes with a modest increase in training time and storage in this setting, while preserving the reported rendering rate. MSTH has the shortest reported training time, and 4D-GS has the smallest reported footprint. The baselines illustrate different tradeoffs. K-Planes and TiNeuVox-B occupy the slower end of the reported rendering comparison, while the explicit Gaussian methods achieve higher frame rates. MSTH has no reported frame rate or storage in this table and is omitted from the speed scatter plot. Figure 5 visualizes the quality–speed relationship and separately summarizes component contributions; the two panels use different experimental settings. 

a) Qualitative observations.: Figure 4 aligns the Cat and Dancer views using a common layout. The comparisons expose local appearance differences and changes around the moving body and silhouette. The ground-truth frames may themselves contain motion blur, so apparent sharpness alone is not a complete measure of reconstruction accuracy. These static views complement the numerical comparison; temporal claims are assessed through the expert diagnostics rather than inferred from a single image. 

C. Component Contributions 

The component study in Table II uses the D-NeRF setting with a 39.73 dB full-model baseline. All five removals decrease PSNR and worsen LPIPS. Removing the coordinate-expert framework gives the largest PSNR decrease, 2.03 dB, and raises LPIPS from 0.02 to 0.05. The grid alone therefore does not reproduce the behavior of the coordinated feature-learning system in this experiment. Removing adversarial alignment decreases PSNR by 1.88 dB, while disabling adaptive weighting decreases it by 1.61 dB. These ablations address different parts of the method: distribution alignment changes how the feature space is learned, whereas adaptive weighting changes which feature information reaches the decoder. Their effects should not be added, since each removal starts from the complete model and may also change how the remaining modules adapt. Without temporal feature flow, PSNR decreases by 1.79 dB and LPIPS increases to 0.04. Removing bidirectional ex-change gives a 1.71 dB decrease and 0.03 LPIPS. D. Deformation and Temporal Experts 

The expert-specific study in Table III has a separate full-model baseline of 38.79 dB. Suppressing the deformation expert yields 36.53 dB, a decrease of 2.26 dB; suppressing the temporal expert yields 37.12 dB, a decrease of 1.67 dB. These differences are calculated directly from the values in that table. They are not measured against the 39.73 dB aggregate or component baseline. Removing the deformation expert increases EDE from 0.08 to 0.21 and flow error from 0.12 to 0.31. Removing the temporal expert raises flow error to 0.58 and TSV from 0.015 to 0.030. The latter doubles the reported temporal fluctuation metric. The flow error becomes about 4.83 × its baseline value, rather than a small percentage change. These changes distinguish a loss of geometric modeling capacity from a stronger degradation of temporal consistency. The image metrics also worsen: deformation removal changes SSIM from 0.98 to 0.95 and LPIPS from 0.03 to 0.05; temporal removal gives 0.96 SSIM and 0.04 LPIPS. The specialists thus have overlapping consequences for ren-dered appearance while showing different sensitivities in the additional diagnostics. The evidence supports complementary attribute roles within this decoder, without implying that the four branches are statistically independent. VI. D ISCUSSION AND LIMITATIONS 

DimFlow depends on the information present in the input views and their camera poses. A coordinate prior and temporal regularity cannot recover unobserved motion uniquely, and excessive coupling can smooth a rapid change that should be preserved. Likewise, a feature projection cannot prove that individual Gaussian trajectories are correct. Frame rate and storage depend on image resolution, the number of primitives, and the feature configuration; the reported aggregate should not be interpreted as deployment latency for every camera setup. Applications to mapping, navigation, or closed-loop control require additional task-specific evaluation. Evaluation must also match the intended task. The NTIRE super-resolution challenge [45] distinguishes reconstruction fidelity from perceptual quality; scaling laws for deepfake detection [46] study coverage of real domains and forgery methods. These criteria address different failure modes from dynamic view synthesis. The current PSNR comparison does not establish perceptual preference, forensic generalization, or causal future prediction. Calibrated expert usefulness, broader sparse-view evaluation, and richer motion priors remain useful extensions. Global image metrics and local expert value operate at different scales. Paired interventions, holding the decoder and camera view fixed, could measure both reconstruction gains and response costs, helping distinguish useful specialization from compensation between attribute branches. Any routing policy would additionally require validation across motion regimes and camera trajectories. VII. C ONCLUSION 

DimFlow connects a compact grid representation with coordinate-expert learning through feature-level alignment and bidirectional exchange. Adaptive fusion, residual feedback, and temporal processing organize the features supplied to specialized dynamic-attribute branches. The aggregate results improve PSNR while retaining the reported rendering speed of 4D-GS, with a small increase in storage. Component and expert ablations identify complementary contributions from representation learning and dynamic specialization.
