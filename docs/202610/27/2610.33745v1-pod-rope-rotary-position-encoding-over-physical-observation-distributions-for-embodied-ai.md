## 摘要
具身感知需要能够同时表征物理几何结构以及观测在空间和时间上延展范围的位置表示。我们提出 POD-RoPE（物理观测分布 RoPE），将 token 的观测范围表示为由相机中心、视线方向和采样时间构成的分布。在独立采样条件下，期望旋转能够编码分布之间的相对关系；当每个分布退化为单一地址时，该方法则还原为逐点 RoPE。相同的旋转统计量可用于 Q/K 匹配以及依赖相干性的 V/O 变换，使观测几何既能指导信息选择，也能指导内容聚合。逐 token 的预聚合无需增加序列长度，也不必处理成对的观测节点。我们在四种机器人策略架构、仿真与真实世界操作任务，以及互补的重建、深度估计和新视角合成任务上评估了 POD-RoPE。将 POD-RoPE 集成到 Fast-WAM 后，其在全部 50 项 RoboTwin 2.0 任务上的平均成功率从 91.83% 提升至 92.88%；在 Sharpa North 上的两项真实机器人任务中，成功率从 32.5% 提升至 52.5%。受控重建消融实验验证了分布编码和 V/O 变换的贡献。在 H20 模型块基准测试中，POD-RoPE 相较于 P-RoPE 和 RayRoPE，前向加反向传播速度的中位数分别提升 1.91 倍和 5.34 倍；相较于标准 RoPE，其中位延迟开销为 17.4%。这些结果表明，物理观测分布能够为几何感知注意力提供有效且计算高效的基础。

## Abstract
Embodied perception requires positional representations that capture both physical geometry and the spatial and temporal extent of observations. We introduce POD-RoPE (Physical Observation Distribution RoPE), which represents token observation footprints as distributions over camera centers, viewing directions, and sampling times. Under independent sampling, expected rotations encode relative relationships between distributions; when each distribution collapses to a single address, the construction recovers pointwise RoPE. The same rotation statistics support Q/K matching and coherence-dependent V/O transformations, allowing observation geometry to guide both information selection and content aggregation. Per-token pre-aggregation avoids increasing sequence length or processing pairs of observation nodes. We evaluate POD-RoPE across four robot policy architectures, simulation and real-world manipulation, and complementary reconstruction, depth-estimation, and novel-view-synthesis tasks. Integrating POD-RoPE into Fast-WAM improves mean success from 91.83% to 92.88% across all 50 RoboTwin 2.0 tasks, and from 32.5% to 52.5% on two real-robot tasks on Sharpa North. Controlled reconstruction ablations support the contributions of distribution encoding and V/O transformations. In H20 model-block benchmarks, POD-RoPE achieves median forward-plus-backward speedups of $1.91\times$ over P-RoPE and $5.34\times$ over RayRoPE, with a median latency overhead of 17.4% over Standard RoPE. These results support physical observation distributions as an effective and computationally efficient basis for geometry-aware attention.

# 1. 核心问题与整体含义

- **研究问题**：具身视觉中的 token 不只是序列里的一个位置。图像 token 通常覆盖一片像素区域，视频 token 还可能汇聚多个时刻的信息；因此，单一坐标或帧索引难以描述它实际观测到的空间与时间范围。
- **研究背景**：标准 RoPE 主要依赖序列索引或时空网格坐标，不能直接表达相机基线、视线方向或真实时间间隔。已有几何位置编码（如 P-RoPE、RayRoPE）引入相机或射线信息，但论文认为它们在计算延迟方面代价较高。
- **整体思路**：论文提出 POD-RoPE，将每个 token 的观测足迹建模为一组**物理观测地址的分布**，再用这些地址对应旋转的期望来编码位置关系。它试图让注意力既知道“观测来自哪里、何时发生”，也知道“这个 token 覆盖了多大范围”。

# 2. 方法论：核心思想与关键技术

## 2.1 构造物理观测地址

对相机 \(c\)、时刻 \(t\) 的像素 \(p\)，论文利用相机内外参计算相机中心 \(o\) 和单位视线方向 \(d\)，并与实际时间组合成地址：

\[
x=[f(\tau),\ \bar{o}^{\top},\ \bar{d}^{\top}]^{\top}.
\]

其中，\(\tau\) 是归一化后的时间，\(\bar{o}\) 和 \(\bar{d}\) 是经过尺度调整的相机位置与视线方向；时间映射在实验中采用 \(f(\tau)=2\tanh(\tau/2)\)。静态任务则省略时间维度。该地址不要求知道射线上未知表面点的深度。

## 2.2 将 token 表示为观测分布

- 一个 token 覆盖的像素区域、以及视频 token 汇聚的多个时刻，共同构成其观测分布 \(\mu_i\)。
- 对地址 \(x\)，RoPE 根据频率向量 \(\omega_m\) 产生旋转矩阵 \(R(\omega_m^\top x)\)。token \(i\) 的位置算子取这些旋转的期望：

\[
M_i=\mathbb{E}_{X_i\sim\mu_i}[R(X_i)].
\]

- 若观测分布收缩为单个地址，\(M_i\) 就退化为该地址对应的逐点 RoPE。因此，POD-RoPE 可视作把点式位置编码扩展到区域和时空足迹。

## 2.3 用期望旋转建立相对位置关系

对两个 token 分别从其分布独立采样 \(X_i\) 和 \(X_j\)，利用 RoPE 的旋转性质，可得：

\[
M_i^\top M_j=\mathbb{E}[R(X_j-X_i)].
\]

因此，Q/K 的交互对应两种观测分布之间相对地址的期望，而非仅比较两个中心点。注意，独立采样是该等式成立的重要条件。

## 2.4 用相干性指导 V/O 内容变换

对每个 token 和频率，计算余弦、正弦的加权均值，得到平均旋转矩阵 \(R_{i,m}\)。其幅度 \(\rho_{i,m}\in[0,1]\) 表示观测中各旋转的**相干性**：相干性低意味着覆盖范围内旋转相互抵消较多。

论文构造内容变换：

\[
G_{i,m}=(1-g\rho_{i,m})I+gR_{i,m},
\]

其中完整方法取 \(g=1\)。该变换在相干性高时更多采用旋转，在相干性低时则靠近恒等变换，以避免直接使用平均旋转造成内容特征不必要地收缩。注意力聚合时，先以 \(G_j\) 变换值，再聚合，最后用 \(G_i^\top\) 变换输出。

## 2.5 计算方式

- 实际实现以有限个确定性节点近似每个 token 的观测分布，并加权计算各频率的正弦、余弦统计量。
- 视觉 token 通常使用 \(3\times3\) 空间采样点；视频 token 最多对应 4 个源帧，因此每 token 最多使用 36 个时空节点。
- 统计量按 token 预先聚合并复用，不增加 token 序列长度，也不需要在注意力中逐对处理观测节点。

# 6. 主要结论与发现

- Fast-WAM 在 RoboTwin 50 项任务上的平均成功率从 **91.83% 提高到 92.88%**；Clean 条件提升 1.24 个百分点，Randomized 条件提升 0.86 个百分点。

- 单任务训练中，\(\pi0\)、RDT、ACT 的平均成功率均有所提高，但增益随架构和条件而异；例如 ACT 的 Randomized 平均成功率只从 2.60% 增至 3.07%。
- 视觉几何任务的收益具有任务和数据集依赖性：POD-RoPE 在部分重建、深度指标上领先，但并非所有数据集、指标都优于基线；RE10K 新视角合成中 RayRoPE 仍取得最佳指标。
- 消融实验支持分布式 Q/K 编码及带恒等分支的 V/O 变换均有贡献；直接平均旋转用于 V/O 的效果较差。
- H20 模型块基准中，完整 POD-RoPE 的前向加反向传播中位速度，相较 P-RoPE 和 RayRoPE 分别快 **1.91 倍**和 **5.34 倍**；相较标准 RoPE 的中位延迟开销为 **17.4%**。

# 7. 优点

- **问题设定贴近视觉 token 的实际性质**：不仅编码中心位置，还考虑 token 对应的空间区域与时间跨度。
- **理论构造清晰**：在独立采样条件下，期望旋转保留分布间相对位置关系；单点分布则退化为逐点 RoPE。
- **统一匹配与内容聚合**：同一套旋转统计既影响 Q/K 匹配，也用于 V/O 变换，尝试将观测几何同时用于信息选择和内容传递。
- **计算设计较务实**：逐 token 预聚合，不增加序列长度；在注意力计算主项之外，统计量可复用，效率测试也显示其比所测 P-RoPE、RayRoPE 更轻。
- **评测维度丰富**：包括仿真、真实机器人、视觉重建、深度估计、新视角合成、消融与计算效率，并公开了多项任务级结果。
- **明确呈现负向或不一致结果**：例如部分重建指标、时间采样变化和某些任务条件下的退步，结论没有将效果描述为普遍占优。

# 8. 不足与局限

- **收益存在明显任务依赖性**：仿真整体提升幅度较小；部分架构或随机化条件下提升有限，视觉任务也有指标未胜过基线的情况。
- **真实机器人证据规模有限**：仅两个任务、每任务 20 次试验，且未报告置信区间；当前结果不足以确定收益在不同机器人、环境和任务上的普遍性。
- **物理地址质量依赖标定与预处理**：相机内外参、图像裁剪缩放后的内参更新、时间戳及坐标系都可能影响地址准确性。论文也指出真实机器人部分相机几何采用近似，不是独立精确标定。
- **观测足迹是近似的**：使用固定模板采样 token 的像素和时间支持；视频的时间范围按名义压缩分箱构建，并非因果 VAE 的完整感受野。因此分布并不一定准确还原网络实际接收的信息范围。
- **计算优势仍需端到端验证**：主要效率数字来自模型块微基准，不包括数据加载、解码、优化和仿真流程；部分 RayRoPE 配置无法运行，也限制了全面的形状对比。
- **训练成本报告不完整**：缺少多数实验的总训练时长、GPU 小时和能耗，难以评估完整复现成本。
- **V/O 变换的理论性质与 Q/K 不完全相同**：Q/K 的相对位置核具有平移不变性，而论文指出 V/O 变换一般还会使用绝对地址信息；其适用方式和泛化影响仍值得进一步研究。
- **对关键设计的进一步分解有限**：现有消融支持分布编码与 V/O 总体设计，但并未完全隔离相干性幅度、相位及采样策略各自的独立贡献。
