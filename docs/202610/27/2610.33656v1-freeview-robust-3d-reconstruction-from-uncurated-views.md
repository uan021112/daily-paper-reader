## 摘要
由于图像集合中存在无关视图或彼此不重叠的视图，从未经筛选的图像集合中重建连贯的三维场景仍然颇具挑战。近期研究表明，前馈式重建模型包含可用于剔除干扰视图的内部视图一致性信号。然而，基于参考视图的筛选依赖经过筛选的干净参考视图，而实际图像集合中并不一定存在这样的视图。为解决这一局限，我们提出 FreeView，这是一种无需训练的框架，可从未经筛选的图像集合中联合选择筛选参考视图并剔除干扰视图。FreeView 利用集合级共识识别具有代表性的视图，将其作为可靠的筛选参考。随后，它结合互补的视觉与几何证据，针对每个输入集合调整视图剔除策略。该方法能够在外观和视角存在显著变化时保留有用视图，同时剔除干扰视图。FreeView 可与 VGGT 和 pi^3 集成，无需人工挑选参考视图或手动校准视图剔除策略。在多个数据集上的大量实验表明，该方法能够实现较高的干净视图保留率和干扰视图剔除率，从而基于未经筛选的视图实现可靠的三维重建。

## Abstract
Reconstructing a coherent 3D scene from uncurated image collections remains challenging due to the presence of irrelevant or non-overlapping views. Recent work has shown that feed-forward reconstruction models contain internal view-consistency signals that support distractor rejection. However, reference-conditioned filtering relies on a curated clean reference, which is not guaranteed in practical image collections. To address this limitation, we introduce FreeView, a training-free framework that jointly selects a filtering reference and rejects distractor views from an uncurated collection. FreeView leverages collection-level consensus to identify a representative view that serves as a reliable reference for filtering. It then adapts view rejection to each input collection by combining complementary visual and geometric evidence. This approach preserves useful views under substantial appearance and viewpoint variations while rejecting distractors. FreeView integrates with both VGGT and pi^3, removing the need for a manually curated reference or manual calibration of view rejection. Extensive experiments across multiple datasets demonstrate high clean-view retention and distractor rejection rates, leading to reliable 3D reconstruction from uncurated views.

## 1. 核心问题与整体含义

- **研究问题：**实际图像集合往往未经整理，可能混有不同场景的图像、无关视角或彼此缺少重叠的视图。这些干扰会导致前馈式三维重建模型恢复出错误或不连贯的几何结构。
- **既有方法的局限：**VGGT、π³ 等模型可以从多张图像直接预测相机参数和场景几何；RobustVGGT 及其 π³ 变体则利用模型内部的视图一致性信号过滤干扰图像。但这类过滤通常依赖一张预先指定的“干净”参考图，并使用固定的剔除标准。如果参考图本身来自干扰场景，过滤结果可能反而保留干扰、排除正确视图。
- **论文的整体思路：**FreeView 将“选哪张图作为过滤参考”与“如何剔除干扰图”一并处理。它先从整个图像集合中自动选择具有代表性的参考视图，再结合视觉相似度和重建模型内部的几何相关特征，按当前集合的得分分布决定过滤结果。
- **方法定位：**FreeView 是一个**无需训练**的视图整理框架，可接入 VGGT 和 π³；它不是新的三维重建骨干模型，而是在重建前筛选输入视图，以提高重建对杂乱输入的鲁棒性。

## 2. 方法论：核心思想与技术流程

FreeView 的流程可以概括为：**集合共识选参考 → 提取双重相关性证据 → 自适应阈值过滤 → 使用原重建模型重建**。

### 2.1 集合共识参考选择（Consensus Reference Selection, CRS）

1. 对每张图像提取 DINOv2 的 CLS 特征，并进行 L2 归一化，记为 \(e_i\)。
2. 计算图像两两之间的外观相似度：
   \[
   S^a_{ij}=e_i^\top e_j.
   \]
3. 对每张图像只考察其最相似的 \(K\) 个邻居，计算局部共识分数：
   \[
   c_i=\frac{1}{K}\sum_{j\in N_K(i)}S^a_{ij}.
   \]
4. 选择共识分数最高的图像作为过滤参考：
   \[
   i_r=\arg\max_i c_i,\qquad I_r=I_{i_r}.
   \]

这一策略不要求目标场景图像占整个集合的大多数，但依赖论文的问题假设：**目标场景能形成一个局部视觉支持较强的群体，且强于竞争的干扰群体**。论文采用
\[
K=\max(3,\lfloor N/3\rfloor)
\]
作为默认值。

参考图选定后，若使用 VGGT，则将它移至输入首位并重新计算多视图特征，因为 VGGT 的表示受首张图像影响；若使用具有置换等变性的 π³，则不需要为此重排输入。

### 2.2 自适应双线索剔除（Adaptive Dual-Cue Rejection, ADCR）

FreeView 用两种互补证据评估每张图像与参考图的相关性：

- **外观相关性：**直接使用 DINOv2 相似度
  \[
  r^a_j=S^a_{i_rj}.
  \]
- **几何感知相关性：**从所选重建骨干的多视图聚合特征中，为每张图像构造描述符。具体做法是先对每个空间特征进行 L2 归一化，再对空间 token 求平均，最后再归一化；随后计算该描述符与参考图描述符的点积，得到 \(r^g_j\)。论文依据 RobustVGGT 的发现，认为较后层的骨干特征能够隐式编码跨视图几何一致性。

为了避免固定阈值对不同数据集和得分尺度不适用，论文分别对外观得分和几何得分使用 Otsu 方法自适应估计阈值 \(\tau_a\)、\(\tau_g\)。由于 Otsu 即使面对区分度很弱的分布也会产生划分，论文还设置均值分离度下限 \(\gamma=0.04\)：若某一线索形成的两组均值差低于该值，则抑制该线索据此拒绝视图。

最终采用保守的联合规则：**只有当两种线索都认为某张图像相关性低时，才拒绝该图像**。即只有在
\[
r^a_j<\tau_a\quad\text{且}\quad r^g_j<\tau_g
\]
时才剔除；只要至少一种线索支持该图像，就予以保留。该过滤执行两轮：参考图保持不变，每轮在当前保留集合上重新计算阈值。最后将保留图像交给 VGGT 或 π³ 完成相机姿态与三维几何重建。

### 3.2 评测设置与指标

论文主要比较四类设置：

- **CK（Clean-view Keep Rate）：**干净视图保留率。
- **DR（Distractor Rejection Rate）：**干扰视图剔除率。

姿态指标包括平移召回率和旋转召回率，并采用覆盖感知的统计方式：**被错误过滤掉的干净视图也计作失败**。这有助于避免方法通过大量丢弃困难视图而获得虚高的姿态指标。

## 6. 主要结论与发现

- **参考图选择是未整理多视图重建的关键环节。**即使视图相关性评分本身有效，如果评分依赖错误参考，过滤效果仍可能崩溃。
- 在干扰参考条件下，若干参考条件方法的干净视图保留率和姿态恢复表现明显下降；FreeView 则通过自动参考选择，在不同数据集和干扰等级下维持较好的过滤与重建表现。
- CRS 消融结果表明，自动选择参考本身带来显著恢复；ADCR 则根据数据集上的得分分布调整拒绝标准，其收益随数据集而异。
- 外观与几何线索的有效性因数据集而变。采用“双线索均判低相关才剔除”的规则，整体上更有利于保留有效视图，同时维持较强的干扰剔除能力。
- FreeView 在 VGGT 和 π³ 上均有实验结果，说明其设计不局限于一种重建模型。不过，各数据集、指标以及两种骨干上的表现并非完全一致，不能将“稳定有效”理解为所有条件下都达到最佳。

## 7. 优点

- **解决了实际流程中的前置难题：**不只过滤视图，还自动处理“谁来做参考”这一依赖条件。
- **无需训练且可复用现有模型：**不需要额外训练新的重建网络，可与 VGGT、π³ 等骨干组合。
- **多证据互补、决策相对保守：**当某一线索不可靠时，另一线索仍可能保留有效视图；联合规则有助于降低误删干净视图的风险。
- **阈值按集合自适应：**通过 Otsu 阈值和均值分离度检查，缓解不同集合之间得分分布变化的问题。
- **评测设计关注视图覆盖：**报告过滤率之外，还使用包含被过滤干净视图失败的姿态召回指标，避免只在保留下来的简单样本上评价。
- **包含组件消融与策略比较：**对参考选择、邻居数和线索融合方式进行了分析，而不只是报告最终结果。

## 8. 不足与局限

- **依赖局部共识假设：**如果目标场景并非局部视觉上最受支持的群体，或干扰图像形成更强的相似性簇，自动参考选择可能选错。
- **视觉相似性可能与几何可重建性不一致：**DINOv2 相似度反映外观关联，不必然代表视角重叠或几何一致性；而骨干特征的可靠性也可能受模型和场景影响。
- **Otsu 阈值的适用性有限：**该方法适合得分分布可分成高低两组的情况；在分布重叠、单峰或存在多类视图时，阈值可能不稳定。均值分离度检查只能缓解，不能彻底解决这一问题。
- **保守融合存在取舍：**双线索均判低才剔除能保护干净视图，但也可能保留由某一个线索误判为相关的干扰图像。
- **实验主要是受控混合场景：**论文没有充分展示对真实大规模图像检索结果、近似场景、动态场景、长尾视点或极端外观变化的泛化能力。
- **资源与可部署性证据不足：**未报告硬件、时间、显存及大规模输入的扩展性数据，难以判断其实际运行成本。
- **结论需要结合指标理解：**论文报告了总体较高的干净视图保留率和干扰剔除率，但具体效果随数据集和骨干而变化；尤其应结合 CK、DR 与姿态召回共同判断，而不能仅凭单一过滤指标概括性能。
