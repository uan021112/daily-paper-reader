## 摘要
近年来，三维重建的进展已从逐场景优化转向前馈推理，语义场景理解也随之发展——然而现有方法仍局限于以物体为中心的感知，忽视了物体之间的空间关系。我们在前馈式、无需位姿的多视角设定下提出三维空间关系分割任务：给定视觉指定的主体和关系文本查询，模型在未获知目标类别名称的情况下跨视角分割出目标。为此，我们提出RelationVGGT，一种新颖的前馈框架，它将视觉基础模型的语义特征与三维几何基础模型的几何感知表示相融合，并利用关系Transformer进行以主体为条件的跨视角关系预测——既不需要逐场景优化，也不需要已知相机位姿。此外，我们基于ScanNet++构建了一个全自动标注流程，借助视觉语言模型（VLM）和大型语言模型（LLM），可为这一新任务实现可扩展的训练数据生成。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

## 1. 核心问题与整体含义

- **背景脉络**：三维重建已从 NeRF/3DGS 的逐场景优化走向 DUSt3R/VGGT/Pi3 等前馈式几何基础模型（无需相机位姿、无需 SfM）；语义理解亦随之从 LangSplat/OpenGS 的逐场景特征场，转向 PanSt3R/Uni3R 等前馈多视图语义分割。
- **核心缺口**：上述工作几乎全部是**以物体为中心**的感知——把场景当作孤立实体的集合，忽略物体之间的空间关系（如“显示器**放在**桌上”“杯子**在**键盘**旁边**）。而关系推理是空间问答、具身智能体行动的基础能力。
- **现有方案的两条死路**：
  - **RelationField**：在辐射场上学习连续关系特征 `gθ(x, z) → r`，但（i）需逐场景优化与标定相机位姿；（ii）定位目标需在整个三维体空间内穷举搜索，计算昂贵且依赖显式体素重建；（iii）依赖场景特定位置编码，难以泛化到新场景。
  - **视频-语言模型**：缺少三维场景表示，在大视角变化下难以维持物体对应关系。
- **本文任务定义**：提出**三维空间关系分割（3D spatial relation segmentation）**，在前馈、无位姿的多视图设定下：输入多视图图像、参考视图中的主体掩码 `Ms`、关系文本查询 `q`（如 "resting on"），要求模型**在不给出目标类别名称**的前提下，在所有目标视图中一致地分割出满足该空间关系的目标物体。该任务同时要求语义身份、方向性空间关系推理与跨视图几何一致性。
- **三大贡献**：（1）新任务设定；（2）RelationVGGT 前馈框架；（3）基于 ScanNet++ 的 VLM/LLM 全自动关系标注流程。

## 2. 方法论

### 2.1 核心思想：把“体空间搜索”改写为“逐像素关系预测”
- 不再在稠密三维体积上搜索目标，而是在每个目标视图的**图像网格**上做以参考主体为条件的关系预测。
- 定义逐视图关系特征图 `Rt = { rt(u) | u ∈ It }`，其中 `rt(u) ∈ R^D` 编码目标视图位置 `u` 与参考主体 `Ms` 之间的空间关系；将其对齐到语言嵌入空间后，即可通过特征-文本相似度支持开放词表关系查询。
- 学到的映射为：`fθ(Ir, Ms, Itgt, u) → Rt`。

### 2.2 特征提取与融合
- 两路冻结的稠密表征（遵循 PanSt3R 思路）：
  - **语义**：DINOv2 特征图 `E^D_n`（强物体级语义，但无多视图意识）；
  - **几何**：Pi3 编码器在预测头之前的 token `E^P_n`（保留通用多视图几何信息）。
- 通道拼接后经 **Input Mixer** `Mθ`（线性投影 + 小型 Transformer 堆栈 + RoPE 位置编码）映射为联合 token：
  `Fn = Mθ([E^D_n ; E^P_n]) ∈ R^{P×df}`，`P = Hp·Wp`。

### 2.3 关系 Transformer：主体条件 + 跨视图
- **主体表示**：不做池化为单向量，而是保留参考视图全部 patch token，并用下采样到 patch 网格的掩码 `M̄s` 逐元素相乘、置零非主体 patch：`F^s_r = M̄s ⊙ Fr`，从而保留主体的空间布局与细粒度语义。
- **目标 token 序列**：把所有目标视图 token 拼接为 `Z0 = Concat({Ft}) ∈ R^{(N-1)P×df}`。
- **交替注意力**（`L` 层，每层）：
  - 主体条件交叉注意力：`Z̄ℓ = CrossAttn_ℓ(Zℓ, F^s_r)`（每个目标 patch 关注被掩码的主体 token）；
  - 全局自注意力：`Z^{ℓ+1} = SelfAttn_ℓ(Z̄ℓ)`（跨所有视图的目标 patch 交换信息，获得多视图一致性）。
- **解码**：将最终 token 还原为逐视图 patch 网格，用 **DPT head** 上采样为像素对齐的关系特征图 `Rt = Dec(Z^L_t)`。
- **三维几何分支**：用 Pi3 点解码器预测每视图点图与置信度图，使每个 `rt(u)` 关联到对应三维点，形成**置信度感知的三维关系表示**（用于可视化/分析，不用于显式体搜索）。

### 2.4 训练目标：多查询监督
- 同一空间关系常有多种有效表述（"standing on" / "on" / "supported by"），单标签分类会惩罚语义合理的替代项。
- 对同一目标掩码用**多个兼容查询**独立做二值监督（sigmoid focal loss，`α=0.75`，`γ=1.5`），再加 Dice 损失：
  `Lmask = w_focal · L_multi-q_focal + w_dice · L_dice`，两项均在像素与查询上平均。

### 2.5 推理
- 逐像素相关性 logit：`zt(u; q) = rt(u)^T e(q)`；掩码分数 `St = sigmoid(zt)`；固定阈值 `τ = 0.3` 二值化，无后处理。
- 与特征场方法不同，**无需正负文本嵌入的 softmax 归一化**，直接 sigmoid 即可。

### 2.6 自动标注流程（ScanNet++）
1. 以三维实例为节点初始化场景图，边为空；
2. 将实例掩码投影到已标定 RGB 帧，用 **Set-of-Mark (SoM)** 提示标记可见物体，查询 VLM（Qwen3-VL-8B）得到逐帧、有向、开放词表的关系候选；
3. **多视图一致性过滤**：同一物体对需至少 `K=3` 帧预测出该关系，否则剔除；通过者按共视帧传播，形成多视图一致标注；
4. **几何过滤**：用三维包围盒与实例质心，剔除包围盒不重叠且质心距离超阈值的物理不合理关系（如远处物体间的接触/支撑）；
5. **LLM 改写**（GPT-5.2）：对验证过的 (subject, relation, target) 三元组做同义改写（如 "hanging on" → "mounted on"），在不改变语义与关系族的前提下提升词汇多样性。

## 6. 结论、局限与启示

### 6.1 主要结论
- 三维空间关系分割可以在**前馈、无相机位姿、无逐场景优化**的设定下完成，且精度优于需逐场景优化的特征场方法与需适配的视频/三维指代模型。
- 把关系推理从"三维体空间穷举搜索"重构为"以参考主体为条件的逐像素关系预测"，是使该任务可前馈化的关键设计；主体以**掩码保留全部 patch token**（而非池化为单向量）对保留空间布局信息至关重要。
- 多查询监督（同一掩码配多个兼容表述）缓解了关系语言的同义多样性带来的标签冲突，是开放词表关系分割能工作的必要条件之一。
- 置信度感知的三维关系表示（关系特征与 Pi3 点图关联）在保持前馈性的同时，为结果提供了可解释、可可视化的三维锚定。

### 6.2 局限
- **任务假设仍较强**：需要参考视图中的主体掩码作为输入，未实现"文本指定主体 + 关系"的端到端设定；主体在目标视图中不可见的 23 个视图虽被单独分析，但性能下降说明方法对共视性仍有依赖。
- **数据依赖**：训练完全依赖 ScanNet++ 上的自动标注，室内场景偏置明显；跨域（户外、驾驶、机器人操作台）泛化未验证。
- **谓词空间有限**：28 个谓词主要覆盖接触/支撑/邻近等静态空间关系，缺少时序关系、功能关系（"可放入"）与多物体联合关系（"位于 A 和 B 之间"）。
- **无显式三维推理**：三维分支仅用于表示与可视化，关系判断本质上仍在二维特征空间完成，对严重遮挡、深度歧义场景的鲁棒性上限存疑。
- **标注流程的算力与成本未披露**，VLM/LLM 引入的标注噪声虽有审计（4,695 条提案），但审计仅覆盖 25 个场景且由作者本人完成，独立性有限。

### 6.3 启示与可拓展方向
- **范式启示**：几何基础模型（VGGT/Pi3）提供的多视图一致 token 可作为通用的"空间推理底座"，把各类需要三维一致性的任务（关系、可供性、抓取位姿、导航目标）都改写为在图像网格上的条件预测，从而绕开显式重建与逐场景优化。
- **可拓展点**：（i）将主体指定从掩码扩展为文本/点击，形成统一的"指代—关系"接口；（ii）引入方向与距离的显式回归头，弥补纯语义相似度对精细空间量化的不足；（iii）把关系图输出接入具身智能体的规划模块，验证其在长程任务中的实用价值；（iv）扩展到动态场景与多主体联合关系。

## 7. 一句话总结

RelationVGGT 把"三维空间关系分割"这一新任务从需要逐场景优化与三维体搜索的旧范式中解放出来，通过"主体掩码条件化的跨视图关系 Transformer + 多查询监督 + 全自动关系标注"，在前馈无位姿设定下实现了开放词表、跨视图一致的关系目标分割，并以 26 ms 对 288 s 的推理效率差距，展示了前馈几何基础模型在空间关系推理上的可行性；其主要短板在于 benchmark 规模、跨域泛化与显式三维推理的缺失。
