## 摘要
VGGT等3D视觉Transformer能够在单次前向传播中从多视图图像预测相机位姿与场景几何，但随着视图数量增加，其对所有拼接视图token的全局注意力在计算中占据主导地位。为降低这一开销，SparseVGGT与HeSS在块级别对注意力进行稀疏化，二者均保留注意力概率较高的块。然而，我们观察到注意力概率并不能很好地预测移除某个块时模型行为的实际变化程度，并表明这种不匹配正是稀疏度提高时性能崩溃的原因。本文提出ReSS（ReSidual-ReStoring Sparse Attention，残差恢复稀疏注意力），将块选择从最大化保留注意力质量的问题重新表述为最小化稀疏化在残差流中所留漂移的问题。我们引入漂移分数来量化每个块对残差的偏移程度；并且，由于丢弃集合的漂移取决于其贡献向量的方向而非仅取决于其幅值，我们进一步提出一种迭代残差恢复过程，从整体上对丢弃集合进行细化。在三个主干网络与五个数据集上，ReSS在相同稀疏度下比此前方法更好地保持了稠密性能。另外两项结果支持漂移是决定稀疏化代价的量：最大化漂移会比随机选择更快地损害性能；而若以实际实现的漂移而非稀疏度为横轴作图，所有方法都近似落在同一条曲线上。代码见 https://github.com/libary753/ReSS。

## Abstract
3D vision transformers such as VGGT predict camera poses and scene geometry from multi-view images in a single forward pass, but their global attention over all concatenated view tokens dominates computation as the number of views grows. To reduce this cost, SparseVGGT and HeSS sparsify attention at the block level, and both retain blocks with high attention probability. However, we observe that attention probability poorly predicts how much the model's behavior actually changes when a block is removed, and we show that this mismatch is why performance collapses as sparsity increases. In this paper, we propose ReSS (ReSidual-ReStoring Sparse Attention), which recasts block selection from a problem of maximizing the retained attention mass to one of minimizing the drift that sparsification leaves in the residual stream. We introduce a drift score that quantifies how much each block shifts the residual, and, since the drift of a drop set depends on the directions of the contribution vectors rather than on their magnitudes alone, an iterative residual restoration procedure that refines the drop set as a whole. Across three backbones and five datasets, ReSS preserves dense performance better than prior methods at matched sparsity. Two further results support drift as the quantity that governs the cost of sparsification: maximizing drift degrades performance faster than random selection, and plotted against realized drift instead of sparsity, all methods fall approximately onto a single curve. Code is available at https://github.com/libary753/ReSS.

## 一、核心问题与研究背景

- **背景**：VGGT、π3、DepthAnything3 等 3D 视觉 Transformer（3D ViT）能在**单次前向传播**中从多视图图像回归相机位姿与场景几何，其能力来源于对所有视图拼接 token 的**全局注意力**。但该注意力的计算量随视图数**二次增长**，在多视图场景下成为主要计算瓶颈。
- **现有方案**：SparseVGGT 与 HeSS 采用**块级稀疏注意力**——先对 query/key 分块并池化得到块级注意力图，再按**注意力概率大小**（top-k / top-p 或按 head 分配预算）保留高分块，仅对选中块计算精确注意力并重归一化 softmax。
- **核心问题**：作者发现"注意力概率高 ⇒ 移除该块影响小"这一隐含假设**不成立**。直接测量屏蔽单块后注意力输出（经输出投影后）的实际变化量，发现注意力概率与该变化量的 **Spearman 秩相关在层间/头间剧烈波动**（如 layer 18、head 0 仅 0.29），在靠后的层甚至接近或低于随机选择。
- **整体含义**：现有方法"决定保留什么，却不去看它真正想保留的量"。作者将稀疏化在残差流中造成的贡献偏移称为**残差漂移（residual drift）**，并指出概率选择与真实影响的不匹配正是**稀疏度升高时性能崩溃**的根因。据此把块选择从"最大化保留注意力质量"重构为"**最小化残差漂移**"。

## 二、方法论（ReSS）

### 2.1 问题形式化
- 记 $P^h_{ij}$ 为 head $h$ 中 query 块 $i$ 到 key 块 $j$ 的池化注意力概率，$V^h_j$ 为对应池化 value；稠密池化输出 $\bar v^h_i=\sum_{j\in B}P^h_{ij}V^h_j$。
- 含特殊 token（camera、register）的块**始终保留**，仅由 patch key 组成的候选集 $P\subseteq B$。
- 目标：为每个 (query 块, head) 独立求解
  $\min_{D^h_i\subseteq P,\ |D^h_i|=|P|-c_h} J^h_i(D^h_i)$，
  即选择丢弃集 $D$ 使残差漂移平方最小，保留集大小固定为每头预算 $c_h$。
- 该组合优化搜索空间指数级，故分两阶段近似：**漂移分数初选** + **迭代残差恢复**。

### 2.2 块漂移分数（Stage 1）
- **单块屏蔽的精确输出变化**：屏蔽块 $j$ 后 softmax 重归一化，输出变化恰为
  $\tilde v^h_{ij}-\bar v^h_i=\frac{P^h_{ij}}{1-P^h_{ij}}\big(\bar v^h_i-V^h_j\big)$。
- 可分解为三因子：块 value 与稠密输出的偏离 $e^h_{ij}=\bar v^h_i-V^h_j$、注意力概率 $P^h_{ij}$、重归一化因子 $1/(1-P^h_{ij})$。
- 定义**未归一化漂移贡献** $d^h_{ij}=P^h_{ij}e^h_{ij}$；映射到残差空间（经输出投影 head 切片 $W^h_O$）得
  $s^h_{ij}=\|W^h_O d^h_{ij}\|_2=P^h_{ij}\|W^h_O e^h_{ij}\|_2$。
- 实际选择时恢复重归一化因子，取 $\ s^h_{ij}/\max(1-P^h_{ij},\epsilon),\ \epsilon=10^{-4}$，保留分数最高的 $c_h$ 个块作为初始选中集。
- **高效计算**：直接物化 $W^h_O e^h_{ij}$ 会产生 $(n_h, q_{blk}, k_{blk}, d)$ 的巨型中间量。改为在模型加载时**预计算每头 Gram 矩阵** $M^h=(W^h_O)^\top W^h_O$，把平方投影偏差展开为三项低维收缩 $(e^h_{ij})^\top M^h e^h_{ij}$，**精确等价且无逐对向量中间量**。
