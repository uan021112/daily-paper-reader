## 摘要
前馈式三维视觉模型（如 VGGT）已取得显著进展，能够在单次前向传播中统一相机估计与稠密场景重建。然而，其二次方全局注意力使长图像序列的计算开销高昂，而现有稀疏方法可能偏向于注意力高但值冗余的区域。为解决这些局限，我们提出 VASC，一种无需训练的稀疏注意力方法，结合值感知块选择与执行感知的跨层记忆。我们的值感知块选择将池化后的查询—键相关性同相邻值对比度相结合，在减少冗余的同时保留与查询相关且具有区分度的内容。跨层记忆跟踪各层中未被满足的需求，并根据实际执行更新该状态，使此前未被充分服务的块能够在固定计算预算下参与竞争。在 7Scenes 和 NeuralRGB-D 上使用 VGGT 与 $π^3$ 的实验表明，与 FasterVGGT 相比，姿态估计与重建质量均有所提升，同时推理速度最高可达稠密 VGGT 的 $2.29\times$。代码见 https://github.com/kosakayamahoo-design/VASC。

## Abstract
Feed-forward 3D vision models such as VGGT have achieved remarkable progress, unifying camera estimation and dense scene reconstruction in a single pass. However, their quadratic global attention makes long image sequences expensive, while existing sparse methods may favor highly attended yet value-redundant regions. To address these limitations, we introduce VASC, a training-free sparse attention method combining value-aware block selection and execution-aware cross-layer memory. Our value-aware block selection integrates pooled query--key relevance with neighboring value contrast, reducing redundancy while preserving query-relevant and distinctive content. Cross-layer memory tracks unserved demand across layers and updates this state according to actual execution, enabling previously underserved blocks to compete under a fixed computation budget. Experiments on 7Scenes and NeuralRGB-D with VGGT and $π^3$ demonstrate improved pose estimation and reconstruction quality compared with FasterVGGT, together with up to $2.29\times$ faster inference than dense VGGT. Code is available at https://github.com/kosakayamahoo-design/VASC.

# VASC 论文总结

## 1. 核心问题与研究动机

- **背景**：DUSt3R、MASt3R、VGGT、π³ 等前馈式三维视觉模型，可在单次前向传播中统一完成相机估计、深度/点图预测与稠密场景重建。但其全局跨视角注意力随视觉 token 数量呈**二次增长**，长图像序列（多帧输入）代价高昂。
- **现有方案不足**：
  - FlashAttention 等精确注意力核只优化内存访问与硬件利用率，**不决定哪些交互可省略**。
  - 循环/流式模型（Spann3R、CUT3R、Point3R、StreamVGGT、TTT3R、InfiniteVGGT）通过空间记忆或状态处理长输入，但需改变预测架构。
  - 免训练加速方案（Token 合并 FastVGGT、块稀疏 FasterVGGT、层调度 AVGGT）中，**选择准则**仍是关键未解问题。
- **核心洞察（第 3 节的分析）**：仅按注意力权重保留 Top-25% 连接仍会降低重建质量。因为注意力权重刻画的是 query–key **相关性**，而 value 向量才提供聚合**内容**；高注意力区域可能具有局部高度相似的 value（内容冗余），而排名较低的区域反而携带更独特的内容。此外，各层独立选择无法反映"先前分配的需求是否真正被执行"。
- **论文含义**：提出一种**免训练**、即插即用的稀疏注意力选择机制，在固定计算预算下同时考虑"**哪些交互值得计算**"与"**先前分配的需求是否被实际服务**"，在不重训练、不替换骨干预测架构的前提下加速已有几何骨干。

## 2. 方法论

### 2.1 核心思想
- VASC = **值感知块选择（Value-Aware Selection）** + **执行感知跨层记忆（Cross-Layer Memory）**，在固定预算内重新分配块级交互的执行支持，保留原生稀疏核、特殊 token 处理与几何头。

### 2.2 基本定义
- 第 $l$ 层：$i$ 为 query 块，$j$ 为 key/value 子块（稀疏执行单位）；每个 query 有容量 $b_l(i)$。
- 相邻 key/value 子块组成**固定配对** $C(p)$（跨层不变），$p(j)$ 表示含子块 $j$ 的配对；配对共享 value 对比度分数与记忆状态，但子块仍各自作为独立执行候选。

### 2.3 值感知块选择
- 池化 query/key 给出相关性：
  $$A_l(i,j)=\mathrm{Softmax}_j\!\left(\frac{\bar{Q}_l(i)^\top \bar{K}_l(j)}{\sqrt{d}}\right)$$
- 对每个相邻配对，用池化 value 的 **RMS 对比度**作为共享内容信号：
  $$I_l(p)=\tfrac{1}{2}\,\mathrm{RMS}\!\left(\bar{V}_l(j_{p,1})-\bar{V}_l(j_{p,2})\right)$$
- 需求 = 相关性 ⊙ 对比度，再做**比例裁剪** $\Pi_b$：
  $$C_l(i,:)=\Pi_{b_l(i)}\!\left(A_l(i,:)\odot I_l(p(:))\right)$$
  其中 $[\Pi_b(r)]_j=\min(1,\, b r_j/\sum_k r_k)$，保证 $0\le C_l(i,j)\le 1$、$\sum_j C_l(i,j)\le b_l(i)$，使需求与单位执行可比。对比度跨 query 共享，相关性保持 query 特定，均以低成本块级归约实现。

### 2.4 预算内执行
- 将当前需求与有界记忆副本相加后按 query 容量做 Top-K：
  $$P_l(i,j)=C_l(i,j)+\tilde{M}_l(p(j)),\qquad X_l(i,:)=\mathrm{TopKMask}_{b_l(i)}(P_l(i,:))$$
- 二值掩码 $X_l$ 直接传给原生稀疏注意力核；camera/register query 保持稠密注意力，special-only key 块始终保留（不参与 patch-child 预算竞争）。

### 2.5 跨层记忆
- 对 $C_l$、$X_l$ 在 query 块与配对子块上平均，得配对需求 $a_l(p)$ 与服务量 $x_l(p)$（均在 $[0,1]$）；从零开始累积**非负**需求–执行失衡：
  $$M_{l+1}(p)=\left[M_l(p)+a_l(p)-x_l(p)\right]^+,\qquad M_1(p)=0$$
- 需求加、服务减；裁剪防止负值，但"得到部分计算"不必然清零余额。每层每 batch、每 head、每配对仅保留一个标量状态。
- 排序只用**有界副本** $\tilde{M}_l=\Pi_{c_l}(M_l)$，$c_l=\sum_p a_l(p)$；原始余额按上式继续跨层传递。
- 附录给出精确残差记账：定义 $\rho_l(p)=[x_l(p)-M_l(p)-a_l(p)]^+$，则 $M_{l+1}=M_l+a_l-x_l+\rho_l$，并证明 $0\le M_l(p)\le l-1$。该非负递推对应经典排队论记账（Lindley 1952；Neely 2010）。

### 2.6 流程总结
1) 每层用当前 Q/K/V 计算池化相关性；2) 与配对 value 对比度相乘并裁剪得需求 $C_l$；3) 加入有界记忆副本，按容量 Top-K 得执行掩码 $X_l$；4) 掩码送入原生稀疏核执行；5) 依据需求与实际服务更新配对级记忆，传向下一层。

## 6. 主要结论与发现

- 在 S75 下，VASC 在 VGGT 与 π³ 上相对对应稀疏基线**六项指标全面提升**；π³ 在两个稀疏度、两个步长下六项均提升。
- 效率：NRGBD S85 下相较稠密 VGGT 在 A6000 / RTX 4090 上分别获得 **2.22× / 2.29×** 全模型加速，相对 FasterVGGT 仅增加 **1.66%–2.62%** 延迟。
- 稀疏度越高收益越大：NRGBD 上 value 对比度带来的 Acc 改善在 S55→S85 从 5.20% 增至 49.07%（VGGT），π³ 为 3.96%→19.97%。
- 跨层记忆与值感知选择互补：在 π³/NRGBD 上 Full VASC 六项指标均优于任一单组件变体；记忆可使 π³/NRGBD 的 Acc 降 19.79%、Comp 降 11.08%，NC 从 0.831 升至 0.881。
- 泛化：ScanNet-50 上 S75 相对 FasterVGGT 将 ATE、RPE-t、RPE-r、ARE 分别降低 13.98%、14.40%、18.10%、15.15%，Chamfer 基本不变（0.08% 改善，50 场景中 23 个更优）。
- 记忆机制可迁移到其他调度器（FastVGGT 的 token 保护、AVGGT-R），Acc/Comp 多数改善，NC 提升。

## 7. 优点

- **免训练、即插即用**：不改变骨干权重、几何头、特殊 token 处理与原生稀疏核，工程落地成本低。
- **方法论有新意**：将"相关性"（QK）与"内容区分度"（相邻 value 的 RMS 对比度）结合，直指稀疏选择中"高注意力但内容冗余"的盲点。
- **执行感知记忆**：以配对级标量记录"需求–执行"缺口，等价于排队论记账，计算与存储开销极小，且与固定预算 Top-K 兼容。
- **形式化较严谨**：附录给出比例裁剪定义、残差记账恒等式与记忆上界 $0\le M_l\le l-1$ 的归纳证明。
- **实验规范**：容量匹配的配对比较、共享评测器与内核、同 GPU 计时、明确排除受干扰的计时记录且不插补，报告口径较诚实。

- **对失败与边界条件有交代**：明确指出 AVGGT-R 在 90% 服务保留率下出现位姿回退、单子块配对的退化情形、以及布局变化时记忆重置的处理方式，未刻意回避负面结果。

## 8. 不足与局限

- **核心观察的证据强度有限**：第 3 节"注意力权重高 ≠ 内容重要"的论断建立在**单个层、单个注意力头、人工挑选区域**的定性可视化之上，论文自述不构成普遍性或因果结论。这使方法的核心动机缺少系统性的统计支撑（例如跨层/跨头的失配频率分布、失配程度与重建误差的相关性分析）。
- **超参选择存在集合内适配**：FastVGGT 的适配超参在评测所用 7Scenes 集合的子集上选取，而非独立留出集；这可能对基线不利或使比较偏乐观，论文虽予标注但未做留出验证。
- **基线复现的公平性存疑**：AVGGT-R 为作者自行复现，缺少官方实现对照，其性能是否达到原方法上限不可知，因而"VASC 优于 AVGGT-R"的结论需谨慎解读。
- **泛化验证范围偏窄**：跨数据集泛化仅在 ScanNet-50 上验证，且该数据集为室内 RGB-D 场景；缺少户外、大规模、无标定或动态场景的测试，方法在分布外几何结构上的稳健性未知。
- **稀疏粒度固定且较粗**：key/value 子块配对 $C(p)$ 跨层固定不变，意味着选择的分辨率上限被预先锁定；若最优交互结构随层变化（浅层偏局部、深层偏全局），固定配对可能成为瓶颈。论文未消融配对大小或配对策略。
- **记忆机制的表达力受限**：每层每 batch、每 head、每配对仅保留一个标量状态，且上界为 $l-1$。这种极简记账虽高效，但无法区分"哪一类内容未被服务"，也无法表达需求的方向性（例如位置信息 vs 外观信息）。
- **算力披露不完整**：未报告显存峰值、显存占用随帧数的增长曲线、批处理吞吐，也未给出 GPU 数量与总机时。对于声称"长序列高效"的方法，缺少这些数据使实际部署成本难以评估。
- **计时协议规模有限**：输入固定为 518 分辨率、步长 10，仅单序列推理、单卡环境，未测试多卡并行、批内多序列或更长序列（数百帧）下的加速比是否维持；稀疏核的收益通常在更长序列中才充分显现。
- **对稠密骨干的依赖**：方法仍需稠密骨干完成 Q/K/V 投影与块级归约，若骨干本身已采用稀疏/线性注意力，value 对比度信号的可用性需重新论证。
- **缺失计时条目未补齐**：论文明确不做插补（态度诚实），但也导致部分稀疏度下的加速比表格存在空缺，削弱了跨设置趋势的完整性。

## 9. 结论与启示

- **一句话结论**：在固定块级计算预算下，稀疏注意力的选择准则应从"query–key 相关性"扩展到"value 内容区分度 + 跨层需求–执行记账"，VASC 以免训练、即插即用的方式在 VGGT/π³ 上实现了质量提升与近线性加速的双赢。
- **方法层面的启示**：
  - **相关性 ≠ 重要性**。在注意力剪枝/稀疏化任务中，引入 value 侧的冗余度度量（此处为相邻配对 value 的 RMS 对比度）是一条低成本的通用改进思路，可能迁移到 LLM 稀疏注意力、视觉 Transformer token 剪枝等场景。
  - **预算分配应带反馈**。将"应得计算量"与"实得计算量"的差额以排队论形式跨层累积，是一种极轻量的信用分配机制，可视为对"层间独立选择"这一常见简化的修正。
  - **免训练加速仍有空间**。在重训练/架构改造之外，仅优化"选择策略"即可获得可观收益，说明当前前馈式三维重建模型存在明显的内容冗余。
- **实践层面的启示**：对已部署 VGGT/π³ 类几何骨干，VASC 提供了一条不改权重、不改几何头的渐进式升级路径，1.66%–2.62% 的额外延迟换取六项指标全面提升，工程性价比高。
- **未来方向（由局限自然导出）**：
  - 用统计化、跨层跨头的定量证据替代单点定性观察，验证 value 冗余假设的普适性；
  - 让配对粒度或选择粒度随层自适应，突破固定配对的分辨率上限；
  - 将标量记忆扩展为多通道或语义分组的记忆，以表达"哪类内容欠服务"；
  - 在户外/大规模/动态数据集与数百帧长序列上验证加速比与精度的可持续性；
  - 与循环式流模型（Spann3R、CUT3R、StreamVGGT 等）结合，检验选择机制与状态记忆是否互补。

## 10. 总体评价

VASC 是一篇**动机清晰、形式化严谨、实验口径相对诚实**的免训练稀疏注意力改进工作。其最大价值在于把"稀疏选择"这一常被视为工程细节的问题重新形式化：用 value 对比度补足相关性信号的盲区，用跨层需求–执行余额补足层间独立决策的短视，并以极小开销与固定预算 Top-K 兼容。实验在两个骨干、三个数据集、多稀疏度与两步长上给出了容量匹配的配对比较，S75 下六项指标全面提升、近 2.3× 加速的结论具备说服力。

其主要弱点集中在**证据层级**与**验证广度**：核心假设的支撑是定性观察而非统计分析；基线 AVGGT-R 为自复现；超参在评测集子集内选取；泛化限于室内数据集；算力与长序列行为披露不足。因此，方法的**工程可用性**较高，但**科学普适性**仍需更大规模的验证来巩固。
