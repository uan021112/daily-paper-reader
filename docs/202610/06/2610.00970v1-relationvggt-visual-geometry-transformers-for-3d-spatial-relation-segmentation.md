## 摘要
近年来，3D重建的进展已从逐场景优化发展到前馈推理，语义场景理解也紧随其后——然而现有方法仍局限于以物体为中心的感知，忽视了物体之间的空间关系。我们将3D空间关系分割形式化为一种前馈、无需位姿的多视图设定：给定视觉指定的主体和关系文本查询，模型在未获得目标类别名称的情况下跨视图分割目标。为此，我们提出RelationVGGT，一种新颖的前馈框架，它将视觉基础模型的语义特征与3D几何基础模型的几何感知表示相结合，并利用关系Transformer进行以主体为条件的跨视图关系预测——既不需要逐场景优化，也不需要已知相机位姿。我们还提供了基于ScanNet++、使用VLM和LLM构建的全自动标注流水线，从而能够为这一新任务可扩展地生成训练数据。

## Abstract
Recent advances in 3D reconstruction have progressed from per-scene optimization to feed-forward inference, and semantic scene understanding has followed suit -- yet existing methods remain confined to object-centric perception, neglecting spatial relations between objects. We formulate 3D spatial relation segmentation in a feed-forward, pose-free multi-view setting: given a visually specified subject and a relational text query, the model segments the target across views without receiving its category name. To this end, we propose RelationVGGT, a novel feed-forward framework that integrates semantic features from a visual foundation model with geometry-aware representations from a 3D geometry foundation model and leverages a relation transformer for subject-conditioned, cross-view relation prediction -- requiring neither per-scene optimization nor known camera poses. We additionally provide a fully automated annotation pipeline built on ScanNet++ with VLMs and LLMs, enabling scalable training data generation for this new task.

  - **RelationField**：在辐射场上学习物体间关系，但依赖逐场景优化与已标定相机位姿，可扩展性与泛化性受限。

- **整体含义**：该工作把关系推理从"体积搜索 + 场景优化"推向"无位姿前馈 + 逐像素预测"，并配套可扩展的自动标注方案。

## 2. 方法论

### 2.1 核心思想
- 将前作的**体积式关系搜索**重构为**目标视图图像网格上的逐像素关系预测**问题，以参考视图主体为条件，避免测试时的场景特定 3D 场与显式体积重建。
- 定义逐视图关系特征图 $R_t=\{r_t(u)\mid u\in I_t\}$，并将其与语言嵌入空间对齐，从而支持开放词汇的关系查询（特征–文本相似度 → 稠密相关图 → 分割 mask）。

### 2.2 特征提取与融合
- 对每张图像 $I_n$ 提取两路稠密表示：**DINOv2** 语义特征 $E^D_n$（物体级语义）与 **Pi3** 编码器几何特征 $E^P_n$（多视图几何信息，取其任务头之前的 token）。
- 沿通道拼接后经 **Input Mixer**（线性投影 + 带 RoPE 的 Transformer 块）映射为联合 token $F_n\in\mathbb{R}^{P\times d_f}$。

### 2.3 关系预测（Relation Transformer）
- **主体表示**：不压缩为单一池化向量，而是保留参考视图全部 patch token，并用下采样到 patch 网格的主体 mask 做逐元素相乘，得到 $F^s_r=\bar M_s\odot F_r$，保留主体空间布局与细粒度语义。
- 目标视图 token 堆叠为 $Z^0=\text{Concat}(\{F_t\})$，经 $L$ 层关系 Transformer，每层**交替**执行：
  - 主体条件交叉注意力：$\bar Z^\ell=\text{CrossAttn}^\ell(Z^\ell, F^s_r)$
  - 多视图全局自注意力：$Z^{\ell+1}=\text{SelfAttn}^\ell(\bar Z^\ell)$
- 输出经 **DPT head** 的 mask decoder 上采样为像素对齐的关系特征图 $R_t=\text{Dec}(Z^L_t)$，与语言嵌入空间对齐。

### 2.4 3D 几何
- 用 Pi3 的 point decoder 预测每视图的 point map 与 confidence map；由于 $R_t$ 像素对齐，每个关系特征可关联到对应 3D 点，形成**置信度感知的跨视图 3D 关系表示**。

### 2.5 训练目标
- 观察到同一空间关系可有多种有效表述（"standing on"≈"on"≈"supported by"），故不视为单标签分类，而是**多查询监督**。
- 每个兼容查询独立用 sigmoid focal loss，叠加 Dice loss：
  $L_{\text{mask}}=w_{\text{focal}}L^{\text{multi-q}}_{\text{focal}}+w_{\text{dice}}L_{\text{dice}}$
- 附录给出细节：$\alpha=0.75,\ \gamma=1.5$；多查询 focal 与 Dice 分别对查询集 $Q$ 取平均。

### 2.6 推理
- 关系 logit：$z_t(u;q)=r_t(u)^\top e(q)$；分数 $S_t=\text{sigmoid}(z_t)$；无需正/负文本嵌入的 softmax 归一化；固定阈值 $\tau=0.3$ 得到二值 mask，无额外后处理。

### 2.7 数据生成流水线
- 基于 **ScanNet++**（含 3D 实例级点标注）构建全自动标注：
  1. 初始化以实例为节点、边为空的场景图；
  2. 将实例 mask 投影到 RGB 帧，用 **Set-of-Mark (SoM)** 提示查询 **VLM（Qwen3-VL-8B）** 获取逐帧关系提案；
  3. **多视图一致性过滤**：同一物体对至少 K=3 帧一致才保留，并传播到所有共视帧；
  4. **几何过滤**：用 3D 包围盒与实例质心剔除几何上不合理的关系（如远距离接触/支撑）；
  5. **LLM（GPT-5.2）改写**：将验证过的三元组改写成多样化的自然语言表述，提升查询多样性（如 "hanging on"→"mounted on"）。
- 文本查询编码使用 **Jina Embeddings v3**（沿用 RelationField）。

## 6. 主要结论与发现

- **主结果**：平均 **mIoU 0.382 / mAcc 0.549**，显著优于最强基线 RelationField（0.303 / 0.480）。
  - Replica：0.446 / 0.640；ScanNet++：0.445 / 0.675；LERF：0.254 / 0.332。
- **在 Replica 与 ScanNet++ 上全面领先**，说明在相机轨迹覆盖整个室内场景、开放词汇分割更困难的条件下具有鲁棒性。
- **LERF 上所有方法均偏低**（

0.254 / 0.332，本方法最低），论文归因于 LERF 场景以物体为中心的语义标注为主、空间关系标注稀疏，且其帧采样与关系覆盖不匹配，导致关系信号弱；但即便在该数据上，本方法仍以 mAcc 略优于 RelationField†，说明关系特征本身有效，瓶颈在数据分布而非方法。
- **视频基础模型对比**：在按相机基线划分的 Small/Medium/Large 三组中，本方法均领先；视频基线在大基线（Large）下退化明显，因为它们依赖 2D 时序对应，缺乏显式 3D 几何约束，视角跨度增大时主体与目标物体的对应关系断裂。
- **3D referring 分割对比**：MVGGT、ReferSplat 等按原生接口适配后表现有限，主要因为其文本接口面向"类别/属性描述"而非"空间关系谓词"，且需要目标物体类别线索；本方法在无类别名条件下仍能定位关系目标。
- **消融结论**：
  - **输入特征**：DINOv2 语义 + Pi3 几何双路拼接优于任一单路，也优于直接用 Pi3 任务头输出；说明几何 token 提供了跨视图对应所需的空间锚点，而语义 token 提供开放词汇判别力。
  - **关系解码器**：交替执行"主体条件交叉注意力 + 多视图全局自注意力"优于纯自注意力、纯交叉注意力，以及将主体池化为单一向量的做法；后者丢失主体空间布局，在主体与目标相邻或部分遮挡时定位退化。
  - **训练目标**：多查询 focal + Dice 优于单查询监督与纯 focal；多查询监督使模型对同义表达更稳健，避免把"语义等价"误判为负样本。
  - **标注流水线**：去掉多视图一致性过滤或几何过滤均导致 mIoU 下降，说明自动标注中的噪声若不剔除会污染关系监督。
- **鲁棒性结论**：
  - 主体 mask 从 GT 逐步退化到自动 grounding 时性能平滑下降，说明方法不依赖完美主体 mask；
  - 同义改写查询性能基本持平，罕见/未见谓词仅小幅下降，表明关系特征空间具有一定组合泛化能力；
  - 意义改变控制（不兼容关系、替换目标物体）导致性能大幅下降，证明模型确实读取并利用了关系文本语义，而非仅凭主体位置猜测；
  - 主体跨视图不可见时性能下降但仍高于随机，说明模型能借助几何先验与场景上下文部分推断关系目标。
- **效率结论**：查询推理 26 ms 对比 RelationField 的 288 s + 数小时优化，具备数量级的实用优势，使关系分割首次具备前馈实时部署的可能。
- **人工审计结论**：25 个场景、4,695 条关系提案的双标注者审计显示自动标注与人工判断高度一致（Cohen's κ 较高，场景级 cluster bootstrap 置信区间支持该结论），说明流水线可扩展性成立。

## 7. 局限性与未来方向

- **关系类型覆盖有限**：当前谓词集中于接触/支撑/相邻等静态空间关系，对动态、时序、功能性关系（如"可放入""用于支撑"）尚未覆盖。
- **数据规模与场景多样性**：训练与评测均以 ScanNet++ 室内场景为主，跨域（室外、工业、驾驶）泛化未验证；基准本身查询数偏少（总计 119），统计功效受限。
- **依赖 VLM/LLM 标注**：标注质量受 Qwen3-VL-8B 与 GPT-5.2 能力上限约束，长尾谓词可能被系统性遗漏或误标；多视图一致性阈值 K=3 与几何过滤规则为经验设定，未做敏感性分析。
- **几何表示精度**：依赖 Pi3 的 point map 与 confidence map，在弱纹理、透明/反光表面或大尺度场景下几何置信度可能下降，进而影响关系特征的 3D 锚定。
- **语言对齐方式**：采用固定文本编码器（Jina v3）+ 相似度阈值 τ=0.3，未做端到端语言–关系特征联合训练，谓词表述的细微差异可能未被充分建模。
- **未来方向**：扩展到动态/时序关系、引入关系组合推理与多主体多目标查询、探索端到端可微的关系–语言对齐、以及在更大规模与跨域数据上验证前馈关系分割的可扩展性。

## 8. 总体评价

- **贡献层面**：论文将物体间空间关系推理从"逐场景优化 + 已标定位姿"的范式推进到"无位姿前馈 + 逐像素预测"，提出新任务定义、新模型架构（RelationVGGT）与可扩展自动标注流水线，三者相互支撑，问题设定清晰且具有现实意义。
- **方法层面**：以 VGGT 类几何基础模型为骨架，将关系搜索重构为图像网格上的逐像素关系预测，配合保留主体空间布局的条件注意力与多视图全局注意力，设计简洁、动机明确；多查询监督与语言嵌入对齐使开放词汇关系查询成为可能。
- **实验层面**：对比基线覆盖面广（特征场、视频基础模型、3D referring），消融与鲁棒性分析较系统，含意义保持/意义改变对照与人工审计，方法学严谨；主要不足是基准规模偏小、部分子集样本过少、LERF 上未取得领先。
- **实用性层面**：26 ms 查询推理与无需位姿的输入形式，使其相较 RelationField 等逐场景优化方法在部署成本上具备数量级优势，具备向空间问答、具身智能体等下游任务迁移的潜力。
- **结论**：RelationVGGT 为 3D 空间关系分割提供了可行且高效的前馈基线，开辟了"几何基础模型 + 关系推理"的交叉方向；若能在更大规模、跨域数据与更丰富关系类型上进一步验证，有望成为整体场景理解的重要组件。
