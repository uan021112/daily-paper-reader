Abstract. Illusory matches between distinct yet visually similar 3D
surfaces—doppelgangers—remain a fundamental obstacle for large-scale,
in-the-wild 3D reconstruction and visual localization. Prior work mit-
igates this issue with pairwise classifiers, but this design limits multi-
view contextual reasoning and incurs O(n2) inference complexity for
downstream structure-from-motion (SfM). We present MVDG, a scal-
able multi-view disambiguation framework built on the 3D foundation
model VGGT, which jointly reasons over an arbitrary number of multi-
view images. By incorporating 3D-aware multi-view features, our method
reduces dependence on pairwise comparisons by encoding and decoding
views in a single pass. We further observe that direct multi-view fine-
tuning of VGGT can be unstable under noisy supervision; motivated by
label ambiguity in Doppelgangers, we construct a pseudo-pairwise train-
ing set from AerialMegaDepth and show that fine-tuning on sampled
subsets yields stable optimization and strong generalization to held-out
scenes. Finally, because full SfM evaluation (even with faster pipelines

Recovering coherent 3D structure from multi-view imagery is a central goal in
computer vision. Conventional pipelines rely on hand-crafted local features and
robust 2D correspondence estimation for 3D point reconstruction in Structure-
from-Motion (SfM) and Multi-View Stereo (MVS) [4,11,12,15]. In contrast, re-
cent data-driven approaches [19–21] largely bypass explicit 2D feature matching
by tokenizing images and decoding geometry in a feed-forward manner, enabling
direct inference of 3D properties (e.g., camera parameters, depth, tracking) with-
out iterative optimization. Despite their different paradigms, both families re-
main vulnerable to the doppelgangers problem: when non-covisible viewpoints
capture visually similar surfaces, the model may incorrectly match those views
and reconstruct inconsistent geometry. This bottleneck has long hindered down-
stream tasks and real-world deployments.
A natural formulation treats doppelganger detection as binary classification:
image pairs with sufficient covisibility (i.e., overlap in visible 3D points) and

rigid transformations are labeled true, and pairs below a threshold are labeled
false. [1] trains a pairwise classifier to reject non-covisible image pairs using
differentiable feature evidence; the filtered image sets can then be passed to
downstream 3D pipelines such as COLMAP [11, 12]. To leverage pre-trained
3D foundation models, [22] incorporates feed-forward 3D features from [6] for
pairwise disambiguation. While effective, pairwise designs underuse multi-view
constraints and scale poorly in large-scale image collections, where cross-view
consistency can expose aliasing contradictions (Fig. 2). They also incur substan-
tial inference overhead when enumerating all candidate pairs.
We address these limitations with MVDG, a scalable multi-view 3D disam-
biguation framework built on VGGT [19]. First, we bridge the data gap be-
tween pairwise supervision and multi-view inference. Both Doppelgangers and
VisymScenes are pairwise datasets [1,22]; we convert them into coarse multi-view
groups by transferring positive pair labels to anchor-centric neighborhoods. How-
ever, annotation noise in Doppelgangers introduces ambiguity (Sec. 10), which
makes convergence less stable. We therefore derive a pseudo-pairwise dataset
from AerialMegaDepth [17] and show that fine-tuning on these subsets improves
training stability and generalization to held-out scenes. Since end-to-end SfM
validation at each checkpoint is prohibitively expensive, we also establish an
empirical relationship between pseudo-pairwise classification accuracy and SfM
metrics (e.g., inlier ratios), yielding a practical proxy for monitoring convergence.
Second, to accelerate inference, we train a confidence-based early-exit module
that avoids unnecessary deeper-layer computation when early encoder and de-
coder features already provide reliable predictions. Overall, this design reduces
SfM-stage runtime by approximately 40%.
In summary, our contributions are:
1. We present MVDG, a scalable multi-view 3D disambiguation framework
built on VGGT, and augment pairwise training resources with pseudo-pairwise
supervision from AerialMegaDepth to improve training stability and gener-
alization.
2. We establish an empirical relationship between pseudo-pairwise classification
accuracy and downstream SfM metrics (e.g., inlier ratio), enabling practical
validation without running full SfM.
3. We introduce an early-exit inference strategy that halts unnecessary deeper-
layer computation when confidence is sufficient, reducing runtime overhead
by ∼40% on SfM evaluation.

Related Works
Classical SfM/MVS and the limits of 2D matching. Early pipelines for image-
based 3D reconstruction—typified by COLMAP—combine robust local feature
detection and matching (e.g., SIFT) with incremental Structure-from-Motion
(SfM) and dense Multi-View Stereo (MVS) [8,11,12]. COLMAP remains a stan-
dard open-source baseline; its core contributions include robust incremental SfM
and pixelwise view-selection MVS with strong completeness and accuracy across

datasets. These systems scale to large, unordered photo collections and set com-
petitive baselines on multi-view depth and point-cloud benchmarks [13]. How-
ever, classical pipelines rely on 2D correspondences [3, 10, 23] and are vulnera-
ble to visual aliasing—repetitive or near-duplicate textures—which can trigger
catastrophic misassociations and broken reconstructions. Recent learned match-
ers improve robustness and efficiency, including SuperPoint [2], attention-based
SuperGlue [10], and detector-free LoFTR [16]. Still, under severe symmetry and
repetition, short-range 2D evidence alone remains insufficient.
Learned multi-view geometry and feed-forward 3D backbones. Recent feed-forward
3D geometry networks directly infer scene attributes from raw images, moving
beyond iterative geometric optimization loops. [21] casts pairwise reconstruction
as camera-agnostic point-map regression, enabling robust wide-baseline align-
ment without priors.
[6] further grounds matching in 3D by augmenting [21]
with dense local features and a fast reciprocal matcher, improving both accuracy
and speed on challenging localization benchmarks.
[18] introduces a spatial-
memory mechanism that predicts per-image point maps in a global coordinate
frame, eliminating post-hoc global alignment and inferring frame sequences in
real time. In parallel,
[20] models a persistent state with a continuously up-
dated transformer, producing metric point maps online as new views arrive.
Most recently, VGGT generalizes this paradigm from one to hundreds of views
and directly predicts camera parameters, multi-view depth, dense point maps,
and 3D tracks [19]. Despite these gains, computation scales unfavorably with the
number of frames because multi-view attention is quadratic in tokens. A concur-
rent study accelerates VGGT via token-redundancy reduction [14], but it does
not explicitly address doppelgangers because ambiguous patch mismatches are
not modeled. We take a complementary route: confidence-conditioned, depth-
adaptive computation for multi-view disambiguation.
Visual aliasing and Doppelgangers.
[1] formalized the Doppelgangers problem
and proposed a pairwise classifier trained on a curated dataset, where posi-
tive/negative supervision is tied to covisibility and relative rigid-transformation
consistency, using keypoints and matches to estimate affine consistency cues. [22]
improved robustness by leveraging 3D-aware features from [6] within a trans-
former classifier and demonstrated gains when integrating into SfM pipelines
across real-world scenes. These works, however, remain pairwise: they do not
exploit the richer geometric constraints available when more than two views are
jointly encoded, and consequently may under-utilize multi-view redundancy that
can disambiguate aliasing. SALAD [5] serves as a strong 2D retrieval baseline in
our comparisons, isolating the gap between global visual similarity and strict 3D
covisibility disambiguation. Our approach targets this gap by operating directly
on a multi-view 3D backbone, aggregating layer-wise tokens across arbitrary
numbers of frames.

Preliminaries
Our method builds on VGGT [19], a 3D foundation model that supports di-
verse downstream geometry tasks. Given a set of multi-view images, VGGT
predicts task-dependent 3D attributes through lightweight decoder heads. The
backbone is a transformer encoder with L = 24 attention blocks, each combin-
ing frame attention and global attention. Initialized from DINOv2 [9] features,
the network transitions from local 2D correspondence cues in shallow layers to
stronger geometric reasoning in deeper layers. Consequently, tokens aggregated
from selected layers (default: 4, 11, 17, 23) provide rich multi-scale information
for downstream decoding. However, for disambiguation, it remains unclear which
layers best separate visually ambiguous but non-covisible image pairs.

4.1
Overview
Given an unordered image set I = {Ii}N
i=1 of a static 3D scene, our task is
to output covisibility by predicting a binary classification label si,j ∈{0, 1} for

pairs (Ii, Ij). We input all views through a frozen VGGT encoder to obtain layer-
wise multi-view tokens. After each encoder block, a decoder takes the patch-wise
tokens as input and learns to output patch features capable of disambiguation.
The decoded features are pooled into a global descriptor vector f(I) within the
scene context for each input image. Pairwise features formed from (f(Ii), f(Ij))
are classified by an MLP head together with a confidence-driven early-exit mod-
ule. If the confidence exceeds a threshold, we halt further encoding and take the
current prediction as the final decision; otherwise, we continue into later lay-
ers. This difficulty-adaptive depth reduces computation for easy cases while still
leveraging deeper-layer tokens for challenging ones.
4.2
Multi-view Supervision from Pairwise Data
Existing doppelganger datasets are pairwise [1,22]. The raw input lists pairs for
a given anchor image, with between 2 and 88 images paired to the same anchor.
We therefore organize the data as a dictionary indexed by image, where each key
Ii maps to the set of its paired images {Ij} along with their labels yi,j ∈{0, 1}
(both positive and negative). This preserves the original pairwise supervision
while exposing an anchor-centric multi-view neighborhood during training.
Pseudo-pairwise supervision. For large-scale multi-view scenes, we derive pseudo-
pairwise labels using geometric overlap computed from available 3D or camera
information. We define a covisibility ratio

Relationship between pseudo-pairwise accuracy and SfM inliers
We use pseudo-pairwise labels to measure classification quality on held-out scenes
and relate it to downstream SfM outcomes. Let S denote a set of scenes and Ps
the evaluated image pairs in scene s.
Motivation. We observe that even after pairwise classification training and val-
idation converge, SfM accuracy (e.g., inlier ratios) can remain unstable and os-
cillate between high and low values during training. Running full SfM evalu-

GLOMAP) and can exceed GPU memory. We therefore study a correlation be-
tween pseudo-pairwise accuracy and SfM inlier ratio as a lightweight proxy: when
pseudo-pairwise accuracy is high, downstream SfM accuracy tends to be high as
well. This provides a practical signal to visualize and validate convergence on
the SfM task without running the full pipeline each time.

Training Dataset
We follow [22] and train our models on a union of Doppelgangers (DG) [1],
MegaDepth [7], and VisymScenes [22]. The training split comprises 1,184 scenes
with 171,498 positive and 171,508 negative image pairs. To standardize resolution
while preserving aspect ratio, images are resized to a fixed width W = 518 and
height H

5.2
Implementation Details
We train with a batch size of 8 and keep the VGGT encoder frozen. For each
encoder layer, a lightweight two-layer DPT head produces per-image descriptors,
which are fed to the scoring head described in Sec. 4.3, along with an early-exit
confidence head. The decoder/channel dimension is set to 1024 with 8 attention
heads. We use gradient accumulation of 8 steps for stable training. The learning
rate to train the first stage starts at 1×10−4 and follows a stepped schedule
down to 1×10−5 by the end of each epoch; for the second stage, the learning
rate decays from 1×10−5 to 1×10−6 within a 5000-step schedule. Unless otherwise
noted, all experiments are conducted on 2× NVIDIA H100 GPUs. We train the
similarity scoring head (Sec. 4.3) with focal loss (gamma= 1) and the confidence
head (Sec. 4.4) with binary cross-entropy (BCE) loss.

We also benchmark against the state-of-the-art VPR method SALAD [5] on
the same test set. Because SALAD outputs a static global descriptor for each
image, we perform a 200-step threshold sweep over cosine similarity to select the
operating point that maximizes F1 on the test dataset; at the optimal threshold
(0.3171), SALAD still yields more false positives and false negatives than both
Doppelgangers++ and our method (Tab. 1). This gap reflects a mismatch in
objective: VPR pipelines optimize global descriptor retrieval in 2D and are not
explicitly trained to resolve ambiguous 3D geometry. Without modeling multi-
view geometric consistency, 2D descriptors can be deceived by visually similar,
non-covisible structures prevalent in our benchmark.

Conclusion
In this work, we addressed multi-view 3D disambiguation with a confidence-
driven early-exit framework built on a strong feed-forward backbone. By lever-
aging selective intermediate-layer tokens from a frozen VGGT encoder and cou-
pling them with a lightweight decoder-classifier, we show that many scenes can be
disambiguated confidently before the deepest layers. This reduces computation
and often improves accuracy by avoiding overly invariant deep representations
that can reintroduce ambiguity. Our approach complements both 2D retrieval
pipelines and pairwise 3D-feature methods, offering competitive disambiguation
accuracy with stronger scalability and runtime efficiency in multi-view settings.
Future work includes tighter integration with downstream SfM/MVS pipelines
for closed-loop filtering, as well as extensions to streaming video and active view
selection. We also plan to audit and correct annotation errors in Doppelgangers,
and to release improved multi-view disambiguation datasets for the community.

Permutation-invariant Classification
We observe that classification accuracy degrades significantly when the input
image order is shuffled at test time. A likely reason is that some images are more
often used as reference views during dataset construction. To mitigate this issue,
we enforce permutation invariance in three ways. First, during sampling we ran-
domly swap the two images in each pair with probability 0.5, exposing the model
to both orderings throughout training. Second, we construct a symmetric pair
feature as in Eq. 4; specifically, absolute difference and element-wise product are
permutation invariant. Third, instead of attention pooling (which can implicitly
encode ordering), we use permutation-invariant average pooling over patches to
obtain frame descriptors.

Implementation Details
VGGT backbone aggregator. We reuse the VGGT encoder as a frozen backbone.
Given a batch of B images and S frames per scene, the aggregator produces a
list of per-layer token tensors
  \{\ma
thbf
 {X} ^ {(l)}\ }_{l=1}^{L}, \quad \mathbf {X}^{(l)} \in \mathbb {R}^{B \times S \times P \times C}, 
and a patch start index indicating the token range corresponding to image
patches. We use up to layer 23 when constructing the head inputs. We ob-
serve that training can become unstable when deeper-layer encodings are added
indiscriminately. Therefore, we early-stop stage 1 and then train stage 2 (the
early-exit module). Using earlier encoding layers for easier cases yields more
stable performance.
Classification head. For each selected encoder layer index l, patch tokens are
first projected to a decoder dimension via a per-frame linear layer, augmented
with a learned layer positional embedding. We then apply a stack of PyTorch
TransformerDecoderLayers per selected layer, with positional encoding over
patches. We decode tokens from each layer independently following VGGT. We
then reduce the layer dimension by summation followed by LayerNorm, and
reduce the patch dimension with average pooling. A final MLP classifier maps
each frame descriptor to logits over two classes (false and true).
Because the training dataset provides only pairwise images, the classifica-
tion head outputs y ∈RB×2×2, corresponding to two frames and two classes.
At test time, when more than two images are provided, the same head can op-
tionally output y ∈RB×(S−1)×2×2, representing anchor-versus-others pairwise
predictions.

Limitations
We present failure cases in Fig. 12. Our pipeline is weaker in four scenarios.
First, large domain shifts between input images (e.g., capture time, season, or
color processing) reduce robustness, likely because VGGT was trained primarily
on static-scene reconstruction within narrower domains. Fine-tuning the VGGT
encoder on this data can partially mitigate this issue, as shown in the main
paper. Second, if one image in a pair is an extreme zoom-in, finding reliable
correspondences becomes difficult. Third, ground-truth labels can be ambigu-
ous. As described in [1], Doppelgangers relies on coarse directional labels (e.g.,
north/south), without strict geometric rules such as treating viewpoint differ-
ences greater than 90◦as false pairs. Consequently, in the third row (Vaguely
Labeled), two pairs with similar visual offsets (about 45◦) receive different labels.
