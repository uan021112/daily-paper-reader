## 摘要
近期，Depth Anything 3（DA3）等深度基础模型在多视角深度估计方面取得了显著成果，但其假设场景为静态3D场景，这限制了它们在真实动态环境中的适用性。现有的免训练4D方法（如Easi3R和VGGT4D）依赖经过对应关系训练的主干网络，其注意力机制编码了跨帧匹配信息，而DA3等仅深度模型不具备这一特性。我们提出Dyna3，一个免训练框架，无需任何微调即可扩展DA3用于4D动态场景重建。我们的关键洞见是，DA3的跨视角特征虽然仅针对深度一致性进行训练，但当与跨帧最佳匹配特征搜索相结合时，会隐式编码运动判别信号。其静态表面能够在全局找到一致的匹配，而动态物体则不能。我们进一步采用视觉语言模型（VLM）自动为SAM 3生成场景特定的语义提示，从而实现精确的实例级分割，区分哪些物体在运动、哪些物体存在。在重建方面，我们将场景解耦为跨帧对齐的静态背景和逐帧动态点云。在四个数据集上的实验表明，Dyna3在动态物体分割上以+5.5pp的J-Mean超越当前最先进的VGGT4D，并优于经过对应关系训练的方法，同时位姿估计速度最高提升13倍，4D重建速度提升3倍，内存降低4至8倍。因此，Dyna3能够支持此前方法无法实现的更密集时间采样。

## Abstract
Recent depth foundation models like Depth Anything 3 (DA3) achieve remarkable multi-view depth estimation but assume static 3D scenes, limiting their applicability to real-world dynamic environments. Existing training-free 4D methods like Easi3R and VGGT4D rely on correspondence-trained backbones whose attention encodes cross-frame matching, a property absent in depth-only models like DA3. We present Dyna3, a training-free framework that extends DA3 for 4D dynamic scene reconstruction without any fine-tuning. Our key insight is that DA3's cross-view features, though trained only for depth consistency, implicitly encode motion-discriminative signals when combined with best-match feature search across frames. Its static surfaces find consistent matches globally, while dynamic objects cannot. We further adopt vision-language models (VLM) to automatically generate scene-specific semantic prompts for SAM 3, enabling precise instance-level segmentation that distinguishes which objects move from what objects exist. For reconstruction, we decouple the scene into a cross-frame aligned static background and per-frame dynamic point clouds. Experiments on four datasets demonstrate that Dyna3 surpasses correspondence-trained methods with +5.5pp J-Mean over state-of-the-art VGGT4D on dynamic object segmentation, while achieving up to 13x faster pose estimation and 3x faster 4D reconstruction with 4 to 8x lower memory. Dyna3 could therefore enable much denser temporal sampling that prior methods cannot support.

## 1. 核心问题与研究背景

- **研究动机**：单目视频的动态 3D 场景重建是自动驾驶、AR、机器人等领域的基础问题，但主流 3D 重建流程普遍假设世界是刚性的、静态的。
- **现有深度基础模型的局限**：Depth Anything 3（DA3）基于冻结的 DINOv2 骨干 + 双 DPT 头，单次前向即可联合预测深度、相机射线与位姿，参数量仅约 135M（远小于 DUSt3R/VGGT 的 571M–1.3B），效率极高；但它只在静态场景上训练，直接用于动态场景会把运动物体当作静态几何，破坏场景结构与相机轨迹。
- **两条既有路线都无法直接套用**：
  - 路线一（免训练，如 Easi3R、VGGT4D）：从**对应关系训练**的骨干（DUSt3R、VGGT）的注意力图中挖掘运动线索，但计算开销大，且依赖注意力中编码的跨帧匹配特性。
  - 路线二（如 MonST3R）：在动态数据上微调 DUSt3R，引入显式跟踪损失，带来训练成本与数据集依赖。
- **关键矛盾**：DA3 只用几何目标（L_depth、L_ray、L_pcd、L_pose）训练，没有对应关系监督（无 L_track），其注意力图编码的是深度关系而非匹配模式。直接套用注意力式运动检测仅能得到约 **8% J-Mean**（接近随机）。
- **核心问题**：能否在不微调、不牺牲效率的前提下，把纯深度的 DA3 扩展到免训练 4D 动态重建？

## 2. 方法论

### 2.1 核心思想
- DA3 的 patch 特征虽为深度回归训练，但仍隐式编码**外观信息**，可用于跨帧匹配。
- 静态表面无论相机如何运动，都能在邻帧中全局找到一致匹配；动态物体因运动破坏跨帧一致性，匹配分数低。
- 由此提出**最佳匹配特征搜索（best-match feature search）**作为运动信号，并叠加 **VLM 语义引导**来区分"哪些物体在动"与"场景中存在哪些物体"。

### 2.2 四阶段流程

**阶段一：DA3 几何提取**
- 从 DA3 获取逐帧深度 D_i、稠密射线图，以及 DPT 解码器输出的特征图 F_i ∈ R^{h×w×C}。
- 相机位姿采用**射线图 + RANSAC 分解**得到外参 E_i ∈ SE(3) 与内参 K_i（作者发现比 camera-token head 更稳健）。
- 反投影公式：X_i(u) = E_i · π⁻¹(u, D_i(u); K_i)，把所有像素提升到统一世界坐标系。

**阶段二：最佳匹配搜索得到运动分数**
- 对帧 i 中位置 u，在时间邻域 N_i 内逐帧寻找余弦相似度最高的匹配位置。
- 运动分数定义：S_i(u) = 1 − (1/|N_i|) Σ_{j∈N_i} max_{u'∈Ω_j} ⟨f_i(u), f_j(u')⟩ / (‖f_i(u)‖‖f_j(u')‖)。
- 高 S_i(u) 表示无法找到好匹配，可能是动态；逐帧归一化（应对场景相关的相似度分布），以 τ 阈值化，取最大连通分量抑制孤立噪声，得到粗运动先验 Φ_i ∈ {0,1}^{H×W}。
- 该先验在空间上较粗糙，只定位"哪里可能有运动"，不提供物体边界。

**阶段三：VLM 引导的实例分割**
- 不用"person"/"vehicle"这类固定类别标签（会同时命中静止与运动实例），而是用运动先验裁剪出关键帧区域，交给 VLM 生成**场景特定提示**：P = V(crop(I_key, Φ_i), ρ)。
- 提示词设计为输出具体描述性名词短语（如 "cyclist"、"dog"），而非宽泛类别。
- 提示送入 SAM 3 做视频实例分割，得到候选掩码 {M^k_i}；通过缓存视频特征、只清除提示相关状态，实现 **4× 加速**。

**阶段四：运动感知的动态实例选择**
- 对每个候选实例 k，计算动态分数 µ(k) = mean_{u∈M^k_i} S_i(u)。
- µ(k) > θ 的实例判为动态；若全部低于阈值，则强制选取分数最高的实例。
- 合并选中实例得到逐帧动态掩码 M_i = ∪_{k: µ(k)>θ} M^k_i。

**阶段五：解耦式 4D 重建**
- **静态背景**：掩码先膨胀 δ 像素形成安全边界（缓解掩码边界不齐导致的"鬼影"），非动态像素投影到 3D 后聚合为统一点云，再经体素网格下采样合并冗余观测：X^stat = Voxel_v(∪_{i=1}^N {X_i(u) : u ∉ M̃_i})。
- **动态前景**：不能跨帧合并，逐帧保留独立点云 X^dyn_i = {X_i(u) : u ∈ M_i}，顺序渲染即形成动画。
- **相机位姿**：由 DA3 射线图经 RANSAC 分解得到；静态点云作持久背景，动态点云按时间戳叠加。
- 整条流水线**不修改 DA3 的任何权重或结构**。

## 6. 主要结论与发现

- **动态分割**：DAVIS-2016 上 65.04% J-Mean，超 VGGT4D **+5.5pp**、超 Easi3R **+16.1pp**；F-Mean 超 VGGT4D **+11.5pp**。DAVIS-2017 上 J-Mean +2.3pp、F-Mean +11.4pp，验证了 SAM 3 边界精度优于点云式掩码。
- **相机位姿**：TUM-dynamics 上 RTE/RRE 排名第二，比 VGGT4D 快 **2.9×**、省 **5.3×** 内存；Sintel 上取得**最优 RTE**，比 VGGT4D 快 8.6×、比 Easi3R 快 67×。
- **效率 → 精度**：TUM-dynamics 上 stride 从 30 降到 3，RTE 改善 5.8×、RRE 改善 5.5×；此时 VGGT4D 因二次方内存增长**OOM**，Dyna3 仍能以 15.6s / 24.7GB 完成。Sintel 上 stride 3→1，RRE 改善 7.5×。
- **4D 重建**：DyCheck 上 Accuracy/Completeness 均列第二，优于所有微调方法；比 VGGT4D 快 3.2×、省 4.5× 内存，比 Easi3R 快 10.2×、省 3.2× 内存。
- **机理结论**：DA3 的注意力确实不编码运动信号（约 8% J-Mean），而显式特征比较（29.65%）证明其 patch 特征仍含可用外观信息；语义引导对消除"运动 vs 纹理变化"的混淆是必要的。

## 7. 优点

- **免训练、零微调**：不改动 DA3 权重与架构，直接复用现成基础模型，落地成本低。
- **方法直觉清晰且可解释**：用"静态面能在全局找到匹配、动态物体找不到"这一简单假设替代对注意力机制的依赖，规避了深度模型无对应关系监督的根本缺陷。
- **VLM 提示场景自适应**：不依赖人工类别先验，能生成 "cyclist"、"dog" 这类细粒度提示，比固定类别更可区分同类中的动/静实例。
- **工程优化实在**：SAM 3 视频特征缓存带来 4× 加速；体素合并 + 掩码膨胀处理点云冗余与边界泄漏。
- **解耦设计提升鲁棒性**：动态区域的重建误差不会污染占场景多数的静态背景，避免了错误匹配的误差累积。
- **效率优势转化为精度优势**：这是全文最有说服力的论证——Dyna3 能跑更密的时间采样，从而在 VGGT4D 已 OOM 的设定下取得可用位姿，且为延迟敏感/离线高精度两类场景提供了可调旋钮。

## 8. 不足与局限

- **动态重建的时间一致性受限**：逐帧动态点云不做跨帧对应，时序连贯性弱于用对应关系跟踪的 VGGT4D，重建指标（Accuracy 0.065 vs 0.022、Distance 0.180 vs
