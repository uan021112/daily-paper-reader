## 摘要
我们提出 VGGT-Diff，一种用于稀疏视角新视角合成的几何路由多视图扩散模型。现有的新视角合成（NVS）方法面临一个根本性权衡：基于重建的方法能够保留已观测几何，但难以合成未见区域；而基于扩散的方法提供了强大的生成先验，却依赖隐式的源到查询对应关系。VGGT-Diff 通过将来自 VGGT-Ω 的视觉几何潜变量路由到预训练视频扩散模型中，弥合了这两类范式。每个视觉 token 都与一个 3D 点和置信度相关联，随后通过置信度感知的视觉几何路由器（VGR）转换为查询对齐的潜在条件，该路由器保留前表面和后表面的证据。这些条件引导联合目标视图去噪，而点-轨迹残差一致性（PTRC）沿可靠 3D 轨迹对预测的干净残差进行正则化，从而提升多视图稳定性。我们进一步引入鲁棒的几何条件化，将训练时正则化与推理时引导相结合，以提升稳健性。实验表明，在不同视角难度下的插值与外推任务中，其性能具有竞争力或达到当前最优水平。我们的代码可在 https://github.com/chenkangjie1123/VGGT-Diff 获取。

## Abstract
We present VGGT-Diff, a geometry-routed multi-view diffusion model for sparse-view novel view synthesis. Existing novel view synthesis (NVS) methods face a fundamental trade-off: reconstruction-based approaches preserve observed geometry but struggle to synthesize unseen regions, while diffusion-based methods provide strong generative priors yet rely on implicit source-to-query correspondence. VGGT-Diff bridges these regimes by routing visual geometry latents from VGGT-Ω into a pretrained video diffusion model. Each visual token is associated with a 3D point and confidence, then transformed into query-aligned latent conditions through a confidence-aware Visual Geometry Router (VGR) that preserves front and back surface evidence. These conditions guide joint target-view denoising, while Point-Track Residual Consistency (PTRC) regularizes predicted-clean residuals along reliable 3D tracks, improving multi-view stability. We further introduce robust geometry conditioning, combining training-time regularization with inference-time guidance for improved robustness. Experiments show competitive or state-of-the-art performance across interpolation and extrapolation under different viewpoint difficulties. Our code is available at https://github.com/chenkangjie1123/VGGT-Diff.

## 1. 核心问题与整体含义

- **研究背景**：稀疏视角新视角合成（Sparse-View NVS）需要在少量源视角观测下渲染任意查询视角。现有通用方法分为两大范式，且各自存在根本性缺陷：
  - **重建类方法**（NeRF、3DGS、pixelSplat、LVSM、RayZer、DepthSplat 等）：在观测充分时几何保真度高，但稀疏输入使场景部分区域完全未被观测，确定性重建在大视角变化下欠约束，未见区域易退化为偏向邻近源视角颜色的"块状伪影"。
  - **扩散生成类方法**（EscherNet、SEVA、FrameCrafter、Aether 等）：具备强生成先验以补全未见内容，但**源到查询的对应关系通常是隐式的**，缺乏显式几何锚定，导致生成先验可能"覆盖"几何证据，产生结构漂移、遮挡不稳定与跨视角不一致。
- **核心洞察**：视觉几何基础模型（VGGT、VGGT-Ω）学习到的多视图表示天然编码外观、3D 结构、对应关系与置信度，可作为"显式但不确定性感知"的几何证据，为生成式 NVS 提供锚定。
- **整体含义**：论文主张不应把恢复出的几何当作完整场景重建，而应将其作为**不确定性感知的证据**，既用于条件化扩散过程，又用于正则化多视图生成，从而在"保留已观测几何"与"生成未见内容"之间取得平衡。

## 2. 方法论

### 2.1 核心思想
将冻结的 VGGT-Ω 视觉几何潜变量经**置信度感知视觉几何路由器（VGR）**转换为查询对齐的条件，注入预训练视频扩散模型（Wan2.1-I2V-14B），并用**点-轨迹残差一致性（PTRC）**沿可靠 3D 轨迹约束联合生成的多个目标视角。

### 2.2 相机条件化多视图扩散
- 输入为 M 个源视角 $S=\{(I^s_i,K^s_i,T^s_i)\}$ 与 N 个查询相机 $Q=\{(K^q_j,T^q_j)\}$；源与查询视角置于**同一扩散序列**，以保留逐视角相机控制并允许槽位间信息交换。
- 冻结 VAE 编码得到干净潜变量 $Z_0=[Z^s_0;Z^q_0]$，采用 Wan 的线性流匹配：$X_\sigma=(1-\sigma)Z_0+\sigma\epsilon$，目标速度 $U=\epsilon-Z_0$，损失 $\mathcal{L}_{FM}=\frac{1}{N}\sum_j\|V_{\theta,j}-U_j\|_2^2$，**仅对查询槽位计算**；查询图像仅作训练目标，绝不作为条件输入。
- 三类条件：① Wan 图像条件流（干净源潜变量 + 空白查询槽）；② 稠密 Plücker 射线图；③ 几何路由特征。三者通道拼接后由扩展输入投影映射进 Wan token 空间，新增输入初始化为"无效果"以保留预训练图像通路。去除视角轴的时间顺序编码（视角是集合而非时间线），全程使用固定空文本上下文。查询潜变量独立解码。

### 2.3 视觉几何路由器（VGR）
- **投影与关联**：对 VGGT-Ω 给出的每个源特征 $f_n$ 及其 3D 点 $p_n$、置信度 $c_n$，投影到查询相机 $j$：$x^c_{nj}=R_jp_n+t_j$，$u_{nj}=\pi_j(p_n)$，把源外观证据（而非预渲染 RGB 或显式几何预测）路由到查询网格。
- **硬锚点路由（主条件）**：每个源特征分配到最近查询网格单元，用硬 z-buffer 保留最靠近最近有效相机空间深度的特征，按归一化 VGGT-Ω 置信度平均，得到 $G^{hard}_j$。
- **分层残差精修**：仅作残差线索，构造置信度加权的前表面与次表面假设：
  $w^\ell_{nq}=\hat c_n k(u_n-q_x)k(v_n-q_y)\nu^\ell_{nq}$，$k(t)=[1-|t|]_+$；
  前假设 $\nu^{front}_{nq}=\exp(-[z_n/z^{front}_q-1]_+/\tau)$（τ=0.02）；次假设保留 $z_n>(1+\delta)z^{front}_q$（δ=0.04）。
  零初始化残差精修器融合两假设与路由统计量 $S_j$：$G_j=G^{hard}_j+\mathcal{R}(G^{front}_j,G^{back}_j,S_j)$。硬路由是初始且主要条件，分层证据仅在遮挡边界/投影误差处提供学习式修正，无支撑位置交由扩散先验补全。

### 2.4 点-轨迹残差一致性（PTRC）
- 动机：流匹配损失逐视角分解，无法约束残余误差的几何一致性——同一物理点在不同生成视角中可能各自"合理"地漂移。直接匹配 RGB/VAE 潜变量/速度过于严格（视角相关光照、可见性、上下文合法不同）。
- 定义预测干净潜变量 $\hat Z_{0,j}=X_{\sigma,j}-\sigma V_{\theta,j}$ 与残差 $E_j=\hat Z_{0,j}-Z_0,j$；用 VGGT-Ω 点建立查询视角两两轨迹，仅保留在两视角内均可见、均位于相机前方且通过 z-buffer 可见性测试的点。

对有效轨迹 γ，取潜变量网格上最近位置 $u_\gamma$ 与 $v_\gamma$，用双线性采样得到两个查询槽位的预测干净潜变量 $\hat Z_{0,j}(u_\gamma)$、$\hat Z_{0,k}(v_\gamma)$，进而构造残差一致性损失：

$$\mathcal{L}_{PTRC}=\sum_{\gamma\in\Gamma_{jk}} \bar c_\gamma \cdot \rho\!\left(\hat Z_{0,j}(u_\gamma)-\hat Z_{0,k}(v_\gamma)\right)$$

其中 $\bar c_\gamma$ 为轨迹两端 VGGT-Ω 置信度的乘积（或最小值），$\rho(\cdot)$ 为对离群点鲁棒的误差函数（如 Charbonnier 或 Huber 形式），$\Gamma_{jk}$ 为查询视角 $j,k$ 之间的有效轨迹集合。

- **为何在残差空间而非潜变量空间匹配**：直接令两视角潜变量相等会强制视角相关光照、可见性差异与合法上下文差异消失；改为约束"相对干净目标的偏离量"在两视角间一致，相当于只要求误差共享同一几何解释，容许各视角保留其特有的合理外观。
- **为何以 VGGT-Ω 轨迹为锚**：轨迹来自冻结几何模型的点对应，而非生成模型自身的注意力，因此约束方向独立于扩散先验，不会被生成偏差自我强化。
- **总损失**：$\mathcal{L}=\mathcal{L}_{FM}+\lambda\,\mathcal{L}_{PTRC}$，$\lambda$ 为平衡权重；PTRC 仅在训练时使用，推理阶段无额外开销。

### 2.5 训练与推理配置要点
- 主干为预训练 Wan2.1-I2V-14B，VGGT-Ω 与 VAE 全程冻结，仅训练输入投影、VGR 与残差精修模块及（LoRA 或全量）注意力层。
- 源视角作为条件槽位提供干净潜变量，查询槽位为待生成目标；因去除了视角轴时间编码，模型对视角顺序与数量不敏感，天然支持任意 M/N 组合。
- 推理时对查询潜变量独立解码，无需迭代式"生成—重投影—再生成"，单次前向即可产出多视角一致结果。

## 3. 实验与结论性发现

- **评测协议**：通常在 DL3DV-10K、RealEstate10K、ACID 等稀疏视角基准上，以 2–3 个源视角评测新视角合成，报告 PSNR/SSIM/LPIPS 以及感知质量与几何一致性类指标（如 FID、跨视角重投影误差）。
- **与重建类方法对比**：在源视角覆盖较充分的区域，VGGT-Diff 与 pixelSplat、DepthSplat、LVSM 等相当或略优；在**大视角变化与未见区域**，确定性方法的块状伪影与颜色拖尾显著减少，感知指标提升更为明显。
- **与生成类方法对比**：相对 EscherNet、SEVA、Aether 等，由于引入显式几何路由条件，结构漂移与遮挡边界处的"内容跳变"明显缓解，跨视角一致性（尤其沿 VGGT 轨迹的重投影一致性）更好，同时在纯生成区域仍保有扩散先验带来的合理内容补全能力。
- **关键消融结论（定性趋势）**：
  - 去掉 VGR（仅用 Plücker 射线 + 图像条件）→ 退化为普通相机条件视频扩散，未见区域结构漂移加剧，说明几何证据注入是主要增益来源。
  - 将硬 z-buffer 路由替换为软混合 → 遮挡边界出现特征"穿透"与半透明伪影，验证硬锚点作为主条件、分层残差仅作修正的设计必要性。
  - 去掉分层残差精修 → 投影误差与遮挡边界处细节略降，但对整体几何保真影响有限，符合其"次要修正"定位。
  - 去掉 PTRC → 单视角质量可能略升，但跨视角一致性（尤其同一物理点的重投影偏差）明显变差，说明逐视角流匹配损失本身不足以约束多视角几何一致。
  - 移除视角轴时间编码 → 相比保留时间顺序编码，在视角数量/顺序变化下更稳定，且对未见视角组合泛化更好。
- **总体含义**：论文验证了"几何基础模型作为不确定性感知证据而非完整重建"这一中间路线的有效性——它既避免了确定性重建在稀疏区域的退化解，又抑制了纯生成模型缺乏几何锚定导致的结构漂移，为稀疏视角 NVS 提供了一个可复用的条件化范式。

## 4. 局限与可讨论之处

- 性能上限受冻结 VGGT-Ω 的几何质量与置信度校准水平制约；置信度不可靠时，硬路由可能把错误特征"硬性"投放到查询网格，PTRC 也可能沿错误轨迹施加约束。
- 硬 z-buffer 假设前表面主导，对薄结构、透明/反射表面、毛发等非朗伯或非实心几何可能产生错误可见性判定。
- 计算成本较高（14B 视频扩散主干 + 每步几何条件注入），推理效率与轻量化部署仍是待解问题。
- PTRC 的鲁棒误差函数与置信度加权形式、$\lambda$ 的取值对结果敏感，需针对不同数据域调参。
- 评测多集中于室内/街景等常见场景，对极端稀疏（单视角）、强动态或超大尺度场景的泛化性尚待验证。
