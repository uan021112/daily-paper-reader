Abstract: World models provide robots with a predictive mechanism for reason-
ing about how actions change object states in manipulation tasks. However, exist-
ing image-based and dense 3D world models do not explicitly impose object-level
rigid motion, leaving rigid-object geometry preservation to be learned implicitly
and making multi-step rollouts susceptible to shape drift or object-level motion
inconsistency. To address this, we propose ORD-WM, a 3D world model that
learns object-centric rigid dynamics for robotic manipulation. ORD-WM learns a
vector-neuron variational autoencoder supervised by signed distance fields, which
encodes each object point cloud as a geometry-aware latent representation com-
posed of 3D vector features, and uses an action-conditioned dynamics model
to predict object-wise SE(3) motion increments. Rather than generating uncon-
strained next latent states, ORD-WM analytically applies predicted object-wise
rigid transformations to the current latent states, separating persistent object ge-
ometry from pose changes. Experiments show that ORD-WM enables stable,
geometry-preserving multi-step prediction and supports efficient real-time replan-
ning for closed-loop model predictive control in simulated and real-world manip-
ulation scenarios.

Introduction
Humans can anticipate how physical scenes evolve and how actions change object states, which
is fundamental to everyday interaction with the physical world. Endowing robots with a similar
predictive ability is an important step toward more capable manipulation: before pushing, grasping,
or rearranging objects, a robot should reason about how its actions may move and transform the
objects in a scene. World models provide a natural framework for acquiring such capability by
learning action-conditioned dynamics and rolling out future states internally, enabling robots to
evaluate candidate actions and plan toward desired object configurations without relying solely on
trial-and-error interaction in the real world [1, 2].
Recent robotic world models have explored several forms of action-conditioned prediction. Video-
based models roll out future visual observations and can capture rich visual changes in robot-object
interaction [3]. However, because prediction is performed in image or visual latent space, these
models lack an explicit metric 3D state. As a result, visual plausibility alone does not guaran-
tee temporally consistent object geometry or physically plausible interactions during rollout [4, 5].
Dense 3D world models based on point clouds, particles, or Gaussian scene representations move
prediction closer to physical space by forecasting the motion of 3D elements [6]. However, when
modeling rigid object motion through local element-wise updates, these models must coordinate lo-
cal motions to produce globally consistent object transformations, which may accumulate into shape
distortions or object-level drift during multi-step rollout [7].
For manipulation tasks involving rigid or approximately rigid objects, prediction should preserve
object geometry while allowing object poses to change through interaction. Rigid-body simula-
tors [8] offer a useful abstraction for this setting: they represent scenes as collections of bodies with
persistent geometry and update object states through constrained body-level motion, rather than by
independently moving dense visual or geometric elements. This separation between geometry and
motion suggests a natural inductive bias for learned world models of rigid-object manipulation.
Building on this perspective, we propose ORD-WM, a 3D world model that learns object-centric
rigid dynamics for robotic manipulation (Fig. 1). ORD-WM represents a manipulation scene as
a collection of geometry-aware object states and evolves them through object-wise rigid motion.
To obtain such states, ORD-WM trains a signed-distance-field (SDF)-supervised vector-neuron
(VN) [9] variational autoencoder (VAE) [10], denoted SDF-VNVAE. Its encoder maps each ob-
ject point cloud to a geometry-aware latent state composed of 3D vector features that capture object
geometry and can be analytically transformed by rigid motions in latent space. Instead of predicting
unconstrained next latent states, ORD-WM predicts object-wise SE(3)1 motion increments condi-
tioned on the current scene state and robot action, and applies these transformations directly to the
object states.
Together, these design choices yield an object-centric 3D world model in which object geometry is
maintained as a persistent latent structure and future states are generated through structured rigid
updates. We evaluate ORD-WM on multi-step dynamics prediction and model predictive control
(MPC) for object pushing and pick-and-place, showing that its object-centric SE(3)-structured roll-
out improves geometric consistency and supports downstream model-based control.

Related Work
World Models for Robotic Manipulation. World models [1] learn action-conditioned predictions
of future states or observations, providing a predictive substrate for planning and policy learning in
imagination [2, 11, 12, 13]. Recent robotic world models extend this paradigm by learning action-
conditioned predictors from large-scale video and robot interaction data. These models forecast
future images [14, 15, 16] or visual latents [17, 18], supporting policy learning [19, 20], policy

conditioning [21], visual model-based control [22, 23], and policy evaluation [24, 25]. However,
prediction in image or visual-latent spaces does not by itself impose physical consistency: visually
plausible rollouts may still fail to preserve object geometry, identity, or rigid-body motion over
time. Another line of work grounds prediction in 3D, using point clouds [7, 26], particles [27,
28], or Gaussian scene representations [29, 30] to model physical scene evolution. While these
representations move prediction closer to physical space [31], dense element-wise motion still leaves
rigid consistency to be learned implicitly: all points of a rigid object must agree with a single
object-level transformation [32]. ORD-WM targets this rigid-object regime by evolving object states
through object-wise SE(3) motion increments rather than future frames or dense point flows.
Object-Centric Representations for Dynamics Modeling. Object-centric representations factor-
ize a scene into entities rather than representing the entire scene with a single holistic latent, provid-
ing a natural structure for learning compositional dynamics [6, 33, 34, 35]. This factorization mirrors
physical scenes, where objects move independently, interact relationally, and form new configura-
tions across contexts [36]. Object-centric dynamics have been shown to benefit prediction [34],
planning [37], model-based reinforcement learning [38, 39], and relation-aware manipulation [40]
by making dynamics more modular and interpretable. However, existing methods typically use ab-
stract object representations that support compositional reasoning but do not explicitly encode object
geometry or constrain transitions to follow rigid-body motion [35, 40, 41]. As a result, rigid geom-
etry preservation remains an implicit property to be learned from data. ORD-WM builds on this
object-centric view, but represents each object with a geometry-aware latent state composed of 3D
vector features and updates the latent state through explicit rigid transformations, thereby imposing
rigid structure directly on the latent transition.
Implicit 3D Object Representations. Implicit 3D object representations, such as SDFs and occu-
pancy fields, model object shape as continuous functions and provide geometric information beyond
discrete surface samples [42, 43]. In robotics, SDFs have been widely used for collision-aware mo-
tion planning, where reasoning about geometry and spatial proximity is essential [44, 45, 46, 47].
Learning-based SDF methods use signed distance supervision to learn object shape representations
for reconstruction [48], perception [49, 50, 51], and manipulation planning [52, 53]. ORD-WM
trains a VNVAE with an SDF reconstruction objective, producing geometry-aware latents composed
of 3D vector features that serve as object states for rigid, geometry-preserving rollout.
3
Method
We present ORD-WM, a 3D world model that learns object-centric rigid dynamics for robotic ma-
nipulation. ORD-WM represents a manipulation scene as a collection of geometry-aware object
states and evolves them through object-wise rigid motion. Given RGB-D observations, ORD-WM
first constructs object-level point clouds and encodes each object into a geometry-aware latent state
composed of 3D vector features. An action-conditioned dynamics model then predicts object-wise
SE(3) motion increments, which are analytically applied to the current latent states to enable struc-
tured multi-step rollout while preserving object geometry and identity.

geometry while allowing rotations to be applied analytically. We therefore train a geometry-aware
VNVAE that maps each object point cloud to a latent representation composed of 3D vector features.

same rotation on each 3D vector feature, making it meaningful to apply predicted object rotations
directly to the latent representation. The decoder predicts signed distance values from the latent
representation and query points in a rotation-invariant manner, encouraging the latent to capture
object geometry and surrounding distance structure, as illustrated in Fig. 2.

3.3
Object-Centric Rigid Dynamics
Given the object-centric scene state St, robot proprioception ρt, and robot action at, ORD-WM
learns a dynamics model that predicts action-conditioned object motion in the scene (Fig. 3). We par-
tition scene objects into floating objects, whose poses can change over time, and fixed objects, which
provide static context such as support surfaces. Robot proprioception is converted into geometry-
aware gripper tokens by applying forward kinematics to pre-sampled points on each gripper part,
which are then encoded with the same VNVAE encoder used for scene objects. Instead of using a
single end-effector pose and gripper width, we represent the action as rigid transformations of in-
dividual gripper parts. Floating objects, fixed objects, gripper parts, and actions are tokenized with
learned role embeddings and fed into a transformer dynamics module, which captures robot-object
and object-object interactions and produces interaction-aware features hi
t for each scene object.

3.4
Model Predictive Control with ORD-WM
A learned world model can be used in several ways, including online planning, policy learning
from imagined rollouts, and policy evaluation. In this work, we use ORD-WM for model predictive
control, where the learned dynamics model is used directly to evaluate candidate action sequences.
At each control step, we construct the current scene state and proprioception, roll out future object
states for candidate action sequences directly in latent space, and optimize the action sequence
using the Cross-Entropy Method (CEM) [57]. CEM iteratively samples candidate action sequences,
evaluates them with the learned dynamics model and task cost, and refits the sampling distribution
toward low-cost candidates. Only the first action of the optimized sequence is executed before the
robot receives a new observation and replans, following a receding-horizon control scheme. The
MPC objective measures the discrepancy between predicted scene states and desired target states
over task-relevant components.

4
Experiments
We conduct comprehensive experiments in simulation and the real world to answer the following
questions: (1) Can ORD-WM accurately predict multi-step object motion while preserving geome-
try? (2) Which components enable stable geometry-preserving rollout? (3) Can ORD-WM support
efficient closed-loop MPC?
4.1
Experimental setup
Datasets.
We train the SDF-VNVAE and its representation baselines using object assets from
LIBERO [58] scenes and RoboCasa [59]. For world-model training, we use trajectories from the
LIBERO benchmark, including LIBERO-Spatial, LIBERO-Object, LIBERO-Goal, and LIBERO-
Long, each containing 10 distinct tasks, together with 1,000 additional object-pushing trajectories.
We reserve 10% of the trajectories for multi-step rollout evaluation.
Real-world setup. Real-world experiments are conducted with a Franka Research 3 robot and three
calibrated RealSense D435 cameras. Depth maps are estimated using FoundationStereo [60], and
object-centric states are constructed from the resulting RGB-D observations following the percep-
tion pipeline in Sec. 3.1.

4.3
Which components enable stable geometry-preserving rollout?
We next analyze which structural components enable the stable rollouts observed in Sec. 4.2. At the
core of ORD-WM are two key structures: a VN-based geometry latent that supports analytic object
rotations, and a dynamics model that predicts object-wise SE(3) motion increments and applies
them to the current object states in latent space. To isolate their effects, we compare ORD-WM
with four variants: two that directly predict the next object state and two that retain SE(3) updates
without using VN representations. The w/o SE(3) update variant uses the same VN-based object
state as ORD-WM but directly predicts the next object state in latent space, removing the analytic
rigid update. The w/o VN and SE(3) update variant replaces the VN-based geometry latent with
a standard SDF-VAE latent and also predicts the next object state directly. The w/o VN baseline
retains object-wise SE(3) prediction but uses a standard geometry latent. Since rotations cannot be
applied directly to this latent, it transforms the object point cloud and re-encodes it at each rollout
step. The Decoupled Geo.+Pose baseline stores persistent geometry and explicit pose separately,
avoiding repeated geometry encoding. We evaluate these variants using Surface CD for prediction
accuracy, Shape Consistency CD for geometric drift, and rollout FPS for computational efficiency.
The comparisons in Table 2 show the value of SE(3) updates. For both VN-based and standard
geometry representations, directly predicting future object states yields larger long-horizon errors
than predicting and applying object-wise SE(3) motion increments. The direct-prediction variants
also exhibit larger Shape Consistency CD, indicating that unconstrained latent updates can gradu-
ally alter the decoded geometry. In contrast, the variants with SE(3) updates preserve object shape
by constraining state evolution to rigid motion. These results support the role of SE(3) updates

4.4
Can ORD-WM support efficient closed-loop MPC?
We finally evaluate whether ORD-WM can support closed-loop control through MPC. Following
Sec. 3.4, the controller uses ORD-WM to roll out candidate action sequences in latent space and se-
lects actions by minimizing the discrepancy between predicted scene states and desired target states
over task-relevant components. We evaluate object pushing and pick-and-place tasks, measuring
task performance and planning efficiency. For pick-and-place, we use a staged planning strategy
inspired by V-JEPA 2 [18], sequentially performing grasping, lifting, and transport.

ORD-WM supports repeated online replanning on the real robot.

selected actions move objects toward the target configurations over successive replanning steps. The
real-world examples further show that ORD-WM can support closed-loop pushing from observed
scenes beyond the simulation setting.

Conclusion
We proposed ORD-WM, a 3D world model that learns object-centric rigid dynamics for robotic ma-
nipulation. By combining SDF-supervised, rotation-equivariant object representations with action-
conditioned SE(3) motion prediction, ORD-WM evolves object states through analytic rigid trans-
formations in latent space. This design preserves object geometry by construction and enables
multi-step rollout without repeatedly reconstructing or re-encoding object point clouds. Experiments
demonstrate improved multi-step prediction accuracy, while ablations highlight the importance of
rigid updates for geometry preservation and the benefits of equivariant representations for prediction
accuracy and rollout efficiency. ORD-WM also supports efficient online replanning for closed-loop
manipulation in both simulation and real-world experiments. Together, these results highlight the
value of explicit rigid-body structure in learning world models for robotic manipulation.
6
Limitations
While ORD-WM introduces an object-centric SE(3)-structured latent rollout for preserving rigid-
object geometry, its current formulation focuses on a restricted class of object dynamics. Specifi-
cally, scene objects are modeled as either floating or fixed rigid bodies, which limits the method’s
applicability to articulated, hinged, or deformable objects. Future work could extend ORD-WM
with additional motion types: articulated or hinged objects could be updated by predicting con-
strained transformations that respect their joint degrees of freedom, while deformable objects could
use shape-changing latent dynamics instead of purely rigid SE(3) updates.
Even for rigid objects, ORD-WM targets low-dynamic, position-controlled manipulation. Mass,
friction, and contact effects are learned implicitly from observed transitions, so the model cannot
distinguish dynamics caused by different unobserved physical parameters under identical observed
states and actions. Its SE(3) updates preserve object geometry but do not enforce contact constraints
or non-penetration.
Finally, due to computational constraints, we have not yet evaluated ORD-WM on substantially
larger datasets or more diverse object and task distributions. Scaling the proposed object-centric
structured rollout to broader manipulation scenarios remains an important direction for future work.

The SDF-VNVAE architecture follows the vector-neuron (VN) framework of Deng et al. [9], which
represents features as channels of three-dimensional vectors and defines SO(3)-equivariant neural
operations such as VN linear layers, VN nonlinearities, pooling, normalization, and standardization.
We adapt these operations to an SDF-supervised variational autoencoder for object geometry encod-
ing. In the architecture tables, “VNLinearLeakyReLU” denotes a VN linear layer followed by a VN
LeakyReLU nonlinearity.
All dimensions in VN layers are reported as vector-channel dimensions. A feature with C VN
channels has shape RC×3, corresponding to C three-dimensional vector features. This differs from
a standard scalar MLP, where the hidden dimension counts scalar channels.

The original Vector Neurons work introduces VN variants of

clouds are constructed from segmented RGB-D observations and can have non-uniform sampling
density.

A.4
Training Details
We train the SDF-VNVAE using object assets from LIBERO and RoboCasa. For each object sam-
ple, surface points are used as the encoder input, and pre-generated SDF query points are used
for decoder supervision. The query points are generated with a mixed sampling strategy and are
shuffled and split into fixed-size chunks during training, rather than being re-sampled by category
online. Here, batch size refers to the number of object samples per optimization step, while each
object sample contains Np surface points and Q SDF query points.
To account for imperfect RGB-D observations, we augment the input point clouds with partial or
missing surfaces, nonuniform sampling, coordinate noise, outlier or background points, and simu-
lated mask and camera perturbations. The object center is computed as the arithmetic mean of the
observed points and can therefore vary with visibility and sampling density. These augmentations
expose the encoder to the resulting variations in both the observed geometry and its centering.
During training, latent vectors are sampled from the posterior using the reparameterization trick.
During evaluation and downstream ORD-WM training, we use the posterior mean as the determin-
istic geometry latent. The main training hyperparameters are summarized in Table A.3.

B.3
Dataset
We train the dynamics model using two types of trajectories: LIBERO manipulation trajectories
and an additional object-pushing dataset. The LIBERO portion contains trajectories from LIBERO-
Spatial, LIBERO-Object, LIBERO-Goal, and LIBERO-Long. Each suite contains 10 tasks, and each
task provides 50 demonstrations, resulting in 2,000 LIBERO trajectories in total.
To increase the coverage of contact-rich rigid-object motion, we additionally collect 1,000 object-
pushing trajectories in simulation. The pushing trajectories are collected fully automatically with-
out human teleoperation. Each trajectory contains five consecutive pushing operations in the same
scene. For each pushing operation, the data-collection script samples a movable target object and a
planar pushing direction. Based on the target-object position and the sampled direction, the script
automatically constructs a short waypoint sequence for the gripper: it first moves the gripper to a
pre-contact pose behind the target object, then lowers the gripper to the pushing height, and finally
moves the gripper along the sampled pushing direction.
The executed action sequence is generated by interpolating between these waypoints. To increase
motion diversity, the execution speed is randomly sampled for each pushing operation, so trajectories
contain pushes with different contact durations and motion magnitudes. After one pushing operation
is completed, the resulting scene state is kept, and the next target object, pushing direction, and
speed are sampled. Repeating this process five times within one trajectory produces diverse object
displacements, contact configurations, and object-object interactions.
Both data sources are converted into the same center-aligned point-cloud trajectory format. For each
frame, we store scene-object identities, object roles, object poses, gripper-part poses, and distance
annotations. Scene objects are labeled as floating or fixed objects. Floating objects provide pose
supervision for the SE(3) motion head, while fixed objects serve as static context. Object identities
are matched with the pretrained SDF-VNVAE latent bank, and demonstrations without valid object
matching or gripper information are filtered out.
For dynamics learning, each demonstration is converted into one-step transitions between consec-
utive frames. The current frame provides object and gripper-part states, the relative motions of the
three gripper parts define the action tokens, and the next frame provides pose and distance supervi-
sion. We split each data source at the trajectory level into 90% training and 10% test data, ensuring
that transitions from the same trajectory do not appear in both sets.
B.4
Training Details
The latents are obtained from the pretrained SDF-VNVAE latent bank, which includes posterior-
mean representations of the augmented object observations described in Appendix A.4. During
training, we randomly sample one initial latent for each object identity. This exposes the dynamics
model to observation-induced variations in the representation of the same object and reduces over-
fitting to a single latent realization. For each training step, object tokens and gripper-part tokens are
constructed from the current object states and gripper states. Action tokens are constructed from
the relative rigid motions of the three gripper parts between two consecutive frames. The model
23


predicts SE(3) motion increments for floating objects, which are composed with the current object
poses before computing the pose losses. The auxiliary distance heads are supervised with next-step
nearest-distance targets.
We use masks to handle variable-size scenes and missing annotations. The token mask removes
padded tokens. The floating-object mask restricts pose losses to valid floating objects. The distance
masks remove objects without valid gripper-distance or floating-object-distance annotations. We
additionally apply group-wise context masking during training. Object groups marked as mask-
eligible are randomly removed with probability 0.5, and the corresponding token masks and loss
masks are updated accordingly. This serves as a data augmentation that reduces reliance on non-
critical static context objects.
The main training hyperparameters are summarized in Table B.2. We train the model with AdamW
and a cosine learning-rate schedule. The materialized transitions are preloaded onto GPU memory
before training to reduce HDF5 reading overhead and host-to-device transfer cost.

C.4
Geometry Preservation During Rollout
We further analyze the effect of the structured SE(3) update in ORD-WM. To isolate this design
choice, we compare ORD-WM with an ablated variant that removes the analytic SE(3) latent update.
Instead of predicting an object-wise rigid motion increment and applying it to the current object
28


latent, this variant directly predicts the next latent state for each object. The two models use the
same object-centric input representation and rollout setting, but differ in whether object evolution is
constrained to follow a rigid transformation in latent space.
As shown in Fig. C.7, ORD-WM preserves object geometry throughout the rollout while updating
object poses according to the predicted motion. In contrast, the variant without the SE(3) update
gradually introduces geometric distortion when directly predicting future latents. These errors accu-
mulate over time: object shapes first become slightly deformed, then progressively lose their original
structure, and eventually collapse into unrealistic geometries. Once the predicted latents deviate sub-
stantially from valid object representations, subsequent dynamics prediction also becomes unstable,
causing the rollout to diverge. This comparison highlights the importance of applying object-level
rigid transformations in latent space rather than freely generating the next object state.

This appendix provides additional details for the model predictive control (MPC) experiments with
ORD-WM. We describe the receding-horizon planning procedure, the CEM optimization settings,
and the target-pose cost used for evaluating candidate rollouts.
D.1
MPC Formulation
At each control step, the current object-centric scene state, gripper-part states, and predicted ob-
ject dynamics are used to plan a sequence of future gripper motions. Only floating objects are
actively predicted; fixed objects provide static context. The planner uses the Cross-Entropy Method
(CEM) [57] to optimize a sequence of relative gripper motions over a finite horizon H. After op-

timization, only the first action in the selected sequence is executed, and the robot replans in a
receding-horizon manner from updated observations.

D.2
Implementation Details
CEM samples action sequences from a diagonal Gaussian distribution in the normalized action space
and refits the distribution using the elite samples at each iteration. Sampled actions are clipped to
valid bounds before being scaled to physical units. For pushing, CEM optimizes planar end-effector
displacements ah = (∆xh, ∆yh) with fixed orientation and a closed gripper. For pick-and-place, it
optimizes three-dimensional displacements ah = (∆xh, ∆yh, ∆zh). Candidate displacements are
converted into the corresponding gripper-part rigid motions for dynamics prediction. Pick-and-place
uses stage-specific target scene states for grasping, lifting, and transport. MPC replans toward the
current stage’s target. Table D.1 summarizes the pushing optimization and cost settings.
