## 摘要
视觉 Transformer 架构在语义分割任务中展现出卓越性能，但其二次方级注意力复杂度限制了实际应用。近期研究主要通过合并 token 来缩短序列长度，从而提升 Transformer 的效率。然而，现有 token 合并方法主要依赖特征相似度来识别相似 token，忽略了空间一致性，这可能会在语义分割中引入分割错误。本文提出 SCMerge，一种无需训练的 token 合并方法，在配对相似 token 时综合考虑特征相似度与空间一致性。随后，在编码器中合并成对的 token，并在解码后将生成的 token 序列重建到原始 patch 网格上。该方法具有灵活性，可直接集成到现有基于视觉 Transformer 的语义分割流程中。在 ADE20K、Pascal Context 和 Cityscapes 基准数据集上的大量实验表明，与基线方法相比，SCMerge 在分割精度与效率之间始终实现了更优的权衡。

## Abstract
Vision Transformer architectures have showcased impressive performance on semantic segmentation, yet their quadratic attention complexity hinders practical applications. Recent works have focused on merging tokens to reduce sequence length and thus improve transformer efficiency. However, existing token merging methods primarily rely on feature similarity to identify similar tokens, overlooking spatial consistency, which may introduce segmentation errors in semantic segmentation. In this work, we propose SCMerge, a training-free token merging method that jointly considers feature similarity and spatial consistency in pairing similar tokens. The pairwise tokens are then merged within the encoder, and the resulting token sequences are reconstructed onto the original patch grid after decoding. The proposed method is flexible and can be plugged into existing vision Transformer-based semantic segmentation pipelines. Extensive experiments on the benchmark datasets ADE20K, Pascal Context, and Cityscapes show that SCMerge consistently achieves a better trade-off between segmentation accuracy and efficiency than baseline methods.

- **论文目标：**提出一种无需训练、可插入现有 ViT 分割模型的 token 合并方法，在降低计算成本的同时，更好地保留空间结构和分割细节。

## 2. 方法论

### 核心思想

SCMerge 在 token 配对时同时考虑**特征相似度**和**空间一致性**：只合并特征相似且局部结构相容的 token。合并发生在编码器中；解码器仍接收压缩后的 token 序列，解码后再利用映射关系将预测结果恢复到原始 patch 网格。

### 关键技术细节

- **特征相似度：**对 token 特征归一化，计算任意两 token 的余弦相似度 \(S_{ij}\)，并将对角线设为负无穷以避免 token 与自身配对。
- **局部变化度：**将归一化特征压缩为固定宽度 \(d_s=48\) 的确定性通道 sketch，在 token 对应的稀疏空间布局上计算 \(3\times3\) 邻域内的通道方差，得到 token 的局部变化值 \(v_i\)，再按当前 token 集合做 min–max 归一化，得到 \(e_i\)。高变化值通常对应边界、细长结构或异质区域。
- **空间一致性惩罚：**
  - 边界敏感项：\(B_{ij}=\max(e_i,e_j)\)。任一 token 局部变化较大时，该项就会增大，从而抑制边界敏感 token 被合并。
  - 邻域一致性项：\(D_{ij}=|e_i-e_j|\)。它惩罚局部变化特征差异较大的 token 对。
  - 综合惩罚：\(R_{ij}=\sqrt{B_{ij}^{2}+D_{ij}^{2}}\)。
- **合并评分与配对：**计算 \(A_{ij}=S_{ij}-R_{ij}\)，每个 token 选择得分最高的另一 token；仅保留互为最近邻的配对。
- **合并与重建：**配对 token 的特征取均值，未配对 token 保持不变。方法维护代表坐标和跨阶段 merge map；解码器输出压缩 token 的类别 logits 后，利用映射将 logits 复制回原始 patch 位置，再上采样至输入分辨率。

### 算法流程概括

1. 计算 token 两两余弦相似度。
2. 在稀疏空间布局上计算局部变化并归一化。
3. 根据边界敏感性和邻域变化差异计算空间惩罚。
4. 以“特征相似度减去空间惩罚”得到配对分数，选择互为最优邻居的 token 对。
5. 对配对特征求平均，更新 token 序列、代表坐标和重建映射。
6. 压缩序列继续经过编码器和原有解码器，最终恢复到原始 patch 网格。

## 6. 主要结论与发现

- SCMerge 在所测试的设置中整体上提供了较好的精度—效率折中；与完整模型相比，能降低 token 数、GFLOPs 和推理延迟，同时保持接近的 mIoU。
- 与 MPM 相比，作者报告 SCMerge 在六个模型—数据集设置中提升约 **0.18–0.76 mIoU**，并将相对完整模型的延迟降低约 **26%–36%**。
- 在 ADE20K 的边界分析中，SCMerge 的 B-mIoU@5 为 35.29，接近完整 token 模型的 35.37；边界 token 合并比例为 22.55%，低于 MPM 和 MPM-top。
- 邻域一致性分析显示，SCMerge 的跨类别配对比例更低、邻域标签一致率更高，与方法设计目标相符。
- 空间惩罚有助于改善配对质量和分割精度；解码后再重建可将压缩序列维持到解码阶段，从而带来计算节省。

## 7. 优点

- **训练-free、易集成：**不需要额外监督、模态输入或可学习参数，且不改动原有解码器结构。
- **针对分割任务设计：**不只考虑外观相似性，还显式关注边界敏感性和局部结构差异。
- **保留紧凑计算路径：**直到解码后才恢复原始 patch 网格，避免过早扩展 token 序列。
- **评估维度较丰富：**除 mIoU 和延迟外，还报告 GFLOPs、token 数、边界指标和邻域一致性指标。
- **报告了端到端延迟：**测量包含合并与重建操作，比只报告理论 FLOPs 更贴近实际推理过程。

## 8. 不足与局限

- **仍可能损害细节：**作者指出，极小目标和极细结构仍可能因特征聚合而被平滑；空间惩罚只能缓解，并不能完全消除错误合并。

- **结果覆盖有限：**实验集中于 Segmenter 系列设置，尚不能据此确定其对其他 ViT 分割架构、不同解码器或其他密集预测任务同样有效。
