title_zh: FlexPart：文本控制的语义感知 3D 部件分割，支持灵活粒度
authors: "Yiqun Zhao, Jiachen Xu, Yihao Zhi, Yunfei Zhao, Zibo Zhao, Xintong Han, Chunchao Guo, Shenghua Gao"

evidence: 支持按用户指定粒度进行语义感知的三维部件分割
tldr: "三维资产可按不同粒度划分，用户也常只想提取指定部件；现有方法受多粒度数据不足、控制方式不完整限制，难以做到所需即所得。FLEXPART以部件名称及位置、形状描述构成整体控制提示，借助自动视觉语言模型流程生成多粒度训练数据，并预测网格面级、视角无关的部件身份。随机丢弃背景促使模型依据语义而非几何先验分割，推理时还可自动补全描述。实验中各粒度均优于基线，平均交并比提升15%至22%，仅给部件名称时选择性分割提升35%，为自然语言控制三维分割提供了统一方案。"

## 摘要
一个 3D 资产可以有多种有效的部件划分方式，而语义感知分割应同时体现所需的粒度以及用户希望提取的部件。理想情况下，实用的分割模型应遵循一个简单原则：用户要求什么，就得到什么。然而，实现这一目标面临两项核心障碍：缺乏多粒度训练数据，以及缺少整体性的控制机制。我们提出 FLEXPART，一个用于文本控制 3D 网格分割的统一框架。为实现灵活控制，我们引入了一种整体控制提示，由语义部件名称以及位置和形状描述组成。为支持这一机制，我们利用自动化视觉语言模型（VLM）流程，构建了一个大规模数据集，其中包含多粒度划分及其对应提示。基于这些数据，FLEXPART 在原生 3D 空间中生成视角无关的部件身份场，直接为网格面分配离散的部件 ID。为促使模型遵循语义条件，而非依赖几何先验，我们采用随机背景丢弃策略训练模型。此外，推理阶段的 VLM 规划器可根据 2D 渲染图自动补全描述性语句，使用户只需用日常语言说出所需部件即可。即使最强的受测基线获得真实标注引导，使用规划器补全提示的 FLEXPART 在 mIoU 上仍领先 15%。在留出测试集 FLEXPARTBENCH 上，FLEXPART 在各个粒度下均表现领先，平均 mIoU 比最强基线提升 22%。即使用户只提供所需部件名称，FLEXPART 在选择性分割上的 IoU 也比最强的点击驱动基线提升 35%。

## Abstract
A 3D asset admits multiple valid part decompositions, while semantics-aware segmentation should reflect both the desired granularity and the parts a user wants to extract. Ideally, a practical segmentation   model should strive for a simple principle: what you ask for is what you get. However, realizing this goal is hindered by two core obstacles: the lack of multi-granularity training data and the absence of a   holistic control mechanism. We propose FLEXPART, a unified framework for text-controlled 3D mesh segmentation. To establish flexible control, we introduce a holistic control prompt comprising semantic part   names with location and shape clauses. To support this mechanism, we utilize an automated Vision-Language Model (VLM) pipeline to construct a large-scale dataset of multi-granularity partitions and their   corresponding prompts. Driven by this data, FLEXPART generates a view-independent part-identity field in native 3D space, directly assigning discrete part IDs to mesh faces. To compel the model to respect   semantic conditions rather than rely on geometric priors, we train the model using randomized background dropping. Furthermore, an inference-time VLM planner can automatically complete descriptive clauses   from 2D renderings, allowing users to simply name the desired parts in ordinary words. FLEXPART with planner-completed prompts outperforms the strongest evaluated baseline by 15% in mIoU, even when that   baseline receives ground-truth guidance. On our held-out FLEXPARTBENCH, FLEXPART leads at each granularity and improves average mIoU by 22% over the strongest baseline. With only the requested part names   supplied by the user, it also improves IoU by 35% over the strongest click-driven baseline on selective segmentation.

# 论文总结：FLEXPART

## 1. 核心问题与整体含义

- **研究问题**：同一个三维资产可以按不同需求进行多种合理的部件划分。例如，用户可能需要粗粒度的功能组件，也可能需要细分到附件；还可能只想单独提取若干部件，把其余区域合并为背景。现有方法往往只能给出固定或偏向几何边界的划分，难以同时响应用户指定的**语义、粒度和目标部件**。
- **研究动机**：作者指出，现有方法面临两项主要障碍：
  1. 训练数据通常只为一个几何体提供一种固定分割，缺少同一对象的多粒度语义标注。
  2. 常见控制信号存在局限：目标部件数量或尺度等全局参数缺少语义，点击等局部提示不易表达完整的部件关系，单视角图像提示还可能遗漏遮挡区域。
- **整体思路**：提出 FLEXPART，用结构化文本提示指定目标部件及其粒度，并在输入三维网格的原生表面上直接预测面级标签。其目标是让分割结果尽量符合用户的语义意图，而不是仅复现几何上的自然边界。

## 2. 方法论

### 2.1 整体控制提示

- 每个目标部件由**语义名称、位置描述和形状描述**组成，例如“右臂：位于躯干右上侧、向下延伸；形状为逐渐变细的圆柱状肢体”。
- 提示中的部件列表直接定义输出标签空间：
  - 更换为较少、更概括的部件项目，可表达粗粒度分割；
  - 列出更多、更具体的部件，可表达细粒度分割；
  - 只列出用户想提取的部件，并将其他部件指定为背景，可进行选择性分割。
- 推理时，用户可以直接提供完整描述；也可以只给部件名称，由视觉语言模型根据多视角渲染补全位置、形状描述，并在选择性分割时补充背景类别。

### 2.2 数据构建

- 作者以 HY3D-Bench 中艺术家制作的组件作为原子部件，使用 VLM 对多视角图像进行语义分组，生成**粗、中、细三个层级**的划分。
- 随后逐个为部件生成名称、位置关系和形状描述，并汇总成模型训练所需的完整提示。
- 该流程处理约 **57,000 个对象**，形成约 **151,492 组提示—目标划分样本**。重复的粒度层级会被剔除，因此每个训练对象最多提供三个划分。

### 2.3 三维部件身份场与模型结构

- FLEXPART 将分割视为在三维空间中生成连续的**部件身份场**，再在输入网格的面中心查询该场，为各个网格面分配离散部件标签。它不重新生成或修改网格几何。
- 模型由两部分构成：
  1. **部件感知 VAE**：将点云的位置、法线和部件 ID 编码为带有三维网格位置锚点的潜变量；解码器可在空间位置查询几何 SDF 和部件 ID。训练时联合优化潜变量正则、SDF 几何重建和部件 ID 的二元交叉熵。
  2. **文本条件 DiT**：采用双流 Transformer 处理文本与三维潜变量。冻结的 Qwen3-VL 编码文本；输入几何则通过将所有部件标签置零后的 VAE 编码得到，作为部件无关的形状条件。模型以流匹配目标从噪声潜变量生成部件场潜变量。
- **离散 ID 编码**：使用 6 位二进制 ID 表示部件，而不是连续 RGB 颜色。全 1 编码保留给背景，因此最多支持 63 个目标部件。提示列表中的第 *i* 项与第 *i* 个 ID 对应，明确建立文本条目与标签通道的映射。
- **随机背景丢弃**：训练时随机删除部分提示条目，并将这些条目对应的表面区域改标为背景。这样模型必须学习“哪些区域被指定为目标”，而不是无条件地把整件物体分成若干区域；该策略也使背景标签具有明确语义，从而支持选择性分割。
- **推理规划器**：使用独立的冻结 VLM Qwen3.8，观察网格的 16 个转台视角渲染图。用户给出部件名称时，规划器补全位置和形状描述；若任务没有指定部件名称（如生成资产测试），规划器还可依据目标粒度自行提出部件清单。

## 7. 优点

- **控制信号直接且表达力较强**：通过语义名称、位置和形状联合描述目标部件，兼顾“分什么”和“分到多细”。
- **统一支持多种任务**：同一模型通过改变提示即可处理多粒度完整分割和目标部件选择性分割。
- **在原网格表面输出标签**：不需要重新生成各部件几何，避免了生成式拆分可能带来的缺面、越界或碎片问题。
- **三维原生表示具有全局性**：在原生三维空间生成部件身份场，较少依赖某一个参考视角，有助于处理遮挡区域。
- **数据和模型设计相互配合**：多粒度数据、背景丢弃和条目—标签绑定共同服务于语义控制，而非只依赖架构改动。
- **自动化程度较高**：规划器使用户能够从简单部件名称出发，降低编写完整结构化提示的负担。

## 8. 不足与局限

- **边界歧义仍然存在**：位置和形状描述如果过于宽泛，或相邻部件的描述重叠，模型可能难以确定边界。
- **相似或重复部件容易混淆**：例如对称结构、多个外观相近的部件，文字位置描述未必足以区分；论文也展示了类似部件被合并的失败案例。
- **标签身份仍可能错配**：区域形状看似合理，不代表其 ID 一定对应正确提示项；direct mIoU 低于经过匹配的 mIoU，反映了这一问题。
- **数据与类别偏差**：训练数据依赖现有资产库和艺术家组件划分，类别分布及“一个部件应如何定义”的观念可能偏向常见对象和特定制作习惯。
- **评测范围有限**：核心定量评测依赖作者构造的数据集；生成资产仅做定性展示，尚未证明在更广泛的真实扫描、复杂拓扑或专业制作流程中同样稳定。

- **后续交互仍有提升空间**：作者提出可让语言模型与用户根据分割结果反复检查、修改提示，以解决歧义；当前方法主要依赖一次性规划和预测。
