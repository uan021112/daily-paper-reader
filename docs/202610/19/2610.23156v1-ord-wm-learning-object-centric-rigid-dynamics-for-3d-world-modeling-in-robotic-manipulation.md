tldr: 机器人操作需要预测动作如何改变物体状态，但现有图像式和稠密三维世界模型缺少显式刚体运动约束，多步推演容易出现形状漂移或物体运动不一致。ORD-WM采用带符号距离场监督的向量神经元变分自编码器，将点云编码为几何感知的三维向量特征，并预测物体级SE(3)运动增量。模型将刚性变换解析施加于当前潜状态，从而分离持久几何与姿态变化。实验显示其多步预测稳定保形，并支持仿真及真实操作中的实时闭环重规划。

## 摘要
世界模型为机器人提供了一种预测机制，使其能够在操作任务中推理动作如何改变物体状态。然而，现有基于图像和稠密三维表示的世界模型并未显式施加物体级刚体运动约束，而是将刚体物体几何形状的保持交由模型隐式学习，因此，多步展开预测容易出现形状漂移或物体级运动不一致。为解决这一问题，我们提出 ORD-WM，这是一种面向机器人操作、学习以物体为中心的刚体动力学的三维世界模型。ORD-WM 学习一个由有符号距离场监督的向量神经元变分自编码器，将每个物体的点云编码为由三维向量特征构成、具有几何感知能力的潜在表示，并采用动作条件化动力学模型预测物体级 SE(3) 运动增量。ORD-WM 不生成不受约束的下一时刻潜在状态，而是通过解析方式将预测得到的物体级刚体变换施加于当前潜在状态，从而将持续保持的物体几何形状与位姿变化分离。实验表明，ORD-WM 能够实现稳定且保持几何形状的多步预测，并支持在仿真和真实世界操作场景中，为闭环模型预测控制进行高效实时重规划。

## Abstract
World models provide robots with a predictive mechanism for reasoning about how actions change object states in manipulation tasks. However, existing image-based and dense 3D world models do not explicitly impose object-level rigid motion, leaving rigid-object geometry preservation to be learned implicitly and making multi-step rollouts susceptible to shape drift or object-level motion inconsistency. To address this, we propose ORD-WM, a 3D world model that learns object-centric rigid dynamics for robotic manipulation. ORD-WM learns a vector-neuron variational autoencoder supervised by signed distance fields, which encodes each object point cloud as a geometry-aware latent representation composed of 3D vector features, and uses an action-conditioned dynamics model to predict object-wise SE(3) motion increments. Rather than generating unconstrained next latent states, ORD-WM analytically applies predicted object-wise rigid transformations to the current latent states, separating persistent object geometry from pose changes. Experiments show that ORD-WM enables stable, geometry-preserving multi-step prediction and supports efficient real-time replanning for closed-loop model predictive control in simulated and real-world manipulation scenarios.

- **研究问题：**机器人在推、抓、搬运物体前，需要预测不同动作会怎样改变场景中的物体状态。现有图像式世界模型虽然能预测视觉变化，但缺少明确的度量三维状态；稠密三维模型则常通过逐点或逐元素更新来描述运动，刚体物体的整体运动一致性仍需模型从数据中隐式学得。

- **论文主张：**对于以刚性或近似刚性物体为主的操作任务，应将“物体几何保持不变”和“物体位姿变化”分开建模。ORD-WM据此把刚体运动结构直接纳入世界模型的状态转移过程，而不只要求网络自行学会保持形状。

# 2. 方法论

## 2.1 整体流程

ORD-WM从多视角RGB-D观测构建场景中的物体点云，为每个物体建立几何感知的潜在状态；随后，动作条件化的动力学模型预测各可移动物体的刚体运动增量，并将其直接作用于潜在状态。多步推演时，模型递归应用这些刚体更新，不必每一步重新分割图像、重建点云并编码物体。

## 2.2 几何感知的物体表示：SDF-VNVAE

- **观测处理：**使用SAM 3提取多视角图像中的物体掩码，将掩码应用于深度图并反投影到共同世界坐标系，再合并同一物体的多视角点云。
- **物体编码：**先减去点云质心，将居中的点云输入向量神经元（Vector Neuron, VN）编码器。编码器输出由三维向量特征构成的潜在均值 \(\mu\)，并通过辅助向量特征得到各潜变量的标量不确定度。
- **旋转等变性：**若物体点云旋转 \(R\)，其潜在向量特征也按同一旋转变换，即 \(\mu(R\circ P)=R\circ\mu(P)\)。这使得潜在特征本身可接受显式三维旋转。
- **形状监督：**解码器根据潜变量和查询点预测有符号距离场（SDF）。训练目标包括SDF重建、Eikonal正则项和KL正则项；解码器被设计为对潜变量与查询点的共同旋转保持不变。
- **物体状态：**训练后使用后验均值作为确定性几何潜变量，并将质心作为额外三维向量附加：
  \[
  s_t^i=[\mu_t^i;c_t^i].
  \]
  其中 \(\mu_t^i\) 表示物体几何，\(c_t^i\) 表示物体中心。

## 2.3 动作条件化的刚体动力学

- 场景物体被分为**可移动物体**和**固定物体**；固定物体作为静态场景上下文。
- 机器人本体状态通过正向运动学转换为夹爪各部分的几何 token，动作则表示为夹爪各部分的相对刚体变换。物体、夹爪状态和动作 token 经带角色嵌入的Transformer处理，以建模物体间及机器人—物体间的交互。
- 对每个可移动物体，模型预测平移增量 \(\Delta \hat{x}_t^i\) 和旋转表示，并将旋转投影到合法的 \(SO(3)\) 矩阵 \(\Delta\hat R_t^i\)。随后进行解析更新：
  \[
  \hat\mu_{t+1}^i=\Delta\hat R_t^i\circ\mu_t^i,\qquad
  \hat c_{t+1}^i=c_t^i+\Delta\hat x_t^i.
  \]
  因而，几何潜变量只接受刚体旋转，中心只接受平移；固定物体保持不变。
- 训练损失包括物体位姿损失，以及物体到夹爪、到最近可移动物体的辅助距离损失。

## 2.4 用于控制的模型预测控制

- 在每个控制周期，使用交叉熵方法（CEM）采样并优化候选动作序列，通过ORD-WM在潜在空间中预测其后果。
- 规划器只执行最优序列的第一步，获得新观测后重新规划。
- 推物任务的规划视野为8步，优化相对平面位移；文中还提到采用分阶段策略处理抓取、抬升和搬运等pick-and-place阶段。
