## 摘要
从长视频中重建高质量、可渲染的三维场景，对于机器人感知和具身智能至关重要。许多前馈式高斯重建方法能够根据少量图像快速预测三维场景，但将其扩展到更长序列时会面临两个瓶颈：联合处理所有视图会增加 GPU 内存需求；而累积像素对齐的预测结果，则会对相同表面进行冗余表示，增加存储和渲染成本。我们提出 LonGaussian，这是一种流式前馈框架，可根据具有已知相机内参、但相机位姿未知的长图像序列，重建紧凑且可进行全局渲染的高斯场景。LonGaussian 基于预训练的流式三维重建骨干网络，将长上下文几何特征解码为稠密高斯。在每个数据块内，多帧点轨迹关联对同一表面的重复观测，并引导一个学习式合并器整合相应的高斯预测结果。基于渲染深度的一致性筛选进一步抑制来自其他数据块、且会错误遮挡局部重建表面的高斯。在 DL3DV 和 RealEstate10K 基准上，与所评估的前馈基线方法相比，LonGaussian 在使用显著更少高斯的同时，提升了新视角渲染质量。

## Abstract
Reconstructing high-quality, renderable 3D scenes from long videos is essential for robotic perception and embodied intelligence. Many feed-forward Gaussian reconstruction methods rapidly predict 3D scenes from a small set of images, but extending them to longer sequences presents two bottlenecks: jointly processing all views increases GPU memory requirements, while accumulating pixel-aligned predictions redundantly represents the same surfaces and increases storage and rendering costs. We present LonGaussian, a streaming feed-forward framework that reconstructs compact, globally renderable Gaussian scenes from long image sequences with known intrinsics and unknown camera poses. Built on a pretrained streaming 3D reconstruction backbone, LonGaussian decodes long-context geometric features into dense Gaussians. Within each chunk, multi-frame point tracks link repeated observations of the same surface and guide a learned merger to consolidate the corresponding Gaussian predictions. Rendered-depth consistency filtering further suppresses Gaussians from other chunks that incorrectly occlude locally reconstructed surfaces. On DL3DV and RealEstate10K benchmarks, LonGaussian improves novel-view rendering quality while using substantially fewer Gaussians than the evaluated feed-forward baselines.

## 1. 核心问题与整体含义

- **研究目标**：从长视频或长图像序列中，快速重建可用于新视角渲染的三维场景。此类能力有助于机器人感知、具身智能和沉浸式媒体。
- **主要瓶颈**：
  - 许多前馈式重建方法需要联合处理多张图像，序列越长，计算和显存需求越高。
  - 许多高斯重建方法按像素预测高斯。长序列中的同一表面会被多次观测，直接累积这些预测会造成大量重叠高斯，增加存储和渲染负担。
- **论文的核心思路**：将长上下文几何重建与紧凑高斯场景构建结合起来。LonGaussian以流式方式处理图像序列，利用跨帧点轨迹识别重复观测并合并对应高斯，再通过深度一致性过滤处理跨数据块的遮挡伪影。
- **适用设定**：输入图像序列的相机内参已知、相机位姿未知；方法主要针对静态场景。

## 2. 方法论

### 2.1 整体流程

LonGaussian基于预训练的 **LoGeR** 长上下文几何重建模型，并保持其骨干网络冻结。序列被切分成有重叠的短数据块，逐块处理；每块的几何信息用于预测高斯，经过块内合并后，再累积到统一坐标系中。整体可概括为：

1. **流式几何预测**：LoGeR按块处理图像，利用局部注意力和跨块记忆提供长程几何上下文，并预测点图、相机位姿和特征。
2. **稠密高斯预测**：可训练的高斯分支为每个上下文像素预测一个高斯，包括中心偏移、尺度、旋转、不透明度及球谐颜色系数。
3. **轨迹引导合并**：在每个数据块内，使用冻结的 AllTracker 对图像点进行跟踪；同一轨迹中的高斯被视为同一表面的重复观测，并合并为一个代表高斯。
4. **全局伪影处理**：将各块的合并结果对齐并累积；通过渲染深度一致性筛除错误的跨块前景遮挡高斯，并对天空区域构造远场高斯壳层。

### 2.2 轨迹引导的高斯合并

- **轨迹筛选**：保留跟踪置信度高于阈值的观测，并确保每个帧像素最多归属于一条轨迹。轨迹至少需要两个有效观测，且平均不透明度达到阈值。
- **几何一致性检查**：计算轨迹内各高斯中心到其均值的均方根偏差；偏差过大的轨迹被拒绝，以避免把几何上不一致的预测错误合并。
- **合并方式**：对接受的轨迹，先通过不透明度加权等方式计算中心、尺度、颜色等属性的基础聚合值；再将观测的均值、标准差、可见帧比例等信息输入一个置换不变的学习式合并器，预测属性修正量。该合并器以零初始化，使其训练初期接近确定性聚合。
- **保留未覆盖区域**：无法获得可靠轨迹支持的稠密预测仍予以保留，避免合并导致场景内容缺失。

### 2.3 跨块深度过滤与天空建模

- 对每个数据块的高斯场景进行渲染，以局部深度和不透明度作为参考；再将其他块的高斯投影到该块的视图中进行比较。
- 若某高斯在多次可靠比较中持续处于参考表面前方，并达到设定的遮挡投票比例，则将其移除。块不会用自身视图否决自身预测。
- 天空像素由固定分割器识别，其有限深度高斯会被替换为远距离球壳上的高斯，以减少不可靠天空几何的影响。

### 2.4 训练目标与训练阶段

- 以渲染图像与真实图像之间的 RGB、LPIPS 和 SSIM 损失训练高斯分支与合并器；训练中还使用上下文视图和不参与高斯构建的目标视图提供监督。
- **第一阶段**：在短序列上训练稠密高斯预测分支，并加入尺度各向异性和中心偏移正则项。
- **第二阶段**：冻结 LoGeR 和特征解码器，先训练合并器，再在混合长度数据上联合适配合并器及部分高斯属性预测头。最终阶段加入深度过滤和远场天空建模。
- 跟踪、轨迹归属、过滤和天空分配等步骤是非可微的；梯度通过保留的高斯属性和可微渲染过程传播。

- 评测采用两遍式未标定位姿流程：第一遍估计上下文和目标视图位姿；第二遍仅用上下文图像构建场景。目标图像不用于生成高斯、轨迹、外观属性或过滤参考，但第一遍中目标图像参与位姿估计。

- 组件消融：比较稠密累积、确定性合并、去除稠密补充、去除深度过滤、去除远场天空壳层以及完整模型。

## 4. 资源与算力

- **训练 GPU**：使用 4 张 RTX 3090，每张显存为 24 GB；全局 batch size 为 4，每张 GPU 处理一个序列。

- 主结果覆盖 **2 个基准、每个基准 3 种序列长度**，比较 LonGaussian 与 4 个基线设置；AnySplat 和 WorldMirror 在报告的长度上均因显存溢出而无法提供数值结果。

## 6. 主要结论与发现

- 在 DL3DV 和 RE10K 的 64、96、128 帧设置中，LonGaussian整体取得更好的 PSNR、SSIM，并显著减少高斯数量。
- 例如 128 帧设置下：
  - DL3DV：LonGaussian 为 PSNR **18.31**、SSIM **0.536**、LPIPS **0.450**，高斯约 **4.80M**。
  - RE10K：LonGaussian 为 PSNR **18.23**、SSIM **0.561**、LPIPS **0.397**，高斯约 **2.15M**。
- LPIPS 并非所有设置都领先：RE10K 的 64 帧设置中，OF3GS 的 LPIPS 略优于 LonGaussian。
- 消融结果显示，深度过滤对 PSNR 的改善尤其明显；删除稠密补充会降低重建质量，说明仅保留具有可靠轨迹的高斯会损失场景内容。学习式合并器相较确定性合并也改善了部分渲染指标。
- 单场景长序列实验表明，构建时间和高斯数量随序列长度近似线性增长，而峰值显存基本稳定；但长序列上的局部渲染质量整体有所下降。

## 7. 优点

- **针对两个不同瓶颈设计方案**：LoGeR的分块和混合记忆处理长上下文，轨迹合并控制重复高斯，避免把长视频问题简化为单纯压缩。
- **利用显式跨帧对应关系**：以跟踪轨迹作为合并依据，直接关联同一表面的重复观测，比只按空间距离或体素邻近度合并更具解释性。
- **兼顾紧凑性和覆盖率**：在合并轨迹高斯的同时保留无可靠轨迹支持的稠密预测，减少因过度合并造成的内容缺失。
- **设置了跨块伪影处理环节**：深度一致性投票和天空壳层分别面向跨块浮点伪影和不稳定天空几何，并有消融实验支持其作用。
- **长序列资源结果较清楚**：报告了序列增长时的显存、耗时和高斯数量，显示该方法在单场景案例中可处理数千帧。

## 8. 不足与局限

- **位姿长程漂移未解决**：LoGeR在长距离重访处可能发生对齐误差。论文指出，完整场景渲染会出现明显鬼影；七块范围内的局部渲染指标因此不能代表整幅全局场景的渲染质量。
- **长序列评测覆盖有限**：最长序列实验只针对一个场景，且多个前缀共享同一条完整序列的第一遍位姿轨迹，不等同于严格的仅前缀因果位姿估计评测。
- **方法依赖场景静态与跟踪可靠性**：动态物体可能使轨迹错误关联；纹理弱、反光或长期遮挡区域可能产生断裂轨迹，导致重复高斯未被合并。
- **存在固定尺度阈值问题**：轨迹几何门限使用骨干重建坐标中的绝对距离，作者明确指出它并非尺度不变，也未独立评估其敏感性。
- **过滤可能误删结构**：深度参考不稳定时，薄结构可能被移除；天空分割错误也可能把有限深度的真实场景内容替换为天空壳层。
- **额外处理带来开销**：跟踪、深度投票和天空分割增加了计算时间；论文没有给出完整训练墙钟时间，也未全面拆分各阶段的推理耗时。
- **基线比较存在可比性限制**：AnySplat 和 WorldMirror 因显存不足而没有可比结果；ReCoSplat适配版是本地分辨率适配而非官方训练复现。不同方法的位姿预测误差也会影响渲染指标。
- **应用边界明确**：论文面向已知内参、静态场景的输入，动态场景、跨块轨迹关联、不确定性感知过滤和更可靠的全局回环对齐仍有待研究。
