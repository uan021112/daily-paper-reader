# Continuous-Action World Models: Learning Cross-Embodiment Spatiotemporal Dynamics Priors 

# Liangyu Li * Qingwen Liu †

# Abstract 

We introduce Continuous-Action World Models (CoAWM), a framework for learning cross-embodiment spatiotempo-ral dynamics priors that support robot action generation across embodiments and execution frequencies. At its core is a shared latent function space that captures the spa-tial and temporal structure of robot actions. We learn this space through two stages. First, function pretraining brings trajectories from different embodiments and sampling fre-quencies into a common representation, learning shared dynamics priors through action reconstruction and consis-tency across temporal sampling views. By accommodat-ing heterogeneous robot trajectories, this stage broadens the range of data sources available for pretraining and fa-cilitates scaling to larger and more diverse datasets. Sec-ond, we connect the pretrained function space to a world-model backbone, enabling observations, language instruc-tions, and the current robot state to condition the prediction of a latent action function. A single decoder takes any query time and returns the corresponding end-effector action. By separating shared dynamics priors from task-conditioned action selection and temporal sampling, our approach pro-vides a unified foundation for transferring robot experience across embodiments and control frequencies. 

# 1. Introduction 

Robots with different bodies can perform similar tasks, yet their experience is recorded through different action inter-faces and control frequencies [3, 13, 24]. A reaching motion may be demonstrated by one manipulator and executed by another, with different command sequences governing a re-lated physical behavior. This diversity raises a central ques-tion for robot world models: how can experience collected across embodiments be used to learn shared spatiotempo-ral dynamics priors that guide action generation? Robot datasets differ in what their actions specify, how those actions are grounded in the robot’s state, and when commands are issued. The same sequence index can corre-spond to different physical times, while numerically similar commands can have different meanings across action inter-faces. A common storage format alone does not resolve these differences. To learn from heterogeneous experience, a model needs a representation that captures reusable spa-tial and temporal structure while retaining the information required to interpret and execute an action on a particular robot. For a world model, this representation must also connect shared experience to action selection in the current scene and task. Our key insight is to learn the evolution of an action as a function, rather than treating its sampled commands as the fundamental object of representation. A latent action function encodes how a motion unfolds in space and time; individual commands are obtained by querying that func-tion (Fig. 2). This provides a common learning space for trajectories sampled at different frequencies. More impor-tantly, it separates two complementary learning problems: acquiring dynamics priors from heterogeneous trajectories, and selecting an action using the current interaction context. The former can draw on a broader pool of robot experience, while the latter connects these priors to the observation-conditioned capabilities of a world model. We introduce Continuous-Action World Models (CoAWM) to realize this idea through two stages (Fig. 1). First, we pretrain a shared latent function space using trajectories from different embodiments and sampling frequencies. A function encoder and decoder learn spa-tiotemporal dynamics priors through action reconstruction and consistency across temporal sampling views. This pre-training stage expands the range of trajectory sources that can contribute to representation learning, providing a path toward larger and more diverse training datasets. Second, we connect the pretrained function space to a world-model backbone. # 2. Related Work 

2.1. Continuous Action and Function Representa-tions 

Action representations determine how a policy organizes motion over time. ACT predicts action chunks [34], Dif-fusion Policy generates action sequences through denois-ing [10], and FAST compresses temporal structure into frequency-domain tokens [26]. Continuous action repre-sentations capture how motion evolves over time and allow actions to be queried at different execution times. Dynam-ical Movement Primitives encode motor behavior through attractor dynamics and learned forcing terms [16], Proba-bilistic Movement Primitives model distributions over tra-jectories [25], and ProDMPs connect these dynamic and probabilistic formulations [19]. These foundations estab-lish motion trajectories as structured objects from which reusable action priors can be learned. Recent visuomotor policies explore different function families and decoding mechanisms. FLASH represents trajectories with a Legendre basis and history-anchored flow [2], while B-spline Policy uses control points and knots to parameterize actions [14]. Neural Implicit Action Fields learn modulated continuous-time action functions and supervise their temporal derivatives [20]. Periodic-activation implicit networks provide a general foundation for coordinate-queryable neural functions and their deriva-tives [27]. These efforts to represent actions motivate us to learn shared spatiotemporal dynamics priors through a con-tinuous function representation. A latent function representation captures how motion evolves over time. A decoder takes this representation and a time query to produce the corresponding action. Query-ing the same representation at different times yields ac-tion sequences at different temporal resolutions. FunDiff combines function encoding, latent diffusion, and continu-ous decoding for physical-field generation [30]. Function-Space Diffusion for Motion Planning models trajectory dis-tributions using temporally correlated noise and boundary-compatible operators [7]. CAT learns a fixed-size set of con-tinuous trajectory latents over a physical-time window and uses frequency-aware positional encoding with a causal ac-tion decoder to accommodate different control rates [31]. These works establish important precedents for learning continuous representations and transferring between tem-poral resolutions. CoAWM focuses on learning shared spatiotemporal dynamics priors from heterogeneous robot trajectories and connecting the resulting function space to world-model-conditioned action generation. 

2.2. Cross-Embodiment Learning and Action Pri-ors 

Cross-embodiment learning expands the experience avail-able for robot policy training. Open X-Embodiment brings together robot datasets and studies cross-robot policies [24]. Octo develops generalist pretraining and adaptation to new observation and action spaces [13], and π0 combines a vision-language model with flow-based action generation for general robot control [3]. These approaches make het-erogeneous data a practical resource for learning behavior across tasks and robot systems. A central representation question is which structure can be shared while maintaining a meaningful connection to each robot’s executable actions. Latent-action learning addresses this question by sepa-rating reusable action knowledge from specific command spaces. LAPA learns latent actions from video before adapt-ing them to robot control [32], and UniVLA learns task-centric latent actions for embodiment transfer [5]. LAC-WM learns shared latent actions from visual transitions with auxiliary motion reconstruction for cross-embodiment world modeling, and reports benefits from increasing the di-versity of pretraining embodiments [15]. These results mo-tivate shared action priors for both control and prediction. CoAWM approaches this problem through action trajecto-ries: a function autoencoder learns their spatial and tempo-ral structure, and an observation-conditioned head connects the pretrained function space to a world-model backbone. Its pretraining interface is designed to accommodate trajec-tories from multiple embodiments and sampling frequen-cies, broadening the sources of data available for learning dynamics priors. 

2.3. World Models for Action Generation and Exe-cution 

World models connect experience to predictions that sup-port action selection. V-JEPA 2 adapts self-supervised video representations for action-conditioned prediction and planning [1]. LAWM learns latent actions through future-frame modeling [28], while Learning Latent Action World Models In The Wild investigates continuous-valued latent actions for prediction and controllable interaction [12]. villa-X combines latent-action modeling with visual and proprioceptive forward dynamics and robot-action predic-tion [9]. Alongside LAC-WM [15], these approaches high-light the role of an action representation in linking predicted transitions to executable behavior. LaWAM conditions action generation on predicted la-tent visual subgoals and explicitly supports physical-time alignment and mixed-frequency training [8]. Its mixed-30 T

CoAWM complements these execution mechanisms by sep-arating the latent action function, the times at which it is queried, and the physical timing of the represented motion. 

# 3. Method 

3.1. Overview 

Continuous-Action World Models (CoAWM) connect world model and action generation through a pretrained space of action functions. The central representation is a latent function that describes how an action evolves over physical time. A decoder takes this latent function and time queries to produce the corresponding actions, enabling ac-tion generation at different execution frequencies through queries at the corresponding time points. CoAWM uses two training stages. Stage A learns an action-function encoder and decoder from timestamped robot trajectories. A Mixture-of-Transformers (MoT) en-coder combines specialized processing of end-effector posi-tion, orientation, and gripper commands with joint attention across these action components. Training aligns representa-tions of the same motion observed at different frequencies. This provides a shared function space for learning from tra-jectories collected across robot embodiments and at differ-ent frequencies, broadening the data available for pretrain-ing. Stage B connects the learned function space to a world-model backbone. The prediction head combines VLM fea-tures, predicted future visual features, and robot proprio-ception, with current visual features contributing through an output residual. It predicts a function in the pretrained space. Expert trajectories supervise both its latent repre-sentation and the actions obtained by decoding it. At in-ference, the decoder queries the predicted latent function at time points determined by the desired execution frequency.

Mixture-of-Transformers for Action Function En-coding. The MoT encoder brings position (XYZ), orien-tation (Q), and gripper (G) components into a shared latent function representation. In the dual-arm implementation, these streams contain six position coordinates, eight quater-nion coordinates, and two gripper commands. Each stream combines the corresponding components of both arms. In-put tokens incorporate timestamps and validity masks, so the encoder can process different temporal views without treating missing observations as valid commands. The encoder first aggregates trajectory tokens into learned latent queries through typed Perceiver blocks. La-tent MoT blocks then exchange information across the three action-component streams. Each stream has its own query, key, value, and output projections, normalization layers, and feed-forward networks. Attention is computed jointly over all streams, allowing the specialized Transformer parame-ters to model each action component while shared attention captures their temporal coordination. The bottleneck con-tains 96 tokens of width 256, with 32 tokens allocated to each modality. 

Independent time queries. The decoder forms a query from the requested physical time, its Fourier features, a modality embedding, and known execution information. Typed cross-attention blocks read the latent memory and produce XYZ, Q, and G outputs. Each requested times-tamp is evaluated through its own query-to-memory atten-tion. Consequently, an action at a given timestamp does not depend on the number or ordering of the other requested timestamps. A single latent can therefore produce actions at different execution frequencies through the correspond-ing time queries.

# 4. Experiments 

We evaluate continuous action functions from four per-spectives: representation accuracy, closed-loop execution, cross-frequency querying, and action quality. We first ex-amine whether the function space can accurately represent robot actions, then evaluate task performance after align-ment with LaWAM, focusing on the effect of the con-tinuous representation on the smoothness of initial execu-tion. (These experiments provide a rapid validation of the method; a subsequent arXiv version will expand the training scale and perform full fine-tuning.) 

4.1. Representation Accuracy of Continuous Ac-tions 

A continuous function representation preserves action de-tails while providing a unified query interface for differ-ent time points. On 8,192 held-out evaluation windows, the function autoencoder achieves a position reconstruction error of 2.503 mm and a rotation error of 0.2295 ◦. This result shows that the function space can represent the origi-nal action trajectories with high accuracy, providing a repre-sentation foundation for subsequent world-model alignment (Fig. 3). 

4.2. Smoother Initial Execution at Similar Move-ment Speeds 

Continuous action functions significantly reduce abrupt changes in motion during initial execution. Across 16 tasks and 800 pairs of matched initial conditions, we measure mo-tion metrics over the first second of each execution. 4.3. Multitask Manipulation and Cross-Frequency Execution 

The aligned function policy can perform a variety of biman-ual manipulation tasks. In evaluations with 50 trials per task, it achieves a success rate of 94% on the two-bottle task, 90% on both left and right A2B tasks, 88% on the burger task, and 86% on the hammer task. In a separate preliminary evaluation covering 50 tasks with three trials per task, both methods complete all three trials on 30 tasks. By changing the time query points, the same function policy can output actions at 10, 15, 20, 30, 50, and 60 Hz while keeping the execution segment and replanning period fixed at 1.2 s. The corresponding numbers of successes are 116, 121, 117, 119, 116, and 110, with 150 trials evalu-ated at each frequency. These results demonstrate cross-frequency execution within a fixed physical-time window (Fig. 5).

# 5. Discussion 

Continuous function representations separate the learning of action structure from the choice of execution frequency. The model learns how actions evolve over physical time, while the execution side obtains commands at the required frequency through time queries. Execution frequency can therefore be adjusted while keeping the action-segment du-ration and replanning period unchanged, allowing the same action representation to serve different execution clocks. This representation also makes action quality an im-portant evaluation dimension alongside task success rate. The current experiments demonstrate high trajectory recon-struction accuracy and smoother initial execution at simi-lar movement speeds. At the same time, offline reconstruc-tion quality, closed-loop task success rate, and stability dur-ing sustained execution have different optimization require-ments. The shared function space provides a unified interface for expanding the training scale. During function pretrain-ing, we will introduce action trajectories from more em-bodiments and collection frequencies; during world-model alignment, we will further perform full fine-tuning, using visual predictions and task information to learn task-related action functions. Subsequent experiments will examine how larger-scale data and training affect task performance, cross-embodiment transfer, and stability during sustained execution. 

# 6. Conclusion 

We present CoAWM, which connects action representation learning, world-model prediction, and time-query execution through a shared function space. Two-stage training uses the spatiotemporal structure in trajectories for task-related action generation and supports different execution frequen-cies through time queries.
