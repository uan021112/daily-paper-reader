PhysInsert: Physically Plausible Object Insertion with
Geometric Priors and Bidirectional Object-Scene Interactions
Yue Gong1,2,∗, Le Zhang2, Rui Chen2, Song Chang2,
Xiaochao Qu2, Luoqi Liu2, Ting Liu2,†, Yebin Liu3,†
1School of Computer Science and Engineering, Beihang University
2MT Lab, Meitu Inc.
3Department of Automation, Tsinghua University
Abstract
We present PhysInsert, a framework for physically plausible reference-based object insertion
that jointly adapts objects and their surrounding scenes. Existing methods often rely on masked
inputs, generation-based pairs, or training pairs with limited viewpoint variation, leaving pose
and illumination adaptation and bidirectional object–scene interactions insuﬀiciently constrained.
We construct the Insert World dataset with strictly aligned Blender-rendered counterfactual
pairs and object references across viewpoints and lighting conditions. Building on these data,
Geometry-Guided Adaptation couples a VGGT geometry stream with image and text streams un-
der target-scene feature supervision to guide spatially consistent insertion. Complementary 2D
Object–Scene Spatial Supervision jointly supervises object occupancy and environmental changes
while grounding spatial instructions in object regions through image–text attention. We introduce
PhysInsert-Bench with dedicated cross-environment and cross-view cases requiring illumination
and pose adaptation beyond appearance copying. Experiments on PhysInsert-Bench and Dream-
Booth demonstrate improved image fidelity; A user study further show more accurate placement
and improved lighting integration, perspective, and pose plausibility.

Introduction
Reference-based object insertion aims to integrate a specified object into a target scene while pre-
serving its identity. Physically plausible insertion further requires geometric and optical consistency,
with the object’s perspective, pose, appearance, and effects on its surroundings all adapted to the
target scene.
As illustrated in Figure 1, despite recent progress, three challenges remain in physically plausible
object insertion. (a) Adaptation across environments. Existing methods (Chen et al., 2024a;
Song et al., 2025; Tian et al., 2025) can insert objects into new scenes, but provide limited controlled
supervision for adapting the same object across lighting environments. (b) Bidirectional object–
scene interactions. Mask-and-fill methods (Gong et al., 2026; Yu et al., 2025) may adapt object
illumination yet struggle to produce consistent scene changes; training pairs constructed through
masking or generative editing (Chen et al., 2024a; Song et al., 2025) do not guarantee accurate
supervision of shadows and reflections.
Training examples with simplified backgrounds (Michel
et al., 2023) also underrepresent complex occlusion, attachment, and spatial relationships with
existing scene objects.
(c) Adaptation across viewpoints.
Even with consistent illumination,
differing reference and target viewpoints still require perspective and pose adaptation; fixed-view
training pairs (Yang et al., 2023; Wang et al., 2025b) offer limited supervision for this change.
Reliance on mask or box guidance also limits fine-grained text control of placement and pose (Chen
et al., 2024a; Gong et al., 2026). Methods relying primarily on 2D image supervision (Chen et al.,
2024a; Song et al., 2025) lack direct constraints on object–scene geometry, making it diﬀicult to
guide adaptation to the target perspective and pose.
We propose PhysInsert, a framework combining counterfactual scene data, geometric priors, and
spatial guidance for physically plausible object insertion.
To provide counterfactual supervision for object–scene adaptation, we construct InsertWorld from
strictly aligned pairs rendered by changing only object presence in complete scenes, capturing both
scene-dependent object appearance and object-induced environmental changes. Object references
rendered across lighting environments and viewpoints support cross-environment and cross-view
adaptation. Paired with spatial instructions, these examples support text-guided control of place-
ment and complex interactions with existing scene objects.
To align object perspective and pose with the scene’s 3D structure, Geometry-Guided Adaptation
models post-insertion geometry as a supervised intermediate representation. Initialized from back-
ground VGGT features, a dedicated geometry stream evolves through joint attention with image and
text tokens, with its feature readouts supervised against VGGT features of the with-object scene.
The geometry stream remains active at inference to guide scene-consistent object adaptation.
To localize insertion-induced changes and ground spatial instructions in the image, we complement
geometric adaptation with two forms of 2D supervision. Counterfactual Object–Scene Supervision
uses object masks and aligned scene pairs to jointly supervise object occupancy and external effects.
Soft-Mask Spatial Grounding aligns image–text attention with the object region to translate spatial
instructions into placement control while retaining the full background input.
To evaluate scene adaptation beyond appearance copying, we construct PhysInsert-Bench with
cases requiring illumination or pose adaptation and include text-guided and real-world evaluations.
Our main contributions are as follows:
2


• Dataset: InsertWorld combines strictly aligned counterfactual scene pairs, cross-view and
cross-lighting object references, and spatial instructions to support learning object adaptation
and complex object–scene interactions.
• Method: PhysInsert combines a background-initialized geometry stream supervised toward
post-insertion scene features with 2D supervision, improving cross-environment and cross-view
insertion and text-guided placement.
• Benchmark: PhysInsert-Bench tests illumination and pose adaptation beyond appearance
copying through dedicated cross-environment, cross-view, and in-the-wild cases.

Related Work
Physics-aware Image Generation and Editing.
Recent work has sought to improve the physical
plausibility of image editing by modeling scene geometry and physical interactions. PhysicEdit (Zhao
et al., 2026) learns video-based transition priors to model causal physical changes in instruction-
based editing. PhyEdit (Xu et al., 2026) relocates existing objects within a scene using geometric
guidance and depth supervision.
Object3DIT (Michel et al., 2023) supports language-guided
translation, rotation, insertion, and removal in procedurally rendered scenes; its insertion specifies
objects through text rather than external reference images. Our task requires preserving a reference
object’s identity while adapting its viewpoint, illumination, and interactions to a new scene.
Reference-based Object Insertion.
For supervision, ObjectDrop (Winter et al., 2024) and Omni-
Paint (Yu et al., 2025) use real counterfactual pairs, supplemented by generated bootstrapping
or insertion–removal cycles. ObjectMate (Winter et al., 2025) and Insert-Anything (Song et al.,
2025) construct backgrounds through learned editing, whose accuracy depends on the editor; PS-
Diffusion (Wang et al., 2025b) uses rendered pairs. For control, mask-based methods (Yang et al.,
2023; Chen et al., 2024a; Yu et al., 2025) discard background information within the editing region,
while ObjectMate uses boxes, Insert-Anything also supports text guidance, and DIRECT (Gong
et al., 2026) requires 3D proxy reconstruction and placement for pose control. For viewpoint adap-
tation, Paint by Example derives same-image references, PS-Diffusion retains the target viewpoint,
and ObjectDrop preserves pasted-object pose and illumination; AnyDoor, Insert-Anything, and
ObjectMate incorporate multiview data. PhysInsert combines controlled counterfactual rendering
and diverse references with supervised geometry states, object–effect supervision, and spatial-text
grounding.

3.2
Dataset Construction
To reduce interpenetration and floating artifacts from random placement, we construct InsertWorld
by removing existing objects from complete BlenderKit scenes (Figure 2). We render each scene
with and without the object under fixed camera, lighting, and remaining scene settings, recomputing
its shadows, mirror images, and reflections.
These strictly aligned counterfactual pairs capture
scene-dependent object appearance and object-induced environmental changes. Quality filtering
and object deduplication retain suitable scene–object combinations.
We augment scene viewpoints and independently render each retained object across lighting en-
vironments and viewpoints to provide references for cross-environment and cross-view adaptation.
Each example combines an object-free background, a with-object target, and reference images with
Gemini-generated annotations comprising an editing instruction, a placement description, and a
target-pose description. Filtering and sampling details are provided in Appendix I.

4.1
Geometry-Conditioned Object Insertion
Our method combines Geometry-Guided Adaptation (GGA) for scene-consistent object adaptation
with 2D Object–Scene Spatial Supervision (2D-OSS) for object regions, environmental changes,
and spatial-text alignment (Figure 3). In our Qwen-Image-Edit-2511 backbone, the image stream
U0 contains the noisy target latent and frozen-VAE encodings of the complete background and
references; a frozen multimodal encoder produces text tokens T0 from the instruction and image
context. Implementation and loss details are provided in Appendix E.
4.1.1
Geometry-Guided Adaptation
To guide scene-consistent object adaptation, GGA initializes a dynamic geometry stream from
background features F−extracted by frozen VGGT (Wang et al., 2025a). An MLP Aϕ maps these
features to the DiT hidden space, with a learned geometry-modality embedding eG. Geometry,

4.2
Benchmark Construction
As shown in Figure 2(b), PhysInsert-Bench evaluates optical and spatial–pose adaptation using
aligned counterfactual scene pairs.
Optical cases emphasize illumination differences and visible
object-induced scene changes; their challenge cases and Structural cases additionally provide in-
dependent reference viewpoints to test pose adaptation. Each case is annotated for bidirectional
interactions in lighting, spatial relationships, and pose, with physical-effect labels and evaluation-
focus tags identifying the effects emphasized by that case.

Evaluation Metrics.
We use PSNR and SSIM (Wang et al., 2004), LPIPS (Zhang et al., 2018), and
FID (Heusel et al., 2017) to evaluate full-image fidelity, and DINO-Obj. to assess object identity
preservation. Following PhyEdit (Xu et al., 2026), we use DIoU to measure object placement with a
center-distance penalty, while Mask IoU measures visible-object overlap, including differences in vis-
ible extent caused by occlusion. AbsRel and δ1.25 assess estimated object-region depth consistency
as a proxy for geometric plausibility. We also adapt the VLM-based physical plausibility evaluation
of PhyEdit (Xu et al., 2026) as Phy-VLM, using GPT-5.5 with a fixed prompt template augmented
by each case’s physical-effect annotations and evaluation-focus tags (§4.2). These tags direct atten-
tion to the physical effects emphasized by that case. Metric definitions and implementation details
are provided in Appendix D.

Conclusion
We presented PhysInsert, combining InsertWorld’s counterfactual scene pairs and references across
viewpoints and lighting with a VGGT geometry stream and 2D object–scene supervision for joint
object and scene adaptation.
PhysInsert-Bench and PhysInsert-Bench-Wild evaluate controlled
adaptation and real-world generalization. Experiments demonstrate improved image fidelity and
placement, supporting joint modeling of objects and their surroundings for physically plausible
insertion.

A
Limitations
PhysInsert does not explicitly optimize for object identity preservation. Its ability to preserve iden-
tity remains limited when the reference and target viewpoints differ substantially. Future work
could better exploit complementary information across multiple reference views to preserve distinc-
tive object features under large viewpoint changes.
B
Geometric Foundation Models
VGGT (Wang et al., 2025a) jointly predicts camera parameters, depth, and 3D scene structure,
while Depth Anything 3 (Lin et al., 2025) recovers consistent geometry across views. Geometry
alone does not determine insertion-induced shadows and reflections, motivating our combination of
geometric priors and counterfactual supervision.

D.5
VLM-Based Physical Plausibility
We adapt the VLM-based physical plausibility assessment in PhyEdit (Xu et al., 2026) to PhysInsert-
Bench, using GPT-5.5 to evaluate the outputs of all compared methods on the same 400 cases.
Each evaluation prompt combines a fixed template with the case’s annotated physical effects and
evaluation-focus tags from Appendix I.1. The tags specify which physical effects warrant particular
attention, such as illumination adaptation, cast shadows, reflections, or occlusion relationships, as
applicable to the case. The same template and case-specific tag information are used across methods.
For each method and case, we obtain three valid numerical ratings, retrying any evaluation that
returns null until three valid ratings are available. No case is excluded because of a null response.
We first average the three valid ratings within each case, then average these case-level scores equally
over all 400 cases. We report the resulting Phy-VLM mean with the half-width of its 95% confidence
interval; higher values indicate greater physical plausibility as judged by the VLM.

Dataset Construction Details
Sample Filtering and Deduplication.
We randomly select candidate objects from complete BlenderKit
scenes and render counterfactual pairs under fixed camera, lighting, and remaining scene settings,
recomputing shadows, mirror images, and reflections after removal. Rule-based filtering first rejects
pairs with excessively small or large image changes. Gemini then examines the scene pair and object
views for object completeness, background plausibility after removal, image quality, and realism,
excluding unsuitable scene structures, residual semantic parts, and visible rendering artifacts. We
deduplicate retained objects using DINO feature similarity while retaining their associated scenes.
The complete Gemini quality-scoring and interaction-classification prompts, including image order
and JSON output examples, are reproduced in Appendix J.1.
Scene Augmentation.
For each retained scene–object combination, we keep the object and scene
configuration unchanged while randomly varying the camera position. At each viewpoint, we reren-
der a matched with/without pair and apply a second quality check.
Object Reference Rendering.
Each deduplicated object is independently rendered under seven light-
ing conditions: fixed white light, fixed studio lighting, and five randomly sampled HDR environ-
ments.
For each condition, we use 11 fixed and 12 random viewpoints while preserving object
geometry and material, yielding 7 × 23 = 161 reference images per object. These references are
associated with the corresponding scene pairs.

We construct 40 test cases covering all objects in DreamBooth. For each case, we
randomly select one image as the target and use the remaining images of the same object as the
reference pool; we report one-reference evaluation. We remove the object from the target image
using Nano Banana Pro and manually review the resulting background.
PhysInsert-Bench-Wild.
The 50 cases draw on Amazon Berkeley Objects (ABO) (Collins et al.,

from NAVI, and cross-scene observations of the same object from ORIDa. For the SAM 3D-based
cases, we use real target images and render reference views from SAM 3D Objects reconstructions.

User Study Protocol
We collect complete responses from 27 distinct participants on 25 in-the-wild insertion cases, com-
paring PhysInsert, Insert-Anything, DIRECT, and Nano Banana Pro. Method identities are hidden,
and case and method orders are randomized. These cases form a separate user-study set constructed
by combining scenes from RealBokeh with foreground objects from Distinctions-646. With the back-
ground and object reference visible, participants rate side-by-side results from 1 to 5 (higher is better)
on lighting integration (including object illumination and cast shadows), perspective, pose, identity
preservation, and background preservation. We average over cases within each participant, then
across participants; the overall score equally weights the five criteria.
The error bars in Figure 4 show 95% percentile confidence intervals estimated from 50,000
participant-level bootstrap resamples, with the 25 cases held fixed.
